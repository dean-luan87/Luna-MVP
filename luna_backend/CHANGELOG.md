# Luna Backend 变更日志

## [1.2.0] - 2025-11-19

### 🎉 工程化重构版本

#### ✨ 新增功能

- **模块化架构**: 完整的目录结构，分离路由层和服务层
- **错误码体系**: MFFF格式错误码，覆盖所有模块
- **统一日志系统**: [LUNA][模块名][LEVEL] 格式
- **统一响应格式**: 标准化的API响应结构
- **异常体系**: 模块化异常类，支持错误码

#### 🏗️ 架构变更

- 创建 `luna_backend/` 新目录结构
- 分离 `routes/` 路由层和 `services/` 服务层
- 创建 `core/` 核心模块（日志、异常、响应）
- 创建 `config/` 配置模块（设置、常量、错误码）

#### 📝 文档

- 工程规范文档 (`docs/ENGINEERING_STANDARDS.md`)
- 迁移指南 (`docs/MIGRATION_GUIDE.md`)
- 架构文档 (`docs/V1.2.0_ARCHITECTURE.md`)

#### 🔧 技术改进

- 错误码体系：9个模块，每个模块1000个错误码空间
- 日志格式：统一格式，支持模块标识
- 响应格式：统一的成功/错误响应结构
