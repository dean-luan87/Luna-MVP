### 1. routes/tts_routes.py ✅

**功能**: TTS API完整拆分版

**路由列表**:
- `POST /tts/generate` - 语音合成
- `GET /tts/cache/stats` - 缓存统计

**特性**:
- ✅ 调用services层的TTSEngine
- ✅ 自动错误码上报
- ✅ 支持style、voice、rate参数
- ✅ 向后兼容路由

**使用示例**:
```bash

  -H "Content-Type: application/json" \

# 缓存统计
curl http://localhost:9001/tts/cache/stats
```

### 3. routes/cache_routes.py ✅

**功能**: 缓存管理（图像 / TTS / 路径 / 临时文件）

**路由列表**:
- `POST /cache/clear_all` - 清空所有缓存
- `GET /cache/stats` - 获取所有缓存统计
- `POST /cache/clear/<cache_type>` - 清空指定类型缓存

**特性**:
- ✅ 统一管理所有缓存类型
- ✅ 支持按类型清空
- ✅ 缓存统计信息
- ✅ 自动记录日志

**使用示例**:
```bash
# 清空所有缓存
curl -X POST http://localhost:9001/cache/clear_all

# 获取缓存统计
curl http://localhost:9001/cache/stats

# 清空TTS缓存
curl -X POST http://localhost:9001/cache/clear/tts
```
