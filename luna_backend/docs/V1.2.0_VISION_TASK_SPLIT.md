### 二、TaskChain × SceneMemory 拆分

#### 1. services/task/task_engine.py ✅

**功能**: 后端统一任务链引擎

**特性**:
- ✅ 支持同步/异步任务
- ✅ 顺序执行
- ✅ 记录错误 & 上报错误码
- ✅ 任务队列管理

**方法列表**:
- `enqueue(task)` - 入队任务
- `clear()` - 清空任务队列
- `running` - 是否正在运行
- `queue_length` - 队列长度

**使用示例**:
```python
from services.task import get_task_engine

task_engine = get_task_engine()

# 同步任务
task_engine.enqueue(lambda: print("同步任务"))

# 异步任务
async def async_task():
    await asyncio.sleep(1)
    print("异步任务")

task_engine.enqueue(async_task)
```

#### 2. services/memory/scene_memory_service.py ✅

**功能**: 场景记忆 + 本地地图服务

**特性**:
- ✅ 记录关键节点（门、楼梯、电梯、标识牌等）
- ✅ 维护小范围地图
- ✅ 为导航/任务链提供上下文

**方法列表**:
- `is_ready()` - 检查服务是否就绪
- `add_node(node_type, position, meta)` - 添加节点
- `get_nodes()` - 获取所有节点
- `update_pose(dx, dy, angle_delta)` - 更新位姿
- `export_map()` - 导出地图

**使用示例**:
```python
from services.memory import get_scene_memory_service

scene_service = get_scene_memory_service()

# 添加节点
scene_service.add_node(
    node_type="door",
    position=(10.5, 20.3),
    meta={"label": "会议室A", "confidence": 0.9}
)

# 更新位姿
scene_service.update_pose(dx=1.0, dy=0.5, angle_delta=15.0)

# 导出地图
map_data = scene_service.export_map()
```
