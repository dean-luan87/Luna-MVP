## 🏗️ 架构设计

### 分层架构

```
┌─────────────────────────────────┐
│         Routes Layer            │ 路由层：参数解析、调用service、返回响应
├─────────────────────────────────┤
│        Services Layer           │ 服务层：业务逻辑、算法、模型调用
├─────────────────────────────────┤
│         Core Layer              │ 核心层：日志、异常、响应、错误管理
├─────────────────────────────────┤
│        Config Layer             │ 配置层：设置、常量、错误码
└─────────────────────────────────┘
```

### 模块职责

| 模块 | 职责 | 示例 |
|------|------|------|
| **Routes** | API端点定义、参数验证、调用service | `routes/tts_routes.py` |
| **Services** | 业务逻辑、算法实现、模型调用 | `services/tts/tts_manager.py` |
| **Core** | 基础设施（日志、异常、响应） | `core/logger.py` |
| **Config** | 配置管理、错误码定义 | `config/error_codes.py` |

## 🔢 错误码体系

### 格式规范

`MFFF` 格式：
- `M`: 模块编码（1位）
- `FFF`: 具体错误（3位）

### 模块编码表

| 模块 | 代码 | 范围 | 示例 |
|------|------|------|------|
| TTS | 1 | 1001-1999 | 1001: TTS初始化失败 |
| Vision | 2 | 2001-2999 | 2001: 图像格式错误 |
| Navigation | 3 | 3001-3999 | 3001: 导航管理器未初始化 |
| Scene | 4 | 4001-4999 | 4001: 节点检测器错误 |
| Path | 5 | 5001-5999 | 5001: 路径规划失败 |
| Performance | 6 | 6001-6999 | 6001: 降级模块异常 |
| Event | 7 | 7001-7999 | 7001: 事件桥接失败 |
| System | 8 | 8001-8999 | 8001: SSL加载失败 |
| Common | 9 | 9001-9999 | 9001: 参数缺失 |

详见 `config/error_codes.py`

## 📝 使用示例

### 路由层示例

```python
# routes/tts_routes.py
from flask import Blueprint, request
from services.tts import tts_service
from core import api_success, api_error
from config.error_codes import TTS_TEXT_EMPTY

bp = Blueprint('tts', __name__)

@bp.route('/tts', methods=['POST'])
def text_to_speech():
    data = request.get_json()
    text = data.get('text')
    
    if not text:
        return api_error(TTS_TEXT_EMPTY)
    
    try:
        result = tts_service.speak(text)
        return api_success(result)
    except Exception as e:
        return api_exception(e)
```

### 服务层示例

```python
# services/tts/tts_manager.py
from core import logger
from core.exceptions import TTSException
from config.error_codes import TTS_TEXT_EMPTY, TTS_ENGINE_ERROR

class TTSManager:
    def speak(self, text: str):
        if not text:
            raise TTSException(TTS_TEXT_EMPTY)
        
        try:
            result = self._do_speak(text)
            logger.info("TTS播报成功", details={"text_length": len(text)}, module="TTS")
            return result
        except Exception as e:
            logger.error("TTS播报失败", details={"error": str(e)}, module="TTS")
            raise TTSException(TTS_ENGINE_ERROR, details={"exception": str(e)})
```
