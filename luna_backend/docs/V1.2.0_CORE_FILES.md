## 📋 核心文件清单

### 1. routes/visual_routes.py ✅

**功能**: 视觉相关API路由

**路由列表**:
- `GET /visual/health` - 视觉系统健康检查
- `POST /visual/detect` - 单帧图片检测 (multipart/form-data)
- `POST /visual/detect_base64` - base64图像推理（实时模式）
- `POST /visual/reload` - 重新加载YOLO模型（热重载）
- `GET /visual/metrics` - 视觉性能指标

**向后兼容路由**:
- `POST /visual/api/recognize` - 基础视觉识别（兼容旧API）
- `POST /visual/api/detect/comprehensive` - 综合检测（兼容旧API）

**使用示例**:
```python
# 健康检查
curl http://localhost:9001/visual/health

# 图片检测
curl -X POST http://localhost:9001/visual/detect \
  -F "image=@test.jpg"

# base64检测
curl -X POST http://localhost:9001/visual/detect_base64 \
  -H "Content-Type: application/json" \
  -d '{"image": "base64_string"}'
```

### 2. config/error_codes.py ✅

**功能**: 统一错误码体系

**错误码格式**:
- **6位数字格式（推荐）**: MMSSEE
  - MM: 模块编码（2位）
  - SS: 子类编号（2位）
  - EE: 具体错误（2位）
- **4位数字格式（向后兼容）**: MFFF
  - M: 模块编码（1位）
  - FFF: 具体错误（3位）

**模块分类**:
- `10xxxx` = 通用模块
- `20xxxx` = 视觉模块
- `30xxxx` = 音频模块
- `40xxxx` = 导航模块
- `50xxxx` = TTS模块
- `60xxxx` = MapMemory/场景理解
- `70xxxx` = 配置模块

**使用示例**:
```python
from config.error_codes import ERR

# 使用6位数字格式（推荐）
if not vision.is_ready():
    return error(ERR.VISION_NOT_READY, "视觉引擎未就绪")

# 使用4位数字格式（向后兼容）
if not vision_engine:
    return api_error(ERR.VISION_NOT_INITIALIZED)
```

### 3. core/response.py ✅

**功能**: 统一API返回格式

**新格式函数（推荐）**:
- `ok(data, message)` - 成功响应
- `error(code, message, http_status, details)` - 错误响应

**向后兼容函数**:
- `api_success(data, message)` - 成功响应（旧格式）
- `api_error(code, details, http_status)` - 错误响应（旧格式）
- `api_exception(exception, error_code, details)` - 异常转错误响应

**响应格式**:

成功响应:
```json
{
  "success": true,
  "code": 0,
  "message": "OK",
  "timestamp": 1703123456789,
  "request_id": "req_1703123456789_1",
  "data": {
    "status": "ready",
    "model": "yolov8n"
  }
}
```

错误响应:
```json
{
  "success": false,
  "code": 200001,
  "message": "视觉引擎未就绪",
  "timestamp": 1703123456789,
  "request_id": "req_1703123456789_2",
  "data": {}
}
```

**使用示例**:
```python
from core.response import ok, error
from config.error_codes import ERR

# 成功响应
return ok({"status": "ready", "model": "yolov8n"})

# 错误响应
return error(ERR.VISION_NOT_READY, "视觉引擎未初始化成功")
```

### services/vision/vision_engine.py

- `detect_base64(base64_str)` - 检测base64图片

- `get_metrics()` - 获取性能指标
