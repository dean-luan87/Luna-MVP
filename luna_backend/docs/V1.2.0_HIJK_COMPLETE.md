## 🚀 使用示例

### 1. 启动医院流程

```bash
# 启动医院就诊任务
curl -X POST http://localhost:9001/api/hospital/start_flow \
  -H "Content-Type: application/json" \
  -d '{
    "hospital_name": "新华医院",
    "department_name": "眼科",
    "is_first_visit": true
  }'

# 返回:
# {
#   "success": true,
#   "data": {
#     "task_id": "hospital_新华医院_眼科",
#     "hospital_name": "新华医院",
#     "department_name": "眼科"
#   }
# }
```

### 2. 更新医院阶段

```bash
# 更新阶段（挂号完成）
curl -X POST http://localhost:9001/api/hospital/update_stage \
  -H "Content-Type: application/json" \
  -d '{
    "task_id": "hospital_新华医院_眼科",
    "stage": "registration_done",
    "ticket_no": "A123"
  }'
```

### 3. 多目标路径规划

```bash
# 规划多目标路径（先去711再去医院）
curl -X POST http://localhost:9001/api/navigation/plan_multi \
  -H "Content-Type: application/json" \
  -d '{
    "start": "当前位置",
    "targets": [
      {"name": "711便利店", "type": "shop"},
      {"name": "新华医院", "type": "hospital"}
    ]
  }'
```

### 4. 本地地图更新

```bash
# 更新本地地图
curl -X POST http://localhost:9001/api/map/generate \
  -H "Content-Type: application/json" \
  -d '{
    "dx": 0.5,
    "dy": 0.3,
    "angle_delta": 0.1
  }'
```
