# Git 提交模板 - v1.4.6

## 提交类型

- `feat`: 新功能
- `fix`: Bug 修复
- `docs`: 文档更新
- `style`: 代码格式（不影响功能）
- `refactor`: 重构
- `test`: 测试相关
- `chore`: 构建/工具相关

## 提交格式

```
<type>(<scope>): <subject>

<body>

<footer>
```

## v1.4.6 提交示例

### 功能提交

```
feat(tts): 实现安全播报高优先级队列

- 新增 SafetyQueue 独立队列
- 实现 push_safety() 方法
- 添加 2 秒限频机制
- 安全播报可跳过时间窗口限制

Closes #XXX

### 文档提交

```

## 提交范围（scope）

v1.4.6 相关 scope：

- `tts`: TTS 系统
- `navigation`: 导航系统
- `task`: 任务系统
- `ask`: 问询系统
- `scene`: 场景系统
- `decision`: 决策系统
- `test`: 测试
- `docs`: 文档
- `release`: 发布

## 提交信息规范

1. **Subject**：
   - 使用中文或英文
   - 首字母小写
   - 不超过 50 个字符
   - 以句号结尾

2. **Body**：
   - 详细描述变更内容
   - 使用列表格式
   - 说明原因和影响

3. **Footer**：
   - 关联 Issue：`Closes #XXX`
   - 关联 PR：`Related to #XXX`
   - 破坏性变更：`BREAKING CHANGE: <description>`
