## 📝 修改内容

### 1. ✅ 新增文件：`speech/tts_manager.py`

**功能**:
- 基于队列的 TTS 播报系统
- 独立线程处理播报队列
- 保证播报按顺序完成，不被主循环覆盖
- 支持播报状态查询

**关键特性**:
- `queue.Queue()` - 播报队列
- `threading.Thread` - 独立工作线程
- `is_speaking()` - 查询播报状态
- 线程安全的状态管理

### 2. ✅ 修改：`main.py`

**变更**:
```python
# 修改前
self.tts = DummyTTS()

# 修改后
self.raw_tts = DummyTTS()
self.tts = TTSManager(self.raw_tts)
self.tts.start()
```

**效果**:
- 所有 TTS 调用自动进入队列
- 播报在独立线程中执行
- 主循环不会被播报阻塞

### 3. ✅ 修改：`navigation/navigation_controller.py`

**变更**:
- 添加 `_last_broadcast_ts` - 上次播报时间戳
- 添加 `_broadcast_interval = 3.0` - 最短播报间隔（3 秒）
- 在 `step()` 方法中添加时间检查，避免频繁播报

**效果**:
- 导航播报最多每 3 秒一次
- 避免重复播报
- 减少播报队列压力

## 🚀 后续可扩展功能

当前架构已支持以下扩展：

1. **播报优先级**
   - 可以为队列添加优先级字段
   - 高优先级播报可以插队

2. **播报合并**
   - 检测相似播报，自动合并
   - 减少重复内容

3. **去重播报**
   - 相同内容在短时间内只播一次
   - 避免重复提示

4. **语速/语气切换**
   - 根据场景自动调整
   - 紧急情况加快语速

5. **取消播报**
   - 支持取消队列中的待播报内容
   - 紧急播报可以清空队列

## 📝 使用说明

### 基本使用

```python
# TTSManager 会自动管理队列
tts_manager.speak("第一条消息")
tts_manager.speak("第二条消息")  # 自动排队
tts_manager.speak("第三条消息")  # 自动排队

# 检查是否正在播报
if tts_manager.is_speaking():
    print("正在播报中...")
```

### 在导航中使用

```python
# 导航控制器会自动节流（3 秒间隔）
nav_controller.step(vision_objects)  # 可能触发播报
nav_controller.step(vision_objects)  # 3 秒内不会重复播报
```
