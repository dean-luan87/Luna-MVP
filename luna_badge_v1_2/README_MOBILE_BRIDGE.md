# Luna Badge 手机桥接服务使用指南

## 📱 概述

这是一个手机前端 + 本地电脑推理的完整方案。手机作为遥控器，电脑作为推理主机。

**功能特性：**
- ✅ 手机摄像头拍照/上传
- ✅ YOLO 识别（在电脑上运行）
- ✅ 场景判断
- ✅ 导航规划
- ✅ TTS 输出语音
- ✅ 全链路延迟 < 250ms（取决于电脑性能）
- ✅ **自动心跳检测**（每 3 秒，实时监控连接状态）
- ✅ **连续导航模式**（每 200ms 自动抓帧并推理）
- ✅ **WebSocket 实时推理**（长连接，减少 HTTP 开销）

## 🚀 快速开始

### 第一步：安装依赖

```bash
pip3 install flask flask-cors pillow opencv-python numpy
```

### 第二步：启动服务器

**需要同时运行两个服务：**

```bash
# 终端1：HTTP 服务（提供静态页面和 REST API）
python3 mobile_bridge_server.py

# 终端2：WebSocket 服务（实时推理）
python3 ws_server.py
```

或者使用后台运行：

```bash
python3 mobile_bridge_server.py > http.log 2>&1 &
python3 ws_server.py > ws.log 2>&1 &
```

服务器启动后会显示：

### 第三步：手机端访问

1. **确保手机和电脑在同一 WiFi 网络**

2. **在手机浏览器打开：**
   ```
   http://你的电脑IP:8899/static/mobile_client.html
   ```
   例如：`http://192.168.1.22:8899/static/mobile_client.html`

3. **配置服务器 IP：**
   - 输入你的电脑 IP 地址
   - 点击「保存」

4. **连接 WebSocket：**
   - 点击「连接 WebSocket」按钮
   - 等待连接成功（状态显示为"已连接"）

5. **开始连续导航：**
   - 点击「开始连续导航 (200ms)」按钮
   - 允许浏览器访问摄像头权限
   - 系统将每 200ms 自动抓取画面并发送推理

6. **查看结果：**
   - 实时预览摄像头画面
   - 日志中显示检测结果和导航指令
   - 心跳状态实时更新（每 3 秒）

## 📁 文件说明

### `mobile_bridge_server.py`
Flask 后端服务器，提供以下 API：

- `GET /` - 首页
- `GET /mobile_client.html` - 手机客户端页面
- `POST /api/detect` - YOLO 检测
- `POST /api/nav` - 导航规划
- `POST /api/full_pipeline` - 完整链路（检测 + 导航 + TTS）

### `ws_server.py`
WebSocket 实时推理服务器，功能包括：
- WebSocket 长连接（端口 8898）
- 自动心跳检测（每 3 秒）
- 连续导航模式支持
- 实时返回 YOLO 检测和导航结果

### `static/mobile_client.html`
手机端网页，功能包括：
- 调用摄像头拍照
- WebSocket 实时连接
- 连续导航模式（每 200ms 自动抓帧）
- 心跳状态监控
- 显示识别结果和导航指令
- 实时日志输出

## 🔧 配置说明

编辑 `mobile_bridge_server.py`，修改：

在手机端页面，可以手动输入服务器地址，或留空使用当前域名。

## 🐛 故障排查

### 1. 无法连接服务器

- 检查手机和电脑是否在同一 WiFi
- 检查防火墙是否阻止了 8899 端口
- 检查服务器是否正在运行

### 2. YOLO 检测失败

- 检查是否安装了 `ultralytics`
- 检查模型文件是否存在（会自动下载）

### 3. 图片上传失败

- 检查图片格式是否支持（JPG/PNG）
- 检查图片大小（建议 < 5MB）

### 4. TTS 不工作

- TTS 目前使用系统命令（macOS: `say`）
- 音频数据可能返回占位符，需要根据实际 TTS 实现调整

## 🎯 性能优化

### 减少延迟

1. **预热模型**：服务器启动时已自动加载模型
2. **图片压缩**：手机端可以压缩图片后再上传
3. **使用 WebSocket**：未来可以升级为 WebSocket 实时推理

### 提高并发

服务器已启用多线程模式（`threaded=True`），可以同时处理多个请求。
