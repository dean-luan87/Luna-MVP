# 停止音频播放

## 如果音频还在播放

pydub 的 `play()` 函数是**阻塞的**，会等待音频播放完成。如果音频文件较长，可能需要等待。

### 快速停止方法

1. **按 Ctrl+C** 中断 Python 程序
2. **强制停止所有 Python 进程**：
   ```bash
   killall -9 Python
   killall -9 python3
   ```

3. **如果仍有音频在播放**，可能是系统音频缓存，等待几秒会自动停止

### 临时文件清理

生成的临时音频文件（`tts_*.mp3`）会在播放完成后自动清理。如果程序异常退出，可能需要手动清理：

```bash
cd luna_badge_v1_2
rm -f tts_*.mp3 tts_*.wav
```

## 注意事项

- pydub 的播放是同步阻塞的，无法中途停止
- 如果需要非阻塞播放，可以考虑使用线程
- 当前实现会在播放完成后自动释放锁
