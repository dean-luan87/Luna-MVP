# Cursor 指令模板

本文档提供标准的 Cursor 指令模板，用于按照《Luna Badge 项目结构与开发规范 v1.0》执行开发任务。

---

## 标准 Cursor 指令

### 完整规范遵循指令

```
请从现在开始严格遵循《Luna Badge 项目结构与开发规范 v1.0》的所有内容进行开发与重构。任何新增模块、重构、目录调整、文件清理，都必须按规范执行。

第一步任务：
按规范拆分测试系统（/tests）与日志系统（/core/logging）。

第二步任务：
按规范重构项目整体目录结构。

第三步任务：
执行代码格式化、无用代码删除、import 清理。

所有执行必须分步骤进行，每一步都要输出 diff 预览并等待确认。
```

## 模块创建指令模板

### 创建新模型模块

```
请按照《Luna Badge 项目结构与开发规范 v1.0》在 src/vision/models/[模型类型] 创建新模型模块 [模型名]。

要求：
1. 实现 VisionModel 统一接口
2. 创建 __init__.py 并导出主要接口

5. 创建对应的测试文件（tests/vision_tests/test_[模型名].py）
6. 生成 diff 预览供确认
```

## 注意事项

1. **所有指令必须包含"生成 diff 预览供确认"**
2. **所有重构必须"分步骤执行，每步完成后测试"**
3. **不确定时先询问，不要随意创建新模块**
4. **所有新文件必须添加日志系统**
5. **所有修改必须符合目录结构规范**

## 快速参考

### 常用路径

- 核心模块：`src/core/`
- 视觉模块：`src/vision/`
- 导航模块：`src/navigation/`
- 音频模块：`src/audio/`
- 任务模块：`src/tasks/`
- 系统模块：`src/system/`
- 测试目录：`tests/`
- 日志目录：`logs/`

### 常用导入

```python
# 日志系统

log = get_logger("module_name")

# 模型接口
from src.vision.models.base import VisionModel

# 模型注册
from src.vision.model_registry import ModelRegistry
```
