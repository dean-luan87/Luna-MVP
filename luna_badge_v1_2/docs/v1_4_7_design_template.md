## 一、版本定位

v1.4.7 将在 v1.4.6 的 TTS 调度系统基础上，引入**任务链问询系统**，实现：

- 主任务确认机制
- 插入任务问询逻辑
- 播报主动问询模块（基于 v1.4.6 Router）

---

## 二、核心功能设计

### 2.1 主任务确认机制

**目标**：在执行任务前，确认用户意图和目标。

**设计要点**：
- 基于 `AskChain` 系统
- 集成到 `TaskChainManager`
- 使用 `TTSRouterFacade` 进行播报

### 2.2 插入任务问询逻辑

**目标**：当检测到新任务时，询问用户是否插入。

**设计要点**：
- 任务优先级判断
- 用户确认流程
- 任务链重组逻辑

### 2.3 播报主动问询模块

**目标**：在适当时机主动询问用户下一步行动。

**设计要点**：
- 基于场景和任务状态
- 使用 `TTSRouterFacade` 进行播报
- 集成到决策流程
