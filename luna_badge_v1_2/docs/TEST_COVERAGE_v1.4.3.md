## 全链路验证场景

### ✅ 已验证场景

1. **模糊回答处理**
   - 用户输入模糊 → 系统识别 → 返回 ASK_USER

2. **拒绝回答处理**
   - 用户拒绝 → 系统识别 → 返回 NO_OP

3. **插入任务**
   - 主任务执行中 → 用户请求插入 → 系统确认 → 插入成功

4. **替换任务**
   - 主任务执行中 → 用户请求替换 → 系统确认 → 替换成功

5. **嵌套任务**
   - 主任务 → 插入子任务1 → 插入子任务2 → 完成子任务2 → 完成子任务1 → 恢复主任务

6. **pending_intent 状态恢复**
   - 需要确认的意图 → 等待用户确认 → 用户确认 → 执行意图

7. **PlanB 降级**
   - 模型全部失败 → 触发 PlanB → 保存状态快照

8. **日志验证**
   - 所有决策行为 → 记录到日志 → 日志格式正确

9. **任务链一致性**
   - 复杂操作后 → 状态检查 → 状态一致

10. **多次节点推进**
    - 任务节点 → advance → 下一个节点 → advance → 完成
