# Luna Badge - Decision & Task System

## Overview

Luna Badge is a decision and task management system designed for intelligent task execution and user interaction.

## Ask System (v1.4.6a)

The Ask subsystem provides:

- parameter clarification
- retry logic
- structured question flow (AskChain)
- automatic chain runtime execution

Read more:

- `docs/ask_system_overview.md`
- `docs/ask_system_v1_4_6a.md`

Run demo:

```bash
python3 scripts/demo_askchain.py
```
