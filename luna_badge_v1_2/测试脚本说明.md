## 📊 测试验证点

运行测试后，请检查以下内容：

### ✅ 语音完整性
- [ ] 所有播报是否完整播放
- [ ] 长句是否被截断
- [ ] 是否有音质问题

### ✅ 中断能力
- [ ] `stop()` 方法是否生效
- [ ] 中断后是否能正常恢复

### ✅ 播报覆盖
- [ ] 新播报是否成功覆盖旧播报
- [ ] 是否出现叠音现象

### ✅ 防抖机制
- [ ] 重复播报是否被阻止
- [ ] 高频重复是否被过滤
- [ ] 不同文案是否正常放行

### ✅ 系统稳定性
- [ ] 是否有系统延迟或卡顿
- [ ] 是否有进程残留
- [ ] 日志是否正常输出

## 🔧 故障排除

### 问题 1：导入错误
**症状：** `ModuleNotFoundError: No module named 'modules'`
**解决：** 确保在 `luna_badge_v1_2` 目录下运行脚本

### 问题 2：权限错误
**症状：** `Permission denied`
**解决：** 运行 `chmod +x run_full_test.sh`

### 问题 3：进程锁冲突
**症状：** `Luna Badge 已在运行`
**解决：** 运行 `rm -f /tmp/luna_badge_main.lock && pkill -f "python3 main.py"`
