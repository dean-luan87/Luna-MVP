## 1. 功能验收标准（Functional Acceptance）

### 1.1 问询能力（B 模块）

#### A. 问句生成
- [ ] 能正确生成问句
- [ ] 支持变量替换（如 `{intent_desc}`）
- [ ] 模板缺失时返回 fallback 问句
- [ ] 问句格式符合规范

#### B. 选项匹配
- [ ] 支持精确选项匹配（是/否、继续/不继续）
- [ ] 大小写不敏感
- [ ] 空白字符自动处理

#### C. 同义词匹配
- [ ] 支持同义词扩展（好/行/可以/继续吧…）
- [ ] 同义词优先级高于特殊指令
- [ ] 同义词匹配准确无误

#### D. 指令解析
- [ ] 支持指令识别（厕所/改目标/买东西/取消）
- [ ] 指令识别准确
- [ ] 指令触发二次确认（`need_confirm=True`）

#### E. 解析结果
- [ ] 解析结果结构化
- [ ] 字段齐全（`intent_type`, `raw`, `need_confirm`）
- [ ] `UNKNOWN` 回答触发 fallback

**验收方法**: 运行 `test_inquiry_parser.py`，所有测试通过

---

### 1.2 决策层联动（DecisionCore）

#### A. 问询闭环
- [ ] `ASK_USER` → Inquiry → `USER_INTENT` → 决策闭环完整
- [ ] 问询结果正确传递给决策层
- [ ] 决策层正确处理问询结果

#### B. 任务插入
- [ ] `INSERT_TASK` → TaskChain 插入子任务成功
- [ ] 主任务状态正确保存
- [ ] 子任务正确启动

#### C. 任务恢复
- [ ] 子任务完成后恢复主任务成功
- [ ] 恢复后的主任务节点与插入前一致
- [ ] `resume_strategy` 生效（auto/ask）

#### D. PlanB 触发
- [ ] PlanB 条件命中后触发 `TRIGGER_PLANB`
- [ ] `context_snapshot` 包含关键信息
- [ ] 系统进入 PlanB 暂停状态

#### E. 稳定性
- [ ] 无异常、无死循环
- [ ] 所有决策输出符合 `DecisionOutput` 结构
- [ ] 字段缺失不会导致崩溃

**验收方法**: 运行 `test_decision_core.py` 和 `test_integration_flow.py`，所有测试通过

---

### 1.3 TaskChain（A 模块）

#### A. 插入任务
- [ ] 支持插入任务
- [ ] 主任务状态正确保存
- [ ] 活动任务正确切换

#### B. 多层嵌套
- [ ] 支持多层嵌套插入（厕所 → 买水 → 主任务）
- [ ] 嵌套顺序正确（LIFO）

- [ ] 新任务正确启动

#### E. PlanB 暂停
