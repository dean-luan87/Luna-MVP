## 🚀 使用指南

### 快速开始
```python
from orchestrator import Orchestrator

# 创建实例
orc = Orchestrator()

# 模拟用户输入
result = orc.simulate_user_input("带我去医院")

# 查看结果
print(result["decision_output"].action)
print(result["taskchain_state"])
```

### 运行测试
```bash
# 运行所有测试
pytest tests/

# 运行 E2E 测试
pytest tests/test_e2e_v1_4_3.py -v
```
