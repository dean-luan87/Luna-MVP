# legacy/voice（受控清理容器）

这里存放/指代 **Legacy Voice 资产**：历史实现、实验脚本、过渡方案、待迁移模块。

## 什么是 legacy voice 资产

- 曾经用于播报/语音输入/路由的实现，但**不再作为未来正式方案扩展**。
- 可用于：兜底运行、对照测试、参考实现、迁移过渡。

## 为什么要保留

本轮的目标是“受控清理”而不是删除：
- **不破坏当前可运行性**
- **不让旧语音继续扩散**
- 给新 Provider 链（Fish 主、Piper 兜底）腾出清晰入口与口径

## 哪些还在主链兜底

- `modules/voice.py`（macOS `say`）当前仍用于 `main.py` 播报链路，属于 **legacy_keep_for_fallback**，保留到 Stage-2 切换完成。

## 哪些准备移除/迁出

- 各类实验脚本（如 edge-tts 测试）与不进入主链的旧测试资产：优先迁入此处或标注为 `legacy_candidate_for_removal`。

## 为什么现在不删

因为删改可能破坏当前运行与回归对照；正确顺序是：
1) 降级口径与归属（legacy）  
2) 新链路接管（Fish+Piper）  
3) 再做可回滚的移除/精简
