# Memory Hierarchy Model v1

```text
Episode Memory
      -> Pattern Candidate
Experience Memory
      -> long-term validation
Principle Memory
```

Episode Memory preserves one experience. Experience Memory represents reusable patterns across multiple Episodes. Principle Memory is deliberately rare and requires long-term, multi-context evidence, provenance, confidence, and governance admission.

No raw observation automatically becomes an Episode, no Episode automatically becomes Experience Memory, and no Experience Memory automatically becomes a Principle. Every promotion remains a candidate until validation and governance review.
