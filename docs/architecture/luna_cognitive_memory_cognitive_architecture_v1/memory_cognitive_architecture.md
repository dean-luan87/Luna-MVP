# Luna Cognitive Memory Architecture v1

## Position

Memory is not a database or an unbounded log. It is a governed, subject-relevant structure formed from Field Evolution and Experience after validation, value evaluation, consolidation, and long-term compression.

```text
Reality -> Field Event -> Experience Candidate -> Experience
        -> Memory Candidate -> Memory -> Pattern -> Principle
```

Memory provides temporal continuity and context support. It never outranks current Reality or Evidence, and it never owns Decision, Identity, Goal, Constitution, or direct Self/Social Self mutation.

## Three cognitive layers

- Episode Memory: one validated experience with strong time, space, Field, Role, Task, sequence, and outcome binding.
- Experience Memory: reusable experience extracted from multiple Episodes and a governed Pattern Candidate.
- Principle Memory: rare, high-level structure supported by long-term, multi-context validation.

## Memory scopes

Self Memory supports Self-layer candidates; Social Memory supports Social Self candidates; Role Memory supports Role Growth Candidates; Field Memory supports Field Understanding; World Memory remains a Cognitive Core context scope. These scopes have separate ownership and do not collapse into one identity or decision authority.

## Boundaries

Knowledge is external information. Reading Knowledge is not Memory. Knowledge becomes candidate Experience only through Field, Role, Task, and practice. Memory retrieval is activated by the current Field and context, not autonomous recall. Memory output is context support only; Reality, Unknown, and current Evidence remain authoritative.

This phase defines contracts only. It does not implement Memory Store, Runtime, automatic compression, Folding, database access, model calls, or automatic growth.
