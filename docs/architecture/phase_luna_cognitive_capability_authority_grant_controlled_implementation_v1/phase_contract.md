# Phase Contract

## Phase

`Phase-Luna-Candidate-Only-Authority-Grant-And-Mechanical-Command-Adapter-v1-001`

## Scope

This phase provides a candidate-only, synthetic-only contract adapter for:

`Capability Boundary → Authority Grant → A semantic command → Loop mechanical validation`

It also provides bounded derived B grants, revocation/expiry records, and
responsibility binding checks.

## Explicit non-scope

This package does not implement Brain runtime, Authority Manager, Permission
Manager, Scheduler, Provider/model execution, camera/OCR, Action, Learning,
Memory or Experience mutation. Existing canonical owners, enums, Dynamic Flow
and Loop implementations remain unchanged.

## Verification ownership

The Runner and Verifier are source artifacts for user-terminal execution. They
are not executed as part of this controlled implementation.
