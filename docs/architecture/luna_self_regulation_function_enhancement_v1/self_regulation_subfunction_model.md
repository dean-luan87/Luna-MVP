# Self Regulation Subfunction Model

The Self Regulation Function has one owner and six internal mechanisms:

| Mechanism | Question | Candidate output |
| --- | --- | --- |
| Homeostasis Regulation | Is a state variable within its contextual range? | range/stability candidate |
| Resource Regulation | What resources can be proposed for use? | budget candidate |
| Cognitive Balance Regulation | Is quality worth its stability and resource cost? | balance/defer candidate |
| Calibration Regulation | What repeated evidence justifies review? | calibration candidate |
| Adaptive Regulation | Which governed adaptive parameter could help? | parameter candidate |
| Stability Protection | Could change damage continuity or a stable invariant? | veto/review candidate |

These mechanisms share the same input/output contract and trace. None is a
standalone scheduler, optimizer, model manager, or action executor.

## Precedence

Stable-core and Constitution checks precede quality optimization. A hard boundary
violation is rejected rather than compensated by a higher score. Unknowns remain
explicit and may cause deferral.
