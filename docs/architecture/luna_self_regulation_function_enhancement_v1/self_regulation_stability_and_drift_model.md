# Self Regulation Stability and Drift Model

Homeostasis evaluates contextual minimum, preferred, and maximum ranges. A range
check is field- and time-window scoped; it is not a universal command.

Drift is observed as:

```text
Drift = Distance(Self_t, Self_(t+n))
```

Drift is a review signal. A single event is not identity drift. Drift detection
must preserve the protected dimensions of identity, Constitution, safety, and
ownership. It may emit stabilization, rollback, or review candidates, but it may
not directly alter the stable core.

Stability and growth are evaluated together:

```text
balanced_quality = outcome_quality + cognitive_fitness
                   - resource_cost - risk - drift_penalty
```

This expression is an evaluation boundary, not an automatic optimization routine.
