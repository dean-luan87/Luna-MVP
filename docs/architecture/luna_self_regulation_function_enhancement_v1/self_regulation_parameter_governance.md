# Self Regulation Parameter Governance

Parameter changes are candidates, not direct updates. A candidate must carry field
scope, evidence, expected benefit, resource cost, risk, reversibility, version,
rollback reference, and review status.

## Classes

- **Immutable:** Constitution, identity, reality priority, safety principles, and
  ownership boundaries. The function cannot update these.
- **Adaptive:** attention weights, exploration thresholds, memory activation,
  strategy, capability policy, schema influence, and cognitive parameters.
- **Experimental:** isolated and limited candidates with explicit exposure, risk,
  evidence collection, rollback, and admission requirements.

Self Regulation can propose a candidate and protect the stable core. It cannot
train a model, modify source code, commit a parameter, or bypass Self Review and
the external application boundary.
