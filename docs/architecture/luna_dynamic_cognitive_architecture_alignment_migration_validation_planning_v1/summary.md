# Phase Summary

The migration route now includes a mandatory post-migration integrity phase and a
separate architecture-freeze decision. “Migration complete” is defined by owner,
interface, chain, regression, documentation, and rollback evidence rather than by
file movement.

The strategy preserves the current canonical owners: Personal Cognitive Network
receives projections rather than owning Memory/Self/Social source state; Task
Manager remains orchestration; Action Runtime remains execution; Model Manager and
OCR/Vision remain capabilities. Existing passed assets are unchanged in this
Planning Only phase.
