# CognitiveFailureGapRefV1 Contract

## Gap vocabulary

The foundation supports the planned Luna-centered categories from Goal,
Context, Role, Field, Attention, Information Need, Observation Planning,
Capability Requirement/Selection, Evidence relevance/conflict/uncertainty/
missingness, Current World, Field Cognition, Hypothesis formation/revision,
Sufficiency, Information Gap, Re-observation, Stop, Decision handoff, Owner
Boundary, and Traceability.

External categories are limited to External Capability Failure, Provider
Failure, and Normalization Failure.

## Required fields

Each ref includes gap identity/type, detector, responsible owner, severity,
affected refs, observation cycle, trace node refs, provenance, source versions,
invalidation, and resolved/unresolved/deferred status.

## Semantics

This is a reference/classification record. It does not repair, retry, refresh,
change policy, or mutate any source owner.
