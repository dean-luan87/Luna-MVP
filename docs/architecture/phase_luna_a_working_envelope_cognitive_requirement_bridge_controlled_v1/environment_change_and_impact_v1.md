# Environment change and A impact

`WorkingEnvelopeVersionCandidateV1` records changed and unchanged source references. `WorkingEnvelopeInvalidationCandidateV1` records that a source update may affect an active envelope and grant. Neither type judges semantic impact.

`AEnvironmentImpactAssessmentCandidateV1` is the semantic boundary. A may select `NO_MATERIAL_IMPACT`, Need/Hypothesis/Sufficiency reassessment, Replan, Pause, Wait or New Evidence. The assessment is grant-checked and does not cause runtime acquisition.
