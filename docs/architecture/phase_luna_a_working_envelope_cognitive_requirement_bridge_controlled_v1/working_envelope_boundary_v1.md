# Working Envelope boundary

`AWorkingEnvelopeCandidateV1` is a bounded reference envelope. Goal and Concern remain Brain-governed; Role/Perspective, Field, Context, Current World, Task/Behavior, Emotion, Experience, Attention, Safety, Permission and Resource remain source-owned.

The explicit guards are `authoritative_state_duplicated=false` and `source_owner_preserved=true`. Loop may record the envelope and version references mechanically, but cannot mutate or interpret the envelope.
