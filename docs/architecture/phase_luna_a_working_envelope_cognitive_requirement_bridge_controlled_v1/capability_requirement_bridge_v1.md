# Capability Requirement bridge

The integration calls the existing `form_capability_requirement` bridge and passes an existing `CognitiveNeedCandidateV1`. Existing `CapabilityRequirementV1`, scope assessment, capability gap and resolution candidates remain canonical for their owners.

The controlled mapping uses existing categories: `OBJECT_DETECTION`, `TEXT_RECOGNITION` and `SPATIAL_RELATION`, with the existing problem classes, operations and input/output contracts from the Scope fixture. Brain and A do not select a provider or model.
