# Phase contract

This phase adds a candidate-only, synthetic-only seam from a Brain-governed working context to A-owned Need and Cognitive Requirement candidates.

The canonical path is:

`Working Envelope refs → A environment impact → A Need decision → Cognitive Requirement → existing Capability Requirement Bridge → existing Scope/Resolution → Observation Admission Candidate → Evidence Return → A reassessment`

The envelope is not authoritative state. Scope, Resolution, Observation Gateway, Field, Context, Current World, Task, Role, Emotion, Attention, Safety, Permission, Resource and Experience retain their existing owners. No provider, model, camera, OCR or runtime invocation is performed by this phase.
