# Attention Prior Model v1

## Prior candidate

```text
Current Field
      + Historical Pattern
      + Self Capability
      + Current Goal
                ↓
      Attention Prior Candidate
```

An Attention Prior Candidate is an early focus suggestion for a similar Field.
Prior is not Decision. Prior is not Fact. Prior is not a Goal and cannot issue
an Action. It must remain scoped by Field, condition, Self Capability,
confidence, uncertainty, and expiry.

## Prior use

The prior may raise, lower, or redirect an Attention Requirement Candidate. It
must be checked against current Reality Evidence before allocation. Current
Reality overrides Historical Pattern. A prior cannot hide Unknown or suppress
an anomaly.

## Boundary

Prior generation is not automatic learning and not a model update. Brain and
Attention Governance retain acceptance, rejection, and resource authority.

Current Reality overrides Historical Pattern. A prior cannot issue an Action.
