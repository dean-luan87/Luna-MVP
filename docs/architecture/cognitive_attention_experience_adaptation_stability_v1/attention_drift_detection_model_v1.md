# Attention Drift Detection Model v1

## Drift candidate

Attention Drift Candidate identifies when historical attention patterns stop
serving the current Field, Goal, Self Capability, or Reality. It is diagnostic
and candidate-only.

## Drift types

- Attraction Drift: low-value stimuli repeatedly attract attention;
- Persistence Drift: attention continues after a requirement is complete;
- Narrowing Drift: the observed scope becomes too small;
- Omission Drift: important information sources are repeatedly missed;
- Overgeneralization Drift: a local pattern is applied outside its scope;
- Resource Drift: cost rises without Information Value.

## Detection boundary

```text
Historical Attention Pattern
      ↓
Current Reality / Field comparison
      ↓
Attention Drift Candidate
      ↓
Validation
      ↓
Attention Allocation Adjustment Candidate
```

Drift detection cannot automatically correct attention, modify Brain, Goal,
Decision, Reality, Self Identity, or Action. A single event is insufficient to
adopt a correction.

Drift detection cannot modify Brain. Drift detection cannot modify Goal. Drift detection cannot modify Reality.
