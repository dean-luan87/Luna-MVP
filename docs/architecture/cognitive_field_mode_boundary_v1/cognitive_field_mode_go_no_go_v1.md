# Cognitive Field Mode Boundary Go/No-Go v1

## Required checks

- Field Mode includes Reality Mode, Historical Reconstruction Mode, Simulation Mode, and Creative Mode.
- Only Reality Mode is allowed in the current phase.
- Reality Mode uses current Reality Field, Self State, Evidence, and constraints.
- Historical Reconstruction Mode is a placeholder and cannot rewrite history.
- Simulation Mode is Reality Field + Hypothesis Modification → Simulation Field Candidate.
- Creative Mode is hypothetical and cannot claim Reality.
- Field Modification cannot alter A Reality, Reality State, Self State, Goal, or current Decision.
- Simulation Result → Brain Evaluation → Candidate is the only future handoff.
- B Route is a boundary placeholder and is not implemented.

## Hard prohibitions

No Simulation Runtime, No Prediction Runtime, No automatic Planning, No automatic
Decision, No automatic Decision, No Action, No real model, No OCR, No SLAM, no Hardware, no B Runtime,
no online learning, and no direct Reality or State mutation.
