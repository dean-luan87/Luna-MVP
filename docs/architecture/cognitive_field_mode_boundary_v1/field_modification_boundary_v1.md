# Field Modification Boundary v1

## Modification contract

Only future non-Reality modes may carry a Hypothesis Modification. Every
modification declares base Field reference, variable path, original value,
hypothetical value, reason, provenance, uncertainty, and scope.

```text
Base Reality / Historical Field
          ↓
Hypothesis Modification
          ↓
Non-Reality Field Candidate
```

## A Reality protection

Simulation Result → Brain Evaluation → Candidate only. B or any future mode
cannot directly modify A Reality, Reality State, Self State, Goal, or current
Decision. Reality Mode has no Hypothesis Modification channel.

## Boundary

Field Modification is not online learning, not automatic planning, not a
Scheduler, and not a Runtime. No variable is changed in the current Reality
Workspace by this contract.
