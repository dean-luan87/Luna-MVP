# Cognitive Field Mode Boundary Model v1

## Shared Field substrate

Cognitive Field is the common world structure for A Route and future B Route;
it is not a data cache or a decision store.
Modes describe how a Field is sourced and constrained; a mode does not create a
new cognitive authority.

```text
Field Mode
├── Reality Mode
├── Historical Reconstruction Mode
├── Simulation Mode
└── Creative Mode
```

Only Reality Mode is allowed in the current architecture. The other modes are
placeholders and are not implemented.

## Mode boundaries

**Reality Mode** represents current Reality Field, current Self State, current
Evidence, and current constraints. It is the only mode available to A Route in
this phase.

**Historical Reconstruction Mode** may one day reconstruct a prior Field from
time, space, relationships, goals, capabilities, and information limits. It must
not rewrite historical facts.

**Simulation Mode** is a future what-if space: `Reality Field + Hypothesis
Modification → Simulation Field Candidate`. It is not a prediction fact and
cannot modify A Reality.

**Creative Mode** is an open hypothetical field for exploration. It cannot claim
Reality, change Self, create a Goal, or issue a Decision.

## Common prohibitions

No mode in this phase performs Decision, Planning, Prediction, Reasoning,
Evaluation, Action, Emotional Judgment, or Value Judgment. Mode selection is a
governance placeholder, not a Runtime.
