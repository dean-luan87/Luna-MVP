## Objective
Plan one complete Cognitive Learning Governance module that transforms candidate/admitted Memory and Experience evidence into Learning Candidates and then candidate-only Parameter Update proposals for Dynamic Cognitive Regulation.

## Main Chain
- Experience Candidate
- Memory Candidate / Memory Reference
- Outcome / Feedback / Contradiction References
- Learning Evidence Candidate
- Learning Candidate
- Parameter Update Candidate
- Dynamic Cognitive Regulation Governance review/bounds
- Separately admitted activation in a future phase

## Frozen Non-Goals
- No Learning runtime
- No runtime training
- No model-weight update
- No memory/experience semantic compression execution
- No direct parameter activation
- No genome activation
- No source-owner mutation
