# Attention Pattern Isolation Model v1

## Isolation rule

Each Attention Pattern is bound to Field Context, Condition, Self Capability,
Goal Context, Reality scope, provenance, and validity window. Work, family,
friend, network, navigation, and maintenance patterns are separate candidates.

```text
Work Field Pattern   ──isolated──  Family Field Pattern
Friend Field Pattern ──isolated──  Network Field Pattern
```

One Field's experience cannot overwrite another Field's pattern. A pattern may
be visible as a Transfer Candidate only after the Transfer Boundary validates
similarity and scope.

## Pollution detection

Pattern Pollution Candidate identifies a pattern used outside its Valid Scope,
with a mismatched condition, stale Reality, or incompatible Self Capability.
It is diagnostic and cannot directly delete or modify a pattern.

Isolation protects Self Continuity: different context-specific attention modes
do not imply different identities or personalities. They do not imply different personalities.
