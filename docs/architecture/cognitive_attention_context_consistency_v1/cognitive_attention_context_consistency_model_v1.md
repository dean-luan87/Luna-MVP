# Cognitive Attention Context Consistency Model v1

## Scope

Attention experience is context-bound. This phase ensures that an Attention
Pattern is valid only within its Field Context and Condition, while allowing
careful transfer candidates between genuinely similar contexts.

```text
Attention Pattern + Field Context + Condition
                       ↓
                    Valid Scope
```

## Consistency principles

1. A work-context attention pattern cannot silently become a family-context
   pattern. Pattern Isolation protects each Field and prevents cross-context
   pollution.
2. Attention Transfer is candidate-only. Similarity, shared constraints,
   provenance, Self Capability, and current Reality must support a transfer.
3. When multiple patterns apply, the result is an Attention Conflict Candidate;
   no pattern automatically overwrites another.
4. Attention Pattern changes do not change Self Identity. Stable Layer remains
   continuous while context-specific attention remains adaptive.

## Boundaries

Context Consistency does not implement Role Runtime, Emotion Runtime, Social
Field, B Runtime, automatic learning, automatic personality modification, or
Action. It does not make a Decision or choose a Goal. Brain and existing
Attention Governance retain final evaluation and resource authority.

Social Field is outside scope.
