# Attention Context Consistency Whitebox v1

```text
Attention Pattern + Field Context + Condition
                  ↓
                Valid Scope
                  ↓
        Pattern Isolation / Transfer Boundary
                  ↓
       Attention Conflict Candidate (if needed)
                  ↓
              Brain Evaluation
```

Transfer path:

```text
Source Pattern → Context Similarity Candidate → Transfer Candidate
               → Validation → Target Attention Prior Candidate
```

Continuity path:

```text
Attention Adaptation → Self Capability Candidate → Self Review
```
