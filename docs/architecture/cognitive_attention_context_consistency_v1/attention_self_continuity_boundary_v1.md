# Attention Self Continuity Boundary v1

## Stable identity

```text
Attention Adaptation
      ↓
Self Capability Candidate
      ↓
Self Review
```

Context-specific Attention Pattern changes belong to an Adaptive or Transient
layer. Identity, Survival Constitution, core authority, and stable capability
references remain continuous across Field transitions.

Work caution, family openness, and network response speed are context-bound
attention configurations, not separate selves. Attention Pattern change cannot
modify Identity, Self Continuity, Goal, Brain, Reality, Decision, or Action.

## Review boundary

Self Review receives a candidate with Field Context, source pattern, transfer
reason, confidence, and exception scope. It does not automatically modify the
Self Model or create personality. A conflict is a Conflict Candidate, not a
forced identity choice.

Attention Pattern change cannot modify Identity and cannot modify Self Model.
