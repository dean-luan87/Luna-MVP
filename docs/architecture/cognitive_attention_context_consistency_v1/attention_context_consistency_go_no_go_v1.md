# Attention Context Consistency Go/No-Go v1

## Required checks

- Attention Pattern binds to Field Context and Condition and has a Valid Scope.
- Pattern Isolation prevents one Field from overwriting another Field's
  attention experience.
- Attention Transfer is a candidate requiring similarity, scope, Self
  Capability, provenance, and current Reality validation.
- Work, family, friend, network, navigation, and maintenance patterns remain
  context-bound.
- Multiple applicable patterns produce an Attention Conflict Candidate rather
  than automatic override or resolution.
- Attention Adaptation flows to Self Capability Candidate and Self Review.
- Identity and Self Continuity remain stable across context-specific patterns.

## Explicit prohibitions

This architecture-only phase has No Role Runtime, No Emotion Runtime, No Social
Field, No B Runtime, no automatic learning, no automatic personality
modification, No Action, No Decision, and No Runtime. It does not implement
automatic conflict resolution or direct cross-context transfer.

The agent performs V0 static checks only, does not run the Final Phase Verifier,
and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`. The user must execute
the phase verifier and return all required sections. No Social Field and no automatic personality modification are enabled.
