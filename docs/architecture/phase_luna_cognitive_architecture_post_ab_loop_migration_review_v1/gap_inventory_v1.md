# Gap Inventory

## P0 architecture blockers

1. Dynamic Flow semantic computation remains duplicated after the A boundary migration.
2. Loop continuity candidate engine constructs semantic resume/disposition decisions instead of consuming A-supplied decisions.
3. Brain has no unified runtime subject/API for Concern admission, Grant issuance/revocation, global adjudication and assimilation.

## P1 integration gaps

1. Semantic Working Outline is deferred.
2. Experience/Short-Path Filter runtime is deferred.
3. Authoritative Working Envelope generator is not one reusable owner.
4. A→Observation request and Capability Requirement/Scope/Resolution handoff are not one integrated bridge.
5. Role/Field/Context/Emotion change propagation and grant invalidation are not unified.
6. A/B reasoning environment generation is distributed across fixtures/envelopes.
7. Cognitive Outcome Candidate → Brain assimilation remains candidate-only.

## P2 consolidation

- unify terminology for historical Route B vs B-CR;
- consolidate state/trace/reference envelope construction;
- document Task Requirement versus Cognitive Need naming;
- retire redundant compatibility outputs only after regression evidence.

## Deferred

Real Observation/Capability execution, Brain runtime, Semantic Module, Filter runtime, Action, Learning, Memory/Experience mutation, semantic compression, autonomous scheduling, and child Loop runtime.
