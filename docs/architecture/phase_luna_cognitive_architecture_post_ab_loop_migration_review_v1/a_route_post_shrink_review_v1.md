# A Route Post-Shrink Review

## KEEP

- lifecycle and stage handoff coordination;
- ingress/context/PCN/Intent/Cognitive State/Decision/Task/Action handoff records;
- trace, provenance, error propagation, defer and reconsideration handoff mechanics;
- ownership guard proving orchestration has no semantic authority.

## SHRINK / MOVE

- `STAGE_PRODUCERS` should remain a product/handoff map, not a claim that A Route owns Context, Intent, Cognitive State, Decision, Task, or Action semantics;
- dynamic regulation stages should be narrowed to handoff of A-owned semantic candidates;
- old Product Loop semantics should be deprecated later where they imply one route is a cognitive subject;
- B Route terminology in historical fixtures should be documented as non-B-CR unless routed through the new A-owned B-CR bridge.

## Do not move into A Route

Observation Gateway, Active Observation, Model Manager, Context, Field, Attention, Intent Governance, Decision, Task Manager, Action Governance, Runtime Executor, Memory and Learning remain their own owners. A Route may orchestrate their handoffs but should not own them.

Classification: orchestration `KEEP`; semantic-looking route chain `SHRINK`; legacy product semantics `DEPRECATE_LATER`.
