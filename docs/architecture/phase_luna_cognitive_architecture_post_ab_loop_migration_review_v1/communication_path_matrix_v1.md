# Communication Path Matrix

| Path | Allowed mode | Boundary |
|---|---|---|
| Brain → A | VIA_GRANT + VIA_ENVELOPE | Brain grants scoped authority and working refs |
| A → Brain | VIA_CANDIDATE | outcome, concern, assimilation or adjudication candidate |
| A → B | DIRECT_ALLOWED only as bounded request candidate | A-issued request and derived grant |
| B → A | DIRECT_ALLOWED only as return candidate | non-binding result/handoff |
| A → Loop | VIA_MECHANICAL_COMMAND | A semantic decision already made; Loop records mechanics |
| Loop → A | VIA_MECHANICAL_RETURN | mechanical facts and supplied refs only |
| Brain → Loop | VIA_GOVERNANCE / MECHANICAL_COMMAND | materialization/closure governance; no Loop cognition |
| Task → Loop | FORBIDDEN for cognitive control | Task may contribute refs through A/envelope |
| B → Loop | FORBIDDEN | B cannot issue mechanical commands |
| Observation → Loop | REFERENCE_ONLY / VIA_A | Observation admission/result is not cognition control |
| Capability → Loop | REFERENCE_ONLY / VIA_A | outcome refs only; no direct Loop judgment |
| Experience → Loop | REFERENCE_ONLY | package/history refs only |
| Role → A | VIA_ENVELOPE | read-only structural input |
| Field → A | VIA_ENVELOPE | authoritative world/context input |
| Emotion → A | VIA_ENVELOPE | modulation candidate, not truth/decision |
| Task → A | VIA_ENVELOPE | target/behavior/completion constraints |
| Context → A | VIA_ENVELOPE | context refs and validity |

Any direct implementation path that bypasses the listed envelope/grant/command boundary is a review finding, not a new owner.
