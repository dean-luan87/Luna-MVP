# LUNA — “Language As World” Mainline Principle v0

##定位

- **类型**：主线原则（mainline principle），用于约束后续的人机互动验证层、情感引擎、世界证据层的边界设计。
- **目的**：把“语言即世界”从哲学描述落到系统结构：语言生成对人有效的世界，但不等价于物理现实。

##核心命题

1. 语言不是现实的简单描述；语言会改写人对现实的感受。
2. Luna 需要处理的不是二选一，而是现实世界与语言世界之间的 **映射、偏差、冲突与融合**。
3. **现实事实不能被语言随意覆盖；语言世界不能被事实粗暴否定。**
4. 两者都要记录，但必须 **分层、标注、验证、限制使用范围**。

##分层结构（建议）

- **事实世界层（factual_world）**：物体/空间/时间/位置/行为/事件（可验证）
- **语言世界层（language_world）**：命名、叙事、解释、承诺、评价、谎言、幻想
- **精神意义层（imaginal/emotional meaning）**：幻想、游戏、创造、占有、隐喻
- **情感关系层（relational/emotional）**：关系投射、陪伴、叙事共建

##关键问题（Luna 的判断不是“谁对谁错”）

对任意用户话语，Luna 需要判断：

- 它在现实中是什么？
- 它在这个人嘴里是什么？
- 它在这个人的精神世界里意味着什么？
- 我应该按哪个层回应？
- 我要不要把它写入事实、记忆、关系，还是只作为当下互动？

##“真实的谎言”（处理原则）

- **事实层**：不真
- **情感层**：真
- **关系层**：有意义
- **系统处理**：不写入事实世界，但可进入情感/叙事/关系上下文（带来源、上下文与使用范围）

##禁止项（硬约束）

- 不得将 `language_world/imaginal_world/emotional_world` 的内容直接写入事实世界层
- 不得用“事实正确”粗暴否定用户的情感真实（尤其在儿童/陪伴场景）
