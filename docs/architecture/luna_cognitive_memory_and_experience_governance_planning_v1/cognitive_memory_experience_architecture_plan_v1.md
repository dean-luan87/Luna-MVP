## Objective
Plan one complete cognitive module that governs Experience Candidate formation and Memory Candidate admission without implementing storage/runtime persistence, retrieval runtime, learning execution, or source-owner mutation.

## Preferred Architectural Position
- Semantic governance module: Cognitive Memory & Experience Governance.
- Storage/runtime persistence stays outside semantic ownership.
- Learning remains downstream and separate.

## In Scope
- Experience candidate schema.
- Memory candidate schema and taxonomy.
- Admission state model.
- Salience/retention/decay and contradiction/revision/revocation planning.
- Boundaries to Context, PCN, Intent, State Formation, Dynamic Regulation, Learning, Self.
- Trace/provenance and idempotency.
- Synthetic minimum scenario suite.

## Out Of Scope
- Persistent store implementation.
- Vector DB or embedding pipeline.
- Real retrieval runtime.
- Automatic learning or parameter update.
- Personality, PCN, Intent, Field, or runtime mutation.
