# Experience Memory Boundary v1

## Retention layers

- Short-term Experience Candidate holds the current Outcome and Cause
  Attribution while validation is pending.
- Mid-term Experience Pattern Candidate aggregates repeated Field, Behavior,
  Attention, or Self observations with provenance.
- Long-term Experience Reference retains compressed, validated patterns with
  scope, confidence, recency, decay, and conflict metadata.

Experience Memory is not a database implementation and is not a substitute for
Reality Workspace. Current Reality > Experience remains mandatory. Unknown and
source provenance survive compression.

## Retention boundary

Retain high-frequency regularity, high-impact events, important Field changes,
and validated Self Capability changes. Do not retain one-off noise, unconfirmed
information, or Model guesses as durable references.

## Decay and release

Pattern strength decays with time, contradiction, and lack of reuse. Archived
Experience remains recoverable as a historical candidate but cannot silently
reactivate an Action, Goal, Decision, Emotion, Role, or Social Relationship.

Cause Attribution remains attached to Experience. Unconfirmed information is
not durable. Archived Experience is bounded. No database implementation. No
Memory Runtime. No automatic learning. No Action.

Unconfirmed information is never durable. No Memory Runtime.

unconfirmed information is excluded from durable retention.
