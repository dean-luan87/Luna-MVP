# Experience and Adaptation Go / No-Go v1

## Required readiness checks

- Experience is defined as long-term compression of Reality, Field, Self, and
  Behavior interaction, not storage-only Memory.
- The chain is Outcome → Cause Attribution → Experience Candidate → Experience
  Evaluation → Experience Memory → Pattern Candidate → Adaptation Candidate.
- Classes include Episodic Experience, Field Experience, Behavioral Experience,
  Self Experience, and Interaction Experience.
- Evaluation covers Repeatability, Reliability, Relevance, Impact, and Conflict.
- Retention excludes one-off noise, unconfirmed information, and Model guesses.
- Current Reality > Recent Experience > Old Experience is explicit.
- Attention, Behavior, and Self Capability adaptations are candidates only.
- Unknown, provenance, conflict, decay, compression, and release boundaries are
  preserved.

## Explicit prohibitions

No automatic learning, No Model Training, No parameter update, No Emotion
Runtime, No Role System, No Social Relationship, No B Route, No Prediction, and
No Action Runtime. Experience cannot directly modify Reality, Goal, Decision,
Identity, or Action.

The Agent performs V0 static checks only, does not run the Final Phase Verifier,
and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.

Experience Evaluation is required. No Emotion Runtime. Experience cannot
directly modify Goal, directly modify Decision, or directly modify Identity.
