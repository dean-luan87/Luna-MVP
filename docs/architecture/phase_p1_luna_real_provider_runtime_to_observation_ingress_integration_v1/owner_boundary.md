# Owner Boundary

| Responsibility | Canonical owner |
|---|---|
| Observation demand/request/capability candidates | Field Perception Orchestrator |
| Capability scope and readiness resolution | Capability Registry / Capability Governance |
| Provider selection and runtime request boundary | Existing capability/provider runtime infrastructure |
| Provider result production | External provider/capability implementation |
| Runtime observation admission | Observation Gateway Governance |
| Cognition coordination | A-Route Orchestration Governance |
| Sufficiency, Gap, Revision, Stop | Cognitive State Formation Governance |
| Re-observation orchestration | Field Perception Orchestrator |

The bridge does not create a Provider Manager, Capability Manager, Observation
Gateway, A-Route, or cognition owner. Providers do not create Facts, World
Truth, Decisions, Tasks, or Actions.
