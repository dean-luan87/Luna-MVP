# Information Processing Pipeline Whitebox v1

The pipeline is intentionally inspectable. Every stage has a named input, output, owner, and forbidden authority. An evidence item can be traced from provider provenance through structuring, Field assembly, attention, context, hypotheses, understanding, and a Brain Decision Candidate. A later outcome is a separate input to Experience Extraction.

The whitebox invariant is:

```text
provider -> evidence -> kernel structures -> field -> attention/context
        -> hypotheses/understanding -> brain candidate -> action boundary
        -> governed experience -> governed memory/growth candidates
```

Unknown, conflict, confidence, and provenance remain visible at each applicable boundary. No candidate is silently promoted to Reality, Identity, Goal, Memory, or Action.
