# A → B Request Boundary

`ABContingencyTriggerCandidateV1` and `BContingencyRequestCandidateV1` are A-issued candidates. The request carries the Concern, Work, source A state version, uncertainty, scenario scope, depth/branch limits, resource, safety, permission, required result, and termination refs.

B cannot create the trigger, enter independently, broaden the request, create a Concern, or recursively delegate another B request.
