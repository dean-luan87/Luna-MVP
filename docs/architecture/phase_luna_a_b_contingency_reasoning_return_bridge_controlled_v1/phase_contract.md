# Phase Contract

This phase is a candidate-only, synthetic-only A → B Contingency Reasoning (B-CR) → A bridge.

A is the only normal initiator and the only local authority that evaluates or adopts a B result. B receives a bounded derived grant, reasons within the request scope, and returns a non-binding candidate to A. No real concurrency, scheduler, provider, model, camera, action, memory, experience, or learning runtime is present.

Historical perception Route B assets are not renamed or reinterpreted here; this package uses **B Contingency Reasoning / B-CR**.
