# Derived B Scope and Termination

The derived B grant is bounded by the A grant, the existing B capability boundary, request scope, resource refs, safety refs, and permission refs. Existing `B_AUTHORITIES` vocabulary is reused; no new canonical authority vocabulary is introduced.

B-local result statuses include completed candidates, partial result, bounded uncertainty, stale source, revoked/limited grant, safety/resource limit, and no useful contingency. These statuses are not A adoption decisions.
