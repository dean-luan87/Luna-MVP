# A3 Controlled DryRun Guard Dual-Proof Matrix v1

This design matrix covers the frozen 24 Negative Guards. Static evidence establishes that forbidden structures are absent from approved source assets; execution evidence establishes that the serialized fixture-only DryRun did not claim or expose the forbidden behavior. Both proofs are required for future strengthening. None of these rows authorizes Runtime execution.

## Blocker Level Definition

- `blocker`: a guard failure violates a frozen execution, authority, candidate-only, determinism, or historical-artifact boundary. It blocks regression acceptance and any Runtime Planning proposal.
- `warning`: evidence is incomplete or needs review but the frozen guard itself remains demonstrably satisfied. A warning cannot replace a failed guard.
- `non_blocking`: an improvement note that has no conflicting static or execution evidence and does not alter the frozen baseline.

All 24 frozen Negative Guard failures are `blocker`. The `warning` and `non_blocking` levels are defined for future evidence-review findings only; they must never downgrade a guard failure.
