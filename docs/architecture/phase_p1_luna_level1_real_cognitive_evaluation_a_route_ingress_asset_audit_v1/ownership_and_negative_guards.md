# Ownership and Negative Guards

| Area | Owner | Evaluation restriction |
|---|---|---|
| Dataset/Sample/Case | Evaluation Governance | Declare, validate, reference only. |
| Observation demand/request | Observation/FPO | Evaluation supplies case inputs, not planning decisions. |
| Evidence admission/normalization | Evidence/Gateway | Evaluation cannot promote provider output to truth. |
| Goal/Concern/Attention/Need | A / cognitive owners | Observe only. |
| Current World/Hypothesis/Sufficiency/Gap | A | Never construct or mutate from Evaluation. |
| Re-observation | Observation/FPO under A need | No autonomous Evaluation retry. |
| Decision | Decision Governance | Handoff only. |
| Field | Field owner/reducer | No Evaluation mutation. |
| White-box | Evaluation | Observe/reference/summarize only. |
| Archive | Evaluation Governance | Immutable history, not runtime memory. |

Required guards: Dataset is not Runtime; GT is not World Truth; replay evidence is not automatically truth; White-box is not control; archive is not Memory/Knowledge/Experience; Plane B does not decide Plane A; Model failure does not equal Luna failure; no runtime binding changes; no parallel Trace/Profile V2.
