# Minimum End-to-End Bridge Gap

## Smallest one-case bridge

`registered sample → Level-1 case → evaluation boundary → governed recorded Observation/Evidence ingress → existing A-Route ingress refs → A-owned cognitive execution → White-box V1 attachment → Evaluation Run → durable archive`

## Required minimum assets

1. One explicitly registered Dataset and Sample with provenance, source versions, media/evidence refs, and layered GT refs.
2. One Level-1 Case referencing that Sample, Goal/Concern, Role, condition, perturbation, capability set, and observation budget.
3. One replay/evidence ingress adapter that consumes an existing Observation/Evidence/Gateway candidate without creating semantic candidates.
4. One actual A-Route ingress consumer that accepts the governed evidence refs; if unavailable, return `BLOCKED`, not synthetic success.
5. Runtime event emission or projection into existing White-box V1 nodes/profile values, preserving unavailable states.
6. One Evaluation Run result bound to the trace/profile/gap refs and immutable archive record.

No new cognition runtime, Model Selector, Dataset Manager, Trace V2, or semantic evaluator is required by the architecture.
