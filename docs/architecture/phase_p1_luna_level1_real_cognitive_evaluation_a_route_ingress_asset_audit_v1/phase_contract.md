# Phase Contract

This phase is an asset audit only for the first real Level-1 A-Route cognitive ingress.

Allowed: source/document inspection, ownership classification, path mapping, readiness verdicts, and audit documentation.

Forbidden: runtime implementation, A-Route changes, White-box changes, Dataset registration, model/provider/Observation/Action execution, Python, Runner, Verifier, pytest, network, dataset download, and state mutation.

`IMPLEMENTED_AND_RUNTIME_REACHABLE` is reserved for a path evidenced by actual runtime-capable source wiring. Types, fixtures, controlled runners, planning documents, and narrow RF-DETR provider results do not satisfy that standard for a general A-Route cognition claim.

Evaluation observes and archives. It does not own Goal, Attention, Evidence truth, Current World, Hypothesis, Sufficiency, Information Gap, Re-observation, Decision, Field, Memory, Knowledge, or Experience.

Final audit status: Gate 3 is blocked; no GO is declared.
