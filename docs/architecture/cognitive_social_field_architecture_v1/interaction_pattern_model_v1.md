# Interaction Pattern Model v1

Interaction Pattern Candidate is a bounded observation of a social interaction
over Field and Time. It records participants, context, observed sequence,
evidence, confidence, Unknown, history, and provenance.

Examples include a meeting host pattern, a repeated speaking order, or a
recurring handoff. These are historical patterns, not Prediction, intention,
emotion, relationship judgment, or Decision.

Promotion requires repeated Evidence and Social Field validation. A single
observation remains a candidate. The pattern may support Attention Candidate,
Behavior Candidate, or Social Field Memory Candidate only; it cannot directly
create Action or modify Identity.

The pattern is not intention, not emotion, not Decision, and not a single
observation.
