# Attention Adaptation and Stability Whitebox v1

```text
Outcome
   ↓
Experience Candidate
   ↓
Attention Pattern Candidate
   ↓
Validation
   ↓
Future Allocation Candidate
```

Familiarity path:

```text
Unknown high → Attention high
Stable Reality Pattern → Attention cost reduction candidate
New Evidence → Deviation Detection → Attention Increase Candidate
```

Capability path:

```text
Capability Change
   ↓
Attention Requirement Adjustment Candidate
   ↓
Validation
```

Drift path:

```text
Current allocation vs Field / Goal / Reality
   ↓
Attention Drift Candidate
   ↓
Future Allocation Candidate
```

Every output remains a candidate. No online learning, automatic strategy
modification, Brain modification, Goal modification, Decision, Action, Emotion,
Role, B, or Runtime occurs here.

No automatic strategy modification, No Decision, No Action, and No Runtime are
enabled.
