# Cognitive Foundation Final Matrix v1

| Foundation area | Primary output | Core isolation |
| --- | --- | --- |
| Field and Perception | Observation, Situation, Affordance Candidate | Does not decide or act |
| Context and Intent | Context, Intent, Goal Candidate | Does not override mission or identity |
| Attention and Resources | Attention, Sufficiency, Resource Candidate | Does not change knowledge or State |
| Reasoning and Future Space | Hypothesis, Causality, Counterfactual, Future Candidate | Does not create facts or predictions as truth |
| Evaluation and Commitment | Value, Decision, Commitment Candidate | Does not select, permit, or execute action |
| Decision–Execution Boundary | Human / external execution reference, outcome observation | Luna does not hold Human Action Authority |
| Experience and Evolution | Experience, Representation, Culture, Gene-Pool Candidate | Does not learn automatically or override local context |
| Governance and Reducer Boundary | Boundary-validation candidate; State mutation through Reducer only | Does not judge reality or execute cognition |

## Final baseline invariant set

`Reality First + Candidate First + Context Bound + Minimum Sufficient Understanding + Evolution With Validation`.

The matrix is an architectural reference, not a Runtime registry, policy engine, authority matrix for execution, or final GO declaration.
