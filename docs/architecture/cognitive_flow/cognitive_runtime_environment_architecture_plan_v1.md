## Position

`Reality Evidence -> Perception Interface -> Cognitive Runtime Environment Candidate -> Cognitive Process Candidate -> Candidate Flow -> Evaluation -> Commitment Candidate -> Reducer Boundary`.

Cognitive Runtime Environment is a proposed Cognitive VM: an isolated, temporary space for hypothesis, branch, uncertainty, error, and candidate evaluation. It does not implement a Runtime Engine, scheduler, model invocation, State mutation, Decision, Action, Memory, or Learning.

`Cognitive State != Reality State`; `Runtime State != Persistent State`; `Thinking != Decision`; `Possible World != Future Truth`; `Runtime Lifecycle != Memory Lifecycle`.
