# Cognitive Counterfactual Reasoning Architecture Plan v1

## Actual asset mapping

This planning layer aligns with Survival Constitution, Field Representation/View, Current Cognitive Context, Hypothesis Layer, Belief State, Cognitive Causality Model, Possible Future Space, Future Branch Governance, Optimization Layer, Decision Candidate, Experience Boundary, Knowledge Boundary, and Reducer Authority. Existing ownership and authority remain unchanged.

## Position

`Causal Candidate -> Counterfactual Candidate -> Possible World Branch Candidate -> Future Evaluation Candidate -> Decision Candidate Support`.

Counterfactual Reasoning describes candidate exploration of what may differ if a condition differs. It is neither prediction of the future nor simulation of reality.

## Planning scope

No Simulation Engine, World Model Runtime, Decision Engine, Decision Execution, Action, or State Mutation is authorized.
