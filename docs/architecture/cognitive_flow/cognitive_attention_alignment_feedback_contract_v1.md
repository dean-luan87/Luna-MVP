# Attention Alignment Feedback Contract v1

```text
Attention Alignment Feedback Candidate
├── Intent Match Candidate
├── Information Value Candidate
├── Coverage Candidate
├── Waste Candidate
├── Missing Information Candidate
├── Drift Candidate
├── Improvement Candidate
└── trace_ref
```

Feedback answers “did this observation help the original purpose?” It does not assert Truth, completion, or permission. Missing information remains visible; an empty or weak result cannot be interpreted as absence.
