# Situated Understanding Authority Matrix v1

| Module | Permitted responsibility | Explicitly prohibited |
|---|---|---|
| Provider | return observation/evidence candidates and provider status | interpretation, truth, decision, action |
| Evidence Gateway | package, preserve provenance, govern evidence flow | confirm reality truth |
| Reality Representation | form Reality Candidates from governed evidence | decide situation or mutate World State |
| World Model | maintain represented World State through admitted Reducer flow | decide, act, bypass provenance |
| Self Model | provide abstract subject/capability context | Registry, Memory, device control |
| Neural Governance | organize cognitive process and couple candidates | goals, truth, decision, provider execution |
| Brain | form understanding and judgment candidates | directly invoke providers or mutate State |
| Middleware | provide capability, feasibility, resource information | cognitive goal, truth, situation judgment |
| Reducer | sole State mutation authority | infer, decide, execute, self-authorize mutation |

No row grants automatic learning, direct hardware control, or Action authority
within this architecture phase.
