# Goal Type Model v1

Goal type candidates may include:

- User Goal: an explicit user-desired result candidate;
- Task Goal: a task-result candidate;
- Safety Goal: a safety-oriented result candidate;
- Assistance Goal: a human-assistance result candidate;
- Exploration Goal: an information/exploration result candidate;
- Maintenance Goal: a state-maintenance result candidate.

Types are candidate classifications, not commands, missions, decisions, actions, permissions, or identity claims.
