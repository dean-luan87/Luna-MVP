# Reflection Strategy Return Model v1

## Controlled return path

```text
B Reflection Candidate
      ↓
Hypothesis / Assumption Validation
      ↓
Reality Feasibility Assessment
      ↓
Constitution and Authority Review
      ↓
Adoption Candidate
      ↓
Future A Strategy / Attention / Capability Guidance Candidate
```

## Return contract

Reflection may return a strategy candidate, observation preference candidate,
capability improvement candidate, or self-understanding candidate. Each return
must preserve its reflection source, hypothesis state, evidence/experience
support, validation result, uncertainty, and adoption status.

No return automatically changes A. A future governance path may consider an
admitted candidate, but B cannot directly mutate a Strategy, Self Model,
Attention, Resource allocation, Provider plan, Decision, Action, or State.
