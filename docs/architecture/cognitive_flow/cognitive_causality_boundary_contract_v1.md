# Cognitive Causality Boundary Contract v1

## Allowed candidate references

Governed Field observations/relationships, Context, Hypothesis, Belief, Future Space, Predictive Field State, Experience, Knowledge, Survival/risk, provenance, and trace references may be read.

## Rejected inputs and effects

World Model Runtime, Causal Engine, causal graph execution, simulation, raw model/provider output, Fact Store authority, Decision result, Action command, permission, State handle, Reducer command, Memory mutation, Learning runtime, and Hive authority are outside this layer.

## Negative guards

- Cause Candidate != Cause Fact.
- Correlation != Causality.
- Causality != Hypothesis.
- Hypothesis != Fact.
- Knowledge != Current Reality.
- Knowledge != Truth.
- Experience != Universal Rule.
- Experience != Rule.
- Prediction != Reality.
- Possible Future != Prediction Truth.
- Risk Cause != Fact.
- Causality != Decision.
- Causality != Action.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not state mutation, not decision, not action, not permission, and not memory.
