# Cognitive Kernel Consistency Model v1

## Purpose

Consistency validation identifies whether a proposed cognitive organization remains aligned with current evidence, context, goal, attention, and available resources.

## Checks

1. **Goal Consistency** — does the proposed process serve the Active Goal Candidate?
2. **Context Consistency** — does it fit the Current Cognitive Context Candidate?
3. **Resource Consistency** — does it remain inside the Resource Budget Candidate?
4. **Attention Consistency** — does it align with admitted attention direction, depth, and duration?
5. **Reality Consistency** — does it preserve the distinction between Evidence, Representation, Schema, Hypothesis, and Simulation?

## Example

```text
Attention Candidate: airport-exit focus
Capability Bundle Candidate: commercial-store search
Resource Budget Candidate: reduced visual sampling
  -> Consistency Adjustment Candidate:
     defer commercial search; preserve goal-relevant evidence scope
```

## Output

The Kernel emits a Consistency Result Candidate, Conflict Candidate, Adjustment Candidate, or Deferral Candidate. It does not correct a module directly or declare a fact.
