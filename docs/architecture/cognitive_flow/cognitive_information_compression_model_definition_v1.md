# Cognitive Information Compression Model Definition v1

`CognitiveInformationCompressionCandidateV1` may retain source-type, structural/causal relation, critical variable, context/temporal/spatial/goal/resource/risk boundary, applicability, exception, failure condition, loss profile, representation, maturity, provenance, and trace references.

It may describe compression, matching, decompression, reconstruction, adaptation, or revision candidates. It remains `candidate_only=true`, `not_data_compression=true`, `not_embedding=true`, `not_fact=true`, `not_memory=true`, `not_knowledge=true`, `not_rule=true`, `not_language=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, and `not_permission=true`.
