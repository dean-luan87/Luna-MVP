# Cognitive Audio Evidence Adapter Model v1

## Future input

`Audio Stream / Audio Capability Output -> Audio Evidence Candidate`

Candidate categories may include Speech Candidate, Speaker Candidate, and Sound Event Candidate.

Audio candidates preserve timing, capture context, confidence, ambiguity, source/provenance, and contradictions. A recognized phrase is not Intent, Goal, Fact, Decision, or Action; it must enter through evidence admission and later cognitive interpretation.
