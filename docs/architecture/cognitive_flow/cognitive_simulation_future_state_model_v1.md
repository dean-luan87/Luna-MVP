# Cognitive Simulation Future State Model v1

Future State Candidate expresses a possible outcome under stated initial condition, changed variable, transformation, and evidence requirements. It retains uncertainty and alternative futures rather than confirming an event.

`Weather Change Candidate -> Traffic Increase Candidate -> Arrival Delay Candidate` is a chain of candidates, not “tomorrow will rain” or “arrival will be delayed.” Future State != Future Fact, Reality, Decision, Action, or Permission.
