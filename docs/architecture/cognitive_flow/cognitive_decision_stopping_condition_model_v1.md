# Decision Stopping Condition Model v1

## Purpose

Decision Stopping Condition Candidate describes when continued reasoning or option expansion may no longer add sufficient value for the current context. It avoids infinite cognition without treating cessation as truth or a Decision.

Candidate conditions can include: sufficient current evidence for bounded future consideration; exhausted relevant information value; a stable conservative option space; time/resource constraint; Survival interruption; or a higher-priority context change.

## Boundary

Stopping is not selection, permission, action, fact confirmation, or deletion of alternatives. A stopped branch can preserve unknown, conflict, and deferred options. Later evidence or changed context may produce a new candidate evaluation.
