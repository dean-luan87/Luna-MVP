# Cognitive Deep Reasoning Model Definition v1

`CognitiveDeepReasoningCandidateV1` may retain context, survival/risk, goal/value, uncertainty, time/resource budget, mode/depth, field/event, causality, counterfactual, future-space, optimization, knowledge/experience, provenance, and trace references.

It may identify a bounded reasoning purpose, candidate scope, activation rationale, branch/resource limits, and termination/reconsideration references. It is `candidate_only=true`, `not_fact=true`, `not_simulation=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
