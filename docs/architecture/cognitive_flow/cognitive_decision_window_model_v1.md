# Cognitive Decision Window Model v1

## Definition

Decision Window Candidate expresses how much candidate cognitive opportunity remains to form, compare, delay, escalate, or commit a future Decision Candidate before Field/Context dynamics may make the current option basis stale.

It is not an action deadline, forced Decision, wall-clock scheduler, or permission to bypass unresolved evidence. A narrow window may preserve a conservative delay, escalation, or limited-option candidate rather than force a decision.

## Commitment relation

Decision Commitment can cite a Decision Window Candidate as one stopping, delay, or escalation condition. It cannot convert window pressure into a Decision, Action, command, State change, or Facts.
