# Cognitive Imagination Space vs Simulation Boundary Model v1

| Dimension | Engineering Simulation | B: Cognitive Imagination Space |
|---|---|---|
| Purpose | predict/verify a specified system outcome | explore a better way of understanding or existing |
| Input | environment/system model and fixed parameters | experience, value, self understanding, explicit hypotheses |
| Constraint | calibrated real parameters where possible | open hypotheses marked as hypothetical |
| Target | accuracy / engineering verification | insight / candidate formation |
| Output | prediction or simulation result | strategy, self-understanding, improvement candidate |
| Responsibility | engineering validation | no real-world execution responsibility |

Example: Simulation asks whether a route will be congested after rain. B asks
whether an ability to understand city rhythms earlier could reduce comparable
future uncertainty.

## Frozen boundary

B is not a Simulation Runtime or Sandbox Environment. A B hypothesis is not a
prediction, evidence, Reality fact, capability state, decision, or action.
Only `Hypothesis → Validation → Reality Feasibility → Adoption Candidate` may
allow a reflection result to influence a future reality-governed path.
