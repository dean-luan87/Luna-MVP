# Cognitive Foundation Constitution Plan v1

## Purpose

This review defines the proposed frozen baseline principles for the Luna A-route rational Cognitive Foundation. It does not declare final GO, alter an existing decision, or authorize a future runtime.

## Reviewed baseline

`Field -> Situation -> Context -> Intent / Goal -> Affordance / Capability -> Attention -> Information Gap / Sufficiency -> Routing -> A/B Candidate Paths -> Reasoning / Future Space / Optimization -> Decision Candidate / Commitment -> Outcome / Experience -> Compression -> Representation Evolution -> Culture / Gene Pool -> Future Cognition`.

## Constitution scope

The baseline governs candidate-first, reality-first, context-bound, minimum-sufficient, and validation-based cognition. It is the rational foundation for future extension interfaces, not an Emotion, World Model, Language, Hive, Decision, Action, Memory, Learning, or State runtime.
