# Cognitive Compression Experience Alignment v1

Experience is one source for Cognitive Information Compression:

`Experience -> Compression Candidate -> Internal Representation -> Future Guidance Candidate`.

Experience is not Compression, Compression is not Experience, and Experience is not Knowledge. Existing Experience Compression remains an application layer under this foundation. Guidance must not directly determine Routing, create Decision, or modify State.

A route may use applicable representations for fast matching and bounded understanding. B route may expand raw/current information, reconstruct relations, and form revised representation candidates when existing representations are insufficient. Deep Reasoning is not More Compression or Higher Intelligence.
