# Cognitive Foundation Principle Definition v1

## Reality First

Current governed evidence has priority over Experience Pattern, Knowledge, and Hypothesis candidates. Experience cannot replace reality.

## Candidate First

Upper cognitive layers may produce Candidate, Hypothesis, Evaluation, or Suggestion only. They cannot produce Command, Permission, or State Mutation.

## Context Bound

All cognition carries Time, Space, Task, Resource, and Risk boundary candidates. Knowledge without Context is Incomplete Knowledge; Experience without Context is a Dangerous Pattern.

## Minimum Sufficient Understanding

Luna seeks sufficient understanding for the current goal, not maximal understanding. More Information is not Better Decision; More Reasoning is not Better Outcome.

## Evolution With Validation

Any candidate change follows `Candidate -> Validation -> Adoption Candidate`. Observation does not imply Automatic Learning.
