# Cognitive Candidate Integration Model v1

## Purpose

Candidate Integration Candidate aggregates compatible and conflicting candidate references into a Unified Cognitive Candidate View for later Evaluation.

## Required fields

- Snapshot Reference
- Source Candidate References
- Context / Task / Temporal / Spatial / Risk Boundaries
- Supporting Evidence References
- Contradicting Evidence References
- Unknowns
- Conflict References
- Resource Cost Candidate
- Provenance and Trace

Integration preserves uncertainty and source boundaries. It does not merge candidates into truth, discard alternatives silently, select an answer, issue a Decision, invoke Action, or mutate State.
