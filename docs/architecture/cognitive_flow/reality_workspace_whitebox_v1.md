# Reality Workspace Whitebox v1

```text
Vision / Audio / OCR / SLAM / User / Capability Evidence
                          ↓
                 Evidence Intake Layer
                          ↓
                Evidence Package Validation
                          ↓
                 Evidence Assembly Layer
           Entity Binding / Temporal / Spatial Association
                          ↓
                    Reality Candidate
                          ↓
              Reality State Reducer (sole State authority)
                          ↓
                  Current World State
                          +
                  Self Reality State
                          ↓
             Situated Reality Context Interface
                          ↓
                    Situation Candidate
                          ↓
                    Brain Evaluation
```

At every boundary, Evidence, Candidate, Fact-layer State, Situation, Decision,
and Action remain distinct. Provenance, timestamp, confidence, uncertainty,
conflict, validity, and Unknown are traceable across the workspace. The whitebox
does not imply Runtime execution.
