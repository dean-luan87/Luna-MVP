# Field Event Prediction Boundary v1

Event Candidate is not Prediction Result. It may express an ongoing or possible transformation, for example “crowd increase trend candidate”; it cannot assert a future fact, such as “congestion will certainly occur in ten minutes.”

Graph, vector, tensor, probability, coordinate, and temporal-sequence mechanisms are future implementation tools only. Event is not timestamp record; Field Change is not coordinate difference; Evolution is not time-series prediction.
