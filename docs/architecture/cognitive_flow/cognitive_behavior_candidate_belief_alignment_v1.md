# Cognitive Behavior Candidate Belief Alignment v1

## Belief-informed, not belief-authorized

Belief and Hypothesis references may shape candidate behavior. If an obstacle remains a meaningful possibility, candidates can include further observation, safe bypass, or delay instead of direct passage. A Belief State does not select among these behaviors.

## Uncertainty preservation

Conflicting hypotheses and uncertain beliefs remain visible in provenance and required-evidence references. Confidence does not transform a candidate into a command, and a higher-probability explanation does not automatically eliminate lower-probability, higher-risk possibilities.

Frozen rule: `Belief != Behavior Authority` and `Belief != Action`.
