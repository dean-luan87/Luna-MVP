# Cognitive Evidence Conflict Model v1

Evidence Conflict Candidate preserves incompatible or competing evidence rather than selecting a winner automatically.

Example:

```text
Camera Candidate: door closed
OCR Candidate: open for business
 -> Evidence Conflict Candidate
 -> Evaluation / Attention / additional evidence candidate
```

Conflict != Error, Fact Resolution, Decision, Action, or source deletion. A conflict can lower sufficiency or raise attention, but cannot mutate Reality.
