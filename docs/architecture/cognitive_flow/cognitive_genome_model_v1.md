# Cognitive Genome Model v1

Cognitive Genome is the designer-provided, governed foundational cognitive structure that makes world understanding possible. It includes boundary-level references for Field, Context, Situation, Goal, Intent, Causality, Experience, Compression, Sufficiency, Survival, Attention, and governance.

Genome is not an individual representation, personality, identity, runtime configuration, or mutable capability asset. Individual experience cannot automatically rewrite Genome.
