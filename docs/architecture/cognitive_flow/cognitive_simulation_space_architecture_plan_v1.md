## Position

`Workspace -> Simulation Candidate -> Branch Generation Candidate -> Future State Candidate -> Evaluation Candidate -> Decision Candidate Support`.

Simulation Space is a Workspace-derived candidate-world space for hypotheses, changed conditions, possible outcomes, and alternative paths. It is not Reality, Prediction, Future Truth, Decision, Action, Permission, or State mutation.
