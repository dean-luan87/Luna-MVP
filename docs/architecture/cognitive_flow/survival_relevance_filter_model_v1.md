# Survival Relevance Filter Model v1

## Purpose

Future Cognitive Flow may evaluate whether an Observation, Evidence reference, Primitive Candidate, Concept Candidate, or Field Representation Candidate is relevant to survival constraints. This is a prioritization model, not an admission, scoring Runtime, or an exclusion mechanism for traceable evidence.

## Candidate path

`Observation / Evidence / Concept / Field Representation -> Survival Relevance Evaluation Candidate -> Cognitive Processing Candidate -> Behavior Boundary Candidate`

Raw inputs do not enter a cognitive core merely because a model produced them, and relevance does not create a Fact, Identity, Permission, or Action.

## Priority classes

1. survival-related information;
2. action-limiting information;
3. task-related information;
4. environmental-understanding information; and
5. non-essential knowledge information.

Priority is contextual and provisional. A lower class is not deleted, false, or permanently irrelevant. Future governance must preserve provenance, uncertainty, and traceability for any relevance assessment.

## Forbidden shortcuts

The model must not automatically suppress unknowns, infer risk as Fact, elevate confidence to authority, or alter Field State. It creates neither a direct Action pathway nor a Provider-specific cognitive taxonomy.
