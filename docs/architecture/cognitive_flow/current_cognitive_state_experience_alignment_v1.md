# Current Cognitive State Experience Alignment v1

## Present versus past

Experience provides traceable historical pattern references; Current Cognitive State is the present candidate interpretation. Experience may inform a state-formation candidate but cannot automatically overwrite Context, Mode, Attention, Hypothesis, Belief, Reasoning, Goal, or Decision references.

`Experience -> Current Cognitive State Formation Candidate -> Future Experience` is a reference loop, not a Memory writeback or automatic adaptation loop.

Experience remains uncertain and context-dependent. It is neither current reality nor Cognitive State authority.
