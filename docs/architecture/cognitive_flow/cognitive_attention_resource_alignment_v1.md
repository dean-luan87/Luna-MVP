# Cognitive Attention Resource Alignment v1

`Attention Candidate -> Resource Budget Candidate -> Reasoning Depth Candidate`.

Low-risk contexts may activate a minimal schema set. High-risk/high-uncertainty contexts may propose broader attention, more active schemas, and B-route resource candidates. Resource limits may defer or keep schemas dormant.

Attention does not control a compute scheduler. More Active Schemas != Better Cognition; more information != better Decision.
