# Cognitive Emotion Attention Interface v1

Future Emotion Engine may emit an `Emotion Attention Candidate`, for example a relationship or safety salience request. It enters the same Attention Candidate Pool as all other sources.

```text
Emotion Attention Candidate -> Cognitive Attention Controller -> Active Cognitive Allocation Candidate
```

Emotion != Attention Override, Context Authority, Reality Interpretation, Decision, Action, Permission, or State mutation. Urgent task/risk/time constraints may limit emotion-derived attention allocation.
