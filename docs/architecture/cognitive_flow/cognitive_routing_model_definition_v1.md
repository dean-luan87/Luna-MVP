# Cognitive Routing Model Definition v1

`CognitiveRoutingCandidateV1` may retain context, situation, intent, goal, information-gap, survival/risk, time/resource budget, experience/knowledge, route type, reasoning objective, expected-output, reason, uncertainty, provenance, and trace references.

It may express `a_route_candidate`, `pattern_match_candidate`, `exploration_candidate`, `deep_reasoning_candidate`, or `deferred_reasoning_candidate`. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_intelligence_level=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
