# Cognitive Experience Trigger Activation Model v1

## Integration flow

`Outcome -> Experience Candidate -> Compression Candidate -> Representation Candidate -> Retention Candidate -> Context Activation Candidate`.

Experience may provide a context-matched pattern reference, but it does not directly enter active Retention and cannot automatically recall itself. Every activation requires Current Context Match and Validity Check candidates.

## Attention integration

`Field Change -> Attention Candidate -> Retention Match Candidate -> Reuse / Refresh Candidate`.

Attention chooses what needs focus; Retention determines whether an existing cognitive representation is eligible for context-bound reuse. Retention != Attention and Attention != Memory Search.

## Boundary

Experience != Automatic Recall, Rule, Decision Authority, or current-reality replacement.
