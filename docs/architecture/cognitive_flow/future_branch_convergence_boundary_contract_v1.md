# Future Branch Convergence Boundary Contract v1

Allowed inputs are governed Future Branch, Branch Governance/Evolution, Hypothesis, Belief, Evidence, Minimum Sufficient Understanding, Survival, Context, provenance, and trace references.

Outputs remain candidate-only, non-Fact, non-State-mutation, non-Decision, non-Action, non-Permission, and non-Memory.

Negative guards:

- Branch != Reality.
- Branch Count != Intelligence.
- Probability != Truth.
- Common Constraint != Fact.
- Merge != Confirmation.
- Pruning != Reality Rejection.
- Convergence != Decision or Action.
- Reducer does not manage Future Branch.
- Reducer remains the only State Mutation Authority.
