# Cognitive Constraint Reasoning Alignment v1

## Reasoning-resource relation

Cognitive Constraint may describe whether continuing a Reasoning Tree is currently worthwhile. It can cite Information Value, uncertainty, risk, time, and reasoning cost to form a reasoning constraint candidate such as retain, reduce, suspend, defer, or abandon.

If a reliable-enough explanation satisfies the present cognitive need, a candidate can identify low marginal value in further expansion. If higher-priority survival context interrupts a branch, it can identify a suspension condition. Neither result establishes truth, deletes evidence, or chooses an action.

## Lifecycle boundary

Reasoning Lifecycle manages tree status; Cognitive Constraint expresses why continuing may be limited. `Suspended != Failed`, `Completed != Fact`, and `Constraint != Decision`.
