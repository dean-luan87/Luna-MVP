# Cognitive Activation Decay Model v1

## Lifecycle

`Dormant -> Candidate -> Activated -> Maintained -> Reduced -> Dormant`.

When context/field/task/risk validity is invalidated, an `Invalidated -> Removed Candidate` path may be proposed. Dormant retains no active resource claim; it does not delete underlying Experience or Representation. Reduced != Wrong and Dormant != Deleted.

Decay is not TTL-only deletion, Memory mutation, Experience mutation, Decision, Action, or State mutation.
