# A-Route Cognitive Logic Metrics v1

## Level 1 metrics

| Metric | Observable fixture condition | Does not measure |
|---|---|---|
| Self Awareness | Self Capability Context changes the Situation Candidate where the World is held constant | intelligence, worth, or task success |
| Reality Grounding | facts, hypotheses, and risk/observation candidates are distinguishable and provenance-linked | final truth or intent attribution |
| Unknown Management | absent or ambiguous support remains in Unknown factors | object classification accuracy |
| Situation Adaptability | material evidence change produces a revised Situation Candidate | route selection or action success |
| Confidence Calibration | uncertainty and capability constraints limit confidence | probability calibration against real data |

## Evaluation method

Each fixture is evaluated as a deterministic contract observation:

1. required state/context fields are present;
2. expected Situation Candidate relations are represented;
3. required Unknown or confidence constraints remain visible;
4. forbidden fact, Decision, and Action outputs are absent.

The metrics are not reward scores, model benchmarks, online-learning signals, or
permission to execute an Action. A missing condition is a logic-validation gap
candidate for later review only.
