# Cognitive Retention Decay Model v1

## Decay Candidate inputs

- long non-use with reduced current applicability;
- changed context, field, goal, time, or risk conditions;
- repeated invalidation evidence;
- resource-pressure candidate.

## Candidate outcomes

`Maintain`, `Refresh`, `Decayed`, `Dormant`, `Retired`, and `Reactivated` are candidate-only lifecycle outcomes. Dormancy preserves an auditable reference; retirement does not erase historical experience.

## Boundary

Decay != TTL-only deletion, wrongness judgment, Memory deletion, Experience deletion, automatic Evolution, Decision, Action, or State mutation. Popularity and frequency cannot be the sole value measure.
