# Cognitive Evidence to Cognition Trace Model v1

```text
Synthetic Adapter Evidence
  -> Input Attention Allocation Candidate
  -> Evidence Admission Candidate
  -> Kernel Constraint / Consistency / Arbitration Candidates
  -> Process Candidate
  -> Runtime Instance Candidate
```

The trace records provenance and boundary flags. It does not record real sensor activity, external capability invocation, decision, action, or persistent-state change.
