# Cognitive Layer Boundary Model v1

## Three temporal cognitive layers

| Layer | Concern | Canonical candidate assets | Must not become |
| --- | --- | --- | --- |
| Present Cognitive Runtime Layer | What Luna currently observes, understands, attends to, and reasons about | Situation, Context, Intent, Goal, Attention, Sufficiency, Routing, Hypothesis, Decision Candidate | Memory truth store, execution authority, State authority |
| Past Memory / Evolution Layer | What prior outcomes and context-bound patterns may support current cognition | Experience, Compression, Representation, Culture, Gene Pool | Current reality, universal rule, local override |
| Future Prediction Layer | What may happen under stated conditions | Hypothesis, Counterfactual, Predictive Field State, Possible Future Space | Fact, event confirmation, action authority |

## Separation rule

`Past Experience Candidate -> Current Context Match -> Evidence Validation -> Present Cognitive Support Candidate`.

`Future Candidate -> Current Context and Evidence Validation -> Attention / Reasoning / Evaluation Support Candidate`.

Neither past nor future information directly mutates the present Field State, cognitive State, Decision, Permission, or Action.

## Negative guards

- Past != Present Reality.
- Future != Present Reality.
- Experience != Memory Authority.
- Representation != Knowledge Truth.
- Prediction != Fact.
- Current Cognitive Runtime != Reducer.
- Reducer remains the only State Mutation Authority.
