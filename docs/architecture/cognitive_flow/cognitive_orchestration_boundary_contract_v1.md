# Cognitive Orchestration Boundary Contract v1

- Orchestration != Decision Authority.
- Orchestration != Runtime Executor.
- Orchestration != Scheduler.
- Orchestration != Action.
- Orchestration != Permission.
- Orchestration != State Machine.
- Orchestration != State Mutation.
- Trigger != Decision.
- Tick != Runtime loop.
- Candidate Integration != Truth.
- Conflict != Automatic Resolution.
- Fast Loop != Learning.
- Slow Loop != Runtime Override.
- Resource Investment != Compute Scheduler.
- Observation -> Belief -> Action shortcut is prohibited.
- Reducer remains the only State Mutation Authority.

Future Emotion, World Model, Hive, Language, and Embodiment can only submit governed candidates through signal contracts; they do not become orchestration, Decision, Action, or State authorities.
