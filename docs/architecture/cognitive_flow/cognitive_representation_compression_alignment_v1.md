`Experience -> Compression Candidate -> Internal Representation Candidate -> Repeated Validation -> Stable Representation Candidate -> Cognitive Primitive Candidate`.

Experience does not directly form a rule. Compression preserves causal structure, critical variables, boundaries, failure/exception conditions, and applicability while producing reusable representation candidates. Representation != Compression Runtime, Experience, Knowledge, Memory, or Truth.
