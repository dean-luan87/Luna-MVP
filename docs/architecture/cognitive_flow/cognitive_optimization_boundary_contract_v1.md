# Cognitive Optimization Boundary Contract v1

Allowed inputs are governed Future Branch/Space/Governance/Convergence, Context, Goal, Survival, Mission, Information Value, Value Evaluation, Time/Resource Budget, Experience pattern, provenance, and trace references.

Negative guards:

- Optimization != Decision.
- Optimal != Truth.
- Highest Value != Mandatory Action.
- Probability != Utility.
- Utility != Survival.
- Experience != Optimal Solution.
- Optimization Stop != Commitment or Action.
- Reducer != Optimization Authority.
- Optimization != State Mutation.
- Reducer remains the only State Mutation Authority.
