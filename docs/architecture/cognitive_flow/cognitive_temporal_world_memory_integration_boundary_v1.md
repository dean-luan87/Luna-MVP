# Temporal / Field / World / Memory Integration Boundary v1

## Current phase boundary

This phase produces only Temporal Context and compact temporal candidates.
It does not connect Field Kernel, World Model Runtime, Simulation, B Reflection,
or a Memory Runtime.

## Future consumers

| Future subsystem | May consume later | Not authorized now |
|---|---|---|
| Field Kernel | validated Temporal Pattern Candidate via a separately admitted interface | Field integration or Field State mutation |
| World Model | governed Temporal State / Representation candidate | World Model Runtime implementation |
| Experience system | Temporal Experience Interface candidate | direct Memory write or Knowledge adoption |
| B Reflection | validated temporal experience through the established handoff | direct B entry or reflection work |
| Emotional Cognition | future value context around temporal opportunity | alteration of temporal facts or trends |

## Information path

```text
Temporal Evidence
        ↓
Temporal Representation Candidate
        ↓
Temporal Pattern Candidate
        ↓
Experience Candidate
        ↓
Future Knowledge / Memory Candidate
```

Future Knowledge / Memory Candidate remains a proposal until separate
Validation and Adoption. Reducer remains the sole State mutation authority.
