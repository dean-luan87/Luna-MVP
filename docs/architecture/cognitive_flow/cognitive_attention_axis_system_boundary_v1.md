# Attention Axis System Boundary v1

## End-to-end candidate chain

```text
Brain
        ↓
Attention Intent Candidate
        ↓
Attention Requirement Candidate
        ↓
Attention Governance
        ↓
Capability Observation Request Candidate
        ↓
Evidence Candidate
        ↓
Reality Cognition
        ↓
Situation Update Candidate
        ↓
Brain Evaluation
```

## Layer ownership

| Layer | Owns | Does not own |
|---|---|---|
| Brain | why information may be needed; final evaluation | Provider/model/device selection |
| Attention Axis / Requirement | what information and relation may be relevant | Goal, Reality interpretation, Decision, Action |
| Attention Governance | candidate admission/arbitration | actual runtime allocation or Provider execution |
| Capability Governance | capability observation request organization | cognitive priority/meaning |
| Provider / Evidence Gateway | governed evidence output | Reality, Situation, cognitive completion |
| Reality Cognition | evidence interpretation and Situation update candidates | observation/device execution |
| Neural Regulation | response-strength and resource feasibility candidates | Attention Goal or hardware control |

## Guards

Attention Requirement != Automatic Frequency Adjustment. Attention does not own device frequency. Neither Attention Intent nor Attention Requirement may control device frequency, sensor sampling, model execution, hardware, an actuator, or a Scheduler.
