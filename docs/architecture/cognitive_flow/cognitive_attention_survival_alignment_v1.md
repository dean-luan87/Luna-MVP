# Cognitive Attention Survival Alignment v1

## Survival-driven focus

Survival Constitution constrains future attention priority. The intent is not to maximize total information; it is to prioritize the attention necessary for current safety, bounded exploration, and task progress.

`Survival -> Attention Selection Candidate -> Minimum Sufficient Information Candidate -> Behavior Boundary Candidate`

## Unknown environment

`Unknown != Ignore`. An unknown Field or unknown Attention condition is valid. Future attention should prioritize survival-related unknowns, action-limiting unknowns, high-risk unknowns, and high-change unknowns before attempting complete Field Identity classification.

Attention cannot turn unknown into Fact, automatically stop every behavior, or generate a direct Action from a model output.
