# Cognitive Hypothesis Boundary Contract v1

Allowed future references are Primitive, Concept, Field Representation, Current Context, Information Gap, Observation Candidate, Experience Candidate, provenance, and trace. Fact Store, Memory Mutation, Decision, Action, Permission, Reducer Command, and State Mutation are prohibited.

Every output remains `candidate_only=true`, `not_fact=true`, `not_state=true`, `not_decision=true`, `not_action=true`, and `not_memory=true`.

Hypothesis != Fact; Confidence != Truth; Hypothesis != Decision; Model Output != Direct Belief; Observation != Confirmation; Experience != Automatic Learning.
