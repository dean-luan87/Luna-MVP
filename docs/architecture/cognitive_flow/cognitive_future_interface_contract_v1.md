# Cognitive Future Interface Contract v1

## Emotion

`Emotion Candidate -> Weight Adjustment Candidate -> Attention/Evaluation Influence Candidate`.

Emotion cannot create Decision, Action, Permission, Reality rewrite, or route override.

## World Model

`World Model Candidate -> Field Understanding Enhancement Candidate -> Reasoning Support Candidate`.

World Model cannot become Reality Authority, Fact source, State mutation path, Decision, or Action.

## Hive

`Hive Candidate -> Experience/Culture/Gene Pool Candidate -> Local Validation`.

Hive cannot become Global Rule, central brain, individual override, or local-context override.

## Language

`Internal Representation Candidate -> Language Expression/Interpretation Candidate`.

Language is an expression/communication layer, not Cognition authority, representation authority, direct Decision, or Action.
