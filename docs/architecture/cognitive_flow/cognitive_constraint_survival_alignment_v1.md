# Cognitive Constraint Survival Alignment v1

## Constraint inheritance

Survival Constitution is the highest input constraint. Cognitive Constraint translates its candidate relevance into bounded cognition and behavior-space restrictions; it does not turn survival into an Action controller or a fixed safety rule database.

For an unknown dark area with unclear exploration value, unresolved risk, and no known return path, an Exploration Constraint Candidate can reduce exploration priority or preserve a defer/alternative-path condition. It does not forbid movement, select waiting, or execute a retreat.

## Frozen relationship

`Survival > Cognitive Constraint > Behavior Boundary > Future Action Candidate` is a constraint-inheritance relationship, not an execution pipeline. Survival safety remains prior to information acquisition; uncertainty remains explicit rather than being filled automatically.

`Unknown != Failure`, `Risk != Fact`, and `Survival != Action Controller`.
