# Complete Cognitive Lifecycle Map v1

## Lifecycle view

```text
Field / Reality Observation Candidate
  -> Perception and Situation Candidate
  -> Context, Intent, and Goal Candidate
  -> Attention, Resource, and Sufficiency Candidate
  -> Routing Candidate
  -> Pattern Match Candidate | Deep Reasoning Candidate
  -> Hypothesis, Causality, Counterfactual, and Future-Space Candidate
  -> Value, Trade-off, and Optimization Candidate
  -> Decision Candidate
  -> Commitment Candidate
  -> Human Choice / External Executor Boundary Reference
  -> Outcome Observation Candidate
  -> Experience and Compression Candidate
  -> Representation Evolution / Future Cognitive Adjustment Candidate
```

## Lifecycle properties

- The present cycle may retrieve past-pattern candidates, but past information is revalidated against current context and evidence.
- Future-space candidates may prepare attention, reasoning, and candidate boundaries; they never confirm a future state.
- Human or separately governed external execution is the only possible route from cognitive output to a reality-changing act.
- Outcome feedback may adjust future experience candidates; it cannot rewrite history, prove a decision correct, or mutate State.

## Non-linear interaction

The map is a governed lifecycle, not a mandatory linear Runtime pipeline. Risk, field, goal, or context changes may request attention reallocation, route reconsideration, or candidate revision. Such requests remain candidate-only and do not bypass the execution boundary.
