## Position

`Cognitive Process -> Outcome Observation Candidate -> Cognitive Feedback Candidate -> Experience / Representation / Schema Improvement Candidate -> Validation -> Evolution Adoption Candidate -> Future Cognitive Guidance Candidate`.

This layer explains why cognition may improve. It is not machine-learning training, model parameter update, automatic self-rewrite, Decision, Action, Memory mutation, or State mutation.
