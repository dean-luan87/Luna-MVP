# Cognitive Mode Switching Time Alignment v1

## Time relation

Mode Candidate can influence the interpretation of a Cognitive Time Budget Candidate: a narrow urgent window can support Reactive candidate processing, while a broader low-dynamics window can retain Adaptive, Exploratory, or Reflective candidates.

It cannot control real time, create a timer, schedule a Runtime, preempt a process, or force a Decision Window. Time Budget and Reasoning Tree Preemption remain independently defined candidate models.

`Mode != Runtime Scheduler` and `Time Budget != Action Deadline`.
