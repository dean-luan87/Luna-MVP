# Cognitive Information Processing Model v1

## Candidate processing flow

`Information Source -> Filtering Candidate -> Alignment Candidate -> Information Representation Candidate -> Cognitive Processing Candidate -> Candidate Output`.

Processing may associate, combine, abstract, complete, detect conflict, and evaluate information value. It must preserve information-boundary metadata and cannot automatically generate fact, change reality, decide, act, grant permission, write Memory, or mutate State.

Information completeness is a candidate need, not authorization to fill gaps as truth.
