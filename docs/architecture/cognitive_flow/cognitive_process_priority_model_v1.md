# Cognitive Process Priority Model v1

## Priority candidates

Process priority is a candidate evaluated against current Intent, Situation,
Survival Constitution, resource state, and escalation policy:

```text
Survival
  ↓
Safety
  ↓
Critical Goal
  ↓
Active Goal
  ↓
Efficiency
  ↓
Optimization
  ↓
Background Exploration
```

Priority does not equal importance permanently. A low-priority process may be
promoted when risk, temporal urgency, or unknown growth changes. A high-priority
candidate still requires Brain or Neural governance according to authority.

## Competition dimensions

Competing processes declare Attention Cost, Capability Cost, Memory Cost, Energy
Cost, Network Cost, expected information value, deadline candidate, and
escalation impact. The Resource Manager returns an Allocation Candidate; it does
not run a Scheduler or execute a process. Information Value and Resource Cost are
explicit comparison fields, and this model is not a Scheduler.
