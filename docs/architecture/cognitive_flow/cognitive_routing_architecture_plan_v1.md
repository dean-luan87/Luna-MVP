# Cognitive Routing Architecture Plan v1

## Actual asset mapping

This planning layer aligns with Field/Situation Understanding, Current Cognitive Context, Intent Understanding, Goal Understanding, Information Gap, Survival Constraint, Risk Candidate, Cognitive Mode Switching, Cognitive Depth Regulation, Dynamic Cognitive Time Regulation, Cognitive Resource Allocation, Experience/Knowledge Boundaries, Deep Reasoning Foundation, Behavior Candidate, Reducer Authority, and L0/L1 Governance.

## Position

`Context -> Intent -> Goal -> Information Gap -> Cognitive Routing Candidate -> A Route / B Route -> Behavior Candidate`.

`Field -> Situation -> Current Context -> Intent Understanding -> Goal Understanding -> Cognitive Routing -> {A Route: Fast Cognition | B Route: Deep Reasoning} -> Behavior Candidate`.

Cognitive Routing decides candidate cognitive path, reasoning objective, and resource investment for an unresolved problem. It does not decide an answer, behavior, permission, decision, or action.

## Planning scope

No Deep Reasoning Runtime, LLM Chain, Simulation, World Model Runtime, Decision Engine, Action Execution, Emotion Engine, Memory Mutation, or State Mutation is authorized.
