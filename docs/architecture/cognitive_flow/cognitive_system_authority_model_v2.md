# Cognitive System Authority Model v2

## Authority matrix

| Authority | Cognitive Brain | Cognitive Neural Architecture | Cognitive Middleware | Body / Capability | Reducer / External Boundary |
|---|---:|---:|---:|---:|---:|
| Goal Authority | ✓ candidate formation | — | — | — | — |
| Attention Authority | ✓ allocation candidate | — transport/classification only | — feasibility input only | — | — |
| Signal Authority | emits/consumes content candidates | ✓ taxonomy, boundary, compatibility, trace governance | emits/consumes capability/evidence/state candidates | emits raw observations/health | — |
| Protocol Authority | constrained participant | ✓ under Cognitive Governance | constrained participant | constrained participant | Governance constrains adoption |
| Capability Authority | defines information need only | — | ✓ capability organization/bundle feasibility candidate | future bounded physical/provider execution only | future admission boundary |
| Evidence Authority | evaluates evidence candidate | transports classified evidence signal | ✓ evidence packaging/provenance/uncertainty | raw result only | — |
| Truth Authority | — | — | — | — | Reality is external; no Luna internal layer confirms truth by authority |
| Decision Authority | Evaluation / Decision Support Candidate only | — | — | — | Future human/executor boundary only |
| Action Authority | — | — | — | no autonomous world action | Future permission-controlled executor only |
| State Mutation Authority | — | — | — | — | ✓ Reducer only |

## Reconciliation rules

1. Brain owns cognitive intention and evaluation, but not final action or truth.
2. Neural owns signal/protocol governance, never signal meaning as fact.
3. Middleware owns capability organization and evidence packaging, never cognitive selection or decision.
4. Body owns raw physical/provider output and limited local self-protection only.
5. Reducer remains the only State Mutation Authority regardless of signal origin.

## No-authority zones

- No layer has `Truth Authority`.
- No A-route layer has final `Decision Authority` or `Action Authority`.
- No module has authority to change State outside Reducer.
