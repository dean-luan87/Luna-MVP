# Evaluation and Decision Support System Architecture v1

## Purpose

Answers: which candidate paths may be worth considering under survival, mission, goal, risk, resource, reversibility, and trade-off constraints?

## Existing module grouping

Cognitive Constraint, Behavior Boundary, Behavior Candidate, Value Evaluation, Multi-Perspective Optimization, Trade-off, Conflict, Decision Candidate Formation, Decision Resolution, Decision Commitment, and Commitment Responsibility.

## Input and output

Inputs are Candidate Space, Future Space, Constraints, Context, Goal, Mission, Survival, Risk, Cost, Reversibility, and Experience candidates. Outputs are behavior/value/trade-off/conflict/decision-support/commitment candidates.

## Boundary

The system does not make Future Decision, grant Action Permission, execute Action, or mutate State. Optimization is not Decision and Commitment is not Action authority.
