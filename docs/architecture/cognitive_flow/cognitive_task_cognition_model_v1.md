# Cognitive Task Cognition Model v1

Task Cognition is the A-route conscious mode for current tasks. It emphasizes Situation, Context, Experience Guidance, Activation, Attention, and Minimum Sufficient Understanding candidates.

It seeks bounded, low-resource task understanding. Task Cognition != decision, action, automatic pattern authority, or permanent workspace retention.

Task Cognition and Deep Reasoning share one Conscious Layer and may be selected through existing Routing/Depth/Resource candidates.
