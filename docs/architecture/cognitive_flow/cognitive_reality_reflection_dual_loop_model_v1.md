# Cognitive Reality–Reflection Dual Loop Model v1

## Purpose

Luna has two complementary cognitive loops. A is responsible for current
reality-bound understanding and reaches the existing Brain Decision Candidate
boundary. B is responsible for slow, open-ended reflection on experience,
value, and possible future ways of existing. B never assumes A's execution
responsibility.

```text
A: Current World State + Self Capability + Goal + Resource
                              ↓
            Situated Understanding → Brain Decision Candidate boundary

B: Experience + Outcome Reference + Value Feedback + Self Model
                              ↓
          Reflection Space → Strategy / Self Understanding Candidates
```

## Shared inputs, separate responsibilities

| Property | A: Reality Cognition | B: Reflective Cognition |
|---|---|---|
| Primary concern | correct, safe, current-world response | better future strategy and self-understanding |
| Tempo | fast / context-bound | slow / depth-budgeted |
| Constraints | only existing capabilities, resources, and conditions | may explore explicit hypothetical conditions |
| Output | reality/situation/feasibility and Brain Decision Candidate boundary | strategy, capability-improvement, self-understanding candidates |
| Responsibility | reality-constrained judgment boundary | no execution responsibility |

Both loops may share traceable Experience and Value Feedback. They do not
share control authority: B cannot directly change A, and A cannot treat B's
hypotheses as current-world facts.

A and B do not share control authority.
