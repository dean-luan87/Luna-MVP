# Cognitive A/B Execution Boundary Model v1

## Shared foundation

Both routes use the same Cognitive Kernel, Organization Layer, Context, Attention Governance, Workspace, Admission Control, trace boundaries, and Reducer separation.

## Route candidates

```text
A Route = Fast Cognitive Process Candidate
B Route = Deep Cognitive Process Candidate
```

## Admission relation

```text
Sufficiency / Risk / Unknown / Resource Candidates
  -> Attention and Kernel Arbitration
  -> A or B Process Admission Candidate
```

B remains frozen in this phase. The architecture defines its admission boundary only; it does not define or execute deep reasoning, simulation expansion, model invocation, decision, or action.

## Boundary

B Route has no independent cognitive authority. It cannot bypass Kernel, Attention, Context, resource, evidence, or Reducer boundaries. A/B route admission is not a decision.
