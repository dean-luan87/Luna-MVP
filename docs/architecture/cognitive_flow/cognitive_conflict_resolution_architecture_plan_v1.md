# Cognitive Conflict Resolution Architecture Plan v1

## Position

Cognitive Conflict Resolution is a candidate-only layer for making incompatible or competing candidate conditions explicit and preparing possible handling paths. Its architecture is:

`Multiple Candidate Space -> Conflict Detection Candidate -> Conflict Classification Candidate -> Conflict Evaluation Candidate -> Conflict Resolution Candidate -> Decision Resolution Candidate`.

It treats conflict as normal cognitive information. It does not treat conflict as an error, failure, Decision, or Action trigger.

## Scope

The layer can identify and describe conflicts among goals, Survival/Mission constraints, information/action needs, risk/reward dimensions, Experience/current evidence, habit/rational evaluation patterns, and future role expectations. It cannot resolve a conflict authoritatively, choose a behavior, grant Permission, mutate State, or control Runtime behavior.
