# Cognitive Flow Module Responsibility Matrix v1

| Layer | Owns | Must not own |
| --- | --- | --- |
| External Capability | Observation/Evidence Candidate | Fact, State, Decision |
| Translation | Reference normalization/provenance | semantic truth, State |
| Primitive | Entity/Relation/State/Event/Situation Candidate | Fact, Decision |
| Concept | Meaning/Pattern/Situation Candidate | State, Memory, Action |
| Field Representation | Scoped cognitive query candidate | Snapshot/State update |
| Current Cognitive Context | Derived selection/sufficiency scope | Fact, State, Decision |
| Field Kernel | Current Field View organization | Reducer, Memory, Decision |
| Field Event | Possible change Candidate | admission, State mutation |
| Admission | Event eligibility/temporal assessment | Field State |
| Reducer | Field State mutation | raw candidate acceptance, Decision |
| L1 Governance | protocol/permission/trace/lifecycle diagnostics | cognitive transformation |
