# Current Cognitive State Resource Model v1

## Referenced resources

Current Cognitive State may refer to Time Budget, Attention Budget, Information Budget, Energy/Resource Budget, Cognitive Depth, and Cognitive Mode candidates. It provides a present coordination view of available/limited cognitive resources.

It does not allocate resources, operate a scheduler, alter time, reduce energy, or start/stop a reasoning process. Resource conditions are candidate references maintained by their respective future layers.

Resource State is not Field State, Permission, Decision authority, Action control, or Runtime management. A constrained budget can coexist with unknown and deferred cognitive paths.
