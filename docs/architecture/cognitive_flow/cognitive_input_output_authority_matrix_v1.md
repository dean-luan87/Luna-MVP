# Cognitive Input / Output / Authority Matrix v1

| Layer | Readable inputs | Permitted outputs | Authority it does not hold |
|---|---|---|---|
| Observation/Understanding | governed field/evidence, primitive, concept, relations | understanding candidates | fact, state, decision, action |
| Context/Intent/Goal | understanding, language/user, task, survival refs | context, intent, goal candidates | command, mission override, action |
| Affordance/Capability | situation/context/goal/resource refs | opportunity/limitation/capability candidates | permission, execution, identity |
| Attention/Value/Sufficiency/Routing | context, gaps, risk, resource, experience refs | attention/value/sufficiency/route candidates | runtime scheduling, decision, action |
| Reasoning/Future/Optimization | route, causal, hypothesis, future, constraints | causal/counterfactual/future/utility candidates | reality, prediction truth, decision |
| Decision Candidate/Commitment | behavior/value/conflict/constraint refs | option, trade-off, commitment responsibility candidates | actual decision, action permission |
| Monitoring/Outcome/Experience | commitment/outcome/field/context refs | monitoring, outcome, experience candidates | action control, learning authority |
| Compression/Evolution/Population | experience/representation/validation refs | representation/evolution/culture/gene-pool candidates | memory/hive write, self rewrite, state mutation |

## Frozen relations

- Observation != Fact.
- Hypothesis != Reality.
- Prediction != Reality.
- Experience != Rule.
- Compression != Knowledge Truth.
- Optimization != Decision.
- Decision Candidate != Decision.
- Decision != Action Permission.
- Reducer remains the only State Mutation Authority.
