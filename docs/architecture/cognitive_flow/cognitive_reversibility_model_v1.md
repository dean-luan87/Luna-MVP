# Cognitive Reversibility Model v1

## Definition

Reversibility is the candidate assessment of whether a future behavior can be limited, undone, exited, or safely redirected under current uncertainty. It is a distinct evaluation dimension rather than a synonym for risk, value, or permission.

For equivalent possible value, a five-meter bounded exploration may be more reversible than an extended entry into an unknown area. The distinction helps preserve alternatives for a future Decision layer without directing it to select either behavior.

## Boundary

Reversibility does not prove safety, create a permission, reduce Survival constraints, or command an Action. Missing reversibility information remains explicit uncertainty.
