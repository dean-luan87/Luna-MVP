# Cognitive Preparation Boundary Contract v1

Allowed inputs are governed references to Future Field State, Anticipation, Context, Attention, Information Value, Strategy, Depth, Hypothesis, Belief, Reasoning, Behavior Boundary, Experience/Learning Candidate, Survival, provenance, and trace.

Forbidden inputs are raw model output, provider payload, Fact Store, State handle, Reducer command, Decision result, Action command, Permission grant, Resource Scheduler command, Memory, Learning execution, or Hive authority.

Negative guards:

- Preparation != Decision.
- Preparation != Action.
- Preparation != Permission.
- Prediction != Preparation.
- Preparation != Future Truth.
- Preparation != State Mutation.
- Experience != Automatic Preparation.
- Emotion != Preparation Authority.
- Reducer remains the only State Mutation Authority.
