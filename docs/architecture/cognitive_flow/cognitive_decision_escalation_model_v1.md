# Decision Escalation Model v1

## Future escalation candidates

When candidate conflict is high, information value is unresolved, risk remains unacceptable, or Mission and Survival are in tension, Decision Candidate Formation may describe one or more non-executing escalation candidates:

- Request More Information Candidate;
- Delay Decision Candidate;
- Seek Alternative Candidate; and
- Human Assistance Candidate.

## Boundary

Escalation is not an observation call, Action trigger, Permission request approval, or Decision. It records an option-space condition and preserves the responsible evidence, uncertainty, conflict, provenance, and trace references for a future governed consumer.
