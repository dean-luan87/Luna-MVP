# Cognitive Attention Stability Model v1

Attention Stability Candidate limits unnecessary allocation oscillation by comparing Previous Attention Allocation Candidate, Current Attention Candidate Pool, current Context/Goal, Change Magnitude Candidate, and interruption/risk candidates.

```text
Previous Allocation + Current Candidate Pool + Change Magnitude
  -> Attention Stability Candidate
  -> Attention Transition Candidate
```

An advertisement may be salient while a crossing-road task remains stable. Stability != attention freeze, truth, importance authority, Decision, or Action.
