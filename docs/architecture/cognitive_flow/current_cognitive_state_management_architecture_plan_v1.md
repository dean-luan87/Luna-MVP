# Current Cognitive State Management Architecture Plan v1

## Position

Current Cognitive State is a candidate description of how Luna is presently facing the world during a bounded cognitive window. It coordinates existing references, without replacing their owners:

`Survival -> Current Cognitive State Candidate -> Current Context -> Attention -> Reasoning -> Decision Candidate -> Outcome Candidate`.

Field State describes governed external-world conditions. Cognitive State describes Luna's role reference, understanding status, goal condition, cognitive process condition, and resource references relative to those conditions.

## Scope

It is not a State Store, State Machine, Memory, Personality, Emotion system, Decision, Action, Field State mutation path, or Reducer replacement.
