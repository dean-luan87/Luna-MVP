# A-Route Extension Taxonomy v1

## Extension categories

| Category | Core question | Candidate A-route contribution | Current status |
|---|---|---|---|
| Temporal Extension | How is reality changing over time? | state change, trend, risk-window, temporal relation candidates | assess only |
| Spatial Extension | Where is Luna relative to the world? | spatial relation, reachability, path structure, layout candidates | assess only |
| Attention Extension | What information is worth understanding next? | priority, risk focus, observation value, information-gap candidates | assess only |
| Social Extension | What social conditions affect the environment? | people, rules, relation, social-context candidates | assess only; no Role Perspective |
| Multi-Agent Extension | How do multiple actors affect the world? | other-actor behavior, multi-party relation, group-effect candidates | assess only |
| Uncertainty Extension | What remains unknown and risk-bounded? | unknown, confidence, insufficiency, risk-envelope candidates | assess only |

Each category may enhance World Understanding, Self Understanding, Situation Quality, Decision support, or reality feedback.
No category gains direct Decision, Brain, Self Model, Action, or State authority.
