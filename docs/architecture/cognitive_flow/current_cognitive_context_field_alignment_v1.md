# Current Cognitive Context Field Alignment v1

## Boundary

`Field != Context` and `Context != Field State`.

Field describes environmental candidates or governed current conditions. Context describes the present interpretation frame, including task, survival constraints, uncertainty, and information gaps.

## Read-only relationship

Context may reference Field Representation, Current Field View, primitive/concept candidates, temporal/spatial scopes, and governed Field references. It cannot edit Field Identity, Affordance, Field Representation, Current Field View, Field Event, Field State, Snapshot, or history.

Field Kernel remains a query/organization layer; Reducer remains the sole Field State Mutation Authority.
