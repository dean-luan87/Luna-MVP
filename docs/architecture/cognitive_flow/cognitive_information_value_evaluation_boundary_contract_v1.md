# Cognitive Information Value Evaluation Boundary Contract v1

Inputs may reference Information Gap, Current Context, Goal, Survival Constraint, Attention Candidate, Field/View, provenance, and trace. No Model Result, Provider payload, Fact, State, Action, Decision, Permission, Reducer command, Memory, Learning, or Hive authority may enter.

Every future Information Value Candidate remains `candidate_only=true`, `not_fact=true`, `not_state=true`, `not_decision=true`, and `not_action=true`.

Information Value is not Decision; Risk is not Fact; Confidence is not Permission; Cost Estimate is not Action Command; Exploration is not Permission; Unknown is not Failure.
