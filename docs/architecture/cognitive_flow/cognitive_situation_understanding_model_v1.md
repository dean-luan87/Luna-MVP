# Cognitive Situation Understanding Model v1

Situation Candidate answers: “what environment or situation may Luna currently be in?” It contains candidate scene type, active environmental relations, task relevance, evidence references, confidence candidate, and unknowns.

Example: an airport departure-area candidate may be supported by camera, OCR, and map evidence while retaining an unknown boarding gate.

Situation Candidate != Reality Fact, Context state, World Model, Decision, Action, or Permission. Existing general Situation Understanding remains the source layer; this model specifies its Current World Understanding integration.
