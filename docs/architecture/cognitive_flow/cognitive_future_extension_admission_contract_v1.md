# Cognitive Future Extension Admission Contract v1

## Admission questions

Every future module must declare:

1. its candidate-only inputs and their context boundaries;
2. its candidate-only outputs and target subsystem;
3. whether it modifies Attention, Evaluation, Routing, or Experience support only;
4. whether it seeks any State Mutation authority (default: none);
5. how current evidence, local validation, provenance, and uncertainty remain visible;
6. how it avoids changing the Cognitive Constitution or A-route authority boundaries.

## Future module interfaces

| Module | Permitted candidate contribution | Forbidden authority |
| --- | --- | --- |
| Emotion Engine | Value Adjustment, Preference, Attention Bias Candidate | Reality judgment, Decision, Action, Constitution override |
| World Model | Field Understanding and Prediction Enhancement Candidate | Reality authority, event confirmation, Action |
| Language System | Internal Representation Expression / Human Communication Candidate | cognition authority, representation truth, Decision |
| Hive | Population Experience / Culture / Gene Pool Candidate for local validation | central intelligence, individual override, rule authority |
| Embodiment | Future Permission-Controlled Action Candidate interface | autonomous execution, Permission grant, State mutation |

## Admission rule

`External Module Output -> Candidate -> Context Match -> Evidence / Boundary Validation -> Local Cognitive Support Candidate`.

No extension may directly call an executor, mutate Field State, replace current observation, change the Reducer, or bypass Human Action Authority in the current baseline.
