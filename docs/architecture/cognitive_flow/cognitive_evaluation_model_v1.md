# Cognitive Evaluation Model v1

Inputs may include Representation Candidate, Hypothesis Candidate, Simulation Branch Candidate, Experience Candidate, Current Evidence, Context, Schema, Goal, Constraint, Risk, Time, and Resource references.

Evaluation Candidate may retain confidence/support, consistency, applicability, risk, uncertainty, information/reasoning value, alternative explanation, evidence gap, provenance, and trace.

Evaluation output is a candidate assessment. It is not Fact, Truth, Decision, Action, Permission, Evidence override, or State mutation.
