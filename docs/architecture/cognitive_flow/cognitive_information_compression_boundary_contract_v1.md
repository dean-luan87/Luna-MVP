# Cognitive Information Compression Boundary Contract v1

## Allowed candidate references

Governed Field, Event, Experience, Knowledge, Situation, Decision Trace, Context, current Evidence, Causality, temporal/spatial/goal/resource/risk boundaries, Sufficiency/Routing, provenance, and trace references may be read.

## Rejected inputs and effects

Compression algorithm/runtime, neural network training, embedding system, vector database, Memory System/Runtime, Hive System/Sharing, Learning System, Emotion Engine, Language Generation, World Model Runtime, Simulation, raw model/provider output, Decision result, Action command, permission, State handle, Reducer command, and State mutation are outside this layer.

## Negative guards

- Compression != Data Compression.
- Compression != Embedding Replacement.
- Compression != Memory.
- Compression != Knowledge Storage.
- Compression != Fact.
- Representation != Natural Language.
- Representation != Knowledge.
- Representation != Memory.
- Representation != Rule.
- Decompression != Reality.
- Similarity != Applicability.
- Pattern != Rule.
- Experience != Universal Truth.
- Local Experience != Universal Rule.
- Deep Reasoning != More Compression.
- Deep Reasoning != Higher Intelligence.
- Guidance != Routing Authority.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not memory, not knowledge, not language, not rule, not state mutation, not decision, not action, and not permission.
