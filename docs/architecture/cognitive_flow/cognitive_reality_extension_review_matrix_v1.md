# A-Route Extension Review Matrix v1

| Future question | Primary ownership | A relationship |
|---|---|---|
| How should Luna understand the environment? | A Extension | direct World/Situation enhancement candidate |
| How should Luna understand current capability? | A Extension / Self Model interface | direct Self/Situation enhancement candidate |
| Which role should Luna use to face a problem? | Brain Perspective Management | external context candidate only |
| How should multiple cognitive tasks coexist? | Process Ecology / Assembly | external coordination only |
| How should Luna reflect on life experience? | B Reflection | receives governed Experience Package |
| How should Luna form value and personal meaning? | Emotional Cognition / B | isolated meaning interface |
| How should A and B become a unified state? | future Context Integration | not in scope |

The matrix prevents Role Perspective and multi-A coordination from being mistaken for unfinished A Core functions.
They are higher-level Brain Interaction concerns and must not be implemented through A internals.
