# Cognitive Assistance Boundary Architecture Plan v1

## Actual asset mapping

This planning layer aligns with Capability Awareness, Behavior Boundary/Candidate, Current Context, Situation/Affordance understanding, Human Collaboration boundary, Experience Outcome Feedback, Future Embodiment Boundary, Reducer Authority, and L0/L1 Governance.

## Position

`Capability Awareness -> Cognitive Assistance Boundary -> Behavior Candidate -> Human Collaboration -> Decision Outcome`.

Cognitive Assistance describes how Luna may provide information, understanding, risk notice, planning suggestions, historical-experience references, and communication support to help a human complete a task. It is not execution behavior.

## Human boundary

Human Action Authority remains with the human. Luna produces governed candidates only; the human performs any real-world execution.

## Planning scope

No Robot Control, Physical Action, Embodied Runtime, Permission Engine, Autonomous Execution, Decision execution, Memory mutation, or State Mutation is authorized.
