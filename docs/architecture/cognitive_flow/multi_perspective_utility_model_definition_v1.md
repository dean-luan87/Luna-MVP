# Multi-Perspective Utility Model Definition v1

Multi-Perspective Utility Evaluation Candidate consumes Future Branch, Context, Goal, Survival/Mission constraints, Resource Budget, Risk, Reversibility, Time, perspective references, provenance, and trace.

It outputs Utility Candidate dimensions only, remaining candidate-only, non-Fact, non-State-mutation, non-Decision, non-Action, non-Permission, and non-Memory.
