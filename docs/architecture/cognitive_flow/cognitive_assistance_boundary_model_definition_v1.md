# Cognitive Assistance Boundary Model Definition v1

`CognitiveAssistanceCandidateV1` may retain assistance type, capability/limitation, context, situation/affordance, behavior-boundary, risk, information, option, experience, human-collaboration, uncertainty, provenance, and trace references.

It may describe Observation, Understanding, Risk, Planning, Memory/Experience, or Communication assistance candidates. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, `not_control=true`, `not_autonomous_execution=true`, and `not_memory=true`.
