# Current Cognitive Context Attention Alignment v1

## Flow

`Survival -> Context Formation Candidate -> Attention Priority Candidate -> Field Observation Selection Candidate`

Context supplies current task, uncertainty, survival, Field, and information-gap references that a future Attention Candidate can consider. Attention allocates cognitive focus; Context does not become Attention Authority.

## Boundary

Attention cannot rewrite Context. Context cannot create an Action, Decision, Permission, Fact, or State mutation. Both remain candidate-oriented and independently traceable under L1 governance.
