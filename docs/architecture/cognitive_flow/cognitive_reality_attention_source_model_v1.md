# A-Route Attention Source Model v1

## Source classes

| Source | Candidate trigger | Priority posture | Boundary |
|---|---|---|---|
| Survival Attention | survival constraint, possible hazard, obstacle, or material environment change | highest constitutional consideration | no safety verdict or Action |
| Goal Attention | Goal Context and information required for its current interpretation | goal-bounded | no Goal creation or Decision |
| Temporal Attention | new, accelerating, recurring, or abrupt temporal change candidate | change-sensitive | no prediction or frequency change |
| Self Attention | Self Capability, resource, health, or limitation context | self-situated | no Self Model or hardware control |
| Social Attention Interface | future Perspective Context / relationship reference | optional and lower-order than Constitution | no relationship graph or Role System |

## Source arbitration input

All source outputs enter a common Attention Candidate Pool with provenance,
uncertainty, constitutional boundary references, and resource-cost candidates.
No source creates an active allocation, Provider request, Decision, or Action.

## Social placeholder

Social Attention is an interface only. It may reference the existing
`Perspective Context Candidate`, but does not implement Emotion, social roles,
relationships, personality, or value-system growth.
