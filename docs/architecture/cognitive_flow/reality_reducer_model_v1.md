# Reality Reducer Model v1

## Authority

The Reality Reducer remains the sole State mutation authority for Persistent Reality State,
Self State, Temporal State, Entity State, Relation State, and Attention Observation State projections.

## Reconciliation

Reducer review considers source authority, provenance, timestamp, confidence,
uncertainty, freshness, validity, conflict, withdrawal, and Unknown. Latest
evidence is not automatically correct. Latest evidence is not automatically correct. A contradictory or low-quality candidate
may remain conflicted, expire, or be rejected.

## Boundary

The Reducer maintains state only. It cannot infer a Situation, produce a
Decision, plan, predict an outcome, interpret value, or execute an Action. It
cannot bypass Evidence Validation or suppress Unknown.
