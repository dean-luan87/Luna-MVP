# Future Branch Governance Model Definition v1

Future Branch Governance Candidate may retain branch references, Bounded Future Space candidate, value/budget/lifecycle/pruning/preservation references, Survival/Mission/Goal/Context/Attention/Experience references, uncertainty, provenance, and trace.

All outputs are `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
