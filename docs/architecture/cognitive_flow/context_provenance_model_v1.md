# Context Provenance Model v1

## Required trace

Every Reality Context Package and each projected field retains:

- source;
- Evidence reference;
- Reality State reference;
- timestamp and validity window;
- confidence and uncertainty;
- projection scope;
- transform trace;
- conflict or withdrawal reference when applicable.

## Meaning preservation

Projection may rename or group fields for a stable interface, but it cannot
change fact meaning, confidence semantics, uncertainty, or source. Provenance is
not an interpretation layer and does not authorize a Decision.

## Boundary

Raw model output remains behind Capability Governance and Reality Workspace. A
Context Package is an auditable read model for A Route, not a new fact source and
not a Situation Engine.
