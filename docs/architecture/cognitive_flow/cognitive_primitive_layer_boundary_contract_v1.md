# Luna Cognitive Primitive Layer Boundary Contract v1

## Candidate Lifecycle

```text
External Evidence
        ↓
Translation
        ↓
Cognitive Primitive Candidate
        ↓
Review / Validation (future)
        ↓
Future Admission (separate owner)
```

Candidate is a lifecycle and authority state, not a claim that the represented thing is unreal. It has no real-world truth status and cannot become Fact by presence, confidence, repetition, or consumer use.

## Field Kernel Boundary

Primitive Layer expresses **what might be represented**. Field Kernel organizes **the currently governed world representation**. Reducer alone mutates Field State.

Primitive Layer must not:

- modify Field State;
- write a Field Snapshot or Current Cognitive Context;
- create Fact or admitted Event;
- invoke, replace, or bypass the Reducer, Read Model, Event Admission, or Temporal Validity;
- create a Decision, Action, Memory, or Learning admission.

## Translation and Provider Boundary

Primitive input is abstract Evidence/Context Reference and frozen Translation candidate output only. External model/provider schemas, raw payloads, provider identities, and real Evidence binding remain outside this layer. Provider identity is provenance only; it cannot define Luna's internal Entity or Primitive taxonomy.

## L1 Alignment

The layer references existing Input/Output Candidate, Traceability, Permission/Admission, Model/Skill Admission, and Runtime Boundary governance. It creates no parallel admission, permission, registry, or protocol system. `runtime_authorized=false` remains unchanged.
