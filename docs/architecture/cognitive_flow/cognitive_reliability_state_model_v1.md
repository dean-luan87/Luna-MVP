# Cognitive Reliability State Model v1

Cognitive Reliability State Candidate describes Luna’s current self-assessed reliability limits for a particular understanding process, based on evidence coverage, capability limitation, uncertainty, contradiction, and recent correction references.

Example: current localization understanding may be medium reliability because evidence is limited and possible position error remains.

Reliability != Truth, Fact Confidence, Reality Probability, Decision, or Action. It is a self-constraint candidate, not an evaluation override.
