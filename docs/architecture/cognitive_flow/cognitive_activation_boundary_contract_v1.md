# Cognitive Activation Boundary Contract v1

- Activation != Attention Selection.
- Activation != Memory Retrieval.
- Activation != Storage.
- Activation != Experience.
- Activation != Rule Engine.
- Activation != Scheduler.
- Activation != Decision.
- Activation != Action.
- Activation != Permission.
- Activation != Reality State Mutation.
- Retention != Activation.
- Attention != Retention.
- Experience != Authority.
- Risk != Automatic Action.
- Time != Decision.
- Future Module != Activation Authority.
- Reducer remains the only State Mutation Authority.

Emotion may offer Activation Preference Candidate; World Model may offer Future Context Activation Candidate; Hive may offer Shared Representation Candidate; Language may offer Human Explanation Interface; Embodiment remains disabled. Each is candidate-only and must pass local context/validity/resource evaluation.

Activation Outcome may form Usage Feedback and Experience Evaluation Candidates, but cannot directly modify Representation, Culture, Gene Pool, Genome, Constitution, or State.
