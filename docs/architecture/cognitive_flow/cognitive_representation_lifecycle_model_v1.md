# Cognitive Representation Lifecycle Model v1

`Candidate -> Context Validation -> Usage Candidate -> Feedback Candidate -> Strengthen / Weaken Candidate -> Evolution Candidate`.

Repeated validation may support Stable Representation or Cognitive Primitive candidates; it never turns a local pattern into an automatic rule. Weakening preserves provenance, exception, and applicability decline. Evolution remains governed and separate from Runtime, Memory mutation, Constitution, Genome, Culture, Gene Pool, Decision, Action, and State mutation.
