# Cognitive Architecture Drift Monitoring v1

Future governance should monitor candidate drift conditions:

- Experience becoming Rule;
- Culture becoming Truth;
- Gene Pool becoming Authority;
- Optimization becoming Decision;
- Prediction becoming Reality;
- Emotion overriding Reality or Candidate boundaries;
- Hive centralizing or overriding Local Context;
- Compression becoming Knowledge Truth;
- Routing becoming Runtime/Decision authority.

Drift Monitoring produces only review candidates. It does not automatically block, rewrite, mutate, learn, decide, act, or change State.
