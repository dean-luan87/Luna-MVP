# A-Route End-to-End Metrics v1

| Metric | Required observation | Not measured |
|---|---|---|
| Loop Integrity | every required stage is present and linked in the complete trace | task completion rate |
| Trace Completeness | input, cognitive, decision, outcome, and experience references remain visible | chain-of-thought detail |
| Reality Alignment | Evidence, World, Situation, and current Unknown boundaries are preserved | real-world truth accuracy |
| Self Alignment | capability and resource context participates without identity collapse | personality quality |
| Decision Quality | Situation, options, evaluation dimensions, risk, and confidence are traceable | optimal action |
| Experience Quality | Situation, Decision, Outcome, Cause, Adaptation, Confidence, and Unknown factors are handoff-ready | automatic learning value |

These metrics are candidate-trace observability checks. They are not rewards,
system health verdicts, model benchmarks, an Experience Adoption gate, or an
authorization to execute an Action.
