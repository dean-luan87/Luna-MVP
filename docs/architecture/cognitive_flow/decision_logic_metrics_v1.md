# A-Route Decision Logic Metrics v1

| Metric | Required trace observation | Not measured |
|---|---|---|
| Situation Dependency | Decision evaluation references a Situation Candidate rather than one Evidence item | action correctness |
| Self Awareness | Self Capability and limitation participate in option evaluation | identity quality |
| Option Diversity | a constrained situation exposes materially different option candidates | number of all imaginable options |
| Risk Awareness | risk and Survival Impact remain visible beside Goal Alignment | absolute safety |
| Uncertainty Handling | Unknown, information cost, and confidence shape evaluation | factual prediction accuracy |
| Decision Stability | unchanged deterministic context retains an equivalent candidate structure | immutable decision policy |
| Decision Adaptability | material new Evidence can produce a reconsideration trace | execution success |

Metrics are contract-observability checks. They are not reward scores,
optimization objectives, model benchmarks, online-learning signals, or
authorization to execute an Action.
