# Minimum Safe Understanding Model v1

## Definition

Minimum Safe Understanding differs from a Minimum World Description and from unconstrained information maximization. It is the smallest sufficient, explicitly uncertain, traceable set of constraints needed to support a current safe behavior boundary candidate and continued bounded exploration.

## Required candidate dimensions

- current Field and context reference;
- known, partially-known, and unknown conditions;
- observable and behavior constraint references;
- allowed and forbidden behavior candidates;
- risk and exploration boundaries;
- information gaps, uncertainty, provenance, and trace.

These dimensions align with Minimum Sufficient Field Understanding and do not create a parallel Field model.

## Adaptation model

An unknown environment can remain `unknown_but_safe` or `partially_understood` when constraints are sufficient for a limited behavior boundary. Identity expansion is incremental and future-governed; it is never the output of a confidence threshold, neighbor relationship, or model prediction alone.

## Non-goals

This model does not implement automatic risk assessment, environmental inference, behavior planning, action selection, learning, Memory, Hive integration, or Capability mutation.
