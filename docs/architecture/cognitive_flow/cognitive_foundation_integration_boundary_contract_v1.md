# Cognitive Foundation Integration Boundary Contract v1

## Candidate and reality contract

- Perception, representation, schema, simulation, operation, evaluation, feedback, and evolution outputs are candidates.
- Simulation != Reality.
- Hypothesis != Fact.
- Confidence != Truth.
- Candidate != Decision.
- Candidate != Action.
- Candidate != Permission.

## Experience and evolution contract

- Experience != Rule.
- Experience != Reality Override.
- Feedback != Automatic System Mutation.
- Feedback != Genome Mutation.
- Feedback != Culture Mutation.
- Improvement Candidate != Adoption.
- Adoption Candidate != Rewrite.

## Schema and routing contract

- Schema != Truth.
- Schema != Action.
- Schema Match != Reality Confirmation.
- B Interface != B Route Execution.
- Route B remains frozen for this phase.

## Runtime and state contract

- Cognitive Runtime Environment != Reality State.
- Runtime != Reducer.
- Reducer remains the only State Mutation Authority.
- Cognitive modules do not mutate Field State, Memory, Genome, Culture, or external state.

Any breach is a boundary regression finding, not an authority grant.
