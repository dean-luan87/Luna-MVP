# Cognitive Candidate Authority Boundary v1

All Cognitive Foundation modules are candidate-only. Their outputs may express understanding, hypothesis, evaluation, suggestion, option, or commitment candidates.

They may not create command authority, decision authority, action permission, direct decision execution, direct action execution, or State Mutation. Reducer remains the only State Mutation Authority.

Candidate is not Adoption, Evaluation is not Decision, Suggestion is not Permission, and Decision Candidate is not Decision.
