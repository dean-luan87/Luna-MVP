# Cognitive Field Dynamics Model v1

## Definition

Field Dynamics Candidate describes a current interpretation that the Field may be changing in ways relevant to cognition. It is not a real-time metric, Event Fact, State update, or prediction result.

Candidate dimensions may include spatial change, object/entity change, population change, risk change, task/context change, uncertainty, provenance, and trace. `Field Change Rate` is a candidate description of how rapidly relevant Field conditions appear to be changing, not a fixed numeric clock value or authority.

## Use

Low apparent dynamics can support a broader Cognitive Time Budget Candidate. High or uncertain risk dynamics can support compressed, interruptible cognition candidates. Neither conclusion proves the Field changed or triggers an Action.
