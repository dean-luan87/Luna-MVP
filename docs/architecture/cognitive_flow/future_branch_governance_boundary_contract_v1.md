# Future Branch Governance Boundary Contract v1

Allowed inputs are governed references to Possible Future Space, Branch Evolution, Hypothesis, Belief, Attention, Information Value, Strategy, Cognitive Constraint, Survival, Mission, Context, Experience/Learning Candidate, provenance, and trace.

Forbidden inputs include raw model output, provider payload, Fact Store, State handle, Reducer command, Decision result, Action command, Permission grant, Memory, Learning execution, or Hive authority.

Negative guards:

- Future Branch Value != Truth.
- Probability != Decision.
- Branch Weight != Authority.
- Branch Governance != Action.
- Pruning != Reality Confirmation.
- Experience != Future Authority.
- Mission != Survival Override.
- Reducer != Future Branch Manager.
- Future Branch Governance != State Mutation.
- Reducer remains the only State Mutation Authority.
