# Cognitive Attention Candidate Aggregation Model v1

Distributed sources may propose Attention Candidates: Perception, Context, Active Goal, Risk, Experience, Unknown, Sufficiency, Resource, and future Emotion.

```text
Distributed Attention Candidates -> Attention Candidate Pool
  -> consistency / conflict checks -> Active Cognitive Allocation Candidate
```

Aggregation preserves source, reason, context, confidence candidate, uncertainty, requested budget/depth/duration/direction, provenance, and trace. Candidate aggregation != source authority, voting truth, or resource allocation execution.
