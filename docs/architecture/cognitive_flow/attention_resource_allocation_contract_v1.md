# Attention Resource Allocation Contract v1

## Contract

```text
Attention Requirement
  ↓
Information Value
  ↓
Attention Cost
  ↓
Allocation Candidate
  ↓
Neural / Middleware Governance
```

Attention allocation considers Intent Relevance, Survival Impact, Temporal
Urgency, Uncertainty, Information Value, and Resource Cost. It returns a
candidate allocation, not a Decision or Action.

## Competing demands

When multiple processes request attention, the contract preserves each intent
reference, scope, expected value, cost, priority candidate, and unmet demand.
Compression or deferral does not imply that an unobserved object does not exist.
Neural may regulate response intensity; Middleware may report capability limits;
Brain retains final judgment.
