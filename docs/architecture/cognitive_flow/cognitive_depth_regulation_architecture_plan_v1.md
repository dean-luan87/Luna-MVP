# Cognitive Depth Regulation Architecture Plan v1

Cognitive Depth Regulation is a Cognitive Flow resource-scheduling layer. It determines the appropriate candidate cognitive investment, reasoning expansion boundary, and observation-demand depth for a current situation.

`Survival Constraint + Current Context + Attention Candidate + Information Value + Experience/Library Pattern Reference -> Cognitive Depth Regulation Candidate -> Cognitive Strategy Candidate -> Hypothesis / Behavior Candidate`

It is not a Decision Engine, Reasoning Engine, Planner, Action controller, Permission system, or State authority. Cognitive Depth is not Intelligence: a mature pattern can require less expansion, while unfamiliar/high-value uncertainty can require more.
