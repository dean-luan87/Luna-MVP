# Cognitive Process Template Model v1

A Process Template is a validated reusable pattern candidate, not a process engine instruction.

Suggested contract fields: `template_id`, `source_experience`, `activation_condition`, `process_type`, `required_capability`, `resource_profile`, `validation_history`, `version`, uncertainty, trace, and adoption state.

Templates must be admitted by future governance. They cannot execute directly, create a Goal, bypass CWO, choose a Provider, or change a State.
