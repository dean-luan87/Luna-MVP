# Cognitive Temporal Activation Model v1

Time may alter cognitive preparation priority when a context-bound time window approaches. For example, a Flight Representation may be low activation in the morning and higher activation near a departure window.

Temporal Activation Candidate must include time boundary, task relevance, current context, expected value, and resource cost. It may request increased readiness or validation; it cannot decide, act, grant permission, or prove an event will occur.

Time != Decision. Temporal urgency != Action Authority.
