# Cognitive Virtual Environment Model v1

## Cognitive VM components

- Runtime Instance Candidate — one isolated cognition-run reference.
- Cognitive Snapshot Candidate — shared context-bound input view.
- Cognitive Process Candidate — a bounded understanding/evaluation task.
- Branch Candidate Set — multiple possible-world candidates.
- Resource Boundary Candidate — compute, memory, time, and branch budgets.
- Replay Trace Candidate — diagnostic reconstruction reference.

The virtual environment may contain temporary hypotheses and incorrect reasoning. None is reality, Field State, Reducer State, Memory State, Experience State, Decision, Action, or Permission.
