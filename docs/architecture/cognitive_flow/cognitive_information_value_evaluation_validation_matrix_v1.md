# Cognitive Information Value Evaluation Validation Matrix v1

| Future DryRun case | Required value-evaluation concern | Forbidden result |
| --- | --- | --- |
| Low Cost High Value Information | high potential uncertainty reduction with bounded cost | automatic acquisition |
| High Cost Low Value Information | visible cost and limited relevance | forced ignore or action |
| High Risk Unknown | survival/risk relevance remains visible | risk becomes Fact or permission |
| Safe Unknown | uncertainty can remain accepted | unknown treated as failure |
| Exploration Opportunity | opportunity/cost tradeoff remains candidate-only | exploration permission |
| Task Deadline | time cost and goal relevance remain explicit | deadline becomes decision command |

Any later authorized DryRun must compare run1/run2 canonical JSON for equality. No evaluator or Runtime is created here.
