# Cognitive Evidence Admission Model v1

Evidence admission determines whether an externally sourced Evidence Candidate is structurally eligible to enter the Cognitive Information Field. It does not determine whether its content is true.

```text
External Evidence Candidate
  -> Source / Context / Provenance / Uncertainty Check
  -> Evidence Admission Candidate
  -> Cognitive Information Field Candidate
```

Admission checks source identity, temporal/spatial/context applicability, provenance presence, confidence representation, contradiction visibility, and permission flags. Admission != Fact Admission, Reality Confirmation, Decision, Action, or State mutation.
