# Temporal Representation Model v1

## Core purpose

Temporal Representation is a compact candidate description of how the current
represented reality differs from an earlier governed reference. It answers
“what changed relative to before?” rather than storing every time slice.

```text
Temporal Representation Candidate
├── Current State Reference
├── Previous Reference
├── Change Delta Candidate
├── Transition Pattern Candidate
├── Stability Candidate
├── Trend Candidate
├── Confidence Candidate
├── Temporal Uncertainty
└── trace_ref
```

| Field | Meaning | Prohibited interpretation |
|---|---|---|
| Current State Reference | current represented state link | complete historical record |
| Previous Reference | minimum governed comparison reference | unverified memory fact |
| Change Delta Candidate | material difference candidate | causal conclusion |
| Transition Pattern Candidate | stable, gradual, abrupt, cyclic, recovering, or unknown | future fact |
| Stability Candidate | current stability interpretation | guarantee that nothing will change |
| Trend Candidate | direction candidate from available evidence | prediction truth |
| Confidence Candidate | support quality for the representation | fact confidence |
| Temporal Uncertainty | missing coverage, interval, cause, or continuity | permission to invent data |

## Governing rules

- Continuous Observation != Temporal Memory.
- Change is preferred over raw time points: insignificant jitter may remain
  transient rather than becoming a retained representation.
- Trend Candidate != Future Fact. Future continuation remains candidate-only.
- Temporal Representation does not replace Reality Representation or modify
  World State.
