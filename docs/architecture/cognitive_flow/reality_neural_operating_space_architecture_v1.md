# Reality Neural Operating Space Architecture v1

## Definition

Reality Neural Operating Space is a persistent, structured, traceable fact
environment for Cognitive Rule Layer. It answers only: **what is the current
state of the world and Luna?**

```text
Models / Sensors / Hardware
          ↓
       Evidence
          ↓
   Evidence Memory Buffer
          ↓
   Reality Assembly / Alignment
          ↓
     Reality Reducer
          ↓
Persistent Reality State
 ┌────────┬────────┬────────┬───────────┐
 ↓        ↓        ↓        ↓
Reality  Self   Temporal  Entity/Relation
State    State  State     State
          ↓
Attention Observation State
          ↓
       A Route
          ↓
        Brain
```

## Responsibility boundary

The operating space maintains Reality Representation, Reality State, Self State,
Temporal State, Entity State, Relation State, Observation State, Evidence
Provenance, Validity, Conflict, and Unknown. It does not answer what should be
done, which choice is best, what an outcome means, or whether a state is valuable.

Prediction Layer, Outcome Prediction, Decision Loop, Planning, Reasoning,
Evaluation, and Experience belong to the Cognitive Rule Layer (A Route + Brain),
not to the operating space.

## Persistent world representation

The space continuously maintains vehicles, people, doors, locations, events,
relations, changes, resources, and self conditions without reinterpreting the
whole world from every frame. A new candidate may update or conflict with a
prior state, but it does not acquire Goal or Decision authority.

## Runtime concept boundary

This phase defines a Reality State Runtime Concept only. It does not implement a
Runtime, Scheduler, model call, sensor loop, hardware control, or state mutation.
