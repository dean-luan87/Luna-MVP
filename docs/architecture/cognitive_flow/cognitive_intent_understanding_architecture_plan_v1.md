# Cognitive Intent Understanding Architecture Plan v1

## Actual asset mapping

This A-route planning layer aligns with Language/Observation Input boundaries, Goal Understanding, Current Cognitive Context, Situation Understanding, Affordance Understanding, Capability Awareness, Behavior Boundary, Cognitive Assistance Boundary, Emotion Engine Future Boundary, Reducer Authority, and L0/L1 Governance.

## Position

`Language / Observation Input -> Intent Understanding Candidate -> Goal Understanding Candidate -> Current Context -> Situation Understanding -> Affordance -> Capability Awareness -> Behavior Boundary`.

Intent describes why a Goal may be needed. It is not a Goal, Decision, Action, Command, Emotion, Personality, Identity, or social relationship model.

## Planning scope

No Emotion Engine, Personality, Social Relationship, Decision Runtime, Action Execution, Memory Mutation, or State Mutation is authorized.
