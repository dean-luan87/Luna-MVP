# Brain Perspective Context Contract v1

## Purpose

Perspective Context is an optional Brain-provided candidate interface for
future Emotional Cognition, relationship, and role systems. It represents how
meaning, responsibility, and care may weight a reality-bound choice without
changing represented reality.

```text
Perspective Context
├── Perspective Source
├── Role Reference
├── Relationship Reference
├── Emotional Weight Candidate
├── Responsibility Weight Candidate
├── Attention Bias Candidate
├── Decision Preference Candidate
└── Boundary Constraint
```

## Contract rules

- Every field is candidate-labelled, traceable, and optionally absent.
- `Perspective Source` identifies the future authorized source; it is not a
  truth/decision authority.
- Weights are evaluation inputs, never outcome facts or Action commands.
- Boundary Constraint must preserve Survival Constitution, safety,
  non-harm, self continuity, and human authority/consent.

Perspective Context is not a Role System, relationship network, emotion model,
personality model, or self update mechanism.
