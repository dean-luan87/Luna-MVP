# Cognitive Counterfactual Boundary Contract v1

## Allowed candidate references

Governed Causal Candidates, Field/Context, Hypothesis, Belief, Future Space/Branch, Optimization, Experience, Knowledge, Survival/risk, provenance, and trace references may be read.

## Rejected inputs and effects

Simulation Engine, World Model Runtime, raw model/provider output, Fact Store authority, Decision result, Action command, permission, State handle, Reducer command, Memory mutation, Learning runtime, and Hive authority are outside this layer.

## Negative guards

- Counterfactual != Causality.
- Counterfactual != Fact.
- Counterfactual != Prediction.
- Counterfactual != Decision.
- Counterfactual != Action.
- Simulation != Reality.
- Possible World != Future Truth.
- Probability != Truth.
- Experience != Rule.
- Experience != Current Result.
- Knowledge != Current Reality.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not prediction, not simulation, not state mutation, not decision, not action, not permission, and not memory.
