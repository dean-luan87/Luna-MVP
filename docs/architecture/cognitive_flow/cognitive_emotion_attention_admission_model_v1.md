# Cognitive Emotion Attention Admission Model v1

Future emotion/relationship signals may produce Emotion Attention Candidates only after source, context, uncertainty, risk/time/resource consistency, provenance, trace, and non-authority checks.

```text
Emotion Signal -> Emotion Attention Candidate -> Candidate Pool -> Controller
```

The candidate may request relationship salience; the Controller can reduce/defer it when urgent navigation or safety context dominates. Emotion Attention Admission != Emotion Engine implementation, override, Decision, Action, Permission, or State mutation.
