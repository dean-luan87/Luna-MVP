# Cognitive Activation Priority Model v1

## Priority inputs

1. Task Importance Candidate
2. Risk Impact Candidate
3. Time Urgency Candidate
4. Field Relevance Candidate
5. Experience Match Candidate
6. Information Value Candidate
7. Resource Cost Candidate

Priority is a candidate explanation for limited resource allocation, not an answer ranking, Decision, Action, or authority grant.

Frequently Used != Important. Popular != Valuable. More Activation != Better Cognition.
