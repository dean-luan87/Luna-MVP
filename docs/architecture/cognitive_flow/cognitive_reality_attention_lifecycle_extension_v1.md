# A-Route Attention Lifecycle Extension v1

## Lifecycle

```text
Attention Candidate
        ↓
Activated Candidate
        ↓
Maintained Candidate
        ↓
Reduced Candidate
        ↓
Released Candidate
```

| Phase | Meaning | Not implied |
|---|---|---|
| Candidate | relevance is proposed | actual allocation |
| Activated Candidate | bounded consideration is admitted | runtime process start |
| Maintained Candidate | relevance persists while conditions remain | permanence or fact |
| Reduced Candidate | relevance or budget candidate decreases | absence or safety |
| Released Candidate | current consideration ends | deletion of Reality or historical evidence |

This extension maps to the existing Attention Lifecycle State Model without
changing it. Lifecycle is a candidate description, not persistent State, Memory, a task queue, Scheduler, or Action mechanism.
