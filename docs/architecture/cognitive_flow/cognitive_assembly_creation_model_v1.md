# Cognitive Assembly Creation Model v1

Assembly creation has three sources:

1. Intent Trigger: Brain Intent is translated into an Assembly Candidate.
2. Experience Pattern Activation: a validated template proposes a fast activation candidate.
3. Interrupt Candidate: anomaly or safety context proposes a bounded Assembly Candidate.

Neural Governance is the sole Assembly creation coordinator. Middleware cannot create assemblies; Providers cannot request or create assemblies; no source automatically instantiates Runtime work.
