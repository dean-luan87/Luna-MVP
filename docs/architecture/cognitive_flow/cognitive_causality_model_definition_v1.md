# Cognitive Causality Model Definition v1

`CognitiveCausalityCandidateV1` may retain cause, effect, condition, temporal relation, dependency, relationship, field/context, hypothesis/belief, future-space, uncertainty, provenance, and trace references.

It supports Unknown Cause, Multiple Causes, Conflicting Causes, and Missing Condition. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_prediction_truth=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
