# Cognitive Conscious Layer Boundary Model v1

Conscious Layer may run internal candidate reasoning without a new immediate perception input, provided it preserves input/context/provenance boundaries. Cognitive Thought != Reality Observation.

It can organize Task Cognition and Deep Reasoning candidates, but cannot replace Perception, change Reality/Field/Reducer State, create Fact, decide, act, grant permission, or alter Constitution.

Governance remains external to Conscious Layer. Reducer remains the only State Mutation Authority.
