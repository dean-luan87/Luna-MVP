# Cognitive Hypothesis Validation Boundary Contract v1

Hypothesis != Fact/State/Decision/Action. Validation != Observation Execution. Evidence != Truth. Confidence != Authority. Experience != Automatic Confirmation. Experience/Library can provide historical pattern priors only; past pattern never replaces local current evidence.

All future validation outputs remain candidate-only, non-Fact, non-State, non-Decision, non-Action, and non-Memory.
