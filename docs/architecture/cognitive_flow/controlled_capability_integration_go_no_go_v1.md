# Controlled Capability Integration Go/No-Go v1

## Required checks

- Capability Isolation: Capability ≠ Understanding, Decision, Reality, Brain.
- Evidence Integrity: Provider Output is validated as an Evidence Candidate.
- Provider Replaceability: Provider substitution leaves A Route structure unchanged.
- Cognitive Independence: providers do not own Goal, Situation, Decision, or Brain authority.
- Failure Traceability: unavailable, low-quality, and protocol-error cases are localized.
- Self Capability feedback is candidate-only and does not directly mutate State.

## Hard prohibitions

No real model, No real OCR, no Provider execution, no Runtime, no Hardware access,
no automatic learning, and no automatic State mutation. No provider output may
bypass the Evidence Gateway into Reality Cognition or Brain.

## Terminal verification handoff

The agent performs only static planning and V0 checks. The user must run the
phase verifier in a terminal. After the command completes, the phase pauses at
`WAITING_FOR_USER_TERMINAL_VERIFICATION` for the V3 audit.

Target output: `COGNITIVE_CAPABILITY_GOVERNANCE_CONTROLLED_INTEGRATION_READY_WITH_NOTES`.
