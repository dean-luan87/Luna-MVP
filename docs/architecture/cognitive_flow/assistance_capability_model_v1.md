# Assistance Capability Model v1

Assistance capability candidates may include:

- Observation Assistance: candidate information discovery or attention support;
- Understanding Assistance: candidate environment/situation explanation;
- Risk Assistance: candidate risk visibility;
- Planning Assistance: candidate option and trade-off explanation;
- Memory Assistance: governed historical experience reference;
- Communication Assistance: candidate human/environment communication support.

Cognitive Capability is not Physical Capability. Information Support is not Action Execution, control, permission, or autonomous behavior.
