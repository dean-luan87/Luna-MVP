# Cognitive Assembly Whitebox Architecture v1

The future Whitebox is read-only and displays:

```text
Brain Intent
  ↓
Assembly Creation Candidate
  ↓
Active / Background / Safety Assembly Candidates
  ↓
Capability Binding Candidates
  ↓
Feedback Candidates
  ↓
Release / Template Candidates
```

It exposes identity, origin, lifecycle candidate, process references, resource-profile candidate, capability requirements, uncertainty, and boundary flags. It does not control assembly creation, activation, release, or template adoption.
