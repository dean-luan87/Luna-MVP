# Reflective Resource Budget Model v1

## Purpose

Reflective Cognition is open-ended, while actual cognitive, computational,
information, and embodiment resources are finite. The Reflective Resource
Budget governs whether reflection is admitted, which question is worth depth,
and when reflection must defer.

| Budget input | Candidate governance question |
|---|---|
| Survival / Situation relevance | Is reflection materially relevant to safe or meaningful continuity? |
| Value feedback significance | Did the outcome expose a meaningful gap, repeated friction, or opportunity? |
| Uncertainty and novelty | Is there a candidate information gain sufficient to justify depth? |
| Current resource envelope | Is reflective effort compatible with A's current reality needs? |
| Constitutional boundary | Is the question legitimate, non-harmful, and non-manipulative? |

The result is a `Reflective Resource Budget Candidate` with depth, duration,
priority, defer/close candidate, and trace reference. It is not a Scheduler,
resource allocation mutation, background Runtime, or permission to preempt A.
