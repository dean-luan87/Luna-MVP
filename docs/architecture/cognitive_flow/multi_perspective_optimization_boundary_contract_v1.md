# Multi-Perspective Optimization Boundary Contract v1

Allowed inputs are governed Future Space/Branch Governance, Context, Role Candidate, Goal, Survival, Mission, Resource Budget, Risk/Reversibility, Time, Attention, Information Value, Experience, provenance, and trace.

Negative guards:

- Mathematical Optimum != Cognitive Optimum.
- Multi-Perspective Optimization != Decision.
- Utility != Permission.
- Highest Utility != Mandatory Action.
- Optimization != Truth.
- Future Branch Value != Future Truth.
- Branch Weight != Selection Authority.
- Experience != Optimization Authority.
- Role != Personality.
- Reducer != Optimization Authority.
- Optimization != State Mutation.
- Reducer remains the only State Mutation Authority.
