# Cognitive Observation Attention Selection Architecture v1

Attention Selection Candidate is the cognitive resource ordering layer between Context-Driven Observation Need Candidates and future cognitive processing. It ranks what warrants further attention under limited observation, time, and computation.

It is not a Decision Layer, Action Layer, Permission Layer, observation executor, model attention mechanism, or authority source. It produces no Fact, Field State, Decision, Action, Memory, or permission grant.

`Current Context + Observation Need + Survival Constraint + Goal + Field + Information Gap -> Attention Selection Candidate -> Future Cognitive Processing`
