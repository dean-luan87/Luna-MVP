# Cognitive Background Cognition Boundary v1

Background Cognition Candidate may arise from retained Experience, Unknowns, long-term Goal candidates, or unresolved questions. It receives only bounded low-priority allocation through Attention Governance and Resource Modulation.

Background Cognition cannot seize all resources, execute sensing, invoke a model, create a Decision/Action, write Memory, learn automatically, or mutate State. It may become active only through a future attention lifecycle/admission candidate.
