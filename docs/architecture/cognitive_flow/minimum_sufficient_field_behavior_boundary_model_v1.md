# Minimum Sufficient Field Behavior Boundary Model v1

Behavior Boundary answers “what can Luna safely attempt or avoid now?” Field Identity answers “what kind of Field is this?” They are distinct. Behavior Boundary can exist while Identity is unknown.

`Field Identity -> Field Affordance -> Behavior Boundary -> Action Candidate`.

Action Candidate is future and must be constrained by Behavior Boundary plus separate permission/governance. Affordance and Behavior Boundary are possibility/constraint descriptions, not permission grants.
