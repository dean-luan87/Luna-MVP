# Attention Alignment / Neural Regulation Boundary v1

```text
Attention Demand Candidate
        ↓
Neural Resource Evaluation Candidate
        ↓
Allowed Attention Allocation Candidate
```

Attention proposes direction and bounded information value. Neural Regulation
and resource governance evaluate whether the system may support it under
current constraints. Attention can then form a constrained/reduced candidate;
it cannot allocate actual resources or modify frequency.

This phase handles one cognitive objective only. Multi-A coordination,
multi-role attention, long-lived multi-task arbitration, and Assembly ecology
remain out of scope.
