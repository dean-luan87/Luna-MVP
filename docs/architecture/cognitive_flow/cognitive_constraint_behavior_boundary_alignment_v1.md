# Cognitive Constraint Behavior Boundary Alignment v1

## Adjustment relation

Cognitive Constraint contributes an evidence-bearing adjustment input to a Behavior Boundary Candidate. It can narrow, preserve, or make explicit the evidence requirements of a behavior space; it cannot independently authorize, deny, select, or execute a behavior.

Example: an unknown device can remain observable while operation stays outside the current behavior space. The constraint expresses risk, missing evidence, and resource conditions. Behavior Boundary remains the separate layer that represents allowed, restricted, and unknown behavior candidates.

## Preserved hierarchy

`Cognitive Constraint Candidate -> Behavior Boundary Candidate -> Future Behavior Candidate` keeps constraint, candidate generation, future Decision, and Action distinct. No relation grants Permission or alters Field, Context, Field State, Snapshot, Memory, or history.
