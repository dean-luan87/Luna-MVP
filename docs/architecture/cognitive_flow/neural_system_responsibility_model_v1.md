# Neural System Responsibility Model v1

## Responsibilities

Neural System is an automatic regulation layer, not a model and not a second
Brain. It may perform high-frequency state refresh, attention maintenance,
resource allocation candidate generation, anomaly detection, and lightweight
regulation candidate evaluation.

It reads a governed Reality Workspace projection rather than all raw evidence.
It may update a monitoring projection through the Reducer contract, but it does
not directly mutate State.

## Escalation

Neural detects change, risk, conflict, unknown growth, capability shortfall, and
resource stress. It emits an Escalation Candidate with evidence references,
urgency, confidence, affected scope, and recommended review path. Escalation is a
request for higher-level attention, not a Decision or Action.

## Non-authority boundary

Neural does not own Goal, Intent, Reality Interpretation, Decision Authority,
Action, provider identity, or value judgment. It cannot modify Identity, replace
World State, suppress Unknown, or bypass Brain. Its regulation candidates remain
subject to policy, resource, capability, and Reducer governance.
