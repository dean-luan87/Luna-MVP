# Cognitive Intent Preservation Go/No-Go v1

## V0 static acceptance criteria

1. Intent Contract includes Original Purpose, Non-Negotiable Objective, allowed
   interpretation, forbidden transformation, required evidence, and success
   evaluation.
2. Brain, Neural, Attention, Middleware, Provider, Evidence, and Reality
   Cognition have distinct interpretation boundaries.
3. Requirement Boundary blocks expansion, narrowing, proxy substitution, and
   technical-objective transfer from replacing Original Purpose.
4. Drift Detection defines expansion, narrowing, substitution, transfer, and
   evidence drift as candidate-only findings.
5. Alignment Trace links intent through requirement, evidence, situation, and
   Decision Support to an Alignment Score Candidate.
6. Alignment evaluation measures intent support, not data return, model metric,
   Truth, or cognitive completion.
7. Attention Axis remains an observation-need interface and never interprets
   Reality or executes a request.
8. Middleware/Capability cannot redefine a cognitive objective or declare
   success from local provider output.
9. Controlled drift scenarios are defined without Runtime or stateful behavior.
10. No Goal rewrite, Decision, Action, Provider selection, Scheduler, automatic
    resource allocation, online learning, B Reflection, or State mutation is
    introduced.
