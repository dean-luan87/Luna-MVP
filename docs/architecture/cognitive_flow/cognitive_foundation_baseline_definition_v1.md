# Cognitive Foundation Baseline Definition v1

`Luna Cognitive Foundation Baseline v1` is the proposed registered reference composed of:

- Cognitive Constitution: Reality First, Candidate First, Context Bound, Minimum Sufficient Understanding, Evolution With Validation;
- Cognitive Flow: Observation -> Understanding -> Evaluation -> Candidate -> Decision Support -> Experience -> Evolution;
- A/B Routing: fast minimum-sufficient/pattern candidates and bounded deep-reasoning candidates;
- Experience Evolution: outcome, experience, compression, representation evolution, population/culture/gene-pool candidates;
- Boundary Contracts: Candidate-only, local validation, future extension isolation, and Reducer authority.

The baseline is not Final Intelligence, a fixed runtime architecture, a rules database, a knowledge truth store, or an authority source.

## Integration-validation registration scope

This baseline is extended by the proposed `Cognitive Foundation Integration Validation v1` reference. The reference registers, for V0 planning review only:

- the complete candidate trace from input signal through feedback and future-improvement candidates;
- the module integration matrix for perception, information field, representation, schema, attention, workspace, simulation, operation, evaluation, and feedback;
- fast-loop and slow-loop separation;
- Cognitive Runtime Environment isolation from Reality State and Reducer authority;
- failure-injection and boundary-regression cases; and
- the A/B interface, with Route B frozen and not executed.

Registration does not adopt a candidate, run a runtime, mutate state, change a genome, update culture, or authorize any Decision or Action. It remains a proposed architecture baseline subject to user terminal verification.
