# Current Field View Evolution Model v1

`Current Field View = Reducer-owned Base + Spatio-Temporal Candidate Overlay + Concept/Primitive/Context/Task/Attention/Uncertainty references`.

Base is the existing governed State/Snapshot reference. Overlay expresses only possible/currently unresolved interpretation; it cannot say “already happened,” become State, modify Snapshot, or write History.

Field Evolution is Spatio-Temporal Transformation: `Current Field -> Field Event Candidate -> Possible Transformation -> Future Field Candidate`. Prediction is not Reality or Fact.
