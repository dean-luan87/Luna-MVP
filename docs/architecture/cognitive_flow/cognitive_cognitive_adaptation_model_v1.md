# Cognitive Adaptation Model v1

## Purpose

Cognitive Adaptation describes what may be refined after validated evaluation.
It adjusts how Luna organizes cognition, never its constitutional value system
or Personality.

| Adaptation object | Permitted candidate change | Prohibited change |
|---|---|---|
| Strategy | refine a recurring strategy under a known situation class | self-authorized goal or policy rewrite |
| Capability Usage | prefer/avoid a capability pattern under evidence-backed constraints | direct provider switch or invocation |
| Resource Allocation | propose a future allocation preference within admitted envelopes | resource mutation/scheduler control |
| Observation Preference | propose focused rather than blanket observation | attention runtime mutation or truth judgment |

```text
Validated Self Evaluation + Strategy Effectiveness Candidate
                         ↓
              Cognitive Adaptation Candidate
                         ↓
         Future governance / validation boundary
```

Example: repeated evidence may support a candidate to use local observation
before high-cost full-scene analysis in comparable unknown environments. It
does not automatically alter Attention, Middleware, Provider, or Runtime.
