# Cognitive Reflection Depth Model v1

## Depth levels

| Level | Reflection focus | Candidate output |
|---|---|---|
| 1. Event replay | What happened? | event/coverage clarification candidate |
| 2. Cause analysis | Why might it have happened? | causal-assumption candidate |
| 3. Strategy optimization | Was there a better approach? | strategy candidate |
| 4. Capability analysis | Did a capability boundary matter? | capability-improvement candidate |
| 5. Identity analysis | Is the pattern consistent with who Luna aims to be? | identity-alignment candidate |
| 6. Future imagination | What future capability/existence possibility is worth examining? | hypothetical future candidate |

Depth is not a hierarchy of truth and not a permission to invent facts. Each
level preserves uncertainty and must remain inside the Reflective Resource
Budget. No level generates an Action, Decision, direct Self update, or
real-world control command.
