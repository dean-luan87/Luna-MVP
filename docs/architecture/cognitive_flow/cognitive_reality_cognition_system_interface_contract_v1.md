# Reality Cognition System External Interface Contract v1

## Admitted inputs

| Input interface | Meaning | Boundary |
|---|---|---|
| Reality Evidence | provenance-preserved observation candidate | not Reality truth |
| Self State / Self Capability Context | abstract current capability, limitation, and confidence | not raw Registry/device details |
| Goal Context | current relevance frame | not a direct Action command |
| Resource Context | abstract admitted operating envelope | not resource allocation authority |
| Experience Reference | validated, traceable historical reference | no direct strategy or self mutation |

## External outputs

| Output interface | Meaning | Boundary |
|---|---|---|
| Situation Candidate | world–self–goal relationship candidate | not Decision or Action |
| Decision Candidate | Brain-judgment input for a current choice | not execution |
| Outcome Reference | future observed outcome/evidence reference | not Evaluation or truth guarantee |
| Experience Candidate | governed feedback for consolidation/reflection | not a direct update |

External systems communicate only through these interfaces. They do not gain
direct access to internal World Model, Self Model, Situation, Decision,
Execution Boundary, Value Feedback, or Experience internals.
