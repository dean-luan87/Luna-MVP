# Cognitive Foundation Baseline Registration Plan v1

## Purpose

This Planning Only registration records the proposed `Luna Cognitive Foundation Baseline v1` as the reference baseline for future extension review. It does not alter a contract, mark final GO, or permit a future module to modify the foundation.

## Included baseline domains

- Cognitive Constitution and Foundation Principles;
- Cognitive Flow, A/B Routing, Candidate/Evaluation boundaries;
- Field/Situation/Context/Intent/Goal/Affordance/Capability understanding;
- Experience/Compression/Representation Evolution;
- Population/Culture/Gene Pool candidates;
- Reducer and governance boundaries.

## Asset inventory basis

The baseline inventory contains 807 files under `docs/architecture/cognitive_flow/` at review time. Review categories: field/representation 157; understanding 94; reasoning/decision 203; experience/evolution 85; foundation boundaries 54; legacy/support 214.

## Registration boundary

Baseline registration is a governance reference, not Runtime input, Decision authority, State authority, or a substitute for local Context/Evidence validation.
