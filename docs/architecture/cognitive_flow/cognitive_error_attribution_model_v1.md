# Cognitive Error Attribution Model v1

Error Attribution Candidate distinguishes possible deviation sources:

- Observation Error
- Representation Error
- Schema Error
- Attention Error
- Workspace / Operation Error
- Simulation Error
- Evaluation Error
- External Unexpected Event Candidate

Attribution preserves alternatives and evidence gaps. An airport congestion prediction failure may arise from an accident rather than a traffic-schema defect. Attribution != blame, truth, automatic correction, Decision, Action, or State mutation.
