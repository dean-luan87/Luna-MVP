# Cognitive Failure Boundary Model v1

## Purpose

Failures are bounded candidate deviations within a cognitive lifecycle. They request local reconsideration; they do not delete history, assign blame, or authorize autonomous correction.

| Failure candidate | Example deviation | Candidate recovery path | Prohibited interpretation |
| --- | --- | --- | --- |
| Perception Failure | observation is incomplete, stale, or misread | Observation Recheck Candidate | observation failure != reality rewrite |
| Understanding Failure | situation or context no longer fits evidence | Situation / Context Reconstruction Candidate | context failure != field mutation |
| Reasoning Failure | a hypothesis or causal path is unsupported | Hypothesis Revision Candidate | revision != fact confirmation |
| Evaluation Failure | value or trade-off assumptions no longer fit | Weight / Evaluation Reconsideration Candidate | evaluation change != Decision override |
| Experience Failure | historical pattern is inapplicable | Experience Applicability Reduction Candidate | past failure != history erasure |
| Commitment Failure | basis, uncertainty, or recovery assumptions no longer hold | Commitment Validity Reconsideration Candidate | reconsideration != execution control |

## Failure handling contract

`Deviation Candidate -> Local Recognition Candidate -> Re-observation / Re-contextualization / Re-evaluation Candidate -> Experience Feedback Candidate`.

Failure remains traceable with evidence, uncertainty, applicability boundary, and provenance. No single failure automatically changes Constitution, Cognitive Genome, Culture, Gene Pool, State, Decision, Action, or Permission.
