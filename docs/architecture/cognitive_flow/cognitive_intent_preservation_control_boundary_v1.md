# Intent Preservation Control Boundary v1

## Control chain

```text
Brain Intent
        ↓
Intent Contract Candidate
        ↓
Neural Interpretation Candidate
        ↓
Attention Requirement Candidate
        ↓
Capability Observation Request Candidate
        ↓
Evidence Candidate
        ↓
Intent Alignment Evaluation Candidate
        ↓
Brain Update Candidate
```

## Boundary allocation

- Brain defines the Original Purpose and retains final cognitive judgment.
- Neural Governance can organize bounded coverage and surface constraint gaps;
  it cannot alter the purpose or remove a Non-Negotiable Objective.
- Attention converts preserved intent into an observation requirement; it does
  not interpret Reality or execute a request.
- Middleware can offer capability feasibility and execution status candidates;
  it cannot reframe intent as a model metric or declare cognitive success.
- Provider can return local evidence only; it cannot set the intent or control
  attention.
- Evidence Gateway and Reality Cognition preserve provenance, uncertainty, and
  situation impact; they do not make a final Decision.

## Related controls

Intent Preservation complements Fact Admission, Evidence Chain, Protocol
Governance, and the Reducer. Those control factual, provenance, protocol, and
State integrity respectively; this boundary controls purpose fidelity.
