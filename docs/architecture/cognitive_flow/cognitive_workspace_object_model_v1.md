# Cognitive Workspace Object Model v1

Workspace object candidates include:

1. Focus Object — current problem/object of focus.
2. Active Representation — activated entity/relation/state/event/goal/constraint candidates.
3. Active Schema — currently relevant schema candidates.
4. Goal Context — current desired-state and success-condition candidates.
5. Constraint — time, budget, resource, risk, capability, or task limits.
6. Unknown — unresolved variable candidates.
7. Hypothesis — candidate explanations or possible states.

Each object retains source/evidence/context, uncertainty/confidence, provenance, and trace. Workspace object != Fact, Decision, Action, Permission, or State mutation.
