# Cognitive Module Integration Matrix v1

| Subsystem | Consumes candidate inputs | Produces candidate outputs | Cannot produce |
| --- | --- | --- | --- |
| Perception | input signal / field view | Perception Candidate | fact, decision, action |
| Cognitive Information Field | perception / source metadata | Information Field Candidate | Reality State mutation |
| Internal Representation | information-field candidate | Representation Candidate | knowledge truth |
| Schema | representation / context | Schema Match Candidate | rule, truth, action |
| Attention | context, goal, risk, schema | Attention Allocation Candidate | authority or unlimited resources |
| Workspace | active schema / representations / goal | Workspace Formation Candidate | memory write or decision |
| Simulation | workspace / causal candidates | Simulation Branch Candidate | Reality or prediction truth |
| Cognitive Operation | workspace / branch | Operation Result Candidate | fact or action |
| Evaluation | operation, evidence, branch, experience | Evaluation Candidate | decision, permission, state mutation |
| Outcome / Feedback | observed outcome and trace | Feedback and Improvement Candidates | automatic learning or evolution |
| Evolution admission | validated improvement candidates | Evolution Adoption Candidate | genome rewrite, culture update, local override |
| Governance / Reducer | candidate requests and authorized state events | validation outcome / state mutation only where separately authorized | cognitive judgment or decision |

All non-Reducer modules are candidate producers. Reducer authority remains isolated from cognitive judgment.
