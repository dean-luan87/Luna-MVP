# Attention Axis Storage and Experience Boundary v1

## Retention levels

| Candidate | Lifetime | Permitted use |
|---|---|---|
| Working Attention Context Candidate | current task window | bounded intent/requirement/axis continuity |
| Attention Pattern Candidate | future Experience validation | possible “what information was valuable” pattern |

The system does not preserve all attention history, all observation requests, or
all Provider responses as Attention Memory. Only a traceable Attention Pattern
Candidate may enter the governed Experience path.

```text
Attention Pattern Candidate
        ↓
Experience Candidate
        ↓
Validation
        ↓
Future Attention Guidance Candidate
```

No candidate in this phase automatically modifies Attention strategy, Runtime,
Goal, Self Model, Decision, Memory, or State.
