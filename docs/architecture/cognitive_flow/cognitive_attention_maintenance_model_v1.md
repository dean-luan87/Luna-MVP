# Cognitive Attention Maintenance Model v1

Attention Maintenance Candidate preserves task-relevant attention with a bounded low or medium allocation after immediate processing decreases.

Example: after locating an airport gate, gate/time/boarding-change attention may remain maintained for later reactivation.

Maintenance != Memory, persistent authority, importance truth, Decision, Action, or indefinite allocation. It remains subject to validity, stability, inertia, and resource constraints.
