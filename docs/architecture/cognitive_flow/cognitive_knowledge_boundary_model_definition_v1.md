# Cognitive Knowledge Boundary Model Definition v1

`CognitiveKnowledgeCandidateV1` may retain knowledge-type, source, context, time-validity, applicability, contradiction, reliability, unknown-status, provenance, and trace references.

Knowledge types may be Stable Knowledge, Contextual Knowledge, Experience Knowledge, Social Knowledge, or Self Knowledge. Each remains a candidate reference rather than a fact, belief authority, decision, action, permission, or memory write.
