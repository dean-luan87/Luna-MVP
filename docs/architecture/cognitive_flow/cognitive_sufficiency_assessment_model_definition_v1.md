# Cognitive Sufficiency Assessment Model Definition v1

`CognitiveSufficiencyCandidateV1` may retain situation, goal, risk, information, uncertainty-impact, time, resource, information-gap/value, minimum-sufficient-understanding, routing, provenance, and trace references.

It may express `sufficient`, `insufficient`, `uncertain`, `require_information`, `require_reasoning`, or `defer` as cognitive status candidates. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_truth=true`, `not_confidence_authority=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
