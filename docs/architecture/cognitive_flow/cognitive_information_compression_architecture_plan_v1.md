## Position

`Field / Event / Experience / Knowledge / Situation / Decision Trace -> Cognitive Information Compression -> Internal Cognitive Representation -> Context Matching -> Cognitive Decompression / Reconstruction -> Current Understanding Candidate -> Sufficiency / Routing / Reasoning`.

Cognitive Information Compression converts high-dimensional, continuous, context-dependent candidate information into low-dimensional reusable cognitive representations while preserving critical structure, relations, constraints, and boundaries.
