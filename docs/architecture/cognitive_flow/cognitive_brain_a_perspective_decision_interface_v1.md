# Brain–A Perspective Decision Interface v1

## Placement

Perspective does not enter World Understanding. The external world, Evidence,
Reality Representation, and World State retain their factual/uncertain
boundaries. Perspective enters after Situation Candidate formation as a
candidate input to Brain Evaluation and Decision Evaluation.

```text
World Evidence + Self Capability + Goal + Resource
                         ↓
                Situation Candidate
                         +
               Perspective Context Candidate
                         ↓
          Decision Evaluation Weight Candidates
                         ↓
                  Brain Evaluation
                         ↓
                  Decision Candidate
```

## Interface boundary

Perspective Context can request visible responsibility, relationship, care,
attention, or preference weighting. It cannot alter situation facts, option
generation, feasibility facts, or direct execution. Brain remains the only
final judgment boundary; A remains the source of reality-grounded candidate
space.
