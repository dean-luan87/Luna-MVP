# Cognitive Situation Understanding Model Definition v1

`CognitiveSituationCandidateV1` may retain field, primitive/concept, object, relationship, context, experience, knowledge, attention, uncertainty, situation-type, provenance, and trace references.

It supports unknown, partial, conflicting, and changing situation states. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_context=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
