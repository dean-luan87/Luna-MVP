# Luna Innate vs Adaptive Capability Model v1

## Innate / constitutionally stable

Candidate-versus-Fact separation; provenance/trace preservation; Admission before Reducer; Reducer-only State mutation; read-only Field/Context query boundaries; no model-to-Fact/Decision shortcut; no Hive central control.

## Cognitive organs

OCR, Vision, SLAM, Audio, ASR/TTS, models, maps, and sensors provide external Evidence Candidates only. They do not define Luna internal taxonomy or authority.

## Adaptive capabilities

Primitive/Concept variants, Field query composition, attention selection, capability providers, future prediction/decision support, Experience, Hive, and language expression may evolve only through future L1 governance, traceability, review, compatibility, and rollback boundaries. Adaptive does not override innate boundaries.
