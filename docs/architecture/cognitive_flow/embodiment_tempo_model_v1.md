# Embodiment Tempo Model v1

Embodiment Tempo describes device-side response characteristics:

- Sensor Tempo: camera frames, ToF updates, IMU sampling, continuous audio.
- Actuator Tempo: vibration, speech, or mechanical response horizons.
- Resource Tempo: battery, thermal, and compute-recovery characteristics.

It is a Hardware Governance observation/profile candidate, not an instruction from Brain or Neural.
