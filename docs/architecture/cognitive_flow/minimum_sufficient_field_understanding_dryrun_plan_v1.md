# Minimum Sufficient Field Understanding Controlled DryRun Plan v1

This DryRun validates only the declared Candidate schema, governance boundaries, provenance closure, and deterministic serialization. It does not test environmental correctness, inference, identity recognition, action planning, or safety in a real environment.

Six fixed declaration fixtures cover Unknown Dark Environment, Industrial Factory Partial Understanding, Public Space Unknown Field, Identity Known But Behavior Limited, Exploration Boundary, and Information Gap Preservation. Each remains fixture-only and uses no Provider, model, Field Kernel, Reducer, Experience, Learning, or Hive integration.

The runner may construct the controlled skeleton Candidate from these fixed declarations. It runs the same fixed set twice and compares canonical JSON. The verifier independently reads the serialized result and does not import or call the runner or skeleton.
