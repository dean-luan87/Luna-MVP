# Cognitive Self Model Boundary Contract v1

## Allowed candidate references

Governed Current Cognitive State and Context, Role Boundary, Mission/Survival constraints, Capability Registry, Resource Model, Experience Outcome, provenance, and trace references may be read.

## Rejected inputs and effects

Personality mutation, identity evolution, emotion authority, raw model/provider output, Decision result, Action command, permission, State handle, Reducer command, Runtime scheduling, Memory write, Learning execution, and Hive authority are outside this layer.

## Negative guards

- Self Model != Role.
- Self Model != Personality.
- Self Model != Identity.
- Self Model != Emotion.
- Self Model != Decision.
- Self Model != Action Permission.
- Capability != Authority.
- Confidence != Truth.
- Experience != Reality.
- Emotion != Self Model Authority.
- Reducer remains the only State Mutation Authority.

All outputs remain candidate-only, not fact, not state mutation, not decision, not action, not permission, and not memory.
