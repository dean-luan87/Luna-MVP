# Cognitive Self Model Architecture Plan v1

## Actual asset mapping

This planning layer aligns with Survival Constitution, Current Cognitive State, Current Context, Role Boundary, Mission Constraint, Cognitive Execution Monitoring, Experience Outcome Feedback, Capability Registry, Resource Model, Reducer Authority, and L0/L1 Governance. Existing ownership and authority remain unchanged.

## Position

`Current Cognitive State -> Self Model Candidate -> Context Interpretation -> Decision Candidate -> Execution Monitoring`.

The Cognitive Self Model expresses Luna's candidate understanding of its current abilities, limitations, resources, experience references, uncertainty, risk, and feasible responsibility. It is not a Self Model Runtime, Personality, Identity, Emotion Engine, Decision, or Action layer.

## Planning scope

Architecture planning only: no Personality, Emotion, Identity Evolution, Learning, Runtime, State Mutation, Decision, or Action is authorized.
