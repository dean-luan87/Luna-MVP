# A-Route Reality Cognition Authority Matrix v1

| Layer / Module | Permitted responsibility | Explicitly prohibited |
|---|---|---|
| L0 Survival Constitution | constrain legitimate candidate space | action policy execution or exception bypass |
| L1 Brain | goal/intent context and final judgment boundary | direct provider/hardware/action execution or State mutation |
| L2 Neural Governance | coordinate regulation/resource/process candidates | replace Brain judgment or run a scheduler |
| L3 Reality Understanding | evidence-governed representation, world/situation candidates | truth guarantee, decision, action |
| L4 Middleware / Provider | capability/resource/status/evidence candidates | cognitive authority or interpretation truth |
| L5 Feedback / Experience | outcome/value/experience/improvement candidates | automatic learning or direct strategy/self change |
| B Reflection | delayed, governed future improvement candidates | control current A or rewrite reality |
| Reducer | sole State mutation authority | infer, decide, execute, self-authorize mutation |

No layer gains Runtime, real Action execution, hardware control, online
learning, automatic model modification, or automatic Attention authority
through this closure phase.
