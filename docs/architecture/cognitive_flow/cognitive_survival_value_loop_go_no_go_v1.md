1. Value Feedback is not Reward and not Truth.
2. Value Feedback does not directly modify Strategy, Self Model, Experience,
   or State.
3. Experience does not directly change Self; Self Update requires Pattern
   Extraction, Validation, and Adoption Review.
4. Survival does not create an infinite self-goal.
5. Emotional Value does not alter Reality Fact; Reality Outcome does not
   replace Emotional Meaning.
6. Strategy effectiveness evaluates repeated patterns, not a single Action.
7. Neural does not replace Brain; Middleware has no cognitive value authority;
   Reducer remains the sole State mutation authority.
8. No online learning, model training, autonomous scheduler, Runtime,
   autonomous action, or automatic State modification is introduced.
