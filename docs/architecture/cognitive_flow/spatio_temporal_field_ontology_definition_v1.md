# Spatio-Temporal Field Ontology Definition v1

Field is not Map, Location, Database Record, Timeline, Snapshot, or Coordinate System.

Spatial Reference describes structural relation: position reference, distance relation, boundary, topology, accessibility, entity/relationship scope. Temporal Reference describes existence: duration, transition, evolution, change pattern, validity window, expiry, and explicit unknowns. Neither independently defines a Field; their relation is mediated by Field Identity, Context, Task, Attention, provenance, and uncertainty.

Coordinates, vectors, time series, and mathematical functions may later be internal calculation tools. They cannot be Luna's world ontology or substitute for Field identity/meaning.
