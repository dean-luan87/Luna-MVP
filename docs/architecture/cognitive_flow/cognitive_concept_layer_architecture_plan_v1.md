# Luna Cognitive Concept Layer Architecture Plan v1

## Position

Concept Layer organizes Cognitive Primitive Candidates into meaning-bearing **Concept Candidates**. A Primitive represents a basic possible cognitive element; a Concept represents a possible meaning formed from a Primitive cluster. Concept is explanation/interpretation candidate, never a Fact layer.

```text
Evidence/Context Reference → Translation → Primitive Candidate
        ↓
Concept Layer: Pattern / Meaning / Contextual Interpretation Candidate
        ↓
Field Kernel current-world representation or future analysis input
        ↓
Future Meaning Representation → Language Expression
```

Translation converts external references. Primitive Layer expresses Entity/Relation/State/Event/Situation elements. Concept Layer expresses Pattern, meaning, contextual interpretation, and situation-understanding candidates. Field Kernel organizes current governed world state; Reducer alone modifies it. Language expresses a meaning representation and never generates a Concept back into Luna's cognitive core.

Concept Layer does not confirm Facts, mutate world state, create Decisions/Actions, write Memory, execute learning, or invoke a model/provider/runtime.
