# Cognitive Conscious Runtime Alignment v1

Conscious Layer is hosted conceptually within Cognitive Runtime Environment Candidates: Runtime Instance supplies temporary isolation; Snapshot supplies current references; Process supplies a bounded task; Workspace supplies task cognition; Simulation Space supplies possible-world exploration.

`Trigger -> Create Workspace Candidate -> Retrieve Guidance Candidate -> Build Understanding Candidate -> Optional Simulation Candidate -> Evaluation Candidate -> Candidate Output -> Close / Retain Candidate`.

Closing a Conscious Runtime process releases temporary resources only. End Runtime != delete Experience or Memory. Conscious Layer != Runtime Engine, Scheduler, or Reducer.
