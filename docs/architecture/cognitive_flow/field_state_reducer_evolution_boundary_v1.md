# Field State Reducer Evolution Boundary v1

Spatio-Temporal Field Evolution is continuous field change described through governed state stages: `Field State(t0) -> Transformation -> Field State(t1)`, where each stage is a bounded time-space field condition, not merely a timestamp.

Reducer is the sole Field State Mutation Authority. It may apply Admitted Event, create a State version, and maintain transition history. It does not discover Event, explain meaning/risk, generate Concept, select model, predict, or decide.
