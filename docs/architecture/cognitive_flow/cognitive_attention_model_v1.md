# Cognitive Attention Model v1

Attention Candidate inputs: Context, Goal, Risk, Time, Uncertainty, Experience Match, Information Value, Activation Candidate, and Resource Availability.

Output may include target representation/schema reference, priority candidate, expected value, resource-cost candidate, validity boundary, reason, source/evidence, confidence, provenance, and trace.

Attention decides cognitive investment candidates only. It does not confirm importance, control reality, select a Decision, execute Action, grant Permission, or mutate State.
