## Position

`Primitive Representation -> Relation / Time / Causality / Goal / Constraint -> Schema Candidate -> Context Matching -> Activation Candidate -> Workspace / Simulation -> Reasoning`.

Cognitive Schema is a candidate organization of representations for understanding a situation. Schema != Rule, Truth, Experience, Reality, Decision, Action, Permission, or State mutation.
