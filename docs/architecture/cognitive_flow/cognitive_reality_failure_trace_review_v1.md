# Reality Failure Trace Review v1

## Purpose

Failure Trace Review verifies that a future scenario can localize an observed
deviation without reducing it to “navigation failed” or another single task
label.

| Trace layer | Required candidate trace question |
|---|---|
| Perception | was relevant Evidence missing, distorted, late, or insufficient? |
| Understanding | was Reality/World representation incomplete or unsupported? |
| Situation | was a world–self–goal constraint omitted? |
| Decision | was an option/evaluation trade-off unsuitable? |
| Execution | did the future execution boundary/status differ from request? |
| Environment | did the represented world change after formation? |
| Resource | did capability/resource limits block the expected path? |
| Unknown Cause | is present evidence insufficient to locate the cause? |

Multiple failure candidates may coexist. The review does not assign blame,
assert causality, modify a strategy, or run remediation. It only establishes
the trace requirements a later simulation must populate.
