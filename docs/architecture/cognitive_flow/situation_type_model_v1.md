# Situation Type Model v1

Situation type candidates may include:

- Routine Situation: a potentially stable everyday context;
- Task Situation: a potentially task-relevant context;
- Risk Situation: a potentially risk-relevant context;
- Social Situation: a potentially social-interaction context;
- Unknown Situation: an unresolved context;
- Transition Situation: a possibly changing context.

Types are candidate classifications, not facts, role assignments, behavior commands, decisions, or action permissions.
