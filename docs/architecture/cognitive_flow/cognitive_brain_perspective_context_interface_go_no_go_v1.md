# Brain Perspective Context Interface Go/No-Go v1

## V0 static acceptance criteria

1. Perspective Context includes source, Role Reference, Relationship Reference,
   emotional/responsibility weight, attention bias, decision preference, and
   boundary constraint candidates.
2. Perspective does not enter World Understanding; it enters after Situation as
   a Brain/Decision Evaluation weight candidate.
3. Emotion does not modify Reality, Evidence, World State, facts, or unknowns.
4. Emotion does not directly create Goal, Decision, Action, Provider call,
   Resource allocation, or State mutation.
5. Survival Constitution, safety, non-harm, consent, self continuity, Brain
   judgment, and Reducer authority remain higher-order constraints.
6. Role Reference is a placeholder only; no Role System, relationship network,
   emotional model, personality, or self update is implemented.
7. No Multi-A Coordination, Context Integration, B deepening, Action Runtime,
   Hardware Runtime, Online Learning, or A Core modification is introduced.
