# Survival Value Loop Authority Matrix v1

| Module | Permitted responsibility | Explicitly prohibited |
|---|---|---|
| Brain | define long-term existence direction and judgment candidates | direct State mutation, automatic action |
| Self Model | provide abstract subject/capability context | self-update or Memory replacement |
| World Model | provide evidence-governed environment understanding | value/meaning truth claim |
| Neural Governance | organize feedback and regulation candidates | replace Brain judgment, execute provider/action |
| Experience System | consolidate validated experience candidates | direct Self or strategy change |
| Emotional Cognition | evaluate meaning/relationship value candidates | alter Reality fact or World State |
| Reality Cognition | evaluate physical/capability outcome candidates | replace emotional meaning |
| Middleware | provide capability/resource status candidates | cognitive value authority or Decision |
| Reducer | sole State mutation authority | infer, evaluate, decide, or self-authorize mutation |

All non-Reducer outputs remain candidates. No module receives Reward,
automatic learning, or autonomous action authority in this phase.
