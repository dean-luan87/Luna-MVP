## Position

`Attention -> Active Schema Set -> Workspace Formation Candidate -> Workspace -> Simulation / Reasoning / Evaluation Candidate`.

Cognitive Workspace is the temporary, task-related composition environment for activated cognitive objects. It is hosted conceptually within Cognitive Runtime Environment, but is not the Cognitive VM itself, Memory, Knowledge Storage, Decision Space, Reality State, Action, Permission, or State mutation.
