# Cognitive Perception and Conscious Separation v1

`Observation -> Situation Understanding -> Context -> Workspace -> Simulation -> Candidate`.

Perception is bound to current external evidence and cannot actively create a future world or produce a reality judgment without input. Conscious Layer receives evidence candidates and may organize internal explanation, planning, and possible-world candidates.

Conscious != Perception. Perception != Decision. Conscious output != Fact, Decision, Action, Permission, or State mutation.
