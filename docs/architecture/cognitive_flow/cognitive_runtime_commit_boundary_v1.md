# Cognitive Runtime Commit Boundary v1

Runtime may close a process with Commit Candidate or Discard Candidate. Commit means a cognitive output is ready for governed Candidate Flow / Evaluation consideration; it does not mean Decision, Permission, Human Choice, Action, execution guarantee, or Reality change.

`Runtime Candidate Output -> Validation Candidate -> Evaluation Candidate -> Decision / Commitment Candidate -> Human / External Execution Boundary`.

Runtime Outcome may later form Experience Candidate input only through validation. Runtime != Experience Storage.
