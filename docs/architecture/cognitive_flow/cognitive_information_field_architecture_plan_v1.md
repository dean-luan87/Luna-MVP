## Definition and position

Cognitive Information Field is the context-bound collection of information candidates currently processed by Luna’s Conscious Layer.

`Information Source -> Cognitive Information Field -> Information Filtering / Alignment -> Information Representation -> Cognitive Processing -> Internal Representation -> Workspace -> Simulation -> Candidate`.

It is not Reality Field, Memory, Knowledge Base, Database, or Truth Repository. This phase defines information organization only; it does not implement collection, search, external knowledge, Memory Runtime, World Model, or Simulation Engine.
