# Cognitive Context Dependency Principle v1

Field, Situation, Context, Intent, Goal, Affordance, Capability, Experience, Knowledge, Representation, and Future Space candidates require applicable Time, Space, Task, Resource, Risk, provenance, and uncertainty boundaries.

Context matching is required before applying Experience, Knowledge, Compression Representation, Culture, Gene Pool, or future external-system candidates. Similarity is not Applicability; History is not Future Applicability.
