# Cognitive Workspace Lifecycle Model v1

`Create -> Populate -> Update -> Reason -> Evaluate -> Close`.

Create forms a workspace candidate from Active Schema Set and current context. Populate adds bounded objects. Update proposes replacement, addition, suspension, or removal references as evidence/context changes. Reason/Evaluate produce candidates. Close releases temporary workspace resources.

Workspace Close != Memory Delete, Experience Delete, history erasure, Decision, Action, or State mutation.
