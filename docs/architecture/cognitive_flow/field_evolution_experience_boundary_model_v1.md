# Field Evolution Experience Boundary Model v1

An Experience Candidate may later reference a reviewed outcome, Field trajectory, Context, evidence, uncertainty, and provenance. It is not automatically derived from Field History and is not Memory.

A Learning Candidate is a review-bound candidate queue item, not Learning, training, model update, Memory write, Case Library write, Fact, or State. Future Hive may associate reviewed Experience Candidates/branches across Lunas; Hive is neither Database, central brain, State writer, nor collective truth authority.
