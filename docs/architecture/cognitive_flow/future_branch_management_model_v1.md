# Future Branch Management Model v1

Future Branch Management Candidate plans Branch Creation, Evaluation, Weighting, Pruning, and Preservation. It controls uncertainty representation, not the future itself.

Creation adds possible paths; evaluation retains evidence and cost; weighting stays non-authoritative; pruning marks a branch currently weak/inapplicable; preservation retains relevant low-probability high-impact paths. No operation deletes evidence, makes a decision, or executes behavior.
