# Cognitive Output Attention Interface v1

Output Attention exposes a future-facing, candidate-only request interface from the Controller toward Perception Adapter boundaries.

Required request fields: information need, target category, time/space/task scope, requested depth/priority/duration candidate, expected information value, resource limit, uncertainty, source/provenance, trace, and `sensor_execution_authorized=false`.

Output Attention Interface != Device Control, Sensor Invocation, Camera Movement, Action Command, Permission, or State mutation.
