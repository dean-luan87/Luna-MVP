# Cognitive Organization Interaction Model v1

```text
Capability Layer -> Candidate Sources -> Attention Candidate Pool
  -> Governance / Controller -> Allocation Candidate
  -> Capability Composition / Resource Modulation Candidates
  -> Workspace / Simulation / Reasoning Candidates
  -> Evaluation / Feedback Candidates
  -> Attention Evolution Guidance Candidate
```

Organization is request/response candidate coordination, not direct subsystem calls or a replacement for Reducer authority. Capability layers retain their own evidence/understanding/evaluation boundaries.
