# Cognitive Candidate Lifecycle v1

Candidate lifecycle states may be:

`Generated -> Supported -> Evaluated -> Validated -> Committed Candidate -> Outcome Observed -> Experience Feedback`.

Candidates may also be deferred, conflicted, suspended, revised, retired, or preserved with failure/exception reasons. A failed Hypothesis Candidate should preserve future applicability limits rather than be treated as an erased fact.

Lifecycle state is not Fact, Adoption, Decision, Action, Learning, Memory write, or State mutation.
