# Cognitive Deep Reasoning Alignment v1

Deep Reasoning is the B-route conscious mode for high-value, high-risk, high-uncertainty, or multi-conflict questions. It may coordinate Causality, Counterfactual, Future Space, Branch Governance, and Optimization candidates.

B Route != Higher Intelligence. B Route = Higher Resource Cognitive Mode. It is not default-on, a Decision Engine, Action authority, prediction truth, or a replacement for A-route Task Cognition.
