# Cognitive Operation Reasoning Alignment v1

A Route favors low-cost Recognition, Association, Retrieval Guidance, and simple Composition candidates for rapid understanding. B Route may request Abstraction, Analogy, Causal Transformation, Counterfactual, and broader Composition/Decomposition candidates.

B Route != Higher Intelligence. More operations != Better Cognition. Reasoning/Evaluation receives operation results as candidates and retains Decision/Action separation.
