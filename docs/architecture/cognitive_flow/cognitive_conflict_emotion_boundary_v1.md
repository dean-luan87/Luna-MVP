# Cognitive Conflict Emotion Boundary v1

## Future interface

A future Emotion Engine may provide separately governed Candidate Weight, Preference, or Attention Bias Candidate references. These can enter conflict evaluation as traceable, uncertain input dimensions only.

## Prohibitions

Emotion cannot be Conflict Authority, direct Decision, Action controller, Permission grant, Survival override, or personality mutation path. Emotion does not establish truth and cannot collapse a conflict into a winner.

`Emotion != Conflict Authority`, `Emotion != Direct Decision`, and `Emotion != Action`.
