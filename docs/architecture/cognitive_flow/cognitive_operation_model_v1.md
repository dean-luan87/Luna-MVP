# Cognitive Operation Model v1

Operation Candidate inputs are Representation, Schema, Workspace, Simulation Branch, source/evidence/context, constraints, uncertainty, and resource references. Outputs may be New Representation, Relation, Hypothesis, Scenario, Decomposition, Composition, or Reasoning candidates.

Core types: Recognition, Association, Decomposition, Composition, Abstraction, Analogy, and Transformation. Each operation records operation type, input references, changed/derived structure, confidence, unknowns, evidence requirement, applicability, provenance, and trace.

Operation output remains candidate-only and must not become Fact, Decision, Action, Permission, Reality mutation, or Evidence override.
