# A/B Reality–Reflection Boundary Contract v1

## Information path

```text
A Reality Cognition
      ↓
Experience + Outcome Reference + Value Feedback
      ↓
B Reflective Cognition
      ↓
Strategy / Self Understanding / Improvement Candidate
      ↓
Validation → Reality Feasibility → Adoption Candidate
      ↓
Future influence on A through existing governance
```

## Frozen rules

- A uses existing World State, Self Capability, Resource State, and admitted
  capabilities only.
- B may use explicit hypotheses, but hypotheses do not become Reality facts.
- B cannot directly modify A reality decisions, Attention, Self Model,
  Middleware, Provider selection, State, or Action.
- A does not execute a B candidate merely because it is insightful.
- B does not replace Brain Decision or take execution responsibility.
- Reducer remains the sole State mutation authority.
