# Current Cognitive Context Candidate Skeleton Plan v1

The controlled skeleton introduces only an immutable `CurrentCognitiveContextCandidateV1`, static Validator, and canonical serializer in a new directory separate from existing Context Runtime assets.

It models a declared current stance through reference fields for Field/View, Survival, Task, Attention, uncertainty, information gap, spatial/temporal scope, Experience, provenance, and trace. The six context types are candidate classifications only: Exploration, Navigation, Social, Task, Risk Awareness, and Unknown Environment.

No context formation, Runtime, model inference, Decision, Action, Memory, Learning, Hive integration, Field Kernel integration, or Reducer integration is implemented.
