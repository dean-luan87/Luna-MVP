# Optimization Closure Boundary Contract v1

Allowed inputs are governed Future Space/Governance/Convergence/Evolution, Optimization, Context, Goal, Survival, Mission, Attention, Information Value, Experience, Decision Candidate/Commitment, provenance, and trace references.

Outputs remain candidate-only, non-Fact, non-State-mutation, non-Decision, non-Action, non-Permission, and non-Memory.

Negative guards:

- Optimization != Truth.
- Satisfaction != Perfect Solution.
- Enough != Best.
- Convergence != Confirmation.
- Value != Reality.
- Decision != Optimization.
- Experience != Optimal Authority.
- Reducer != Cognitive Optimization Authority.
- Reducer remains the only State Mutation Authority.
