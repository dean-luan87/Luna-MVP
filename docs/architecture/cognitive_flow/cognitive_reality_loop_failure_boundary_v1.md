# A-Route Reality Loop Failure Boundary v1

## Failure localization chain

```text
Perception Failure Candidate
        ↓
Understanding Failure Candidate
        ↓
Situation Failure Candidate
        ↓
Decision Failure Candidate
        ↓
Execution Failure Candidate
        ↓
Outcome Deviation Candidate
        ↓
Adaptation Failure Candidate
```

The chain is a localization taxonomy, not a causal sequence or blame model.
Several candidates can coexist and `Unknown Cause` remains valid.

| Boundary | Candidate question |
|---|---|
| Perception | was evidence missing, distorted, late, or insufficient? |
| Understanding | was a representation/world relation unsupported or incomplete? |
| Situation | did world–self–goal coupling omit a relevant constraint? |
| Decision | did the option evaluation expose an unsuitable trade-off? |
| Execution | did a future execution request/status fail to realize its boundary? |
| Outcome Deviation | did observed reality diverge from expected outcome? |
| Adaptation | did a future correction/improvement candidate lack support or feasibility? |

Failure localization creates traceable candidates for experience and B
reflection. It never directly updates Strategy, Self Model, attention, model,
or State.
