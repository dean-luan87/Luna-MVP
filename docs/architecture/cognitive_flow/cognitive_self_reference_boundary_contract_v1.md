# Cognitive Self Reference Boundary Contract v1

## Allowed candidate references

Governed Self Model, Context, Current Cognitive State, Role Boundary, Mission/Survival constraints, capability/resource/experience candidates, provenance, and trace references may be read.

## Rejected inputs and effects

Emotional Self, Personality, Identity Evolution, Role Formation, social relationship model, raw model/provider output, Decision result, Action command, permission, State handle, Reducer command, Learning Runtime, Memory mutation, and Hive authority are outside this layer.

## Negative guards

- Self Reference != Self Model.
- Self Reference != Personality.
- Self Reference != Identity.
- Self Reference != Emotion.
- Self Reference != Role.
- Self Reference != Mission.
- Self Reference != Decision.
- Self Reference != Action Permission.
- Capability != Authority.
- Confidence != Truth.
- Experience != Self Definition.
- Emotion != Self Reference Authority.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not state mutation, not decision, not action, not permission, and not memory.
