# Reality Cognition Simulation Metric Model v1

## Architecture metrics

| Metric | Trace evidence required | Not measured |
|---|---|---|
| Self Awareness | Self Capability/limitation reference participates in Situation and evaluation | subjective intelligence or self-worth |
| Reality Grounding | evidence/world references remain candidate-only; unknowns remain visible | factual answer accuracy |
| Situation Quality | world + self + goal/resource relation is recorded | universal answer selection |
| Decision Reasoning | options, evaluation factors, constraints, confidence appear in trace | optimal decision outcome |
| Feedback Quality | outcome, difference, failure, value, and experience candidates are linked | learning success or model improvement |

Metrics are boolean contract-observability checks for v1. They are not reward
scores, performance rankings, truth scores, or a pass to execute an Action.
