# Attention Allocation Model v1

## Contract

```text
Attention Candidate + Intent Contract + Situation + Temporal Context + Resource Constraint
        ↓
Attention Allocation Candidate
```

Allocation Candidate proposes where limited cognitive consideration may go. It
is not a Decision, actual CPU/GPU/device allocation, Provider call, Action, or
Attention Runtime instruction.

## Evaluation factors

- Intent Relevance Candidate
- Survival Impact Candidate
- Temporal Urgency Candidate
- Uncertainty Candidate
- Information Value Candidate
- Resource Cost Candidate

Attention Priority != Importance. A generally important concern may receive less current allocation than an immediate safety-relevant requirement. Complete Observation != Optimal Cognition: the aim is minimal sufficient information.
