# Brain Intent Trace Contract v1

```json
{
  "original_intent": {},
  "non_negotiable_objective": {},
  "attention_intent": {},
  "interpreted_requirement": {},
  "a_route_situation_candidate": {},
  "a_route_decision_candidate": {},
  "brain_evaluation": {},
  "feedback_to_brain": {
    "cause": {},
    "confidence": {},
    "unknowns": [],
    "adaptation_candidate": {}
  },
  "alignment_result": {}
}
```

The trace is structured provenance, not private chain-of-thought, Goal
mutation, Action instruction, or State mutation request. Alignment Result may
be aligned, expansion drift, narrowing drift, replacement drift, attraction
drift, or insufficient evidence candidate.

The contract treats attraction drift as a detectable alignment-result candidate.
