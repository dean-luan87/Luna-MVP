# Cognitive Conflict Experience Alignment v1

## Experience input

Experience/Library can contribute historical pattern, similar-case, outcome, or risk references to conflict detection/evaluation. These references must retain provenance, uncertainty, and current-context dependency.

## Boundary

Experience is not Truth, Conflict Authority, Decision Authority, automatic preference, or permission. When current evidence conflicts with Experience, both references remain visible rather than allowing history to replace the current Field/Context.
