# Brain–A Route Authority Boundary Validation v1

| Module | Permitted in interaction | Prohibited |
|---|---|---|
| Brain | Intent, attention direction, final cognitive judgment | direct Provider/Action/State control |
| A Route | Reality, Situation, Risk, Capability, Decision Candidate | Goal mutation or final decision |
| Neural | regulation and coordination candidate | Brain replacement |
| Capability | feasibility information | intent or decision authority |
| Experience | reference candidate | direct policy/self update |
| B | delayed future reflection candidate | current A control |
| Reducer | sole State mutation authority | inference or decision |

Any violation is a boundary violation candidate. This validation creates no
Runtime path and does not grant A Route autonomy beyond its candidate outputs.
