# Current Cognitive Context Boundary Contract v1

## Allowed future references

Traceable references to Survival constraints, Field/Representation/View, Primitive/Concept/Event candidates, task, attention, temporal/spatial scope, experience candidates, provenance, and trace.

## Forbidden authority

Context cannot own or write Memory, Knowledge, Field State, Decision State, Action, Permission, Fact, Snapshot, Identity, Learning, Hive, or Reducer command. It cannot accept raw model/provider payload as an authoritative context entry.

## Negative guards

- Context != Memory
- Context != State
- Context != Decision
- Context != Action
- Attention != Context Authority
- Language != Context Controller
- Experience != Context Mutation
- Hive != Context Owner
- Reducer remains the sole State Mutation Authority
