# Cognitive Compression Context Boundary v1

Every compressed representation must bind candidate Time, Space, Goal, Resource, and Risk boundaries. Similarity is not Applicability, Pattern is not Rule, and Experience is not Universal Truth.

Lifecycle candidates may be:

`Raw Information -> Compression Candidate -> Validated Representation -> Repeated Pattern -> Stable Cognitive Representation -> Context Adaptation`.

Maturity may decline when applicability declines or context changes; representation revision remains candidate-only.
