# Cognitive Mode Switching Model v1

## Candidate modes

Mode Switching Candidate relates a Cognitive Time Budget Candidate to existing Cognitive Depth modes:

- Reactive Response Candidate for narrow, high-pressure cognitive windows;
- Pattern Match Candidate for bounded traceable familiar patterns;
- Exploration Candidate for lower-risk information expansion; and
- Deep Reasoning Candidate for high-value uncertainty with a broad available window.

## Boundary

Mode switching changes neither intelligence nor authority. It is not a Decision, Action, Permission, policy selection, or model invocation. It only proposes an appropriate future cognitive-path shape under present candidate constraints.
