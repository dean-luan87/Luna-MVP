# Reality Cognition System Authority Matrix v1

| System boundary | Permitted responsibility | Explicitly prohibited |
|---|---|---|
| Reality Cognition System | compose A-route reality understanding, decision, and feedback candidates | independent Action, Runtime, direct State mutation |
| World Understanding | represent governed evidence/world candidates | Goal/Decision/Action authority |
| Self Understanding | provide current subject context | decision selection or direct hardware control |
| Situation Understanding | couple world, self, goal, and resource context | execute or decide |
| Decision Formation | generate/evaluate Decision Candidates for Brain judgment | action execution or provider control |
| Action Feedback | form outcome, difference, failure, and adaptation candidates | action control or automatic correction |
| Adaptation Feedback | provide value/experience/future-improvement candidates | automatic learning or direct strategy/self change |
| External B Reflection | receive/govern delayed exports and future candidates | direct internal A access or current A control |
| Reducer | sole State mutation authority | infer, decide, execute, self-authorize mutation |

Encapsulation does not transfer Brain, Neural, Middleware, Provider, or
Reducer authorities into a new system owner. It only defines the A-route
composition and access boundary.

Reality Cognition System is not a new authority owner.
