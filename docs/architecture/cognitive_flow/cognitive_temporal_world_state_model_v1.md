# Temporal World State Model v1

## Core model

```text
World State Reference
        +
Temporal Context Candidate
        ↓
Temporal World State Candidate
```

Temporal World State Candidate describes how a governed World State may have
changed, not what the future certainly is. It remains an A-route World
Understanding extension and does not replace Reality Representation.

## Dimensions

| Dimension | Candidate question | Example |
|---|---|---|
| Past | What represented state preceded the current state? | road was clear earlier |
| Current | What is currently represented? | traffic is currently dense |
| Transition | How did the state change? | congestion is increasing |
| Duration / cadence | How long or how often has the transition been observed? | three governed samples |
| Pattern | Is there a repeated, cyclic, continuous, or abrupt pattern candidate? | lower illumination recurs at night |
| Future possibility | What bounded continuation remains possible? | continued congestion may raise route-delay risk |
| Uncertainty | What is not sufficiently observed? | duration and cause remain unknown |

## Authority boundary

- Temporal World State Candidate does not modify Reality, World State, or
  Evidence.
- A Transition Pattern Candidate is not causality. Temporal order alone does
  not prove cause.
- Future Possibility Candidate is a bounded support signal, not a forecast
  model, scheduled plan, or future fact.
- Only the Reducer has sole State mutation authority.
