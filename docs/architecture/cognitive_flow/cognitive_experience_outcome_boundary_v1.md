# Experience Outcome Boundary v1

## Experience relation

Experience Candidate can retain a context-bound `Field/Context -> candidate behavior/decision path -> outcome candidate -> adaptation reference` pattern. It is neither a Memory item, Fact Store record, Knowledge Base entry, Learning result, nor automatic behavior change.

Experience may describe what was attempted, under which constraints, what candidate outcomes were observed, and which information remains uncertain. It must retain supporting and contradictory evidence, provenance, trace, and alternative explanations.

`Experience != Memory`, `Experience != Fact Store`, `Experience != Knowledge Base`, `Experience != Learning`, and `Experience != Automatic Behavior Change`.
