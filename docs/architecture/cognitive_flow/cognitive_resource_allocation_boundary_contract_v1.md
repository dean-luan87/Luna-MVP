# Cognitive Resource Allocation Boundary Contract v1

## Allowed candidate references

Survival pressure, context, goal, risk, information value, self capability/resource awareness, time, experience, future space, reasoning, provenance, and trace references may be read.

## Rejected inputs and effects

Runtime scheduler control, compute allocation, raw model/provider output, sensor invocation, Decision result, Action command, permission, State handle, Reducer command, Memory mutation, Learning execution, and Hive authority are outside this layer.

## Negative guards

- Resource Allocation != Scheduler.
- Resource Allocation != Decision.
- Resource Allocation != Action.
- Attention != Resource Allocation.
- Attention != Authority.
- Depth != Intelligence.
- Depth != Correctness.
- Efficiency != Correctness.
- Experience != Shortcut.
- Confidence != Permission.
- Resource Allocation does not modify Self Model.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not state mutation, not decision, not action, not permission, and not memory.
