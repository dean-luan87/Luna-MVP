# Cognitive Self Reference Model Definition v1

`CognitiveSelfReferenceCandidateV1` may retain capability, limitation, resource, knowledge-status, experience, risk, recovery, context, provenance, and trace references.

It describes cognitive-subject constraints, not an identity or personality. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_personality=true`, `not_identity=true`, `not_emotion=true`, `not_role=true`, `not_mission=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
