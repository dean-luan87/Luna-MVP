# Cognitive Urgency Assessment Model v1

## Candidate assessment

Urgency Assessment Candidate describes whether a current Field/Context condition may warrant a narrower cognitive window or higher-priority reasoning review. It can reference Field Dynamics, Survival, risk, task relevance, uncertainty, and provenance.

Urgency is not an emergency Fact, Action trigger, permission, or command. It must retain uncertainty and cannot bypass Survival, Context, Behavior Boundary, L1 governance, or the Reducer.

## Example boundary

A vehicle-approach interpretation may raise an urgency candidate and request preemption review of low-value reasoning. It does not prove a vehicle exists, command avoidance, or execute a safety response.
