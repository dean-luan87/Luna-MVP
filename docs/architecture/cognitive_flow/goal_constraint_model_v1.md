# Goal Constraint Model v1

Goal Constraint Candidate describes possible limits, dependencies, conflicts, resources, time windows, survival considerations, capability limits, or uncertainty that may affect a Goal Candidate.

Success Condition Candidate describes a candidate criterion for sufficient goal progress. Neither condition creates a plan, determines completion as fact, grants permission, or triggers action.

The A-Route may consume explicit governed objective-condition rules to form a
candidate-only set of currently required cognitive conditions from the current
cognitive situation. This is a state-sensitive formation step before Minimum
Relevant Cognitive View and Information Need; it does not replace Goal
Governance or reinterpret opaque Goal/Context strings.
