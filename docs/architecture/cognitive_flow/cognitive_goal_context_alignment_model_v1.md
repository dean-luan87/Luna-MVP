# Cognitive Goal Context Alignment Model v1

Goal Context Alignment Candidate evaluates whether a Goal Candidate is meaningful under the current cognitive situation. It retains Context Fit, Capability Fit, Resource Fit, Risk Fit, Intent support, uncertainty, conflicts, provenance, and trace.

Alignment output is an evaluation candidate, not a selection. A low context fit for finding a fuel station inside an airport does not delete the Goal Candidate or declare the world claim false.
