# Possible Future Space Boundary Contract v1

Allowed inputs are governed references to Predictive Field State, Anticipation, Preparation, Field/View/State/Evolution, Hypothesis, Belief, Current Cognitive State, Reasoning, Decision Candidate, Experience/Learning Candidate, future emotion salience candidate, Survival, provenance, and trace.

Forbidden inputs are raw model output, provider payload, Fact Store, State handle, Reducer command, Decision result, Action command, Permission grant, World Model output asserted as truth, Memory, Learning execution, or Hive authority.

Negative guards:

- Future Branch != Fact.
- Future Branch != Prediction Truth.
- Future Branch != Decision.
- Future Branch != Action.
- Future Branch != Permission.
- Probability != Safety Priority.
- Belief != Future Truth.
- Experience != Future Authority.
- Emotion != Future Reality.
- Future Branch != State Mutation.
- Reducer remains the only State Mutation Authority.
