# Cognitive Representation Goal and Constraint Model v1

Goal Representation Candidate describes desired state, goal boundary, sub-goal, success condition, and unresolved requirement. Constraint Representation Candidate describes temporal, spatial, resource, risk, capability, mission, or context limits.

Goal != Command, Decision, Action, Mission, or completion. Constraint != Permission, rule authority, or State mutation. Goal/constraint representations only organize what Workspace and Simulation may evaluate.
