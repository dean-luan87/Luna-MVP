# Resource Governance Review v1

## Review dimensions

Resource Governance evaluates compute, battery, attention, memory, network,
capability availability, thermal state, and process cost. It compares Information Value
with Resource Cost and returns an Allocation Candidate.

## Competing process review

For simultaneous Navigation, OCR, Conversation, and Environment Monitoring:

- Survival and Safety monitoring remain protected candidates;
- active Goal work receives context-appropriate resources;
- low-value Background Threads may be reduced, suspended, or archived;
- unmet demands and reasons remain explicit;
- a shortage may escalate to Neural or Brain review.

Resource allocation is not a Scheduler and does not execute a process. It does not
silently discard critical monitoring, create a Goal, choose an Action, or mutate
State directly. Brain retains long-horizon policy; Neural proposes dynamic
regulation; Middleware evaluates capability and physical limits.

## Unlimited-thinking guard

Every process declares a resource budget candidate, expected value, stop or
release condition, and escalation path. Deep reasoning cannot continue without a
governed budget candidate and reviewable justification.
