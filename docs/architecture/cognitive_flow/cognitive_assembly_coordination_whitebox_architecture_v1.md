# Assembly Coordination Whitebox Architecture v1

Future read-only Whitebox flow:

```text
Brain Intent
↓
Assembly Candidate
↓
Members / Member Relationships
↓
Capability Requirements
↓
Evidence Bus / Fusion Package
↓
Neural Feedback Package
```

It must display member type, relation type, coverage, conflict, unknowns, and boundary flags—not a raw model-call list and not controls for execution.
