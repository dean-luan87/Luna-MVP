# Cognitive Snapshot Candidate Model v1

`CognitiveSnapshotCandidateV1` may retain references to Current Situation, Current Context, Current Goal, Current Attention, Current Hypothesis, Current Future Space, Current Confidence, Current Unknown, temporal/spatial boundary, provenance, and trace.

It provides a shared candidate interpretation reference for future subsystem interaction. It is not Field State, World State, Reducer Snapshot, State write target, Fact, Memory, Decision, Action, or permission.
