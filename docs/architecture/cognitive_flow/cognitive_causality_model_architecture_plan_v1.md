# Cognitive Causality Model Architecture Plan v1

## Actual asset mapping

This planning layer aligns with Survival Constitution, Field Representation/View, Current Cognitive Context, Hypothesis Layer, Belief State, Future Space, Predictive Field State, Experience Boundary, Knowledge Boundary, Optimization Layer, Decision Candidate, Reducer Authority, and L0/L1 Governance. It does not redefine ownership or authority.

## Position

`Field Observation -> Relationship Candidate -> Causal Candidate -> Hypothesis / Belief Update Candidate -> Future State Candidate -> Decision Evaluation Candidate`.

Cognitive Causality describes Luna's candidate understanding that some factors may lead to some changes under stated conditions. It is not a fact-causality database, World Model, Causal Engine, Simulation Runtime, Decision, or Action layer.

## Planning scope

No World Model Runtime, causal graph execution, simulation, Decision Engine, Action, or State Mutation is authorized.
