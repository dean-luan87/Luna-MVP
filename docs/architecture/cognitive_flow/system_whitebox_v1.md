# A Route System Integration Whitebox v1

```text
External Capability
        ↓
Evidence
        ↓
Reality Workspace
        ↓
World State + Self State + Unknown
        ↓
Neural Processing / Cognitive Process / Resource Governance
        ↓
Attention Requirement
        ↓
Situation
        ↓
Decision Candidate
        ↓
Execution Boundary (future, no Runtime here)
        ↓
Outcome
        ↓
Experience Candidate
```

```text
Hardware State
        ↓
Capability State
        ↓
Self Capability Candidate
        ↓
A Route Evaluation
        ↓
Decision Constraint
        ↓
Brain Final Judgment
```

Every arrow is governed by a contract. No Model Output goes directly to
Decision, Emotion, or Goal. No Registry or Diagnostics signal becomes Action.
Reducer remains the sole State mutation authority.
