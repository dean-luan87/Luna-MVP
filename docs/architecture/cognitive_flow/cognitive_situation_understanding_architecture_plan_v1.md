# Cognitive Situation Understanding Architecture Plan v1

## Actual asset mapping

This A-route planning layer aligns with Field Representation/View, Primitive and Concept candidates, Relationship candidates, Current Cognitive Context, Attention, Behavior Candidate, Experience Boundary, Knowledge Boundary, Reducer Authority, and L0/L1 Governance.

## Position

`Field Observation -> Primitive / Concept -> Relationship Candidate -> Situation Candidate -> Current Context -> Attention -> Behavior Candidate`.

Situation Understanding describes what may be occurring in the current environment, what situation Luna may be in, and what the situation may mean. It is not a fact judgment, Context, Decision, Action, World Model, or Simulation.

## Planning scope

No Situation Model Runtime, World Model, Simulation, Decision Engine, Action, Memory Update, or State Mutation is authorized.
