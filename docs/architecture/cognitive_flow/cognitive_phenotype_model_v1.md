# Cognitive Phenotype Model v1

Cognitive Phenotype Candidate describes the individual, context-bound expression of shared cognitive foundations through experience, environment pressure, task history, resource limits, validated representation candidates, and survival value.

Different Luna instances may develop distinct candidate emphases—such as path-risk, family event, or workplace pattern understanding—without changing their shared Cognitive Genome. Phenotype is not Identity, Personality, Emotion, capability authority, or self-modification.
