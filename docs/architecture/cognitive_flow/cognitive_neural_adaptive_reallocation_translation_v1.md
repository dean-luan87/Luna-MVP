# Neural Adaptive to Reallocation Translation v1

Neural Governance converts the prior adaptive-control candidate rather than selecting a model.

| Provider condition | Capability gap | Reallocation candidate |
|---|---|---|
| Sufficient observation | No material gap | Maintain `text_understanding`. |
| Degraded text evidence | `quality_gap_candidate` | Add `region_understanding`; reduce primary OCR dependency; offer alternate text understanding. |
| Unavailable / no bounded result | `provider_failure_gap_candidate` | Request additional evidence; offer alternate text and region understanding. |

No text result means insufficient current evidence, never that text is absent in Reality.
