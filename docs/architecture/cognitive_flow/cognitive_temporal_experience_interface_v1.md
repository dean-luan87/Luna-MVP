# Temporal Experience Interface v1

## Extension of the governed Experience Package

```text
Experience Package Candidate
├── Situation Context
├── Temporal Context Candidate
├── Decision Trace Reference
├── Expected Outcome Reference
├── Actual Outcome Reference
├── Difference Candidate
├── Adaptation Candidate
├── Temporal Uncertainty
└── trace_ref
```

Temporal context adds the change process and turning-point references around an
experience. It does not convert an Experience Candidate into Memory, Knowledge,
Truth, a rule, or a strategy update.

## Handoff rule

```text
Temporal Pattern Candidate
        ↓
Experience Candidate
        ↓
Validation
        ↓
Future Memory / Knowledge Candidate
```

Validation and later adoption remain outside this phase. No temporal artifact directly enters B Reflection, online learning, or a Memory Runtime.
