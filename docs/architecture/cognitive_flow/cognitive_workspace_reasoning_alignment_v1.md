# Cognitive Workspace Reasoning Alignment v1

Workspace is the bounded input composition for Reasoning and Evaluation candidates. A Route uses a small workspace for high-match, minimum-sufficient task understanding. B Route may expand workspace content, unknowns, hypotheses, and branch references under resource/depth boundaries.

Workspace Bigger != Better. Reasoning != Decision. Evaluation != Action. Workspace does not choose routes, produce truth, or execute behavior.
