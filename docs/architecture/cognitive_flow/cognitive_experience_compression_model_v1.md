# Cognitive Experience Compression Model v1

Experience Compression Candidate may support:

- Event Compression;
- Decision Trace Compression;
- Pattern Extraction;
- Applicable Condition Extraction;
- Strategy Extraction;
- Exception Preservation.

Compression removes no governance requirement: context, uncertainty, contradictory evidence, exception, provenance, and trace remain referenceable. Compression does not write storage, learn, train, change policy, or mutate cognition/state.
