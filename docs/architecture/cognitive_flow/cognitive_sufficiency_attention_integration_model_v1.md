# Cognitive Sufficiency / Attention Control Integration Model v1

Sufficiency is an input to attention control, not an independent resource allocator.

```text
Sufficiency Evaluation Candidate
  -> require_information / require_reasoning / defer / sufficient candidates
  -> Attention Candidate Pool
  -> Cognitive Attention Controller
```

Insufficiency may increase attention to a relevant unknown, lower depth because time is unavailable, or preserve the current allocation. It cannot force information acquisition, route execution, Decision, or Action.
