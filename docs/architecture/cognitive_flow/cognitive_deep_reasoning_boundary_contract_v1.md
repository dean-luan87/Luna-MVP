# Cognitive Deep Reasoning Boundary Contract v1

## Allowed candidate references

Governed Mode/Depth/Time/Resource candidates, Context, Field/Event, Causality, Counterfactual, Future Space/Branch, Optimization, Knowledge/Experience, Survival/risk, provenance, and trace references may be read.

## Rejected inputs and effects

Reasoning Runtime, model integration, LLM chain, inference engine, simulation engine, World Model Runtime, raw provider/model output, Decision result, Action command, permission, State handle, Reducer command, Memory mutation, Learning runtime, and Hive authority are outside this layer.

## Negative guards

- Deep Reasoning != Intelligence Level.
- Deep Reasoning != Always Better.
- Longer Reasoning != Correctness.
- Deep Reasoning != Runtime.
- Simulation != Reality.
- Causality != Fact.
- Counterfactual != Prediction.
- Hypothesis != Fact.
- Future Branch != Prediction.
- Optimization != Decision.
- Deep Reasoning != Decision.
- Deep Reasoning != Action.
- Deep Reasoning != Permission.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not simulation, not state mutation, not decision, not action, not permission, and not memory.
