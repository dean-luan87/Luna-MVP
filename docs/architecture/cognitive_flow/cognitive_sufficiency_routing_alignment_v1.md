# Cognitive Sufficiency Routing Alignment v1

Sufficiency determines whether further cognition may be needed; Cognitive Routing determines which candidate cognitive path may be appropriate.

`Sufficiency Candidate -> Routing Candidate` may support A-route, pattern-match, exploration, B-route/deep reasoning, deferred, or information/reasoning requirement candidates. Sufficiency does not select a route, invoke a runtime, choose a decision, or execute an action.
