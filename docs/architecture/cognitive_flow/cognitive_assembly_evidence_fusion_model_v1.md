# Assembly Evidence Fusion Model v1

Evidence Fusion produces an `Assembly Evidence Package`, not an answer or Truth claim.

```text
Evidence references
+ relation candidates
+ coverage candidate
+ conflict candidate
+ remaining unknowns
+ confidence candidate
= Assembly Evidence Package
```

For example, OCR text, a sign region, and right-side spatial relation may coexist without forming “this is an exit.” Neural Governance receives the package for alignment; Brain Evaluation remains outside the Assembly.
