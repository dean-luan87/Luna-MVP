# A-to-B Experience Handoff Contract v1

## Experience Package

An A-route handoff is neither Memory, a log dump, raw process recording, nor direct learning input.
It is a governed `Experience Package Candidate`.

```text
Experience Package
├── Situation Context
├── Self State Reference
├── Decision Trace
├── Expected Outcome
├── Actual Outcome
├── Difference
├── Failure Classification
├── Value Impact
├── Confidence
└── Unknown Factors
```

## Contract

Every field is traceable, candidate-labelled, and uncertainty-preserving.
B uses the package only for delayed reflection.
B cannot change the current decision, rewrite Reality, access A internals, or directly update Self/Strategy/Attention/Provider plans.
Future returns require Hypothesis → Validation → Reality Feasibility → Adoption Candidate.
