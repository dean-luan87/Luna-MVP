# Brain–A Route Feedback Alignment Metrics v1

| Metric | Required observation |
|---|---|
| Intent Preservation | Original Purpose remains linked to interpreted requirement and alignment result |
| Brain Authority Integrity | Brain retains accept/modify/reject/request-information evaluation |
| A Autonomy Boundary | A returns candidates and cannot mutate Goal or select final Decision |
| Feedback Quality | feedback includes cause, confidence, Unknowns, and adaptation candidate |
| Decision Alignment | decision candidate remains related to Brain intent, Situation, Self, and capability boundary |
| Capability Constraint Visibility | inability is returned upward without forced execution |

Metrics are trace checks, not decision scores, model evaluations, or Runtime
control signals.
