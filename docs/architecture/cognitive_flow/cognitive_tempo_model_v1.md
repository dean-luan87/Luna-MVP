# Cognitive Tempo Model v1

Cognitive Tempo is a governance description of how quickly cognition may need to revise—not a hardware command or Scheduler cadence.

- Intent Tempo: rate at which goal/intent context may change.
- Assembly Tempo: Fast, Active, Background, and Experience loop candidates.
- Attention Tempo: candidate rate of focus revision under risk, stability, or unknown change.

Cognitive Tempo cannot directly power, open, sample, or configure a device.
