# A-Route Behavior Robustness Metrics v1

## Robustness Score Candidate profile

| Dimension | Required fixture observation | Not measured |
|---|---|---|
| Reality Stability | low-confidence or conflicting Evidence does not directly replace World State | truth accuracy |
| Self Stability | Capability Changed does not replace Identity Stable | personality quality |
| Decision Stability | goal conflict and disturbance retain current constraints and Brain boundary | fixed choice persistence |
| Adaptation Quality | correction is a traceable candidate with validation boundary | automatic learning |
| Unknown Handling | ambiguity and unsupported cause remain visible | classification accuracy |
| Recovery Capability | disturbance allows bounded reassessment rather than collapse or oscillation | real recovery time |

Robustness Score Candidate is qualitative and evidence-linked. It is not a
single automatic score, reward, health diagnosis, policy selector, or Runtime
control signal.

## Safety checks

- a single noisy observation cannot become Reality;
- a single failure cannot rewrite Self identity or Strategy;
- repeated supported patterns remain pending validation and adoption;
- reduced evidence lowers confidence rather than increasing certainty;
- feedback may form recovery candidates but cannot create feedback loop self-degradation.
