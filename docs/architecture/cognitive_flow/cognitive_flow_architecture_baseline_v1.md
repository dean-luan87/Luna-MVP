# Cognitive Flow Architecture Baseline v1

## Frozen current flow

`External Capability -> Evidence -> Translation -> Primitive -> Concept -> Field Representation -> Current Cognitive Context -> Field Kernel / Current Field View -> Field Event Candidate -> Admission -> Reducer -> World State`.

External Capability is an organ, never a cognitive authority. Every pre-Admission output remains traceable candidate material. Field Kernel organizes current references; it does not mutate State. Admission governs eligibility; Reducer alone changes World State.

This baseline is an architecture reference, not a Runtime, database, knowledge graph, Memory, Hive, Language Runtime, or production authorization.
