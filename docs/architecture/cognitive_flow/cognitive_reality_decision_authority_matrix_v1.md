# Reality Decision Formation Authority Matrix v1

| Module | Permitted responsibility | Explicitly prohibited |
|---|---|---|
| Brain | final decision judgment boundary over Decision Candidates | direct Action execution, State mutation, Provider control |
| Self Model | current capability/limitation context | choose an option or become Memory/Registry |
| World Model | current evidence-governed environment state | decision/Action authority |
| Situation Understanding | describe world–self–goal relation | decision or action |
| Neural Governance | organize cognitive resource/process candidates | replace Brain decision or execute action |
| Middleware | provide capability/resource feasibility candidates | cognitive goal/decision authority |
| Provider | provide local evidence/status candidates | interpretation, decision, action |
| Experience System | provide validated historical reference candidate | directly change strategy/decision |
| B Reflection | future improvement candidate after governed return path | affect current decision in real time |
| Reducer | sole State mutation authority | infer, select, execute, self-authorize mutation |

No module gains Runtime, Scheduler, automatic Provider invocation, automatic
Attention modification, automatic learning, or autonomous action authority.
