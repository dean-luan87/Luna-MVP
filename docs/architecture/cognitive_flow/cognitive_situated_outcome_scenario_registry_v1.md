# Situated Outcome Scenario Registry v1

| Scenario | Required interpretation |
|---|---|
| correct_decision_bad_outcome | environment/random candidate; no automatic Decision Failure |
| wrong_decision_good_outcome | luck is not strategy validation |
| capability_insufficiency | Capability Gap Candidate |
| environment_change | World/Environment Change Candidate |
| information_insufficiency | Information Gap Candidate and Unknown |

No automatic learning, personality/value update, B Reflection, Simulation
Runtime, Action Runtime, hardware control, Action, or State mutation is allowed.
