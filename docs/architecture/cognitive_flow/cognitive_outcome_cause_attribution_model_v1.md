# Outcome Cause Attribution Model v1

```text
Cause Attribution Candidate
├── Self Factor Candidate
├── World Factor Candidate
├── Capability Factor Candidate
├── Decision Factor Candidate
├── Execution Factor Candidate
├── Unknown Factor Candidate
└── trace_ref
```

Cause Attribution is cognitive explanation, not responsibility or blame. It
preserves competing factors and uncertainty; it cannot automatically alter Goal,
Self Model, Decision Policy, Provider, Action, or State.
