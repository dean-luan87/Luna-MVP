# Cognitive Behavior Evaluation Validation Matrix v1

| Validation area | Required condition | Boundary failure |
| --- | --- | --- |
| Candidate linkage | One evaluation references one governed Behavior Candidate and Boundary | Evaluation creates a behavior or bypasses Boundary |
| Survival alignment | Survival value and risk remain candidate dimensions | Survival becomes an action command |
| Goal alignment | Goal value is contextual, not a selection | Goal forces a chosen behavior |
| Cost/value clarity | Physical, cognitive, time, risk, and opportunity costs remain distinguishable | Single score asserted as authority |
| Uncertainty | Unresolved outcome and risk are retained | Unknown is automatically completed |
| Reversibility | Reversibility is explicit and non-authoritative | Reversible label treated as permission |
| Experience | Historical patterns retain provenance and current-context dependency | Experience automatically selects a candidate |
| Decision separation | No chosen/execute/permit field exists | Evaluation output contains Decision or Action semantics |
| State boundary | No State/Field/Memory mutation target exists | Evaluation can write State or Memory |

Planning V0 validates document completeness and these boundary statements only. It does not execute evaluation, simulate a Decision, or perform an Action.
