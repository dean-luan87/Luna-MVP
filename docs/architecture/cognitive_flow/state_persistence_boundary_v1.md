# State Persistence Boundary v1

## Retention tiers

- **Immediate State:** seconds; transient observations and active changes;
- **Working State:** minutes to hours; current environment and task context;
- **Persistent Reality Pattern:** long-lived validated state relationships that
  remain useful for future Reality Representation.

## Persistence rules

Persist only structured reality, self condition, temporal validity, entity/relation
state, provenance, Unknown impact, and validated state transitions. Do not persist
an unverified Decision as a fact, a prediction as reality, a Goal as a world
state, or a reasoning trace as a state mutation.

## Boundary

Persistence is not Experience Consolidation, Planning Memory, or automatic
learning. It is not automatic learning. Compression and expiry preserve Reality State integrity and do not
change Cognitive Rule Layer authority.
