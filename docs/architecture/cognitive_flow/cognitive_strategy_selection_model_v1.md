# Cognitive Strategy Selection Model v1

The v1 candidate taxonomy is:

- `information_seeking` — request a future information-acquisition candidate;
- `information_reduction` — narrow the information need to the minimum safe/relevant set;
- `safe_approximation` — preserve uncertainty while using bounded non-authoritative approximation;
- `risk_acceptance` — express a review-bound risk candidate, never a permission;
- `task_defer` — preserve the task for later context; and
- `task_abandonment` — express that continuing lacks sufficient constraints.

Each is a cognitive path hypothesis, not a Decision, Action, or command. Unknown and Information Gap remain explicit rather than automatically completed.
