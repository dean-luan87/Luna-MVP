# Cognitive Interrupt Model v1

Cognitive Interrupt Candidate describes a candidate need to suspend, compress, reprioritize, or redirect ongoing cognitive work when high-priority risk, field, goal, context, or information changes arise.

Example path:

`Risk Spike Candidate -> Interrupt Candidate -> Minimum Safe Understanding / Human Assistance Candidate -> Context/Attention/Route Reassessment Candidate`.

Interrupt is not an Action command, emergency controller, Decision, Permission, or State mutation. It may not bypass Candidate, Evidence, Context, Survival, Governance, or Reducer boundaries.
