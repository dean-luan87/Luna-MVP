# Cognitive Schema Evolution Model v1

`Experience -> Representation Candidate -> Schema Candidate -> Repeated Validation -> Stable Schema Candidate -> Culture Candidate`.

Evolution may strengthen, weaken, refine, or propose new schema structures while preserving exception and applicability conditions. Stable != universal rule. Culture Candidate != individual override. No schema directly modifies Experience, Genome, Culture, Gene Pool, Constitution, Field/Reducer State, Decision, or Action.
