# Cognitive Self State Model v1

`Cognitive Self State Candidate` is a bounded view of what the current cognitive system may currently support, lack, trust, attend to, retrieve, and sustain.

It aggregates source candidates without changing them: Capability State, Resource State, Cognitive Reliability State, Attention State, Knowledge Availability State, and Cognitive Load State.

Self State Candidate != persistent state store, Self Model authority, Identity, Personality, Emotion, or a command to change the system.
