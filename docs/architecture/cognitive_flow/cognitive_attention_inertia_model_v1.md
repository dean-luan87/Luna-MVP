# Cognitive Attention Inertia Model v1

Attention Inertia Candidate preserves task-relevant allocation continuity when current Goal Context, Task Retention, and Field Activation remain valid.

```text
Task Retention + Previous Allocation + Field Activation
  -> Attention Inertia Candidate
  -> Stable Allocation Candidate
```

Inertia prevents minor salience from evicting an active airport-travel schema. It is revisable by material evidence/risk/context change and is not persistence authority, importance truth, Decision, or Action.
