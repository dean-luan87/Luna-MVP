# Cognitive Failure Injection Model v1

## Purpose

Define V0 negative cases for checking local correction and preventing overlearning. These are architecture test cases, not runtime tests.

| Case | Injected condition | Expected candidate response | Prohibited result |
| --- | --- | --- | --- |
| Experience error | historical pattern conflicts with current evidence | lower applicability and request current-evidence evaluation | experience overrides Reality |
| Schema match error | selected schema does not fit new context | weaken match and form alternative schema candidate | schema becomes truth or action |
| Attention error | focus omits a high-risk unknown | produce attention reallocation candidate | resource authority or forced action |
| Simulation error | simulated branch differs from observed outcome | retain deviation and revise branch support | future hypothesis becomes fact |
| Evaluation error | evaluation trace identifies unsupported weighting | create error-attribution and improvement candidates | evaluation self-certifies as truth |
| External anomaly | one exceptional outcome conflicts with stable pattern | preserve exception and require repeated validation | automatic overlearning or genome/culture mutation |

Failure is a traceable candidate for local correction, not a reason to replace the entire foundation.
