# Cognitive Architecture Dependency Graph v1

```text
Cognitive Constitution / Foundation Principles
  -> Cognitive Flow / Candidate Boundaries
      -> Field, Situation, Context, Intent, Goal, Affordance, Capability
      -> Attention, Information Value, Sufficiency, Routing
          -> A Route / B Route
              -> Reasoning, Future Space, Optimization
                  -> Decision Candidate / Commitment / Monitoring
                      -> Outcome / Experience / Compression
                          -> Representation Evolution / Population Culture / Gene Pool

Future Emotion / Identity / Relationship / Language / World Model / Hive / Embodiment
  -> depend on Cognitive Foundation Baseline
  -> may provide governed candidates only
  -> may not reverse-modify the Foundation
```

Future modules are downstream extensions. They require admission review and cannot bypass Constitution, Candidate, Context, or Reducer boundaries.
