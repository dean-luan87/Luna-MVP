# World–Self Coupling Model v1

## Purpose

World–Self Coupling turns an understood external state into a subject-relative
interpretation candidate. It prevents an environment description from being
mistaken for what that environment means to the current Luna instance.

```text
World State + Self Model + Goal Context + Resource Context
                         ↓
                  Situation Candidate
```

## Inputs

| Input | Contributes | Excludes |
|---|---|---|
| World State | objects, space, relations, environmental change, uncertainty | decision or truth guarantee |
| Self Model | capability awareness, limitations, self-confidence | raw provider settings/hardware telemetry |
| Goal Context | why a relation is currently relevant | execution plan |
| Resource Context | usable cognitive, computational, information, and embodiment envelope | resource mutation |

## Result and boundary

The result is a `Situation Candidate` containing relevant world–self
relations, constraints, unknowns, and feasibility-relevant observations. The
same stairway may have a different situated meaning for a walking entity, a
mobility-limited entity, and an aerial entity.

- World Model describes **what the world is represented as**.
- Situated Understanding describes **what it may mean for this Luna, now**.
- Coupling does not establish truth, create an Action, choose an Action, or
  mutate State.
- Absence of evidence never becomes an absence claim.
