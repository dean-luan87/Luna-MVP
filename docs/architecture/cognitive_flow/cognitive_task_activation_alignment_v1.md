# Cognitive Task Activation Alignment v1

Task Driven Activation Candidate maps active Goal, Intent, Mission, constraint, task phase, and completion condition to retained representations that may be relevant now.

Airport travel may activate Route Representation, Traffic Pattern, Time Constraint, and Risk Assessment candidates. Task completion may propose reduced activation or dormancy.

Task != Permanent Activation. Task activation does not create or override Goals, select Attention, decide, act, or retain information indefinitely.
