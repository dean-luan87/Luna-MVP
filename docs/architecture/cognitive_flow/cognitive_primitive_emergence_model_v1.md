# Cognitive Primitive Emergence Model v1

Candidate primitive emergence path:

`Raw Experience -> Repeated Pattern -> Representation Candidate -> Primitive Candidate -> Validation -> Adoption Candidate`.

A Primitive Candidate may be considered only when it can help explain historical phenomena, improve understanding efficiency, lower cognitive cost, or support prediction/decision quality candidates. Primitive Candidate is not Immediate Adoption, fact, rule, Self Rewrite, schema mutation, capability mutation, or state change.
