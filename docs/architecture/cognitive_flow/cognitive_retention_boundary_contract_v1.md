# Cognitive Retention Boundary Contract v1

## Required separation

- Retention != Memory Storage.
- Retention != Experience Storage.
- Retention != State Machine.
- Retention != Knowledge Base.
- Retention != Decision.
- Retention != Action.
- Retention != Attention.
- Reuse != Truth.
- Reuse != Skip Validation.
- Experience != Automatic Recall.
- Old Representation != Current Field.
- Frequency != Value.
- Popular Pattern != Truth.
- TTL != Sole Validity Authority.
- Future Module != Current Authority.
- Reducer remains the only State Mutation Authority.

## Future interfaces

Emotion may provide Retention Priority Adjustment Candidate; World Model may provide Field Prediction Candidate; Hive may provide Representation Candidate; Language may provide External Expression Interface; Embodiment remains disabled. None receives current Retention, Decision, Action, Permission, or State authority.

## Evolution boundary

Retention data may form Experience Evolution Candidates only through validation and repeated evidence. It cannot directly modify Cognitive Genome, Culture, Gene Pool, Constitution, Field State, or Reducer State.
