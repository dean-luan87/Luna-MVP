# Cognitive Affordance Understanding Model Definition v1

`CognitiveAffordanceCandidateV1` may retain object, spatial, social, task, risk, and resource affordance references together with field, primitive/concept, relationship, situation, context, goal, capability, role, uncertainty, provenance, and trace references.

It supports Unknown Affordance, Conflicting Affordance, Hidden Affordance, and Unsafe Affordance. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_behavior=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, `not_goal=true`, `not_identity=true`, and `not_memory=true`.
