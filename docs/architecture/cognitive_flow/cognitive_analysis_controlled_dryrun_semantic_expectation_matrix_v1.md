# A3 Controlled DryRun Semantic Expectation Matrix v1

This is a design-time semantic oracle for the eight frozen A3 fixture cases. `expected_status` is the immutable fixture-declared status; the listed semantic reason is independently derivable during a future approved regression phase. No Runner result is an authority for its own expectation.

| case_id | fixture_ref | expected_status | semantic_reason | required_evidence | blocker_condition |
| --- | --- | --- | --- | --- | --- |
| `case_01_supported` | `CognitiveAnalysisFixtureV1.case_01_supported` | fixture-declared `expected_status` | admitted input, supported hypothesis, sufficient context, and complete candidate-only result | admitted status; supported hypothesis; sufficient status; complete result; local references | any missing support/sufficiency signal, status mismatch, or execution/writeback flag |
| `case_02_competing` | `CognitiveAnalysisFixtureV1.case_02_competing` | fixture-declared `expected_status` | competing hypotheses remain unresolved; no dominant candidate may be forced | unresolved competing set; at least two member refs; null dominant candidate ref | a dominant candidate is set, members are invalid, or serialized status differs from fixture declaration |
| `case_03_contradicted` | `CognitiveAnalysisFixtureV1.case_03_contradicted` | fixture-declared `expected_status` | contradictory evidence with a reason prevents a complete conclusion | `contradicts` assessment; non-empty contradiction reason; non-complete result | contradiction evidence/reason absent, result becomes complete, or fixture declaration differs |
| `case_04_insufficient` | `CognitiveAnalysisFixtureV1.case_04_insufficient` | fixture-declared `expected_status` | insufficient Context blocks admission and therefore blocks the result | blocked admission; `context_insufficient` reason; blocked result | admission/result is treated as admitted or non-blocked, or required reason is absent |
| `case_05_revoked` | `CognitiveAnalysisFixtureV1.case_05_revoked` | fixture-declared `expected_status` | revoked evidence must be explicit and yields stale analysis output | revoked assessment; revoked lifecycle semantics; stale result | revoked evidence remains valid support, revocation signal is absent, or result is not stale |
| `case_06_temporal_unknown` | `CognitiveAnalysisFixtureV1.case_06_temporal_unknown` | fixture-declared `expected_status` | unknown temporal validity remains explicit and produces a provisional result | `temporal_validity_unknown` warning; provisional result; non-silent unknown preservation | unknown time is completed/suppressed, warning absent, or result is not provisional |
| `case_07_gap_request` | `CognitiveAnalysisFixtureV1.case_07_gap_request` | fixture-declared `expected_status` | an information gap may produce a candidate observation request but cannot execute it | refinement and request refs; `execution_admitted=false`; candidate-only lifecycle | missing refinement/request linkage or any observation execution admission |
| `case_08_writeback_denied` | `CognitiveAnalysisFixtureV1.case_08_writeback_denied` | fixture-declared `expected_status` | analysis output is not allowed to write State or cross the Decision boundary | `state_writeback_admitted=false`; `decision_boundary_admitted=false`; simulation-only result | State writeback/Decision admission, runtime execution, or fixture-status mismatch |

All rows additionally require traceable local references, immutable fixture serialization before/after validation, `runtime_executed=false`, and `simulation_only=true`.
