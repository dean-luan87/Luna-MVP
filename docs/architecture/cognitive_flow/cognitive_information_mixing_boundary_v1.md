# Cognitive Information Mixing Boundary v1

Mixed Information Processing may hold different source types together: current weather unknown, historical airport experience, airport-rule knowledge candidate, and tomorrow-congestion hypothesis candidate.

`Mixed Information != Mixed Truth`.

Mixing preserves each source’s evidence, uncertainty, confidence, applicability, time/context scope, and contradiction reference. External information does not become fact; Knowledge does not override Evidence; Experience does not override Current Observation; Simulation does not write Reality.
