# Cognitive Runtime Resource Boundary v1

Runtime resource candidates include Compute Budget, Memory Budget, Time Budget, Branch Budget, risk, task importance, and expected information value. A low-risk context may retain one small process; complex risk may request more branches.

Candidate outcomes include reduce, preserve, suspend, defer, or terminate a cognitive process candidate. They are not compute scheduling, Decision, Action, Permission, or State mutation.

Unlimited Thinking != Better Result. More Branches != Better Cognition.
