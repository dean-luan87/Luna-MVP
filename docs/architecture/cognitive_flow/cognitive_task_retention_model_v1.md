# Cognitive Task Retention Model v1

## Definition

Task Cognitive Retention Candidate describes the minimum cognitive set currently relevant to Goal, Intent, Mission, Constraint, Commitment, task phase, and expected outcome.

## Lifecycle

`Candidate -> Activated -> Maintained -> Updated -> Completed -> Released / Archived`.

Examples: airport navigation may retain Route Understanding, Traffic Situation, Arrival Constraint, and Risk Assessment candidates until the task completion condition changes. Completion or task change proposes release; it does not delete Memory, Experience, or history.

## Boundary

Task Retention != permanent retention, Decision, Action, Permission, State mutation, or Goal authority. It cannot create a task, override a Goal, or execute a commitment.
