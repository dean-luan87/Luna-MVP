# Spatio-Temporal Field Event Alignment v1

Field Event is a **Spatio-Temporal Field Transformation Candidate**, not merely a timestamped record:

`Before Field Condition -> Transformation Candidate -> After Field Condition`.

Before/after are traceable Field/Context/Spatial/Temporal candidate references, not State values or mutation commands. `Event Candidate != Fact` and `Event Candidate != State Mutation`. Admission and Reducer boundaries remain unchanged.
