# Learning Candidate Feedback Model v1

## Candidate-only influence

An Outcome/Experience-derived Learning Candidate may propose only review-bound future cognitive influence candidates:

- Pattern Update Candidate;
- Attention Adjustment Candidate;
- Hypothesis Prior Candidate; and
- Strategy Adjustment Candidate.

These are proposals for a future governed review/admission path. They do not modify the Cognitive Flow automatically.

## Prohibitions

Learning Candidate cannot modify Constitution, Field/Identity, Permission, Decision Policy, Reducer State, Model parameters, Memory, Case Library, Knowledge Base, or Hive. It cannot train a model or change current behavior.
