# Cognitive Capability Awareness Model Definition v1

`CognitiveCapabilityAwarenessCandidateV1` may retain affordance, situation, context, cognitive-state, resource, experience, capability-dimension, limitation, uncertainty, confidence-boundary, provenance, and trace references.

It supports Unknown Capability, Partial Capability, Temporary Capability Loss, and Capability Conflict. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_self_model=true`, `not_identity=true`, `not_personality=true`, `not_emotion=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
