# A-Route Integrity Checklist v1

Use this checklist as an architecture and fixture-review instrument. A failed
item is a gap candidate, not an automatic defect classification or State change.

| ID | Integrity check | Pass condition |
|---|---|---|
| I-01 | Original purpose remains traceable | Brain Intent, non-negotiable objective, and required evidence remain linked |
| I-02 | No sub-goal substitution | model metric, capability detail, or local efficiency does not replace intent |
| I-03 | Self and World are coupled | Situation references both World State and Self Capability Context |
| I-04 | Unknown is preserved | missing Evidence is not represented as a fact |
| I-05 | Confidence is proportionate | Decision Confidence exposes unsupported assumptions |
| I-06 | Decision is current-context grounded | Goal, resource, risk, and current Reality are traceable |
| I-07 | Outcome is situated | past decision review uses Past Available Context, not later knowledge |
| I-08 | Attribution is localized | perception, understanding, capability, decision, execution, world, random, and Unknown stay distinguishable |
| I-09 | Capability envelope is respected | unavailable capability produces limitation or help-request candidate |
| I-10 | Experience adoption is governed | one event is an Experience Candidate; repeated validation precedes Adoption |
| I-11 | Brain authority is retained | no Provider, Middleware, Attention, Experience, or emotion interface selects the decision |
| I-12 | A/B boundary holds | A exports experience/outcome/failure/value candidates, never personality, worldview, or life goals |
| I-13 | Self continuity is represented | condition changes adjust context without replacing Luna identity |

## Required trace anchors

Each reviewed fixture should retain: `intent_ref`, `self_context_ref`,
`world_context_ref`, `situation_ref`, `attention_ref`, `evidence_refs`,
`decision_ref`, `outcome_ref`, `attribution_ref`, `experience_candidate_ref`,
and `unknown_factors`.
