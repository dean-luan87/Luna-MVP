# Prediction–Outcome Alignment Model v1

## Purpose

Prediction–Outcome Alignment compares an expected outcome candidate associated
with a Decision Candidate against governed Outcome Evidence. It identifies
difference candidates; it does not immediately modify a model, strategy, or
belief.

```text
Decision Candidate
        ↓
Expected Outcome Candidate
        +
Outcome Evidence Candidate
        ↓
Difference Analysis Candidate
        ↓
Prediction Error Candidate
```

## Difference dimensions

- expected versus observed goal progress;
- expected versus observed resource cost;
- assumed versus represented environment condition;
- missing observation or temporal mismatch;
- unexpected event or uncertainty increase.

Example: a route predicted as fastest but observed as congested creates a
Prediction Error Candidate. It does not establish that the route model was
wrong, because perception, understanding, execution, and environment-change
explanations remain possible.
