# Cognitive Feedback Evolution Alignment v1

`Feedback Candidate -> Validation -> Repeated Evidence -> Evolution Candidate -> Adoption Candidate -> Future Cognitive Guidance Candidate`.

Feedback can propose future attention/schema/representation/evaluation guidance but cannot directly modify Genome, Culture, Gene Pool, Constitution, Field/Reducer State, model parameters, Decision, or Action.

Frequency != Value. Repeated outcome != universal applicability. Adoption != automatic rewrite.
