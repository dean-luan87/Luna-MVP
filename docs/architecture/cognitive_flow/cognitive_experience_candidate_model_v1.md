# Cognitive Experience Candidate Model v1

Experience Candidate may preserve references to Context, Field, Goal, Decision Trace Candidate, Action Trace Candidate, Outcome Candidate, Success/Failure Evaluation Candidate, Applicable Condition Candidate, Exception Condition Candidate, Confidence Candidate, provenance, and trace.

Success/Failure is an outcome evaluation candidate, not proof that reasoning was correct or wrong. Experience is not Memory, Fact, Knowledge, Truth, Rule, Decision Authority, or Automatic Shortcut.
