# Cognitive World Understanding / Attention Alignment v1

Current World Understanding is upstream of cognitive attention because the same evidence has different relevance in different situations.

```text
Evidence Field -> Situation / Current World Understanding Candidate
  -> Attention Allocation Candidate -> Workspace
```

An exit sign may have different priority near a metro entrance, in a mall, or in an airport. Understanding guides an Attention Candidate; it does not decide evidence truth, resource authority, Decision, or Action.
