# Field State Ontology Definition v1

Field State contains governed Field Identity/context/relations; Spatial Structure (entity relation, topology, boundary, accessibility, organization); Temporal Existence (valid time, duration/stage, evolution/history references); Concept Structure (current meaning/pattern references); Task/Goal/User/Attention Context; and Source/Evidence/Admission/Event provenance traces.

Current Field View is a contextual query expression derived from Field State and may include Candidate Overlay. It is never Field State or a State source. Field Kernel organizes/query-represents State but does not mutate it.
