# Cognitive Genome and Culture Boundary v1

Slow Evolution concerns Cognitive Genome Evolution candidates: long-cycle, high-threshold, foundational-structure impact candidates. Fast Evolution concerns Culture/Pattern Evolution candidates: context-specific, reversible, locally adaptive candidates.

Culture Evolution is not Genome Evolution. Fast culture/pattern candidates cannot modify Cognitive Genome, and genome-evolution candidates cannot be created through frequency, popularity, or automatic individual/pool aggregation.
