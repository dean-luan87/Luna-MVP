# Cognitive Attention Authority Boundary Model v1

Cognitive Attention Controller may aggregate attention requests and issue an Active Cognitive Allocation Candidate. It may propose budget, depth, direction, duration, persistence, and route-admission candidates.

It may not judge facts, generate knowledge, modify evidence/experience, choose a goal, select an action, issue permission, mutate state, or execute a route.

Attention Authority != Intelligence Authority. Allocation governance is separate from Reality/Evidence/Understanding/Evaluation authority.
