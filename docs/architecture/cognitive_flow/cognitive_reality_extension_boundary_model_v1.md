# A-Route Extension Boundary Model v1

## Belongs to A Extension

An extension belongs to A when it improves represented reality understanding, current self capability/resource context, situated meaning, decision support, or outcome feedback.

```text
Reality Understanding Enhancement
        ↓
Situation Enhancement Candidate
        ↓
Decision Support Candidate
        ↓
Feedback / Experience Candidate
```

## Does not belong to A

| Concern | Correct ownership |
|---|---|
| Which role/perspective should the subject take? | Brain Perspective Management |
| How do multiple reality processes coexist and coordinate? | Cognitive Process Ecology / Assembly |
| How is life meaning explored? | B Reflective Cognition / Emotional Cognition |
| How does personality grow? | Emotional Cognition / B |
| How are A and B globally integrated? | future Context Integration |

No extension may alter the A Core Constitution, A/B Boundary, Brain Authority, or Decision Boundary.
