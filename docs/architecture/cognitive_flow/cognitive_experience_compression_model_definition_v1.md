# Cognitive Experience Compression Model Definition v1

`CognitiveExperienceCompressionCandidateV1` may retain Experience Candidate, event/decision/action trace candidate, context, field, goal, outcome, condition, exception, pattern, strategy, maturity, representation, guidance, provenance, and trace references.

Any Action Trace is a historical candidate reference only; this layer cannot execute, create, or authorize Action. Outputs remain `candidate_only=true`, `not_fact=true`, `not_memory=true`, `not_knowledge=true`, `not_truth=true`, `not_rule=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_state_mutation=true`.
