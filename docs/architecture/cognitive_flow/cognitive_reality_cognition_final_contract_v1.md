# A-Route Reality Cognition Final Contract v1

## Core responsibility

Reality Cognition System is Luna's stable A-route foundation.

- It understands represented reality through governed Evidence and World State.
- It provides Self Capability and limitation-aware context.
- It forms self-situated Situation Candidates.
- It forms reality-bound Decision Candidates for Brain judgment.
- It receives future Outcome references and forms feedback/Experience Candidates.

## Explicit non-responsibility

Reality Cognition System does not own Personality formation or value creation.
It does not own long-term life direction, open-ended imagination, or B Reflection.
It does not execute Actions, control hardware, operate a Runtime, self-modify, or mutate State.

## Final contract

All core outputs remain candidates.
Experience uses only the governed handoff interface.
Experience never directly updates Self, Strategy, or Decision.
Reducer remains the sole State mutation authority.
