# Reality Workspace + Neural + Middleware Operating Model v1

## System position

```text
Brain / Cognitive Rules
          ↓
Reality Workspace ←→ Neural System
          ↓              ↓
   World / Self State   Escalation Candidate
          ↓              ↓
       A Route       Brain Evaluation
          ↑
      Middleware
          ↑
Capability Registry / Model Manager / Protocol Manager / Diagnostics / Resources
```

Reality Workspace is Luna's current world-state operating space. Neural System is
the automatic regulation and monitoring layer. Middleware is the capability and
resource governance interface. None of these layers replaces Brain authority.

## Normal operating loop

```text
Capability
  ↓
Evidence
  ↓
Reality Workspace
  ↓
Neural Processing
  ↓
Workspace Update
  ↓
continue bounded loop
```

The loop maintains Immediate State, Working Reality, and Stable Reality Pattern.
It refreshes facts and monitoring projections without making an Action or
changing a Goal.

## Dual drivers

Brain Driven Observation begins with an Attention Intent and a cognitive
requirement. Neural Driven Monitoring observes governed projections for health,
change, conflict, unknown growth, and resource anomalies. Both drivers return
candidates through governed contracts; neither bypasses Reality Workspace,
Middleware, or Brain.

## Abnormal and capability loops

An anomaly may produce:

```text
Reality Workspace
  ↓
Unknown / Risk / Conflict Candidate
  ↓
Neural Escalation Candidate
  ↓
Situation Candidate
  ↓
Brain Decision Evaluation
```

When a capability is insufficient:

```text
Neural
  ↓
Capability Requirement
  ↓
Middleware Governance
  ↓
Capability Selection Candidate
  ↓
Evidence
  ↓
Reality Workspace
```

Neural does not select a provider directly, and Middleware does not interpret the
world.

## Task as cognitive object

Task is a Reality Workspace cognitive object alongside entities, events, and
resources. A task may be represented as a Task Thread, but it is not the highest
authority and it cannot bypass Survival Constitution, Brain, or A Route.
