# Cognitive Decision and Execution Boundary Contract v1

## Required separation

Understanding, Candidate, Evaluation, Decision Candidate, Commitment Candidate, Human/External Execution Boundary, Reality Observation, Outcome, and Experience remain separately governed.

## Negative guards

- Decision Candidate != Decision.
- Decision Support != Human Choice.
- Commitment != Action.
- Commitment != Permission.
- Commitment != Execution Guarantee.
- Luna != Human Action Authority.
- Human Choice != Luna Control.
- Prediction != Reality.
- Candidate != Reality Change.
- Outcome != Decision Correctness.
- Error Recovery != History Erasure.
- Future Permission Candidate != Permission.
- Embodiment != Autonomous Execution Authority.
- Reducer remains the only State Mutation Authority.

No Cognitive Flow module may directly execute action, grant permission, modify reality, or mutate State.
