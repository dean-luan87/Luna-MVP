# Cognitive State Transition Boundary Contract v1

- Snapshot != State.
- Snapshot != Reality State.
- Transition != Command.
- Transition != Decision.
- Transition != Action.
- Transition != Permission.
- Transition != Reality Mutation.
- Transition != Memory Mutation.
- Experience != Transition Authority.
- Transition != Learning.
- Transition != Schema Mutation.
- Transition != Representation Mutation.
- Transition != Genome Mutation.
- Transition != Culture Mutation.
- Reasoning Mode Transition != B Route Execution.
- Next Cognitive Snapshot Candidate != Persistent State.
- Reducer remains the only State Mutation Authority.

Retention and Activation only provide candidate references. Cognitive Runtime may use a next snapshot candidate for a future tick but does not own persistent system state.
