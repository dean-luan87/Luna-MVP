# Cognitive Composition Operation Model v1

Composition Operation Candidate combines representations/schemas/constraints into a larger scenario candidate, such as weather + traffic + airport forming adverse-weather airport-risk candidate.

Decomposition is its complementary candidate operation: a complex object like airport travel may be organized into preparation, leaving home, transport, security, and boarding candidates.

Composition / Decomposition != Reality, Fact, Decision, Action, Permission, or State mutation.
