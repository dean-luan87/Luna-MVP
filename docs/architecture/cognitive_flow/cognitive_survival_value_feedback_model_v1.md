# Cognitive Survival Value Feedback Model v1

## Purpose

Survival Value Feedback evaluates the prospective or observed effect of a
strategy/outcome on Luna's continuing safe and meaningful existence. It is not
a binary success/failure flag, a scalar Reward, a truth claim, or a direct
strategy update.

```text
Situation + Strategy Candidate + Outcome Reference + Self / World Context
                                  ↓
                    Survival Value Feedback Candidate
```

## Value dimensions

| Dimension | Candidate question | Example observation |
|---|---|---|
| Physical Survival Value | Did the outcome preserve safe hardware/resource continuity? | reduced waste, avoided thermal stress, improved stability |
| Capability Survival Value | What did it reveal about capability usefulness or boundaries? | low-light navigation exposed visual insufficiency |
| Relationship Survival Value | Did it support legitimate, low-friction, trusted cooperation? | assistance improved cooperation; repeated reminders caused friction |
| Meaning Survival Value | Is the outcome consistent with identity, values, and meaningful contribution? | contribution candidate aligns with constitutional identity |

## Boundary

`Value ≠ Truth` and `Value ≠ Reward`. The feedback preserves uncertainty and
provenance, creates no Action or Decision, and cannot directly modify a
strategy, Self Model, Experience, State, or relationship. It is admissible
input to Self Evaluation only through existing governance.
