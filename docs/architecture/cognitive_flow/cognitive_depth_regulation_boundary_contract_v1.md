# Cognitive Depth Regulation Boundary Contract v1

Allowed future inputs are Context, Survival, Risk, Time, Information Value, Attention, Experience/Library Pattern, uncertainty, provenance, and trace references.

Every future output remains `candidate_only=true`, `not_fact=true`, `not_state=true`, `not_decision=true`, `not_action=true`, and `not_memory=true`.

Frozen boundaries: Attention != Depth; Depth != Decision; Depth != Action; Experience != Automatic Shortcut; Knowledge != Authority; Confidence != Permission. A Depth Controller cannot call Action, Experience cannot bypass Cognitive Flow, Library cannot replace local judgement, Model Output cannot directly trigger Depth, and Depth cannot modify Field State.
