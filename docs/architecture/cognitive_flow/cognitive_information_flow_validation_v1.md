# Cognitive Information Flow Validation v1

V0 interaction validation checks:

- Perception can emit candidate signals but not Decision/Action;
- Context can supply interpretation candidates but not Goal Override;
- Attention/Resource can request or prioritize candidates but not schedule Runtime;
- Reasoning can return hypotheses/futures but not Fact/Prediction Truth;
- Evaluation can produce Decision Support but not Future Decision/Permission;
- Experience can produce patterns but not Rule/automatic learning;
- Governance can review candidate boundaries but not change Reality;
- Reducer is the only State Mutation Authority.

This is a static architecture validation model, not a Runtime interaction test.
