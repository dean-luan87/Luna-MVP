# Survival Boundary and Cognitive Flow v1

## Flow alignment

The existing flow remains unchanged:

`External Capability -> Evidence -> Translation -> Primitive -> Concept -> Field Representation -> Current Cognitive Context -> Field Kernel / Current Field View -> Field Event Candidate -> Admission -> Reducer -> World State`

Survival relevance is a future candidate-filtering concern inside Cognitive Flow. It does not bypass Evidence, Translation, Candidate lifecycle, Admission, or Reducer.

## Field alignment

`Survival Constitution Foundation -> Field Identity -> Field Affordance -> Behavior Boundary -> Action Candidate`

Field Identity expresses stable Field constraints; Affordance expresses identity-constrained possibilities; Behavior Boundary expresses current contextual constraints. Survival Constitution describes how Luna treats these inputs under risk and uncertainty. It cannot mutate Identity, Affordance, State, Event, Snapshot, or Context.

## Authority boundary

Survival Drive has no Decision Authority, Action Authority, Permission Authority, Fact Authority, or State Mutation Authority. A future Action Candidate must separately satisfy its own Decision, Permission, and Admission governance. Reducer remains the only Field State mutation authority.

## Unknown-environment adaptation

`Unknown Field -> Constraint Understanding -> Safe Behavior Space Candidate -> Exploration Candidate -> Identity Expansion Candidate`

No unknown status can automatically stop all behavior, infer a missing identity, generate an Action, or make a model prediction authoritative.
