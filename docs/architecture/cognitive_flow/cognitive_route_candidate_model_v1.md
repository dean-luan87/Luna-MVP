# Cognitive Route Candidate Model v1

Route candidates describe candidate cognitive paths:

- A Route Candidate: fast cognition where information appears sufficient, risk low, pattern clear, or time short;
- Pattern Match Candidate: a governed similar-experience/knowledge path may be considered;
- Exploration Candidate: information is insufficient and acquisition value may be high;
- Deep Reasoning Candidate: high risk, value, uncertainty, conflict, or long-term impact may justify B-route consideration;
- Deferred Reasoning Candidate: information insufficient, value low, or cost too high.

Routes are not answers, intelligence levels, decisions, actions, permissions, or runtime calls.
