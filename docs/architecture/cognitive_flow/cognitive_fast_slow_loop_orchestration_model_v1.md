# Cognitive Fast / Slow Loop Orchestration Model v1

## Fast loop candidate

Current Field / Context / Attention / Sufficiency / Routing / Candidate Evaluation support within a current cognitive need window. It may request immediate re-observation or cognitive interrupt candidates but cannot execute a safety action.

## Slow loop candidate

Outcome / Experience / Compression / Representation / Evolution candidates support later governed adaptation. It does not change a live fast-loop context, candidate, constitution, or State automatically.

## Coordination contract

Fast Loop may emit trace and outcome references to Slow Loop. Slow Loop may later offer context-bound representation or activation candidates to Fast Loop only through local validation. Fast Loop != Learning; Slow Loop != Runtime override.
