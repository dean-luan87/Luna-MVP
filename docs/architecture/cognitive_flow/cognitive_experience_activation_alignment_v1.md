# Cognitive Experience Activation Alignment v1

Experience Match may provide an Activation Candidate when a context-bound historical pattern is relevant, such as rain + slope + elderly person supporting a safety pattern candidate.

Experience Guided Activation requires Current Context Match and Validity Check. It can raise candidate priority or suggest resource allocation, but cannot supply truth, authority, automatic recall, Decision, Action, or Permission.

Experience != Authority. Experience != Truth. Similarity != Applicability.
