# Fast / Normal / Deep Decision Path Model v1

## Path selection candidates

| Path | Candidate admission characteristics | Output boundary |
|---|---|---|
| Fast Path | time-sensitive, high evidence consistency, known capability fit, repeated validated pattern | fast Decision Evaluation Candidate; not an Action |
| Normal Path | ordinary trade-off with manageable uncertainty | standard candidate comparison |
| Deep Evaluation Path | high impact, unresolved conflict, long-horizon or identity/value relevance | expanded evidence/option/reflection candidate request |

Fast does not mean simple or less governed. It means lower-cost candidate
formation when a context-bounded, repeatedly validated pattern exists. It
cannot bypass the Survival Constitution, Brain judgment, missing-information
handling, or the no-Action boundary.

No path creates a Scheduler, automatic Provider call, automatic Attention
mutation, autonomous action, or State change.
