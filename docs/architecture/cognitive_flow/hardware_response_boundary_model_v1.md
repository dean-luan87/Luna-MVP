# Hardware Response Boundary Model v1

| Layer | Boundary |
|---|---|
| Brain | Does not know/control specific devices. |
| Neural | Proposes cognitive/temporal requirements only. |
| Middleware | Coordinates capability and resource feasibility only. |
| Hardware Protocol | Governs power, stream, calibration, health, and hot-plug operations. |
| Hardware | Executes device-local behavior. |

Hardware Protocol has no Goal, Truth, Decision, or cognitive-completion authority.
