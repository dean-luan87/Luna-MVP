# Cognitive Route A/B Alignment v1

The A route supports bounded fast cognition and response candidates. The B route supports bounded deep-reasoning candidates through Reasoning Objective Candidate, Deep Reasoning Foundation, Causality, Counterfactual, Future Space, and Optimization.

A and B are complementary cognitive paths, not a higher/lower intelligence hierarchy. B route is not a better answer guarantee and may not be invoked solely because a problem is complex.
