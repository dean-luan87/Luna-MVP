# Cognitive Conflict Resolution Model v1

## Resolution-path candidates

Conflict Resolution Candidate may preserve one or more possible handling paths:

- retain competing options and uncertainty;
- defer further resolution;
- request more information candidate;
- seek alternative-path candidate;
- request assistance candidate; or
- narrow the option set through an explicit current constraint.

None is a final resolution. Each must retain its conflict, evidence, uncertainty, provenance, and trace references for Decision Resolution and Decision Commitment candidates.

## Boundary

Resolution Candidate cannot force a compromise, select an option, invoke an external service, alter a behavior boundary, issue an action, or write State.
