# Cognitive Attention Evolution Interface v1

Future Attention Evolution consumes only validated Attention Pattern Adjustment Candidates and returns Future Attention Guidance Candidates, never a direct allocation write.

```text
Validated Pattern Adjustment Candidate -> Future Attention Guidance Candidate
  -> Attention Candidate Pool
```

Frequency != Value. Repetition != Importance. Novelty != Relevance. Risk != Probability. Low-frequency high-risk candidates remain eligible for preservation.
