# Cognitive Subsystem Boundary Definition v1

The seven subsystem views are Perception & Situation Understanding; Context & Intent Understanding; Attention & Cognitive Resource Management; Reasoning & Future Simulation; Evaluation & Decision Support; Experience & Representation Evolution; and Cognitive Governance.

Subsystems group responsibilities for architecture comprehension only. Grouping does not merge module authority, alter module contracts, introduce Runtime calls, or permit a subsystem to hold Understanding, Decision, Action, and Authority together.

Independent boundaries:

- Field: world-description foundation;
- Reducer: sole State Mutation Authority;
- Emotion: future independent value-modulation layer;
- Hive: future independent population-exchange boundary.
