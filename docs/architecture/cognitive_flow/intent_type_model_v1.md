# Intent Type Model v1

Intent type candidates may include:

- Explicit Intent: user-stated purpose;
- Implicit Intent: possible context-supported purpose;
- Assistance Intent: desired assistance form;
- Constraint Intent: a possible implicit limit;
- Exploration Intent: desire to explore, understand, or compare;
- Unknown Intent: unresolved purpose.

Types are candidate classifications, not commands, goals, emotions, personality attributes, decisions, actions, or permissions.
