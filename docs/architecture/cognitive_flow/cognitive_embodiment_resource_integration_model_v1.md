# Cognitive–Embodiment Resource Integration Model v1

| Resource | Owner |
|---|---|
| Cognitive | Neural Governance |
| Computational | Middleware |
| Information | Neural Governance candidates |
| Embodiment: battery, thermal, device life, sensor occupancy | Hardware Governance / Protocol candidates |

Embodiment resource state may become a State Signal through Middleware/Neural boundaries. It cannot directly enter Memory, alter Attention, or override Brain intent.
