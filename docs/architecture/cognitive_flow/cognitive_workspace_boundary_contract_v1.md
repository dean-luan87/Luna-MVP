# Cognitive Workspace Boundary Contract v1

- Workspace != Memory.
- Workspace != Knowledge Storage.
- Workspace != Reality State.
- Workspace != Decision Space.
- Workspace != Decision.
- Workspace != Action.
- Workspace != Permission.
- Workspace != State Mutation.
- Workspace != Cognitive Runtime Environment.
- Workspace != Attention.
- Workspace != Schema.
- Workspace cannot request unlimited Attention.
- Workspace Close != Memory Delete.
- Workspace Experience != Immediate Learning.
- Simulation Cannot Replace Workspace.
- Workspace Bigger != Better Cognition.
- Reducer remains the only State Mutation Authority.

Emotion may offer focus-tendency candidates; World Model may offer simulation candidates; Hive may offer schema candidates; Language may offer expression interfaces; Embodiment remains disabled. None controls Workspace or gains Decision/Action/State authority.
