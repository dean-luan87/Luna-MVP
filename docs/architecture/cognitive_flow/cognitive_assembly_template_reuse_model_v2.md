# Assembly Template Reuse Model v2

An Assembly Template retains reusable organization structure: member patterns, parallel/dependency/competitive relations, required capability categories, resource profile candidates, and observed failure patterns.

```text
Validated Assembly Experience
→ Assembly Template Candidate
→ Future Fast Activation Candidate
```

Templates do not save member Runtime state, auto-create an Assembly, override current evidence, or select Providers. They remain subject to current Intent, Context, capacity, and admission candidates.
