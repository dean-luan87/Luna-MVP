# Cognitive Authority Matrix v2

| System | May produce | Must not produce |
|---|---|---|
| Perception | Observation/Field/Situation/Affordance candidates | Decision, Fact, Action |
| Context | Context/Intent/Goal candidates | Goal Override, Decision, Action |
| Attention & Resource | Focus/Value/Sufficiency/Resource candidates | Knowledge change, Runtime schedule, Action |
| Reasoning & Future | Hypothesis/Causal/Counterfactual/Future candidates | Fact, Prediction Truth, Decision/Action |
| Evaluation & Decision Support | Value/Trade-off/Decision Support/Commitment candidates | Future Decision, Permission, Action |
| Experience & Evolution | Experience/Pattern/Representation/Culture candidates | Rule, automatic learning, State mutation |
| Governance | admission/rejection/deferment/drift-review candidates | Reality change, Runtime gate, Reducer replacement |
| Reducer | State mutation through governed admitted path only | Cognitive judgment, Hypothesis, Evaluation, Decision |

Every non-Reducer system is Candidate-only. Reducer remains the only State Mutation Authority.
