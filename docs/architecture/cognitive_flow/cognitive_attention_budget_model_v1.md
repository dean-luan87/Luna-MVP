# Cognitive Attention Budget Model v1

Attention Budget Candidate represents a bounded share of current cognitive capacity, not CPU scheduling or a resource-state command.

Example candidate allocation for an airport boarding context:

```text
navigation schema: 40
time risk: 30
luggage check: 20
commercial information: 5
other: 5
```

Budget Candidate expresses proposed relative investment under current risk, time, resource, and goal constraints. Attention Budget != Runtime Scheduler, Resource Authority, Decision, or Action.
