# Cognitive Reasoning Value Assessment Model Definition v1

`ReasoningValueCandidateV1` may retain potential-benefit, risk-reduction, decision-impact, uncertainty-reduction, reasoning-cost, time-constraint, reversibility, experience-availability, context, attention, information-value, provenance, and trace references.

It may express `shallow_reasoning`, `pattern_match`, `deep_reasoning_candidate`, `defer_reasoning`, or `abandon_reasoning` as cognitive allocation candidates. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
