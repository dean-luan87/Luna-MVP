# Cognitive Information Source Model v1

## Cognitive Information Source Candidate

Sources may include:

1. Self Observation Candidate
2. Experience / Compression Candidate
3. Knowledge Candidate
4. External Information Candidate (future interface)
5. Simulation Output Candidate
6. Human Input Candidate

Every source reference retains source identity, evidence, confidence, applicability, time scope, context scope, provenance, and trace. Source != Truth, Fact, Decision, Action, Permission, or State authority.
