# Cognitive Experience Compression Boundary Contract v1

## Allowed candidate references

Governed Outcome, Experience, Context, Field, Goal, Decision/Action trace candidates, conditions, exceptions, Sufficiency/Routing, provenance, and trace references may be read.

## Rejected inputs and effects

Memory Runtime, Memory write, Learning Runtime, Hive sharing, training, autonomous learning, Emotion Engine, Personality, Language Generation, raw model/provider output, Decision result, Action command, permission, State handle, Reducer command, and State mutation are outside this layer.

## Negative guards

- Experience Compression != Data Compression.
- Experience != Memory.
- Experience != Fact.
- Experience != Knowledge.
- Experience != Truth.
- Experience != Rule.
- Experience != Decision Authority.
- Experience != Automatic Shortcut.
- Representation != Natural Language.
- Guidance != Routing Authority.
- Guidance != Decision.
- Guidance != State Mutation.
- Success != Correct Reasoning.
- Failure != Wrong Reasoning.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not memory, not knowledge, not truth, not rule, not decision, not action, not permission, and not state mutation.
