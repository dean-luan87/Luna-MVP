## Position

`Context -> Goal -> Schema Candidate Pool -> Attention Evaluation Candidate -> Active Schema Set Candidate -> Workspace -> Reasoning`.

Cognitive Attention allocates limited conscious cognitive resources to representations and schemas relevant now. It is distinct from Observation Attention, which selects sensory regions/objects. Attention != Decision, importance truth, reality value, Action, Permission, or State mutation.

## Attention Control alignment

Attention Selection remains a distributed source of Attention Candidates. It does not independently allocate the shared cognitive budget. `Phase-Cognitive-Attention-Control-Architecture-Planning-v1-001` introduces a Cognitive Attention Controller that aggregates this and other candidate sources before emitting an Active Cognitive Allocation Candidate.
