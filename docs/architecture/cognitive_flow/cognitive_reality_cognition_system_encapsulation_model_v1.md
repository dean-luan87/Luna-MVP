# Reality Cognition System Encapsulation Model v1

## System identity

`Reality Cognition System` is the encapsulated A-route cognitive organ through
which Luna forms reality-grounded, self-situated understanding and future
decision/outcome-feedback candidates. It is an architecture system boundary,
not a Runtime process, independent agent, Action executor, or State owner.

```text
Reality Cognition System
├── World Understanding
│   ├── Evidence
│   ├── Reality Representation
│   └── World State
├── Self Understanding
│   ├── Self Model
│   ├── Capability Awareness
│   └── Limitation / Resource Context
├── Situation Understanding
├── Decision Formation
│   ├── Option Generation
│   ├── Decision Evaluation
│   └── Decision Candidate
├── Action Feedback
│   ├── Execution Boundary
│   ├── Outcome Observation
│   └── Prediction Alignment
└── Adaptation Feedback
    ├── Value Feedback
    ├── Experience Candidate
    └── Future Improvement Candidate
```

The system reuses the existing A Route Constitution and layer-map assets. Its
encapsulation boundary prevents other systems from treating internal modules
as ungoverned services.
