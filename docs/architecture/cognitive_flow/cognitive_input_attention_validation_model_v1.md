# Cognitive Input Attention Validation Model v1

The controlled intersection fixture creates 100 visual observations. Traffic lights, vehicles, and the intersection receive high input-attention priority; walls, advertisements, and decorations remain background.

Only the 15 high-priority evidence candidates are admitted. The 85 background candidates remain suppressed for this cycle, not deleted or declared false.

This validates Input Attention as a candidate filter, not a sensor-control command or truth mechanism.
