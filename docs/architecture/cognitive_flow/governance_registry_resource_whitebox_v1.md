# Governance Registry and Resource Whitebox v1

```text
Brain / Cognitive Rules
          ↓
Process + Intent + Resource Need
          ↓
Neural Regulation Candidate
          ↓
Resource Manager
          ↓
Authority Manager + Registry System
   ┌──────────┬──────────┬──────────┬────────────┐
   ↓          ↓          ↓          ↓
Capability  Model     Hardware   Diagnostics
 Registry   Registry  Registry
   └──────────┴──────────┴──────────┴────────────┘
                     ↓
            Self Awareness Infrastructure
                     ↓
            Self Capability Context
                     ↓
              Brain Awareness / A Route
```

```text
Capability Requirement
        ↓
Registry Admission
        ↓
Provider / Hardware Selection Candidate
        ↓
Evidence or Health State Candidate
        ↓
Reality Workspace / Self Model
```

Registry and manager layers describe and govern resources. They do not interpret
Reality, create Goals, choose Actions, or directly mutate State.
Capability Registry, Model Registry, and Hardware Registry remain infrastructure
records and do not become a cognitive subject.
