# Situated Outcome Interpretation Model v1

```text
Outcome Evidence + Original Intent + Past Decision Context + Self Capability Context + World Context
        ↓
Outcome Interpretation Candidate
```

Outcome != Success / Failure. Outcome Interpretation Candidate contains Expected
Result, Actual Result, Difference Candidate, Impact Candidate, Confidence
Candidate, Unknown, and trace references.

Past Decision Evaluation must use Past Available Context. Later information
cannot retroactively make an earlier bounded decision wrong. A correct decision
may have a bad outcome after environment change; a risky decision may have a
good outcome without becoming a good strategy.
