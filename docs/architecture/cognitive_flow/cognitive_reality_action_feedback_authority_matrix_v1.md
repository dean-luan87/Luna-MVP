# Reality Action Feedback Loop Authority Matrix v1

| Module | Permitted responsibility | Explicitly prohibited |
|---|---|---|
| Brain | decision judgment and future evaluation boundary | Action execution, direct State mutation |
| Action Execution Boundary | describe request/status/outcome handoff candidates | execute/control hardware or create scheduler |
| Outcome Observation | organize post-boundary evidence candidates | success verdict, correction, State mutation |
| Prediction–Outcome Alignment | form difference/prediction-error candidates | immediate model/strategy change |
| Failure Analysis | classify possible causes with uncertainty | blame, truth claim, direct correction |
| Neural Governance | organize feedback and adaptation candidates | replace Brain or execute Action |
| Middleware | provide capability/resource/execution-status information | cognitive evaluation or decision authority |
| Experience System | consolidate governed feedback candidates | automatic learning or direct strategy/Self change |
| B Reflection | future strategy-improvement candidate | direct current A control or past rewrite |
| Reducer | sole State mutation authority | infer, evaluate, execute, self-authorize mutation |

No module receives real execution Runtime, hardware control, automatic
decision execution, provider invocation, reinforcement learning, or automatic
state-modification authority in this phase.
