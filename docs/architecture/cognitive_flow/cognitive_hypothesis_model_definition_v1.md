# Cognitive Hypothesis Model Definition v1

A future Cognitive Hypothesis Candidate contains hypothesis type, target Field/reference, supporting evidence reference, contradicting evidence reference, uncertainty, confidence candidate, validation need, provenance, and trace.

Types are Field Identity, Object Function, Behavior Pattern, Risk, Relationship, and Goal Context hypotheses. Each can coexist with conflicting alternatives and must retain its own evidence and uncertainty.

`Hypothesis -> Validation Candidate`, never `Hypothesis -> Fact`.
