# Possible Future Space Model Definition v1

`PossibleFutureSpaceCandidateV1` may contain Current State Reference, Branch Candidate, Trigger Condition, Supporting/Contradicting Evidence, Survival Impact, Value, Cost, Reversibility, Uncertainty, Provenance, and Trace.

Each branch remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
