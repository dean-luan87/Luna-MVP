# Reality Decision Formation Model v1

## Purpose

Reality Decision Formation is the A-route process for comparing possible
reality-bound choices after Luna has formed World, Self, and Situation
understanding. It does not perform an Action, control hardware, invoke a
Provider, or mutate State.

```text
Situation Candidate
        ↓
Option Generation Candidate Set
        ↓
Decision Evaluation Candidates
        ↓
Decision Candidate
        ↓
Brain Evaluation / Approval Candidate
        ↓
Neural Organization Candidate
        ↓
Future Execution Candidate Boundary
```

## Separation contract

| Layer | Question | Explicitly not |
|---|---|---|
| Situation Understanding | What is currently represented as the case? | Decision, Action, Outcome |
| Decision Formation | Which option appears more appropriate under current constraints? | Action execution or State mutation |
| Action Execution | How would an admitted choice be carried out? | in scope for this phase |
| Outcome | What occurred after a future action? | assumed or fabricated by Decision Formation |

All outputs remain candidates. Brain retains the final decision judgment
boundary. Neural only organizes the cognitive process after a candidate;
Middleware only supplies feasibility/resource information.
