# Cognitive Mode Switching Architecture Plan v1

## Position

Cognitive Mode Switching is a candidate-only cognitive-resource coordination layer. It derives a possible cognitive mode from Survival Pressure, Field Dynamics, Current Context, Goal, Information Value, Time Budget, Experience Match, and provenance.

`Survival Constitution -> Field Dynamics -> Current Cognitive Context -> Cognitive Mode Candidate -> Cognitive Time Budget Candidate + Cognitive Depth Candidate -> Reasoning Process`.

Mode affects the shape of future cognitive investment, not a Decision, Action, Permission, Runtime scheduler, or personality state.

## Candidate modes

- **Reactive Mode**: narrow cognitive window and survival-sensitive, conservative candidate path.
- **Routine Mode**: bounded low-cost pattern-match candidate path for familiar conditions.
- **Adaptive Mode**: necessary-information and small-step adjustment candidate path in ordinary unknown conditions.
- **Exploratory Mode**: lower-risk field-understanding/experience-expansion candidate path.
- **Reflective Mode**: future long-horizon experience interpretation candidate path.

Modes are strategy descriptions, not capability levels or behavioral commands.
