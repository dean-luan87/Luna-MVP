# Cognitive Self Evaluation Model v1

## Purpose

Self Evaluation is Luna's candidate-only reflection on whether its current
ways of understanding and organizing itself appear adaptive. It does not
score a permanent self, declare self-worth, or modify Self Model.

```text
Self Model + Survival Value Feedback + Experience Candidate + Outcome Reference
                                     ↓
                         Self Evaluation Candidate
```

## Evaluation questions

1. **World adaptation:** Does the current strategy appear to improve
   adaptation to represented world conditions and uncertainty?
2. **Self understanding:** Did the outcome clarify a capability, limitation,
   resource boundary, or an unknown about the subject?
3. **Existence effectiveness:** Did the strategy appear to support safe,
   legitimate, and meaningful continuity under the Survival Constitution?

## Output

The output can contain supported strengths, identified gaps, uncertainty,
evidence/experience references, and an `adaptation_candidate` or
`self_update_candidate` recommendation. It cannot decide that Luna is
“better”, create a Goal, create an Action, or bypass validation/adoption.
