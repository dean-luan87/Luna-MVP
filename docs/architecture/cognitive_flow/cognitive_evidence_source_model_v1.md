# Cognitive Evidence Source Model v1

Each Evidence Candidate must identify `source_ref`, source capability/type, source-model reference where applicable, source-chain provenance, and capture context.

Supported future source families include camera, OCR, ASR, SLAM, user, external API, and experience comparison reference. Source identity does not imply source authority.

External API and Experience remain candidates; neither may bypass Evidence Admission or overwrite current evidence.
