# Cognitive Decompression / Reconstruction Model v1

Decompression Candidate expands a Compressed Cognitive Representation through Context Matching into hidden condition, cause, strategy, exception, and uncertainty references, producing a Current Situation/Understanding Candidate.

`Compressed Representation -> Context Matching -> Hidden Condition Reconstruction -> Current Situation Understanding Candidate` requires current Field, Context, and Evidence validation. Decompression is not retrieval runtime, reality replacement, prediction, Decision, Action, or State mutation.
