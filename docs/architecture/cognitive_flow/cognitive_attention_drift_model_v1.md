# Attention Drift Taxonomy v1

| Drift | Meaning | Example |
|---|---|---|
| Expansion Drift | attention exceeds bounded intent | road safety becomes city scan |
| Narrowing Drift | attention omits required evidence | road safety becomes vehicle-only |
| Replacement Drift | model metric substitutes intent | accuracy score substitutes user support |
| Attraction Drift | irrelevant salient stimulus captures attention | advertisement distracts pharmacy search |
| Persistence Drift | released need continues consuming candidate allocation | resolved hazard remains dominant |

Drift findings are Attention Drift Candidates. They do not modify Goal,
Decision, Action, Provider selection, State, or Runtime.
