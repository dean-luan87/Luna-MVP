# Cognitive Governance Registry and Resource Architecture v1

## Position

This layer is Luna's self-awareness and governance infrastructure. It does not
become another Brain and it is not part of Reality Cognition itself.

```text
Brain / Cognitive Rules
          ↓
  Cognitive Governance Layer
  ├── Cognitive Process Manager
  ├── Resource Manager
  ├── Authority Manager
  └── Self Awareness Infrastructure
      ├── Capability Registry
      ├── Model Registry
      ├── Hardware Registry
      └── Diagnostics
          ↓
  Capability Middleware
          ↓
  Models / Hardware / External Services
```

Registry, Hardware Manager, and Diagnostics answer: what do I have, what is its
current state, what can I do, and where are my limits? They are Self Awareness
Infrastructure, not a monitoring-only dashboard and not a decision authority.

## Cognitive Process and resource relationship

```text
Event / Intent
      ↓
Cognitive Process Creation
      ↓
Workspace Context
      ↓
Neural Processing
      ↓
Resource Evaluation
      ↓
Escalation Candidate
      ↓
Brain Review
      ↓
Experience Candidate
```

Resource Management evaluates information value versus resource cost. It creates
Allocation Candidates for compute, battery, attention, memory, and network; it is
not a Scheduler and does not execute Actions.

## Registry-to-Self relationship

```text
Hardware Registry + Model Registry + Capability Registry + Diagnostics
                         ↓
                 Capability State Candidate
                         ↓
                 Self Capability Context
                         ↓
                    Brain Awareness
```

Hardware Manager registers body structure, health, capability, and lifecycle. It
does not open a camera or control a device. A capability may provide Evidence,
but it cannot interpret Reality, own Goal, or make a Decision.

## Frozen boundaries

Authority Registry describes who may do what. Neural may regulate candidate
resources and escalate. Brain retains Goal, Intent, and final judgment. The
Reducer remains the sole State mutation authority. No registry entry changes the
cognitive subject or creates an independent Goal.
