# Reality Context Bridge Whitebox v1

```text
Capability / User / Sensor Evidence
              ↓
Reality Neural Operating Space
  Reality State + Self State + Temporal State
  Entity / Relation State + Unknown Lifecycle
              ↓
Reality Context Projection
  Observable State
  State Change
  Relevant Constraints
  Unknowns
  Provenance
              ↓
Reality Context Package
              ↓
A Route Input Context
              ↓
Situation Understanding
              ↓
Brain Evaluation
```

The bridge filters and packages fact-level state. It does not interpret risk,
emotion, value, recommendation, plan, prediction, Decision, or Action. The
Reality Reducer remains the State mutation authority; the Context Bridge is
read-only.
