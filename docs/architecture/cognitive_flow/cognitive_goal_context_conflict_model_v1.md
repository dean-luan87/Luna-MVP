# Cognitive Goal Context Conflict Model v1

Goal Context Conflict Candidate preserves competing or incompatible goal-context relationships, such as time-critical departure versus low-priority exploration, or user request versus survival-risk constraint.

Conflict != Failure, automatic priority decision, goal deletion, Decision, or Action. It may lower sufficiency or produce a future Deep Reasoning Request Candidate when high risk, high impact, and high unknowns coexist.
