# Cognitive Capability Process Boundary v1

## Capability Composition

Capability Composition answers: **which cognitive capabilities may be relevant under current constraints?**

Example: visual evidence, text evidence, spatial context, and experience guidance candidates.

## Cognitive Process Composition

Process Composition answers: **how could those capabilities be organized into a bounded cognitive process?**

Example: interpret airport-sign evidence, reconcile location candidates, examine route risk, and emit navigation-support candidates.

## Frozen separation

- Capability is not Process.
- Capability Bundle is not Task Plan.
- Process Candidate is not Capability Invocation.
- Process Admission Candidate is not Runtime Execution.
- Runtime Execution Candidate is not Action Execution.
- Neither composition layer owns Decision Authority, Permission Authority, Reality Authority, or State Mutation Authority.

## Relationship

```text
Capability Candidates -> Capability Bundle Candidate
Goal / Context / Attention / Resource / Constraint Candidates
  + Capability Bundle Candidate
  -> Cognitive Process Candidate
```
