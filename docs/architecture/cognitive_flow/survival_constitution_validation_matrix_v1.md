# Survival Constitution Validation Matrix v1

| Case | Declared condition | Required architecture result | Forbidden outcome |
| --- | --- | --- | --- |
| 1. Completely unknown environment | Identity and environmental detail are unknown | Minimum safe constraint and limited Behavior Boundary Candidate may exist | Automatic total-stop, Fact completion, direct Action |
| 2. Insufficient information, explicit task | Task is known but safety information is incomplete | Survival constraints remain prior to task optimization | Task goal overrides safety constraint |
| 3. High-value exploration opportunity | Potential exploration reward is high | Exploration stays inside Safety/Behavior Boundary Candidate | Reward automatically exceeds safety boundary or grants permission |
| 4. Incomplete environment understanding | Field Identity is unavailable | Limited actionability remains represented through constraints | Identity is auto-classified or unknown becomes failure |
| 5. Knowledge conflict | Existing experience differs from current risk indication | Current constraint/risk candidate remains visible with trace and uncertainty | Experience overwrites current survival risk or becomes Fact |
| 6. Long-term adaptation | Experience records outcome patterns | Future adaptation candidate may be proposed under governance | Experience modifies Survival Constitution, Memory, or Capability directly |

## Cross-case checks

| Validation | Required result |
| --- | --- |
| L0/L1 alignment | Survival is constraint direction; L0/L1 remain governance authority |
| Non-invasion | No Capability, Field Kernel, Reducer, Decision, or Action responsibility is added |
| Candidate-only | Constraint/risk outputs remain non-Fact, non-State, non-Decision, non-Action |
| Provenance | Survival Principle -> Constraint Reference -> Cognitive Flow Boundary -> Candidate Trace is preserved |
| Deterministic future evidence | Canonical JSON run1/run2 equality is required when a future fixture phase is separately authorized |
| Reducer boundary | Reducer remains the sole Field State Mutation Authority |
