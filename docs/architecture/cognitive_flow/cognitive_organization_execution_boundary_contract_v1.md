# Cognitive Organization Execution Boundary Contract v1

## Frozen contracts

- Cognitive Cycle is not a fixed timer.
- Cognitive Tick Candidate is not a Scheduler.
- Attention Controller is not a Runtime Scheduler.
- Attention Allocation is not module execution.
- Attention Authority is not Intelligence Authority.
- Cognitive Allocation Candidate is not Decision Authority.
- Capability Composition is not Task Planning.
- Capability Bundle Candidate is not capability invocation.
- Capability Execute Candidate is not Action Execution.
- Resource Budget is not Resource State Mutation.
- Resource Budget is not device, hardware, or model control.
- Interrupt Candidate is not Action.
- Interrupt Candidate is not an unconditional Attention Override.
- Cognitive Process Instance is not persistent State.
- Cognitive Process Instance is not a State Machine.
- Organization Execution is not Model Invocation.
- Outcome Observation is not Truth.
- Feedback is not Learning Mutation.
- Attention Evolution Candidate is not automatic adoption.
- Planning architecture is not Runtime Engine implementation.
- Planning architecture is not Decision Runtime or Action Runtime.
- Reducer remains the only State Mutation Authority.

## Authority routing

```text
Sources -> Candidates -> Attention Governance -> Organization Candidates
  -> future runtime admission -> outcome candidates -> feedback candidates
```

No arrow in this contract grants authority to alter reality, create facts, grant permissions, make decisions, execute actions, rewrite capability structures, mutate memory, or mutate State.
