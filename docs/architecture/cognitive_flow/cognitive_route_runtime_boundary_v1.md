# Cognitive Route Runtime Boundary v1

## A route candidate conditions

Pattern match, known/low-risk situation, sufficient information, constrained time, or applicable experience candidates may support A-route consideration.

## B route candidate conditions

Unknown, high impact, high uncertainty, novel/conflicting situation, high-value information gap, and `Information Value Candidate > Reasoning Cost Candidate` may support B-route/deep-reasoning consideration.

Neither route is a Runtime execution path, Intelligence Level, Decision, Action, or Permission. B route is not automatically selected merely because a topic is complex.
