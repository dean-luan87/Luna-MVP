# Cognitive Mode Switching Context Alignment v1

## Context relation

Current Cognitive Context supplies the current Field reference, task/goal, attention conditions, information gap, uncertainty, temporal/spatial scope, and experience reference. Mode Switching uses these as candidate inputs; it cannot write them back or redefine the Context.

Home, workplace, navigation, unknown-environment, and risk contexts can yield different candidate modes without turning Context into a Decision or the Mode into a role/personality label.

## Personality, role, and emotion isolation

Future role, personality, or emotion systems may contribute separately governed preference or value-weight candidates. They cannot directly control Survival Mode, mutate a Mode Candidate, or make mode selection into identity/personality/emotion mutation.
