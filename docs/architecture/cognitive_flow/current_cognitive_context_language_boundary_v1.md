# Current Cognitive Context Language Boundary v1

## Future interface

`Context Candidate -> Concept Compression Candidate -> Language Encoding Candidate`

Language is a future expression layer. It may receive a governed Context-derived candidate for expression or compression, but cannot become the source of Context, rewrite Context, resolve unknowns, or override Survival/Attention boundaries.

No Language Runtime, generation, evolution, admission, or reverse-control path is authorized by this interface.
