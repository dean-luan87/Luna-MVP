# Cognitive Hypothesis Field Alignment v1

Field provides spatial relationships, temporal change references, and environmental constraints. Hypothesis interprets possible current conditions, transformation causes, and future possibilities while preserving contradictory evidence and uncertainty.

`Field Evidence -> Primitive -> Concept Candidate -> Hypothesis Candidate`

Field is not Hypothesis, and Hypothesis is not Field State. No hypothesis may update Field, Snapshot, History, Event, Admission, or Reducer input directly.
