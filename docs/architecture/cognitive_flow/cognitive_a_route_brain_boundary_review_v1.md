# A-Route Brain Boundary Review v1

## Authority review

| Layer | May provide | Must not do |
|---|---|---|
| Brain | final cognitive judgment; intent and decision evaluation | direct Provider call, Action execution, or State mutation |
| Intent Preservation | alignment and drift candidates | rewrite Original Purpose |
| Self Model | capability, limitation, and continuity context | choose a Decision |
| World / Reality | Evidence-governed reality context | create Goal or interpret emotional meaning as fact |
| Situation | world–self–goal relation candidate | execute or choose Action |
| Attention | observation requirement and allocation candidate | define Goal, interpret Reality, or control hardware frequency |
| Neural Governance | resource, regulation, and coordination candidate | replace Brain judgment |
| Middleware | capability organization and feasibility | cognitive completion or decision selection |
| Provider | local Evidence and status candidate | truth, decision, action, or State mutation |
| Experience | historical reference candidate | direct strategy, Self Model, or policy update |
| B Reflection | delayed improvement candidate | current A control authority |
| Reducer | sole State mutation authority | infer, decide, or execute |

## Boundary findings

Any apparent capability, model, emotion-interface, attention, or experience
overreach is retained as a `brain_boundary_violation_candidate`. It cannot be
silently repaired through a Runtime path. This review does not introduce B
Reflection, Context Integration, an emotional engine, multi-role control,
multi-A coordination, hardware, or Runtime.
