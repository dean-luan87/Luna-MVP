# Long-Running Stability Review v1

## Controlled horizon

The review uses a deterministic 24-hour architecture scenario containing Evidence
input, Reality State changes, multiple Cognitive Processes, Capability changes,
resource pressure, Unknown growth, and process lifecycle transitions.

## Stability invariants

- **No state inflation:** redundant Immediate State is compressed or expired;
- **No authority drift:** Brain, A Route, Neural, Registry, Middleware, and
  Reducer retain their matrix roles;
- **No experience contamination:** Experience Candidate cannot replace current
  Reality without Reality Confirmation;
- **Unknown preservation:** unresolved evidence remains Unknown and does not become
  fact merely through elapsed time;
- **Identity continuity:** capability or hardware changes do not redefine Luna;
- **Lifecycle validity:** Candidate, Active, Stale, and Expired states remain
  distinguishable;
- **Resource stability:** background processes cannot consume unlimited resources.

## Review output

The output is a Stability Finding Candidate with time window, affected layer,
trace references, confidence, and remediation candidate. It is not a Runtime
result and cannot authorize an automatic State update.
