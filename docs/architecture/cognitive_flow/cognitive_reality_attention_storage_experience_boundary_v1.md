# A-Route Attention Storage and Experience Boundary v1

## Three candidate levels

| Level | Lifetime | Purpose | Boundary |
|---|---|---|---|
| Instant Attention Candidate | seconds | current bounded relevance | not retained Memory |
| Working Attention Context Candidate | task window | active Goal/Situation-oriented focus | not a persistent state or runtime queue |
| Attention Pattern Candidate | future experience review | possible “what to notice” pattern | not a policy, rule, or automatic strategy update |

## Experience path

```text
Attention Pattern Candidate
        ↓
Experience Candidate
        ↓
Validation
        ↓
Future Attention Guidance Candidate
```

Experience can preserve a candidate about what information was valuable, but it
cannot directly modify attention strategy, Attention Runtime, Self Model,
Decision, or Memory. This phase introduces no online learning or automatic
attention evolution.
