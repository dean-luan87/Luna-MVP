# Experience to Self Update Model v2

## Controlled consolidation path

```text
Experience Candidate
        ↓
Pattern Extraction Candidate
        ↓
Validation
        ↓
Self Update Candidate
        ↓
Adoption Review
        ↓
Admitted Self Model Update
```

## Rules

- A single event cannot change Self Model, Identity, relationship expectation,
  capability awareness, or strategy preference.
- Pattern Extraction preserves sample limitations, counterexamples,
  uncertainty, and trace references.
- Validation tests repeatability, context relevance, constitutional compliance,
  and possible impact before any Adoption Review.
- Adoption Review can accept, reject, defer, or request more evidence; it does
  not self-authorize mutation.
- Reducer remains the sole State mutation authority.

This is an architecture for experience governance, not online learning,
training, personality rewriting, or autonomous self-modification.
