# Cognitive Execution Monitoring Model Definition v1

`CognitiveExecutionMonitoringCandidateV1` may reference commitment responsibility, current context/state, field and predictive-field candidates, goal, hypothesis, outcome observation, resource budget, provenance, and trace.

It may describe environment alignment, goal alignment, prediction validation, resource status, commitment validity, deviation, and a non-executing monitoring state candidate: `Maintain`, `Adjust`, `Suspend`, `Reconsider`, or `Abort Candidate`.

It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
