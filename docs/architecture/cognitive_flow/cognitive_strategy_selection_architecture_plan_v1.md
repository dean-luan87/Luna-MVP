# Cognitive Strategy Selection Architecture v1

Cognitive Strategy Candidate is Luna's candidate-level choice of a cognitive path when information remains incomplete. It sits between Information Gap / Attention and future Behavior Candidates.

`Current Context + Goal + Information Gap + Survival Constraint + Risk Candidate + Attention Candidate -> Cognitive Strategy Candidate -> Future Behavior Candidate`

It selects no real behavior and does not execute an action. Decision, Action, Permission, Fact admission, Field Kernel, and Reducer remain separate governed layers.
