# Cognitive Internal Representation Model v1

An Internal Representation Candidate may contain Primitive References, relation/state/event/goal/constraint/pattern/unknown/scenario references, context/temporal/spatial/risk/resource boundaries, evidence, confidence, applicability, provenance, and trace.

Airport-travel example: goal reach airport before flight; entities home/airport/transport; constraints time/security/ticket; risks traffic/delay; unknowns weather/crowding; early-departure pattern guidance. This is a candidate cognitive object, not current reality or a final plan.
