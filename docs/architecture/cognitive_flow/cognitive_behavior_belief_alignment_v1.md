# Cognitive Behavior Belief Alignment v1

## Belief contribution

Belief State contributes a `Behavior Constraint Candidate`; it does not produce behavior or select an action. If a Field contains competing possibilities—such as clear path versus obstacle—unresolved or risk-sensitive beliefs can preserve cautious observation and restrict rapid passage.

## Risk-sensitive treatment

Highest probability is not automatically the broadest behavior space. A lower-probability, higher-cost risk may justify retaining a conservative boundary while the Belief State remains uncertain. `Belief != Action`, and `Probability != Safety Priority`.

## Evidence requirement

Boundary expansion requires a future, separately governed evidence and admission path. Confidence, evidence quantity, or historical similarity does not grant permission.
