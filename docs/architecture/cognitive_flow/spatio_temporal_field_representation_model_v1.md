# Spatio-Temporal Field Representation Model v1

Current Field Representation evolves conceptually to a Spatio-Temporal Field Representation composed of Field Identity, Spatial Structure, Temporal Evolution, Entity Relation, Concept Pattern, Context, Task Relation, Attention Scope, Uncertainty, Provenance, and Trace.

It remains candidate/read-only where the existing Field Representation contract is candidate-only. Spatial and temporal references are retained, not rewritten; governed Field State/Snapshot remains Reducer/Field Kernel-owned. Future reservations: Field Invariant, Field Pattern, Field Compression, and Field Language Encoding—none implemented here.
