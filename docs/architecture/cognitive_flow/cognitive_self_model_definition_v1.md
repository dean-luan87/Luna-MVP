# Cognitive Self Model Definition v1

`CognitiveSelfModelCandidateV1` may retain capability, resource, experience, uncertainty, risk, role-boundary, mission/context, provenance, and trace references.

It describes what Luna may currently have, lack, afford, or need to qualify before consideration. It is always `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_identity=true`, `not_personality=true`, `not_emotion=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
