# Minimum Sufficient Field Unknown Adaptation Model v1

`Unknown Field -> External Context Observation -> Neighbor Field Relationship Candidate -> Local layout/object/behavior observation -> Constraint Extraction -> Safe Behavior Space -> Incremental Field Understanding`.

Surrounding Field, larger context, and Field Cluster relationship may supply candidate evidence only; “similar things cluster” never directly creates Identity. Internal evidence may include layout, decoration, object distribution, population behavior, and activity pattern. When Identity is unclear, Behavior Constraint has priority over identity classification.

States include `unknown_but_safe`, `partially_understood`, and `gradually_expanding`; none is a Fact or State mutation.
