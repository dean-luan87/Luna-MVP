# Context and Intent Understanding System Architecture v1

## Purpose

Answers: what current problem may Luna be facing, why may it matter, and what result may be needed?

## Existing module grouping

Current Cognitive State, Context Formation, Intent Understanding, Goal Understanding, Task/Role references, and Cognitive Assistance boundary inputs.

## Input and output

Inputs are Situation, Human Input, task signal, survival/mission/role references, and Capability candidates. Outputs are Context, Intent, Goal, Sub-goal, Constraint, and Success Condition candidates.

## Boundary

The system does not self-determine a final goal, modify values, form identity/personality, decide, command, permit, act, or mutate State. Context is not Goal and Intent is not Goal.
