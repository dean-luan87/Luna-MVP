## Objective and position

Extend Attention from internal cognitive resource coordination to a three-direction information-control architecture.

```text
Attention Origin Hierarchy
  -> Attention Candidate Pool -> Governance -> Controller
       /               |                    \
Input Attention  Cognitive Attention   Active / Output Attention
       |               |                    |
Evidence Admission   Workspace        Perception Request Candidate
```

Attention is an information-regulation system between external perception, internal cognition, and future sensor information needs. It is not a sensor runtime, external-device controller, Decision, Action, Permission, or central intelligence.

## Scope

Define origin hierarchy, Input/Cognitive/Active attention, Output interface, source arbitration, Constitution and Self Preservation sources, future Emotion admission, and Sensor Feedback boundary.

## Out of scope

No camera/OCR/ASR/VLM/SLAM invocation, sensor/device control, perception runtime, Controller runtime, Decision, Action, Permission, B Route runtime, Emotion Engine, Memory/Learning/Evolution, or State mutation.
