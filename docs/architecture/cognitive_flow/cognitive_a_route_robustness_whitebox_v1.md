# A-Route Brain Robustness Whitebox v1

```text
Survival Drive
      ↓  [intent integrity check]
Brain Intent
      ↓
Intent Preservation ── drift / coverage candidates
      ↓
Self Context + World Context + Goal / Resource
      ↓  [world–self and Unknown check]
Situation Assessment
      ↓
Attention Axis → Observation Requirement → Evidence Gateway
      ↓  [Evidence is not Reality]
Decision Formation
      ↓  [Brain final judgment boundary]
Execution Boundary → Outcome Evidence
      ↓  [Past Available Context comparison]
Situated Outcome Evaluation → Cause Attribution Candidate
      ↓
Adaptation / Experience Candidate → governed A-to-B handoff
```

The whitebox must make visible: Original Purpose, non-negotiable objective,
Unknown factors, Self Capability boundary, selected option rationale, expected
and actual outcome, failure localization, authority boundary warnings, and
Experience Adoption status. It visualizes candidates and traces only; it does
not operate an Action or modify State.
