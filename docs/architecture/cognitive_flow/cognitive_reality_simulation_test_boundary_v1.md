# Reality Cognition Simulation Test Boundary v1

## Test intent

A future simulation test receives a controlled reality situation and observes
how the Reality Cognition System forms self-situated understanding, a
traceable Decision Candidate, and feedback candidates.

```text
Controlled Scenario Input
        ↓
Reality Evidence + Self / Goal / Resource Context
        ↓
Situation / Decision Trace Candidates
        ↓
Injected Outcome Reference
        ↓
Difference / Failure / Value / Experience Candidates
```

## Explicit exclusions

The future test does not prove general intelligence, execute a real Action,
call external Providers, access hardware, train online, create a Scheduler,
or mutate production/cognitive State. It validates contract adherence,
traceability, boundary preservation, and failure-localization readiness.

The future simulation test does not execute a real Action.
