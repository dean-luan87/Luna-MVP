# A-Route Attention / Neural Resource Boundary v1

## Distinct responsibilities

| Layer | Candidate responsibility | Does not own |
|---|---|---|
| A-Route Attention | what may deserve limited cognitive understanding | system-wide intensity, hardware frequency, actual resource allocation |
| Neural Regulation | whether current system conditions warrant response-strength reweighting | Reality facts, Attention Runtime, Goal, Decision |
| Middleware | capability/resource feasibility input | cognitive relevance or completion judgment |
| Hardware governance | embodiment/resource constraint input | cognitive priority |

## Relation

```text
Situation Importance Candidate
        ↓
Attention Selection Candidate
        ↓
Information Prioritization Candidate
        ↓
Neural Resource Allocation Candidate
```

The final node is a future candidate interface. Attention does not set tempo,
allocate CPU/GPU/device resources, increase sensor frequency, or start an
Assembly. Neural Regulation does not turn attention selection into Reality,
Decision, or Action.
