# Unknown Propagation Contract v1

## Preservation rule

Unknowns in Reality Neural Operating Space must propagate into the Reality
Context Package with scope, reason, evidence gap, validity, confidence, and
provenance. Projection cannot resolve an Unknown by assumption, prediction, or
language completion.

```text
Reality Unknown
      ↓
Context Unknown
      ↓
A Route Unknown-aware Situation Candidate
```

## Examples

`flow_speed: unknown` remains `flow_speed: unknown`. `exit_status: unknown`
remains explicit in the package. The bridge may state that information is missing
but may not state that a route is dangerous, safe, blocked, or preferred.

Unknown propagation is not a Decision and does not authorize an Action. A Route
may request more information under its own authority.
