# Brain–A Route Interaction Validation Model v1

## Scope

This Planning Only validation checks the bidirectional candidate interface:

```text
Brain Intent / Attention / Context
             ↓
          A Route
             ↓
Situation / Decision / Outcome / Experience Candidates
             ↓
      Brain Evaluation
```

It excludes models, Middleware Runtime, Provider calls, real hardware, Action,
B Reflection, emotional runtime, multi-role, multi-A, online learning, and
State mutation.

## Interaction invariants

- Brain Original Purpose and Non-Negotiable Objective remain traceable into A Route.
- Intent expansion, narrowing, replacement, and attraction drift remain detectable candidates.
- Brain supplies Attention direction; A does not substitute visual salience for the purpose.
- A returns Reality/Situation/Risk/Capability/Decision candidates only; it cannot change Goal or decide.
- Brain Evaluation may accept, modify, reject, or request further information for a Decision Candidate.
- capability limitation returns upward as a constrained context, not a forced attempt.
- Outcome feedback returns cause, confidence, Unknowns, and adaptation candidates, not bare success/failure.

## Authority boundary

Brain owns Intent and final cognitive judgment. A Route owns reality
understanding and Decision Candidate formation. Neural provides regulation
candidates, Capability provides feasibility, Experience provides reference, and
B provides delayed future reflection only. Reducer remains sole State mutation
authority.
