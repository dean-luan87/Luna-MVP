# Cognitive Optimization Model Definition v1

`CognitiveOptimizationCandidateV1` may retain Future Space/Branch Governance references, Goal, Context, Survival, Mission, Information Value, Value/Cost/Risk/Reversibility candidates, Time/Resource budget, candidate-path set, stop-condition reference, uncertainty, provenance, and trace.

It outputs a current feasible-path candidate set, never a selected Decision. Output remains candidate-only, non-Fact, non-State-mutation, non-Decision, non-Action, non-Permission, and non-Memory.
