# Cognitive Representation Information Field Alignment v1

Cognitive Information Field supplies mixed, source-preserving candidates. Information Processing filters, aligns, relates, and abstracts them into Internal Representation Candidates.

`Information Field != Internal Representation`; information field is the active information environment, while representation is a structured candidate object derived for cognition. Source, evidence, confidence, applicability, time/context scope, unknowns, and conflicts remain available after abstraction.
