# Cognitive Simulation Space Model v1

Simulation Space Candidate references Workspace, active representations/schemas, initial conditions, changed variables, assumptions, branches, evidence/unknowns, confidence candidates, evaluation references, resource boundary, provenance, and trace.

For airport travel, a workspace with goal/time/transport/risk/unknowns may produce taxi, subway, earlier-departure, congestion, or weather-change scenario candidates. Simulation organizes possible worlds; it does not assert that they will happen.
