# Reality Cognition System Reflection Interface v1

## A-to-B export boundary

Reality Cognition System may export only the following governed candidates to
B Reflective Cognition: Outcome Reference, Experience Candidate, Survival
Value Feedback Candidate, and Failure/Difference Candidate.

```text
Reality Cognition System
        ↓
Outcome / Experience / Value / Failure Candidates
        ↓
B Reflective Cognition
        ↓
Strategy / Capability / Self Understanding Improvement Candidates
        ↓
Validation → Reality Feasibility → Adoption Candidate
        ↓
Future Reality Cognition System input
```

B cannot directly access or modify internal A modules. It cannot influence a
current Situation Candidate, Decision Candidate, Action Boundary, Attention,
Provider selection, Resource State, Self Model, or Reality fact in real time.
The Reflection interface is delayed, candidate-only, and future-oriented.
