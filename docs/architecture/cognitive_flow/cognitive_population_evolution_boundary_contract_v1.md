# Cognitive Population Evolution Boundary Contract v1

## Allowed candidate references

Genome, individual experience/phenotype/representation, compression, primitive candidate, propagation, local/population validation, culture, diversity, Hive future boundary, survival/value, provenance, and trace references may be read.

## Rejected inputs and effects

Evolution Runtime, Hive Runtime, Learning Engine, Language Generation, model training, distributed learning, model copy, parameter sync, automatic self rewrite, central control, raw model/provider output, Decision result, Action command, permission, State handle, Reducer command, Memory/Hive write, and State mutation are outside this layer.

## Negative guards

- Genome != Final Intelligence.
- Genome != Fixed Architecture.
- Genome != Individual Phenotype.
- Individual Experience != Universal Truth.
- Primitive Candidate != Immediate Adoption.
- Primitive Emergence != Self Rewrite.
- Culture != Rule.
- Culture != Truth.
- Culture != Individual Override.
- Propagation != Automatic Learning.
- Receive != Learn.
- Hive != Central Brain.
- Hive != Local Decision Authority.
- Hive != Individual Override.
- Diversity != Error.
- Evolution != Random Growth.
- Evolution != Self Rewrite.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not model copy, not training, not learning, not self rewrite, not decision, not action, not permission, not memory/hive write, and not state mutation.
