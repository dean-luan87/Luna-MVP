# Cognitive Fast and Slow Loop Model v1

## Fast cognitive loop

Current problem support over seconds/minutes:

`Observation -> Understanding -> Candidate Evaluation -> Decision Support -> Outcome Candidate`.

## Slow evolution loop

Experience adaptation over days/months/years:

`Outcome -> Experience -> Compression -> Representation Evolution -> Culture/Gene Pool Candidate`.

Fast and slow loops are separated. A single error, observation, outcome, or candidate cannot automatically alter a foundational representation, culture, gene pool, capability, Constitution, or State.
