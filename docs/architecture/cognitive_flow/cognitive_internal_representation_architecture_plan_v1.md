## Position

`Cognitive Information Field -> Information Processing -> Internal Representation Candidate -> Workspace Candidate -> Simulation Candidate -> Reasoning / Evaluation Candidate`.

Internal Representation is the context-bound cognitive object structure Conscious Layer may combine, inspect, and simulate. It is not Neural Representation, Embedding, Vector, Database schema, text, Knowledge entry, Memory, Language, Reality, Truth, Decision, Action, or Permission.

This phase defines candidate structures only; no neural model, vector database, Memory Runtime, language generation, learning runtime, or State mutation is authorized.
