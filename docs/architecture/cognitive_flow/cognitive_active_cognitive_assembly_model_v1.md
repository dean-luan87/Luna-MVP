# Active Cognitive Assembly Model v1

An Active Cognitive Assembly is a temporary process composition proposed from a Cognitive Work Objective. It groups relevant observation, relation-seeking, and evaluation requirements; it is not an Agent, planner, or independent cognitive subject.

| Allowed | Forbidden |
|---|---|
| CWO reference, lifecycle candidate, capability requirement candidate, resource-profile candidate, feedback channel | Independent Goal, Memory, Personality, Decision, Action, Provider execution |

Assembly creation remains a future Neural Governance candidate. This phase defines no automatic creation or process engine.
