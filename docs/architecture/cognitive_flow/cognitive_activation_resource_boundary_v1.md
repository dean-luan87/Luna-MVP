# Cognitive Activation Resource Boundary v1

Activation must assess compute, time window, task priority, risk, expected value, and resource cost candidates. It cannot activate all retained cognition indiscriminately.

Possible outputs are increase, maintain, reduce, defer, or refresh Activation Candidates. These remain resource-investment suggestions only; they do not control a Runtime scheduler, Attention, Decision, Action, Permission, or Reducer.

More Activation != Better Cognition. More Information != Better Decision.
