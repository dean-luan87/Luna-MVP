# Cognitive Conflict Detection Model v1

## Detection candidate

Conflict Detection Candidate identifies that two or more governed candidates may impose incompatible, competing, or insufficiently comparable conditions. Detection can arise from Choice Space, Value Evaluation, Behavior Boundary, Cognitive Constraint, Hypothesis/Belief, Context, Survival, Mission, or Experience references.

The detection result does not assert that a conflict is objectively real. It retains evidence, uncertainty, provenance, and trace. Detection cannot discard a candidate, select a winner, invoke a runtime, or enforce a policy.

`Conflict Detection != Error`, `Conflict Detection != Failure`, and `Conflict Detection != Decision`.
