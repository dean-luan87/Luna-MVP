# A-Route Attention / Observation Boundary v1

## Relationship

```text
Brain / Goal / Situation Context
        ↓
Attention Context Candidate
        ↓
Information Prioritization Candidate
        ↓
Observation Request Candidate
        ↓
Existing Observation Attention / Capability Governance
        ↓
Vision, OCR, SLAM, or future Provider Candidate
```

A-route Attention is cognitive control: it states what information may be
worth understanding. Existing Observation Attention is the lower capability
selection boundary: it may translate an admitted observation need into bounded
observation/capability candidates.

## Prohibitions

- A-route Attention does not invoke a model, camera, sensor, Provider, or
  Capability Session.
- Observation Attention does not decide cognitive goals, facts, situations, or actions.
- A model does not decide what Luna should observe.
- An Observation Request Candidate is not an execution command.
