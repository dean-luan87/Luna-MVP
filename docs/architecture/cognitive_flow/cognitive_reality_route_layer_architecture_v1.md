# A-Route Reality Cognition Layer Architecture v1

## Layer map

```text
L0 Survival Constitution
    - constitutional non-harm, legitimacy, and continuity boundaries
        ↓
L1 Brain Cognitive Layer
    - Survival Drive, Self Model, Goal Context, Decision judgment boundary
        ↓
L2 Neural Governance Layer
    - regulation, resource candidates, assembly, coordination
        ↓
L3 Reality Understanding Layer
    - Evidence Gateway, Reality Representation, World State, Situation
        ↓
L4 Capability Boundary Layer
    - Cognitive Middleware, Provider, Hardware / execution boundary
        ↓
L5 Outcome Feedback Layer
    - outcome observation, value feedback, experience consolidation,
      future improvement candidates
```

## Direction and non-authority

Lower layers provide governed evidence, feasibility, execution-boundary status,
or feedback candidates upward; upper layers provide context and candidate
requirements downward. No layer may bypass another to mutate State, execute an
Action, establish truth, or obtain a hidden decision authority.

This map describes ownership and interfaces only. It does not create a
Scheduler, Runtime orchestration loop, or hardware/model integration.
