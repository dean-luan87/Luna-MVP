# Cognitive Representation Evolution Boundary Contract v1

## Allowed candidate references

Governed Compression/Decompression, Context/Field/Situation/Goal/Intent, Experience/Outcome, Knowledge, Survival, Sufficiency/Routing, representation applicability/value/deviation, provenance, and trace references may be read.

## Rejected inputs and effects

Representation Evolution Runtime, self-modification, autonomous rewrite, random growth, Genome mutation, capability mutation, Memory/Hive write, training, Learning Runtime, raw model/provider output, Decision result, Action command, permission, State handle, Reducer command, and State mutation are outside this layer.

## Negative guards

- Evolution != Self Modification.
- Evolution != Autonomous Rewrite.
- Evolution != Random Growth.
- Evolution != Capability Increase.
- Genome != Individual Phenotype.
- Phenotype != Identity.
- Phenotype != Personality.
- Mutation Candidate != Structure Mutation.
- Selection != Adoption.
- Aging != Error.
- Deletion Candidate != Deletion.
- Experience != Automatic Evolution.
- Hive != Central Brain.
- Hive != Genome Modifier.
- Hive != Individual Override.
- Representation != Rule.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not memory, not knowledge, not rule, not capability mutation, not self modification, not state mutation, not decision, not action, and not permission.
