# Cognitive Cognitive Attention Architecture v1

Cognitive Attention is the internal branch already coordinated by Cognitive Attention Controller. It allocates cognitive budget, depth, duration, direction, and persistence candidates across admitted Evidence, Representation, Schema, Workspace, Simulation, and Reasoning candidates.

```text
Cognitive Information Field -> Representation / Schema
  -> Cognitive Attention Controller -> Workspace Allocation Candidate
```

Cognitive Attention != Input Evidence Truth, Output Sensor Command, Decision, Action, or Permission.
