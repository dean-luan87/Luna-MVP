## A-to-B exports

| A export | Meaning |
|---|---|
| Experience Candidate | governed, traceable experience reference |
| Outcome Reference | future execution/outcome observation reference with uncertainty |

## B-to-future-A returns

| B return | Required route |
|---|---|
| Strategy Improvement Candidate | hypothesis → validation → reality feasibility → adoption candidate |
| Capability Improvement Candidate | governed capability/self-capability adoption route |
| Self Understanding Candidate | self-update validation and adoption route |

## Frozen contract

B cannot affect Current Decision, current Situation, current Action boundary,
current Attention, Provider selection, Resource State, Self Model, or Reality
fact in real time. A cannot treat B hypotheses as evidence or existing
capability. Both routes share Experience/Value references without sharing
responsibility or control authority.
