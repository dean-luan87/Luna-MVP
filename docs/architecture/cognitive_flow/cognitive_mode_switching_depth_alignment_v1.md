# Cognitive Mode Switching Depth Alignment v1

## Depth relation

Mode Candidate can reference or suggest a future `CognitiveDepthRegulationCandidate`: Reactive tends toward reduced cognitive expansion; Routine tends toward bounded pattern matching; Adaptive toward minimum necessary information; Exploratory toward controlled expansion; Reflective toward longer-horizon candidate analysis.

Mode does not set a fixed numeric depth, force a reasoning tree to expand/compress, or determine intelligence. Depth remains a separate candidate layer governed by Survival, Time Budget, Information Value, uncertainty, and traceability.

`Mode != Depth Authority` and `Depth != Decision`.
