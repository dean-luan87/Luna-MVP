# Cognitive External Capability Boundary v1

An External Capability is a future sensory or interpretation provider, not a cognitive authority.

```text
Camera / OCR / ASR / VLM / SLAM
  -> Capability Adapter Candidate
  -> Evidence Candidate
  -> Cognitive Information Field
```

Capability output is source-scoped, context-bound, uncertain, and traceable. External Capability != Reality, Fact, Situation Truth, Decision, Action, Permission, Memory write, or State mutation.

The downstream A3 Evidence Context Adapter may normalize already-governed evidence references only. It does not replace this upstream evidence-admission boundary.
