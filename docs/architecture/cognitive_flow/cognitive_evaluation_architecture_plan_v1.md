## Position

`Cognitive Operation -> Candidate -> Cognitive Evaluation Candidate -> Decision Support Candidate`.

Cognitive Evaluation assesses quality, support, consistency, applicability, risk, uncertainty, information value, and reasoning value of representation/hypothesis/simulation/experience candidates. It is distinct from behavior-value evaluation and does not decide, act, permit, mutate State, or generate truth.
