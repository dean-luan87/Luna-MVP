# Attention and Cognitive Resource Management System Architecture v1

## Purpose

Answers: what may merit attention and how much candidate cognitive resource may be invested?

## Existing module grouping

Attention, Information Gap, Information Value Evaluation, Cognitive Sufficiency, Cognitive Resource Allocation, Dynamic Cognitive Time Regulation, Cognitive Depth Regulation, and Cognitive Mode Switching.

## Input and output

Inputs are Context, Goal, Risk, uncertainty, time/resource budgets, Survival, Experience, and Knowledge candidates. Outputs are Attention, Value, Sufficiency, Time/Resource/Depth/Mode, and Information/Reasoning requirement candidates.

## Boundary

Attention chooses candidate cognitive targets; resource management describes candidate investment. Neither schedules Runtime, invokes observation, decides, permits, acts, or mutates State.
