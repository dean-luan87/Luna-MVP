# Cognitive Attention Origin Hierarchy Model v1

All sources submit Attention Candidates to one Candidate Pool; hierarchy constrains candidate urgency review, not authority or action.

| Layer | Candidate source | Example |
| --- | --- | --- |
| L0 | Constitution Attention | safety/device failure risk candidate |
| L1 | Self Preservation Attention | localization reliability degradation candidate |
| L2 | Goal Attention | airport boarding time/gate candidate |
| L3 | Experience Attention | security-queue risk expectation candidate |
| L4 | Emotion / Relationship Attention (future) | user distress salience candidate |
| L5 | Exploration Attention | unfamiliar environment candidate |
| Cross-cutting | Unknown / Risk / Context | unresolved risk and context candidates |

Origin Hierarchy != Attention Authority. Constitution Attention is high-priority input, not an action override or Reality claim.
