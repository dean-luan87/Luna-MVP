# Current Cognitive State Context Alignment v1

## Context relation

Current Cognitive Context supplies current Field, Survival, task, attention, uncertainty, information-gap, spatial/temporal, and experience references. Current Cognitive State may assemble these with process/lifecycle references into a present self-facing interpretation candidate.

Context remains its own candidate layer. Cognitive State cannot mutate Context, complete unknown information, alter a task/goal, or turn context interpretation into a Decision.

Known, Partial, Unknown, Conflict, and Risk are valid situation-understanding candidates. Unknown Cognitive State is not failure and does not trigger automatic inference or action.
