# Decision Candidate Behavior Alignment v1

## Alignment

Each Decision Candidate must cite one Behavior Candidate and the governing Behavior Boundary. Candidate formation can organize options for future consideration but cannot widen the behavior space, promote a restricted behavior, or turn an unknown behavior into an allowed behavior.

`Behavior Boundary -> Behavior Candidate -> Value Evaluation -> Decision Candidate` is a reference chain, not an execution chain. Future Decision and Action remain separate phases with separate governance.

## Example

In a dark environment, bounded illumination, waiting, withdrawal, and slow observation may enter a Choice Space if represented by valid Behavior Candidates. No candidate formation artifact selects one of these options.
