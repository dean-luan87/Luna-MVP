# Cognitive Behavior Reasoning Alignment v1

## Lifecycle interaction

Reasoning Tree Lifecycle Management can request a boundary review when a tree is Active, Suspended, Completed, Abandoned, or Archived. It manages whether to continue cognition; it does not choose, permit, or execute behavior.

When a reasoning tree is suspended because evidence is missing or a higher-priority survival condition interrupts it, the Behavior Boundary does not disappear. It retains an explicit `unknown` and conservative candidate boundary until a future governed update supplies evidence.

## Completion and abandonment

Completed means sufficient for the current cognitive need, not Fact. Abandoned means continuing is not currently warranted, not that a restricted behavior becomes allowed. Archived reasoning is an Experience Candidate reference only and never a permission shortcut.
