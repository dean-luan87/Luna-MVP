# Cognitive Prohibited Coupling List v1

The following couplings are prohibited:

- Experience != Rule.
- Culture != Truth.
- Gene Pool != Authority.
- Optimization != Decision.
- Prediction != Reality.
- Emotion != Override.
- Hive != Central Brain.
- Popularity != Truth.
- Frequency != Value.
- History != Future Applicability.
- Representation != Identity.
- Capability != Permission.
- Confidence != Authority.
- Knowledge != Understanding.
- Understanding != Action.
- Observation != Fact.
- Hypothesis != Reality.
- Decision Candidate != Decision.
- Decision != Action Permission.
- Compression != Knowledge Truth.
- Reducer remains the only State Mutation Authority.
