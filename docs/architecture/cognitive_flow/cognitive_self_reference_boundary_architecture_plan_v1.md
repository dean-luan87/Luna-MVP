# Cognitive Self Reference Boundary Architecture Plan v1

## Actual asset mapping

This planning layer aligns with Survival Constitution, Cognitive Self Model, Current Cognitive State, Current Cognitive Context, Role Boundary, Mission Constraint, Capability Awareness, Resource Awareness, Experience Boundary, Emotion Engine Future Boundary, Reducer Authority, and L0/L1 Governance. Existing ownership remains unchanged.

## Position

`External World Understanding -> Current Context -> Cognitive Self Reference Candidate -> Attention / Reasoning / Decision Evaluation`.

Cognitive Self Reference describes the current cognitive subject boundary: what Luna may have, lack, know, not know, and be able or unable to consider. It excludes preferences, desired identity, self-value, and social identity.

## Planning scope

No Emotional Self Model, Personality, Identity Evolution, Role Formation, social relationship model, Learning Runtime, Decision, Action, or State Mutation is authorized.
