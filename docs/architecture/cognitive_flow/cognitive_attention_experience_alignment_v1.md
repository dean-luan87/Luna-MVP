# Cognitive Attention Experience Alignment v1

Attention Lifecycle may provide a Pattern Candidate to Feedback and Experience systems. Experience may later provide Attention Candidate support only after current Context/Evidence validation.

```text
Attention Pattern -> Feedback -> Experience Candidate -> Validation
  -> Future Attention Guidance Candidate
```

Attention != Experience. Experience != Attention Authority. One lifecycle outcome cannot create an experience rule or alter Attention allocation directly.
