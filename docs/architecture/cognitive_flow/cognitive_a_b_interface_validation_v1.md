# Cognitive A/B Interface Validation v1

## A route

The active foundation route performs minimum-sufficient understanding through bounded perception, schema matching, attention, workspace formation, simulation candidates, operations, and evaluation candidates.

## B route interface

The frozen interface is:

```text
Workspace Candidate
  -> Simulation Expansion Candidate
  -> Deep Reasoning Request Candidate
  -> Future Evaluation Support Candidate
```

## V0 checks

- Route B has a named input/output interface;
- Route B is not invoked, simulated, or implemented in this phase;
- A-route outputs do not imply B-route execution;
- a future B-route request remains candidate-only and resource-bound; and
- Route B is not an intelligence hierarchy, Decision authority, or Action path.

`B Interface != B Route Execution.`
