# Temporal Understanding Boundary v1

## In scope

Temporal Understanding is an A-route extension for reality continuity:

- governed temporal evidence and state references;
- change, transition, cyclic, abrupt-change, trend, possibility, and
  uncertainty candidates;
- Self- and Goal-bounded Situation enhancement;
- Decision Support Candidate and Experience Extension Candidate inputs.

## Explicit non-responsibilities

Temporal Understanding does not perform time planning, Scheduler work, Runtime
execution, process orchestration, hardware tempo control, or automatic frequency adjustment. Those remain respectively outside this extension or in Neural Regulation, Process Ecology, and Hardware Tempo governance.

It does not:

- create a time prediction model or write a prediction into Reality;
- automatically call Providers, change Attention Runtime, or create an Action;
- perform world-model training, online learning, Simulation Runtime, or B
  Reflection;
- modify A Core, Brain, Self Model, Goal, Resource State, Decision Candidate,
  or Reducer State.

## Cross-system relation

Field Kernel may consume a future Temporal Context only through a separately
admitted interface; this phase does not connect Field assets. Emotional
Cognition may later supply value-weight context for temporal opportunities,
but it cannot alter temporal facts or World Understanding.
