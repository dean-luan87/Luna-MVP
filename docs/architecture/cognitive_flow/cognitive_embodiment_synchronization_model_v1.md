# Cognitive–Embodiment Synchronization Model v1

Synchronization is represented as candidates at three points:

1. Demand Synchronization: a cognitive need is expressed.
2. Capability Synchronization: a capability/hardware temporal profile is matched.
3. Response Synchronization: Hardware State Signal reports bounded device response.

```text
Need → Capability Match Candidate → Hardware Activation Candidate → Hardware State Signal → Neural Feedback Candidate
```

No point automatically invokes a device, changes a goal, or mutates state.
