# Field Kernel Spatio-Temporal Architecture Plan v1

Field Kernel is Luna's organization and maintenance layer for the current Spatio-Temporal Cognitive Field. It is not Database, Knowledge Base, Memory, Map, Fact Store, or Decision Engine.

It organizes current field structure, multi-source candidate references, queryable field state references, change observation, and evolution preparation. It does not admit events, mutate State, transition State, commit History, predict, or decide.
