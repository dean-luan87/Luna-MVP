# Decision Resolution Candidate Filtering v1

## Purpose

Constraint Filtering Candidate identifies Decision Candidates that are currently ineligible for future consideration because they conflict with explicit Survival, Mission subordination, Behavior Boundary, Cognitive Constraint, evidence, or resource conditions.

For example, entry into a high-risk equipment zone can be marked as constraint-ineligible because it exceeds the present Behavior Boundary. This is not preference, dislike, or a permanent ban; it is an evidence-bearing current candidate result.

## Boundary

Filtering cannot delete provenance, change a Behavior Boundary, enforce a rule, select another candidate, execute an Action, or write State. Constraint-ineligible candidates can remain traceable and may be reconsidered only through future governed changes in evidence or context.
