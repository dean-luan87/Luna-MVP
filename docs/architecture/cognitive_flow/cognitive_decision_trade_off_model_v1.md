# Decision Trade-Off Model v1

## Purpose

Decision Trade-Off Candidate explains a value conflict between Decision Candidates without resolving it. It can express:

- Safety vs Goal;
- Mission vs Cost;
- Speed vs Accuracy;
- Information Gain vs Resource Cost;
- Exploration vs Stability; and
- Short Term vs Long Term.

## Boundary

A trade-off is a candidate explanation, not a Decision rule, reward function, ordering command, or Permission. It preserves conflicting dimensions for a future governed Decision stage. High Mission value cannot override Survival; high apparent value cannot erase uncertainty or cost.
