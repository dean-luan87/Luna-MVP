# Cognitive Belief State Model Definition v1

`CognitiveBeliefStateCandidateV1` may associate Object/Field/Context/Concept/Hypothesis references with a belief status: `confirmed_candidate`, `probable_candidate`, `possible_candidate`, `uncertain_candidate`, or `unknown`.

It retains supporting, contradicting, and missing evidence. Confidence is a structure of belief distribution, uncertainty, and evidence quality—not a single truth score. Confirmed candidate is not Fact.
