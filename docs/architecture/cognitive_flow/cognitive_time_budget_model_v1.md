# Cognitive Time Budget Model v1

## Definition

`CognitiveTimeBudgetCandidateV1` describes an available candidate window for further cognition under Field Dynamics, Survival pressure, risk, Context, Information Value, Cognitive Constraint, and resource conditions.

It can indicate broad, ordinary, or constrained cognitive windows without treating them as fixed durations, system timers, deadlines, or execution schedules. The purpose is to bound cognitive investment, not to control real time.

## Alignment

- Quiet/low-dynamics context can retain multi-hypothesis, information gathering, and comparison candidates.
- Ordinary context can retain simplified reasoning or pattern-match candidates.
- Urgent/high-dynamics context can retain reactive, conservative, or preemptive reasoning candidates.

Budget does not decide a behavior, terminate a tree, or authorize an Action. It contributes a future input to Cognitive Depth Regulation and Reasoning Lifecycle candidates.
