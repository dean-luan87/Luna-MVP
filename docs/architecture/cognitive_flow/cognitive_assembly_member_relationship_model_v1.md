# Assembly Member Relationship Model v1

| Relation | Meaning | Example | Boundary |
|---|---|---|---|
| Parallel | Contributions may be collected independently | text evidence + object evidence | Not concurrent Runtime execution. |
| Dependency | One contribution conditions another candidate | region understanding → text understanding | Not a direct member command. |
| Competitive | Multiple capability/provider options address a similar need | OCR option A vs option B | Resolution remains Middleware/Neural candidate governance. |

Relationships are assembly-template metadata. They do not select a Provider, schedule execution, or create a winner.
