# Cognitive Propagation Model v1

Propagation Candidate chain:

`Luna A -> Compressed Representation -> Communication / Language Interface Candidate -> Luna B/C/D -> Local Validation -> Accept / Modify / Reject Candidate`.

Reception never implies inheritance. Each receiver requires Current Context Match, Evidence Validation, Value Evaluation, uncertainty preservation, and local validation. Communication/Language is an interface candidate only; no language generation or protocol is implemented.
