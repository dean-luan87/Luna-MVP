# Cognitive Conflict Evaluation Model v1

## Evaluation candidate

Conflict Evaluation Candidate can compare the affected constraints, evidence sufficiency, uncertainty, risk exposure, reversibility, time/resource pressure, value dimensions, and potential information gain of each conflicting path.

Survival remains the highest constraint. Mission, Experience, role expectations, and future preference candidates can influence evaluation only within Survival, Behavior Boundary, Cognitive Constraint, and L1 governance limits.

Evaluation does not produce a winner, a Decision, a policy, an Action, or an authority grant. `Confidence != Authority` and `Value != Truth`.
