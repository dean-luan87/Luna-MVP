# Cognitive Conflict Classification Model v1

## Candidate types

- **Goal Conflict**: competing goal references.
- **Survival vs Mission Conflict**: Mission value under Survival limitation.
- **Information vs Action Conflict**: need for evidence versus bounded future action opportunity.
- **Risk vs Reward Conflict**: potentially valuable but exposed candidate paths.
- **Experience vs Current Evidence Conflict**: historical pattern diverges from current evidence.
- **Habit vs Rational Evaluation Conflict**: a future routine/pattern candidate diverges from present evaluation.
- **Role Expectation Conflict**: future role expectation candidate conflicts with Context, Survival, or Goal.

Classification is descriptive. It does not determine priority, selection, personality, role identity, or emotional authority.
