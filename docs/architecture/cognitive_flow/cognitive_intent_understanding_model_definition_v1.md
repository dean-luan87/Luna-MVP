# Cognitive Intent Understanding Model Definition v1

`CognitiveIntentCandidateV1` may retain language-input, user-behavior-signal, context, situation, goal, assistance, intent-type, constraint, uncertainty, provenance, and trace references.

It supports Unknown Intent, Multiple Intent, Conflicting Intent, and Changing Intent. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_command=true`, `not_goal=true`, `not_emotion=true`, `not_personality=true`, `not_identity=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
