# Cognitive Capability Awareness Architecture Plan v1

## Actual asset mapping

This A-route planning layer aligns with Situation Understanding, Affordance Understanding, Current Cognitive Context, Current Cognitive State reference, Resource references, Experience Boundary, Behavior Boundary/Candidate, Reducer Authority, and L0/L1 Governance. It does not enter or redefine Self Model Runtime, Personality, Emotion, or Identity Growth.

## Position

`Situation -> Affordance -> Capability Awareness Candidate -> Behavior Boundary -> Behavior Candidate`.

Capability Awareness describes whether Luna may currently have the conditions to use an Affordance candidate. It is neither capability growth, identity definition, personality, permission, decision, nor action.

## Planning scope

No Self Model Runtime, Personality, Emotion Engine, Identity Evolution, Decision Execution, Action, or State Mutation is authorized.
