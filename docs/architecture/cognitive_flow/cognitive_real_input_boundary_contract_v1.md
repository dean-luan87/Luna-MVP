# Cognitive Real Input Boundary Contract v1

- External Capability != Cognitive Brain.
- Model Output != Reality.
- Model Output != Fact.
- OCR Output != Text Truth.
- VLM Output != Situation Fact.
- SLAM Output != Route Plan.
- Language Input != Intent Fact.
- Audio Output != Speaker/Meaning Fact.
- Evidence Admission != Truth Admission.
- Evidence Candidate != Decision.
- Evidence Candidate != Action.
- Evidence Candidate != Permission.
- Evidence Candidate != Memory Mutation.
- Evidence Candidate != State Mutation.
- Adapter != Model Invocation.
- Adapter != World Model.
- Reducer remains the only State Mutation Authority.

All future external input must preserve source, context, confidence candidate, uncertainty, provenance, trace, and explicit non-authority flags.
