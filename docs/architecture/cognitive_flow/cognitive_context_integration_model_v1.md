# Cognitive Context Integration Model v1

Context Integration Candidate combines bounded inputs without converting them into one authority claim.

Inputs:

- Current World Understanding Candidate;
- Task, Capability, Resource, Unknown, and temporal-position candidates; and
- source/provenance, scope, confidence, uncertainty, and constraints.

Output: a Current Cognitive Context Candidate for Attention and Workspace formation. Integration retains input distinctions and conflicts. It is not a fact merge, state update, goal selection, or decision.
