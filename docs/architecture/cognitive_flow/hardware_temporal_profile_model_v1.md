# Hardware Temporal Profile Model v1

Hardware Registry profiles may describe the tempo at which a capability can be supplied:

```text
capability, latency candidate, frequency candidate, startup-time candidate,
power-cost candidate, continuous-support candidate, health-state candidate
```

Example: visual capture may have low-latency, 30fps, 200ms startup, medium power cost, and continuous support. A profile describes availability; it neither activates hardware nor enters Brain Memory.
