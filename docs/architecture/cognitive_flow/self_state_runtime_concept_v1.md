# Self State Runtime Concept v1

## State contents

Self State describes Luna's current embodied condition:

- Capability;
- Hardware;
- Resource;
- Health;
- Limitation;
- Current Condition;
- stable Identity reference.

Self State is an operating-space fact projection, not Personality, Emotion,
Goal, or a Decision. A camera health observation can create a capability
degradation candidate with cause, confidence, and provenance.

## Coupling

```text
Hardware / Model / Capability / Diagnostics
                  ↓
             Self State Candidate
                  ↓
              Self State Reducer
                  ↓
              A Route Context
```

Self State constrains situated understanding but does not interpret the world or
select an Action. Identity remains continuous while capability, health, resource,
and limitation change.
