# Reality Workspace Fact Layer Go/No-Go v1

## Required contracts

- Evidence ≠ Fact; Fact ≠ Reality; Reality State ≠ Situation.
- Evidence Intake cannot write World State directly.
- Evidence Assembly produces Reality Candidate, not a fact or decision.
- Reality State Reducer remains the sole State mutation authority.
- Current World State preserves provenance, validity, confidence, conflict, and Unknown.
- Self Reality State includes Identity, Capability, Resource, Limitation, and Current Condition; Self State ≠ Personality.
- Situated Context outputs Situation Candidate only and cannot bypass Brain.

## Hard prohibitions

No real model, No OCR Runtime, no SLAM Runtime, no Hardware, no Action, no B Route,
no Emotional Engine, no Runtime, no automatic learning, and no direct state
mutation outside the Reducer. The workspace cannot modify Goal, Intent, or
Decision.

## Verification handoff

The agent performs planning and V0 static checks only. User Terminal must run the
phase verifier and return all required sections. The agent then stops at
`WAITING_FOR_USER_TERMINAL_VERIFICATION`.

Target output: `COGNITIVE_REALITY_WORKSPACE_FACT_LAYER_READY_WITH_NOTES`.
