# Cognitive Kernel Responsibility Model v1

## Definition

The Cognitive Kernel is a consistency-governance layer for candidate-based cognitive organization. It does not produce perception, representations, schemas, hypotheses, evaluations, decisions, or actions.

## Five responsibilities

1. **Global Constraint** — emits constraints aligned with Survival Priority, Reality First, Candidate First, Safety Boundary, and Resource Boundary.
2. **Cognitive Consistency** — detects directional, contextual, attentional, resource, and evidence inconsistencies across candidates.
3. **Cross Module Arbitration** — produces Arbitration Candidates for attention, capability, resource, and goal conflicts.
4. **Cognitive Mode Candidate** — represents a bounded operating-mode proposal for the current process context.
5. **Future Extension Boundary** — admits future extension influence only as Candidate input.

## Constraint ordering examples

```text
Evidence > Experience
Reality evidence > Hypothesis
Safety boundary > Efficiency preference
Resource boundary > unlimited cognitive expansion
```

These are governance constraints, not truth-generation rules, decisions, or action commands.

## Explicit non-responsibilities

The Kernel cannot select a final option, invoke a module, allocate actual hardware, execute a process, store experience, alter reality, or write Reducer-owned State.
