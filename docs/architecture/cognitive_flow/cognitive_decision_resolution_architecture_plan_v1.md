# Decision Resolution Architecture Plan v1

## Position

Decision Resolution Candidate is a candidate-only convergence layer between Decision Candidate Formation and Decision Commitment:

`Behavior Candidate -> Cognitive Value Evaluation -> Decision Candidate -> Decision Resolution Candidate -> Commitment Candidate -> Future Decision`.

It expresses how a current Choice Space may be narrowed, deferred, escalated, or left uncertain under Context, Survival, Mission, Time Budget, and Value Evaluation constraints. It does not choose an answer, make a Decision, execute an Action, grant Permission, or mutate State.

## Resolution functions

1. Constraint Filtering;
2. Value Comparison;
3. Risk/Reward Balance;
4. Uncertainty Handling;
5. Reversibility Preference; and
6. Decision Deferral.

Each function produces traceable candidate reasoning only. The final selection remains outside this phase.
