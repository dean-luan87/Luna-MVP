# Cognitive Evolution Feedback Loop Boundary Contract v1

## Allowed candidate references

Genome, individual experience/representation/primitive, compression, local/population validation, culture/gene-pool, Hive future boundary, survival/value/pressure/selection/diversity, provenance, and trace references may be read.

## Rejected inputs and effects

Learning Runtime, Evolution Runtime, Hive Runtime, Memory mutation, automatic self rewrite, automatic capability growth, model training, distributed learning, raw model/provider output, Decision result, Action command, permission, State handle, Reducer command, and State mutation are outside this layer.

## Negative guards

- Evolution != Learning.
- Evolution != Automatic Change.
- Candidate != Adoption.
- Adaptation != Rewrite.
- Gene Pool != Hive Runtime.
- Gene Pool != Central Brain.
- Gene Pool != Truth Database.
- Gene Pool != Rule Authority.
- Gene Pool != Individual Override.
- Culture != Rule.
- Culture != Truth.
- Culture != Constitution.
- Individual != Population.
- Propagation != Automatic Learning.
- Propagation != Copy.
- Propagation != Authority.
- Receive != Learn.
- Inherit != Accept.
- Frequency != Value.
- Popularity != Truth.
- History != Future Applicability.
- Experience != Knowledge.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not learning, not self rewrite, not capability growth, not memory/hive write, not decision, not action, not permission, and not state mutation.
