# Cognitive Attention Source Arbitration Model v1

Source Arbitration Candidate compares the origin, urgency, goal relevance, risk, information value, resource cost, current allocation stability, and uncertainty of requests from the Attention Origin Hierarchy.

```text
Source Candidates -> Origin-aware Arbitration Candidate
  -> Controller Allocation Candidate
```

Attention Priority != Reality Importance and Attention Priority != Cognitive Value. A highly salient plastic bag may receive short input attention while low-value for the current cognitive goal. Arbitration does not create truth, suppress a source permanently, decide, or act.
