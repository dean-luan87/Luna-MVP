# Cognitive System Architecture Reconciliation Risk Review v1

## Risk review

| Risk | Failure mode | Frozen mitigation | Residual review trigger |
|---|---|---|---|
| Neural becomes a new Brain | Protocol Manager begins generating goals, prioritizing attention, or interpreting signals as facts | Neural is limited to transport, classification, compatibility, trace, and evolution proposal governance | Any Neural design that writes Context/Goal/Attention or emits a decision |
| Middleware regains Decision authority | Capability feasibility/model ranking silently selects task direction or final action | Middleware returns capability/resource/evidence/failure candidates only; Brain owns cognitive evaluation | Any route from model/capability output to decision/action bypassing Brain evaluation |
| Capability Manager replaces Attention | Available/strong provider creates autonomous observation/task or changes priority | Attention-bound Brain request is upstream; capability availability is only a constraint/alternative | Provider availability causing a new request without an Attention candidate |
| Experience contaminates Reality | Experience pattern is treated as current evidence or overrides contrary observation | Experience only creates adaptation/guidance candidates; Evidence/Reality remain higher verification proximity | Experience pattern changes context/evidence status without validation |
| Simulation contaminates Reality State | Hypothesis/future branch is stored as fact, evidence, or State | Simulation path is Brain-internal and produces candidates only; no evidence/Reducer path | Simulation result appears in Evidence Gateway or State mutation path |
| Self State becomes Middleware state authority | Resource/health data overwrites Brain's cognitive self understanding | Middleware emits State Signals; Brain forms Self State Candidate | Middleware directly writes Self State/Attention/Goal |
| Whitebox becomes control plane | UI writes priority, sessions, provider selection, or State | Whitebox v2 is trace projection only | New UI endpoint or interactive control proposal |

## Mandatory review questions for later phases

1. Does the proposed component create a goal, allocate attention, judge truth, decide, act, or mutate State?
2. Does any raw provider output reach Brain without Evidence Gateway and Neural classification?
3. Can a signal version/payload change introduce hidden authority?
4. Can Experience or Simulation cross into current Reality/Evidence without validation?
5. Does a local safety mechanism exceed device protection into a world action?

## Conclusion

The v2 four-layer model contains the identified risks only if every future integration maintains candidate-only, evidence-first, protocol-governed paths. This is a planning conclusion; it does not authorize integration.
