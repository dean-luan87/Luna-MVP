# Cognitive Kernel Boundary Contract v1

## Frozen boundaries

- Kernel is not Decision.
- Kernel is not Planner.
- Kernel is not Controller Override.
- Kernel is not Reality Authority.
- Kernel is not Runtime Engine, Scheduler, or Kernel Runtime.
- Kernel is not Action.
- Kernel is not Memory or Experience Storage.
- Kernel is not Emotion.
- Kernel is not Personality.
- Kernel is not Hive.
- Kernel is not World Model.
- Kernel is not Reality State.
- Kernel is not Reducer.
- Constraint Candidate is not State Mutation.
- Consistency Candidate is not Truth.
- Arbitration Candidate is not Final Choice.
- Cognitive Mode Candidate is not a State Machine.
- Process Composer is not Task Planning.
- Cognitive Process Candidate is not Process Executor input with automatic execution.
- Process Admission Candidate is not Runtime Execution.
- Runtime Execution Candidate is not Model Invocation or Action Execution.
- Outcome Observation is not automatic learning.
- Future extensions are Candidate Only and cannot modify Kernel authority.
- Reducer remains the only State Mutation Authority.

## Authority flow

```text
Candidates -> Kernel Constraint / Consistency / Arbitration Candidates
  -> Organization Candidates -> future runtime admission candidate
  -> Outcome / Feedback Candidates
```

No path grants a Kernel, Composer, capability, process, extension, or runtime candidate permission to alter reality, execute an action, rewrite cognition, or mutate State.
