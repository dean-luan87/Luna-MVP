# Cognitive Reasoning Tree Preemption Model v1

## Preemption candidate

Reasoning Tree Preemption Candidate expresses that a higher-priority Survival, urgency, Context, or Field-Dynamics condition may justify reviewing a current Reasoning Tree for compression, suspension, termination, or replacement by a higher-priority cognitive path.

It is analogous to a candidate resource-allocation request, not an operating-system scheduler. The candidate cannot suspend a Runtime, delete a reasoning branch, trigger a response, or establish truth.

## Preservation rule

Preempted trees retain provenance, hypotheses, uncertainty, evidence, and lifecycle references. Lower-priority reasoning can be suspended rather than discarded; completion/termination remains non-Fact and non-Decision.
