# Cognitive Future Extension Boundary v1

| Future layer | May provide candidate inputs | Must not provide |
|---|---|---|
| Emotion Engine | Value Adjustment, Attention Bias, Preference, Relationship Context candidates | Decision, Permission, Reality Rewrite, override |
| World Model | Field Understanding, Causal, Future State candidates | truth authority, State mutation, Decision, Action |
| Hive | Population Experience, Culture, Gene Pool candidates | individual override, local-context override, central-brain authority |
| Language System | Human communication, representation expression/interpretation candidates | internal representation authority, direct action, truth authority |
| Future Embodiment | capability/constraint references | autonomous execution, permission, State authority |

Every future candidate remains subject to Current Context, Evidence, Value, and governance validation.
