# Predictive Field State Model Definition v1

`FutureFieldStateCandidateV1` describes a possible future Field change. It contains Current Field Reference, Current State Reference, Evolution Pattern Candidate, Time Window, Trigger Condition Candidate, Expected Change Candidate, Uncertainty, Alternative Futures, Provenance, and Trace Reference.

It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.

The future reference is a possibility horizon, not a current Field State or promise that change will occur.
