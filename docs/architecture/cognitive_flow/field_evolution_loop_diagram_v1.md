# Field Evolution Loop Diagram v1

```text
Candidate cognition / Current Field View
        -> Field Event Candidate
        -> Admission + Temporal Validity
        -> Admitted Event
        -> Reducer (only State mutation authority)
        -> Field State
        -> Temporal Evolution + derived Snapshot
        -> next read-only Current Field View

Reviewed outcomes -> Experience Candidate -> Learning Review Candidate -> future Hive association
```

The lower path cannot back-write State, Memory, Fact, Decision, or Action.
