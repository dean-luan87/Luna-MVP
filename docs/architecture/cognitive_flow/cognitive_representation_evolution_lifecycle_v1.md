# Cognitive Representation Evolution Lifecycle v1

Evolution lifecycle candidates:

`Raw Experience / Observation / Outcome -> Candidate Representation -> Context Validation -> Representation Usage -> Value Evaluation -> Strengthening / Weakening -> Mutation Candidate -> Validation -> Controlled Adoption Candidate -> New Representation Candidate`.

Repeated validation may form Context-Bound Representation, Stable Cognitive Pattern, or Adaptive Cognitive Pattern Candidate. No stage is fact, rule, automatic learning, or direct adoption authority.
