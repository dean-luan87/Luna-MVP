# A-Route Extension Interface Contract v1

## Permitted attachment path

```text
Evidence Extension
        ↓
World Understanding Extension
        ↓
Situation Enhancement Candidate
        ↓
Decision Support Candidate
        ↓
Outcome / Feedback Extension Candidate
```

Extensions may add candidates and traceable information through these existing interfaces.
They cannot directly modify a Decision Candidate, Brain, Self Model, Strategy, Attention runtime, Resource State, Provider plan, Action, or Reducer State.

Every material extension must declare candidate schema, authority boundary, unknown handling, trace fields, scenario additions, and simulation-baseline regression requirements before adoption.
