# Cognitive Attention Route Admission Model v1

The Cognitive Attention Controller provides an A/B Route Admission Candidate after aggregating depth, budget, direction, sufficiency, risk, unknown impact, and time/resource constraints.

```text
Active Cognitive Allocation Candidate
  -> A Route Admission Candidate | Need Deep Reasoning Candidate | Defer Candidate
```

The Controller decides only whether cognitive investment is warranted. A/B Route Admission != B Route execution, answer selection, Decision, Action, or Permission.
