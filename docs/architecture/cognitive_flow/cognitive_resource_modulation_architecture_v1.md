# Cognitive Resource Modulation Architecture v1

Resource Modulation Candidate translates Self State, hardware/capability availability candidates, runtime-load candidates, battery/resource candidates, model-availability candidates, and reliability candidates into bounded cognitive constraints.

Possible outputs: Attention Budget Candidate, Reasoning Depth Candidate, Simulation Depth Candidate, Evidence Request Level Candidate, and exploration/defer candidates.

Example: low-resource context can prefer A-route candidates, lower sampling/depth candidates, and preserve high-value experience references. Resource Modulation != scheduler, device control, capability shutdown, B Route execution, Decision, Action, or State mutation.
