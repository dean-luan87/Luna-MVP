# Cognitive Resource Allocation Model Definition v1

`CognitiveResourceAllocationCandidateV1` may reference survival pressure, context, goal, risk, information value, self capability/resource awareness, time constraint, experience, future-space and reasoning references, provenance, and trace.

It may describe observation increase, exploration reduction, reasoning-depth limit, alternative-branch preservation, information-search stop, or other non-executing cognitive resource allocation candidates.

It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_scheduler=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
