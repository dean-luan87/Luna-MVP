# Cognitive Active Attention Architecture v1

Active Attention is goal/context-driven information seeking at the candidate level.

```text
Active Goal + Context + Unknown / Sufficiency Candidate
  -> Information Need Candidate
  -> Active Attention Candidate
  -> Perception Request Candidate
```

Active Attention can request that a future Perception Adapter seek bounded evidence such as EXIT signs, entrances, or current route markers. It does not execute sensing, move a device, call a model, decide an answer, or action a plan.
