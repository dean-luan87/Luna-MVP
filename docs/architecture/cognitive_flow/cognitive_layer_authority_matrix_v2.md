# Cognitive Layer Authority Matrix v2

| Layer | Owns | Must not own |
|---|---|---|
| Brain | Intent, Goal, final judgment, Decision acceptance | direct hardware call, Middleware bypass, Reality State mutation |
| A Route | Situation, Decision Candidate, Outcome Interpretation | autonomous Action, Self mutation, Reality mutation |
| Neural | fast response candidate, state maintenance candidate, risk escalation | long-term Goal, final Decision, Reality Interpretation |
| Reality Workspace | Evidence assembly, World State projection, validity, Unknown | Action, Goal, Intent, Decision |
| Registry | capability description, state description, provenance | cognition, Situation, Goal, Decision |
| Middleware | capability/resource governance, admission, protocol, diagnostics | world understanding, value judgment, final Decision |
| Hardware Manager | registration, health, lifecycle, capability profile | direct Hardware control, Goal, Reality interpretation |
| Experience | historical reference and candidate pattern | direct current-fact replacement, automatic Self mutation |
| Reducer | sole State mutation authority | Goal, value, Decision, Action |

The matrix is a review contract. A capability or model output cannot acquire
authority merely by producing high-confidence data.
