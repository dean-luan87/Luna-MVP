# Decision Evaluation Model v1

## Purpose

Decision Evaluation compares each Option Candidate against explicit,
traceable dimensions. It produces a `Decision Evaluation Candidate`, not a
truth claim or a choice.

| Dimension | Evaluation question |
|---|---|
| Survival Impact | Does the option appear consistent with safe, constitutional continuity? |
| Goal Alignment | Does it address the current Goal Context? |
| Capability Fit | Is it within current Self Capability and feasibility boundaries? |
| Resource Cost | What candidate time, compute, energy, attention, and embodiment cost applies? |
| Risk and Uncertainty | What present/potential risk and unresolved unknowns remain? |
| Experience Reference | What validated, context-relevant historical pattern is available? |

The evaluation retains conflicting evidence, unknowns, resource limits, and
hypothesis labels. Experience only provides a candidate reference; it cannot
select an option. Evaluation does not issue a Decision, invoke a Provider, or
modify Attention/State.
