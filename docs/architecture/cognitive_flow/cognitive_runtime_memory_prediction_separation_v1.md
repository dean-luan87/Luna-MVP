# Cognitive Runtime, Memory, and Prediction Separation v1

## Present / past / future contract

```text
Past: Experience / Representation / Culture Candidate
  -> Context Match + Local Validation
  -> Present Support Candidate

Present: Observation / Situation / Context / Attention / Reasoning Candidate
  -> Evaluation / Decision / Commitment Candidate

Future: Hypothesis / Counterfactual / Future Space Candidate
  -> Preparation / Attention / Reasoning Support Candidate
```

## Boundaries

- The present layer answers what may currently be understood; it does not automatically store or evolve itself.
- The past layer retains only context-bound reusable candidates; it does not replace present evidence.
- The future layer preserves possibilities and uncertainty; it does not confirm events or execute behavior.
- Fast cognitive cycles and slow experience/evolution cycles remain distinct. A single outcome cannot directly alter foundational representation or population culture.

## Negative guards

- Memory != Current Context.
- Experience != Reality Replacement.
- Prediction != Current Observation.
- Future Space != Decision.
- Culture != Local Override.
- Runtime Candidate != State Mutation.
