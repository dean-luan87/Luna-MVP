# Field Event Spatio-Temporal Architecture Plan v1

`Field Event = Spatio-Temporal Field Transformation Candidate`.

It describes how a bounded Field may be changing across a jointly scoped space-time condition. It is not Event Log, Fact, State, History, Memory, Decision, Action, or Reducer command.

`Current Field View -> Field Event Candidate -> Admission -> Admitted Event -> Reducer -> New Field State` remains the only state path.
