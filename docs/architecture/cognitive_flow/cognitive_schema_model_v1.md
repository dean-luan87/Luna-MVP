# Cognitive Schema Model v1

A Cognitive Schema Candidate may contain entity/relation/state/event/goal/constraint/pattern/unknown references, sequence candidate, causal candidate, applicability boundary, exception/failure conditions, risk, provenance, trace, and activation reference.

Airport-travel schema example: arrive-before-flight goal; prepare/leave/transport/security/board sequence candidates; time/ticket/security constraints; traffic/queue/delay risks; weather/crowding unknowns; early-departure pattern guidance. It is a way to organize understanding, not a current plan or fact.
