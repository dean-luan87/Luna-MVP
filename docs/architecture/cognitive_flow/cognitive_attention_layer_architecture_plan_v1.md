# Cognitive Attention Layer Architecture Plan v1

## Position

Attention Layer is Luna's Cognitive Resource Allocation Layer. Under limited observation, time, and computation, it selects which candidate information is worth further cognitive processing.

It is not Vision Attention, Transformer Attention, a Decision Engine, Action Controller, Permission System, Fact authority, or State authority. It does not decide what Luna should do.

## Hierarchy

`Survival Constitution -> Attention Priority Candidate -> Current Field View -> Primitive / Concept Selection Candidate -> Cognitive Processing -> Candidate Generation`

Survival constrains priority; Attention allocates cognitive focus; cognition interprets; future Decision and Action remain separately governed.

## Scope

This is architecture only. No automatic attention calculation, runtime, model attention, external capability integration, Decision, Action, Permission, Learning write, or Hive write is authorized.
