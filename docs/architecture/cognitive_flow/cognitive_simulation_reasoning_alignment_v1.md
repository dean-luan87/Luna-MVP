# Cognitive Simulation Reasoning Alignment v1

A Route may use existing schemas for bounded quick future candidates. B Route may expand Simulation Space with causal, counterfactual, future-space, and optimization candidates when risk/value/uncertainty justify resource cost.

`B Route = Simulation Space Expansion + Causal Reasoning + Counterfactual Reasoning`.

Simulation expansion != Higher Intelligence, Fact, Decision, Action, or default processing path. Reasoning/Evaluation receive simulation outputs as candidate support only.
