# Cognitive Knowledge Boundary Contract v1

## Allowed candidate references

Governed external knowledge, Experience, Library/Hive, Context, Self Reference, Field, Hypothesis, Belief, temporal/spatial scope, provenance, and trace references may be read.

## Rejected inputs and effects

Knowledge Runtime, Retrieval Engine, raw provider/model output, Fact Store authority, Memory mutation, Learning system, Decision result, Action command, permission, State handle, Reducer command, and local Hive authority are outside this layer.

## Negative guards

- Knowledge != Fact.
- Knowledge != Reality.
- Knowledge != Hypothesis.
- Knowledge != Belief Authority.
- Knowledge != Decision.
- Knowledge != Action.
- Knowledge != Permission.
- Experience != Rule.
- Experience != Truth.
- Experience != Automatic Shortcut.
- Hive != Reality.
- Hive != Constitution.
- Hive != Local Decision Authority.
- Retrieval != Understanding.
- Confidence != Authority.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not state mutation, not decision, not action, not permission, and not memory.
