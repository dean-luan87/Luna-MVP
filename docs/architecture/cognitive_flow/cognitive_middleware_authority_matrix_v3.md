## Frozen rules

1. Cognitive Middleware organizes execution infrastructure; it has no cognitive authority.
2. Model/Provider Management has no task-decision authority; all capability needs originate from CWO-derived requirements.
3. Registry, Admission, Manifest, Baseline, Lifecycle, and Diagnostics are governance/execution inputs—not a Brain.
4. Evidence Gateway is a packaging/provenance boundary, not a truth engine.
5. Reducer remains the sole State Mutation Authority.
