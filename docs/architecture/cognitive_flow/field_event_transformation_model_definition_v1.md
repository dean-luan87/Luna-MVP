# Field Event Transformation Model Definition v1

`FieldEventCandidateV1` contains candidate identity, Field/source-view references, Before Field Condition reference, Transformation Pattern, After Field Condition Candidate reference, unified Spatio-Temporal Field Scope, confidence, uncertainty, provenance, trace, and candidate status.

Spatial scope includes affected field area, entity-relation scope, and topology relation. Temporal scope includes observation/transition/validity windows and uncertain duration. Space and time are inseparable Field Scope, not independent Event modules.

Transformation categories: Structural, Population, Behavior, Relationship, Risk, and Context. All remain candidate descriptions.
