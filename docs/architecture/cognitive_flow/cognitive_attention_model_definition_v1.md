# Cognitive Attention Model Definition v1

## Attention Candidate

A future Attention Candidate may reference a Field, Primitive Candidate, Concept Candidate, Event Candidate, Context Candidate, task, provenance, and trace. It represents a request for further observation, comparison, or understanding—not a conclusion or command.

## Future priority dimensions

1. Survival Relevance;
2. Risk Relevance;
3. Task Relevance;
4. Change Intensity;
5. Uncertainty;
6. Opportunity Value; and
7. Historical Experience reference.

No individual dimension, including confidence, determines attention authority. Any future aggregation must preserve uncertainty, provenance, candidate status, and L1 governance.

## Candidate-only boundary

Attention priority never produces Fact, Decision, Action, Permission, Field State, Snapshot mutation, or Memory update.
