# Cognitive Evidence / Attention Alignment v1

Evidence Field retains the available candidate set; Cognitive Attention chooses which evidence candidates are active for the current task.

```text
Evidence Field -> Evidence Attention Candidate -> Attention Evaluation -> Active Evidence Candidate Set
```

Attention does not delete inactive evidence or decide evidence truth. In an airport, a sign, boarding pass, and time candidate may become active while unrelated objects remain in the Evidence Field.
