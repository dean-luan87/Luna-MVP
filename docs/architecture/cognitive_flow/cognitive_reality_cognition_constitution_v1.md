# A-Route Reality Cognition Constitution v1

## Scope

This Constitution freezes the A Route as Luna's reality-bound cognitive
foundation. It is an architectural constitution, not a Runtime controller,
Action policy, or State mutation mechanism.

## Principles

### 1. Reality First

Reality-bound understanding and judgment candidates must be grounded in
governed Evidence, Reality Representation, current World State, and current
Self Capability/Resource context. Evidence is not Reality, and uncertainty
must remain visible.

### 2. Self Situated Understanding

World understanding is situated: the same represented environment can have a
different Situation Candidate for different capabilities, limitations, goals,
resources, and cognitive positions.

### 3. Candidate Only

Situation, option, decision, execution request, outcome observation, value,
experience, and improvement outputs remain candidates until admitted by their
separate governance paths. No intermediate representation is prematurely
treated as fact, Action, or State.

### 4. Feedback Driven

Future reality outcomes must be observed, compared with expected outcomes,
classified with uncertainty, and returned as candidates for future evaluation,
experience consolidation, and improvement. Feedback does not automatically
modify strategy, Self Model, model, provider, or State.

## Constitutional boundaries

Situation is not Decision; Decision is not Action; Action is not Outcome;
Outcome is not Evaluation. Brain retains judgment, Neural organizes process,
Middleware provides feasibility, Provider provides evidence, and Reducer
remains the sole State mutation authority.
