# Emotion Influence Boundary v1

## Allowed influence

Emotional/relationship meaning may produce candidates that influence what is
worth attending to and how a Decision Evaluation presents trade-offs:

```text
Emotion / Relationship Context Candidate
        ↓
Decision Weight Candidate / Attention Bias Candidate
        ↓
Brain Evaluation
        ↓
Decision Candidate
```

## Prohibited influence

- Emotion does not modify Reality, Evidence, World State, or factual uncertainty.
- Emotion does not directly create an Action, Decision, Goal, provider call,
  Resource allocation, or State mutation.
- Emotion does not override Survival Constitution, safety, non-harm, consent,
  self continuity, Brain judgment, or Reducer authority.

Emotion supplies value weights; Reality Cognition supplies possibility space.
Neither subsystem is sufficient to issue an Action.
