# Cognitive Deep Reasoning Foundation Architecture Plan v1

## Actual asset mapping

This B-route foundation aligns with Survival Constitution, Current Context, Cognitive Mode Switching, Dynamic Cognitive Time Regulation, Cognitive Depth Regulation, Cognitive Resource Allocation, Causality, Counterfactual Reasoning, Possible Future Space, Future Branch Governance, Optimization, Experience/Knowledge Boundaries, Decision Candidate, Reducer Authority, and L0/L1 Governance.

## Position

`Cognitive Mode Switching -> Cognitive Depth Regulation -> Deep Reasoning Candidate -> Causality -> Counterfactual Reasoning -> Future Space -> Optimization -> Decision Candidate`.

Deep Reasoning is not longer thought. It is a candidate mode for high-value, high-risk, or high-uncertainty questions that may require multiple possible-world expansions and path evaluation.

## A/B relationship

A route supports fast cognition, response, and low-cost candidate formation. B route supports bounded deep examination when conditions justify it. They are complementary cognitive modes, not intelligence levels or a hierarchy.

## Planning scope

No Reasoning Runtime, LLM chain, inference engine, simulation, Decision execution, Action, or State Mutation is authorized.
