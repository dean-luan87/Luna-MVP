# Cognitive Attention Field Alignment v1

## Field relationship

Field Representation and Current Field View supply candidate objects for attention: Entity/Primitive Candidates, Concept Candidates, Event Candidates, and Context Candidates.

`Field Representation / Current Field View -> Attention Evaluation Candidate -> Attention Candidate -> Cognitive Processing Candidate`

Attention selects what warrants further cognitive work. It does not edit the selected object, promote it to Fact, classify a Field, mutate a Snapshot, submit an Event, or invoke Reducer.

## Authority separation

Field Kernel continues to organize/query governed references. Field Event remains a change candidate. Admission remains event eligibility governance. Reducer remains the sole Field State Mutation Authority.
