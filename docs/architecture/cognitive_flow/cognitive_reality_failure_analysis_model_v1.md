# Reality Failure Analysis Model v1

## Purpose

Reality Failure Analysis avoids collapsing every unexpected outcome into one
failure label. It forms evidence-linked explanatory candidates for future
evaluation and reflection; it does not assign blame or immediately change a
strategy.

| Failure class | Candidate question |
|---|---|
| Perception Failure | was relevant evidence missing, distorted, or incorrectly observed? |
| Understanding Failure | was the represented relation/situation unsupported or incomplete? |
| Decision Failure | did the selected option fit the available situation and constraints poorly? |
| Execution Failure | did a future execution boundary/status fail to realize an admitted request? |
| Environment Change | did the represented world materially change after formation? |
| Resource Constraint | did capability/resource envelopes prevent the expected path? |

Multiple classes may coexist, and `Unknown Cause` remains valid. Failure
Analysis preserves uncertainty and trace links. It never treats no evidence as
no event, writes to Memory/Self Model, trains a model, or directly adjusts a
Decision/Action.
