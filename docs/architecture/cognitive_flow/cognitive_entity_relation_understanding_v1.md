# Cognitive Entity Relation Understanding v1

`Entity Relationship Graph Candidate` is a small, current-cognitive-scope graph of entities and possible relations. It is not a complete world graph.

```text
User -> Ticket -> Gate -> Terminal
```

Nodes and edges carry evidence, context/scope, confidence candidates, unknowns, provenance, and trace. Entity Relationship Candidate != Entity Fact, Relationship Fact, Causal Fact, or Knowledge Graph authority.
