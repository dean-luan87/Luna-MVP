# Cognitive Tick Coordination Model v1

## Tick candidate phases

1. Trigger Assessment Candidate — whether a cognitive cycle is warranted.
2. Snapshot Formation Candidate — Field, Situation, Context, Goal, Attention, Unknown, and Hypothesis references.
3. Module Activation Candidate — eligible subsystems and requested contribution types.
4. Candidate Collection Candidate — candidate references with boundary, uncertainty, provenance, and trace.
5. Unified Cognitive Candidate View — an integrated, unresolved input to Evaluation.

Tick Coordination != Runtime tick loop, State Machine transition, scheduler operation, Decision, Action, or Reducer mutation.
