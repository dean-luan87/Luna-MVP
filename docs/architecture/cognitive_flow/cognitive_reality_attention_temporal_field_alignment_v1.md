# A-Route Attention / Temporal / Field Alignment v1

## Temporal coupling

Temporal Understanding may increase the relevance of an Attention Context
Candidate when a represented condition is new, abrupt, accelerating, cyclic,
or insufficiently observed.

```text
Temporal Change Candidate
        ↓
Attention Candidate
        ↓
Situation Enhancement Candidate
```

Example: a static roadside sign may remain low-priority; an observed collapse
candidate can raise attention relevance. This does not declare an emergency,
change tempo, or direct a response.

## Field relationship

Future Field work may combine `Field State Candidate` with an `Attention Axis
Candidate` to create a Relevant Field Representation Candidate. Attention is
the subject’s bounded relevance lens, not a filter that deletes unselected entities from Field or Reality.

```text
Future Field State Candidate
        +
Attention Axis Candidate
        ↓
Relevant Field Representation Candidate
```

Field Kernel integration is explicitly not implemented in this phase.
