# Cognitive Neural Regulation Model v1

Neural Regulation is a dynamic governance mechanism, not a resource class and not a cognitive Goal source. It interprets salience, context, risk, unknowns, and current system state into a `Regulation State Candidate`: Normal, Alert, or Critical.

The Regulation State governs how existing resource candidates may be reweighted. It does not directly allocate CPU/GPU, modify Attention Runtime, start an Assembly, control hardware, or create a decision.
