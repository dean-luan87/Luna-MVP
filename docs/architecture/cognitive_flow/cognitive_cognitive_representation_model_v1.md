# Internal Cognitive Representation Model v1

Internal Cognitive Representation is a candidate internal cognitive form containing compressed structure, pattern, relation, causal/condition/boundary, exception, uncertainty, applicability, provenance, and trace references.

It is not natural language, Language Generation, Knowledge, Fact, Memory, Rule, Hive Asset, Embedding, or vector database record. It may only support governed context matching, decompression, and future understanding candidates.
