# Cognitive Goal Understanding Model Definition v1

`CognitiveGoalUnderstandingCandidateV1` may retain user-input, context, situation, mission reference, capability, assistance, goal type, sub-goal, constraint, success-condition, uncertainty, provenance, and trace references.

It supports Unknown Goal, Conflicting Goal, Changing Goal, and Hidden Goal. It remains `candidate_only=true`, `not_fact=true`, `not_state_mutation=true`, `not_command=true`, `not_mission=true`, `not_identity=true`, `not_emotion=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
