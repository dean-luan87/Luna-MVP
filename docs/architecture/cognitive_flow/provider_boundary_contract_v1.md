# Provider Boundary Contract v1

## Provider role

A Provider Candidate supplies a declared Capability. It may produce an Evidence
Candidate through the Evidence Gateway. A Provider is not a cognitive subject.

Provider has **no Truth**, **no Decision**, **no Reality**, and **no Brain
authority**. It cannot create a Goal, interpret a Situation, modify Self, or
write State. Its output is bounded by the admitted input and output contracts.

## Execution boundary

Provider Execution Boundary is a contract marker for a future execution system;
this phase does not execute a Provider, call a model, run OCR, or access hardware.
Admission, replacement, and failure fixtures remain static candidates.

## Replacement invariant

Provider A and Provider B may both satisfy `text_evidence_extraction`. Replacing
one with the other must preserve the Capability contract and A Route structure.
Only Evidence Quality Candidate, confidence, limitation, or failure trace may
differ.
