# Cognitive Evolution Selection Model v1

Evolution governance candidates include:

- Mutation: possible new field, relation, or representation candidate;
- Selection: survival value, utility, generalization, resource efficiency, reliability, and local-context candidate comparison;
- Retention: high-value, stable, or long-effective pattern candidates;
- Extinction: reduced-weight, dormant, archive, or retirement candidates.

Evolution is not Random Growth or Self Rewrite. Selection does not automatically adopt, delete, synchronize, or create a rule.
