# Cognitive Depth Regulation Model Definition v1

`CognitiveDepthRegulationCandidate` may retain Context Reference, Survival Pressure, Risk Level Candidate, Time Constraint, Information Value, Experience Match, Knowledge Match, Uncertainty Level, Required Cognitive Mode, Depth Boundary, provenance, and trace.

The modes are cognitive-path candidates, not fixed numeric levels:

- Reactive Response Candidate — short window, high survival/risk pressure;
- Pattern Match Candidate — bounded reuse of traceable mature experience;
- Exploration Candidate — lower-risk, information-value-oriented expansion; and
- Deep Reasoning Candidate — high value/uncertainty with sufficient time.

Mode selection never executes behavior or proves that an interpretation is true.
