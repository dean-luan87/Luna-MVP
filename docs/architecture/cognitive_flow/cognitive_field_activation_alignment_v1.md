# Cognitive Field Activation Alignment v1

Field Driven Activation Candidate aligns Current Field, Situation, spatial relation, environmental pattern, event pattern, and risk pattern with retained representations.

Example: intersection + vehicle + night may form a Safety Representation Activation Candidate. It must still pass Context, Validity, and Resource checks before entering candidate space.

Field Activation != User Request, reality confirmation, Attention selection, Decision, Action, or Permission.
