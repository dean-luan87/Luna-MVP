# Cognitive Hypothesis Attention Alignment v1

Attention determines which Hypothesis Candidates warrant validation or further observation. It does not confirm, reject, or execute a hypothesis.

`Hypothesis Candidate -> Information Value Evaluation -> Observation Priority Candidate -> Future Observation Planning`

This is not `Hypothesis -> Action`. Hypothesis remains a possible-world expression; Attention, Information Value, Context, Survival, and L1 governance preserve the candidate boundary.
