# Cognitive State Transition Trigger Model v1

Transition trigger candidates may reference: Field Change, Context Change, Role Reference Change, Goal Change, Survival Pressure Change, Cognitive Failure Signal, or Time Constraint Change.

Cognitive Failure Signal may describe no-progress, repeated unvalidated hypotheses, obsolete reasoning, or unresolved conflict. It is not a failure Fact and cannot force a transition. All triggers retain uncertainty and evidence lineage.
