# Cognitive Retention Lifecycle Model v1

## Lifecycle

`Candidate -> Activated -> Maintained -> Validated -> Strengthened -> Decayed -> Dormant -> Reactivated -> Retired`.

- Strengthened: repeated context-bound validation supports continued relevance.
- Decayed: lack of use, changed conditions, or applicability decline lowers active priority.
- Dormant: inactive but not deleted.
- Reactivated: a new Field/Task/Context match requests renewed validation.
- Retired: long-term low value is proposed after governed review.

## Frozen interpretation

Unused != Wrong. Old != Invalid. Frequency != Value. Lifecycle is a candidate description, not a Runtime State Machine, automatic deletion policy, or Evolution adoption path.
