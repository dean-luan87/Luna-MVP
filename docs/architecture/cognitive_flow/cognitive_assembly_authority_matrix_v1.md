# Assembly Authority Matrix v1

| Authority | Owner |
|---|---|
| Goal / Value | Brain |
| Coordination | Neural Governance |
| Organization | Assembly |
| Local activity pattern | Process |
| Ability request | Capability |
| Evidence production | Provider |
| State mutation | Reducer only |

No Assembly/Process/Capability/Provider owns final Truth, Decision, or State Mutation authority. Neural has no final value-arbitration authority.
