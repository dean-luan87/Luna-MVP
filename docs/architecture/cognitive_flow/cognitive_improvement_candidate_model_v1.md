# Cognitive Improvement Candidate Model v1

Improvement Candidate proposes future adjustment such as extra accident-risk check, attention-priority revision, schema exception candidate, representation refinement, simulation pattern candidate, or evaluation metric review.

It must include target layer, rationale, evidence, context/applicability boundary, expected value, risk, reversibility, validation requirement, provenance, and trace. Improvement != immediate modification, Learning mutation, rule, Decision, Action, or State mutation.
