# Cognitive Counterfactual Reflection Model v1

## Purpose

Counterfactual Reflection asks “what alternative interpretation, strategy,
capability, or relationship approach might have produced a better candidate
outcome?” It examines the past or possible future without rewriting what
actually occurred.

```text
Experience Reference + Outcome / Value Feedback
                         ↓
      Explicit Counterfactual Assumption Candidate
                         ↓
 Alternative Strategy / Capability / Self Understanding Candidate
```

## Allowed questions

- If observation had focused on a different relation, what uncertainty might
  have remained or reduced?
- If communication had been more timely or less frequent, what relationship
  friction candidate might change?
- If a future capability existed, which present limitation could it address?

## Boundary

Counterfactuals preserve the actual Experience reference and label all changed
conditions. They cannot recast history as fact, assign blame, generate an
Action, make a Decision, or update Strategy/Self Model without validation.

Counterfactual Reflection does not rewrite what actually occurred.
