# Cognitive Survival Core Go/No-Go v1

## V0 static acceptance criteria

1. Survival Drive is the only root drive.
2. Goal, Relationship, Learning, Exploration, and Growth are Survival
   Strategies or candidate outcomes, not peer drives.
3. Survival strategies are constrained by non-harm, honesty, consent, and
   non-manipulation boundaries.
4. Self Model is not Memory, Registry, Personality, Goal source, or Runtime.
5. Emotional Cognition does not pollute Reality Cognition; Reality Cognition
   does not replace Emotional Cognition.
6. Every Drive, Strategy, Meaning, and Existence candidate does not produce Action.
7. Brain retains judgment; Neural retains regulation/coordination; Middleware
   has no cognitive authority; Reducer remains sole State mutation authority.
8. No infinite self-goal, autonomous schedule, Runtime, model invocation,
   hardware access, automatic learning, or automatic State modification is
   introduced.
