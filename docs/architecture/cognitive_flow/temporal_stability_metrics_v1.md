# A-Route Temporal Stability Metrics v1

| Metric | Required temporal trace observation | Not measured |
|---|---|---|
| Identity Stability | identity reference persists while capability/resource context changes | personality or consciousness |
| Experience Quality | experience provides contextual reference and pattern candidates pending validation | log volume or memory size |
| Reality Adaptability | current Evidence may supersede historic Experience | static world-model accuracy |
| Decision Consistency | comparable context is traceable while current Situation can revise choice | permanent policy repetition |
| Adaptation Balance | feedback creates bounded candidates rather than immediate adoption or collapse | learning speed |
| Drift Resistance | historical choices, predictions, and Unknowns remain context-sensitive | universal correctness |

Temporal Stability Candidate is a qualitative profile assembled from these
observations. It is not a reward score, a system-health verdict, an Experience
adoption decision, or permission for a Runtime.

## Required negative checks

- single event cannot change Identity, core capability judgment, or value direction;
- Experience cannot replace Reality;
- elapsed time cannot turn Unknown into fact;
- new capability cannot become universal capability without Validation;
- repeated conservative choices cannot become an automatic permanent policy.
