# Cognitive Assembly Member Model v1

Assembly Member is a bounded Process/Capability participation unit, not an Agent. It contributes to one Assembly cognitive purpose without independent Goal, Decision, long-term state, Personality, or Truth authority.

| Member type | Contribution | Boundary |
|---|---|---|
| Evidence Producer | Evidence Candidate from vision, OCR, audio, map, etc. | Does not interpret as Reality. |
| Context Builder | Evidence relationship, history, or spatial-context candidate | Does not overwrite Evidence. |
| Evaluation Support | Confidence, conflict, completeness candidates | Does not decide Truth. |
| Coordination Support | Observation-adjustment or missing-information candidate | Does not control device or Attention. |
