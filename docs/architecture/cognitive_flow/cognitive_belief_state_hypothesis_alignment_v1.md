# Cognitive Belief State Hypothesis Alignment v1

Hypothesis asks what the world may be. Belief State asks how Luna currently and provisionally holds those alternatives.

`Hypothesis Space -> Belief State Candidate -> Future Strategy Candidate`

If hypotheses are A/person, B/animal, and C/object, a belief distribution may order A > B > C without asserting A as reality. Multiple alternatives, conflict, and unknown remain valid.
