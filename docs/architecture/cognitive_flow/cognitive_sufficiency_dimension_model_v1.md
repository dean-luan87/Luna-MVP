# Cognitive Sufficiency Dimension Model v1

Sufficiency assessment may retain candidate dimensions for:

- Situation Sufficiency: current environment interpretation sufficiency;
- Goal Sufficiency: desired-result interpretation sufficiency;
- Risk Sufficiency: risk understanding sufficiency;
- Information Sufficiency: task-relevant information sufficiency;
- Uncertainty Impact: possible effect of unknowns;
- Time Sufficiency: available cognitive window;
- Resource Sufficiency: available cognitive resource references.

No dimension is a fact score, confidence authority, decision, action, or permission.
