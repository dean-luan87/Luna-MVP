# Cognitive Information Flow Final Boundary v1

Allowed flow: Evidence → Reality Representation → Situation → Decision
Candidate → Outcome → Experience Candidate.

Model output must enter as Model Evidence and cannot bypass Reality Cognition to
reach Brain. Experience is a Decision Reference and requires Reality
Confirmation; it cannot become current fact. Reality evidence cannot directly
replace value judgment or Brain final judgment.

Reality Confirmation is required before Experience can influence current decision reference.
