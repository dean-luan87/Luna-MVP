## Objective and position

Converge A-route modules into a Cognitive Organization Layer that coordinates candidate sources, resource constraints, capability-composition candidates, attention allocation, feedback, and future evolution without centralizing truth or execution authority.

```text
Luna Cognitive Foundation
  -> Cognitive Organization Layer
      -> Attention Governance Core
      -> Capability Composition Candidates
      -> Resource Modulation Candidates
      -> Evolution Feedback Candidates
  -> Cognitive Capability Layer
      Perception / Context / Workspace / Simulation / Operation / Evaluation
```

## Scope

## Out of scope
