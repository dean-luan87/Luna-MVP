# Field Kernel Spatio-Temporal Model Definition v1

`SpatioTemporalFieldStateReference` expresses Current Field through Spatial Structure + Temporal Existence + Entity Relation + Concept Meaning + Context + Task + Attention.

Spatial references cover topology, distance, accessibility, boundary, and entity relation. Temporal references cover existence, validity, transition, evolution, expiry, and change pattern. They are jointly scoped by Field Identity and cannot independently constitute Field or State.
