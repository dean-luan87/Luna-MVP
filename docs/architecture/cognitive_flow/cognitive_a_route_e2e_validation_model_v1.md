# A-Route End-to-End Life-Loop Validation Model v1

## Purpose and scope

This phase validates that the frozen A Route can represent one complete
candidate-only reality cognition life loop without skipped cognitive layers.
It is an integration validation of existing contracts, not a new capability,
Runtime, model integration, or task-success benchmark.

```text
Survival Drive → Brain Intent → Intent Preservation → Attention Requirement
→ Reality Evidence → World Understanding + Self Understanding
→ Situation Candidate → Option Generation → Decision Evaluation
→ Decision Candidate → Execution Boundary → Outcome Evidence
→ Situated Outcome Evaluation → Cause Attribution
→ Adaptation Candidate → Experience Candidate
```

## Inputs and outputs

| Side | Required candidate inputs or outputs |
|---|---|
| Input | Intent, Goal Context, Reality Evidence, Self Capability, Resource Context, Experience Reference |
| Cognitive chain | Attention, Situation, Option, Evaluation, Decision |
| Output | Decision Trace, Outcome Trace, Cause Attribution, Adaptation Candidate, Experience Candidate |

## Integration invariants

- Evidence never skips Reality/World/Situation to become Decision.
- Self and Resource context remain present in Situation and Decision Evaluation.
- Decision Candidate does not implement an Action; Execution Boundary does not run an Action.
- Outcome Evidence requires interpretation and cause attribution before adaptation.
- Reality remains higher priority than Experience.
- Experience Candidate is traceable, uncertainty-preserving, and cannot update Self, Strategy, Decision, or State.
- B Reflection has no current A-route control authority.

No real Hardware, Action, Provider, Model Manager, Capability Registry,
Middleware runtime, online learning, multi-role, multi-A process, Emotional
Engine Runtime, or B Reflection is added.
