# Cognitive Representation Primitive Model v1

## Primitive candidate families

- Entity Representation: person, vehicle, place, object, concept, event.
- Relation Representation: near, causes, belongs-to, affects, depends-on.
- State Representation: open, closed, moving, waiting, risk-increasing.
- Event Representation: change, trigger, process, outcome candidate.

Primitives preserve source/evidence/context and do not become facts merely because they are named. Entity != object truth; relation != causal truth; state != persistent State mutation; event != confirmed event.
