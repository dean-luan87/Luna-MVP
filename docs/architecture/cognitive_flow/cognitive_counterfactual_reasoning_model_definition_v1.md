# Cognitive Counterfactual Reasoning Model Definition v1

`CognitiveCounterfactualCandidateV1` may retain causal, current-context, field, hypothesis, belief, changed-condition, possible-outcome, future-branch, cost/risk/benefit/reversibility, uncertainty, provenance, and trace references.

It supports Unknown Outcome, Multiple Outcomes, Conflicting Outcomes, and Missing Variables. It remains `candidate_only=true`, `not_fact=true`, `not_prediction=true`, `not_simulation=true`, `not_state_mutation=true`, `not_decision=true`, `not_action=true`, `not_permission=true`, and `not_memory=true`.
