# Cognitive Field Activation Model v1

## Definition

Field Cognitive Activation Candidate describes whether current Field State, Situation, risk signal, temporal pattern, or context-matched representation may warrant reactivating a cognitive pattern.

## Lifecycle

`Detected -> Matched -> Activated -> Validated -> Maintained -> Decayed`.

Spatial, environmental, event, risk, and routine patterns are activation inputs. For example, entering a road crossing may create a Traffic Risk Representation Activation Candidate even without a user request.

## Boundary

Field Activation != user request, current reality confirmation, Attention, Memory search, Decision, Action, or Permission. A match can only request local validity checking or cognitive refresh.
