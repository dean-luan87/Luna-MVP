# A/B Cognitive Route Interface Contract v1

## Common routing input

Context, Intent, Goal, Information Gap/Value, Sufficiency, Survival/Risk, Time/Resource, Experience, Knowledge, and current evidence candidates may support routing.

## A Route

**Position:** Fast Cognitive Processing.

**Input:** Context, Experience, Pattern, Current Evidence.

**Output:** Minimum Sufficient Understanding Candidate, Pattern Match Candidate, Behavior Candidate Support.

**Properties:** low cost, fast, experience-guided, context-bound.

## B Route

**Position:** Deep Reasoning Support.

**Input:** High Uncertainty, High Risk, High Value Information Gap, conflicting or insufficient pattern candidates.

**Output:** Causal Candidate, Counterfactual Candidate, Future Space Candidate, Deep Reasoning Candidate.

**Properties:** higher cost, lower frequency, problem-driven, bounded by time/resource/depth controls.

## Frozen boundaries

- A != Low Intelligence.
- B != Higher Intelligence.
- Route != Decision.
- Route != Action.
- Experience != Automatic Routing.
- Deep Reasoning != Better Answer.
- Both routes remain candidate-only and cannot mutate State.
