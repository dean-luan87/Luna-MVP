# Cognitive Representation Reasoning and Simulation Alignment v1

A Route may use minimal representations for Situation, Context, Goal, Pattern, and Unknown candidates. B Route may expand representation with causal, counterfactual, future-space, and scenario candidates.

`Internal Representation -> Workspace -> Simulation -> Reasoning / Evaluation Candidate`.

Deep Reasoning operates on representation candidates; it does not create New Reality, Truth, Decision, Action, Permission, or State mutation.
