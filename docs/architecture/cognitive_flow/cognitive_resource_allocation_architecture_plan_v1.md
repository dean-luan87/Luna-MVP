# Cognitive Resource Allocation Architecture Plan v1

## Actual asset mapping

This planning layer aligns with Survival Constitution, Cognitive Self Model, Cognitive Attention Layer, Information Value Evaluation, Cognitive Strategy, Cognitive Depth Regulation, Cognitive Mode Switching, Current Cognitive Context, Future Space, Reasoning Tree Lifecycle, Decision Commitment, Experience Boundary, Reducer Authority, and L0/L1 Governance. It does not redefine these modules.

## Position

`Self Model -> Resource Awareness -> Cognitive Resource Allocation Candidate -> Attention Selection -> Reasoning Depth Regulation -> Decision Candidate`.

Cognitive Resource Allocation describes candidate cognitive investment under limited time, compute, attention, information acquisition cost, and memory/experience retrieval cost. It is not a Runtime Resource Scheduler or compute allocator.

## Planning scope

No Runtime Scheduler, algorithm implementation, compute scheduling, Decision, Action, permission, or State Mutation is authorized.
