# Field Identity Ontology Definition v1

`Field Identity = stable spatial + social + functional + rule constraint set`.

Planned fields: `field_type`, `spatial_characteristics`, `social_role`, `functional_scope`, `allowed_activity_pattern`, `prohibited_activity_pattern`, `identity_confidence`, and provenance.

Identity answers “what kind of Field is this?” It is cognitive prior, not real-time observation, current use, activity, State, or model output. Identity Confidence is not Identity admission authority.
