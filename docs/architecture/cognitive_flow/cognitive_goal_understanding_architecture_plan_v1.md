# Cognitive Goal Understanding Architecture Plan v1

## Actual asset mapping

This A-route planning layer aligns with Current Cognitive Context, Situation Understanding, Affordance Understanding, Capability Awareness, Behavior Boundary/Candidate, User Input Boundary, Mission Constraint reference, Cognitive Assistance Boundary, Reducer Authority, and L0/L1 Governance. It does not implement a Mission System or alter existing ownership.

## Position

`Current Context -> Goal Understanding Candidate -> Situation Understanding -> Affordance -> Capability Awareness -> Behavior Boundary -> Behavior Candidate`.

Goal Understanding describes what result may need to be achieved in the current environment. It is not an execution plan, task planner, command, decision, action, permission, or state change.

## Planning scope

No Task Planner, Decision Runtime, Action Execution, Mission System, Emotion Engine, Memory mutation, or State Mutation is authorized.
