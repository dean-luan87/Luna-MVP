# A-Route E2E Failure Analysis Validation v1

## Failure loop contract

```text
Outcome Evidence
      ↓
Difference Candidate
      ↓
Cause Attribution Candidate
      ↓
Adaptation Candidate
      ↓
Experience Candidate
```

The chain distinguishes Information Gap, Understanding Gap, Capability Gap,
Execution Gap, Environment Change, Random Event, and Unknown. It is
cognitive explanation, not blame, automatic remediation, or a decision-policy
rewrite.

## E2E failure assertions

- a failed task cannot bypass outcome interpretation and cause attribution;
- a map-data failure does not lower unrelated capability or identity context;
- a single outcome creates an adaptation candidate only;
- repeated supported observations can create a pattern candidate pending Validation;
- failure analysis retains current Reality and does not use Experience to overwrite it;
- no failure result can directly mutate Goal, Self Model, Strategy, Decision Policy, or State.
