# Cognitive Workspace Model v1

## Definition

Cognitive Workspace Candidate is the current task-related, short-term composition environment for Focus Object, Active Representation, Active Schema, Goal Context, Constraint, Unknown, Hypothesis, experience guidance, and temporal/risk/resource boundaries.

Example: an airport-arrival workspace may contain home, airport, transport, timely-arrival goal, ticket/ID/time constraints, traffic risk, weather unknown, early-departure guidance, and route-plan candidates.

Workspace is a bounded candidate-only view within Cognitive Runtime Environment. It is not Memory Storage, Knowledge Storage, Reality State, persistent identity, Decision Space, Action, Permission, or State mutation.
