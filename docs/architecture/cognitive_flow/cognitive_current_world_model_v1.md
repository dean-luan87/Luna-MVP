# Current World Understanding Model v1

`Current World Understanding Candidate` is Luna’s local, task-bound interpretation of the present world from current evidence, representations, schemas, and context.

Example:

```text
Situation: possibly near a Metro Line 2 entrance
Goal relevance: enter the metro system
Evidence: sign + OCR + spatial candidates
Unknown: exact entrance/line direction
```

Despite this filename, it is not a World Model. It has no global map, persistent truth authority, historical simulation, or reality overwrite path. It is candidate-only and must be revalidated by current evidence.
