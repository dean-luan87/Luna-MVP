# Background Monitoring Model v1

## Purpose

Background Monitoring provides low-intensity passive observation of governed
Reality Workspace projections. It watches for state refresh needs, temporal
changes, resource stress, capability health, conflict, and Unknown growth.

## Lifecycle

```text
Registered
  ↓
Dormant
  ↓
Monitoring Candidate
  ↓
Signal Detected
  ↓
Escalation Candidate or Refresh Candidate
  ↓
Reduced / Released
```

Monitoring is not full observation and does not forward all data to Brain. It uses
Immediate State, Working Reality, or Stable Reality Pattern projections according
to declared scope and retention. It must preserve timestamps, provenance,
confidence, uncertainty, and resource cost.

## Boundary

Background Monitoring does not execute Action, call a model, control a sensor,
change hardware frequency, create a Goal, or decide a Situation. Its output is a
candidate for Workspace, Neural, Middleware, or Brain review.
