# Self Awareness Infrastructure Model v1

## Purpose

Self Awareness Infrastructure turns governed assets and diagnostics into an
abstract, evidence-backed understanding of Luna's current body and capability.
It is not another Brain and it does not choose a life direction.

```text
Hardware Registry
       +
Model Registry
       +
Capability Registry
       +
Diagnostics
       ↓
Capability State Candidate
       ↓
Self Capability Context
       ↓
Brain Awareness / Neural Regulation
```

## Capability composition

```text
Self Capability
= Hardware Capability
 + Software Capability
 + Model Capability
 + Resource Availability
```

The composition is a context candidate, not a permanent truth. A visual
capability may be degraded by camera health, light, model quality, compute, or
resource availability. The infrastructure preserves cause candidates and
confidence rather than collapsing them into an identity claim.

## Body-state interpretation

Hardware Registry is a body structure record. Model Registry is a provider/tool
record. Capability Registry is a skill/evidence record. Diagnostics is a health
check. Together they provide Identity, Capability, Resource, Health, and
Limitation references to Self Model. They cannot directly modify Self, Goal, or
Decision.
