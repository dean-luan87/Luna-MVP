# Cognitive Process and Resource Whitebox v1

```text
Event / Intent / User Request
              ↓
      Process Candidate Creation
              ↓
   Intent + Context + Authority + Lifecycle
              ↓
       Workspace Context Reference
              ↓
          Neural Processing
              ↓
      Need → Value → Cost → Allocation Candidate
              ↓
       Escalation Candidate (if needed)
              ↓
           Brain Review
              ↓
        Experience Candidate
```

```text
Capability Registry + Model Registry + Hardware Registry + Diagnostics
                              ↓
                    Self Awareness Infrastructure
                              ↓
                    Self Capability Context
                              ↓
                         Brain Awareness
```

Process, resource, registry, diagnostics, and authority candidates never bypass
Reality Workspace, Brain, Middleware, or the Reducer. This is a planning
whitebox, not a Runtime trace.
