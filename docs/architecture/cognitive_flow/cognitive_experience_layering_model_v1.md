# Experience Layering Model v1

| Layer | Retains | Forbidden cross-layer authority |
|---|---|---|
| Brain Experience | Meaning, value, preference, world-understanding guidance | Middleware cannot modify it. |
| Neural Process Memory | Cognitive organization patterns, such as text → spatial → direction | Cannot become a Goal or direct Attention authority. |
| Middleware Operational Memory | Capability operation patterns, such as low-light OCR degradation | Cannot modify Brain Experience or Reality. |

All layers emit adaptation or template candidates. None is automatic runtime mutation or a replacement for current Evidence.
