# Cognitive Gene Pool Model v1

Cognitive Gene Pool Candidate is a set of cognition-structure candidates validated across multiple individual, context, and temporal references. It may hold representation, primitive, pattern, condition, exception, and validation-history candidates.

Gene Pool is not Central Brain, Truth Database, Rule Authority, individual override, automatic inheritance, Memory store, or Hive runtime.

Receiving path:

`External Candidate -> Context Match -> Evidence Validation -> Value Evaluation -> Local Validation -> Adoption Candidate`.

Receive is not Learn. Inherit is not Accept. Popularity is not Truth.
