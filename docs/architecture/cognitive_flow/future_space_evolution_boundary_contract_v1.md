# Future Space Evolution Boundary Contract v1

Allowed inputs are governed references to Possible Future Space, Branch Management, Predictive Field State, Anticipation, Preparation, Context, Attention, Information Value, Hypothesis, Belief, Reasoning, Experience/Learning Candidate, Survival, provenance, and trace.

Forbidden inputs include raw model output, provider payload, Fact Store, State handle, Reducer command, Decision result, Action command, Permission grant, World Model asserted as truth, Memory, Learning execution, or Hive authority.

Negative guards:

- Future Space Evolution != Decision.
- Future Space Evolution != Action.
- Future Space Evolution != Permission.
- Evidence Update != Truth Confirmation.
- Confidence != Reality.
- Probability != Safety Priority.
- Experience != Future Space Override.
- Emotion != Future Reality.
- Future Space Evolution != State Mutation.
- Reducer remains the only State Mutation Authority.
