# Cognitive Activation Trigger Model v1

## Trigger sources

- Task / Goal change candidate;
- Field / Situation / spatial event candidate;
- temporal-window candidate;
- risk-change candidate;
- Experience Match candidate;
- resource availability candidate.

Each source can form an Activation Candidate, not an activation command. A valid trigger carries target representation, reason, priority, expected value, resource cost, context boundary, confidence, and provenance.

Field Activation != User Request. Risk != Panic. Time != Decision. Experience != Authority.
