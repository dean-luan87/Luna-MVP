# Cognitive Attention Evolution Architecture v1

Attention Evolution candidate flow:

```text
Experience / Outcome -> Attention Pattern Candidate -> Validation
  -> Attention Evolution Candidate -> Future Allocation Guidance Candidate
```

For example, repeated validated misjudgment at unfamiliar intersections may support future attention to pedestrian/sign/intersection candidates. Evolution is value- and context-bound: Frequency != Value, Risk != Probability, and validated guidance does not directly write an allocation or alter a running controller.
