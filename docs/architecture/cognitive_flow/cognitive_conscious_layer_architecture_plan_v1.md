## Three layers

`Reality Perception Layer -> Cognitive Conscious Layer -> Governance Layer`.

Perception forms current reality-bound Object, Situation, Context, Risk, and Affordance Candidates. Conscious Layer organizes goal understanding, planning, experience/knowledge guidance, hypothesis, counterfactual, and future-thinking candidates in an internal workspace. Governance constrains Constitution, Candidate Validation, Permission Boundary, and Reducer authority.

Conscious Layer is not Authority, Reality Observation, Decision, Action, Runtime implementation, Simulation Engine, World Model, LLM Chain, Memory mutation, or State mutation.
