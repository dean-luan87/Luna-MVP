# Cognitive Information Value Evaluation Architecture v1

Information Value Evaluation is the candidate-level layer between Information Gap and Cognitive Strategy. It evaluates whether a missing piece of information appears worth future cognitive resource allocation.

It does not acquire information, make a Decision, select an Action, approve risk, grant Permission, or mutate State. It provides traceable value candidates for future Strategy Candidates only.

`Information Gap + Context + Survival + Goal + Attention -> Information Value Candidate -> Cognitive Strategy Candidate`
