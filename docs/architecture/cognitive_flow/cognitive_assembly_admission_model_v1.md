# Cognitive Assembly Admission Model v1

Before an Assembly Candidate can be admitted, Neural Governance evaluates candidate dimensions:

```text
Priority Candidate = Risk + Goal Relevance + Time Sensitivity + Information Value - Resource Cost
```

This expression is conceptual, not a fixed runtime score. High-value candidates may be proposed for activation; medium candidates may wait; low candidates may be reduced to background; no-value candidates may be rejected. Admission is not automatic Assembly creation, scheduling, Decision, or Action.
