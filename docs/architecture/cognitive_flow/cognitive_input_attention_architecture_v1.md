# Cognitive Input Attention Architecture v1

Input Attention governs which raw/perception outputs are eligible for Evidence Candidate admission and which admitted evidence candidates become active.

```text
External World -> Sensors / Perception -> Raw Information Stream
  -> Input Attention Candidate -> Evidence Candidate / Evidence Admission Candidate
  -> Cognitive Information Field
```

Input Attention may propose suppression, deferment, or increased salience under task/context/risk constraints. It does not discard Reality, decide Evidence Truth, invoke a sensor, or create a fact.

For a metro-entrance goal, sign/entrance/intersection candidates may be prioritized over advertising candidates; inactive evidence remains governed evidence, not erased reality.
