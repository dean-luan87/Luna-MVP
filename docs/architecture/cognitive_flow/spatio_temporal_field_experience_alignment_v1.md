# Spatio-Temporal Field Experience Alignment v1

Experience is not Location + Time Record. A future Spatio-Temporal Field Experience describes a subject's Observation, Interaction, Outcome, Adaptation, and Learning Candidate reference in a bounded field/context/trajectory.

It remains Experience Candidate, not Memory, Fact, Knowledge Base, Learning, or State. It may later provide review-bound Learning Candidate input and non-central Hive association references while preserving individual context, uncertainty, provenance, and trace.
