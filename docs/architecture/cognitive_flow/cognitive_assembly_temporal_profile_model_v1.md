# Assembly Temporal Profile Model v1

Assembly Temporal Profile describes cognitive timing candidates, not execution frequency: Fast Reactive Loop (safety), Active Cognitive Loop (goal work), Background Observation Loop, and Experience Consolidation Loop.

Suggested fields: `assembly_id`, `loop_type`, `latency_requirement`, `update_frequency_candidate`, `coordination_mode`, and trace. Profiles do not create loops, schedule work, or invoke capabilities.
