# Situation Assessment Model v1

## Purpose

Situation Assessment forms a candidate description of the current
world–subject–goal relationship. It makes environmental facts usable by the
Brain without silently converting them into a decision.

```text
World State + Self Situated Position + Goal Context + Resource Context + Experience
                                      ↓
                              Situation Candidate
                                      ↓
                                Brain Context
```

| Input | Role |
|---|---|
| World State | objects, spatial/temporal relations, evidence-linked uncertainty |
| Self Model / Situated Position | capability, limitation, resource, cognitive position |
| Goal Context | relevance frame for the relation |
| Resource Context | permitted operating envelope, not allocation authority |
| Experience | optional pattern candidate; never an override of present evidence |

`Situation Candidate` may include situation type, relevant relations,
constraints, information gaps, evidence coverage, self-capability relevance,
and observation/regulation candidates. It remains provisional.

Dark-road navigation + reduced night vision + safe-passage goal may yield a
low-illumination navigation context with increased visual uncertainty. It does
not assert “danger”, select a route, or create an Action.

Reality is not Situation; Situation is not Decision, Action, or State
mutation.
