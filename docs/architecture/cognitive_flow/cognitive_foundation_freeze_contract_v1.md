# Cognitive Foundation Freeze Contract v1

The frozen cognitive foundation is Survival Drive → Brain → Intent, Attention,
Evaluation → A Route → Reality Cognition → Self, World, Situation → Decision
Candidate → Outcome Evaluation → Experience Candidate.

Brain owns Intent, Goal, final judgment, and Decision Acceptance. A Route owns
Reality Interpretation, Situation Formation, Decision Candidate, and Outcome
Analysis. Neural owns regulation/resource coordination candidates. Experience
provides reference only. All outputs remain candidates; Reducer remains sole
State mutation authority.

This contract is the stable upper boundary for future Middleware, model,
hardware, and B-route extensions. It adds no Runtime or capability.

Reducer remains sole State mutation authority.
