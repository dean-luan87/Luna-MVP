# Decision Reasoning Termination Boundary v1

## Relation to Reasoning Lifecycle

Reasoning Tree Lifecycle determines whether a tree is Active, Suspended, Completed, Abandoned, or Archived. Decision Commitment can cite a termination-boundary candidate but cannot control the tree, erase evidence, or classify its result as Fact.

`Completed != Decision`, `Suspended != Failed`, and `Abandoned != invalidated evidence`.

## Frozen boundary

Reasoning termination may bound current option formation only. It must not issue a Decision, Action, command, Permission, State change, Memory update, or automatic commitment. A conservative deferred option remains valid when reasoning ends under unresolved risk or uncertainty.
