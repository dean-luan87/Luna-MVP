# Cognitive Goal / Attention Alignment v1

Attention responds to a contextualized active goal, not a bare Goal Candidate.

```text
Current Context + Active Goal Candidate
  -> Attention Allocation Candidate
  -> Active Evidence / Schema Candidate Set
```

At the same airport, an active boarding goal may prioritize gate/time/security evidence; an active pickup goal may prioritize arrival exit and flight-status evidence. Attention remains candidate-only.
