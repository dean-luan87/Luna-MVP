# Cognitive Mission Value Alignment v1

## Mission and Survival

Mission can change candidate value weighting but cannot make an unsafe, prohibited, or evidence-insufficient behavior permissible. The frozen relation is:

`Survival Constitution > Mission Constraint > Cognitive Value Evaluation`.

In a case where Mission Alignment is high but survival risk exceeds the current boundary, the evaluation must preserve the survival limitation and unresolved risk. It cannot use mission relevance to authorize the candidate.

## Mission, goal, and task

- **Mission**: high-level, traceable value constraint candidate.
- **Goal**: current desired outcome reference.
- **Task**: bounded current work reference.

Mission can contextualize goal value; it cannot replace goal admission, select a behavior, or become user intent by itself.
