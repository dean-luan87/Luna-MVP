# Cognitive Execution Monitoring Boundary Contract v1

## Allowed candidate references

Governed Commitment Responsibility, Context, Cognitive State, Field and Future Space, Outcome Observation, Hypothesis, Goal, resource, provenance, and trace references may be read.

## Rejected inputs

Action executor control, Runtime controller, Policy engine, permission, Action command, Decision result, State handle, Reducer command, raw provider/model output, Memory write, Learning execution, and Hive authority are outside this architecture.

## Negative guards

- Execution Monitoring != Action Controller.
- Monitoring != Permission.
- Monitoring != Decision Override.
- Outcome != Truth.
- Failure != Wrong Decision.
- Success != Correct Reasoning.
- Monitoring != Decision Authority.
- Experience != Automatic Correction.
- Emotion != Monitoring Authority.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not state mutation, not decision, not action, not permission, and not memory.
