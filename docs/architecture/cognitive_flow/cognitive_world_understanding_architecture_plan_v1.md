## Objective and position

Define how Evidence Field, activated representations, schema matching, and current context combine into a bounded Current World Understanding Candidate.

```text
Evidence Field
  -> Representation Activation
  -> Schema Matching
  -> Situation Candidate
  -> Current World Understanding Candidate
  -> Workspace Candidate
```

This is an Evidence-to-Situation governance layer. It is not a World Model, Reality mirror, fact database, Decision layer, or large-scale simulator.

## Scope

Define Situation Candidate, local Entity Relationship Graph Candidate, State Candidate, Unknown Space Candidate, attention/schema/experience alignment, and future World Model interface boundaries.

## Out of scope

No World Model runtime, external evidence/model invocation, real perception, simulation engine, B Route runtime, Decision, Action, Permission, Memory/Learning/Evolution, or State mutation.
