# Cognitive Mode Candidate Model v1

## Definition

A Cognitive Mode Candidate is a temporary, scoped characterization of how cognitive organization may prioritize constraints. It is not a finite State Machine state, personality mode, decision, or execution command.

## Candidate modes

- **Normal Mode Candidate** — normal bounded task processing;
- **Emergency Mode Candidate** — risk and survival relevance receive priority for arbitration;
- **Conservation Mode Candidate** — resource protection narrows attention and composition scope;
- **Exploration Mode Candidate** — permitted unknowns receive bounded information-seeking consideration.

## Inputs and effects

```text
Context + Risk + Self State + Resource + Unknown Candidates
  -> Cognitive Mode Candidate
  -> Constraint / Attention / Resource Adjustment Candidates
```

The mode candidate can influence governance proposals only. It cannot directly change hardware, execute a process, determine facts, make a decision, or initiate action.

## Lifecycle

Generated -> Validated Candidate -> Applied-to-Organization Candidate -> Expired / Replaced Candidate.

Lifecycle labels are local candidate metadata, not persistent State transition authority.
