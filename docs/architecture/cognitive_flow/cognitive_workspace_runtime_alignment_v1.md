# Cognitive Workspace Runtime Alignment v1

Cognitive Runtime Environment provides isolated Runtime Instance, Process, Snapshot, branch/resource boundaries, and lifecycle candidates. Workspace is a temporary task composition within one Runtime Process.

`Cognitive Runtime Environment -> Cognitive Process Candidate -> Workspace Candidate -> Simulation / Reasoning Candidate`.

Workspace != Cognitive Runtime Environment, Runtime Engine, Scheduler, Reducer, Field State, Memory State, Decision, Action, Permission, or State mutation.
