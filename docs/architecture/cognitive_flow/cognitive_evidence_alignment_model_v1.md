# Cognitive Evidence Alignment Model v1

Evidence Alignment Candidate compares evidence by declared context, temporal validity, spatial scope, source conditions, relationship candidates, and visible conflicts.

Alignment can produce reinforcement candidates when independent evidence is compatible. It cannot produce a Fact, silently remove contradiction, or let a high-confidence source override all others.

```text
Evidence Field -> Alignment Candidate -> Evidence Candidate Set -> Cognitive Information Field
```
