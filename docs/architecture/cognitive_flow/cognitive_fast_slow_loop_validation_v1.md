# Cognitive Fast / Slow Loop Validation v1

## Fast loop

```text
Observation -> Understanding -> Candidate
```

The fast loop is current-context cognition. It may revise active candidates but cannot learn, mutate representations, or alter long-term structures.

## Slow loop

```text
Outcome Observation -> Feedback Candidate -> Improvement Candidate -> Evolution Adoption Candidate
```

The slow loop is a deferred, validation-bound evolution path. It cannot overwrite the current cognitive cycle or mutate a system automatically.

## Isolation checks

- Fast Loop != Learning.
- Slow Loop != Runtime Override.
- A fast-loop result may provide trace evidence to the slow loop; it does not provide automatic adoption.
- A slow-loop candidate may provide future guidance only after local validation; it does not rewrite the active snapshot.
- Failure in one cycle does not modify the Cognitive Genome, Culture, or Reducer state.
