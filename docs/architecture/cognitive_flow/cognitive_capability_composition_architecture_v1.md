# Cognitive Capability Composition Architecture v1

Capability Composition Candidate describes a possible combination of available cognitive capabilities for an Active Goal and Information Gap.

Example for finding an airport gate:

- visual + map + spatial/navigation candidates;
- OCR + experience + spatial-relation candidates; or
- audio broadcast + position + task-state candidates.

Composition Candidate is evaluated against resource, risk, reliability, information gap, and attention allocation candidates. It is not capability invocation, model call, task plan, Decision, Action, or Permission.
