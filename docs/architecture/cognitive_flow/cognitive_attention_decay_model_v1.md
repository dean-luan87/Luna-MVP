# Cognitive Attention Decay Model v1

Attention Decay Candidate proposes reduction, not time-only expiry. Its validity inputs are Goal Relevance, Risk, Uncertainty, Future Impact, Resource Cost, current Context, and new evidence.

```text
Attention Validity Candidate
  = Goal Relevance + Risk + Uncertainty + Future Impact - Resource Cost
```

This is a qualitative candidate model, not a fixed formula or TTL. Decay != deletion, memory removal, truth downgrade, Decision, or Action.
