# Cognitive Hypothesis Survival Alignment v1

Survival-Driven Hypothesis Filtering prioritizes candidate explanations without deleting ordinary alternatives. Priority order is: survival-risk explanations, behavior-limiting explanations, task-relevant explanations, then ordinary explanations.

For an unknown sound, “possible person” and “possible dangerous source” may coexist. Neither becomes Fact, Risk truth, Decision, Action, Permission, or automatic observation execution.

`Unknown Field -> Hypothesis Space -> Information Value -> Observation Strategy Candidate -> Hypothesis Update Candidate`
