# Current Cognitive State Field Boundary v1

## Distinction

Field State describes external, governed world conditions—such as people at a mall entrance or rainfall. Current Cognitive State describes Luna's current cognitive relation to those references—such as seeking a sign, retaining an information gap, or using an Adaptive Mode Candidate.

`Cognitive State != Field State`. Cognitive State cannot create, modify, snapshot, rewrite temporal history of, or replace Field State. Field View remains an external-world query/reference and does not become Cognitive State authority.

## Reducer boundary

Reducer remains the only Field State Mutation Authority. Current Cognitive State neither issues Reducer commands nor coordinates World State changes.
