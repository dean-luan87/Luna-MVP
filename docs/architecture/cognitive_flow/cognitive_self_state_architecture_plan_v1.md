## Objective and position

Define a current, candidate-only self-state constraint layer for cognitive context, attention control, workspace formation, and future route-admission evaluation.

```text
Capability Context + Resource Context + Runtime Context + Cognitive Reliability
+ Attention State + Knowledge Availability + Cognitive Load
  -> Cognitive Self State Candidate
  -> Context Integration Candidate
  -> Workspace / Attention Candidates
```

Self State describes the cognitive subject’s current operational condition. It is not Identity, Personality, Emotion, Memory, Consciousness, Reality, Decision, or persistent System State.

## Scope

Define Capability, Resource, Reliability, Attention, Knowledge Availability, and Cognitive Load State Candidates plus Context/Attention alignment.

## Out of scope

No Self State runtime, battery/device integration, capability upgrade, Identity/Personality/Emotion system, Memory, Decision, Action, Permission, B Route runtime, Learning/Evolution, or State mutation.
