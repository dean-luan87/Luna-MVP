# Cognitive Flow Data Flow Definition v1

Evidence and trace enter Translation. Translation emits Primitive Candidates. Primitive combinations may form Concept Candidates. Context and governed references scope Field Representation Candidates. Field Kernel composes Current Field View from read-only governed base references plus candidate overlays. Possible changes become Field Event Candidates.

Only this state path is authorized:

`Field Event Candidate -> Admission + Temporal Validity -> Admitted Event -> Reducer -> Field State -> derived Snapshot / Read Model`.

Downstream Analysis, Decision, Experience, Hive, and Language are future consumers under separate contracts; none can back-write the flow.
