# Cognitive Candidate Flow Model v1

The required cognitive flow is:

`Observation -> Candidate -> Evaluation -> Validation -> Adoption Candidate`.

Candidate flow may branch, merge, defer, retain unknowns, request information, or generate alternatives. It must not shortcut as `Observation -> Belief -> Action`.

Validation does not create Fact or Decision authority. Adoption Candidate is not adoption execution, permission, Action, Memory write, Learning, or State mutation.
