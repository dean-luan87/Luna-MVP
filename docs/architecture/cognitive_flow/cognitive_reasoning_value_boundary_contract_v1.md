# Cognitive Reasoning Value Assessment Boundary Contract v1

## Allowed candidate references

Governed Context, Attention, Information Value, Survival/risk, time/resource/depth/mode candidates, Experience/Knowledge, Future Space, provenance, and trace references may be read.

## Rejected inputs and effects

Reasoning Runtime, algorithm implementation, LLM/model invocation, Simulation Engine, World Model, raw provider output, Decision result, Action command, permission, State handle, Reducer command, Memory mutation, Learning runtime, and Hive authority are outside this layer.

## Negative guards

- Reasoning Value != Decision.
- Reasoning Value != Answer Correctness.
- Reasoning Depth != Intelligence.
- More Thinking != Better Result.
- Deep Reasoning != Always Enabled.
- Reasoning Value != Runtime.
- Simulation != Reality.
- Hypothesis != Fact.
- Future Branch != Prediction.
- Reasoning Value != Action.
- Reasoning Value != Permission.
- Reducer remains the only State Mutation Authority.

Outputs remain candidate-only, not fact, not state mutation, not decision, not action, not permission, and not memory.
