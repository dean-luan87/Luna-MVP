## Critical rules

- Entity has capability and local-resource authority only; it has no Goal, Memory, Value, Personality, Decision, or independent Brain authority.
- Entity Governance routes candidates but does not execute a Provider, allocate resources, or create cognitive objectives.
- Middleware retains execution organization within the Entity boundary but never becomes cognitive authority.
- No layer receives Truth, Decision, or Action authority in this planning-only A-route phase.
