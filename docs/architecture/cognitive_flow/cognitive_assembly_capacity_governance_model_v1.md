# Cognitive Assembly Capacity Governance Model v1

Capacity Governance constrains simultaneous Assembly candidates rather than permitting unbounded creation.

| Category | Constraint |
|---|---|
| Core Process support | Limited long-lived safety/environment support candidates. |
| Background Process support | Numerous but low-resource and reducible candidates. |
| Active Assembly | Strictly bounded, admission-controlled candidates. |

Capacity is a cognitive governance concern. It is separate from Middleware compute, memory, battery, and Provider resource management.
