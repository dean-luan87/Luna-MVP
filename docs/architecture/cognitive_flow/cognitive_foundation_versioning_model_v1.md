# Cognitive Foundation Versioning Model v1

Baseline versioning separates:

- `Frozen`: architecture principles and boundaries are stable pending terminal verification;
- `Registered`: a terminal-verified baseline becomes the reference for future extension review;
- `Extension Candidate`: a future module proposes a bounded connection;
- `Revision Candidate`: a governed proposal to change a baseline reference;
- `Supersession Candidate`: a future baseline proposal after full review.

Version status is governance metadata, not Runtime behavior, self-modification, automatic architecture rewrite, decision authority, or State mutation.
