# Cognitive Attention Authority Model v1

Constitution/Survival, Goal, Context, Risk, Unknown, Self State, Experience, Resource, Capability, and future Emotion may each emit Attention Candidates only.

```text
Candidate Sources -> Attention Candidate Pool -> Governance / Controller
  -> Active Cognitive Allocation Candidate
```

No source directly changes an allocation. Attention Governance may constrain allocation candidates but does not judge facts, create knowledge, decide goals, select actions, or mutate state.
