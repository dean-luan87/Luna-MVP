# Cognitive Affordance Understanding Architecture Plan v1

## Actual asset mapping

This A-route planning layer aligns with Field Representation/View, Primitive/Concept, Relationship Candidate, Situation Understanding, Current Context, Goal, Capability/Self Reference, Role Boundary, Behavior Boundary/Candidate, Experience Boundary, Reducer Authority, and L0/L1 Governance.

## Position

`Field Observation -> Primitive / Concept -> Relationship -> Situation Understanding -> Affordance Candidate -> Behavior Boundary -> Behavior Candidate`.

Affordance Understanding describes what environmental objects, spaces, resources, relationships, and situations may offer or limit for Luna's current cognitive state. It is not behavior, permission, decision, or action planning.

## Planning scope

No Affordance Runtime, Action Planner, Behavior Executor, Permission System, Decision Engine/Runtime, Memory Update, or State Mutation is authorized.
