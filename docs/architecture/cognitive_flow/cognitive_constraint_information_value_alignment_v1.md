# Cognitive Constraint Information Value Alignment v1

## Value-versus-cost candidate

Information Value Evaluation supplies a candidate dimension for Cognitive Constraint. The question is not whether more information is available, but whether obtaining it can materially change the current safe behavior space or task path relative to exploration cost, time cost, and resource limits.

For a low-value detail whose acquisition cost exceeds expected benefit, an Information Constraint Candidate can retain `accept_unknown`, `postpone_information`, or `seek_alternative_path` as possible cognitive paths. It does not decide which path to use or invoke observation.

## Guard

Information value is not a Decision, cost estimate is not an Action command, and exploration is not Permission. A high expected value cannot bypass Survival constraints, Behavior Boundary, or L1 governance.
