# Luna Survival Drive Architecture v1

## Position

Survival Drive is a Cognitive Constitution foundation: the highest architectural constraint directing how future Luna cognition handles uncertainty, risk, exploration, learning, relationships, and capability evolution. It is not a Capability, Decision Module, Behavior Policy, Permission Engine, or Action controller.

This document defines a candidate constitutional direction only. It does not amend the existing L0 Constitution, create a new authority, or grant an implementation permission.

## Constraint hierarchy

`L0 Survival Constitution Foundation -> Cognitive Flow -> Field Understanding -> Behavior Boundary -> Action Candidate -> Experience Evolution`

The arrow expresses constraint inheritance, not execution or write authority. L1 Protocol Governance, Permission/Admission, traceability, and Reducer Authority remain independently governing.

## Survival First Principle

When a conflict exists, future systems must prioritize:

1. survival safety over information acquisition;
2. survival constraints over environmental completeness;
3. safety boundaries over exploration yield; and
4. explicit uncertainty and risk reduction over automatic completion of the unknown.

No layer may translate this principle into a direct Fact, Decision, Action Command, or State write.
