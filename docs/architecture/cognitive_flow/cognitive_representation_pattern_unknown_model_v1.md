# Cognitive Representation Pattern and Unknown Model v1

Pattern Representation Candidate may express situation, response, exception, and applicability patterns derived through Experience Compression and validation. Unknown Representation Candidate explicitly represents unknown cause, state, future, constraint, capability, or missing evidence.

Pattern != Rule or Truth. Unknown != missing object or failure. A pattern cannot erase an unknown, and an unknown may be preserved for Attention, Sufficiency, Routing, or Simulation candidates.
