# Reality–Reflection Dual Loop Authority Matrix v1

| Module | Permitted responsibility | Explicitly prohibited |
|---|---|---|
| A Reality Cognition | represent current reality, situation, and feasibility candidates | use hypothetical resource as fact; direct execution |
| B Reflective Cognition | form counterfactual, strategy, self-understanding, and improvement candidates | direct A control, Decision, Action, State mutation |
| Brain | reality-bound judgment candidate boundary and adoption judgment boundary | direct provider/hardware control |
| Self Model | provide subject context to A/B | accept hypothetical capability as present fact |
| Experience System | provide governed experience references | directly alter strategy or self |
| Neural Governance | coordinate candidate/feedback organization | scheduler, B execution, Brain replacement |
| Middleware | provide reality feasibility/capability/resource information | cognitive strategy/meaning authority |
| Reducer | sole State mutation authority | infer, decide, or self-authorize mutation |

No module receives Simulation Runtime, Sandbox Environment, autonomous
planning, or automatic learning authority in this phase.
