# A-Route Regression Boundary and Extension Policy v1

## Permitted future extension

New A-route capabilities may attach as `A Route Extension Capability`.
They must enter through existing Evidence, Self/Resource, Situation, Decision, Outcome, or Experience interfaces.
Examples include attention, temporal, spatial, social-role, or multi-subject extensions.

## Forbidden regression

An extension must not break Reality First.
An extension must not break Self Situated Understanding.
An extension must not break Candidate Only or Feedback Driven.
An extension must not break Decision ≠ Action ≠ Outcome.
An extension must not break the delayed A-to-B handoff.
Reducer remains the sole State mutation authority.

Extensions cannot directly enter internal modules, bypass contracts, turn B into current A control, or replace the core loop.
Material changes require baseline simulation revalidation before Adoption.
