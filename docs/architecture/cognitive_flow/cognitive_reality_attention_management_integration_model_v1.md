# A-Route Attention Management Integration Model v1

## A-route attachment path

```text
World / Self / Goal / Resource / Temporal Context
        ↓
Situation Importance Candidate
        ↓
Attention Context Candidate
        ↓
Attention Selection Candidate
        ↓
Information Prioritization Candidate
        ↓
Situation Enhancement / Observation Request Candidate
        ↓
Decision Support / Outcome Feedback Extension Candidate
```

This follows the existing A-Route Extension Interface Contract. It is not a parallel decision loop, model-control runtime, attention scheduler, or a replacement for existing Attention Governance.

## Authority preservation

- Reality Representation retains fact/reality-candidate responsibility.
- Situation Understanding retains situated-meaning responsibility.
- Brain retains final Decision judgment.
- Existing Attention Governance may aggregate admitted attention candidates;
  it does not obtain Reality, Decision, or Action authority.
- Neural Regulation may reweight response-strength candidates; it does not
  create cognitive Goals or actual resource allocation.
- Reducer remains the sole State mutation authority.
