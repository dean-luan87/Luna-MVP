# Cognitive Extension Admission Contract v1

Every future Luna system requesting admission must define:

1. Which governed inputs it reads;
2. Which candidate outputs it produces;
3. Which existing candidate it may influence;
4. Whether it proposes a change to Cognitive Foundation;
5. Whether it claims State Mutation authority.

Default answers: it has no Foundation-change authority and no State Mutation authority. Any module claiming otherwise is outside this baseline and requires separate governed review.

All extension outputs must preserve provenance, trace, uncertainty, Context/Evidence validation, Candidate-only status, and no direct Decision/Action/Permission effect.
