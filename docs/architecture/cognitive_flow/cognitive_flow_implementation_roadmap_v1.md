# Cognitive Flow Implementation Roadmap v1

| Phase | Objective | Minimum deliverables | Exit boundary |
| --- | --- | --- | --- |
| A0: Architecture Baseline | Freeze Route A vocabulary, ownership, protocol map, and non-goals | this architecture set and human review | no runtime or module integration |
| A1: Core Protocols | Define versioned contracts for observation, evidence, field identity/state, analysis, delivery, outcome, experience | protocol schemas, lifecycle matrices, compatibility map | no persistence or decision execution |
| A2: Field Kernel Minimum Loop | Establish minimal event admission → reducer → read-model cognitive input loop | controlled Field identity/state read contracts and trace/replay cases | no models, no automatic action |
| A3: Cognitive Analysis Loop | Add hypotheses, difference points, information gaps, and exploration/delivery candidates | deterministic analysis contracts and controlled fixtures | no conclusions, no action execution |
| A4: Real Capability Connection | Connect bounded OCR/SLAM/model/attention outputs through Perception Admission | adapter contracts, quality/error boundaries, human-review routes | models remain candidate producers |
| A5: Experience Episode | Record outcome-linked episodes with review and provenance | Episode protocol, retention/retraction and outcome linkage | no automatic reuse or value learning |
| A6: Experience Kernel | Abstract reviewable reusable patterns from episodes | Kernel applicability/counterexample/review contracts | no policy override or vector-based judgment |
| A7: Self System | Model individual perspective, emotion, relations, and worldview as governed candidates | self-context protocols and isolation/consent boundaries | no global truth or direct action control |
| A8: Hive Experience Field | Associate multi-Luna branches, conflicts, and game-analysis candidates | sharing, branch, conflict, consent and isolation protocols | no voting, consensus, central decision, or shared values |

## Sequencing Rules

- A1 must precede any new Cognitive Analysis implementation.
- A2 must be stable before A3 uses Field State as analysis input.
- A3 must remain candidate-only before A4 connects real capability outputs.
- A5/A6 require explicit outcome and review contracts; a case library alone is insufficient.
- A7 is local to each Luna and must precede any A8 sharing semantics.
- A8 may never retroactively grant Hive local decision authority.

## Deferred Until Explicit Authorization

Persistence architecture, message transport, model routing runtime, database schemas, execution workflows, external APIs, production topology, and any registry/lifecycle promotion remain outside this roadmap phase.
