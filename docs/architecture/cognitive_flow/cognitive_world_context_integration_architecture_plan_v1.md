## Objective and position

Define the candidate integration layer that places Luna’s current task, available capabilities, resources, temporal position, and unknowns into a locally understood world.

```text
Current World Understanding
  + Task + Capability + Resource + Unknown + Temporal Position
  -> Context Integration Candidate
  -> Situation Context Candidate
  -> Task Context Candidate
  -> Current Cognitive Context Candidate
  -> Workspace Candidate
```

Context is the current constraint environment used to interpret and prioritize cognition. It is not Reality, Situation, Memory, Identity, Goal, Decision, Action, or persistent State.

## Scope

Define World, Task, Capability, Resource, Unknown, and temporal context candidates along with Attention and Workspace alignment. Reuse existing Self Model, Self Reference, Goal, Capability, Resource Allocation, and Current Context boundaries without changing their ownership.

## Out of scope

No Identity, Personality, Role formation, Emotion Engine, World Model runtime, Decision, Action, Permission, Memory/Learning/Evolution, external capability invocation, B Route runtime, or State mutation.
