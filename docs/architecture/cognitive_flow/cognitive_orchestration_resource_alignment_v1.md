# Cognitive Orchestration Resource Alignment v1

Orchestration may aggregate Time Budget, Attention Budget, Reasoning Budget, Information Value, Risk, task importance, Activation Priority, and expected resource cost into Resource Investment Candidates.

Candidate outcomes include request, defer, reduce, preserve, or refresh cognitive participation. They are not compute scheduling, Attention control, Decision, Action, Permission, or State mutation.

More participating modules != Better Cognition. More reasoning != Better outcome. Resource pressure may preserve high-impact uncertainty without activating every candidate.
