# Cognitive Compression Target Model v1

Compressible candidate targets include:

- Field Compression: spatial structure, object relationships, environmental regularities, and dynamic changes;
- Event Compression: process, trigger conditions, changes, and outcomes;
- Experience Compression: decision traces, strategies, success/failure patterns, and applicability;
- Knowledge Compression: stable regularities, general relations, and transferable knowledge candidates;
- Situation Compression: scene patterns, environmental status, and task relations;
- Decision Trace Compression: considered basis, trade-offs, uncertainty, and outcome feedback.

Targets remain distinct source candidates. Compression does not convert them into fact, memory, knowledge storage, or universal rules.
