# Cognitive Language Input Adapter Model v1

## Future input

`User Language -> Language Evidence Candidate -> Intent / Goal Candidate Support`

Language is an information entry point, not the cognitive subject and not the authority that forms cognition. A language adapter preserves source, turn/context reference, ambiguity, confidence, and provenance.

Language Evidence Candidate != Intent Fact, Goal Command, Decision, Action, or Permission. Intent and Goal remain later candidate interpretations with current Context and evidence checks.
