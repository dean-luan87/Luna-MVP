# Concept Future Encoding Interface v1

## Recorded future boundary

A validated `Cognitive Concept Candidate` may later be represented by a Luna Internal Language Primitive for communication or compression. That future interface is one-directional: `Concept Candidate -> Meaning Representation -> Language Expression`.

## Current prohibition

This phase does not implement Language Encoding, Language Evolution, Hive Adoption, Common Language Promotion, or any reverse `Language -> Concept` generation path. Language cannot supply concept taxonomy, admission, authority, or truth status.

## Required future governance

Any future encoding interface must retain concept provenance, uncertainty, traceability, candidate status, and the existing L1 permission/admission boundary. It cannot promote a candidate to Fact or create Decision, Action, State, Memory, or Learning authority.
