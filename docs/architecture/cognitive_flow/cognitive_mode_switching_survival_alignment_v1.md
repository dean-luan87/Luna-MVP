# Cognitive Mode Switching Survival Alignment v1

## Survival priority

Survival Constitution is the highest constraint on Cognitive Mode candidates. No mode may lower, suppress, reinterpret away, or override Survival constraints.

Reactive Mode is not a panic Action pattern: it is a candidate description of narrow time/depth and conservative cognitive processing under pressure. Routine, Exploratory, and Reflective candidates remain subordinate to current Survival and Behavior Boundary constraints.

`Mode != Survival Override`, `Mode != Action`, and `Survival != Action Controller`.
