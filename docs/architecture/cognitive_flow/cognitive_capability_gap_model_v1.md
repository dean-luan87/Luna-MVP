# Capability Gap Model v1

Capability gaps describe the mismatch between the current information need and current observation support.

- `quality_gap_candidate`: evidence exists but is degraded or insufficiently reliable for the current need.
- `coverage_gap_candidate`: required observation dimensions are not covered.
- `latency_gap_candidate`: observation timeliness may be unsuitable.
- `resource_gap_candidate`: resource constraint may limit a candidate combination.
- `provider_failure_gap_candidate`: current Provider is unavailable or unable to supply bounded evidence.
- `information_gap_candidate`: unresolved information remains.

Gap is not failure, and an empty OCR result is not proof of absent text.
