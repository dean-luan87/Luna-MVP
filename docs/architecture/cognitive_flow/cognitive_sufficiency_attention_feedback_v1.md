# Cognitive Sufficiency / Attention Feedback v1

Sufficiency may produce Attention Adjustment Candidate when a task-relevant unknown changes what should be observed or reconsidered.

```text
Attention -> Workspace -> Understanding -> Sufficiency
  -> Attention Adjustment Candidate -> future Attention Candidate
```

This is a candidate feedback loop. Sufficiency does not allocate resources directly, force evidence acquisition, or decide attention truth.
