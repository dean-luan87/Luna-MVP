# A-Route Final Authority Matrix v1

| Module | Final A-route responsibility | Prohibited authority |
|---|---|---|
| Survival Constitution | existence and non-harm principles | execution or exception bypass |
| Brain | final cognitive judgment boundary | direct Action/State mutation |
| Self Model | self capability and limitation context | decision selection |
| World Model | represented reality context | goal/decision authority |
| Situation Understanding | current situated relation | action or decision |
| Neural Governance | resource regulation and coordination candidates | Brain replacement |
| Middleware | capability organization and feasibility | cognitive judgment |
| Provider | local Evidence/status candidate | truth/decision/action |
| Experience | historical reference candidate | direct strategy/self update |
| B Reflection | future reflection candidate | current A control |
| Reducer | sole State mutation authority | inference/decision/execution |

No row creates a Runtime, Action scheduler, hardware control, online learning, or autonomous self-modification path.
