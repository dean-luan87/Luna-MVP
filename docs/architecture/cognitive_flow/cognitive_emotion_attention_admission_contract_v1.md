# Cognitive Emotion Attention Admission Contract v1

Future Emotion Signal may enter only as an Emotion Attention Candidate with source, context, salience request, uncertainty, provenance, trace, and explicit non-authority flags.

```text
Emotion Signal -> Emotion Attention Candidate -> Attention Candidate Pool
  -> Cognitive Attention Controller -> Allocation Candidate
```

Admission checks task/risk/time/resource consistency. Emotion != Attention Override, Attention Authority, Reality Interpretation, Decision, Action, Permission, Memory mutation, or State mutation.
