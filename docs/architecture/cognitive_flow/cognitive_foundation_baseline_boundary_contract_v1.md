# Cognitive Foundation Baseline Boundary Contract v1

## Baseline authority

The baseline provides a reference for future architecture admission and drift review. It does not control Runtime, decide, act, grant permission, write Memory/Hive, or mutate State.

## Extension guards

- Future Module != Foundation Override.
- Emotion != Decision Authority.
- Emotion != Reality Override.
- World Model != Truth Authority.
- World Model != State Mutation Authority.
- Hive != Individual Override.
- Hive != Central Brain.
- Language != Internal Representation Authority.
- Embodiment != Autonomous Execution Authority.
- Experience != Rule.
- Culture != Truth.
- Gene Pool != Authority.
- Optimization != Decision.
- Prediction != Reality.
- Reducer remains the only State Mutation Authority.

Future modules must be admitted through candidate-only, Context/Evidence/Value-governed interfaces and cannot reverse-modify the foundation.
