# Cognitive Core Integrated Life Cycle Whitebox v1

```text
Reality Change
  ↓
Field / Role / Relationship
  ↓
Self Context → Attention → Workspace
  ↓                         ↓
Drive / Value          Brain Input Package
  ↓                         ↓
Experience ← Action Boundary ← Decision Candidate
  ↓
Learning Candidate → Future Attention / Reflex Candidate
```

## Control questions

- Does Reality enter through Evidence and Reducer? Yes; no direct fixture mutation.
- Does Field update before Workspace refresh? Yes.
- Does Role/Relationship remain contextual? Yes; Identity is continuous.
- Does Attention arbitrate resources without deciding? Yes.
- Do Drive and Value remain influence/constraint inputs? Yes.
- Does Brain receive a governed package? Yes; Brain retains Goal and Decision.
- Does Action remain an Action Boundary request? Yes; no execution is tested. Action remains an Action Boundary request.
- Do Experience and Learning remain candidates? Yes; no automatic adaptation.
- Does Reflex interrupt safely? Yes; candidate/escalation only.
- Does Emotion Context remain metadata? Yes; no emotion computation. Emotion Context remains metadata.

## Negative paths

Unknown and Conflict are preserved in every package.
Reflex → automatic Action is forbidden.
Model → Decision, Emotion → Decision, Learning → automatic strategy, Reflex →
automatic Action, Workspace → Reality Write, Field → Goal Mutation, Role → Identity Mutation, and fixture → external side effect are forbidden.
