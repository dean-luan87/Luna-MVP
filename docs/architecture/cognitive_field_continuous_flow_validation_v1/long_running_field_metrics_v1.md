# Long-Running Field Metrics v1

## Metrics

- **Field Existence Continuity:** fields remain valid across time slices;
- **Transition Fidelity:** expected Activate, Background, Suspend, Close, and
  Archive transitions occur;
- **Stable Layer Stability:** Identity, Constitution, and Core Capability remain;
- **Adaptive Layer Responsiveness:** current context changes without Identity Drift;
- **Transient Cleanup:** temporary context is released at validity end;
- **Event Stream Integrity:** consecutive events preserve context and order;
- **Unknown Persistence:** Unknown does not disappear due to elapsed time;
- **Pollution Isolation:** one Field cannot rewrite another Field's Reality;
- **Parallel Structure Integrity:** Active/Background fields coexist without
  multi-A Decision;
- **Action Boundary:** trace stops before Action.

Metrics evaluate trace continuity and boundary compliance, not task success or
intelligence.
