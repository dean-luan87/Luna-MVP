# State Transition Model

## 合法迁移

`Observation → Understanding` 需要足够且可追踪的 Evidence；`Understanding → Decision` 需要可用的 Belief/Understanding Candidate；`Decision → Action` 需要批准的 Decision Candidate 和 Self/Constitution 约束检查；`Action → Reflection` 需要 Outcome Available；`Reflection → Learning` 需要长期价值、模式或能力缺口候选；`Learning → Observation` 需要学习候选完成治理并返回新的观察上下文。

## 迁移原则

迁移是候选，不是自动状态机。新 Evidence、Field Change、Risk Increase、Capability Failure、Contradiction 或 Unknown 可以产生 Reconsideration/State Transition Candidate。所有迁移包含来源事件、时间、Field、Flow 和 trace 引用。
