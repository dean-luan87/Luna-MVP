# State and Attention Relation

Attention 不是 State。Cognitive State 为 Attention 提供模式约束和关注策略候选：Observation 关注环境变化与 Evidence，Understanding 关注 Hypothesis/Belief/Validation，Decision 关注 Goal、Utility、Risk 与 Candidate 差异，Action 关注 Outcome，Reflection 关注 Expected/Actual Difference，Learning 关注 Pattern、Schema 与 Growth Evidence。

Attention 只能提出资源分配候选，不能切换 State、执行 Action、写入 Memory 或改变 Reality。Self Rhythm 提供资源节奏建议，不能替代 Cognitive State Owner。
