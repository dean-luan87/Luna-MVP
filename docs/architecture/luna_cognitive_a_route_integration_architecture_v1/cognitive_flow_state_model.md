# Cognitive Flow State Model

## 定义

Flow State 是一次 A Route 认知过程的阶段性状态，不是现实状态、人格状态或动作命令。

## 状态

`Observed → Structured → Fielded → Attending → Contextualized → Hypothesized → Understood → GoalEvaluated → Valued → Arbitrated → ActionPending → OutcomePending → Evaluated → Experienced → Remembered → Learned → SelfReviewed`

状态迁移必须有来源事件、时间、Field 引用和 trace 引用。任何不确定性、冲突或验证缺口都必须保留。

## 权限

Flow Controller 只维护候选流程状态和 trace。它不能生成 Reality、执行 Action、自动学习、写入 Memory/Schema、修改 Identity 或绕过 Constitution。

## 与 Field 的区别

同一 Field 可以承载多个 Flow（普通观察、搜索、安全响应）；Flow 不能创建或覆盖 Field。Field 变化可以触发 Flow 重新组装和 Attention 重算候选。
