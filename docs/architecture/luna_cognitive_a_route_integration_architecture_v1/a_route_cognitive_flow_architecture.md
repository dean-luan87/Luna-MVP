# A Route Cognitive Flow Architecture v1

## 定位

A Route 是 Luna 对当前现实进行认知、决策、行动与反馈的连续流程。本阶段把已验证模块收敛为一条架构流，不实现运行时连接。

## Canonical Flow

`Reality → Evidence → Cognitive Field → Attention → Context → Hypothesis → Belief → Understanding → Goal → Value Utility → Decision Arbitration → Action Boundary → Outcome → Experience → Memory → Schema → Selective Learning → Growth Candidate → Self Review`

Self Constitution 和 Self State 对所有阶段施加约束，但不替代现实证据。每一段只产生其被授权的对象或候选，不越权直接改变下游最终状态。

## 信息与状态原则

- Reality 优先于 Memory、Belief、Schema 和 Knowledge。
- Field 提供当前场上下文；Attention 选择资源焦点；Context 组合可用输入。
- Hypothesis、Understanding、Goal、Value、Decision 和 Growth 都是候选或受治理对象。
- Action 由 Action Boundary/Runtime 未来执行；本阶段不执行。
- Outcome 通过 Reality Validation 回流，不能直接写 Memory、Schema 或 Self。
- Selective Learning 只在证据、效用和 Self Review 通过后产生 Growth Candidate。

## Cross-Field reuse and situated meaning

A Route may eventually consume reusable Entity/Field/Relation/Experience
references, but it must form meaning under the current Field, Relation,
Context, Role, and Goal/Task. Cross-Field knowledge reuse does not authorize
cross-Field meaning reuse. The canonical boundary is [Field-Conditioned Entity Semantics & Cross-Field Information Reuse Principle v1](../field_conditioned_entity_semantics_and_cross_field_information_reuse_v1.md).

No current A-Route behavior, Memory/Experience mutation, resolver, or reuse
percentage is introduced by this documentation addendum.

## Flow State

Cognitive Flow State 表示认知过程当前如何运行，例如 `observe`、`understand`、`decide`、`act`、`evaluate`、`learn`。它不是 Field，也不是 Scheduler；它只描述当前流程阶段和阻塞/待验证条件。
