# Feedback Loop Architecture

## 主回流

`Action → Outcome Observation → Expected/Actual Comparison → Reality Validation → Understanding Adjustment Candidate → Experience Candidate → Memory/Schema Candidate → Selective Learning Candidate → Self Review`

## 回流规则

Outcome 是现实结果，不是经验；单次结果不能自动形成 Schema 或改变 Self。验证必须保留原始 Evidence、Field、时间、预期、实际结果、差异和置信度变化。

Reality 变化优先于历史 Memory。矛盾结果产生 Contradicted/Unknown/Requires Review 候选，不得静默覆盖旧对象。

## 资源与稳定性

Self Regulation、Self Rhythm 和 Constitution 可限制反馈处理的资源投入，但不能自动批准学习或修改核心身份。Runtime 未来决定是否执行候选刷新；本阶段仅定义接口。
