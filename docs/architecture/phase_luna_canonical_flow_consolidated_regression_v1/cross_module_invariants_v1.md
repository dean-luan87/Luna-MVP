# Cross-Module Invariants v1

回归必须保持：

- A 保持 Concern-local semantic authority；Brain 保持 Goal/Concern/Grant/global consequence authority。
- Capability Governance 保持 Capability ↔ Model binding lifecycle authority。
- Provider Governance 保持 Model ↔ Provider binding lifecycle authority和Provider boundary。
- Action Governance 是唯一 Action admission owner。
- Candidate、Binding、Admission、Execution、Evidence、World Truth、Outcome、Brain adjudication、Loop persistence 不得合并。
- Derived/ref-only products 不得修改 source state。
- 每个 authority 都带有对应 responsibility。
