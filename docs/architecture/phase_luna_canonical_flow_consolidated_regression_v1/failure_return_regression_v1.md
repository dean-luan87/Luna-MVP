# Failure Return Regression v1

代表性失败包括：stale Requirement、revoked Grant、binding mismatch、Runtime blocked、permission block、stale Evidence、stale Action Result、source-version mismatch 和 stale Outcome。

失败首先回到负责该边界的 owner；只有 local semantic consequence 才回到 A，只有 Goal/Concern/Grant/policy consequence 才进入 Brain。失败不会直接伪造成功、Reality、Concern closure 或 Loop closure。
