# Selective Learning Implementation Plan v1

This phase is Architecture Only.

1. Reuse the existing Cognitive Learning System, Self Evolution, Growth
   Candidate, Knowledge/Memory Boundary, Information Lifecycle, Value Utility,
   and Self–World Boundary contracts.
2. Add adapters that distinguish Knowledge, Experience, Memory, Schema, and
   Learning Candidate without creating parallel stores or a Learning Runtime.
3. Keep Learning as candidate generation and admission input; Self Governance
   and Capability Governance own approval boundaries.
4. Preserve source lineage, unknowns, reversibility, and revocation paths.
5. Defer online learning, model training, parameter updates, Emotion, Social
   Runtime, and B Route.

No existing code or architecture asset is moved or changed in this phase.
