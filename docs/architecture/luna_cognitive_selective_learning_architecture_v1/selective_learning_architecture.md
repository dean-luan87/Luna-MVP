# Luna Cognitive Selective Learning Architecture v1

## Position

Selective Learning turns validated interaction into a candidate for future
capability or strategy improvement. It is not knowledge injection, Memory, a
Schema, model training, or an automatic self-change mechanism.

```text
Reality / Outcome
       ↓
Experience
       ↓
Pattern / Schema Candidate
       ↓
Learning Candidate
       ↓
Cognitive Utility Evaluation
       ↓
Self Review / Learning Admission
       ↓
Capability Growth Candidate
       ↓
Self Evolution Governance
```

Knowledge becomes learning only when it is admitted, contextualized by Field,
Role, and Task, applied in interaction, and supported by outcome evidence.
Reading or retrieving a fact alone is Knowledge, not Learning. Memory preserves
history; Learning changes a future capability or strategy candidate.

## Selectivity

Learning is an investment. A candidate must expose Expected Capability Gain,
Future Decision Improvement, Learning Cost, Risk, evidence quality,
reversibility, and unknowns. A hard Constitution or Self boundary can reject a
candidate regardless of utility.

## Protection

Self Review is mandatory because learning can change future behavior. Approved
growth remains a candidate for Capability Governance and Self Evolution. No
automatic Memory write, Schema update, parameter update, personality change,
Emotion Runtime, B Route, or Learning Runtime is implemented here.
