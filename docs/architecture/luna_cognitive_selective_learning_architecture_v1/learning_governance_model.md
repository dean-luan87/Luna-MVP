# Learning Governance Model v1

## Admission sequence

```text
Learning Candidate
       ↓
Utility Evaluation
       ↓
Evidence / Boundary Review
       ↓
Self Review
       ↓
Approved Growth Candidate / Rejected / Deferred / Revised
```

Review checks evidence quality, repetition or impact, utility, cost, risk,
reversibility, current capability state, Constitution, Identity Boundary,
Safety Boundary, and unknown preservation. Admission is explicit and
revocable. A candidate can be deferred when learning is useful but current
resources or risk do not permit it.

Learning sources are Experience Learning, Knowledge Assimilation, Social
Learning, and Self Reflection Learning. Source attribution does not grant
authority. All sources use the same admission boundary.

## Non-goals

This phase does not run online learning, train a model, update parameters,
write Memory, update Schema automatically, alter Identity, or execute an
Action.
