# Capability Growth Model v1

Learning may produce a Capability Growth Candidate, not a capability change.

```text
Validated Learning Candidate
          ↓
Capability Growth Candidate
          ↓
Capability Governance Admission
          ↓
Self Evolution Review
          ↓
Future Capability Update Candidate
```

Level 0 Temporary Information is not growth. Level 1 Experience Pattern is a
Schema candidate. Level 2 Capability Improvement can affect a capability
profile. Level 3 Self Evolution Candidate requires the strongest evidence,
reversibility, and Self review.

Growth may change capabilities, strategies, and schemas. It may not directly
change Constitution, Identity, Safety Boundary, or core Brain rules. The model
does not specify an implementation algorithm or parameter update.
