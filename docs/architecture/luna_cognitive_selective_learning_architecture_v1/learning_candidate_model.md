# Learning Candidate Model v1

Each Learning Candidate states what gap was found, why it matters, and what
bounded change could address it.

Required context includes:

- source type and provenance;
- Field, Role, and Task context;
- Experience, Memory, or Knowledge references;
- current capability limitation or decision gap;
- expected capability gain and future decision improvement;
- cost, risk, reversibility, confidence, and unknowns.

The candidate does not claim that learning has happened. It requests review.
Temporary Information stays temporary; Experience Pattern may become a Schema
Candidate; Capability Improvement and Self Evolution Candidate require stricter
admission.
