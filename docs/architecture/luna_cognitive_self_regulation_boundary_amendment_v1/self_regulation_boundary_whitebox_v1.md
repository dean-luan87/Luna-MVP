# Self Regulation Boundary Amendment Whitebox v1

| Question | Amended answer |
|---|---|
| What happens when one capability fails? | Analyze its failure domain; update affected capabilities only and preserve unaffected capabilities. |
| Who decides whether the system remains operational? | Self Regulation proposes stability status; Brain/Governance retain system authority. |
| Who can reject an unsafe upgrade? | Self Regulation may issue an Upgrade Rejection Candidate under Self Preservation Governance. |
| Who admits an alternative capability? | Capability Governance / Admission. |
| Who supplies model/version options? | Model Manager, without authority to force selection. |
| What outranks optimization? | Stability and core cognitive function. |
| Can this amendment switch models or providers? | No; it only produces candidates. |
| Can it modify Identity, Value, Goal, Constitution, or Brain rules? | No. |
| What remains explicit? | Failure domain, affected/unaffected sets, unknown, confidence, evidence, and trace. |

This is a boundary amendment, not a runtime controller.
