# Model↔Provider Binding Declaration

`model-provider-binding:yolo11n:yolo:v1` is declared in the Provider
Governance binding registry.

Owner and lifecycle owner: Provider Governance.

The binding connects the YOLO11n Model Asset to the YOLO Provider, Provider
contract, adapter, and loader compatibility declaration.  It preserves
independent versions, provenance, invalidation, and supersession metadata.

Compatibility is not Provider Admission and is not invocation.
