# Capability↔Model Binding Declaration

`capability-model-binding:object-detection:yolo11n:v1` is declared in the
Capability Governance binding registry.

Owner and lifecycle owner: Capability Governance.

The binding connects the object-detection Capability and Slot to the YOLO11n
Model Asset while preserving model/version/weights refs, compatibility
constraints, source versions, provenance, invalidation, and supersession
metadata.

It does not create Runtime Admission or Provider invocation authority.
