# Authority and Responsibility

| Domain | Owner | Responsibility |
|---|---|---|
| Capability Slot | Capability Governance | Slot identity, lifecycle, and declaration correctness |
| Capability↔Model binding | Capability Governance | Binding identity, lifecycle, compatibility declaration, invalidation |
| Model identity/declaration | Model Governance | Model asset, versions, loader, dependencies, provenance |
| Provider identity/declaration | Provider Governance | Provider identity, contract, adapter, lifecycle |
| Model↔Provider binding | Provider Governance | Provider-facing compatibility binding and lifecycle |
| Runtime eligibility | Runtime Admission | Future executable assessment |
| Translation | Integration adapter | Reference composition and translation correctness |

No shared final mutation authority is introduced.
