# Capability Condition Gap

`CapabilityConditionGapV1` is distinct from a Cognitive Information Gap.

An Information Gap says which information is missing for cognition. A
Capability Condition Gap says which situated condition prevents a selected
Capability from being usable now. For example:

`information-gap:visible-transit-sign-text`
may coexist with
`condition:target-visible`
as a Capability Condition Gap.

An adjustment candidate may point from that condition gap to
`NEED_BETTER_VISIBILITY` or `NEED_STABLE_RELATION`. It never contains a
distance, angle, step count, route, or Action instruction.
