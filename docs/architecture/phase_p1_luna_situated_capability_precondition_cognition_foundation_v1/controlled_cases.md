# Controlled cases

1. `TEXT_PRESENCE_ONLY`: the resolver selects only target visibility as the
   minimum condition.
2. `READ_PRIMARY_SIGN_TEXT`: the same `text_recognition` capability resolves
   target visibility, completeness, adequate scale, and stable relation.
3. `SAME_CAPABILITY_DIFFERENT_INFORMATION_NEED`: two requests use the same
   capability and equivalent situated target state, but different Information
   Needs. The weaker presence requirement is feasible with visibility alone;
   the stronger primary-reading requirement remains infeasible.

The cases are controlled candidate states only. They do not claim real
environmental motion or provider execution.
