# Governance boundary

The implementation is a candidate-only evaluator under the existing Capability
Admission / Capability Governance boundary. Capability Registry retains
identity ownership; Capability Governance retains binding/admission authority;
Self State and Field State retain their mutation authorities.

Forbidden:

- provider/model/runtime invocation;
- treating availability as execution authority;
- Self or Field mutation;
- World Truth or Fact promotion;
- Decision, Task, Action, Runtime Executor, device control, or navigation;
- scenario/cycle-index semantic branching;
- numerical geometry or action prescriptions.
