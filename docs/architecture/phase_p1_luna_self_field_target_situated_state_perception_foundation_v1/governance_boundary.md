# Governance Boundary

This is a controlled candidate-only precondition evaluation.  It does not:

- invoke a provider or model;
- declare Field Truth, World Truth, or Fact;
- mutate Self, Field, Target, or World state;
- own Observation, Capability, Decision, Task, or Action execution;
- issue movement, camera, navigation, or device instructions.

Condition Adjustment Need remains an abstract condition request such as
`NEED_BETTER_VISIBILITY` or `NEED_STABLE_RELATION`.  It is not an Action
Candidate or an Action Plan.
