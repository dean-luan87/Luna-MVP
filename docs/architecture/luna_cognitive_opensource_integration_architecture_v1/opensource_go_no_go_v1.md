# Open Source Integration Architecture Go/No-Go

## Readiness criterion

`LUNA_COGNITIVE_OPENSOURCE_INTEGRATION_ARCHITECTURE_READY` is emitted by the user-owned V2 verifier only when layer mapping, admission, adapters, authority, data flow, replacement, failure isolation, and negative guards are complete.

## No-go conditions

- external framework becomes Cognitive Kernel;
- storage engine decides Memory Value or deletion;
- similarity output is treated as Meaning;
- graph storage bypasses Knowledge Admission;
- provider output becomes Decision or Reality;
- external failure causes whole Self failure;
- any real open-source library, network, model, hardware, or provider is activated in this architecture-only phase.

The agent stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION` and does not declare a final GO decision.
