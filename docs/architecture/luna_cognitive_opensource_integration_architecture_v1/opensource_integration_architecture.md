# Luna Cognitive Open Source Integration Architecture v1

## Position

Open-source assets are capability providers to Luna's Cognitive Kernel, not Luna Intelligence. This phase defines how external assets may be admitted, wrapped, observed, replaced, and isolated. It does not install, call, benchmark, or execute any named project.

## Frozen layers

```text
L0 Constitution
L1 Self Layer
L2 Cognitive Kernel
L3 Experience / Memory / Knowledge Growth
L4 Social Self / Role / Interaction
L5 Capability Layer: Models, Vision, Audio, OCR, SLAM, Hardware, Tools
```

Open-source storage engines, similarity engines, knowledge graph engines, research references, and model/provider adapters remain below the Kernel. They may provide input processing, computation, storage, or similarity. They cannot provide Meaning, Decision, Self Definition, Memory Value, or Growth Direction.

## Mappings

- Mem0: future Memory Storage Engine through a governed adapter;
- Letta: Memory hierarchy reference only, not direct Runtime adoption;
- Generative Agents: Reflection reference producing Pattern/Growth Candidates only;
- FAISS / Chroma: similarity and vector storage boundaries, not meaning engines;
- Neo4j: Knowledge Library storage boundary, not Knowledge Admission authority;
- OpenCog Hyperon: research reference for Attention/Pattern ideas only;
- SOAR: cognitive-cycle research reference only;
- Vision, Audio, OCR, SLAM, and language models: Capability Governance and Provider boundaries.

These are architecture mappings, not dependency declarations or integration approvals.

## Authority and failure isolation

Memory Governance decides what is retained; Knowledge Admission decides what is admitted; Brain decides cognitive candidates; Action Boundary gates execution. If an external asset fails, Self Regulation receives a degraded capability observation and Capability Governance may propose a replacement. The external asset never becomes a Kernel owner or direct state writer.

## Next boundary

The next architecture phase should freeze Luna's own Information Processing Pipeline: per-layer inputs, processing contracts, outputs, external capability options, and Luna-owned logic. This phase intentionally stops before that work.
