# Phase-P1 Luna Governed Cognitive Branch Formation v1-001

Status: `GO — VERIFIED — PHASE CLOSED`

本阶段是现有 Minimum Sufficient Cognition Loop 的受限扩展，不创建第二套
Cognitive Loop，也不抽取 General Cognitive Exploration Loop runtime。

实现范围仅为：

```text
Existing governed cognitive alternatives / gaps / conflicts
→ candidate-only Cognitive Branch Candidates
```

Branch 是针对当前认知问题、仍值得独立继续推理的 exploration/process
candidate。它不是 Hypothesis、Information Need、Information Gap、Plan、Task、
Action 或 Current World Candidate。

Branch Formation 只组织已有 governed cognitive basis，不生成 commonsense
探索方向，不执行资源获取，不创建 Observation Demand 或 Capability Requirement。

Branch Formation 与 Branch Governance 分离。本阶段不包含 Admission、rejection、
priority、merge、dormant、close、reopen、child runtime 和 convergence；这些由
后续独立 Governance / Lifecycle 边界分别约束。

本阶段成熟度限定为 `Governed Branch Formation`。用户终端已真实验证通过，
`COGNITIVE_BRANCH_FORMATION_GAP = CLOSED`。

本阶段之后的认知 handoff 为：

```text
Branch Candidates
→ Governance Decisions
→ Governed Active Exploration Set
```

Branch Governance 不属于本阶段历史实现范围。
