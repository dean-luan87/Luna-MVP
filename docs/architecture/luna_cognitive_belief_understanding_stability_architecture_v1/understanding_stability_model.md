# Understanding Stability Model v1

Understanding is a governed synthesis, not a fact store:

```text
Candidate Understanding
  -> Supported Understanding
  -> Active Understanding
  -> Challenged Understanding
  -> Invalidated Understanding
  -> Archived Understanding
```

An Understanding requires multiple evidence references, stable Context, provenance, uncertainty, and decision relevance. It may remain challenged or Unknown. Stability means evidence-backed continuity, not resistance to correction.
