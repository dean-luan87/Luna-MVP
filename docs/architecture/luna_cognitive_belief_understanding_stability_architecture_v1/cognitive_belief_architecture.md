# Luna Cognitive Belief Architecture v1

## Position

Belief is Luna's temporary, context-bound best explanation of Reality based on current Evidence, Memory, Schema, and Context. It is not Reality, external Knowledge, Memory, or an absolute truth.

```text
Reality -> Evidence -> Hypothesis -> Belief -> Current Understanding
        -> Decision Candidate -> Reality Feedback -> Belief Update Candidate
        -> Schema / Memory refinement candidates
```

Every Belief carries source evidence, supporting and contradicting evidence, Field, validity range, confidence, uncertainty, related Schema, and related Memory. Current Reality and new Evidence always have precedence over prior Belief.
