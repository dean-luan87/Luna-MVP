# Capability Execution Boundary Whitebox v1

## Audit questions

1. Did L2 express a capability need rather than a provider name?
2. Was the request admitted by registry, permission, health, calibration, and
   resource checks?
3. Which capability candidate was selected, and who owns that selection?
4. Did the execution contract return Evidence rather than Fact, Decision, or
   Action?
5. Are confidence, limitation, timestamp, context, and provenance preserved?
6. Did failure degrade capability and preserve Unknown?
7. Is the complete request-to-evidence trace available?

## Explicit non-authority

Capability Boundary is not Brain, Goal, Decision Commitment, Reality Reducer,
Emotion Controller, or Action Runtime. It cannot modify Constitution, Flow,
Goal, Decision, Belief, or Reality directly.
