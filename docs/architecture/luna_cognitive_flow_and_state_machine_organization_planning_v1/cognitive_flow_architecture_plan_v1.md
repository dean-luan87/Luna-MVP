## Objective
Organize already-built cognitive modules into one inspectable, deterministic cognitive cycle organization layer without creating a semantic super-owner.

## Canonical Cycle Scope
- Context
- Personal Cognitive Network
- Intent
- Cognitive State Formation
- Cognitive State Vector
- Dynamic Cognitive Regulation
- Reconsideration / transition governance
- Next-cycle inheritance

## Preserved Independent Owners
- Field State Reducer
- Causal Governance
- Future Memory Governance
- Future Experience Governance
- Future Learning Governance

## Planning Principles
- Flow governance may sequence, read, and link only.
- Flow governance may not rewrite owner outputs.
- State transition remains candidate/governance logic, not runtime scheduler logic.
- Suspend/resume/interrupt are planning constructs only.
- Memory and Learning receive reserved insertion points only.
