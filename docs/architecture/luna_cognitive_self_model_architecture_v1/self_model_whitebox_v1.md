# Cognitive Self Model Whitebox v1

| Question | Answer |
|---|---|
| Who creates a current state snapshot? | Self Model composition from owned module states. |
| Who supplies capability evidence? | Capability/Profile and reviewed Self Evolution evidence. |
| Who records limitations? | Limitation Awareness from evidence, failures, and unknowns. |
| Who supplies resources? | Hardware/Runtime state interfaces as read-only context. |
| Who reviews update candidates? | The authorized Self Model Governance boundary with Brain/Governance review. |
| Who owns judgment? | Brain; Self Model does not decide. |
| Who gates execution? | Action Boundary; Self Model only supplies eligibility context. |
| What must remain unchanged? | Constitution, Value, Identity, Goal ownership, Emotion Runtime, Reality. |
| What is preserved? | Provenance, confidence, limitation, permission, and unknown metadata. |

This whitebox describes authority and data ownership; it is not an implementation runtime.
