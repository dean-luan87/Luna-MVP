# Self Regulation Whitebox v1

| Question | Answer |
|---|---|
| Who observes self changes? | Self Observation from read-only Runtime, Hardware, Capability, Model, Memory, and Resource interfaces. |
| Who assesses health? | Self Health Assessment; it produces a health state, not a decision. |
| Who proposes capability/resource regulation? | Self Regulation candidates, subject to Adaptation Governance. |
| Who admits a capability option? | Capability Governance / Admission. |
| Who supplies versions and providers? | Model Manager and Provider Boundary, without cognitive authority. |
| Who validates recovery? | Calibration/health evidence plus governance review. |
| Who owns judgment and goals? | Brain and Goal System remain unchanged. |
| Who executes? | Action Boundary and Action Runtime only; Self Regulation does not execute. |
| What is immutable here? | Constitution, Value, Identity, Goal, Brain core rules, and current Reality. |

This whitebox is a static authority description, not an operational self-modification engine.
