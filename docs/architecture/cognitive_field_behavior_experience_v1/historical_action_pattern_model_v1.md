# Historical Action Pattern Model v1

## Pattern boundary

Historical Action is an Experience-derived Pattern Candidate, not a rule,
preference, Goal, Decision, or Action command. It records what happened in a
prior Field under prior Self, Goal, Task, and Constraint conditions.

```text
Outcome / Experience
        ↓
Historical Action Pattern Candidate
        ↓
Current Field Validation
        ↓
Behavior Candidate
```

## Example pattern

Prior mall visits may show:

1. inspect a map;
2. locate the target store;
3. pause near a preferred area.

The pattern carries frequency, confidence, context, Self State, Goal, Task,
Rule references, outcome quality, validity, time decay, and Unknowns. It must
be revalidated in the current Field.

## Reality priority

If current Reality or Temporary Rule conflicts with history, current Evidence
has priority. A familiar route may be closed; the pattern becomes a Revalidation
Candidate, not an automatic Behavior or Action.

No automatic learning, automatic planning, prediction, Action execution,
Emotion Runtime, Role System, Social Relationship, B Route, or personality
switching is implemented.

Historical Action is not a preference. A Revalidation Candidate is required;
personality switching is not implemented.
