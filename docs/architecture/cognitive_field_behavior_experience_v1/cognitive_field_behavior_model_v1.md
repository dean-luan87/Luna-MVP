# Cognitive Field Behavior Model v1

## Purpose and boundary

Field Behavior describes how Luna may adapt within a Field. It is a behavior
tendency/candidate layer, not an Action, Decision, Goal, Personality, Role, or
Emotion Runtime.

```text
Field Rules / Dynamics
        + Self Capability / State
        + Goal / Task
        + Experience / Preference
        ↓
Behavior Candidate
        ↓
A Route Situation / Option / Decision Candidate
        ↓
Action Boundary (future, separate)
```

## Behavior structure

```text
Field Behavior
├── Behavior Pattern
├── Personal Preference Candidate
├── Historical Action Pattern Candidate
├── Constraint
├── Adaptation Candidate
└── Behavior Candidate
```

Behavior Candidate may express “tend to seek a quiet area”, “inspect a map
first”, “prioritize an exit”, or “explore within safe boundaries”. It does not
specify a movement command or execute an Action.

## Reality and experience

Experience produces a Behavior Pattern Candidate. Current Field Reality and
Rule Evidence validate, weaken, or reject the pattern. Reality is authoritative
over Experience. A historical action is not a Rule, and a Preference is not a
Goal.

## Attention and Task

Behavior Preference may produce Attention Bias Candidate. Task + Field + Goal
may constrain the Behavior Candidate. Neither interface grants Behavior
authority over Attention, Goal, Decision, or Action.

## Placeholders

Emotion Attachment Candidate and Role Binding Placeholder are schema-only
interfaces. Emotion Runtime, Role System, Social Relationship, Personality
Switching, B Route, Prediction, and Action Execution are out of scope.

Field Behavior is not a Decision, not a Goal, not a Personality, not a Role,
and not an Emotion Runtime. Self State is part of the behavior context.
Preference is not a Goal. Personality Switching is out of scope.
