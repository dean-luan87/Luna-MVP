# Field Behavior / Experience Whitebox v1

## Integrated trace

```text
Field Rule / Dynamic
        + Self
        + Goal / Task
        + Experience / Preference
        ↓
Behavior Pattern Candidate
        ↓
Current Field Reality Validation
        ↓
Behavior Candidate
        ↓
Attention Bias Candidate / A Route Review
        ↓
Decision Candidate
        ↓
Action Boundary (separate)
```

## Assertions

- Behavior is a tendency/candidate, not Action.
- Historical Action Pattern is Experience-derived, not a Rule.
- Preference is context-bound and is not Emotion, Personality, Role, Goal, or
  Decision.
- Reality > Experience; current Rule and Evidence validate history.
- Behavior may bias Attention but cannot control Attention, Goal, Decision, or
  Action.
- Task and Field constrain Behavior without changing Task identity.
- Emotion Attachment Candidate and Role Binding Placeholder are schema-only.
- Reducer remains the sole State mutation authority.

No Emotion Runtime, Role System, Social Relationship, Personality Switching,
B, Prediction, Action Execution, automatic planning, or Runtime is included.

No Role System, No Social Relationship, No Personality Switching, No B, No
Prediction, No Action Execution, and No automatic planning are included.

No Prediction is included.
