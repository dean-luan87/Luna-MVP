# Behavior Experience Boundary v1

Experience may create Historical Action Pattern Candidate, Personal Preference
Candidate, Field Association Candidate, or Adaptation Candidate. It cannot
directly become a Behavior, Rule, Goal, Decision, Action, Emotion, Role, or
Personality.

```text
Outcome
  ↓
Experience Candidate
  ↓
Pattern / Preference / Association Candidate
  ↓
Current Reality + Field Rule Validation
  ↓
Behavior Candidate
```

Reality is higher priority than Experience. One successful or failed outcome
does not automatically reinforce or remove a pattern. Repeated patterns need
provenance, confidence, context binding, time decay, and review.

Future Emotion Attachment Candidate is a placeholder only. It does not run an
Emotion Engine. Future Role Binding Placeholder is a schema only; it does not
run a Role System or Social Relationship runtime.

Personal Preference Candidate is context-bound. One failed outcome is not
enough to rewrite a pattern.
