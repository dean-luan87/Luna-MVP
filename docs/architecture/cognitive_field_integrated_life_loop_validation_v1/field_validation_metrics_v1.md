# Cognitive Field Integrated Validation Metrics v1

## Metrics

- **Field Transition Fidelity:** Reality Change produces the expected Field
  lifecycle transition;
- **Goal-Conditioned Field Separation:** same Reality with different Goal yields
  distinct Field context;
- **Reality Fidelity:** Field does not rewrite Reality State;
- **Self Stability:** Self Identity and core capability remain stable while Self
  Layer changes are represented;
- **Continuity Quality:** Stable, Adaptive, and Transient layers transition as
  specified;
- **Unknown Preservation:** Unknown remains explicit through Field and A Route
  input;
- **Feedback Integrity:** Observation Requirement produces a governed Reality
  Update Candidate;
- **Parallel Isolation:** placeholder fields do not contaminate one another;
- **Decision Boundary:** output stops at Decision Candidate without Action.

Metrics evaluate trace and boundary quality, not task success or intelligence.
