# Static audit

The existing Universal Capability Slot planning candidate contains capability
identity, binding, availability, health, resource, governance, trace, and
provenance surfaces. It does not contain a current situated minimum-condition
assessment.

Existing Capability Requirement / Observation Request contracts provide
capability and information/evidence references, but do not provide a generic
per-need `required_condition_refs` resolver.

Active Observation Preconditions already has requirement-specific condition
semantics. Its condition fields are a visual specialization, not a generic
fixed rule for every `text_recognition` use.

Decision, Task, and Action assets are downstream and are not used here.
