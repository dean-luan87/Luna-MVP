# Governance boundary

Capability Registry remains the identity source. Capability Governance /
Capability Admission remains the existing admission boundary. The resolver
produces a candidate requirement; it does not mutate a Capability Slot or
authorize runtime execution.

Forbidden in this phase:

- Provider or Model invocation;
- availability treated as feasibility or eligibility;
- Capability definition deciding the current cognitive need;
- Self or Field mutation;
- World Truth, Fact, Decision, Task, Action, device control, or Runtime
  Executor execution.
