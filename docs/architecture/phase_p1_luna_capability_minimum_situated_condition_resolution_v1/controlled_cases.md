# Controlled cases

1. `TEXT_PRESENCE_ONLY`: `text_recognition` resolves the lower minimum of
   target visibility only.
2. `READ_PRIMARY_SIGN_TEXT`: the same capability resolves the stronger minimum
   of visibility, completeness, adequate scale, and stable relation.
3. `SAME_CAPABILITY_DIFFERENT_INFORMATION_NEED`: both sides use the same
   capability and equivalent target state. The presence need is feasible with
   visibility alone; the primary-reading need is not feasible until the extra
   resolved conditions are satisfied.

The case names are labels and identity fields only. The resolver keys on the
canonical Information Need and Goal inputs.
