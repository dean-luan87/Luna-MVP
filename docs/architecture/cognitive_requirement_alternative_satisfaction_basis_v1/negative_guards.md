# Negative guards

The implementation and controlled evaluation preserve these boundaries:

- no Strategy Coordination, Observation Demand, Provider, Model, OCR, or
  Capability execution;
- no Decision, Task, Action, Truth authority, World Truth, Current World or
  Field mutation;
- no Memory/PCN mutation, evidence fusion, confidence scoring, Boolean DSL, or
  generalized many-to-many basis engine;
- no Need lifecycle/reopen implementation and no hidden fallback strategy;
- no acquisition path inserted into Required Cognitive Condition semantics;
- no modification to Information Need's core subtraction ownership;
- no static Goal/Question/Need string lookup, scenario/case branching, opaque
  Context guessing, or semantic token matching.

The candidate remains candidate-only and read-only. A satisfied requirement is
not treated as no longer required; satisfaction is an independent evaluation
dimension.
