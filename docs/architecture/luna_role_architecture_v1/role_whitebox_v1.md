# Role Architecture Whitebox

Role is the connection layer between Self capability and Social Self expectation inside a Field. A role instance is temporary, evidence-bound, and responsibility-scoped. It is not an identity claim.

Role Memory records performance and interaction patterns; Knowledge can be selectively matched to a capability gap, but only practice and outcome can produce a Role Growth Candidate. B Route can compare role candidates without activating one.

This directory contains contracts and a static verifier only. No Role Runtime, automatic role generation, learning execution, Emotion Runtime, Social Runtime, action, or B simulation is present.
