# Anti-Monolith Guards

The following constraints remain active:

- no Brain runtime owner is introduced;
- Brain does not mutate Intent, Context, or Field;
- Brain does not own A-Route cognition or Cognitive State Formation;
- Brain does not produce Sufficiency, Gap, Re-observation, Revision, or Stop;
- Brain does not perform observation or directly invoke a provider/model;
- Brain does not perform Decision, Task, or Action;
- Brain does not write Memory or promote Experience/Knowledge;
- Brain does not declare World Truth;
- Cognitive Flow does not rewrite source-owner outputs;
- Cognitive Flow lifecycle mechanics cannot override canonical Sufficiency;
- Assimilation Candidate consumption cannot imply downstream admission;
- unresolved authority is never replaced by a descriptive “Brain” label.
