# Phase Contract

This phase resolves authority classification for exactly four coordination
boundaries:

1. Cognitive Request Acceptance;
2. Goal/Concern to Information Need;
3. Closure Acceptance;
4. Assimilation Candidate Consumption.

The phase must not create a Brain runtime owner or change canonical external
runtime components. A resolved result must be backed by an existing owner
contract. Otherwise the exact sub-authority remains `OWNER_UNRESOLVED`.

The outcome is a protocol authority map, not a runtime implementation or a
claim that unresolved Brain responsibilities are already executable.
