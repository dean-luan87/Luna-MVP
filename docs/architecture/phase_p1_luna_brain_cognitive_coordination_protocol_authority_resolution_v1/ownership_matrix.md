# Four-Boundary Ownership Matrix

| Boundary/sub-authority | Producer | Semantic owner | Mutation/mechanical owner | Brain relationship | Decision |
|---|---|---|---|---|---|
| Cognitive Request producer | BRAIN responsibility domain | OWNER_UNRESOLVED | none | COORDINATE | `OWNER_UNRESOLVED` |
| Cognitive Request admission | request producer | OWNER_UNRESOLVED | OWNER_UNRESOLVED | REQUEST | `OWNER_UNRESOLVED` |
| Loop lifecycle creation/tracking | admitted protocol | Cognitive Flow Governance for mechanics | Cognitive Flow candidate state | COORDINATE | `RESOLVED_TO_EXISTING_OWNER` |
| Need formation | A/B or future semantic boundary | OWNER_UNRESOLVED | OWNER_UNRESOLVED | REQUEST | `OWNER_UNRESOLVED` |
| Need admission/registration | Need protocol | OWNER_UNRESOLVED | OWNER_UNRESOLVED | REQUEST | `OWNER_UNRESOLVED` |
| Need lifecycle tracking | CFlow | Cognitive Flow Governance for tracking | CFlow candidate state | REFERENCE_ONLY | `RESOLVED_TO_EXISTING_OWNER` |
| Need satisfaction | CState | Cognitive State Formation Governance | Cognitive State Formation Governance | CONSUME | `RESOLVED_TO_EXISTING_OWNER` |
| Closure eligibility | CState proof consumer | OWNER_UNRESOLVED | none | CONSUME | `OWNER_UNRESOLVED` |
| Closure Candidate | closure candidate boundary | source cognition; no final authority | candidate-only adapter | CONSUME | candidate surface only |
| Closure Acceptance | future authorized consumer | OWNER_UNRESOLVED | OWNER_UNRESOLVED | OWNER_UNRESOLVED | `OWNER_UNRESOLVED` |
| Lifecycle closure transition | accepted ref | CFlow mechanics | Cognitive Flow Governance | COORDINATE | `RESOLVED_TO_EXISTING_OWNER` |
| Assimilation Candidate production | closure/outcome boundary | OWNER_UNRESOLVED | no mutation | CONSUME | `OWNER_UNRESOLVED` |
| Assimilation routing/consumption | candidate producer | OWNER_UNRESOLVED | OWNER_UNRESOLVED | REQUEST | `OWNER_UNRESOLVED` |
| Downstream Memory/Experience | routed candidate | Cognitive Memory & Experience Governance | same owner | FORBIDDEN mutation | existing owner retained |
| Downstream Learning | routed candidate | Cognitive Learning Governance | same owner | FORBIDDEN mutation | existing owner retained |
| Decision/Task/Action | routed domain candidate | respective canonical owners | respective canonical owners | FORBIDDEN execution | existing owners retained |

Semantic ownership and mutation ownership are intentionally separate.
