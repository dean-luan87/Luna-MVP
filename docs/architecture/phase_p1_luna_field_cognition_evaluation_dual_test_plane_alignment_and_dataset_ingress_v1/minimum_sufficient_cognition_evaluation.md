# Minimum Sufficient Cognition Evaluation

The target is the smallest reasonable observation/evidence set that lets Luna
complete or safely stop a field cognition goal.

Record where observable:

- observation and external capability call counts;
- consumed versus ignored evidence;
- cognitive transitions;
- re-observation count and reason;
- Hypothesis revisions;
- unresolved information gaps;
- stop timing and completion state.

Do not reward volume. Do not convert unavailable runtime measurements to zero.
An unnecessary observation is a Plane A process defect even if the external
model is accurate.
