# Progressive Cognitive Level Gates

## Level 1 — Field Cognition

Primary current gate: Luna controls governed external capabilities, obtains
information, rejects interference, and completes field cognition with minimum
sufficient information.

## Level 2 — Field + Self/Role Cognition

Role may be supplied by the case. Evaluate role-specific meaning, targets,
Attention priorities, cautions, and constraints.

## Level 3 — Field + Self/Role + Goal Cognition

Evaluate goal decomposition, target tracking, observation planning, and
cognition-to-Decision-Governance handoff.

## Level 4 — Migration

Field/Role migration and multi-role changes are future-only.

A lower level must be sufficiently stable before the next level becomes the
primary target. This phase defines gates only; it does not implement levels
deeply.
