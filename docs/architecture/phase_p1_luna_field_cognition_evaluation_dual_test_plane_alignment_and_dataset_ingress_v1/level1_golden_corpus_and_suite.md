# Level-1 Golden Corpus and Controlled Evaluation Suite

## Status

The Golden Cognitive Corpus is declared at v1 with sixteen diagnostic case
categories and zero registered datasets/samples. This is intentional: the
next phase may register explicit real-world sources without changing cognitive
test semantics.

## Categories

1. obvious field
2. multiple candidate field
3. irrelevant distractors
4. target absent
5. missing critical information
6. partial occlusion
7. conflicting evidence
8. false external evidence
9. stale evidence
10. wrong-attention trap
11. capability mismatch
12. re-observation required
13. hypothesis revision
14. premature sufficiency trap
15. stop-condition test
16. environment-state change

Each category specifies cognitive property, World/Observation GT
characteristics, allowed perturbations, Plane A assertions, Plane B
observations, and attribution rules. It does not encode a natural-language
answer or model-specific output.
