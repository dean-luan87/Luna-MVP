# Phase Contract

## In scope

- evaluation dual-plane alignment;
- explicit Dataset Registry registration bridge;
- empty v1 Golden Cognitive Corpus declaration;
- Level-1 case composition;
- World/Observation/Cognitive GT layers;
- controlled perturbation declarations;
- separate Plane A/Plane B result contract;
- existing White-box/Profile linkage.

## Out of scope

- dataset download or real sample registration;
- model/provider/observation/runtime execution;
- model training or model optimization;
- White-box UI;
- automatic annotation or data lake;
- runtime model selection/binding;
- Level 2 Role cognition, Memory, B-Route, Learning, or Emotion.

## Stop condition

Stop after the explicit registration path, empty Golden Corpus declaration,
Level-1 composition/GT/perturbation contracts, dual-plane result semantics,
and White-box refs are available. User-terminal verification is required
before registering real-world samples.
