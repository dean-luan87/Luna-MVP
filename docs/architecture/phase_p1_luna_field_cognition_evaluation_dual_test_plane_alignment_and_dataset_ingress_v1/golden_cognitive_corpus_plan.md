# Golden Cognitive Corpus Plan

The first corpus is small, interpretable, and diagnostic rather than large.
Initial categories:

- obvious target;
- multiple candidates;
- target absent;
- missing information;
- occlusion;
- conflicting evidence;
- deliberately false evidence;
- irrelevant distractors;
- stale evidence;
- wrong-attention trap;
- capability mismatch;
- re-observation required;
- Hypothesis revision;
- premature Sufficiency;
- stop-condition test;
- environment change.

Ground truth may describe objectively annotatable world/observation facts. A
separate process contract may describe expected cognitive constraints. Neither
should inject the answer into Provider input. No public data is downloaded in
this phase.
