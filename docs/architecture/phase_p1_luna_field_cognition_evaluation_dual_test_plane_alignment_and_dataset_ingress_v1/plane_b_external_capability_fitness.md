# Plane B — External Capability Fitness Evaluation

Plane B evaluates an external implementation under:

`Capability + Implementation/Model + Version + Provider + Task + Environment
Condition + Observation Requirement + Resource Constraint`.

Metrics include evidence usefulness/stability, missing/false evidence,
uncertainty, latency, resource signals, provider/normalization failures,
re-observation burden, and cognitive burden introduced into Plane A.

Plane B owns no Luna cognition. It cannot create Need, Attention, Hypothesis,
Sufficiency, Decision, Task, Action, Field state, World Truth, or runtime model
selection. Its output is an External Capability Fitness candidate and may not
modify Model Manager bindings.
