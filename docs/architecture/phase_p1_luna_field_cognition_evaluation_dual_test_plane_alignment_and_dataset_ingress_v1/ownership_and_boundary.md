# Ownership and Boundary

Evaluation owns observation, measurement, comparison, Dataset declarations,
evaluation profiles, and protected evaluation records.

Evaluation does not own or mutate:

- Goal, Intent, Concern, Role, Field;
- Attention or cognition runtime;
- Current World or Hypothesis authority;
- Sufficiency or Re-observation control;
- Decision, Task, Action;
- Capability admission or Model/Provider binding;
- runtime model selection;
- World Truth.

The canonical rule remains: **WHO HAS AUTHORITY OWNS RESPONSIBILITY.**
