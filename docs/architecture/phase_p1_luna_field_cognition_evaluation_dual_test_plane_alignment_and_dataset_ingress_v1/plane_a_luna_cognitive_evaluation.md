# Plane A — Luna Cognitive Evaluation

## Subject

`Luna A-Route Field Cognition Brain`.

## Evaluation chain

`Goal/Concern → Context/Role/Field → Attention → Information Need →
Observation Planning → Capability Requirement → Observation → Evidence →
relevance/missingness/uncertainty/conflict/staleness → Current World Candidate
→ Hypothesis/Revision → Sufficiency → Information Gap → Re-observation or
stop → Decision Governance handoff`.

## Pass requirements

Luna must select what to observe for a reason, use only relevant evidence,
preserve uncertainty/conflict, avoid premature Sufficiency, target the next
observation at the gap, stop at minimum sufficient cognition, and preserve
authority boundaries.

Luna may pass with incomplete external evidence when its response is correct
for the information state. It fails when it mishandles even perfect evidence.

## Minimum Sufficient Cognition

Plane A measures whether the goal is completed using the minimum reasonable
information set, not maximum observation volume. Planned refs include
observation/capability calls, consumed/ignored evidence, transitions,
re-observations, Hypothesis revisions, unresolved gaps, stop timing, and
completion state. Unavailable metrics remain unavailable.
