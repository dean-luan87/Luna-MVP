This phase moves controlled integration consumption from direct Dynamic Flow semantic fields to the existing A-owned semantic decision boundary.

The boundary is:

`Dynamic Flow computation → DynamicFlowCompatibilityOutputV1 → verified A semantic wrapper → A decision refs → downstream integration`

Dynamic Flow remains present and useful for deterministic calculation, state/reference bookkeeping, evidence lineage, stale-reference calculation, provisional-plan metadata, and trace/provenance. Its output is compatibility data only. A owns interpretation of Current Need, Local Sufficiency, Reconsideration, and Next-step.

Loop remains mechanical-only. This phase is candidate-only and synthetic-only at the new seam. It does not invoke Provider, model, camera, OCR, Action, Learning, Memory, or Experience mutation.
