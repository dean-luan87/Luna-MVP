# Scope Validation Contract

`CapabilityScopeAssessmentV1` returns structured results:
`IN_SCOPE`, `PROBLEM_CLASS_UNSUPPORTED`, `OPERATION_UNSUPPORTED`,
`INPUT_CONTRACT_UNSUPPORTED`, `OUTPUT_CONTRACT_UNSUPPORTED`,
`AUTHORITY_NOT_ALLOWED`, or `OUT_OF_CAPABILITY_SCOPE`.

Validation occurs before readiness and before Invocation Candidate formation.
