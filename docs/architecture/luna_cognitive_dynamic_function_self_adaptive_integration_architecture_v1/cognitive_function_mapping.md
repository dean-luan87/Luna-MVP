# Cognitive Function Mapping

| 既有模块 | 动态函数定位 |
|---|---|
| Field | Input State Space |
| Attention | Attention Function / Resource Allocation |
| Memory | Historical Influence Function |
| Knowledge | Prior Knowledge Function |
| Belief / Understanding | Dynamic Cognitive State Variable |
| Goal | Cognitive Drive Function |
| Value Utility | Utility Function |
| Decision Arbitration | Decision Function |
| Outcome Evaluation | Error Signal Function |
| Selective Learning | Parameter Evolution Candidate Generator |

映射不替换模块、不创建重复 Owner；函数输出带 Field、来源、时间、置信度和 unknowns。
