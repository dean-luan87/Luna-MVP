# Self Regulation and Calibration Model

## 当前调节

`R(t)=f(Self,Resource,Constitution)` 输出 Attention Budget、Compute Budget、Exploration Permission、Risk Threshold、Learning Permission Candidate。它保护主体稳定性，不负责产生目标或替代 Decision。

## 长期校准

`Calibration=f(Outcome,History,Performance)` 输入 Outcome、Prediction Error、Capability Performance 和 Long-term Pattern，输出 Optimization Candidate。校准必须经过证据、风险、可逆性、Constitution 和 Self Review。
