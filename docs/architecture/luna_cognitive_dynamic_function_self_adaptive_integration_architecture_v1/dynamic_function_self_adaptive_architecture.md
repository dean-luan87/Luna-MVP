# Dynamic Function Self Adaptive Integration Architecture v1

## 定位

本阶段把 Dynamic Cognitive Function Mapping 与 Self Adaptive Regulation 统一为 Meta Architecture。既有 A Route 模块保持 canonical，新增层只描述函数、参数、校准和治理关系，不进入 Runtime。

## 总体模型

`Self Constitution → Self Regulation Function → Dynamic Cognitive Function → Cognitive Capability Modules → Self Calibration Function → Adaptive Parameter Candidate → Self Review`

Dynamic Function 负责描述认知变化规律；Self Regulation 负责当前资源与风险调节；Self Calibration 负责长期结果校准。三者都只能产生候选，不能越权修改 Reality、Identity、Constitution 或直接执行 Action。
