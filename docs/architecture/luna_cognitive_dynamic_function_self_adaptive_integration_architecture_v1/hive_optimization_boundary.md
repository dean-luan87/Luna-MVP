# Hive Optimization Boundary

Hive 只观察 `Field × Cognitive Genome × Outcome`，经过 Performance Analysis 产生 Optimization Candidate。流程为：

`Hive Observation → Performance Analysis → Optimization Candidate → Luna Self Review → Accept/Reject → Adaptive Update Candidate`

Hive 没有直接写入 Luna 参数或 Self 的权限，不连接 Hive Runtime，不绕过 Constitution、Self Boundary、Capability Governance 和版本/回滚要求。
