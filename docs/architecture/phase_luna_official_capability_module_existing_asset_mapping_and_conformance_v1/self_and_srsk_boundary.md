# Capability Self and future SRSK boundary

Capability Self remains a read-only projection owned by Cognitive Self /
Capability Awareness. This phase adds optional CSA references to the canonical
Module and Self view contracts so Self can associate a capability with its
minimal descriptive problem classes. Self does not admit, bind, activate,
remove, or optimize capabilities.

CSA may be consumed by a future SRSK semantic-resolution boundary. SRSK,
semantic folding/expansion, semantic sufficiency, Knowledge acquisition, and
learning remain unimplemented and deferred.
