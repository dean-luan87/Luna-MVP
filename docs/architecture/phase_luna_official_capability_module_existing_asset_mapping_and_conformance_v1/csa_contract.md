# Capability Semantic Annotation (CSA)

CSA is a mandatory, minimal, descriptive annotation attached by reference to
each catalogued Official Capability Module. It tells Luna what problem class a
capability generally helps with and where its boundary lies.

Required semantics include purpose, applicable problem/situation classes,
expected contribution, boundaries, non-capabilities, and requirement hints.
`semantic_depth=MINIMAL`, `candidate_only=true`, and `descriptive_only=true`.

CSA authority flags are all false. CSA is not Module identity, an
Implementation, Model, Provider, Knowledge, World Truth, Field Rule, Intent,
Decision, Task, Learning, or SRSK. Dynamic expansion/folding and semantic
sufficiency execution remain deferred.
