# Official Capability Catalog

The catalog is a read-only metadata projection under Capability Registry /
Capability Governance. It records Official Module references, CSA references,
implementation/model/provider dependencies, generic Slot compatibility,
resource/permission/health/recovery/provenance/lifecycle references.

Catalog means “which Official Luna capabilities are defined.” Universal Slot
means “how a current Luna instance carries a capability.” Catalog entries do
not imply admission, installation, binding, activation, or provider execution.

Market origin remains deferred. Official does not mean mandatory; the catalog
contains `MANDATORY_SAFETY`, `SYSTEM_REQUIRED`, and `OPTIONAL` entries.
