# Official Capability Module asset mapping and CSA catalog

This package classifies existing Luna assets against the already verified
Universal Capability Slot foundation. It adds a candidate-only Capability
Semantic Annotation (CSA) and an Official Capability Catalog projection under
the existing Capability Registry / Capability Governance owner.

It does not create a Registry, Slot, Model Manager, Provider, Self, or
semantic owner. It does not install, activate, invoke, or infer.

Status: inventory and conformance foundation; user-terminal verification
remains required.
