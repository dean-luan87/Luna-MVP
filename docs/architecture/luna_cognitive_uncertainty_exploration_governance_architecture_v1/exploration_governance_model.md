# Exploration Governance Model v1

```text
Unknown
  -> Impact Evaluation
  -> Exploration Candidate
  -> Self Exploration Governance
  -> Approved / Rejected / Deferred
```

The conceptual value interface is:

```text
Exploration Value = Impact * Expected Benefit * Information Gain - Resource Cost
```

It is an interface, not an implemented computation. Governance controls priority, resource budget, depth, and stopping. Stop conditions include Value Exhausted, Budget Exhausted, Information Ceiling, Decision Sufficient, and Accept Unknown.
