# Uncertainty Taxonomy Model v1

Six uncertainty classes are frozen:

- Perception Uncertainty: sensing is incomplete; consider resampling or observation changes.
- Semantic Uncertainty: an observed object or event lacks meaning; consider Knowledge, context, or history.
- Field Uncertainty: the current environment is incomplete; consider Field expansion.
- Causal Uncertainty: the reason for an event is unclear; preserve Hypothesis branches.
- Decision Uncertainty: candidate options have unresolved risk or outcome trade-offs.
- Capability Uncertainty: Luna's ability to complete a task is unclear; consult Self Layer boundaries.

Classification does not create an exploration task by itself. Impact, value, cost, and Self governance remain necessary.
