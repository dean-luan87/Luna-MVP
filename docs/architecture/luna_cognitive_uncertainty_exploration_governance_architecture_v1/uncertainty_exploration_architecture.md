# Luna Cognitive Uncertainty and Exploration Governance Architecture v1

## Position

Uncertainty is a first-class cognitive condition, not a defect to hide. The A route may detect and classify Unknown, evaluate its impact, and propose exploration. It may also accept Unknown when exploration is not worth the cost.

```text
Reality -> Evidence -> Uncertainty Detection -> Classification
        -> Impact Evaluation -> Exploration Candidate
        -> Self Governance Approval -> Exploration Execution Candidate
        -> Evidence Update -> Understanding Update Candidate
        -> Experience / Memory / Schema candidates
```

## Authority

Cognitive Kernel detects Unknown and proposes exploration. Exploration Evaluation assesses impact and value. Self Layer's Exploration Governance Controller approves, rejects, or defers resource investment. Self Rhythm supplies state and budget constraints; Cognitive State supplies current mode. Knowledge, Memory, and Schema provide context. Brain consumes results for understanding and Decision Candidates. No layer is required to resolve every Unknown.

## Boundary

This phase defines taxonomy, value interfaces, strategy candidates, approval, budget, stop conditions, and ownership only. It does not implement an Exploration Engine, Scheduler, Runtime, automatic Knowledge retrieval, automatic learning, model calls, database access, B route, Action, or Self mutation.
