# Cognitive Attention Priority Model v1

## Candidate formula

```text
Attention Priority Candidate =
    Survival Impact
  + Goal Relevance
  + Field Relevance
  + Temporal Urgency
  + Information Value
  + Uncertainty Reduction
  - Resource Cost
```

The formula is a transparent candidate model, not a fixed ranking algorithm.
Context, Self State, Risk, Field, and available resource can change the
candidate. Priority does not equal Importance, and Attention Priority does not
equal Decision.

## Outcomes

The governance layer returns an Allocation Candidate, Arbitration Candidate,
defer candidate, background candidate, or release candidate. It cannot create
a Goal, choose an Action, assert a Value Judgment, or bypass Brain Evaluation.

Unknown and Uncertainty Reduction remain explicit. A high score is not proof
that the underlying Evidence is true.
