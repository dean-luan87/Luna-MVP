# Cognitive Attention Release Model v1

## Lifecycle

```text
Created
   ↓
Allocated
   ↓
Maintained
   ↓
Decayed
   ↓
Released
   ↓
Archived
```

## Release criteria

Attention may be released when information is sufficiently covered, risk is
reduced, the task or Field is complete, the Attention Value has declined, the
request expires, or resource governance requires release. The release reason
and confidence remain traceable.

Release prevents attention leakage and does not delete Reality, Unknown, or a
losing request. A released request may be re-created only through a new
candidate and governance admission.

Attention Release does not modify Goal, Decision, Reality State, Self Model, or
Action. It is not automatic learning and not a Scheduler.

Release occurs when risk is reduced, information is sufficient, or the Field
is complete.
