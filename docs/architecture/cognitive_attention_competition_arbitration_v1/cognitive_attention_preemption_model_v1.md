# Cognitive Attention Preemption Model v1

## Interrupt path

```text
New Evidence
    ↓
Risk Candidate
    ↓
Attention Interrupt Request
    ↓
Attention Arbitration
    ↓
Resource Reallocation
```

Preemption is a resource transition, not a Decision or Action. A Mandatory
Attention request may reserve capacity and suspend or background a lower class
candidate. The request must retain provenance, trigger, confidence, affected
Field, and restoration candidate.

## Restoration

After the interrupt decays or is released, suspended attention may return as a
Recovery Candidate. Restoration is not automatic execution and does not erase
the conflict trace.

## Boundary

Attention Preemption cannot alter Reality, create a Goal, modify Self Identity,
call a model, control hardware, or trigger Action. Neural Fast Attention may
provide a fast candidate; A Route and Brain still govern interpretation and
choice.

Mandatory Attention is the highest arbitration class. Preemption is not an
Action, and this layer cannot trigger Action.

Preemption is not an Action.
