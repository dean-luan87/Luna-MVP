# Canonical Module Ledger v1

`state class` describes the primary state owned or produced by the boundary; it does not turn a candidate into authoritative reality.

| ID / boundary | Purpose | Disposition | Authority / responsibility | Mutation / admission domain | Inputs → outputs | Status / evolution boundary |
|---|---|---|---|---|---|---|

| SEMANTIC | Derived semantic expansion/folding and Working Outline | NARROW | Semantic Module owns derived-product correctness | Outline local lifecycle; no source mutation | Envelope/context/world refs → Semantic Working Outline | CONTRACT_ONLY / DEFERRED_RUNTIME; A judges usefulness |
| A | Concern-local reality thinking | KEEP | A owns Need, Hypothesis, relevance, Sufficiency, Reconsideration, Next-step | A-local semantic state; no global policy | Envelope, outline, snapshot, evidence → local consequences | CONTRACT_ONLY with VERIFIED_CONTROLLED handoff seams; no Provider invocation |
| B-CR | B contingency/reconsideration reasoning boundary | NARROW | B-CR owns its local contingency candidate transformation | B-CR local candidate only | A/constraint/status refs → contingency candidates to A | CONTRACT_ONLY; A remains semantic consequence owner |
| COGNITIVE_STATE_FORMATION | Version-aligned cognitive snapshot formation | KEEP/NARROW | Formation owns assembly/alignment/version/status | Cognitive Snapshot candidate lifecycle | Envelope/source refs → Cognitive Snapshot | CONTRACT_ONLY / CANDIDATE_ONLY; A adopts/uses |

## Negative authority rule

No row may silently acquire a responsibility listed in another row's forbidden domain. In particular: A does not own Attention priority; Diagnostics does not remediate; Protocol Governance does not mutate source state; Loop does not close semantic work; Working Envelope does not become a second Brain or Context.
