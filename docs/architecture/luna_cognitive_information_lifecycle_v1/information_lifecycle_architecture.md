# Luna Cognitive Information Lifecycle Architecture v1

## Definition

Information inside Luna is not static storage. It flows through Cognitive Field and changes state according to relevance, future utility, Self/Role impact, repetition, uncertainty, context match, and time. This lifecycle is the shared substrate for Field Information, Experience, Memory, and Knowledge.

## Canonical lifecycle

```text
Reality / Knowledge Input
 → Information Candidate
 → Admission
 → Field Information
 → Cognitive Processing
 → Experience Candidate
 → Experience Processing
 → Memory Candidate
 → Memory
 → Pattern / Principle
 → Long-term Influence
```

## States

`Observed → Candidate → Admitted → Active → Reinforced → Compressed → Dormant → Archived → Removed`.

Removed means no longer influencing current cognition; it is not destructive deletion. Unknown and contradiction remain explicit throughout the lifecycle.

## Shared mechanisms

Every information type uses the same admission, value evaluation, reinforcement, folding, decay, retention, and exit vocabulary. Parameters differ by type and timescale. Memory is an advanced validated stage, not a bucket for every event.

## Boundaries

This phase defines contracts only. It does not implement information Runtime, automatic learning, automatic compression, Pattern Mining, Emotion weighting, Memory consolidation, or B Route simulation.
