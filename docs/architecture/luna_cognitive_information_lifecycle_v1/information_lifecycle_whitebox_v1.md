# Information Lifecycle Whitebox

The lifecycle is a common vocabulary, not an automatic pipeline. An item can remain Unknown, Candidate, Dormant, or Removed without being treated as false or deleted. Folding and compression preserve provenance, contradictions, scope, and representative evidence.

Field Information is short-lived current context; Experience is situated outcome-bearing history; Memory is validated retained structure; Knowledge remains externally sourced and admission-bound. Self/Social impact remains candidate-only.

This directory contains architecture contracts and a static verifier only. No information Runtime, automatic learning, compression worker, Pattern Mining, Emotion weighting, Memory Consolidation, or B Route simulation is implemented.
