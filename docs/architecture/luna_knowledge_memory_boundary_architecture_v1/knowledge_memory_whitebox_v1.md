# Knowledge–Memory Boundary Whitebox

The three terms answer different questions:

- Knowledge: what information is available in a library;
- Experience: what Luna underwent while using information in a concrete Field, Role, and Task;
- Memory: which experiences passed retention governance and remain useful as context.

Knowledge can be shared; Memory is subject- and scope-bound. Knowledge may inform a hypothesis, but it cannot become fact without Evidence. Memory can support retrieval, but it cannot decide or overwrite current Reality.

This directory contains contracts and a static verifier only. It contains no connector, network client, vector database, RAG pipeline, ingestion worker, or automatic learning path.
