# Luna Knowledge–Memory Boundary Architecture v1

## Position

This phase freezes boundaries among Knowledge, Experience, Memory, and later Self/Social growth. It is Architecture Only: no knowledge ingestion, network access, RAG, cache implementation, automatic learning, Self mutation, Emotion Runtime, or Role Runtime is introduced.

## Canonical chain

```text
External Knowledge
  → Knowledge Admission
  → Knowledge Library / Local Knowledge Boundary
  → Cognitive Processing
  → Field + Role + Task Interaction
  → Experience Record
  → Memory Governance
  → Self / Social / World Memory
  → Growth Candidate
```

Knowledge is information that can be shared, copied, updated, and replaced. Experience is a situated interaction in which knowledge is used with a Field, Role, Task, time, space, interaction, and outcome. Memory is validated experience retained as future context. None of these is automatically Reality, Decision, Identity, or Goal.

## Conversion rules

Knowledge becomes Experience only when the required situation, role, task, interaction, and outcome evidence exist. Reading or importing knowledge alone is not Experience.

Experience becomes Memory only after retention evaluation: repeatability, value, impact, relevance, reliability, conflict, and (where present) emotion metadata. A single occurrence or unverified claim is not automatically retained.

Memory may produce Self, Social Self, or World growth candidates only after stable multi-context validation and Constitution compatibility review. Candidates never directly rewrite those systems.

## Authority and precedence

Knowledge Library owns knowledge assets and admission metadata. Experience System owns situated records. Memory System owns validated retained entries. Current Reality and Evidence remain higher precedence than Knowledge or Memory. Brain evaluates growth candidates; Governance controls activation.

## Knowledge Injection Governance

```text
External Knowledge → Admission → Local Boundary → Cognitive Usage
```

No external source can directly modify Reality, Self, Social Self, Role, Memory, Value, Goal, or Brain rules. This phase defines the gate only; it does not connect an external source.
