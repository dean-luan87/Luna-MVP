# Adaptive Evolution Boundary

Hive Evaluation 只能比较 `Field × Cognitive Genome × Outcome`，产生 Parameter Improvement Candidate。流程为：

`Hive Observation → Parameter Improvement Candidate → Luna Self Review → Accept/Reject/Defer → Parameter Evolution Candidate`

本阶段不连接蜂巢、不执行优化、不自动修改参数。任何候选都必须有证据、效用、风险、可逆性、适用 Field 和版本记录；Identity、Constitution、Safety Boundary、Core Brain Rules 不是可自动演化参数。
