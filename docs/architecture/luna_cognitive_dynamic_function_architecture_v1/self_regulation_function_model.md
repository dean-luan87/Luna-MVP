# Self Regulation Function Model

`R(t) = f(Self, Resource, Constitution)` 的输入包括 Self State、Capability Health、Resource State、Self Rhythm 与 Constitution。输出包括 Attention Budget、Exploration Budget、Compute Budget、Risk Threshold、Learning Permission Candidate。

Self Regulation 保护稳定性和边界；它不生成事实、不覆盖 Reality、不直接切换 Model/Hardware、不直接批准 Learning，也不修改 Identity、Value、Goal 或 Constitution。
