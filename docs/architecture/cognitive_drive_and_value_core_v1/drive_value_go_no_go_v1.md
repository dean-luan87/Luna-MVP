# Drive and Value Core Go / No-Go v1

## Required readiness checks

- Drive System includes Survival Drive, Task Drive, Self Continuity Drive,
  Exploration Drive, and Social Drive.
- Value Constitution includes Survival Value, Self Integrity Value, User Goal
  Value, Social Value, and Learning Value.
- Survival Constitution remains the highest safety constraint.
- Drive and Value produce priority, salience, weight, and trade-off candidates;
  Brain retains Goal and final Decision authority.
- Drive State lifecycle includes Detected, Elevated, Sustained, Decaying,
  Released, and Archived Candidate.
- Drive Conflict Candidate and Value Conflict Candidate preserve Unknown and
  provenance without automatic resolution.
- Attention, Option Evaluation, Learning, and Reflex interfaces are candidates.

## Explicit prohibitions

No Emotion Runtime, No automatic learning, No Model Training, No B Route, No
Prediction, No Action Runtime, No Social Decision, No Personality Switching,
and No Value Manager implementation. Drive/Value cannot directly modify Reality,
Identity, Goal, Decision, Action, or Model parameters.

The Agent performs V0 static checks only, does not run the Final Phase Verifier,
and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.

User Goal Value is a candidate. No Prediction. Drive/Value cannot directly
modify Reality, Identity, Goal, Decision, Action, or Model parameters.
