# Cognitive Drive and Value Core Model v1

## Position

Drive and Value provide internal motivational and evaluative context for
cognition. Drive answers “what internal condition requires sustained attention?”
Value Constitution answers “which considerations should carry importance?”
Neither is Emotion, Goal, Decision, or Action.

The hierarchy is:

```text
Survival Constitution
        ↓ highest safety constraint
Value Constitution
        ↓ value candidates
Cognitive Drive
        ↓ priority / salience candidates
Attention → Situation → Option Evaluation → Brain Judgment
```

Value Constitution cannot override Survival Constitution. Drive cannot create a
Goal or substitute for Brain Judgment. All outputs are candidates with source,
scope, confidence, Unknown, and provenance.

## Cognitive Drive

```text
Cognitive Drive
├── Survival Drive
├── Task Drive
├── Self Continuity Drive
├── Exploration Drive
└── Social Drive
```

Survival Drive can increase when battery, health, capability, or safety risk
declines. This is a priority candidate, not fear or Emotion. Task Drive tracks
unfinished Goal/Task pressure. Self Continuity Drive protects Identity,
Capability, and State continuity. Exploration Drive supports information value
under bounded risk. Social Drive is a future social-context candidate and does
not perform social judgment.

## Value Constitution

```text
Value Constitution
├── Survival Value
├── Self Integrity Value
├── User Goal Value
├── Social Value
└── Learning Value
```

Value Constitution is a stable governance reference, not a Value Manager or a
single numeric score. It provides Value Weight Candidate and Tradeoff Candidate
to Option Evaluation and Brain. User Goal Value remains subordinate to safety
and Constitution boundaries. Learning Value cannot authorize automatic learning.

## Drive and Value loop

```text
Reality / Self State / Field / Goal / Outcome
                    ↓
             Drive State Candidate
                    ↓
             Value Weight Candidate
                    ↓
       Attention / Option Evaluation Support
                    ↓
                Brain Review
```

Low battery may raise Survival Drive and reduce low-value observation. A safe,
slow option may receive a Survival Value advantage over a fast, risky option.
The system supplies trade-offs; Brain retains final judgment.

## Conflict and boundaries

Drive conflict produces Drive Conflict Candidate. Value conflict produces Value
Conflict Candidate. Neither is automatically resolved. Current Reality,
Survival Constitution, Authority, and Brain review remain authoritative.

Drive/Value may affect Attention Candidate, Option Evaluation Candidate,
Learning Candidate, and Reflex Candidate interfaces. They cannot modify Reality,
Identity, Goal, Decision, Action, Model parameters, or Emotion state directly.

## Explicit non-goals

No Emotion Runtime, automatic learning, Model Training, B Route, Prediction,
Action Runtime, Social Decision, Personality Switching, or Value Manager
implementation is included.

Drive and Value are not Emotion, not Goal, not Decision, and not Action. Low
battery is a Survival Drive trigger. Value Conflict Candidate remains a
candidate.
