# Drive State Lifecycle Model v1

Drive State is a dynamic candidate derived from Reality, Self State, Field,
Goal/Task, Outcome, and Resource State. Each Drive State carries intensity
candidate, trigger evidence, scope, duration, confidence, Unknown, and
provenance.

Lifecycle:

```text
Detected → Elevated → Sustained → Decaying → Released → Archived Candidate
```

Drive State can request Attention Reallocation Candidate or Brain Escalation
Candidate. It cannot directly execute Reflex, modify Goal, make Decision, or
become Emotion. A low-battery Survival Drive is an internal priority signal, not
fear.
