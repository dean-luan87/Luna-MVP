# Drive and Value Core Whitebox v1

```text
Reality / Self State / Field / Goal / Outcome
                    ↓
             Drive State Candidate
                    ↓
             Value Weight Candidate
                    ↓
Attention / Option Evaluation / Learning / Reflex Candidates
                    ↓
                 Brain Review
```

## Control questions

- Who defines hard safety limits? Survival Constitution and Governance.
- Who supplies value weights? Value Constitution, never a Value Manager.
- Who creates Drive State? Evidence-backed Reality, Self State, Field, Goal,
  Outcome, and Resource candidates.
- Who resolves Drive/Value conflict? Brain Review after Option Evaluation;
  this phase records conflict candidates only.
- Who owns Goal and final Decision? Brain.
- Who may execute Action? No component in this Planning Only phase.
- Who receives Drive/Value outputs? Attention, Option Evaluation, Learning, and
  Reflex interfaces as candidates.

## Isolation invariants

Drive → Attention Candidate and Value → Option Evaluation Candidate are allowed.
Drive → Emotion, Drive → Goal, Drive → Decision, Drive → Action, Value →
Reality Mutation, Value → Identity Mutation, and Value → Model Training are
forbidden.

This is a Planning Only artifact. No Emotion Runtime, automatic learning, Model
Training, B Route, Prediction, Action Runtime, Social Decision, Personality
Switching, or Value Manager implementation is included.

Social Action is out of scope. Value → Reality Mutation is forbidden. Personality
Switching is forbidden.

Personality Switching is forbidden.
