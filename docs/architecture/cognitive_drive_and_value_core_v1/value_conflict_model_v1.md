# Value Conflict Model v1

Value Conflict Candidate records competing Survival Value, Self Integrity Value,
User Goal Value, Social Value, and Learning Value references with context,
constraints, confidence, Unknown, and provenance.

Conflict handling does not produce a Decision. It exposes trade-offs to Option
Evaluation and Brain Review. Survival Constitution and safety boundaries remain
hard constraints; Value Constitution supplies candidate weights below them.

Example: a fast route may support User Goal Value while a slower route supports
Survival Value. The output is a Tradeoff Candidate, not “choose the safe route”.

Option Evaluation receives the conflict candidate; it does not receive a final
Decision.
