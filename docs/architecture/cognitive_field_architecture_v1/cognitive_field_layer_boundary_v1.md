# Cognitive Field Layer Boundary v1

## Layer responsibilities

| Layer | Responsibility | Exclusion |
|---|---|---|
| Reality Field | carry space, Entity, Event, Relation, State, and Change | no meaning or Decision |
| Self Field | carry Capability, Resource, Health, and Limitation | no Identity rewrite or Goal |
| Goal Field | carry Task Goal and Intent Reference | no new Goal creation |
| Rule Field | carry Survival Constitution, Safety Boundary, Authority Constraint | no rule invention |
| Social Field | carry Role Reference, Relationship State, Permission Context | no social reasoning |
| Emotion Field | carry Attention Bias, Priority Influence, Relationship Weight candidates | no Emotional Judgment or Action |
| Cognitive Field | organize the layers and lifecycle | no Decision, Reasoning, Planning, Prediction, Evaluation, or Action |
| A Route | form Situation and Decision Candidate | no direct raw evidence or hardware |
| Brain | final Goal, Intent, evaluation, and choice | no direct Reality State mutation |

## Boundary invariant

Field State is an input environment, not an interpretation. Cognitive Field cannot
modify Reality State or substitute itself for A Route or Brain. Cognitive Field
does not modify Reality State.
