# Cognitive Field Whitebox v1

```text
Reality Neural Operating Space
        ↓
Reality Field + Self Field + Goal Field + Rule Field
        + Social Field + Emotion Field Candidate
        ↓
Situated Cognitive Field
        ↓
Field State / Unknown / Provenance / Lifecycle
        ↓
Cognitive Field Package
        ↓
A Route Input Environment
        ↓
Situation Understanding
        ↓
Brain Evaluation and Decision
```

Field is the organized environment between Reality and cognition. It does not
perform Decision, Reasoning, Planning, Prediction, Outcome Evaluation, Action,
Emotional Judgment, Value Judgment, or Personality Formation. Multi-field support
is a structural placeholder only.
