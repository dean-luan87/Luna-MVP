# Cognitive Field Constitution v1

## Definition

Cognitive Field is Luna's bounded information organization environment before
cognition. It is a local cognitive space derived from Reality Field, Self State,
Goal Context, Rule References, Social Context, and Emotion Influence Candidates.

```text
Reality Field (large reality space)
          ↓
     Cognitive Field (bounded small field)
          ↓
     A Route / Brain
```

Reality Field carries reality. Cognitive Field organizes a current relevant
environment. A Route forms Situation and Decision Candidate. Brain retains Goal,
Intent, final judgment, and choice.

## Constitutional boundaries

Cognitive Field may extract relevant information, organize a current cognitive
environment, manage information lifecycle, maintain field state changes, support
multiple field instances as a placeholder, and provide an input package to A
Route.

Cognitive Field does not perform Decision, Reasoning, Planning, Prediction,
Outcome Evaluation, Action, Emotional Judgment, Value Judgment, or Personality
Formation. It is not a data cache, Context Window, Memory, Decision Engine, or
World Model Predictor. It is not a Context Window and is not a Decision Engine.

## Authority

The Field is read-organizational and candidate-only. It cannot modify Reality
State, Self State, Goal, Rule Constitution, Emotion State, or Decision. Unknown
and Provenance must remain visible in every field package.
