# Cognitive Reality Field Model v1

## Reality Field

Reality Field is the large reality space supplied by Reality Neural Operating
Space. It describes:

- space and location;
- Entity and object candidates;
- Event;
- time and temporal change;
- Relation;
- observed State and State Change.

Reality Field describes reality and does not explain meaning, danger, value,
emotion, or action. It is not a Decision Engine or World Model Predictor.

## Field extraction

```text
Reality State
 + Self State
 + Goal Context
 + Rule Reference
 + Social Context
 + Emotion Influence Candidate
          ↓
      Field State Candidate
```

The extraction is a bounded organization operation. It may select facts under a
declared scope, preserve Unknown, and retain Provenance. It cannot infer a
recommendation or replace A Route.
