# Cognitive Field Lifecycle Model v1

## Lifecycle

```text
Created
  ↓
Activated
  ↓
Updated
  ↓
Suspended
  ↓
Resumed / Merged / Closed
```

Created means a bounded field candidate exists. Activated means its package is
available to A Route. Updated means new Reality, Self, Goal, Rule, Social, or
Emotion candidates were incorporated. Suspended means the field is retained but
not active. Merged is a structural package operation only; it does not merge
Decision authority. Closed releases the field from active use.

## Lifecycle rules

Every field has owner, scope, validity, resource reference, provenance, Unknown,
and closure condition. A field may be created by Brain or Cognitive Process
Governance, but it cannot create an independent Goal, execute Action, or make a
Decision. Lifecycle management is not a Scheduler Runtime.
