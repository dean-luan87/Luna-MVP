# Overview

This phase adds the minimum Brain-domain contract around the verified
controlled replay cognition path.  It runs exactly two controlled cases:

`Brain-domain request → Information Need → Observation Gateway → A-Route →
Cognitive State Formation → Sufficiency/Stop → Closure Candidate → controlled
Closure Acceptance → Brain-domain Assimilation Candidate`.

The repository does not contain a concrete canonical Brain runtime owner for
this boundary.  Brain-level responsibilities therefore carry
`responsibility_domain=BRAIN` and `canonical_owner_status=OWNER_UNRESOLVED`.
The integration package is a controlled candidate-only boundary, not a new
Brain authority.

The implementation is a controlled skeleton.  It performs no live observation,
model/provider invocation, Decision, Task, Action, Field mutation, Memory
mutation, Experience mutation, or Knowledge promotion.
