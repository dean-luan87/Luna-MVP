insufficient→Gap→Re-observation→Revision→Sufficiency→Stop→Closure.

Memory, Experience, Learning, or Knowledge behavior.

responsibilities use `responsibility_domain=BRAIN` with
`canonical_owner_status=OWNER_UNRESOLVED`; the controlled package is not a
replacement Brain runtime.
