# Task / Brain Boundary v1

Brain owns Intent, Value, long-term Goal, current Goal, final judgment, and
authorization. Task manages continuity: lifecycle state, progress evidence,
pending information, constraints, and resume candidates.

Task cannot become a second Brain. It cannot modify Goal, Value, Decision,
Reality, Self Identity, or Action Policy. Task cannot execute Action and cannot
authorize external operations.

Brain may accept, revise, suspend, resume, complete, or abandon a Task
candidate. A Task may request Attention or provide a Conflict Candidate, but
Brain remains the final authority. A Field transition changes context; it does
not silently change Goal or Task identity.

The Runtime owns only lifecycle mechanics when a future phase authorizes them.
The Reducer remains the sole State mutation authority. Provider and Capability
are not Goal authority, Task authority, or Decision authority.

No automatic planning, no automatic execution, no Emotion, no Role, no Social
Runtime, no B Route, and no Simulation Runtime are included.

Task candidate is submitted to Brain review. Task cannot modify Value, modify
Decision, or modify Reality. No automatic execution, No Emotion, No Role, and
No B Route are included.

Task cannot modify Decision.
