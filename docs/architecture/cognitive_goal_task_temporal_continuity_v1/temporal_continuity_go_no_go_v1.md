# Temporal Continuity Go / No-Go v1

## Required readiness checks

- Goal hierarchy distinguishes Long Term, Current, and Task Goal.
- Task is a Field-bound Cognitive Process, not a Todo List or Action.
- Task lifecycle includes Created, Active, Background, Suspended, Resumed,
  Completed, Abandoned, and Expired.
- Cross-day continuity preserves identity, constraints, pending information,
  provenance, and unknowns.
- Field transitions can suspend/background/resume a Task without silent Goal
  mutation or context pollution.
- Resume requires current Reality confirmation, Field confirmation, and Self
  State reassessment.
- Completion requires outcome evidence; abandonment requires review.
- Attention provides allocation candidates; it does not decide or execute the
  Task.
- Brain retains Goal, Value, Decision, and authorization authority.
- Experience is a candidate reference and cannot replace current Reality.
- The Reducer remains the sole State mutation authority.

## Explicit prohibitions

No automatic planning, No automatic execution, No Action Runtime, No hardware,
No external system operation, No Emotion Runtime, No Role Runtime, No Social
Runtime, No B Route, No Simulation, No online learning, No direct Reality
mutation, No direct Goal mutation, No direct Decision mutation, and No second
cognitive subject.

The agent performs V0 static checks only, does not run the Final Phase
Verifier, and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.

Cross-day continuity is required. Self State reassessment is required before
resume. No Social Runtime, No direct Reality mutation, and No second cognitive
subject are permitted.

The required cross-day continuity check is explicit. No second cognitive subject is permitted.
