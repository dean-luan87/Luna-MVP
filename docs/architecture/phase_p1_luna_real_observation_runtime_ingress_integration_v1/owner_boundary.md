# Owner Boundary

| Boundary | Owner | Phase behavior |
|---|---|---|
| External result production | Provider/capability implementation | Outside this adapter; result is supplied as input |
| Observation admission | Observation Gateway Governance | Validates and normalizes the envelope |
| Cognitive coordination | A Route Orchestration Governance | Consumes Gateway admission |
| Cognition, Sufficiency, Gap, Revision, Stop | Cognitive State Formation Governance | Existing conditioned execution path |
| Re-observation | Field Perception Orchestrator | Candidate boundary only; no provider call here |
| Decision / Task / Action | Existing downstream owners | Not entered in this phase |

No provider or model owns Attention, Evidence relevance, Hypothesis, Current
World Candidate, Sufficiency, or Stop.
