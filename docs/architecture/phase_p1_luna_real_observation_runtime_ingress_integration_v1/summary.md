# Summary

The real-observation ingress contract is statically implemented as an
additive `LIVE_RUNTIME` path. Provider-result-shaped vision, OCR, and
SLAM/spatial inputs are adapted into the canonical Observation Gateway, whose
admission proof is consumed by the existing A-Route and Cognitive State
Formation runtime path.

The phase runner is intentionally controlled: it uses normalized provider
outputs and does not execute external capability code. Real provider adapters
can later supply the same envelope. Decision, Task, Action, and Runtime
Executor remain outside the phase boundary.

Terminal verification is pending; no GO claim is made by this static change.
