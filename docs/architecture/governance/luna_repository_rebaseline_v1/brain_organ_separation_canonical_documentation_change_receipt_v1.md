## Doctrine summary

The canonical architecture now states that Organ-side sensing/native execution and provider-specific normalization remain logically separate from governed cognition and world processing. `ProviderRuntimeResultV1` is the current governed normalization seam when existing contracts suffice. Organ results are candidates, not admitted Evidence, World/Field/Current World truth, cognition results, or Decision authority. After normalization, provider families reuse the existing `RuntimeObservationEnvelopeV1 → Observation Gateway → Evidence` and downstream governed paths.

“Brain side” is a descriptive grouping, not a new Owner. Runtime Admission, Provider Runtime, Observation Gateway, Evidence admission, Field, Current World, Cognition, and Decision retain their existing owners and authorities. Logical separation permits future evaluation of different physical deployments but does not mandate remote transport or authorize an OrganManager, OrganBus, OrganRegistry, OrganAuthority, RPC protocol, distributed scheduler, new Canonical Fact, or parallel Observation/Evidence pipeline. The existing 06.1 → 06.2 → 06.4 → 06.5 governance chain remains applicable.
