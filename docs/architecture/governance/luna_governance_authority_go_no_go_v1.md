# Luna Governance Authority Model Go/No-Go v1

## Conflict Resolution Model

| conflict | resolution | result |
| --- | --- | --- |
| Capability conflicts with Protocol | Protocol prevails; Capability must reject or be remediated | no execution context for incompatible route |
| Protocol conflicts with Constitution | Constitution prevails; Protocol is invalid and requires governance remediation | no permission/admission evaluation may bypass L0 |
| Consumer requests overreach | Permission/Admission and Consumer Governance deny the operation | read-only candidate access remains bounded |
| Learning Candidate overreach | Learning Governance denies Training/Memory/Case/Knowledge/Fact write | remains review/admission candidate only |
| Diagnostics reports a violation | report is preserved; applicable higher authority evaluates it | Diagnostics cannot self-authorize remediation |
