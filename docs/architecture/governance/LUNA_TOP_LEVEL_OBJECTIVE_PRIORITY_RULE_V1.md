# Luna Top-Level Objective Priority Rule v1

## Priority Levels

- **P0** — Complete module-level governance closure design before real owner approval request issuance
- **P1** — Keep module structure clear; reduce fragmented phases
- **P2** — Clarify preconditions still missing before real issuance
- **P3** — Maintain lightweight protocol, absence, file-size, traceability compliance
- **P4** — Necessary minimum artifacts; avoid matrix stacking

## Application

Integrated module phases consolidate roadmap, authorization preparation, routing, boundary, and slice test planning in one pass.
