# Luna Action Boundary Whitebox v1

## Audit questions

1. Is the source a reviewed Decision Commitment rather than raw model output?
2. Are multiple Action Candidates preserved where appropriate?
3. Are physical, social, privacy, and resource risks evaluated?
4. Did Constitution, Safety, Permission, and Context checks pass?
5. Is the output still an Approved Candidate rather than an execution command?
6. Is Human Override available for high-risk cases?
7. Are outcome, failure, and partial-success paths traceable back to the
   request and decision?

## Explicit non-authority

Action Boundary is not Action Runtime, Hardware Control, Provider, Brain,
Goal/Value owner, or Reality Reducer. Emotion, Capability, and Brain cannot
directly execute through this boundary.
