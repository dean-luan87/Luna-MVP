# Brain Capability Regulation Boundary

`CapabilityRegulationCandidateV1` is a reserved interface only.

It carries action, Module reference, optional Slot reference, source, reason,
and governance handoff reference. It explicitly forbids direct mutation,
automatic optimization, automatic acquisition, and automatic uninstall.

Capability Governance remains the only lifecycle authority. No energy,
storage, usage, utility, portfolio, or dynamic cognition algorithm is
implemented.
