# Verifier Contract

The deterministic Verifier checks:

- expected implementation/documentation source set
- 30 controlled scenarios
- Universal Slot and Official Module coverage
- admission/binding/resolution/invocation boundaries
- Safety baseline protection
- current/historical/recoverable Self visibility
- negative guards
- no provider/model/runtime execution flags

It does not invoke existing providers, Model Manager runtime, downloaders,
installers, activation paths, or lifecycle mutators.
