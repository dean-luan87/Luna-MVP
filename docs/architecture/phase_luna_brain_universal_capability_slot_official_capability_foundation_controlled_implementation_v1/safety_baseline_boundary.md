# Safety Baseline Boundary

Mandatory Safety Modules use the same generic Universal Slot system.
Safety classification belongs to Module requirement governance, not Slot type.

The controlled foundation rejects user or Brain requests that unbind or make a
Mandatory Safety Module recoverable below the constitutional baseline.

Safety priority does not grant semantic authority, World Truth authority,
Field mutation authority, or Action authority. Unapproved implementation or
provider references cannot satisfy the safety admission assessment.
