# Universal Slot Contract

`UniversalCapabilitySlotV1` is capability-neutral. It preserves:

- slot identity and version
- lifecycle state
- zero/one current Module binding
- compatibility, resource, permission, health, provenance, history,
  recovery, and trace references
- read-only Self visibility
- candidate-only and negative truth-authority flags

The Slot is not a Module, Model, Provider, Knowledge asset, safety class, or
origin class. No specialized OCR, face, vision, audio, safety, official, or
market Slot exists.

Binding returns a projected Slot candidate. It does not mutate persistent
state.
