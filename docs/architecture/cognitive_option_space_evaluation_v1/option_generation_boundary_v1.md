# Option Generation Boundary v1

## Authorized sources

Option Candidate generation may be initiated by A Route, a Brain Request, or
Capability Feedback. Situation, Self Capability, Self State, Goal Context,
Rules, Survival constraints, Experience Reference, and Unknown Context provide
inputs. A Provider is not an authorized behavior source.

```text
Situation + Self + Goal + Constraints + Unknown
                         ↓
             Option Generation Candidate Set
```

The candidate set must not be ranked as a Decision. It should preserve viable,
infeasible, waiting, rerouting, clarification, and help-request alternatives
when they are materially different. An empty set is a diagnostic candidate,
not permission for an implicit Action.

## Prohibitions

Provider cannot generate behavior. Capability cannot decide. Experience cannot
directly override current Reality. Option Generation cannot create Goal,
Decision, Action, Prediction, or Value Judgment. No automatic execution is
allowed and the Reducer remains the sole State mutation authority.
