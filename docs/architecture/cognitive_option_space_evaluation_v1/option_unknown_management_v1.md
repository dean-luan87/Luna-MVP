# Option Unknown Management v1

## Unknown in the candidate space

Unknown must be carried from Situation into each affected Option Candidate.
Examples include unknown road closure extent, unknown water depth, unknown
resource duration, or unknown Capability availability. Unknown road closure extent, Unknown water depth, Unknown resource duration, and Unknown Capability availability are preserved.

```text
Unknown
   ↓
Option Confidence Adjustment Candidate
   ↓
Information Request / Waiting / Alternative Option Candidate
```

Unknown may raise risk, lower confidence, increase information value, or make
an option require confirmation. It must not be silently converted to a fact,
assumption, certainty, or automatic prohibition. An option can remain viable
with explicit uncertainty; Option Evaluation must not hide Unknown.

New Evidence may regenerate the Option Candidate Space. Unknown handling does
not create a Decision, Action, Prediction, Goal, or Reality mutation.
