# Option Space and Evaluation Go / No-Go v1

## Required readiness checks

- Situation plus Self Capability, Self State, Goal, Constraint, and Unknown
  forms an Option Candidate Space.
- Option Candidate is distinct from Recommendation, Decision, Action,
  Execution Plan, and Prediction.
- Multiple materially different options can coexist without implicit ranking.
- Every option exposes Expected Benefit Candidate, Resource Cost, Risk
  Candidate, Capability Requirement, Unknown, and Dependency. Risk Candidate is required.
- Self Capability Filter produces Capability Fit and Feasibility Candidates.
- Unknown remains visible and affects Option Confidence.
- Option Evaluation includes Survival Impact, Goal Alignment, Capability Fit,
  Resource Cost, Risk, Uncertainty, Experience Reference, and Confidence.
- Brain receives an Option List and retains final Decision authority.
- Provider cannot generate behavior or make a Decision.
- Experience supplies a prior only and cannot override Current Reality.
- Reducer remains the sole State mutation authority.

## Explicit prohibitions

This architecture-only phase has No Action, No Execution Runtime, No automatic execution,
No automatic execution, No Provider Decision, No Emotion, No Role, No Social Runtime, No B,
No Prediction, No automatic learning, No online learning, No real model, No OCR,
No OCR, No SLAM, No Camera, and No Hardware Runtime. There is No direct Reality
mutation, No direct Goal mutation, and No direct Decision mutation. No direct Reality mutation.

The agent performs V0 static checks only, does not run the Final Phase
Verifier, and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.
