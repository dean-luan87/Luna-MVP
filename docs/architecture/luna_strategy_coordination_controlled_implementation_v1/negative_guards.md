# Negative guards

The implementation and verifier preserve:

- no winner selection, ranking, priority, utility or confidence scoring;
- no semantic string similarity, Goal/Question lookup or fallback strategy;
- no Branch, Strategy Candidate, Need, Requirement, Current World, Field,
  Memory/PCN mutation;
- no Strategy Formation rerun or new Branch generation;
- no Resource Governance, Resource Acquisition, locking, scheduler or async runtime;
- no Attention, Observation Demand, Capability Resolution or Capability execution;
- no Provider, Model, OCR, Decision, Task or Action execution;
- no evidence fusion, Truth authority or World Truth promotion;
- no merge, convergence, close or reopen lifecycle.

Governance decisions preserve strategy lineage, Need/Gap refs, basis refs and
provenance without changing the source candidate.
