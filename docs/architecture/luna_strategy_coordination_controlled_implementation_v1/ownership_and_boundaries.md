# Ownership and boundaries

```text
Required Condition / Satisfaction → A-Route Cognitive Responsibility
Information Need                 → A-Route Cognitive Responsibility
Branch Formation / Governance    → Cognitive Flow
Strategy Formation               → Cognitive Flow
Strategy Coordination            → Cognitive Flow Strategy Coordination
Sufficiency / Stop               → existing canonical owners
```

Strategy Coordination does not recompute requirement satisfaction, Need closure,
Sufficiency or Stop. It does not mutate Branch, Strategy, Need, Current World, Field,
Memory or PCN. It does not form Attention, Observation Demand, Capability
Requirement, Decision, Task or Action, and it does not invoke Provider/Model.

Resource availability is outside this owner. A dependency block is a controlled
coordination status, not resource acquisition or scheduling.
