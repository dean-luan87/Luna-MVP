# Cognitive End-to-End Controlled Integration and Closure

This phase composes the verified Brain closure integration into one explicit
two-case baseline. It does not add a Brain runtime owner, new governance, or a
parallel cognition engine.

The wrapper calls the existing controlled path for:

- `CASE_A_SUFFICIENT_STOP`: one-cycle Sufficiency → Stop → Closure Candidate →
  Assimilation Candidate;
- `CASE_B_GAP_REOBSERVE_REVISE_STOP`: Gap → Re-observation → second cycle →
  Hypothesis Revision → Sufficiency → Stop → closure/assimilation candidates.
