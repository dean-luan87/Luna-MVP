# Traceability Contract

Each case exposes and cross-links:

`goal_ref`, `intent_ref`, `concern_ref`, `context_ref`,
`information_need_ref`, `cognitive_loop_ref`, `gateway_admission_refs`,
`a_route_execution_refs`, `evidence_refs`, `hypothesis_refs`,
`current_world_refs`, `sufficiency_refs`, `information_gap_ref`,
`reobservation_ref`, `hypothesis_revision_ref`, `stop_ref`,
`closure_candidate_ref`, and `assimilation_candidate_ref`.

The projection is derived from the raw Gateway, A-Route, Cognitive State
Formation, and existing closure outputs. No downstream identity is generated
by the new integration layer.
