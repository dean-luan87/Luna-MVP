# Case Definitions

## CASE_A_SUFFICIENT_STOP

One controlled replay cycle admits sufficient information. Cognitive State
Formation produces Sufficiency and Stop. The existing closure adapter then
produces candidate-only closure and assimilation envelopes.

Required negative condition: no Gap, Re-observation, or second cycle.

## CASE_B_GAP_REOBSERVE_REVISE_STOP

Cycle 1 is insufficient and produces the canonical Gap and FPO-owned
Re-observation. The exact Gap, Re-observation, and next-cycle ingress refs are
carried into Cycle 2. New replay evidence produces canonical Hypothesis
Revision, final Sufficiency, and Stop, followed by candidate-only closure and
assimilation envelopes.
