# Negative Guards

The baseline must preserve false values for:

- model/provider invocation;
- live Observation;
- Field mutation;
- World Truth declaration;
- Memory, Experience, and Learning mutation;
- Decision, Task, and Action execution;
- Evaluation-owned cognition;
- CState mutation of Brain;
- closure without Sufficiency or Stop.

The existing integration exposes one dynamically exercised negative closure
fixture. Other boundaries remain structurally guarded and are reported as
structural rather than falsely claimed dynamic coverage.
