# Canonical Cognitive Flow v1

## Mainline

`Brain Goal/Concern/Grant → Working Envelope admission/binding → Semantic Working Outline formation + Cognitive Snapshot formation → A reasoning cycle → Need / Hypothesis / Sufficiency / Reconsideration / Next-step.`

Semantic Outline and Cognitive Snapshot are sibling derived products. Neither is required to own or precede the other.

## Local loop

`A Need → Cognitive Requirement → Acquisition Flow → evidence/source updates → refreshed Envelope-derived products → A.`

`A local disposition → Decision Flow → execution/result → local evaluation → A or Outcome Flow.`

## Global return

Brain receives Concern/Goal/Grant, cross-Concern, safety, permission, protected-resource, and final Outcome consequences. Brain does not execute every local cycle.

## Flow classes

Envelope admission is `BINDING / VALIDATION / ADMISSION`; Outline and Snapshot are `FORMATION`; A consumption is `ADOPTION`; A interpretation is `SEMANTIC EVALUATION`; Loop is `MECHANICAL_PERSISTENCE`.
