# Canonical Outcome and Closure Flow v1

## Flow

`Action Result + Task Completion + A Local Evaluation + Decision refs + governed source-state changes → Outcome Evaluation → Outcome Candidate → Brain final adjudication/Assimilation → Goal/Concern consequence + Intent impact candidate + follow-up cognitive work or semantic closure → authorized Loop CLOSE/FREEZE/ARCHIVE.`

## Distinctions

Action Result is concrete execution reporting. Task Completion is contract-level progress. A Local Evaluation is Concern-local semantic interpretation. Outcome Candidate is bounded multi-source evaluation. Brain adjudication is final global consequence. None may be collapsed into a Boolean success.

## Closure

A sufficiency or local closure recommendation plus an Outcome Candidate may support Brain closure adjudication. Brain alone closes, continues or supersedes the Concern. Task completion and Action success do not close a Concern. Loop only persists the authorized closure refs.
