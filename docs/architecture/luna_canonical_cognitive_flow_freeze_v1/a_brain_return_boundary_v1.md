# A versus Brain Return Boundary v1

| Return condition | Immediate target | Owner of meaning | Brain escalation condition |
|---|---|---|---|
| evidence relevance, hypothesis update, Need, Sufficiency | A | A | only if global Concern/Goal consequence appears |
| more observation required | A → Acquisition | A | global resource/safety/permission conflict |
| local replan recommendation | A → Decision | A proposes; Decision commits | Goal/Concern/priority change |
| Provider/runtime/local Task failure | A/Task | A evaluates local meaning; Task owns completion | cross-Concern, protected resource, safety or global impact |
| Decision blocked/rejected | A or Decision | A interprets local consequence; Decision owns commitment | Brain veto/override or global policy conflict |
| partial/uncertain Outcome | A and Brain | Outcome evaluates candidate; Brain adjudicates global effect | always Brain for final acceptance/assimilation |
| Goal consequence / Concern closure | Brain | Brain | Brain authority by definition |
| Grant, priority, safety, permission, protected resource | Brain | Brain/global governance | Brain |

A must not become Brain. Brain does not rerun every local A reasoning cycle.
