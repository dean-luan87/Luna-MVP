# Canonical Execution Flow v1

## Mainline

`A Local Disposition → Decision Candidate → Decision Governance commitment/admission → approved Decision → Task organization/readiness → Action Candidate → Action Governance admission → Runtime/Provider → Action Result → effect evidence / Observation → Field or Current World candidate → Task/A/Outcome.`

## Direct bounded path

`Decision → bounded simple Action Candidate → Action Governance → Provider/runtime` is permitted only for previously adjudicated bounded, low-complexity actions. It never bypasses Action Admission, Safety, Permission, Resource, target freshness, idempotency or provenance checks.

## Ownership

Decision selects what should be done. Task organizes execution. Action governs the concrete side effect. Provider invokes runtime. Action Result reports execution; it does not declare Goal success, Concern closure or World Truth.
