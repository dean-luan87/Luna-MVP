# Canonical Cognitive Work Unit v1

## Unit

The bounded cognitive-work unit is:

`Brain-admitted Concern + valid Grant + Working Envelope`.

Goal supplies global purpose. Concern identifies the bounded cognitive work. Intent supplies governed orientation. Grant supplies authority and scope. Working Envelope binds the admitted source refs, constraints, versions and provenance.

## Identity

Concern identity persists across multiple A reasoning cycles, observations, Decisions, Tasks, Actions and Outcome Candidates until Brain closes, supersedes, or replaces the Concern. A cycle identity changes for each local reasoning pass. Envelope versions change when the admitted binding set changes; Concern identity does not.

## Continuation and termination

Observations, Actions, partial Outcomes and failed Tasks may continue the same Concern through a new A cycle. Semantic work terminates only through Brain closure, supersession, or explicit global stop. Loop `CLOSE`, `FREEZE`, and `ARCHIVE` are mechanical operations authorized by semantic/governance refs; they do not themselves terminate meaning.

No Work Manager is introduced. Task remains execution organization, Decision remains commitment, and Loop remains mechanical persistence.
