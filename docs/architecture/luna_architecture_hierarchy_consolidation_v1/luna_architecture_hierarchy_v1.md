# Luna Architecture Hierarchy v1

## Purpose

This document freezes the ownership hierarchy for the existing Luna assets. It
does not create a cognitive capability, activate Runtime, or move/delete a
historical file. Each module has one canonical layer and one accountable owner.

```text
Luna Cognitive System
├── L0 Constitution Layer
├── L1 Cognitive Operating System
├── L2 Cognitive Core
├── L3 Social & Emotion Intelligence (boundary-first)
└── L4 Capability & Execution System
```

## Layer contracts

### L0 Constitution Layer

Defines non-negotiable constraints: Reality priority, Unknown preservation,
Safety/Survival, permission, and authority boundaries. L0 does not schedule,
interpret, decide, or execute.

### L1 Cognitive Operating System

Owns lifecycle, registry, contract, admission, flow, state, event, diagnostics,
resource, and runtime-governance mechanisms. L1 provides the operating
substrate; it does not own cognitive meaning or final judgment.

### L2 Cognitive Core

Owns world cognition, self cognition, attention/workspace, memory/learning,
motivation, intent/goal/task, brain evaluation, and decision commitment. L2
forms candidates and judgments but does not directly invoke providers or
execute actions.

### L3 Social & Emotion Intelligence

Owns the future social and emotion domain. Current assets are boundary-only or
planning-only unless explicitly admitted by a future phase. L3 cannot mutate
Reality, Constitution, Identity, or Decision authority.

### L4 Capability & Execution System

Owns capability contracts/discovery/calibration, model/provider boundaries,
hardware capability, evidence gateway, and the Action Boundary. L4 supplies
evidence or execution requests; it cannot control Brain, create Goals, or write
Reality directly.

## Consolidation rules

1. A module has exactly one canonical layer and one owner.
2. Aliases and historical assets remain retained; canonical ownership is
   recorded rather than resolved by deletion.
3. Dependencies may point down the operating hierarchy only through declared
   interfaces. Provider output is evidence-candidate output.
4. Social and Emotion remain boundary surfaces in this phase.
5. Any migration is a plan entry, not an executed file move.
