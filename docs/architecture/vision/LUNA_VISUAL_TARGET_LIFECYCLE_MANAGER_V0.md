# Luna Vision — Visual Target Lifecycle Manager v0（视角目标生命周期管理：占位）

**文件**：`docs/architecture/vision/LUNA_VISUAL_TARGET_LIFECYCLE_MANAGER_V0.md`  
**性质**：运行时目标生命周期管理占位文档（只冻结方向与边界；不落实现）  

---

## 1. 文档定位（写死）

- 这是 **视角运行时目标生命周期管理** 的占位文档。
- 当前只冻结：方向、角色、边界、互动关系。
- 当前不做真实运行时实现，不落代码。
- 当前不影响既定 **P1/P2 主线推进**（不打断已冻结主线与接线节奏）。

---

## 2. 模块定位（写死）

- **组织归属**：属于“中台向下延伸的视角运行时治理分支”。
- **运行上相对独立**：可独立维护其运行时状态与输出面。
- **拥有局部自治权限**：可在本模块职责范围内做状态维护与建议输出。
- **不拥有最终裁决权**：对外只输出状态与建议；最终裁决仍归中台主层。

并写死：
- 它 **不是** 前端 YOLO/OCR 的一部分  
- 也 **不是** 中台主裁决器本体  
- 而是 **“前端感知之后、解释/纠偏层之前”的运行时治理层**

---

## 3. 该模块负责什么（占位职责清单）

### 3.1 目标生成逻辑（Mount Logic）

- 什么候选值得挂载成“受管目标”（受管对象/受管文本/受管区域等，均为占位概念）
- 初始优先级 / 初始状态 / 初始 TTL 策略（占位：本期不定义数值与算法）

### 3.2 目标存活与恢复逻辑

- TTL（占位）
- Recovery Window（占位）
- 一致性恢复原则（占位：只定义存在，不定义算法）

### 3.3 目标消失与清理逻辑

- 短时不可见（占位：允许 recoverable/weak 等状态）
- 生命周期过期（expired）
- 任务语义消失（例如当前任务不再需要该目标，占位）
- 清理原因分类（占位：仅声明“需要分类”，不定义枚举全集）

### 3.4 挂起任务监控（Task Suspension Watcher）

- 当前任务目标长时间无进展（占位）
- 反复丢失且恢复失败（占位）
- 当任务进入挂起态时向中台上报（仅上报，不裁决）

---

## 4. 必须互动的对象（强/中/弱互动，写死）

> 口径：互动强度反映“必须互相提供输入/输出”的耦合程度，不代表权限。

- **当前任务链（强互动）**  
  - 提供：任务目标语境、关注对象范围、优先级/容忍度策略输入（占位）  
  - 接收：目标状态、挂起/无进展建议（占位）
- **安全模块（强互动）**  
  - 提供：安全优先级与风险约束输入（占位）  
  - 接收：目标状态变化对安全的提示（占位）
- **中台主层（中互动）**  
  - 提供：全局调度上下文、跨模块治理约束（占位）  
  - 接收：目标生命周期状态与建议；**中台拥有最终裁决权**
- **解释/纠偏层（中互动）**  
  - 提供：候选/纠偏建议输入（占位）  
  - 接收：当前受管目标集合/状态摘要（占位）
- **记忆/环境建模层（弱互动）**  
  - 提供：历史稳定片段摘要（占位）  
  - 接收：仅经中台批准后的“可沉淀候选”与状态摘要（占位）

并明确（写死）：
- 任务链/安全模块提供策略输入
- 本模块对外输出状态与建议
- **中台拥有最终裁决权**

---

## 5. 必须写清的运行时状态（只定义语义，不定义时长/实现）

- **active**：当前被强关注、处于主要跟踪/治理状态的目标
- **weak**：仍相关但证据不足/可见性较弱的目标（占位语义）
- **recoverable**：允许在 Recovery Window 内尝试恢复的一类目标
- **expired**：生命周期已过期或明确不再需要的目标

写死：
- 当前只定义状态语义
- 不定义具体时长与实现策略

---

## 6. 必须写清的运行时动作（占位）

- **mount**：将候选挂载为受管目标
- **refresh**：在新证据到来时刷新目标状态/TTL/优先级（占位）
- **recover**：在短时不可见或弱证据情况下尝试恢复（占位）
- **cleanup**：清理目标（过期/任务语义消失/恢复失败等，占位）

---

## 7. 与开关机 / 任务缓存恢复的边界（必须单列，写死）

- 开关机导致的任务挂起/消失问题 **不归本模块决定**。
- 该事项归 **中台主层未来的任务缓存/恢复治理** 处理。
- 本模块只能上报“当前目标/任务挂起状态”，**不决定跨会话保留**。

可引用/指向未来系统级治理专题：
- `docs/architecture/LUNA_TASK_CACHE_AND_RESUME_GOVERNANCE_V0.md`（若尚未创建：未来系统级治理专题占位）
