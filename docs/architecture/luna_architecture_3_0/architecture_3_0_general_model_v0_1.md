```text
Luna Engineering Constitution
        ↓ bounds
Semantic / System Axis × Governance Axis
        ↓ connected by
Canonical Contracts / Semantic Mappings / Protocols
        ↓ realized by
Engineering Implementation
        ↓ observed through
Runtime Effects / Evidence / Verification
```

Semantic/System Axis answers WHERE DOES IT BELONG? Governance Axis answers WHAT GOVERNS IT? Contracts, mappings and protocols answer HOW IS IT CONNECTED? They are not a third axis.

P3-02H placement:

- XG-01 Authority/Effect: Constitution principle with GF-B realization.
- XG-02–XG-16: primarily Governance Dimensions.
- XG-17 Capability: Canonical Domain D02.
