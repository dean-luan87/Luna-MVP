# Luna Reality Validation Loop Architecture v1

## Position

Reality Validation closes the A-route understanding loop. It compares an earlier Hypothesis and Understanding with later Reality Feedback, preserving the original context and emitting adjustment candidates.

```text
Hypothesis
  -> Current Understanding
  -> Decision Candidate
  -> Reality Feedback
  -> Validation Result
  -> Understanding Adjustment Candidate
```

## Validation results

The permitted result vocabulary is `Confirmed`, `Supported`, `Contradicted`, `Unknown`, and `Expired`. A result records the original hypothesis, validation evidence, timestamp, Field reference, source, and confidence change. Unknown is a valid result; it is not forced into contradiction or confirmation.

## Boundary

Validation does not rewrite Reality, Memory, Self, Identity, Value, Goal, or the original Hypothesis. It produces a candidate for Brain, Learning, or governed consolidation to review. The current Reality and Evidence precedence rules remain higher than prior Understanding, Belief, or Memory.
