# Cognitive State and Reality Validation Whitebox v1

The two mechanisms remain separate but connected:

```text
Self Regulation + Self Rhythm + Field + Task + Capability Health
                         -> State Candidate

Hypothesis + Understanding + Decision Candidate
                         -> Reality Feedback
                         -> Validation Event
                         -> Understanding Adjustment Candidate
```

State candidates describe the condition in which cognition operates. Validation events describe how an earlier understanding compares with later evidence. Neither path directly executes, changes Reality, rewrites Memory, or changes Self/Identity/Goal. Every adjustment retains source, Field, time, confidence delta, and Unknown.
