# B Route Contingency Thinking Reconciliation

## Target flow

A detects material uncertainty
→ A initiates B
→ A provides bounded cognitive package
→ B performs contingency reasoning
→ B returns Plan-B candidate
→ A decides whether / when / how it matters

B is not an independent initial entry and is not a second cognitive subject.

## Frozen boundaries

- B has no independent initial entry.
- B cannot recursively expand without A authorization.
- B output is non-binding.
- B does not create World Truth.
- B does not directly control Loop.
- B may run concurrently with A under shared governance.
- A may pause while B continues.
- B may finish and wait.
- A may discard B output.
- B output may become stale before use.
- A may pass reasoning state into B.
- A may pass new reality information back into B.
- B branch is not automatically a child Cognitive Concern.
- Child Concern creation returns to Brain governance.

## B result contract

The future B output should reference:

- assumption / trigger;
- expected state;
- response candidate;
- confidence candidate;
- validity boundary;
- source A state version;
- invalidation condition;
- trace and provenance.

## Current conflict

The future simulation B Route document supports this contract. The model-test
dual-perception Route B is a separate planning-only candidate pipeline and must
not be silently treated as this contingency engine. Terminology must be fixed
before implementation.

## Loop relationship

B may use the shared Loop Engine for persistence, state version and waiting,
but B does not gain Loop control authority. A B working branch does not imply a
new Loop or child concern.
