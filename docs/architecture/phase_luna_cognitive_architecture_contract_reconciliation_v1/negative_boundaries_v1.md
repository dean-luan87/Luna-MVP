# Negative Boundaries

The following remain explicitly forbidden in this phase and in any contract
reconciliation step:

- new Brain owner;
- Loop Manager;
- Loop Planner;
- Loop Scheduler;
- separate Loop cognitive environment;
- Task super-owner;
- independent B initial entry;
- autonomous B recursive expansion;
- Loop cognition authority;
- direct Task to Loop cognition control;
- direct Provider to Loop cognition control;
- Semantic Module implementation;
- Experience/Short-Path Filter runtime implementation;
- Experience mutation;
- Memory mutation;
- Action execution;
- Provider invocation;
- model inference;
- YOLO;
- OCR;
- camera;
- semantic compression;
- autonomous child Loop spawning;
- autonomous branch/merge;
- World Truth declaration by evidence, Capability, A, B or Loop;
- Provider/model selection by Brain, A, B or Loop;
- canonical enum expansion in this phase;
- mass code deletion;
- deletion of previously verified implementation.

Existing candidate-only guards remain authoritative until a later architecture
review explicitly changes them.
