# Brain / A / B / Loop Flow Contract

## Primary target flow

Brain
→ Semantic Working Outline
→ Experience / Short-Path Filter
→ A Reality Thinking
→ optional Loop persistence
→ optional B Contingency Thinking
→ A Result Consolidation
→ Brain Assimilation / Decision Governance

## Brain boundary

Brain remains:

- cognitive subject;
- Self governance;
- global information holder;
- global resource governance;
- Safety / Permission governance;
- Cognitive Concern owner;
- cognitive-work configurator;
- result receiver and assimilator.

Brain must not duplicate detailed reasoning for a concern after that concern is
materialized into A or B.

## Semantic Working Outline boundary

The Semantic Module is a future boundary only in this phase. It is expected to
compose and expand/fold semantic work information, define Role/Field meaning,
Goal, known information, constraints and work boundary. No implementation or
new owner is created here.

## Experience / Short-Path Filter boundary

The filter compares the expanded semantic need with governed Experience and
known information and selects one of:

- direct resolution;
- short bounded Capability resolution;
- A reasoning required.

The filter does not become a Brain, does not judge general sufficiency and
does not declare World Truth.

## Optional Loop materialization

Short-path work does not automatically create a Loop. A Loop is materialized
only when persistent state, cross-time continuity, multi-step reasoning,
re-observation, waiting, pause/resume or governed capability continuity is
required.

## Direct short paths

Brain
→ Semantic Working Outline
→ Experience hit
→ Brain

Brain
→ Semantic Working Outline
→ Short Capability Requirement
→ governed Capability
→ Result
→ Brain or A, depending on the unresolved cognitive gap

## A and B boundary

A is the initial Reality Thinking entry. A may request B when a material
uncertainty requires bounded contingency reasoning. B returns a non-binding
candidate to A. A decides whether the result remains relevant, is discarded,
or is consolidated into the Cognitive Result.

## Result boundary

Cognitive Result remains candidate-only until Brain assimilation or the
appropriate Decision/Action governance path accepts a later candidate. It does
not automatically become World Truth, Decision, Task, Action, Memory,
Experience or Intent mutation.
