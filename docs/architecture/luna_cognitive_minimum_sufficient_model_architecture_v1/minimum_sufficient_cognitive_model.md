# Minimum Sufficient Cognitive Model v1

## 定位

本阶段不是删除模块，而是定义解释 Luna 持续认知所需的最小状态空间。七个核心状态为：`Field、Self、Understanding、Goal、Value、Memory、Resource`。

## 核心关系

`L(t+1) = F(L(t), Reality(t))`。既有模块作为状态变化函数、约束、观察器或适配器存在；它们可以继续独立治理，但不得产生第二套核心状态真相源。

## 最小充分原则

若一个模块不能改变七个核心状态、提供约束、提供历史影响或提供可验证反馈，则属于扩展能力，不进入 Core State Vector。未知、冲突和候选仍必须保留。
