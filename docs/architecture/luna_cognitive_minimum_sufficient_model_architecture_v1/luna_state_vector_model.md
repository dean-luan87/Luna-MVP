# Luna State Vector Model

`L_t = (Field_t, Self_t, Understanding_t, Goal_t, Value_t, Memory_t, Resource_t)`。

- Field：空间、时间、环境、关系、事件。
- Self：Identity、Capability、Boundary、Regulation。
- Understanding：Belief、Hypothesis、Confidence、Unknowns。
- Goal：Intent、Task、Priority、Activation。
- Value：Benefit、Cost、Risk、Utility。
- Memory：历史影响、激活、衰减、上下文依赖。
- Resource：算力、时间、电量、注意力、网络和存储。

向量是当前主体状态快照，不是数据库、Reality、Action 或人格。每个分量必须有来源、版本、时间、Field Scope 和 trace。
