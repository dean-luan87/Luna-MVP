# Anti-monolith guards

Brain must not become a super-owner or bypass layer.

Brain must not:

- mutate Intent owned by Intent Governance;
- mutate Context or Field state;
- admit evidence outside Observation Gateway;
- perform direct Re-observation;
- bypass A-Route or Cognitive State Formation;
- create Attention, Hypothesis, Current World, Sufficiency, Gap, Revision, or
  Stop candidates;
- execute Decision, Task, Action, model, or Provider work;
- persist Memory or promote Experience/Knowledge;
- mutate Emotion or Self state;
- declare World Truth;
- auto-consume Assimilation Candidates;
- convert a coordination reference into authoritative state.

Every future Brain API must expose source owner, mutation owner, candidate-only
status, provenance, and unresolved-owner status where applicable.
