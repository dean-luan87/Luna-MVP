# Reuse plan

Reuse existing assets without creating parallel owners:

- `Intent Governance` for Intent state and mutation;
- `Context Foundation` for Context projections and provenance;
- `Field Event Admission` and `Field State Reducer` for Field state;
- `Observation Gateway` for evidence admission;
- `Field Perception Orchestrator` for observation/re-observation control;
- `A Route Orchestration Governance` for route mechanics;
- `Cognitive State Formation Governance` for canonical cognition;
- `Cognitive Flow Governance` for lifecycle mechanics;
- `Dynamic Cognitive Regulation Governance` for bounded regulation candidates;
- `Decision Governance` for Decision formation/handoff;
- `Task Manager` for Task lifecycle;
- `Cognitive Memory & Experience Governance` for durable admission;
- `Cognitive Learning Governance` for Learning candidates/admission;
- `Self Governance` for Self/identity continuity;
- Capability/Model/Provider Governance for capability execution boundaries;
- existing closure, outcome, and assimilation candidate contracts.

The future Brain boundary should transport refs and candidate envelopes rather
than copy or reinterpret canonical state.
