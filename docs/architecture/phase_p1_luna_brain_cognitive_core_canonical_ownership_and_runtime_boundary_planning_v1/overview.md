# Overview

This phase is a planning-only definition of the future Luna Brain / Cognitive
Core boundary. It does not create a Brain runtime, mutate existing owners, or
extend the verified A-Route replay path.

The current evidence supports Brain as a responsibility domain and protocol
boundary over existing governance owners. It does not yet support a concrete
canonical Brain runtime owner. Brain-level responsibilities therefore remain
explicitly `OWNER_UNRESOLVED` until a separate authority decision establishes
an owner and API.

The selected planning route is Route B: retain Brain as a coordination and
orchestration domain over independently authoritative Governance modules.
