# Lifecycle contract

The planned lifecycle is:

```text
Goal / Intent / Concern refs
  → Brain-domain coordination
  → Information Need request/binding
  → Cognitive Flow lifecycle
  → Observation Gateway / A-Route
  → Cognitive State Formation
  → Sufficiency / Gap / Re-observation / Revision / Stop
  → Closure Candidate
  → Closure Acceptance boundary
  → Assimilation Candidate
```

Authority decisions:

- Loop lifecycle mechanics remain with Cognitive Flow Governance.
- A-Route and Cognitive State Formation remain the cognition execution owners.
- Sufficiency and Stop are produced by Cognitive State Formation Governance.
- Information Gap and Hypothesis Revision remain with their existing canonical
  cognition owners.
- Re-observation is requested by cognition but admitted/executed by Field
  Perception Orchestrator.
- Brain consumes Sufficiency and Stop; it does not produce them.
- Closure Candidate is a candidate derived from canonical cognition.
- Closure Acceptance authority at the Brain boundary is unresolved.
- Assimilation remains a candidate-only handoff; durable state owners decide
  admission separately.

Stop is not itself closure. Closure is not assimilation.
