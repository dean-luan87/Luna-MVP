# Negative Guards

本阶段明确禁止：

- Requirement / Need / Branch / Strategy / Coordination mutation；
- Attention formation、Decision、Task、Action；
- Capability Requirement formation、Resolution、Execution；
- Provider、Model、OCR、Camera、SLAM、runtime Observation；
- resource acquisition/scheduling、async execution；
- strategy ranking、priority、winner selection、merge、conflict resolution；
- evidence fusion、Truth 或 World Truth promotion；
- fallback demand 或 hidden strategy fabrication；
- goal/question/need string lookup、scenario/case mapping、opaque target guessing；
- cross-problem demand merge 或 cross-gap lineage collapse。

不支持的 acquisition mode 与缺失/不一致 lineage 均 fail closed。
