# Negative guards

本阶段禁止 Provider/Model binding、ranking、score、winner、fallback、runtime allocation、slot/resource reservation、capability activation、execution identity creation、session start、Gateway submission、provider/model invocation、Camera/OCR/SLAM/VLM execution、truth/world mutation、Decision/Task/Action、以及任何 upstream semantic mutation。

Governance Backbone 自动执行 candidate-only、read-only、no-truth、no-runtime、authority/responsibility、requester/executor 和 adapter boundary 规则；任何 blocker 都阻止业务 engine 或统一决策。
