# Luna Midplatform — Field-First Model Document Capability Review v1

## Phase

`Phase-Midplatform-Field-First-Core-Model-Document-Capability-Review-v1-001`

## 目标

用 Luna requirement matrix **反查模型文档**，判断每个模型能否填对应运作节点的出口。不是评价强弱，而是判断状态。

## 审查原则

- 先按 Luna 要求审模型，不按模型宣传反推架构
- 文档审查 ≠ 选型
- 禁止下载/推理/clone/大依赖安装
- 输出仍是 candidate，不得 production_ready

## recommended_status 分类

| 状态 | 含义 |
|------|------|
| reference_only | 结构参考，不接入 |
| candidate_for_future_adapter | 有用但 Phase 1 不适合 |
| candidate_for_near_term_adapter | 匹配 Phase 1，仍未授权下载 |
| unsuitable_for_phase_1 | 不匹配 |
| deferred_due_to_runtime_cost | 过重 |
| deferred_due_to_missing_outputs | 文档未确认关键输出 |
