# Ownership

- Capability Usage and individual capability aggregation: Capability Registry /
  Capability Governance integration surface.
- Execution outcome truth/evaluation: existing Outcome Evaluation Governance;
  this phase stores a separated candidate assessment only.
- Capability lifecycle, scope, binding, and admission: existing canonical
  owners; feedback has no mutation authority.
- Capability Self: read-only projection owner.
- Hive: observer/aggregation boundary only; no write access to an individual.
- Learning and Memory: existing owners; both are deferred here.
