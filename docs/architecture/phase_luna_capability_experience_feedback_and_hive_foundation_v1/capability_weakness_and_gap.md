# Weakness and Gap

`CapabilityWeaknessCandidateV1` means an admitted existing Module has observed
insufficient satisfaction for a problem class/operation/context.

`CapabilityGapCandidateV1` means the formal capability system cannot satisfy a
requirement. It is reused from the existing Resolution contract.

Neither candidate changes scope/lifecycle, replaces a Model/Provider,
downloads/installs, triggers Learning, or acquires a capability.

Hive demand uses `CAPABILITY_WEAKNESS` and `CAPABILITY_GAP` explicitly.
