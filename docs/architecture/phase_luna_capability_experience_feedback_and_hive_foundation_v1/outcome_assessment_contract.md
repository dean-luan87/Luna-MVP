# CapabilityOutcomeAssessmentV1

The assessment retains three independent dimensions:

1. execution outcome: SUCCESS, FAILURE, DEGRADED, TIMEOUT, CANCELLED, UNKNOWN;
2. requirement satisfaction: SATISFIED, PARTIAL, UNSATISFIED, UNKNOWN;
3. task contribution: RESOLVED, CONTRIBUTED, NO_CONTRIBUTION, UNRESOLVED,
   UNKNOWN.

Execution success does not promote requirement satisfaction or task resolution.
The assessment cannot declare World Truth or mutate lifecycle state.
