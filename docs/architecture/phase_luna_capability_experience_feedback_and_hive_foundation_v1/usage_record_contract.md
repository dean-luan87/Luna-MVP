# CapabilityUsageRecordV1

Each record references Module/version, Slot, Invocation, Requirement, problem
class, operation, task/context, execution result, dependencies, temporal
references, and trace/provenance. It contains no raw sensory payload or
unnecessary personal-memory content.

`candidate_only=true` is mandatory. A usage record is evidence about a governed
invocation candidate, not proof of World Truth or task completion.
