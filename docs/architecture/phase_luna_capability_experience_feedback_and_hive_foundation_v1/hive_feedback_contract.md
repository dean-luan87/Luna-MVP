# Hive Feedback and Demand Contract

`HiveCapabilityFeedbackCandidateV1` contains bucketed/aggregate counts,
problem/operation distributions, outcome dimensions, weakness/gap references,
privacy policy reference, and provenance. It explicitly excludes raw
conversations, images, audio, identity records, Memory contents, and full
personal task histories.

`HiveCapabilityDemandCandidateV1` is candidate-only. Demand kind is either
`CAPABILITY_WEAKNESS` or `CAPABILITY_GAP`; it is not a request to acquire,
learn, install, or replace anything.
