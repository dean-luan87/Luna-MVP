# Negative Boundaries

This phase freezes the following prohibitions:

- no Provider invocation;
- no model loading or model inference;
- no checksum computation;
- no dependency probe;
- no runtime/device health probe;
- no new Runtime Admission Manager;
- no new Scheduler, Permission Manager, or Provider Manager;
- no canonical enum expansion unless a later phase proves it unavoidable;
- no Brain model/provider/path selection;
- no A model/provider/path/checksum selection;
- no B-CR admission or Provider control;
- no Loop admission, readiness interpretation, or semantic judgment;
- no terminal readiness argument promoted to canonical authority;
- no creation of Goal, Need, Decision, Action, Memory, or Experience mutation;
- no direct logical-resolution result treated as executable admission;
- no executable candidate without a valid accepted admission candidate;
- no autonomous Provider execution from an Executable Capability Candidate.
