# A Route Long-Term Stability Validation v1

## Synthetic horizons

- **24-hour**: Home, Transit, Office, and Home Fields; routine Tasks; one
  interruption and recovery.
- **7-day**: repeated Field patterns, capability fluctuation, Task resume, and
  Experience candidates.
- **30-day**: environment change, Goal conflict, stale Experience, Unknown
  preservation, and provider replacement candidates.

## Stability assertions

Identity remains stable. Attention does not drift into unlimited allocation.
Field and Task state do not grow without lifecycle release. Reality remains
Evidence-first and Unknown remains explicit. Experience does not replace
current Reality. Decision and Action boundaries remain separated. Capability
changes update Self Capability/State candidates without changing the subject.

## Failure observations

The suite records state pollution, permission drift, Task leakage, Goal drift,
Unknown disappearance, resource exhaustion, and cause-attribution collapse as
diagnostic candidates. It does not silently repair them and does not perform
online learning or automatic policy changes.

The long-term validation is fixture-based architecture review, not a 24-hour
Runtime, 7-day Runtime, 30-day Runtime, Scheduler, Model call, or Hardware
test.

Field transitions and Task interruption are included. Reality remains
Evidence-first. Capability changes remain candidates. This is not a 24-hour
Runtime, not a Scheduler, not a Model call, and not a Hardware test.

Reality remains Evidence-first. This is not a 24-hour Runtime.
