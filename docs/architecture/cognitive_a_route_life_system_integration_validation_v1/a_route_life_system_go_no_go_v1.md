# A Route Life System Integration Go / No-Go v1

## Required readiness checks

- Complete lifecycle trace covers Reality, Field, Self, Attention, Situation,
  Goal, Task, Option, Decision, Action Boundary, Outcome, and Experience.
- Reality Update precedes Field Adjustment and Situation Formation.
- Attention influences observation, Capability requests, Task priority
  candidates, and Brain input without modifying Goal or Decision.
- Task is a Field-bound Process with lifecycle continuity, not a global list.
- Field transitions preserve Task identity and do not leak context.
- Self Identity remains stable while Capability and State change.
- Brain retains Goal, Value, final Decision, and authorization authority.
- Action remains a request boundary; Outcome returns through Evidence and the
  Reducer.
- Experience remains a candidate and cannot replace current Reality.
- 24-hour, 7-day, and 30-day fixtures cover long-term stability.
- Failure injection covers wrong Evidence, Capability degradation, Task
  interruption, Goal conflict, and incorrect Experience.
- No Model → Goal, Capability → Decision, or Action → direct Reality path exists.

## Explicit prohibitions

No real Runtime, No Scheduler implementation, No Model call, No OCR, No SLAM,
No Hardware, No Action execution, No Emotion, No Role, No Social, No B, No
Simulation, No online learning, No automatic planning, No automatic execution,
No direct Reality mutation, No direct Goal mutation, and No direct Decision
mutation.

The Agent performs V0 static checks only, does not run the Final Phase
Verifier, and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.

Task interruption is covered. No Simulation and No direct Decision mutation
are permitted.
