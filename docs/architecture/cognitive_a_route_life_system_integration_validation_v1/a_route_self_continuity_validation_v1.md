# A Route Self Continuity Validation v1

## Self invariant

```text
Self
├── Identity      stable across Field, Task, Capability, and State changes
├── Capability    may degrade, recover, or be replaced
└── State         may fluctuate with resource and health context
```

Field changes, Task changes, Capability degradation, and State changes must not
produce Identity Drift. A degraded camera means Capability/State changed; it
does not mean Luna became a different subject.

## Validation cases

1. Office → Home → Transit preserves Identity and Constitution.
2. Visual capability becomes unavailable while Identity remains stable.
3. Low battery changes Self State and resource candidates, not Reality or
   Identity.
4. Provider replacement changes Evidence Quality Candidate only.
5. A failed Task creates Cause Attribution and Adaptation candidates, not an
   automatic Self rewrite.

Self Capability and Self State may constrain Situation, Attention, Task, and
Option candidates. They cannot change Goal authority, Value, or Brain identity.
The Reducer remains the sole State mutation authority.
