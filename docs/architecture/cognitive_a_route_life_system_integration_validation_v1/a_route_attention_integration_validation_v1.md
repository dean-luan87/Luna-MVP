# A Route Attention Integration Validation v1

Attention is validated as the global cognitive resource scheduling layer, not
as a Goal or Decision authority.

## Integration responsibilities

Attention may produce candidates for:

- Reality acquisition and Context Projection;
- Capability request priority;
- Task resource allocation and suspension;
- Brain awareness input;
- Observation persistence, release, and reactivation.

Attention must preserve Information Value, Uncertainty, Risk, Goal relevance,
Field relevance, and Resource Cost. It may preempt a low-value observation for
a survival signal, but it cannot modify Goal or Decision.

## Validation cases

1. **Normal operation**: stable Field produces bounded observation and Task
   attention without exhausting resources.
2. **Survival preemption**: a danger Evidence candidate creates an Attention
   Interrupt and a resource reallocation candidate; no Action is executed.
3. **Task competition**: Navigation and Conversation produce a conflict
   candidate; Brain receives the conflict without Attention choosing a Goal.
4. **Capability degradation**: visual reliability drops and alternative
   observation candidates are produced; Reality remains evidence-grounded.
5. **Release and recovery**: completed observation releases resources and a
   suspended Task can request attention again after resume validation.

## Boundary assertions

Attention does not modify Goal, Decision, Reality, Self Identity, or Task
identity. Attention does not execute Action. Brain retains final judgment and
authorization. All changes remain candidates until their owning authority and
Reducer process them.

Capability requests remain candidates. Attention Interrupt is a candidate.
The conflict candidate is reported without automatic arbitration. An
alternative observation candidate may be emitted. Attention does not modify
Decision.

Attention does not modify Decision.
