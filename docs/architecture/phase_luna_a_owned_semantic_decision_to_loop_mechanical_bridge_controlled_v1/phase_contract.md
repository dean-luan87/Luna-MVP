# Phase Contract

## Phase

`Phase-Luna-A-Owned-Semantic-Decision-To-Loop-Mechanical-Bridge-Controlled-Implementation-v1-001`

## Scope

This phase freezes a candidate-only migration seam for three semantic
decisions:

- current Need selection;
- local sufficiency judgment;
- reconsideration and next-step judgment.

The semantic decision owner at this integration boundary is the A reasoning
role. Existing Dynamic Flow remains available as a compatibility computational
source. Loop receives only governed mechanical commands.

## Non-scope

No Brain runtime, A reasoning algorithm, B runtime, Provider/model execution,
Semantic Module, Experience Filter, Scheduler or Action is implemented. No
canonical enum, owner or verified Dynamic Flow/Loop implementation is changed.

Runner and Verifier remain user-terminal-owned artifacts and are not executed
in this phase.
