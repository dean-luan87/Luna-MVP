# Self State Experience Boundary v1

## Experience relationship

Self State can be included as context in an Experience Candidate:

```text
Self State Context
        + Decision Context
        + Outcome Evidence
        ↓
Situated Outcome Evaluation
        ↓
Experience Candidate
```

Experience may record that low battery, high load, or degraded network
coincided with an outcome. It may produce a future Resource Management
Candidate or Attention Pattern Candidate. Resource Management Candidate is a
candidate only. It cannot directly modify Identity,
Capability, Goal, Decision, Reality, or Self State.

One event cannot permanently change the Self Model. Repeated validated evidence
may produce a Self State Pattern Candidate, but adoption requires governance,
current evidence, provenance, confidence, and expiry. Experience is not
automatic learning, not online learning, and not a personality update. It is
not automatic learning.

## Recovery precedence

Current Runtime Evidence has priority over stale Experience. A recovered
battery or cleared load must be allowed to produce a Recovery Candidate; an
old failure must not permanently keep Luna in a degraded state.
