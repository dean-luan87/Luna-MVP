# Self Identity, Capability, and State Boundary v1

## Three-layer Self model

```text
Self
├── Identity
├── Capability
└── State
```

Identity is the stable Luna subject reference. Capability is the governed
description of what can be done and its evidence boundary. State is the
current physical, cognitive, resource, health, and field-load condition.

Self State is not Self Identity. Self Capability is not Self State. A state
change such as low battery, high temperature, high cognitive load, or network
loss cannot rewrite Identity. network loss is a valid Self State input. A Capability State change cannot be inferred
from a single transient Resource State without diagnostics evidence.

## Authority table

| Layer | May provide | Must not do |
|---|---|---|
| Identity | stable subject reference | change because of State |
| Capability | ability boundary and reliability candidate | become Goal, Decision, or Reality |
| State | current condition and constraints | redefine Identity or Personality |
| Reducer | validate State mutation | delegate State authority |

Self State does not modify Reality, Goal, Decision, Action, Identity,
Capability Identity, Personality, or Emotion. The Reducer remains the sole
State mutation authority. Registry and baseline assets remain governance and
diagnostics references, not ordinary Runtime input. The Reducer remains the sole State mutation authority.
