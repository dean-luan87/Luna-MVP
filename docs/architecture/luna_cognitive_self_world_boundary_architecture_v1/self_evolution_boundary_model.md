# Self Evolution Boundary Model v1

The controlled growth path is:

```text
Experience
   ↓
Memory
   ↓
Schema
   ↓
Growth Candidate
   ↓
Self Review
   ↓
Self Evolution Candidate
```

Potentially mutable objects include capability confidence, strategies, and
validated schemas. Constitution, Identity, and Safety Boundary are protected
from automatic change. Social feedback may inform a candidate, but Social Self
does not replace the Self Core. Capability failure updates capability evidence
or a degradation candidate, not identity.

Self Evolution is a governance path only in this phase. It does not execute
learning, modify code or model weights, change personality, or activate an
Emotion/Social Runtime.
