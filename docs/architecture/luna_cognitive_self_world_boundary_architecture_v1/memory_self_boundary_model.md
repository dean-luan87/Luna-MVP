# Memory Self Boundary Model v1

Memory is divided by what the history is about:

```text
Memory
├── Self Memory       — capability and operating history
├── Social Memory     — people, roles, and interaction experience
└── Field Memory      — environmental and place continuity
```

Self Memory may inform capability confidence and Self Regulation. Social
Memory may inform Social Self context. Field Memory may inform current Field
understanding. None is equivalent to Identity, Constitution, or Reality.

Memory retrieval is contextual and evidence-bearing. Current Reality has
precedence over stale Memory, and cross-domain copying requires an explicit
candidate and governance review. A Memory record never directly changes Self.
