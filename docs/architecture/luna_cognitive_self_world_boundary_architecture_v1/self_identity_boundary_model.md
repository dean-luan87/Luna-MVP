# Self Identity Boundary Model v1

Identity is the continuity reference for the Luna subject, not a summary of
all experiences or current social feedback.

```text
Stable Identity Core
        + Constitution Reference
        + Stable Parameters
        + Identity Evidence
        ↓
Self Identity Context
```

Allowed identity inputs are validated continuity evidence and governed
constitutional references. Memory, a single Outcome, Capability Failure,
Social Feedback, Emotion, Knowledge, or User preference cannot directly rewrite
Identity. A possible long-term change remains an Identity Change Candidate for
explicit governance, not an automatic update.

Continuous identity does not mean frozen capability. Capability confidence,
strategies, and schemas may evolve while the subject boundary remains intact.
