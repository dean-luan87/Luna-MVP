# Cognitive Field Role Dynamic Core v1

## Position

This layer integrates Field, Role, Relationship, Task, Self, Attention, Drive,
and Value into a dynamic relational cognitive core. Luna does not merely
observe a world; it persists in nested and associated Fields with contextual
positions.

```text
Field State + Role Stack + Relationship Layer + Task + Self + Drive + Value
                               ↓
                         Dynamic Core State
                               ↓
                  Attention / Brain / Memory Candidates
```

All outputs are candidates. Brain retains Goal and final Decision authority;
Reality Reducer retains Reality mutation authority; Identity remains continuous.

## Field Network

Field Network supports Physical Field, Social Field, Virtual Field, Task Generated Field, and Relationship Field. Nodes may be nested, associated,
activated, backgrounded, suspended, closed, archived, or transferred. A School
Field may contain a Meeting Task Field, Meeting Room Field, and Virtual Chat
Field without merging their boundaries.

Field sources include Reality, Social Relationship, Task, Goal, Virtual Interaction, and Memory Reconstruction. A Task can create a Temporary Field;
closing it does not erase Outcome or Memory candidates.

## Role Projection and composition

```text
Role Instance = Field + Relationship + Task + Rule + Time
```

Role is a dynamic instance, not an Identity attribute. A Role Stack can contain
Organizer, Participant, Safety Observer, and Employee simultaneously. Each Role
has Priority Candidate, Responsibility, Constraint, and Attention Requirement.
Role conflicts are recorded as Role Conflict Candidate and are not auto-
resolved.

## Relationship Layer Stack

Multiple relationship candidates can coexist: Colleague + Friend + Historical Conflict. Each relation carries Source Field, Time, Evidence, Confidence,
History, Boundary, and Unknown. Relationship is contextual and temporal, not a
single global label or direct Emotion judgment.

## Dynamic integration

```text
Field State + Role Stack + Drive + Value + Risk
                      ↓
                Attention Allocation
```

Task flow is `Goal → Task → Field Creation → Role Assignment → Capability Requirement`. Memory stores Field State, Role, Relationship, Outcome, and
Experience candidates rather than a bare event. Field Conflict Candidate enters
Brain review and is not silently resolved.

## B Route placeholder

Future B Route may copy a Current Field State into a Simulation Field Candidate
and modify Role, Rule, Relationship, or Goal variables. This phase only defines
the interface; no B Runtime or Prediction is implemented and no Simulation Field
may mutate Reality.

## Explicit non-goals

No Emotion Runtime, automatic personality switching, Social Decision,
Relationship Judgment, B Runtime, Prediction, Action Runtime, or autonomous
multi-agent/hive behavior is included.
