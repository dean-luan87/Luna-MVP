# Field Role Dynamic Core Whitebox v1

```text
Field Network
  ↓
Field State / Role Stack / Relationship Layer
  ↓
Task + Self + Drive + Value
  ↓
Attention Allocation Candidate
  ↓
Brain / Memory / Capability Candidates
```

## Control questions

- Who creates a Field? Reality, Social Relationship, Task, Goal, Virtual Interaction, or Memory Reconstruction through a Field Generation Candidate.
- Who activates or closes a Field? Field Governance lifecycle candidates.
- Who projects Role? Field + Relationship + Task + Rule + Time.
- Who composes Roles? Role Stack; conflicts remain Role Conflict Candidate.
- Who supplies Relationship? Contextual history and Evidence; not a judgment
  engine.
- Who owns Goal and final Decision? Brain.
- Who owns Reality mutation? Reality Reducer after Evidence Gateway.
- Who receives dynamic outputs? Attention, Memory, Capability, and Brain as
  candidates.

## Isolation invariants

Field Network → Role Assignment Candidate, Role Stack → Attention Candidate,
Relationship Layer → Memory Candidate, and Task → Field Creation Candidate are
allowed. Field/Role → Identity Mutation, Relationship → Emotion Judgment,
Field → Decision, Field → Action, and Simulation Field → Reality Write are
forbidden.

B Route is a placeholder only. Emotion is a placeholder only. This is a
Planning Only artifact with no runtime or automatic resolution.
