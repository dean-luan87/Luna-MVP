# Field Role Dynamic Core Go / No-Go v1

## Required readiness checks

- Field Network includes Physical, Social, Virtual, Task Generated, and
  Relationship Fields.
- Network supports nested, associated, activated, closed, archived, and
  transferred Field states.
- Field Generation sources include Reality, Social Relationship, Task, Goal,
  Virtual Interaction, and Memory Reconstruction.
- Role Instance equals Field + Relationship + Task + Rule + Time.
- Role Stack preserves Priority, Responsibility, Constraint, and Attention Requirement; Role Conflict Candidate is not auto-resolved.
- Relationship Layer Stack preserves Source Field, Time, Evidence, Confidence,
  History, Boundary, and Unknown.
- Attention integrates Field State, Role Stack, Drive, Value, and Risk.
- Task can create a Field and Memory stores integrated Field/Role/Relationship
  state candidates.
- Current Field State → Simulation Field Candidate is placeholder-only.

## Explicit prohibitions

No Emotion Runtime, No automatic personality switching, No Social Decision, No Relationship Judgment, No B Runtime, No Prediction, No Action Runtime, No autonomous Multi-Agent, and No Hive. Dynamic Core cannot directly modify Identity, Reality, Goal, Decision, or Action.
