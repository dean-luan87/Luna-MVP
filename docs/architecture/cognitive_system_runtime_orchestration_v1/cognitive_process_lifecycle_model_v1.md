# Cognitive Process Lifecycle Model v1

## Process classes

```text
Cognitive Process
├── Survival Process
├── Foreground Process
├── Background Process
└── Maintenance Process
```

Survival Process is persistent health/safety monitoring. Foreground Process is
the current primary intent context. Background Process maintains field,
capability, and unknown-state awareness. Maintenance Process performs a low
frequency maintenance candidate such as experience organization.

## Lifecycle

```text
Created → Active → Background → Suspended → Completed → Archived
```

A process carries intent reference, context reference, state reference,
resource request, priority candidate, authority boundary, lifecycle state, and
provenance. A process is not a person, Brain, Goal, Decision, or Action. It is not Brain,
not a Decision, and not an Action.

## Process boundaries

Process orchestration may create a wake-up candidate, suspend a process, or
return a resource conflict candidate. It cannot interpret Reality, choose a
Goal, make a Decision, or execute Action. Multiple processes are represented;
multi-A coordination remains outside this phase.
