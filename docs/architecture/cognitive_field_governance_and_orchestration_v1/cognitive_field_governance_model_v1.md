# Cognitive Field Governance Model v1

## Purpose

Field Governance makes Cognitive Field a stable operating environment. It
manages registration, admission, lifecycle, resources, information boundaries,
health signals, and field relationships. It does not make a Decision or become a
cognitive subject. Governance is not a cognitive subject.

```text
Field Request
      ↓
Field Registry
      ↓
Validation / Field Admission
      ↓
Activation Candidate
      ↓
Resource / Information / Health Governance
      ↓
Field Relation Candidate
      ↓
A Route Input / Brain Interface
```

## Governance invariants

- external models provide Evidence and cannot create a Field directly;
- Registry describes current managed fields and is not Memory or cognition;
- Resource Governance returns Allocation Candidates for Attention, Memory,
  Compute, Sensor, and Energy;
- Information Boundary prevents unauthorized cross-field data flow;
- Health Monitoring returns Diagnostic Candidates, not repairs;
- Orchestration manages coexist, pause, and shared-resource relationships only;
- Reality, Self, and State remain Reducer-governed and are not modified by Field
  Governance.
