# System Constitution Governance Whitebox v1

## Authority questions

| Question | Canonical answer |
|---|---|
| What is highest? | L0 System Constitution |
| Who governs lifecycle and admission? | L1 Cognitive OS Governance |
| Who understands and generates decisions? | L2 Brain within Cognitive Core |
| Who manages capability options? | L3 Capability Governance |
| Who executes? | L4 Action/Capability Runtime after admission |
| Who may edit L0? | Governed constitutional change process only |

## Invariants

- One owner per core state;
- Brain is the only Decision Candidate generator;
- Evidence Gateway separates provider output from Reality;
- Action requires an authorization gate;
- Long-term Memory requires admission;
- Self Regulation and Learning emit candidates rather than silently rewriting
  protected state;
- Future extensions enter through Constitution, Governance, Core Integration,
  and Capability Admission.

## Verification boundary

The phase verifier performs static contract checks only. It does not import or
execute Runtime, Model, Provider, Hardware, Emotion, Social, or automatic
self-modification behavior.
