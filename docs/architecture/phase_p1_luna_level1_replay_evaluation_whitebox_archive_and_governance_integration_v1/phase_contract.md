# Phase Contract

This phase stops at one controlled replay case with canonical cognition execution, White-box V1 observation, independent Plane A/B/G results, one immutable archive record, and one narrow negative governance check.

Deferred: live runtime, providers/models, multi-case evaluation, baselines, regression, Governance Console, White-box UI, remediation, promotion, learning, Memory, Field mutation, Decision, Task, and Action.
