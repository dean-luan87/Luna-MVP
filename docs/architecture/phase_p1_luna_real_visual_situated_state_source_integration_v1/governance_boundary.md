# Governance Boundary

Allowed in this phase:

- one bounded real YOLO11n invocation at user terminal time;
- candidate-only visual state projection;
- existing condition, feasibility and eligibility evaluation.

Prohibited:

- OCR or another provider invocation;
- target semantic truth, Field mutation, or World Truth;
- camera, movement, IMU, SLAM, tracking or device control;
- Decision, Task, Action, or Runtime Executor execution;
- invented scale thresholds or inferred temporal stability;
- bypassing existing Provider Runtime or condition owners.

`eligible_now` and any resulting feasibility are candidates only. This phase
does not authorize downstream execution.
