# Field Temporal Evolution Whitebox v1

The temporal layer preserves the distinction between a current snapshot, a candidate continuity judgment, and historical context:

```text
Field_t0 Snapshot
      -> evidence-backed identity candidate
      -> transition candidate
      -> Field_t1 Snapshot
      -> ordered evolution history candidate
```

Memory may provide historical references, but a snapshot is not Memory and history does not overwrite Reality. Self Regulation and Role provide constraints; they do not become Field owners. Unknown, provenance, timestamps, and confidence remain visible at every transition.
