# Field Transition Model v1

## Transition vocabulary

- `Stable`: the current Field remains materially continuous.
- `Changed`: a Field property changed while identity continuity remains possible.
- `Expanded`: the Field scope or participating context increased.
- `Merged`: two Field candidates share sufficient continuity evidence.
- `Split`: one Field candidate separates into distinct contexts.
- `Expired`: the Field is no longer active for the current context.
- `Replaced`: a new Field candidate supersedes the current context after review.

Every transition is a candidate with a source event, evidence, time, prior snapshot, next snapshot, confidence, and Unknown. A transition never directly performs an Action, writes Memory, or changes Reality.
