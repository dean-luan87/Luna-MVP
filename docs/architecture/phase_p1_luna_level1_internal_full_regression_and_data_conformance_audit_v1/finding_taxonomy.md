# Finding Taxonomy

Severity is `BLOCKER`, `MAJOR`, `MINOR`, or `INFO`.

- BLOCKER: runtime cannot execute, causal/owner boundary is broken, archive is
  corrupted, forbidden capability executed, or a false success hides failure.
- MAJOR: required data, identity, White-box, governance evidence, or artifact
  consistency is missing or ambiguous.
- MINOR: non-critical metadata or documentation omission.
- INFO: contextual observation.

The report retains finding ID, severity, category, component, run ref,
description, expected, observed, evidence ref, and remediation requirement.
