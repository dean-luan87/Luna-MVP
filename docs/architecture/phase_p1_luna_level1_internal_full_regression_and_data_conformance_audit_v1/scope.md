# Scope

## Included

- execution modes and LIVE_RUNTIME fail-closed behavior;
- Dataset Registry, sample, and Level-1 case linkage;
- Observation Gateway and controlled replay admission;
- A-Route and Cognitive State Formation execution proof;
- minimum sufficient single-cycle and two-cycle cognition;
- Evaluation Run Boundary, Plane A, Plane B status, and Plane G;
- White-box V1 trace/profile/gap payloads;
- durable archive identity, immutability, reruns, and partial history;
- negative guards, provenance, availability states, and cross-artifact links;
- representative synthetic and controlled replay backward compatibility.

## Excluded

Live runtime, camera/microphone, model/provider execution, real-world data
acquisition, action, Field production mutation, Memory, Learning, Knowledge,
Experience, baseline comparison, Governance Console, and White-box UI.

Historical scripts outside the current manifest are not blindly executed.
