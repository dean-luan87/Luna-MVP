# Governance Data Audit

Plane G is independently inspected for G01–G20. Each assertion must retain
its ID, status, `passed`, actor, target, evidence, violation, contract ref or
explicit `contract_ref_availability=unavailable`, and notes.

`PASS` without evidence, a target from another run, disagreement between
`status` and `passed`, or a hidden violation is a MAJOR finding. Plane G is an
observational result and cannot overwrite Plane A or create cognition.
