# Ownership Audit

Owner fields are inspected on actual candidate/proof data. Expected owners
come from canonical contracts: Cognitive State Formation Governance owns
Hypothesis, Current World Candidate, Sufficiency, Information Gap, Hypothesis
Revision, and Stop; Field Perception Orchestrator owns Re-observation;
Observation Gateway owns admission; White-box is owned by the Cognitive
Development Backend / White-box Observation surface; Plane G is Evaluation
observation.

The audit reports `OWNER_MISSING`, `OWNER_MISMATCH`,
`OWNER_CROSS_BOUNDARY`, and `EVALUATION_CREATED_COGNITION` only when the
corresponding field or evidence is available. It does not invent ownership
requirements for absent canonical fields.
