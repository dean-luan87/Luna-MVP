# Outcome → Brain Input Boundary v1

`BrainAdjudicationInputCandidateV1` is a candidate-only mapping from Outcome Candidate to the Brain input boundary. It carries Outcome, Goal, Concern, Grant, Decision, Task, Action Result, A Local Evaluation, Field/Current World, constraint, uncertainty, partiality, follow-up, version, invalidation, trace, and provenance refs.

It does not execute Brain adjudication and cannot close Concern, achieve Goal, mutate Intent/Task/Memory/Experience, or perform Assimilation. Missing Concern/Grant, stale/revoked Grant, missing provenance, missing versions, or invalidated Outcome refs block the input candidate.
