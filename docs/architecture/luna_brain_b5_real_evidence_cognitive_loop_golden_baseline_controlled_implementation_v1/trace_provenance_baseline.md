# Trace and provenance baseline

The reverse lineage is Outcome/Reobserve → Task → Decision → Intent →
Cognitive State/Flow → Current World → Context → Gateway → Visual Evidence →
Provider/Model/Frame. Trace, provenance, temporal, uncertainty, and
conflict/contradiction reference classes are required. Provenance grants
auditability, not authority.

The source planning field is `required_ref_classes`; the governance snapshot
also exposes the normalized name `required_reference_classes` with the
independent values `trace_refs`, `provenance_refs`, `temporal_refs`,
`uncertainty_refs`, `conflict_refs`, and `contradiction_refs`.
