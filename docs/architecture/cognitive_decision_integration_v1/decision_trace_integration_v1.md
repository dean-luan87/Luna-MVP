# Decision Trace Integration v1

## Integrated trace

```text
Situation Candidate
        ↓
Option Candidate Space
        ↓
Option Evaluation Candidates
        ↓
Decision Context Package
        ↓
Decision Candidate
        ↓
Brain Review Candidate
        ↓
Revision / Acceptance / Rejection Trace
```

The trace preserves situation reference, option list, constraints, risk,
unknown, capability, Self State, confidence, Evidence Support, Experience
Experience Reference, review status, revision reference, and provenance. It must preserve
rejected options and previous package references rather than overwriting them.

The trace is structured decision basis, not private chain-of-thought. It is not
an Action plan, Action Command, Runtime record, Outcome claim, Goal mutation,
or Decision approval. Brain Review remains the final cognitive judgment
boundary. The final cognitive judgment boundary remains Brain Review.
