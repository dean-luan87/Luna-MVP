# Episodic Memory Model v1

Episodic Memory retains a bounded event reference: event, Field, Self context,
Goal/Task context, Outcome, time, evidence, confidence, provenance, Unknown,
and conflict. It is not a full recording of Reality.

Admission requires an Experience Candidate and Memory Admission review. A
single unconfirmed event remains a candidate and cannot become a durable
pattern. Retrieval is scoped by Current Field, Goal, Task, Attention, time, and
relevance.

Current Reality > Memory. If an old event says an exit exists and current
Evidence says the wall is closed, the current Reality Update Candidate wins;
the episodic item remains a historical reference with conflict metadata.

Episodic Memory may be compressed into a Field Pattern Candidate or Behavior
Pattern Candidate, retaining provenance and Unknown. It cannot directly create
Action, Goal, Decision, Identity, or Model Training.

The event is not a durable pattern until Memory Admission. Behavior Pattern
Candidate remains a candidate.
