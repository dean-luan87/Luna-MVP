# Memory Architecture Go / No-Go v1

## Required readiness checks

- Memory is defined as organized Experience reference, not a database.
- Core chain is Experience Candidate → Memory Admission → Memory Storage →
  Memory Retrieval → Current Field Context → Attention / Situation Support.
- Classes include Working Memory, Episodic Memory, Field Memory, Semantic
  Memory, Self Memory, and Relationship Memory Placeholder.
- Memory is bound to Field, Time, Self, Goal, Task, and Context.
- Retrieval is driven by Current Field + Goal + Task + Attention.
- Reality > Memory and Current Reality > Recent Valid Memory > Old Memory are
  explicit.
- Admission, provenance, confidence, Unknown, conflict, decay, compression,
  archive, and release boundaries are present.
- Experience and Adaptation interfaces remain candidate-only.

## Explicit prohibitions

No automatic learning, No Model Training, No model-weight modification, No
Emotion Runtime, No Role System, No Social Runtime, No B Route, No Prediction,
and No Action Runtime. No database implementation and No Memory Runtime are
included. Memory cannot directly modify Reality, Goal, Decision, Identity, or
Action.
