# Memory Architecture Whitebox v1

```text
Experience Candidate
  ↓
Memory Admission
  ↓
Memory Storage
  ↓
Memory Retrieval
  ↓
Current Field Context
  ↓
Attention / Situation Support
```

## Control questions

- Who admits Memory? Memory Admission after Experience Evaluation; not a Model
  and not a Provider.
- Who queries Memory? Current Field, Goal, Task, and Attention produce a scoped
  Memory Query.
- Who resolves Reality conflict? Current Reality through the Reality Reducer;
  Memory has no Reality Write authority.
- Who owns final Goal and Decision? Brain.
- Who controls retention and decay? Governed Memory policies with provenance,
  scope, confidence, importance, and time.
- Who may revoke or archive? Governance/retention candidates, not Memory itself
  as a cognitive subject.

## Isolation invariants

Memory → Attention Support, Memory → Situation Support, and Memory → Pattern
Candidate are permitted. Memory → Reality, Memory → Goal, Memory → Decision,
Memory → Action, Memory → Identity Mutation, and Memory → Model Weight Mutation
are forbidden.
