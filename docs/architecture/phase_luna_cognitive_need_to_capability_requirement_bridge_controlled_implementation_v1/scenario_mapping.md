# Scenario Mapping

The controlled fixture contains 40 cases `CNB-01` through `CNB-40` covering
text, precise OCR, object detection, spatial mapping, decomposition of Field
Rule/action goals, scope rejection, unavailable/degraded replanning, Gap
preservation, Brain model/provider/scope/lifecycle boundaries, authority
guards, no fallback hallucination, no acquisition/Learning/Memory, and no
runtime/provider/model execution. `CNB-31` through `CNB-40` cover provisional
plans, current-minimum materialization, state-version reconsideration,
`STOP_SUFFICIENT`, non-binding remaining candidates, and the
`NOT_REQUIRED_AFTER_SUFFICIENCY` experience boundary.
