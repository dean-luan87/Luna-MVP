# Minimum Sufficient Capability Requirement

The bridge requests only the smallest bounded contribution that advances the
cognitive process: information, evidence, or a named operation inside a
Module contract.

For an effective Field Rule goal, the bridge forms `READ_TEXT -> text_candidate`
when sign text is the missing evidence. It does not ask OCR to determine the
effective rule or mandatory action.

`Cognitive Goal != Cognitive Need != Capability Requirement != Capability Scope != Capability Output`.
