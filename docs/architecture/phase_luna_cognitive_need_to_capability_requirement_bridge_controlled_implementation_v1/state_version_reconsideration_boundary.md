# State Version and Reconsideration Boundary

Every bridge Need and formed Requirement carries the cognitive state version
that formed it. Existing `Cognitive Flow ReconsiderationCandidateV1`, B4
Outcome/Reobserve candidates, and Decision `DEFER`/`REQUEST_MORE_EVIDENCE`
remain the canonical downstream references.

After an important state/evidence update, a prior Requirement may be
`STILL_RELEVANT`, `SATISFIED`, `OBSOLETE`, `SUPERSEDED`, or
`REPLANNING_REQUIRED`.

This is a candidate disposition, not a runtime state machine.
