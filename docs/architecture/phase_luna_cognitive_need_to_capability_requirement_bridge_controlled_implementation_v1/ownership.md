# Ownership

- Cognitive Need formation: cognitive/Brain governance boundary, represented by
  an integration candidate.
- Requirement formation and Capability scope: Capability Registry / Capability
  Governance.
- Scope and Resolution: existing Universal Slot resolution functions.
- Observation execution: FPO / Active Observation Control and Observation
  Gateway remain authoritative.
- Intent, Decision, Task, Learning, and Memory owners are unchanged.

The bridge has no lifecycle or execution mutation authority.
