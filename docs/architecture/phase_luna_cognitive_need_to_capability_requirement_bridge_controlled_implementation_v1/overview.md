# Cognitive Need to Capability Requirement Bridge v1

This bounded integration maps cognitive information needs to the existing
`CapabilityRequirementV1` contract:

`Cognitive State / Intent / Context / Field / Hypothesis -> Need -> minimum Requirement -> existing Scope -> existing Resolution`

The dynamic boundary is:

`Goal -> provisional Plan -> current minimum Need -> Requirement -> Evidence/Outcome -> updated State -> Reconsideration`.

Plan completeness is not execution completeness. New evidence may stop,
supersede, or replan remaining candidates.

It does not create a Brain owner, Resolver, Router, Registry, or capability
system. All bridge artifacts are candidate-only.
