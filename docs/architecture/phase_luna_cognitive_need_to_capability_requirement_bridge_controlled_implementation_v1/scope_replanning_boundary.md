# Scope Rejection and Replanning

Scope failures, unsupported problem/operation/contracts, authority rejection,
unavailability, and degradation may produce a
`CognitiveNeedReplanningCandidateV1`. It can point to refined/decomposed Needs,
alternative Requirements, information insufficiency, or an existing Gap.

Replanning is not retry, stronger prompting, hallucinated fallback, authority
escalation, Provider selection, or automatic acquisition.
