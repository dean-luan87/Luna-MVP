# Progressive Cognitive Exploration Methodology

## Frozen sequence

1. few, high-explanation, human-understandable cases;
2. deliberate missing/conflicting/incorrect evidence;
3. additional observation cycles;
4. increased scene/task complexity;
5. external capability implementation switch;
6. environment and distribution changes;
7. fixed Cognitive Test Suite;
8. large-scale Dataset expansion.

## Gate logic

First establish that A-Route knows what it needs, uses evidence correctly,
recognizes uncertainty, re-observes for a reason, and stops. Only then use
external capability comparisons to find useful implementations. A million
images with only model metrics is not an acceptable first gate.

## Preservation

Every stage preserves sample/task/capability/version/trace lineage and writes
durable protected evidence through TestBoard when an actual test is later
executed.
