# Minimum A-Route Cognitive Test Corpus Plan

The first corpus is small and explanatory. It tests Luna process behavior,
not model ranking.

1. **obvious target** — one observation should be sufficient;
2. **multiple candidate** — disambiguation is required;
3. **missing information** — first observation is insufficient;
4. **conflicting evidence** — claims disagree;
5. **false external evidence** — provider detection is wrong;
6. **no target exists** — absence must be represented without forced success;
7. **occluded target** — targeted observation is needed;
8. **wrong attention** — initial focus is unhelpful;
9. **capability mismatch** — first capability does not answer the need;
10. **re-observation required** — second observation is structurally necessary;
11. **hypothesis correction** — later evidence supersedes an earlier candidate;
12. **premature sufficiency trap** — plausible evidence is intentionally incomplete;
13. **stop-condition test** — sufficient cognition must stop;
14. **environment change** — world changes between cycles;
15. **stale evidence** — old evidence must be invalidated or rejected.

Each case should declare expected process classes and failure ownership, not a
prewritten semantic answer.
