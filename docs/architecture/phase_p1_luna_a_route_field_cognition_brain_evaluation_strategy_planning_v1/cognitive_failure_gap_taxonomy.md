# Cognitive Failure and Gap Taxonomy

## Primary Luna categories

- `GOAL_GAP`, `CONTEXT_GAP`, `ROLE_GAP`, `FIELD_REPRESENTATION_GAP`
- `ATTENTION_GAP`, `INFORMATION_NEED_GAP`, `OBSERVATION_PLANNING_GAP`
- `CAPABILITY_REQUIREMENT_GAP`, `CAPABILITY_SELECTION_GAP`
- `EXTERNAL_EVIDENCE_GAP`, `EVIDENCE_RELEVANCE_GAP`,
  `EVIDENCE_CONFLICT_HANDLING_GAP`, `EVIDENCE_UNCERTAINTY_HANDLING_GAP`,
  `EVIDENCE_MISSING_HANDLING_GAP`
- `CURRENT_WORLD_FORMATION_GAP`, `FIELD_COGNITION_GAP`
- `HYPOTHESIS_FORMATION_GAP`, `HYPOTHESIS_REVISION_GAP`
- `PREMATURE_SUFFICIENCY`, `DELAYED_SUFFICIENCY`, `FALSE_INSUFFICIENCY`
- `INFORMATION_GAP_FORMATION_ERROR`, `REOBSERVATION_TARGET_ERROR`,
  `REOBSERVATION_LOOP_ERROR`
- `STOP_CONDITION_ERROR`, `DECISION_HANDOFF_ERROR`
- `OWNER_BOUNDARY_ERROR`, `TRACEABILITY_GAP`

## External source categories

- `EXTERNAL_CAPABILITY_FAILURE`
- `PROVIDER_FAILURE`
- `NORMALIZATION_FAILURE`

Model failure is a source of External Capability Failure, not the organizing
center of the Luna taxonomy.

## Attribution

Every gap records detector, responsible owner, semantic consequence owner,
affected node/case, severity, evidence/trace refs, source versions, and
resolution status. This prevents an external model defect from being confused
with an Attention, planning, or Hypothesis defect.
