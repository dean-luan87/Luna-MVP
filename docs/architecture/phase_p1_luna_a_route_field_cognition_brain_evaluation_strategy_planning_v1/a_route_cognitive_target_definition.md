# A-Route Cognitive Target Definition

## Core question

Given a task and a real or simulated world, can Luna:

`Goal/Concern → Context/Role/Field → Attention → Information Need →
Observation Demand/Request → Capability Requirement → external Evidence →
Evidence assessment → Current World Candidate → Hypothesis → Sufficiency →
Information Gap → Re-observation or stop → Decision Governance handoff`

while preserving ownership and provenance?

## Observable competencies

- understand Goal/Concern and context;
- identify what is currently unknown and why it matters;
- select a governed capability requirement;
- distinguish relevant, irrelevant, conflicting, uncertain, stale, and missing
  evidence;
- form/revise candidate Current World and Hypothesis;
- avoid premature Sufficiency;
- create a targeted next observation when needed;
- stop at minimum sufficient cognition;
- hand off to Decision Governance without creating a Decision itself.

## Success is not model accuracy

Task completion is evaluated together with process correctness. A successful
external detection cannot compensate for an incorrect cognitive route.
