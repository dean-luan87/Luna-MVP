# A-Route Evaluation Constitution

> Alignment note (Phase-P1-Luna-Field-Cognition-Evaluation-Dual-Test-Plane-Alignment-And-Dataset-Ingress-v1-001): this document remains historical evidence and is now the Plane A constitution within the formally named Luna Field Cognition Evaluation System. Plane B external capability fitness is subordinate supporting evidence, not the primary evaluation subject.

## Primary subject

The primary subject is the **Luna A-Route Field Cognition Brain**. External
perception models and providers are capability implementations used to expose
evidence to that subject.

## Evaluation hierarchy

1. **L0 — Field Cognition Goal Completion**
2. **L1 — Luna Cognitive Process Correctness**
3. **L2 — Observation / Evidence Quality**
4. **L3 — External Capability Fitness**
5. **L4 — External Model / Provider / Version Metadata Comparison**

L4 can explain a Luna result but can never promote itself into L0 or L1.
Model PASS does not imply Luna PASS. Incorrect Attention, observation
planning, evidence use, hypothesis revision, sufficiency, stopping, or owner
boundary is a Luna failure even when a model prediction is technically right.

## Non-goals

Luna does not train, fine-tune, distill, optimize, search, or architect
object-detection, OCR, segmentation, depth, SLAM, VLM, speech, embedding, or
other perception models. Those remain external capability engineering.

## Authority rule

Evaluation observes and reports candidate evidence. It does not own Goal,
Concern, Attention, A cognition, Decision, Field, Current World, Runtime
Admission, Model/Provider binding, or World Truth.
