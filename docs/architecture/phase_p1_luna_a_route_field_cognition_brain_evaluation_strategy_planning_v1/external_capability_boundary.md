# External Capability Boundary

## External implementation role

Object detection, OCR, segmentation, depth, visual localization, SLAM,
speech, VLM, embedding, and motion/change detection are External Perception
Capability Providers. RF-DETR, YOLO, and future providers are implementations,
not cognitive owners.

## Luna owns

- what information is needed;
- Attention and observation demand;
- Capability Requirement;
- evidence relevance, conflict, uncertainty, and sufficiency;
- Current World/Hypothesis candidates;
- information gap and re-observation target;
- stop and Decision Governance handoff.

## Provider may do

- execute an admitted capability;
- return provider result metadata and uncertainty;
- preserve frame/ROI/model/provider/workflow provenance;
- report failure or unavailable output.

## Provider may not do

- create Goal, Need, Attention, Hypothesis, Sufficiency, Decision, Task, or Action;
- write Field or Current World authoritative state;
- declare World Truth;
- autonomously re-observe or retry semantically;
- bypass Capability/Model/Provider governance.
