# Cognitive Burden Plan

## Definition

Cognitive Burden is the work imposed on Luna's A-Route by external Evidence
and by Luna's current cognitive strategy before a field cognition goal can be
completed or safely handed off.

## Components

- uncertainty;
- evidence conflict;
- hypothesis creation/revision/supersession;
- information-gap persistence;
- re-observation count and targeting cost;
- cognitive transition count;
- retries or failure amplification;
- stale evidence and invalidation handling;
- correction/review cost.

## Attribution

The profile must separate:

- external capability burden: poor/unstable/missing evidence;
- Luna planning burden: wrong capability or ROI request;
- Luna cognition burden: poor relevance/conflict/sufficiency/hypothesis handling;
- governance burden: blocked or invalid handoff.

Cognitive Burden is a Luna system metric. It is not a model score and not a
runtime policy.
