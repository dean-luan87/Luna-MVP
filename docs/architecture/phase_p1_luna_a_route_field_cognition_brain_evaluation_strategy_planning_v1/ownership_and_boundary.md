# Ownership and Boundary

| Boundary | Canonical owner | Evaluation posture |
|---|---|---|
| Goal / Concern / global consequence | Brain | Reference and assess handoff, never mutate. |
| Need / Attention intent / relevance / Sufficiency / Hypothesis consequence | A | Primary subject of L0/L1 evaluation. |
| Attention allocation | Attention/A boundary | Record candidate selection and competition. |
| Observation request/lifecycle | Observation/FPO | Record demand/request and cycle behavior. |
| Capability resolution/binding | Capability Governance | Reference; no evaluator selection authority. |
| Model identity | Model Governance | Metadata reference only. |
| Provider binding/invocation | Provider Governance | External execution boundary; no cognition. |
| Evidence structural admission | Gateway/Observation | Candidate evidence, not Truth. |
| Current World candidate | Cognitive State Formation | Candidate observation of cognition. |
| Decision commitment | Decision Governance | Evaluation may observe handoff only. |
| Task/Action | Task/Action Governance | Out of scope for first A-route gate. |
| Dataset/sample/GT | Evaluation subsystem | World/observation corpus infrastructure. |
| Evaluation trace/profile | Evaluation subsystem | Own evaluation evidence, not runtime state. |

The rule remains: **WHO HAS AUTHORITY OWNS RESPONSIBILITY.**
