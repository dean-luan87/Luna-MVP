# Phase Contract

Phase: Phase-Luna-Cognitive-Authority-And-Shared-Reasoning-Envelope-Contract-Freeze-v1-001

Mode: READ / CONTRACT FREEZE / SCHEMA DESIGN ONLY

## Purpose

Freeze the minimum authority and reference-only data contracts required before
controlled migration toward Brain → Semantic → Filter → A/B reasoning.

## Scope

- freeze Brain, A, B and shared Loop Engine authority;
- define candidate-only Working Envelope, B request/result envelopes and A/Loop
  mechanical command/return contracts;
- define concern split/merge, Task and Experience boundaries;
- map current implementation leakage to future authority;
- define the smallest later migration cut line.

## Explicitly prohibited

- runtime implementation changes;
- changes to verified Loop engines;
- canonical enum/type changes;
- Semantic Module or Filter runtime;
- Python, Runner, Verifier, pytest or py_compile execution;
- Provider, YOLO, OCR, camera or model inference;
- new Brain, Loop Manager, Planner or Scheduler owners.

## Status

This is a contract freeze and schema design phase. It is not GO or PASS.
