# Negative Boundaries

The following remain forbidden:

- new Brain owner;
- Loop Manager, Loop Planner or Loop Scheduler;
- separate Loop cognitive environment;
- runtime modification in this phase;
- modification of verified Loop engines;
- canonical enum/type changes;
- Semantic Module implementation;
- Filter runtime implementation;
- independent B initial entry;
- autonomous B recursion;
- Loop cognition authority;
- direct Task to Loop cognition control;
- direct Provider to Loop cognition control;
- Experience or Memory mutation;
- Action execution;
- Provider invocation;
- model inference;
- YOLO;
- OCR;
- camera;
- semantic compression;
- autonomous child Concern or Loop spawning;
- autonomous concern split or merge;
- World Truth declaration by A, B, Loop, Capability or Experience;
- Provider/model selection by Brain, A, B or Loop;
- deletion of previously verified implementation;
- mass code deletion.

All new contracts remain candidate-only and reference-only.
