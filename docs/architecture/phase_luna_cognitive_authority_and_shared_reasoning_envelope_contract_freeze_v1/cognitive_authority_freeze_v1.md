# Cognitive Authority Freeze

## Brain

Brain owns:

- Cognitive Concern admission;
- Cognitive Concern identity;
- concern split admission;
- concern merge admission;
- global Goal governance;
- global Safety, Permission and Resource priority;
- result assimilation;
- final global adjudication.

Brain does not duplicate detailed reasoning after a concern has been admitted
to A or B.

## A Route

For one admitted concern, A owns:

- reality-grounded reasoning;
- local Cognitive Gap;
- current Need selection;
- Hypothesis generation and maintenance;
- evidence relevance judgment;
- local sufficiency judgment;
- reconsideration judgment;
- REQUEST_MORE_EVIDENCE semantics;
- Capability and Observation request semantics;
- B Route request;
- continuation semantics;
- pause, wait and resume semantic decisions;
- closure request semantics;
- A/B result consolidation.

A is the Reality Thinking Engine. A requests external Capability, Observation,
Decision, Task and Action governance; it does not become their owner.

## B Route

B owns only:

- bounded contingency reasoning requested by A;
- scenario and assumption exploration within A scope;
- conditional response candidate generation;
- uncertainty boundary analysis;
- contingency result package.

B does not own:

- Cognitive Concern;
- final Need;
- final sufficiency;
- final continuation;
- Loop lifecycle authority;
- result adoption;
- Provider identity.

## Loop Engine

Loop owns only mechanical state:

- persistence;
- state version;
- local execution-state lineage;
- wait/pause/resume storage;
- pending references;
- Requirement references;
- trace/provenance;
- closure mechanics;
- final freeze mechanics.

Loop receives semantic commands from A or Brain governance and does not infer
them.

## Resolved ownership table

| Concept | Semantic owner | Mechanical/reference owner | Final authority |
|---|---|---|---|
| Goal | Brain global governance | Working Envelope/Loop refs | Brain |
| Cognitive Concern | Brain | Loop identity ref | Brain |
| Need | A for admitted concern | Loop records Need ref | A, within Brain scope |
| Hypothesis | A/B reasoning | Hypothesis owner and Loop lineage | A/B local; Brain global adjudication |
| Sufficiency | A local concern reasoning | Loop stores result ref | A local; Brain global adjudication |
| Reconsideration | A/B | Cognitive Flow/Loop transport | A/B local; Brain for global conflict |
| Continuity semantics | A/B compare authoritative inputs | Loop stores assessment/mechanics | A/B/Brain by scope |
| Closure semantics | A requests | Loop performs mechanics | Brain/Cognitive Flow governance |
| Cognitive Outcome | A/B consolidate candidate | Loop records closure ref | Brain assimilation |
| Assimilation | Brain | Loop/package provides refs | Brain |

## One-to-one authority rule

No component may receive responsibility for a semantic result without the
corresponding authority. A component with only mechanical authority may not
reinterpret a semantic candidate.
