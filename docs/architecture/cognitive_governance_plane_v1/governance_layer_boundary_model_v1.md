# Governance Layer Boundary Model v1

## Plane separation

```text
Constitution → Governance Plane → Runtime Plane → Capability Plane → World
```

Governance Plane is policy and lifecycle governance. Runtime Plane performs
authorized lifecycle mechanics. Capability Plane provides Evidence. Cognitive
Layer performs Reality understanding, Situation, Decision, and Experience.

Governance does not become a cognitive subject. It cannot modify Reality, Goal,
Value, Decision, Self Identity, or Action directly. The Reducer remains the
sole State mutation authority.

## Responsibility table

| Component | Owns | Does not own |
|---|---|---|
| Constitution | prohibitions and invariants | registration or execution |
| Protocol Manager | protocol lifecycle | meaning or Decision |
| Registry Plane | identity and inventory | what to do |
| Admission | entry review | Runtime execution |
| Authority Governance | permission candidates | Goal or Value |
| Diagnostics | anomaly candidates | Action or repair |
| Resource Governance | budget candidates | Decision |
| Runtime Governance | Process/Tick mechanics | cognition |

Registry answers “what exists”; Admission answers “may it enter”; Governance
answers “under what authority”; Runtime answers “how mechanics run”. None
answers “what should Luna want”.

Governance is not a second cognitive subject.
