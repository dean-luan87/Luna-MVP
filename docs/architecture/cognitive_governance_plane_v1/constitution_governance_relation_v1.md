# Constitution / Governance Relation v1

The Constitution is the highest constraint and the Governance Plane is its
enforcement and lifecycle interpretation layer.

## Constitution controls

The Constitution freezes:

- Brain final authority for Intent, Goal, Value, Decision, and authorization;
- Evidence → Reality → Field → Attention → Situation flow;
- Reducer as sole State mutation authority;
- Unknown Preservation and Reality > Experience;
- Self Identity Continuity;
- Provider and Capability isolation;
- no direct model-to-cognition or Action-to-Reality path.

## Governance duties

Governance checks every Protocol, Registry entry, Admission, Authority change,
Resource allocation, Runtime lifecycle change, and Change Proposal against the
Constitution. A failed check returns a Governance Blocker or Rejection
Candidate; it does not silently weaken the Constitution.

Constitution does not register objects, schedule Processes, run Providers, or
execute Actions. Governance does not become Brain and cannot modify Goal,
Reality, Decision, Value, or Self Identity.

Any future Model Manager Runtime must remain below this relation.

Constitution does not schedule Processes. Constitution does not run Providers.
Constitution does not execute Actions.
