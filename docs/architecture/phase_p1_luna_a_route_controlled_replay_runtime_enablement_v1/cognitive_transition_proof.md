# Cognitive Transition Proof

The proof is emitted by the canonical Cognitive State Formation call, not by a fixture or Evaluation. `ARouteCognitiveExecutionEvidenceV1` contains:

- `execution_ref`
- `execution_proof_source`
- canonical owner
- replay and ingress refs
- transition refs
- Current World and Hypothesis refs
- explicit unavailable states for unformed downstream nodes

The first fixture produces transitions for ingress→attention, attention→hypothesis, and hypothesis→Current World Candidate.
