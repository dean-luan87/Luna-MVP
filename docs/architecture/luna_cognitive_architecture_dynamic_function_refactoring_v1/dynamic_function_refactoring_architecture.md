# Cognitive Architecture Dynamic Function Refactoring v1

## 定位

本阶段是 Meta Architecture，不推翻或修改既有 A Route 模块。它把既有模块映射为 Dynamic Function Model 中的输入空间、函数、历史影响项、约束和调节器。

## 统一抽象

`Field → Cognitive Function → Understanding`；`Understanding + Goal + Value → Decision Function`；`Outcome Feedback → Parameter Adjustment Candidate`。旧模块仍是 canonical 资产，动态函数层只增加解释、参数和治理映射。

## 兼容原则

Field、Memory 分层、Knowledge Boundary、Self Boundary、Value Utility、Decision Arbitration、Outcome Evaluation 和 Selective Learning 均保留。映射不是运行时替换，不自动迁移，不产生新的 Owner。
