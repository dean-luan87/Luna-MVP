# Cognitive Genome Governance Model

Cognitive Genome 是可审计的认知参数集合，不是生物基因、人格或 Identity。它描述感知、认知、记忆、决策和资源风险倾向，支持不同 Luna 个体使用不同参数组合。

Hive 只能观察 `Field × Cognitive Genome × Outcome` 并产生比较证据和 Optimization Candidate。Luna 自己通过 Self Review、Constitution Review、Capability Governance 决定是否接纳，所有变更必须版本化、可回滚和可追溯。
