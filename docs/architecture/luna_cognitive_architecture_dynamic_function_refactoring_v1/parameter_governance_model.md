# Parameter Governance Model

参数必须具备 ID、版本、范围、单位、Field Scope、来源、证据、风险、验证指标和回滚引用。参数可以影响资源分配、阈值、权重和激活强度，但不能绕过 Constitution、Self Boundary 或 Capability Governance。

候选流程：`Observation → Parameter Adjustment Candidate → Impact Review → Self Review → Accept/Reject/Defer → Versioned Parameter Candidate`。

禁止自动调参、无证据覆盖、跨 Field 无条件迁移、直接修改 Identity/Constitution/Safety Boundary。
