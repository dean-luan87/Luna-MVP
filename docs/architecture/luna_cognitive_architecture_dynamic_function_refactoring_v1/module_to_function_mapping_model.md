# Module to Function Mapping Model

| 既有模块 | Meta Function 定位 |
|---|---|
| Field | Input State Space、Field Influence Weight、Field Transition Signal |
| Attention | Resource Allocation Function |
| Memory | Historical Influence Function、Activation Function |
| Self Rhythm | Self Regulation Function 子函数 |
| Uncertainty Exploration | Exploration Drive Function |
| Belief / Understanding | Confidence Dynamics、Prediction Error Update |
| Goal | Goal Activation Function |
| Value Utility | Utility Function |
| Decision Arbitration | Decision/Selection Function |
| Selective Learning | Parameter Evolution Function |

每个映射保留原 Owner、生命周期和边界；函数输出默认是 Candidate，不直接执行或修改状态。
