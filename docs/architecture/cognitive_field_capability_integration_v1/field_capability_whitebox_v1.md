# Field Capability Integration Whitebox v1

```text
Brain / A Route
      ↓
Cognitive Field
      ↓
Observation Requirement
      ↓
Capability Registry
      ↓
Capability Admission
      ↓
Model Manager / Provider Candidate
      ↓
Provider Execution Boundary
      ↓
Evidence Gateway
      ↓
Evidence Candidate
      ↓
Reality Workspace
      ↓
Field Update Candidate
      ↓
A Route / Brain
```

Failure path:

```text
Provider unavailable / low quality / protocol error
      ↓
Capability Failure
      ↓
Diagnostics
      ↓
Self Capability Candidate
      ↓
Brain awareness
```

The whitebox keeps Capability, Model Manager, Provider, and Human Feedback
below the Evidence Gateway. Evidence is not Reality until the existing
Reality Workspace governance and Reducer rules admit it. No model or Provider
has Field, Reality, Goal, Decision, or Action authority.

This is a contract-only architecture. It contains no real model execution,
real OCR, real SLAM, Hardware Runtime, Action Runtime, or B Simulation Runtime.
