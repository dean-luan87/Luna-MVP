# Vision Capture Governance v1 GO/NO_GO Pack v0

## GO

- Capture quality / frame / region / crop / text-region readiness 定义
- dynamic vs static capture、hardware placeholder、UG / system self-adjustment
- expired capture + long-term context routing
- 不摄像头 / 不新帧 / 不 OCR / 不写事实

## CONDITIONAL_GO

- 阈值与硬件能力为 placeholder；current case 仅 dry-run

## NO_GO

- 调用摄像头、采新帧、运行 OCR、TTS、硬件、写 WM/SceneDelta、routing 变更、benchmark claim
