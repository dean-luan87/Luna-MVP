# OCR Activation Governance Policy v1 GO/NO_GO Pack v0

## GO

- Gate 决策表（含 EXPIRED_OBSERVATION_TO_WORLD_HINT）
- dual trigger、default-off WM
- **Expired Information Value Principle**（四维：action / world / profile / emotional）
- stale 长期路由五类候选 + 必填 metadata
- 不 OCR / 不 TTS / 不写事实

## CONDITIONAL_GO

- 过期策略仅候选；current case dry-run only

## NO_GO

- 运行 OCR、写 WM、routing 变更、benchmark claim
