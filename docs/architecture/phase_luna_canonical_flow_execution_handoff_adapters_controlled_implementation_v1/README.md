# Canonical Flow Execution Handoff Adapters v1

This package closes five candidate-only handoff seams in the frozen Luna
flow:

`A→Attention`, `Runtime Admission→Observation`, `Decision→Action`,
`Task→Action`, and `Action Result→Task/A`.

All inputs are synthetic and candidate-only. No Observation, Action, Provider,
Runtime Admission, model, source mutation or semantic/global consequence is
executed.
