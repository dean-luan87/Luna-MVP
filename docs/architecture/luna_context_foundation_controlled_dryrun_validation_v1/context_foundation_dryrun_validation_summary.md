## Validation position

This phase describes Context Foundation as part of a Constraint-driven dynamic cognitive system. Context does not simply receive inputs and emit outputs. It forms a candidate envelope while being bounded by current Field, source evidence, source Owner authority, Resource Budget References, temporal validity, Unknown, and trace requirements. Its candidate output may later constrain downstream cognition without taking downstream ownership.

No existing Context Skeleton code is changed or executed by the Agent in this phase.

## Context Assembly

The admitted validation flow is:

```text
Synthetic Projection References
        ↓ constrained assembly
Context Envelope Candidate
        ↓
Context Trace Candidate
```

The envelope remains reference-only, candidate-only, provenance-bearing, and source-Owner preserving. It contains no Fact, Intent, Causal Explanation, Decision, Action, or mutation command.

## Expansion boundary

Context expansion must cite Existing Evidence, Historical Experience Reference, Memory Projection, or System Rules Reference. Unsupported information creation is forbidden.

`inference_allowed=true` is restricted to an admitted Candidate Completion reference. Context itself owns no reasoning, causal inference, Intent generation, Decision generation, or Fact promotion.

## Resource constraint

Context expansion is governed by a Context Expansion Budget Reference supplied by Hardware, Runtime, and Cognitive resource owners. There is no static numeric expansion limit in this candidate.

When resources are insufficient, the result is a `Degraded Context Scope Candidate`: reduce eligible expansion range while preserving current Reality, required references, Unknown, provenance, and trace. Resource insufficiency is not treated as Context failure.

## Unknown handling

Unknown may remain unresolved or receive one or more `Unknown Completion Candidate` references from Historical Experience, Personal Memory Pattern, or System Rule sources. Confidence, provenance, candidate status, and contradiction preservation are mandatory.

Unknown cannot be promoted directly to Fact and cannot generate Intent, Causal Conclusion, or Decision.

## Carryover handling

Work-to-home continuity is represented as a Mental Field Continuity Reference. Context carries previous/current Field references, source-owned Emotion reference, duration, release condition, Unknown, and provenance. It does not calculate pressure, infer dislike of work, mutate Emotion, or persist Memory.
