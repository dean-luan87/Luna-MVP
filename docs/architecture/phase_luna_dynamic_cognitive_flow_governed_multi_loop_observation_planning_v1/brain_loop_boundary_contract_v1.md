# Brain ↔ Cognitive Loop boundary contract

## Subject and subordinate process

Brain is the cognitive subject. Cognitive Flow is an existing Brain-governed
process owner. A Cognitive Loop is a subordinate, persistent local process
state used only when a concern needs continuity or repeated governance.

There is no Loop Brain, Loop Manager, Loop Planner, or second cognitive
governance layer.

## Materialization rule

Brain / existing Brain Governance may materialize a Loop only when the local
concern requires one or more of:

- an unresolved information gap;
- multi-step reasoning;
- hypothesis maintenance;
- re-observation or reconsideration;
- waiting or pause/resume;
- governed capability use or acquisition candidate;
- cross-time continuity.

Immediate cognition may remain directly inside Brain / Cognitive Flow. A
candidate plan, thought, Need, or single evidence check is not automatically a
Loop.

Once a concern is materialized as a Loop, Brain must not independently solve
that same local concern in parallel. Brain continues to govern goal formation,
priority, safety, resources, materialization, and outcome assimilation. The
Loop carries only local candidate state and references.

## Ownership boundary

| Brain / canonical owner | Loop-local envelope |
|---|---|
| Self, Intent, Role, Field, Emotion, Safety, Resource, Memory, Experience, Action, World Truth, Provider identity | local disposition, current Need, hypothesis lineage, pending candidates, state-version lineage, pause/wait reason, last disposition |
| Attention, Task / Behavior, Current World, Capability Scope / Resolution, Observation Gateway | read-only refs, source versions, admission candidates, trace and provenance refs |

The Loop cannot mutate any left-column owner and cannot promote a right-column
candidate into authority.

## Completion boundary

Loop completion emits a Cognitive Outcome Candidate containing its local goal,
state version, evidence, disposition, and trace/provenance. Brain assimilates
that candidate. Completion does not automatically create World Truth, Decision,
Action, Memory, Experience, or Intent mutation.
