# Cognitive Learning Whitebox v1

```text
Reality / Field / Self / Attention / Memory / Outcome
                         ↓
                 Experience Record
                         ↓
              Pattern Extraction Candidate
                         ↓
                 Strategy Candidate
                         ↓
                  Validation / Review
                         ↓
              Adaptive Update Candidate
```

## Control questions

- Who records experience? Experience and Memory contracts with provenance.
- Who extracts a pattern? Learning System, only as a Pattern Candidate.
- Who proposes a strategy? Strategy Candidate contract.
- Who validates adaptation? Learning Governance plus the owning subsystem.
- Who owns Goal and final Decision? Brain.
- Who owns Reality mutation? Reality Reducer after Evidence Gateway.
- Who owns Model parameters? Model Manager; Learning has no training authority.
- Who can revoke an incorrect pattern? Governance through the revocation contract.
- Who handles Prediction Error? Learning Signal only; it is not Prediction Runtime.

## Isolation invariants

Experience → Pattern Candidate, Pattern → Strategy Candidate, and Outcome → Learning Signal are allowed. Learning → Reality Write, Learning → Identity Mutation,
Learning → Goal Mutation, Learning → Decision, Learning → Action,
Learning → Model Training, and Learning → automatic strategy activation are
forbidden.

Current Reality outranks Experience. Unknown, Conflict, Evidence, Confidence,
and Provenance remain attached. Survival Learning is in scope; Skill Learning is
a placeholder only.
