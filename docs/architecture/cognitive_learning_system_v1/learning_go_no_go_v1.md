# Cognitive Learning Go / No-Go v1

## Required readiness checks

- Experience → Pattern → Strategy → Feedback → Adaptive Update Candidate is explicit.
- Experience → Pattern → Strategy → Feedback → Adaptation Candidate is explicit.
- Survival Learning covers Field, Attention, Navigation, Safety, and Interaction Patterns.
- Skill Learning is placeholder-only.
- Prediction Error is defined as Expectation–Reality Difference and not Prediction Runtime.
- Field Learning preserves Field, Role, Task, and context binding.
- Attention, Memory, and Capability interfaces produce candidates only.
- Learning Governance enforces Reality priority, Unknown preservation, validation, and revocability.
- Learning lifecycle supports Observed, Recorded, Evaluated, Pattern Candidate, Strategy Candidate, Validated, Adaptation Candidate, Accepted, Rejected, Revoked, and Archived.

## Explicit prohibitions

No automatic model training, No parameter modification, No Online Learning Runtime,
No automatic strategy switching, No Emotion Runtime, No B Route, and No Action Runtime.
Learning cannot modify Reality, Identity, Goal, Decision, or
Action.

The Agent performs V0 static checks only, does not run the Final Phase Verifier,
and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.
