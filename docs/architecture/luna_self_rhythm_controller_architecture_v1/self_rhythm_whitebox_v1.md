# Self Rhythm Controller Whitebox

The controller is a candidate generator at the Self Regulation boundary. A mode transition is meaningful only when its source observations, reason, budget, affected activity, and constraint checks are present.

The controller does not own Runtime scheduling. Runtime owns acceptance and application of any future rhythm hint. Capability Governance owns capability admission and Model Manager owns model assets. Emotion remains in Integration Layer; low mood and low power are intentionally unrelated states.

This directory contains contracts and a verifier only. There is no runtime loop, scheduler hook, hardware call, model call, provider call, or automatic learning path.
