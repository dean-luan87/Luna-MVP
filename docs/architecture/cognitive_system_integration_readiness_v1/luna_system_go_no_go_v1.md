# Luna System Integration Readiness Go / No-Go v1

## Required readiness checks

- Global Cognitive Loop includes External World, Reality Update, Field Update,
  Attention Allocation, Situation Update, Goal / Task Check, Decision
  Candidate, Action Boundary, Outcome, Experience, and Future Adaptation.
- Cognitive Process lifecycle includes Created, Activated, Running, Background,
  Suspended, Completed, and Archived.
- Attention Global Bus covers Reality Observation, Field Update, Task, Brain
  Escalation, and Capability Usage.
- Capability execution is Need → Capability → Model / Hardware → Evidence.
- Governance interception includes Protocol, Authority, Admission, Resource,
  Runtime, and Diagnostics.
- Long-term stability includes 24 hours, 7 days, and 30 days.
- Failure recovery includes Model Unavailable, Hardware Degraded, Network
  Disconnected, and Information Conflict.
- Reality Reducer remains the sole Reality mutation authority; Brain retains
  Goal and final Decision authority.

## Explicit prohibitions

No real models, Camera, OCR, SLAM, Hardware Runtime, Action Runtime, Emotion
Runtime, Social Runtime, or B Runtime. No Scheduler implementation, automatic
execution, automatic model switching, automatic learning, Provider-to-Decision,
Model-to-Goal, Model-to-Action, or direct Reality mutation.

The Agent performs V0 static checks only, does not run the Final Phase Verifier,
and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.

The Decision Candidate and Brain Escalation are candidates only. Network
Disconnected remains a failure case. Brain retains Goal and final Decision
authority. No Camera, No OCR, No SLAM, No Hardware Runtime, No Action Runtime,
No Emotion Runtime, No Social Runtime, No B Runtime, and No automatic execution
are included.

Network Disconnected. Brain retains Goal and final Decision authority.
