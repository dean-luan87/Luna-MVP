# Negative Guards

The runner/verifier preserves checks for action-before-valid-task,
Task/Decision/Brain/Cognitive-State-Formation Action execution, runtime
dispatch, device control, model/provider invocation, live observation, Field
mutation, Memory/Experience/Learning mutation, and World Truth declaration.

Action Governance's existing candidate-only and no-device-control validators
remain authoritative. The negative fixture verifies rejection without Action
Boundary invocation.
