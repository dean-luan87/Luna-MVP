# Phase Contract

Prove:

`admitted planned Task → Task-to-Action handoff → existing Action Governance
candidate/readiness`

for exactly two positive cases, plus one rejected no-valid-Task handoff.

The phase must stop before Runtime Executor, device control, Action execution,
and all external side effects.

Acceptance uses the shared [Luna Cognitive Logic Conformance Test
Contract](../luna_cognitive_logic_conformance_test_contract_v1.md):
`operational_result=PASS` and `cognitive_logic_result=PASS` are both required
for `final_decision=GO`. These are independent results; this phase does not
turn a boundary candidate into evidence of cognition conformance.
