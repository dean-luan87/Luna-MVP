# Context Foundation Owner Closure Review v1

Status: `CLOSURE_CANDIDATE`

## Unique Owner

The canonical and unique Owner is `Context_Foundation`. This closure does not create a second Writer and does not transfer any source-object ownership.

## Owned responsibility

Context Foundation owns only:

- Context Envelope Assembly;
- Projection Reference Management;
- Context Trace Candidate management;
- preservation of Unknown, provenance, temporal validity, confidence, and source-Owner authority inside a candidate envelope.

Its write scope is limited to `Context Envelope Candidate` and `Context Trace Candidate` metadata.

## Explicitly not owned

Context Foundation does not own:

- Reality or Field State;
- Memory or Experience;
- Emotion State or emotion calculation;
- Self, Role, or Relationship source state;
- Intent;
- Causal Reasoning or Causal Result;
- Fact promotion;
- Decision;
- Action;
- Runtime or resource control.

Field, Memory, Emotion, Self, Role, Relationship, PCN, Intent, Causal, Decision, Action, and Runtime retain their separate Owners. A reference entering Context never changes its Owner.

## Closure result

The Owner boundary is stable and singular. Context remains cognitive infrastructure: it collects, organizes, constrains, and exposes the current cognitive environment without interpreting, judging, deciding, or acting.
