# Governance Boundary

Allowed:

- two bounded real YOLO11n calls on local image inputs;
- candidate cross-frame association;
- normalized geometry and temporal relation metric candidates;
- existing fail-closed stability condition consumption.

Prohibited:

- tracking lifecycle or permanent object identity;
- World Truth, Field mutation, semantic target resolution or identity fact;
- OCR, SLAM, IMU, camera control, movement or device control;
- Decision, Task, Action or Runtime Executor execution;
- invented stability thresholds or cycle/case-driven stability;
- use of recorded provider output as live output.
