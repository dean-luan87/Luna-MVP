# Brain Capability Regulation boundary

Brain may generate governed capability lifecycle candidates based on survival
pressure, energy/compute/memory/storage/thermal state, task requirements,
usage and contribution history, recovery cost, compatibility, and newly
available Official Modules.

Candidate vocabulary:

`ACQUIRE`, `DOWNLOAD`, `INSTALL`, `BIND`, `ACTIVATE`, `SUSPEND`, `RESUME`,
`RELEASE`, `UNLOAD`, `UNINSTALL_IMPLEMENTATION`, `RESTORE`, `REBIND`,
`REPLACE`, `UPGRADE`, `DEGRADE`, `ROLLBACK`.

These are requests/candidates, not execution. Brain cannot bypass Capability
Governance, admission, integrity/signature, permission, compatibility,
resources, Safety Constitution, Model Manager, Provider Governance, or
rollback/degradation governance.
