# Capability, implementation, model, provider, and knowledge boundary

`Capability Slot` hosts a `Capability Module`.

The Module is realized by a `Capability Implementation`, which may depend on
Model, Provider, Runtime, and resource assets. Model Manager governs model
resources and compatibility; Provider Governance governs adapters; Runtime
executes only admitted requests.

Capability is not Knowledge. A Module may declare knowledge dependency or
interface references, but this phase does not design Professional Knowledge,
Knowledge Packs, retrieval, learning, Semantic Folding, Semantic Expansion,
or SRSK internals.
