# Capability history and recovery boundary

Slot binding history, last-known Module identity, implementation removal
reason, usage/contribution references, recoverability, and estimated recovery
cost are metadata/reference candidates. They do not directly mutate Memory or
Self state in this phase.

When Enhanced OCR is removed after prolonged non-use, Capability Self may
retain: previous possession, solved problem classes, usage contexts, removal
reason, restoration possibility, and recovery cost. “Previously possessed” is
not “currently usable”. Existing Memory/Experience Governance remains the
owner of persistence and consolidation.
