# Capability Self model boundary

Capability Registry answers: “What capability assets and definitions exist?”

Capability Self, under the existing Cognitive Self Model / Capability
Awareness owner, answers: “What does Luna understand about its own ability
state?” It is not a duplicate registry and does not become a lifecycle writer.

## Current

Represent current possessed, usable, active, degraded, unavailable, and
resource-limited capabilities with evidence, conditions, confidence and
provenance.

## Historical

Represent previous Module bindings, usage/contribution references, removal or
suspension reasons, and recovery possibility/cost references.

## Potential

Represent official Modules that could solve problem classes, compatibility and
resource support, and whether consideration is appropriate. Potential is not
current availability and not an activation decision.

Capability loss does not automatically equal Self loss. Existing Self state
mutation authority and Memory ownership remain unchanged.
