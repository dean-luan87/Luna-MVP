# Safety Capability constitution mapping

Basic Environment / Safety Perception is an Official Capability Module with
`requirement_class = MANDATORY_SAFETY`. It is bound through the same generic
Universal Slot system as every other Module. There is no Safety Vision Slot
type.

Survival/Safety Constitution protects the minimum baseline. Brain, user, and
ordinary lifecycle governance may propose approved implementation selection,
replacement, degradation, rollback, restoration, and resource allocation,
but may not remove the minimum survival capability.

Safety evidence remains evidence. It does not become World Truth or direct
Field/Action authority.
