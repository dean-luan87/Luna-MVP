# Traceability

For every case, the bridge retains:

`Goal / Information Need / Capability Requirement`
→ `Minimum Condition Requirement`
→ `Situated State / Condition Candidates`
→ `Feasibility / Opportunity / Eligibility`
→ `Execution Admission`.

For admitted cases, the existing runtime adds:

`Provider Request → Provider Result → Runtime Observation → Gateway Admission`
→ `Evidence → A-Route → Cognitive State`.

Admission and precondition references are retained beside the runtime result;
the existing Provider Request/Result trace and provenance are not rewritten.
All outputs remain candidate-only and no recorded OCR result is used.
