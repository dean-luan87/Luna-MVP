# Governance Boundary

This phase owns only the composition between existing Situated Eligibility and
existing Provider Runtime invocation.

It does not own or execute:

- Field mutation or World Truth promotion;
- Decision, Task, Action, Runtime Executor, or device control;
- Camera, movement, IMU, SLAM, YOLO, or additional providers;
- OCR result interpretation, relevance, coverage, sufficiency, or Stop
  semantics.

Real OCR output remains Observation/Evidence Candidate.  An OCR success is not
by itself cognitive sufficiency.  The existing relevance-to-coverage guard is
only checked after the real evidence path and is not reimplemented here.
