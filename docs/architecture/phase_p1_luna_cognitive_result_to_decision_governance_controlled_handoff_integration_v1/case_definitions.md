# Case Definitions

## Case A — first-cycle sufficient

The existing controlled case reaches `SUFFICIENT` and canonical Stop in one
cycle. One handoff is admitted and Decision Governance produces a candidate.

## Case B — gap and revision

Cycle 1 is `INSUFFICIENT` and produces the existing Gap/Re-observation chain.
The handoff gate rejects that cycle. Cycle 2 reaches `SUFFICIENT` and Stop;
only then is one handoff admitted and consumed by Decision Governance.
