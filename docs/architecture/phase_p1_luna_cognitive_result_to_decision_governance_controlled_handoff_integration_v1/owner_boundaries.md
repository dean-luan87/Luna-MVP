# Owner Boundaries

| Boundary | Owner |
|---|---|
| Cognition, Sufficiency, Gap, Revision, Stop | Cognitive State Formation Governance |
| Cognitive Flow lifecycle mechanics | Cognitive Flow Governance |
| Re-observation | Field Perception Orchestrator |
| Cognitive-result handoff production | Existing cognition result, exposed through the adapter |
| Decision Candidate formation and Decision trace | Decision Governance |
| Brain semantic ownership | Remains outside this phase; no Brain runtime owner is created |
| Task and Action execution | Not executed; downstream boundaries remain independent |

The adapter transports references; it does not form cognition or Decision
semantics.
