# Controlled fixtures

Evaluation package 包含 28 个 cases：11 个 responsibility audit cases 与 17 个 binding/runtime preparation cases。

覆盖：完整/不完整 Requirement、Provider 不重解释 Demand、不创建 Capability Requirement、FPO/Gateway 不越权、Requester/Provider/Resource/Runtime failure ownership、single/multiple Provider targets、same Provider 多 Demand、same class distinct Provider、zero、invalid、lineage mismatch、optional/no Model、无 Execution Instance、无 Runtime Allocation、无 Gateway submission、Scenario 12 signage/flow/both、deterministic replay、malformed input。

Scenario 12 的 Provider refs 是 controlled opaque refs，不表示 OCR、VLM、detector、SLAM、Camera 或具体 Model。
