# Negative guards

The formation and evaluation boundary forbid:

- Gateway submission, FPO runtime request, routing admission, route selection,
  ranking, scoring, priority, or winner selection;
- capability matching rerun, activation, reservation, scheduling, or execution;
- Provider/Model selection, binding, invocation, OCR, Camera, VLM, or SLAM
  inference;
- Attention formation, resource acquisition, runtime observation, async work,
  evidence ingress/fusion, or conflict resolution;
- mutation of Requirement, Need, Gap, Branch, Strategy, Coordination, Demand,
  capability resolution, slot, Current World, Field, Memory/PCN, Intent, or
  Goal;
- Truth/World Truth declaration, Decision, Task, Action, or fallback route
  fabrication;
- semantic string inference, cross-demand merge, or cross-gap lineage collapse.

Every route must be backed by exactly one valid active resolution candidate and
one explicit Observation Demand. A route's capability class must equal the
source resolution candidate's class, and all source lineage remains present.
