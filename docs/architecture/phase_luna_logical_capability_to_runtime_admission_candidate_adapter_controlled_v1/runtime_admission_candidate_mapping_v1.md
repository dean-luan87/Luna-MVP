# Runtime Admission Candidate Mapping

The candidate input maps the frozen fields to refs/evidence:

- logical resolution and slot refs;
- model asset, model version, governed path refs;
- declared checksum and observed integrity evidence refs;
- dependency and runtime-health evidence refs/status candidates;
- Provider compatibility refs;
- permission, resource, safety refs;
- source/acquisition context and source state version;
- trace, provenance, staleness and validity refs.

Assessment uses only these supplied values. It does not verify them.
