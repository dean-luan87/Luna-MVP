# Cognitive Field Dynamics Model v1

## Purpose

Cognitive Field Dynamics defines how a single Cognitive Field exists as a
continuously maintained information environment. It does not define what the
field thinks or chooses.

```text
Field Creation Source
        ↓
Field Candidate
        ↓
Field Lifecycle / State
        ↓
Attention Requirement
        ↓
Observation
        ↓
Field Update
        ↓
Experience Candidate (outbound only)
```

## Creation sources

Field Creation Source may be Brain Intent, Neural Detection, External Event, or
User request. A source proposes a bounded scope, purpose reference, validity,
resource candidate, and owner. Creation does not create a Goal, Decision, Action,
or Personality.

## Dynamic state

The field maintains active scope, relevant Reality, Self State, Goal Context, Rule
Reference, Social/Emotion candidates, Unknown, Provenance, lifecycle, and update
reason. It may be refreshed, backgrounded, suspended, or closed. Field dynamics
are not Runtime execution.
