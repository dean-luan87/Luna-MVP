# Cognitive Field Memory Boundary v1

## Field is not Memory

Cognitive Field is a current operating environment, not Memory. During its
lifecycle it may emit an Experience Candidate containing field context, outcome
reference, provenance, and confidence for the Experience System or future B.

```text
Companion Field
        ↓
User Feedback / Outcome Reference
        ↓
Experience Candidate
        ↓
Experience Governance / future B
```

## Prohibitions

Field cannot accumulate Personality, Identity, Value System, or an autonomous
life story. A single field event cannot directly update Self, Memory, Goal, or
Strategy. Experience adoption remains Candidate → Validation → Adoption.
