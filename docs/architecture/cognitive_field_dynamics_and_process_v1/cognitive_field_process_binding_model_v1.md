# Cognitive Field Process Binding Model v1

## Binding

A Cognitive Process may bind to a Cognitive Field using:

```text
Process ID
Field ID
Intent Reference
Context Scope
Lifecycle Reference
Resource Budget Candidate
Priority Candidate
Escalation Path
```

Binding gives a process a declared information environment; it does not merge
process authority with Field authority. A field may be referenced by a Task
Thread, Attention Thread, Monitoring Thread, or Background Thread according to
the declared scope.

## Boundary

The binding layer does not implement Multi-A Coordination, multiple A decisions,
multi-role competition, emotional relationship calculation, Prediction, Planning,
Decision, or Action Runtime. Process binding cannot create an independent Goal or
modify Reality State.
