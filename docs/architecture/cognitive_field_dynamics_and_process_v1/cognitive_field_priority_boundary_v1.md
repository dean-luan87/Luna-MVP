# Cognitive Field Priority Boundary v1

## Priority candidate

When several fields exist, priority is a resource and lifecycle candidate based
on:

- Survival;
- Goal Context;
- Urgency;
- Resource Cost;
- Attention Demand.

Priority does not select a Decision, Action, role, or value. Brain and future
governance layers retain authority for conflicting long-term goals.

## Single-field scope

This phase defines priority metadata and allocation constraints for a single
field. It does not implement Multi-A Coordination, multiple A routes, role
competition, or Emotional Relationship Calculation. It does not implement role competition.

## Output

The priority contract returns Active Candidate, Background Candidate, Suspension Candidate,
or Closure Candidate with evidence, resource cost, confidence, and
reason. It does not return Recommendation or Decision.
