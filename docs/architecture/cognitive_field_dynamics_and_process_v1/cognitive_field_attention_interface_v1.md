# Cognitive Field Attention Interface v1

## Interface

```text
Active Cognitive Field
        ↓
Attention Requirement
        ↓
Observation Candidate
        ↓
Evidence / Observation State
        ↓
Field Update Candidate
```

Attention is an information regulation mechanism inside a field. It may declare
direction, region, entity, attribute, relationship, information need, evidence
type, cost, and Unknown requirement.

## Frozen boundaries

Attention does not create a Field. Field does not decide a Goal. Neither Attention
nor Field performs Decision, Planning, Prediction, Reasoning, Action, Emotional
Judgment, or Value Judgment. Attention does not perform Decision. Attention does not perform Planning.
Attention does not perform Prediction. Observation feedback updates Field State only through
the governed Reducer and provenance contract.
