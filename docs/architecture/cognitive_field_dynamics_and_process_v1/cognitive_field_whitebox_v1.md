# Cognitive Field Dynamics Whitebox v1

```text
Brain Intent / Neural Detection / External Event / User
                         ↓
                 Field Creation Source
                         ↓
                   Field Candidate
                         ↓
        Created → Active → Background → Suspended
                         ↓                 ↓
                      Closed ←────────────┘
                         ↓
                      Archived
                         ↓
                   Attention Requirement
                         ↓
                     Observation
                         ↓
                    Field Update
                         ↓
              Experience Candidate (optional)
```

Priority uses Survival, Goal, Urgency, Resource Cost, and Attention Demand. The
whitebox contains no Multi-A Coordination, Decision, Prediction, Planning,
Reasoning, Action Runtime, Emotional Relationship Calculation, or Personality
Formation. The whitebox has no Decision and no Prediction.
