# Cognitive Field Resource Boundary v1

## Resource contract

Each field declares an Allocation Candidate for Attention, compute, memory,
energy, capability, and network. The candidate includes expected information
value, Resource Cost, urgency, validity, and release condition.

```text
Field Demand
        ↓
Expected Value / Resource Cost
        ↓
Allocation Candidate
        ↓
Neural / Middleware Governance
```

## Boundary

Field resource management is not a Scheduler and does not execute a process. It
cannot reserve unlimited attention, create a Goal, choose a Decision, invoke a
Provider, control Hardware, or mutate State. Critical safety or Survival signals
may produce an Escalation Candidate for Neural or Brain review.
