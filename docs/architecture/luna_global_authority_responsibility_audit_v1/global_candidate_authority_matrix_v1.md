| Candidate | Producer | Admission / final authority | Authoritative target | Bypass allowed? |
|---|---|---|---|---|
| Potential Intent / Intent impact | A, Brain, Outcome | Intent Governance | Intent | NO |
| Field Event | Observation/Gateway | Field boundary/reducer | Field | NO |

| Context candidate | Context source/formation | Context Foundation | Context | NO |
| Executable Capability Candidate | Runtime Admission | Runtime Admission | executable candidate | NO |
| DecisionCandidate | A/Brain/Intent | Decision Governance | Decision | NO |
| ActionCandidate | Task/Decision | Action Governance | Action | NO |
| EvidenceCandidate | Provider/Observation/FPO | Observation Gateway | admitted Evidence | NO |

| Diagnostic Incident Candidate | Diagnostics | Diagnostics candidate aggregation; external maintenance resolution | incident record | NO semantic bypass |
| Budget Candidate | Attention/Task/Decision | Resource Governance | budget | NO |
| Reservation Candidate | Task/Runtime/Provider | Resource Governance | reservation | NO |
| Envelope Candidate | source changes/Brain/adapter | Working Envelope admission contract not fully explicit | Working Envelope | NO; vacuum |
| Semantic Outline | Semantic Module | adoption/lifecycle authority not explicit; A consumes | derived outline | NO; vacuum |
| Cognitive Snapshot | Cognitive State Formation | adoption authority not explicit; A consumes | derived snapshot | NO; vacuum |

## General rule

The producer owns correct source binding, version and provenance of its candidate. It does not thereby own admission, source mutation or semantic consequence.
