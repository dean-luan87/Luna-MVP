## Planning Goal

Define a narrow canonical Self Governance owner for self-attribution and self-continuity semantics without turning Self into a super-owner over cognition, memory, personality, emotion, intent, identity, or runtime state.

## Owner Decision

Preferred canonical owner name: Self Governance.

Rationale:

- Current canonical core already carries self-related references and evidence interfaces.
- No current canonical owner fully and non-conflictingly owns self-attribution and self-continuity semantics.
- Historical assets provide strong concept boundaries, but their owner names conflict with current canonical owner convergence.

## Planning Scope

- Define Self vs Identity boundary.
- Define self reference, identity reference, identity attribution candidate, self attribution candidate, self continuity candidate.
- Define Self boundary classes: SELF, OTHER, SHARED, ENVIRONMENT, SYSTEM, UNKNOWN, CONTESTED.
- Define stable, semi-stable, transient, and future personality-derived self partitions.
- Define Self relationships to PCN, Memory, Learning, Intent, Dynamic Regulation, Personality, and Emotion.
- Define revision, revocation, provenance, privacy, idempotency, and negative guards.

## Out Of Scope

- Runtime self engine.
- Persistent self profile database.
- Personality Governance.
- Emotion Engine.
- Semantic compression.
- Direct mutation of existing modules.

## Planning Principles

1. Self Governance is a narrow owner.
2. Self Governance consumes evidence and references; it does not rewrite source-owner semantics.
3. Self attribution remains candidate-only.
4. Self continuity preserves trace and provenance but never overwrites original owner lineage.
5. Stable self, semi-stable self, and transient self must remain separated.
6. Personality and Emotion remain future owners.

## Readiness Rule

The planning phase is ready when a coherent narrow Self Governance owner, boundary model, attribution model, continuity model, inter-owner boundary set, scenario suite, gap registry, and verifier are all defined under this planning directory and pass editor diagnostics.
