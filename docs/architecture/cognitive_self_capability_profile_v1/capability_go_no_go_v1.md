# Self Capability Profile Go / No-Go v1

## Required readiness checks

- Profile is a Self Capability Awareness layer, not a score system.
- Core chain is Experience → Memory → Performance Evidence → Capability
  Assessment → Self Capability Profile → Future Attention / Decision Support.
- Dimensions include Perception, Field Understanding, Task Execution,
  Adaptation, Information Seeking, and Reliability.
- Capability is bound to Capability × Field × Condition.
- Assessment uses Outcome Evidence, Experience Pattern, Failure Attribution,
  and Confidence Calibration; Model self-evaluation is excluded.
- Known Strength, Known Limitation, and Unknown are preserved.
- Growth and Confidence changes remain candidates and allow Human Calibration.
- Attention and Model Manager interfaces cannot mutate Identity, Goal, Decision,
  Reality, or Action.

## Explicit prohibitions

No automatic learning, No automatic capability upgrade, No Model Training, No
model parameter modification, No Emotion Runtime, No Role System, No Social
Runtime, No B Route, and No Action Runtime. Profile cannot directly modify
Reality, Goal, Decision, or Identity.

The Agent performs V0 static checks only, does not run the Final Phase Verifier,
and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.

Capability Assessment is required. No model parameter modification. No Social
Runtime. Profile cannot directly modify Reality, directly modify Goal, directly
modify Decision, or directly modify Identity.

No Social Runtime. Profile cannot directly modify Decision.
