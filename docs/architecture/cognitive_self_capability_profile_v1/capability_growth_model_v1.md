# Capability Growth Model v1

Growth is a validated historical pattern, not automatic upgrade. Repeated
Performance Evidence may create a Capability Growth Candidate or OCR
Capability Confidence Increase Candidate. The candidate requires Context,
Failure Attribution, Confidence Calibration, provenance, and human calibration
availability.

Growth lifecycle:

```text
Performance Pattern
  ↓
Growth Candidate
  ↓
Assessment Review
  ↓
Capability Adjustment Candidate
```

A single success does not upgrade a Capability. A provider/model replacement
does not define Self Capability. Hardware State, Resource State, and current
Field Condition remain constraints. No automatic capability upgrade, Model
Training, model parameter modification, or automatic learning is implemented.

OCR Capability Confidence Increase Candidate requires human calibration
availability. Provider/model replacement is not growth evidence by itself.
Model Training and automatic learning remain disabled.
