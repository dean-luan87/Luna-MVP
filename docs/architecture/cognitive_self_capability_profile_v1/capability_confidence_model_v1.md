# Capability Confidence Model v1 Boundary Note

Capability confidence is contextual and not a single score. Performance
Evidence, Outcome Evidence, Experience Pattern, Failure Attribution, and
Confidence Calibration produce a Confidence Candidate scoped by Capability,
Field, Condition, time, source, provenance, and Unknown.

Knowing that I do not know is represented by Unknown and Human Review. Model
self-confidence is not sufficient evidence. A confidence candidate cannot
modify Reality, Goal, Decision, Identity, Model parameters, or Action.

Performance Evidence is required. Model self-confidence is not sufficient.
