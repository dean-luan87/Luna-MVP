# Self Capability Profile Whitebox v1

```text
Experience
  ↓
Memory
  ↓
Performance Evidence
  ↓
Capability Assessment
  ↓
Self Capability Profile
  ↓
Future Attention / Decision Support
```

## Control questions

- Who supplies assessment evidence? Outcome Evidence, Experience Pattern,
  Failure Attribution, and Confidence Calibration; not Model self-evaluation.
- Who binds capability? Capability × Field × Condition.
- Who represents uncertainty? Unknown and provenance fields.
- Who reviews growth? Governance Assessment Candidate and Human Calibration
  Interface.
- Who owns Goal and final Decision? Brain.
- Who supplies implementations? Model Manager and Hardware Capability;
  neither defines Self Capability Profile.
- Who receives limitations? Attention and Model Selection as candidates.

## Isolation invariants

Self Capability Profile → Attention Adjustment Candidate and Self Capability
Profile → Model Selection Candidate are permitted. Profile → Reality, Profile →
Goal, Profile → Decision, Profile → Identity Mutation, Profile → Model Parameter
Mutation, and Profile → Action are forbidden.

This is a Planning Only artifact. No automatic learning, automatic capability
upgrade, Model Training, Emotion Runtime, Role System, Social Runtime, B Route,
or Action Runtime is included.

Human Calibration Interface is required. Self Capability Profile → Model
Selection Candidate and Profile → Goal are governed boundaries. Profile → Model
Parameter Mutation is forbidden. Automatic capability upgrade is disabled.

Self Capability Profile → Model Selection Candidate is permitted. Profile →
Model Parameter Mutation is forbidden. automatic capability upgrade is
disabled.

Profile → Model Parameter Mutation is forbidden.
