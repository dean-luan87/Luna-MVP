# Self Capability Profile Model v1

## Position

Self Capability Profile is the long-term, context-bound self-awareness layer
that combines Capability State, Hardware Capability, Memory, Experience, and
Performance Evidence. It is not a score, personality, Goal, Decision, or Model
self-evaluation.

```text
Experience
  ↓
Memory
  ↓
Performance Evidence
  ↓
Capability Assessment
  ↓
Self Capability Profile
  ↓
Future Attention / Decision Support
```

Every output is a Capability Assessment Candidate or Adjustment Candidate.
Current Reality and current Capability State override historical profile data.
Identity remains continuous and cannot be changed by a profile.

## Multi-dimensional profile

The profile is a multi-dimensional capability space, not a single total score:

- Perception;
- Field Understanding;
- Task Execution;
- Adaptation;
- Information Seeking;
- Reliability.

Each dimension is bound to `Capability × Field × Condition`. For example,
Vision may be High indoors, Medium outdoors, Low in low light, and Medium in a
dynamic crowd. A context-free “Vision 90” is invalid.

## Assessment sources

Capability Assessment Candidate uses Outcome Evidence, Experience Pattern,
Failure Attribution, and Confidence Calibration. Model self-report is not an
assessment source. Failure must be attributed before it lowers a capability:
vision limitation, hardware degradation, resource denial, network loss, and
task/goal mismatch remain distinct candidates.

## Strength, limitation, and Unknown

The profile records Known Strength, Known Limitation, and Unknown for each
Context. Unknown is a first-class capability-profile state; it is not treated
as failure or silently filled by a Model.

## Growth boundary

Repeated validated performance may produce Capability Confidence Increase
Candidate or Capability Growth Candidate. It does not automatically upgrade a
Capability, modify Model parameters, train a Model, or change authority.
Human Calibration Interface remains available for review.

## Interfaces

Capability Profile may produce Attention Adjustment Candidate and Model
Selection Candidate together with Hardware State and Self Capability State.
Model Manager supplies implementation options; it does not define Luna's
Capability Profile. Memory supplies evidence and patterns; it does not define
Identity.

## Explicit non-goals

No automatic learning, automatic capability upgrade, Model Training, model
parameter modification, Emotion Runtime, Role System, Social Runtime, B Route,
or Action Runtime is implemented.

The profile is not a personality, not a Goal, not a Decision, and not a Model
self-evaluation. Indoor, Outdoor, Low Light, and Dynamic Crowd are explicit
conditions. Capability Confidence Increase Candidate and Model Selection
Candidate remain candidates. Model Manager does not define Luna's Capability
Profile. No model parameter modification is allowed.

The profile is not a Model self-evaluation. Model Selection Candidate is
contextual. Model Manager does not define Luna's Capability Profile.
