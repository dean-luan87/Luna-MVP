# Capability Limitation Model v1

Capability Limitation records Known Strength, Known Limitation, and Unknown by
Capability × Field × Condition. Examples include Indoor Navigation as a Known
Strength, Night Vision as a Known Limitation, and Crowded Outdoor as Unknown.

Limitation requires Performance Evidence, Outcome Evidence, Failure Attribution,
or Hardware/Resource evidence. It distinguishes capability limitation from
temporary State degradation, Model availability, network failure, and goal
mismatch.

Limitations create Attention Adjustment Candidate, alternative Capability
Candidate, or Model Selection Candidate. They do not create a Goal, make a
Decision, modify Identity, directly control Action, or permanently define a
Luna without review.

Goal mismatch is distinct from limitation. Alternative Capability Candidate is
only a candidate. A limitation does not create a Goal, does not make a
Decision, and does not permanently define a Luna.

Goal mismatch is not a limitation. Alternative Capability Candidate is
provisional. It does not make a Decision.

goal mismatch; alternative Capability Candidate.
