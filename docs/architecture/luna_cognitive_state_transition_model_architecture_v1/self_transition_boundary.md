# Self Transition Boundary

Self 不是普通状态更新项。`Self(t+1)=f(Self(t),GrowthCandidate)` 只能产生 Self Review Candidate；Identity、Constitution、Safety Boundary 和 Ownership Boundary 不得由单次 Outcome、Memory、Learning、Hive 或 B Route 直接修改。

允许在治理后调整 Capability、Strategy、Cognitive Parameters、Schema 和 Thresholds。任何调整必须具备证据、影响分析、可逆性、版本和明确 Owner。
