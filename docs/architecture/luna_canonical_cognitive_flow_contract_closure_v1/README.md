# Luna Canonical Cognitive Flow Contract Closure v1

## Disposition

**FLOW_CONTRACT_SURFACE_COHERENT_WITH_ADAPTER_GAPS.** The frozen flow can be represented by a minimal, reference-oriented contract surface. Existing canonical families are reused; the remaining work is binding schema, adapter, version/invalidation and runtime integration.

## Scope

This package closes only:

1. Capability ↔ Model binding;
2. Model ↔ Provider binding;
3. Evidence/Result → source-state handoff;
4. Outcome Candidate → Brain adjudication;
5. cross-domain version/invalidation;
6. canonical edge observability.

No runtime, provider, model, source state, protocol, owner, canonical enum/type, UI, Manager, Scheduler, retry/fallback engine, Memory/Experience architecture or test was changed.

## Design rule

Every contract preserves identity, version, producer, authority, consumer, refs, provenance, constraints, admission/validation state, invalidation, failure owner, trace linkage, mutation permission and forbidden bypass. Formation, validation, binding, admission, adoption, mutation, execution, evaluation and mechanical persistence remain distinct.
