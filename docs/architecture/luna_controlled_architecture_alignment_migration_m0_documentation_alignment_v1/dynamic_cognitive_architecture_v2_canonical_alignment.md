## 6. Canonical responsibility semantics

### Field State

Field State maintains admitted, traceable real-world and Field state candidates. It is not user psychological understanding, Memory, Intent, causal judgment, Decision, or Action.

### Observation

Observation coordinates observation requests, modalities, evidence quality, and evidence candidates. It is not final cognition, final fact, Understanding, Decision, or Action.

### Task Manager

Task Manager owns approved task lifecycle, dependencies, interruption, aggregation, and capability routing. It does not generate Intent, own Goal, perform causal judgment, select the final Decision, dispatch Runtime directly, or execute Action.

### Model Manager

Model Manager owns model identity, admission, matching, routing candidates, lifecycle, fallback, diagnostics, trace, and replay. It is not Luna's cognitive subject and cannot generate Reality, Goal, Intent, final Decision, or Action.

### Memory

Memory owns historical and experience persistence, admission, consolidation, activation, and retrieval candidates. It provides historical influence to current cognition. It is not full cognition, cannot override Reality, and cannot directly mutate Self, Identity, Cognitive Core, Decision, or the Personal Cognitive Network.

## 7. Personal Cognitive Network boundary

Personal Cognitive Network owns only:

- governed cross-object links;
- context-bound activation coordination;
- read-only cognitive context projection.

It does not own Self, Role, Relationship, Memory, Emotion, Value, Belief, or Schema. It does not persist or mutate those source objects. It is a future core capability; this phase does not create its implementation or Runtime.

## 8. Status language

M0 uses explicit evidence-bearing status terms:

- `ENGINEERING_BASELINE_ACTIVE` for modules with an active module baseline;
- `ARCHITECTURE_AND_CONTROLLED_SKELETON` for architecture plus an isolated skeleton without production activation;
- `ARCHITECTURE_VALIDATED` for passed architecture boundaries;
- `PLANNING_ONLY` for plans without implementation;
- `FUTURE_BOUNDARY_ONLY` or `FUTURE_CORE_CAPABILITY` for reserved future responsibility;
- `LEGACY_RUNTIME_UNALIGNED` for an existing Runtime surface whose Dynamic Cognitive v2 equivalence is not established.

Historical source assets remain immutable. When an older document uses `implemented` for architecture completion, M0 qualifies that term through this overlay rather than rewriting history.

## 9. Runtime non-equivalence

The root `runtime/` remains the existing A3 Runtime surface. Names such as intent, decision, state, or memory inside an existing Runtime do not prove that Dynamic Cognitive Architecture v2 is implemented. M0 records explicit non-equivalence and performs no Runtime boundary adjustment.
