# Binding Authority / Responsibility v1

| Surface | Authority | Responsibility |
|---|---|---|
| Capability ↔ Model binding | Capability Governance | wrong Capability/Slot binding, stale lifecycle, version/provenance loss |
| Model identity/declaration | Model Governance | incorrect identity, version, loader, dependency or declaration |
| Model ↔ Provider binding | Provider Governance | wrong Provider compatibility binding and lifecycle |
| Runtime eligibility | Runtime Admission | executable eligibility, later |
| Provider execution | Provider Governance / runtime boundary | admission and invocation, later |

Shared declarations are references. They do not create dual mutation authority.
