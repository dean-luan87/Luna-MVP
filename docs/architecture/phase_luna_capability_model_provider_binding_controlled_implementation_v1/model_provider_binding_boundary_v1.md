# Model ↔ Provider Binding Boundary v1

`ModelProviderBindingCandidateV1` binds Model-side declarations to a Provider
family, contract, adapter and loader compatibility declaration. Provider
Governance owns this binding lifecycle and invalidation.

Model Governance remains responsible for Model identity, loader, dependency
and model-side compatibility declarations. Provider Governance remains
responsible for Provider identity and Provider-side declarations.

Compatibility is not health, Provider Admission, model loading or invocation.
