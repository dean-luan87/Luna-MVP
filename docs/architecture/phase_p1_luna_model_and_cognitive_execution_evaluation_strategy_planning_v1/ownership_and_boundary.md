# Ownership and Boundary

| Concern | Owner | Evaluation role |
|---|---|---|
| Dataset/sample/annotation declarations | Evaluation Governance | Own future evaluation registry entries. |
| Model identity/version | Model Governance | Reference only. |
| Capability/slot/resolution | Capability Governance | Reference only. |
| Provider/binding/invocation | Provider Governance | Observe and reference; never bypass. |
| Observation demand/request | FPO / canonical observation owners | Record candidate trace. |
| Evidence admission | Observation/Gateway boundary | Consume candidate outputs; no direct fact. |
| Current World candidate | Cognitive State Formation | Observe candidate only. |
| Hypothesis/Sufficiency/Reconsideration | A | Observe candidate transitions; no evaluation takeover. |
| Decision commitment | Decision Governance | Observe handoff; do not fabricate commitment. |
| Test result/evidence | Evaluation Tools/TestBoard | Own evaluation artifact lifecycle. |
| Human correction | Human Correction Layer | Candidate review signal, not automatic GT. |

Evaluation has responsibility for its own translation/reporting defects. It
does not acquire semantic authority merely by measuring a canonical owner.
