## Closure Position

PCN is frozen as Luna's Personal Subjective Cognitive Association Network.

PCN responsibilities:
- Preserve and express subjective cognitive association candidates across personal cognitive objects.
- Activate relevant cognitive structures from Context-linked references.
- Express link strength, dormancy, reactivation, and growth candidates.
- Express personal association projections across Field, Role, Relationship, and related references.
- Consume and forward Interaction Candidate References.
- Scale active projection scope under resource constraints.
- Provide Personal Cognitive Projection candidates for future Intent/Causal modules.

PCN non-responsibilities:
- Reality Truth ownership or arbitration.
- Context/Field/Role/Relationship/Memory/Emotion ownership.
- Intent generation, Causal reasoning, Decision, Action.
- Interaction Kernel computation ownership.
- Runtime dispatch, source mutation, persistence authority.

## Frozen Semantic Boundaries

- subjective_strength != truth
- resonance != causal_fact
- competition != arbitration
- dormant != deleted
- temporary_occupation != structural_mutation
- resource_degradation != knowledge_deletion
- historical_reactivation != new_truth

## Nested Constraint Closure

PCN remains inside a nested living-system constraint model:
- Context <-> PCN
- Field <-> Role
- Role <-> Relationship
- Memory Reference <-> PCN
- Resource <-> PCN
- Interaction <-> PCN
- Observation Axis Reference <-> Interaction

Closure principle:
- Owner independence does not mean cognitive isolation.
- Constraint, feedback, activation, inhibition, and amplification do not grant cross-owner source mutation authority.

## Resource Closure

Resource governance remains tri-sourced:
- Hardware Resource
- Runtime Resource
- Cognitive Resource

Resource insufficiency may shrink active projection, depth, and concurrent scope, but must not delete source/dormant state, mutate truth, mutate core field, mutate relationship, or mutate memory.

## Unknown/Subjective Closure

Unknown may become future candidate completion through evidence/experience/memory/rules/causal modules, but PCN cannot promote Unknown to Fact.
PCN may preserve subjective beliefs and subjective strengths without reality arbitration.
