# Need / Requirement terminology map

| Term | Meaning | Producer | Consumer | Finding |
|---|---|---|---|---|
| Cognitive Need | bounded missing information / evidence gap | A / existing Need bridge compatibility | A, Requirement bridge | target semantic Need |
| Current Minimum Need | only Need allowed to bind downstream demand | A | Capability Requirement bridge, Loop ref recording | do not confuse with plan list |
| Observation Need | acquisition/admission request after a cognitive gap | Observation/Outcome routing under A request | Observation Gateway/FPO | service request, not cognitive authority |
| Task Requirement | behavior/completion constraint | Task governance | Decision/Task execution path | not cognitive Need |
| Cognitive Requirement | A-owned information requirement | A | Capability Requirement bridge | new integration candidate seam |
| Capability Requirement | governed technical capability demand | existing Capability bridge/governance | Scope/Resolution | not provider identity |
| Requirement | generic historical label | varies by module | varies | ambiguous until qualified |

No canonical vocabulary is renamed in this phase. Future contracts should qualify every unqualified `Requirement`.
