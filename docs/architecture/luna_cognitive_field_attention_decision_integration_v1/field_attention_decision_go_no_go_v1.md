# Field Attention and Decision Integration Go/No-Go

## Readiness criterion

`LUNA_COGNITIVE_FIELD_ATTENTION_DECISION_INTEGRATION_READY` is emitted by the user-owned V2 verifier only when Attention, Context, Hypothesis, Understanding, Decision Candidate, Self/Social constraints, A flow, B boundary, and negative guards are complete.

## No-go conditions

- Attention or Context writes Reality;
- Hypothesis becomes fact or automatically resolves conflict;
- Current Understanding is treated as a World Model;
- Self/Social/Emotion directly creates or overrides Decision;
- Decision Candidate is treated as Action;
- B Route writes Field or executes Action;
- Learning, Emotion, Role, World Model, Action, or Runtime implementation appears.

The agent stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION` and does not declare a final GO decision.
