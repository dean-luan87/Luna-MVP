# Luna Cognitive Field Attention and Decision Integration v1

## Position

This phase mounts the existing Attention, Context, Hypothesis, Current Understanding, and Decision Candidate contracts inside Cognitive Field. It is an architecture integration, not a new cognitive runtime or automatic decision engine.

## A Route processing chain

```text
Reality / Evidence
      ↓
  Cognitive Field
      ↓
  Attention Candidate
      ↓
  Context Assembly
      ↓
  Hypothesis Candidate
      ↓
  Current World Understanding Candidate
      ↓
  Decision Candidate
      ↓
  Action Boundary (future execution gate)
      ↓
  Experience / Memory
```

Field components contribute different context: Self supplies capability and stability, Social Self and Role supply participation constraints, Memory supplies relevant history, and Knowledge supplies admitted contextual reference. Attention chooses relevance; Context assembles; Hypothesis explains uncertainty; Understanding remains a candidate; Brain evaluates Decision Candidates.

## Boundaries

No component in this phase owns automatic Decision, Action, Reality mutation, World Model, Self Modification, Learning Runtime, Role Runtime, or Emotion Runtime. B Route receives a Field snapshot and returns a future simulation candidate only.
