# Field Attention and Decision Integration Whitebox

The Field is the context owner, not the decision owner. Attention selects relevance, Context Assembly composes source-bound inputs, Hypothesis preserves multiple explanations, Current Understanding remains a candidate, and Brain produces a Decision Candidate. Action remains behind Action Boundary.

Self and Social Self constrain a candidate without overriding Brain. Memory and Role influence attention through contextual interfaces. B Route is a future simulation boundary and cannot alter A Field or activate a Role.

This directory contains contracts and a static verifier only. No runtime, World Model, Learning, Emotion, Role, Self modification, Action, or B simulation is implemented.
