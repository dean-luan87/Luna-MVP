# Value Hierarchy Model v1

The canonical hierarchy is contextual rather than a fixed numerical table:

```text
Survival Value
      ↓
Safety Value
      ↓
Integrity Value
      ↓
Mission Value
      ↓
Relationship Value
      ↓
Growth Value
```

The ordering expresses a constraint preference, not an automatic action. A
high-level safety or integrity violation rejects a candidate even when its
mission, relationship, or growth benefit is large. Current Field, Goal,
Capability, resource state, and evidence determine the contextual evaluation.

Legacy Value Constitution assets are reused through an explicit mapping:
survival and self-integrity map to Survival/Safety/Integrity boundaries; user
goal and social values map to Mission/Relationship context; learning maps to
Growth context. No legacy asset is deleted or silently rewritten.
