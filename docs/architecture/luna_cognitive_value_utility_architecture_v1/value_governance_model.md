# Value Governance Model v1

Value governance keeps evaluation subordinate to Constitution and preserves
the distinction between ranking and authority.

1. Receive a Value Evaluation Candidate with provenance and unknowns.
2. Check hard constraints and current Self resource boundaries.
3. Produce benefit, cost, risk, utility, and priority candidates.
4. Expose the candidates to Brain and future Decision Arbitration.
5. Keep rejection, deferral, and uncertainty explicit.

Value may evaluate a Goal, Task, exploration, maintenance, or learning
candidate. It cannot create or rewrite a Goal, make a Decision, execute an
Action, modify Reality, modify Identity, rewrite Constitution, or change its
own hierarchy. Emotion is a future context provider only; it may propose an
`Utility Weight Adjustment Candidate` subject to Self review, but it cannot
change Value directly.
