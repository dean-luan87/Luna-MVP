# Luna Core Architecture Baseline v1.0

## Purpose

This baseline freezes the canonical ownership, information flow, state ownership, and authority boundaries of Luna after the Cognitive Self Model phase. It is a governance artifact, not a runtime implementation.

```text
L0 Constitution
      |
L1 Governance Plane
      |
L2 Cognitive Core: Reality / Field / Attention / Workspace / Brain / Memory / Learning / Self
      |
L3 Social and Emotion Boundary (interfaces only)
      |
L4 Capability and Action Boundaries
      |
L5 Runtime Foundations and external implementation boundaries
```

## Canonical information flow

```text
Observation -> Evidence -> Context -> State -> Hypothesis / Belief
-> Expectation -> Brain Evaluation -> Decision Commitment
-> Action Boundary -> Action Runtime -> Outcome
-> Learning Candidate -> Memory Consolidation -> Self Evolution
-> Capability / Limitation Profile Candidate -> Self Model Update Candidate
```

Feedback is represented as a re-entry event and does not grant any module a second owner for the target state.

## Ownership principles

- Every canonical concept has one owner.
- Reader, proposer, updater, and executor permissions are separate.
- Brain owns judgment and Decision Candidate generation; it does not execute.
- Memory owns records; Learning and Self Evolution produce candidates.
- Capability produces evidence and health candidates; it does not own Goal, Brain, or Reality.
- Action Boundary gates execution; Action Runtime executes only an admitted request.
- Self Model represents current self context; it does not create Identity, Value, Goal, Emotion, or Social Runtime state.

## Frozen extension rule

Future Emotion, Social, Provider, Model, and Hardware work must enter through the declared boundary contracts. No extension may replace Brain, become a Reality authority, write Memory facts directly, or bypass Governance and Admission.

## Baseline status

This baseline is ready for user-terminal V2 review. It does not authorize external model admission, hardware integration, Action execution, Emotion Runtime, Social Runtime, or automatic learning.
