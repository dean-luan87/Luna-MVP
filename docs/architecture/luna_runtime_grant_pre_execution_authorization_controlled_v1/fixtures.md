# Controlled fixtures

The evaluation covers complete and incomplete requests, provider binding
eligibility, permission/safety/constitution outcomes, runtime boundary,
freshness, expiry, revocation, resource feasibility, FPO continuation versus
grant, and Gateway admission versus grant.

It also covers authority/responsibility mismatch and laundering, candidate
versus authoritative decision, deterministic replay, malformed input,
provider-only requests without model inference, no resource allocation, no
execution identity, and no runtime submission.

Scenario 12 uses two abstract provider paths for signage and human-flow. The
fixture names remain controlled provider references and do not infer OCR, VLM,
camera, SLAM, YOLO, or a concrete model.
