# Case Definitions

## Case A — direct Decision to Task

The existing one-cycle cognition path reaches Sufficiency and Stop. Decision
Governance selects one eligible candidate. The adapter submits one Task
handoff and the Task Manager produces controlled Task state.

## Case B — re-observation before Decision to Task

Cycle 1 remains insufficient and produces no Decision or Task handoff. After
the existing linked second cycle reaches Sufficiency, Stop, and revision,
Decision Governance selects one candidate and Task Manager receives exactly
one final handoff.
