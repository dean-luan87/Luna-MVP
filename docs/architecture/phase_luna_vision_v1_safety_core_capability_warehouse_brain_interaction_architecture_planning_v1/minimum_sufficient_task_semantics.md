# Minimum sufficient task semantics

Minimum Sufficient Task Semantics is a future SRSK-governed mechanism, not a
Vision-owned sufficiency decision. The Brain supplies the task, reason,
semantic need, and stop condition; Vision only supports the requested
evidence acquisition depth. SRSK evaluates semantic sufficiency. For example,
an unknown sign plus an exit semantic and a right-arrow candidate can be
sufficient for an exit-finding task without formal sign identification.

Evidence Sufficiency asks whether enough evidence was acquired for an
observation request. Semantic Sufficiency asks whether the resolved meaning
is enough for the active task or cognitive need. They are independent. A
partial `EXIT + right arrow` evidence package may be semantically sufficient.
Richer recognition must not be invoked merely because it is available.
