# Implementation roadmap

1. Formalize the mandatory slot and minimum semantic benchmark under
   Capability Governance and Model Manager.
2. Extend capability registration with typed manifests and lifecycle guards.
3. Integrate approved safety slots with the existing safety-critical
   observation exception and Observation Gateway evidence path.
4. Define SNSP pack scopes and Field Rule reconciliation inputs without
   making a norm prior authoritative.
5. Define the future cross-modal SRSK boundary and separate Evidence
   Sufficiency from Semantic Sufficiency.
6. Add metadata-only Learning Need handoffs through existing cognitive/FPO
   boundaries.
7. Add degradation/rollback diagnostics and user-terminal governance tests.

No step in this planning phase activates a provider or implements Learning.
