# Field Rule Reconciliation boundary

The future route is:

`Visual Evidence -> SNSP Norm Semantic Prior -> Field Rule Reconciliation -> Effective Field Rule Candidate`.

Reconciliation may consider current physical state, local instructions,
temporary facilities, staff direction, repeated group behavior, conflicting,
outdated, or superseded signs, and temporal validity. Group behavior is
evidence, not automatic correctness. Social Norm is a prior, not final
authority. Safety Governance retains a safety veto candidate.

No Field State mutation or effective-rule truth declaration is introduced by
this planning alignment.
