# Semantic Resolution & Sufficiency Kernel boundary

SRSK is a future cross-modal cognitive component, not part of Vision. Its
planned responsibilities are semantic resolution, expansion, folding, depth
governance, sufficiency, Unknown/Partial-Known governance, cross-layer
translation, semantic-gap detection, and Learning Target formation support.

Future inputs may include Vision, Audio, Language, Touch, Memory, SNSP, and
other knowledge evidence. SRSK may own semantic interpretation governance,
but never World Truth, Field/Intent/Decision/Task mutation, or Learning
execution.

`Semantic Authority != Truth Authority != Mutation Authority`.
