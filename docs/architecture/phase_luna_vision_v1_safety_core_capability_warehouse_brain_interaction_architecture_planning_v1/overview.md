# Luna Vision V1 Architecture Planning

This planning package defines the next-generation Vision architecture without
implementing runtime behavior.

The architecture has four governed layers plus two future cross-cutting
semantic boundaries:

1. Mandatory Safety Vision Core
2. Optional Visual Capability Warehouse
3. Brain-controlled Task Observation
4. Brain-governed Learning Need boundary

5. Social Norm Semantic Pack (SNSP) prior boundary
6. Semantic Resolution & Sufficiency Kernel (SRSK) boundary

Vision remains an evidence acquisition system. SNSP is a standardized norm
prior source, not a Vision model or final Field Rule authority. SRSK is a
future cross-modal semantic governance component, not part of Vision. All
outputs remain candidates; no provider becomes a World Truth owner, and no
new runtime semantic owner is introduced in this phase.
