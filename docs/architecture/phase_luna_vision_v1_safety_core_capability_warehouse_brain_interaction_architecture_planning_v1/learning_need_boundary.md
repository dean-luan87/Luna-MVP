# Learning Need boundary

`Vision/Audio/other Evidence -> Unknown/Partial Known -> SRSK semantic gap
evaluation -> Brain cognitive/task relevance evaluation -> Learning Need
Candidate -> Learning Governance`.

If the gap is not task-blocking, preserve the unknown/partial-known state and
stop. If SRSK identifies a gap and Brain determines that it blocks the task,
Brain may create a candidate containing
`learning_target`, `required_semantic_depth`, `task_relevance`, and
`stopping_condition`. Learning sources may later include Internet, human,
other Luna experience, self experience, or external knowledge providers.

Vision cannot autonomously initiate Learning because a sign/object is
unknown, and SRSK cannot execute Learning. This phase creates no learner,
memory write, model update, or knowledge-provider invocation.
