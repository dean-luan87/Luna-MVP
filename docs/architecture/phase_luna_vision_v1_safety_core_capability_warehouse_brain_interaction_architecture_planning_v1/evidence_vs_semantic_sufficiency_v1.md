# Evidence Sufficiency versus Semantic Sufficiency

Evidence Sufficiency is owned by FPO / Active Observation Control and asks
whether enough evidence has been acquired for the current observation
request. Semantic Sufficiency is future SRSK governance and asks whether the
resolved meaning is sufficient for the active task or cognitive need.

These are independent. Evidence can be complete while meaning remains
insufficient; partial evidence can still support task-semantic sufficiency.
For example, `EXIT + right arrow` may be enough to leave a building even when
formal sign identity remains unresolved. Richer recognition is not automatic.
