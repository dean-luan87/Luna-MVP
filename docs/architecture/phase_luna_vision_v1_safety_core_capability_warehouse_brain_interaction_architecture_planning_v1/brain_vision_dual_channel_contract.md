# Brain–Vision dual-channel contract

## Safety Perception Channel

`Safety Vision Core -> canonical evidence -> Observation Gateway -> Brain`.
It is not gated by ordinary Brain Observation Need, but remains bounded,
admitted, provenance-bearing, candidate-only evidence. Safety priority does
not grant truth authority or permit a provider/Gateway bypass. Reuse the
existing safety-critical observation exception candidate.

## Task Observation Channel

`Brain Observation Demand/Request -> Active Observation Control/FPO ->
Capability/Model admission -> provider -> evidence -> Observation Gateway ->
Brain`.

The Gateway receives evidence; it does not invoke providers. Both channels
preserve the Brain Golden Baseline candidate/truth and mutation boundaries.

## Semantic boundary

Vision may emit sign/symbol evidence. A future SNSP may add a standardized
semantic prior. The route is:

`Visual Evidence -> SNSP Norm Semantic Prior -> Field Rule Reconciliation ->
Effective Field Rule Candidate`.

SNSP does not declare effective rule, World Truth, obedience, or action
authority. Current physical state, local instructions, temporary facilities,
staff direction, repeated behavior, conflicting/outdated signs, and temporal
validity remain reconciliation inputs. Safety Governance retains its safety
veto capability.
