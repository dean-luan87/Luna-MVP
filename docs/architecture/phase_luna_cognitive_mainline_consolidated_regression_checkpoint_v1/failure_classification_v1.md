# Failure classification

The harness classifies failures as:

`ENTRYPOINT`, `SOURCE_MANIFEST`, `DOCUMENTATION`, `SCENARIO`, `AUTHORITY`, `GRANT`, `A_SEMANTIC`, `B_CR`, `LOOP_MECHANICAL`, `DYNAMIC_COMPATIBILITY`, `WORKING_ENVELOPE`, `CAPABILITY`, `OBSERVATION`, `REAL_INPUT`, `REAL_PROVIDER_SINGLE_INVOCATION`, `TRACE_PROVENANCE`, or `UNKNOWN`.

Original phase failure details remain in the captured Runner/Verifier summaries.
