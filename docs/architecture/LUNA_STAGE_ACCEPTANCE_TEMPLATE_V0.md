# 阶段验收模板 v0（强制模板，不得省略）

**适用范围**：本模板适用于路线图中所有后续阶段（Model/Perception/SceneTask/Fusion/Expression/Device）。  
**强制要求**：任何阶段没有本模板的“立项前 + 收尾时”两段，就不得宣称完成，不得进入下一阶段。  

---

## 立项前（必须填写）

1. **阶段名称**  
2. **唯一目标**（只允许 1 条主问题）  
3. **非目标**（明确排除项）  
4. **输入依赖**（必须列出依赖的冻结结论/前置阶段）  
5. **输出交付物**（文件/代码/报告的可交付清单）  
6. **完成指标**（量化/可核验；“全部满足才算完成”）  
7. **停止条件**（满足即停止，禁止顺手扩展）  
8. **下一阶段入口条件**（进入下一阶段所需的最小条件）  

---

## 收尾时（必须填写）

1. **实际完成项**（逐条对照输出交付物与完成指标）  
2. **未完成项**（必须说明是否影响停止条件）  
3. **是否达到停止条件**（是/否；若否必须进入 fix sprint 或回滚范围）  
4. **是否允许进入下一阶段**（是/否；必须引用“下一阶段入口条件”逐条核验）  
5. **是否需要 fix sprint**（需要/不需要；若需要必须限定唯一目标与停止条件）  
6. **当前阶段是否冻结**（冻结/未冻结；冻结意味着阶段结论在后续不得被“顺手重写”）
