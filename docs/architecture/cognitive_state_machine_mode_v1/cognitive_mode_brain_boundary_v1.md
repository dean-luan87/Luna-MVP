# Cognitive Mode Brain Boundary v1

## Authority split

Runtime evaluates conditions and emits a Cognitive Mode Transition Candidate.
Brain may evaluate that candidate alongside Intent, Goal, Value, Risk, and
Self. Runtime does not replace Brain.

```text
Runtime State / Mode Candidate
          ↓
Brain Evaluation
          ↓
Goal or Decision Candidate
```

Brain can change a long-term Goal through its own authority. A mode cannot
change Goal, Decision, Identity, Reality, or Action. Attention cannot decide
Mode. Attention cannot decide Mode, and Runtime cannot use a mode transition
to bypass Brain.

## Escalation

Survival Mode Candidate or Emergency Candidate may increase Brain Escalation,
but an emergency candidate is not an Action. The existing Brain Activation
Boundary remains authoritative.
