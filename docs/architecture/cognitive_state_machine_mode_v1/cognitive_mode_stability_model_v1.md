# Cognitive Mode Stability Model v1

## Stability controls

Mode stability uses entry threshold candidate, maintenance evidence, exit
threshold candidate, minimum dwell candidate, timeout, hysteresis, cooldown,
and recovery conditions. These are governance parameters, not Scheduler code.

## Oscillation prevention

exit threshold is required. Normal Mode ↔ Survival Mode oscillation must preserve the transition trace and
require meaningful deviation or recovery evidence. A false trigger produces a
Diagnostic Candidate; it does not cause unlimited mode switching.

Exit threshold is required. Focus Mode must not exhaust the system. Recovery Mode and Maintenance Mode
remain available as resource-protection candidates. No stability mechanism
modifies Goal, Decision, Identity, Reality, or Action. The stability model does
not modify Goal, does not modify Decision, does not modify Identity, does not
modify Reality, and does not modify Action. The stability model does not modify Goal
or Reality. The stability model does not modify Reality.
