# Cognitive Mode Experience Boundary v1

## Experience influence

Experience may change the probability or confidence of a Mode Transition
Candidate. Familiar environments may lower a Survival Mode prior; repeated
validated risk may raise it. Experience cannot lock a mode or replace current
Reality Evidence.

```text
Experience Reference
      ↓
Mode Transition Prior Candidate
      ↓
Current Reality / Self / Resource Validation
      ↓
Cognitive Mode Candidate
```

One event cannot permanently alter a mode prior, Identity, Goal, Decision, or
Attention Policy. Mode Transition Candidate and Current Reality Evidence are
required for validation. Experience is a reference, not an automatic mode switch.
