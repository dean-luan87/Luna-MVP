# Cognitive Mode Neural Boundary v1

## Fast path

```text
Stimulus
    ↓
Neural Response Candidate
    ↓
Runtime State Candidate
    ↓
Attention Reallocation Candidate
    ↓
Brain Escalation if needed
```

Neural Fast Path can surface Emergency Candidate, Risk Increase Candidate, or
Resource Protection Candidate. It does not decide, alter Goal, modify Reality,
or execute Action.

## Boundary

Neural may inform mode evaluation but cannot lock Survival Mode, suppress
Recovery, or control hardware frequency. Neural cannot control hardware frequency.
Mode and Neural candidates retain provenance, confidence, and
release conditions.
