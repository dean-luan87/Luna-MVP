# Negative guards

The controlled evaluation verifies no real Provider/Model invocation, network,
subprocess, thread, socket, camera, OCR, YOLO, VLM, SLAM, Gateway submission,
RuntimeObservation, Evidence, Truth, Current World mutation, Task, or Action.

It also verifies no provider fallback, retry engine, autonomous continuation,
resource action, upstream semantic rewrite, or loss of lineage. `CREATED`,
`STARTED`, and `COMPLETED` remain distinct lifecycle states.
