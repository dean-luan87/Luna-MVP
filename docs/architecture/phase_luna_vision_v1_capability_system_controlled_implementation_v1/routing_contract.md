# Capability routing contract

The candidate-only router distinguishes:

- `ROUTE_READY_CANDIDATE`
- `CAPABILITY_NOT_INSTALLED`
- `CAPABILITY_DEGRADED`
- `CAPABILITY_INCOMPATIBLE`
- `SAFETY_BASELINE_BLOCKED`
- `OBSERVATION_NEED_REQUIRED`

Routing retains Model Manager admission as a future prerequisite and never
becomes a Provider-to-Brain shortcut.
