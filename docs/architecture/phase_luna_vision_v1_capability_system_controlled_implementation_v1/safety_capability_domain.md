# Safety Capability domain

Safety Vision is represented by mandatory category-level slots:

- environment awareness
- motion/vehicle/pedestrian risk awareness
- passability/obstacle/edge hazard awareness
- standardized safety/sign awareness
- visual sensor health

Slot identity is independent of model identity. Mandatory slots cannot be
user-uninstalled, disabled below baseline, or replaced by an unapproved
provider. They require baseline checks, degradation monitoring, rollback
references, candidate-only evidence, and no truth authority.
