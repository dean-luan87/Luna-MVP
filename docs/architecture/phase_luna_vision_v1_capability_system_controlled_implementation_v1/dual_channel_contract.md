# Brain–Vision dual-channel controlled contract

## Safety Perception Channel

Safety requests use registered mandatory capability references and may proceed
without ordinary Observation Need. They can expose priority, interrupt, or
escalation candidates, but remain candidate-only and require the Observation
Gateway boundary.

## Task Observation Channel

`Brain/FPO Observation Need -> capability requirement -> capability router
candidate -> registered capability -> future provider/evidence route`.

Task Observation requires ordinary Observation Need. Neither channel invokes a
provider in this phase.
