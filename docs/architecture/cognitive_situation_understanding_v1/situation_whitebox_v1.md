# Situation Understanding Whitebox v1

## Structured trace

```text
Reality Evidence / Reality State
                  ↓
             Field State
                  ↓
     Self State + Capability State
                  ↓
       Goal Context + Attention Context
                  ↓
            Situation Candidate
          ┌───────┼────────┬────────┐
          ↓       ↓        ↓        ↓
      Environment Self   Risk    Unknown
        Context Context Context Context
                  ↓
       Situation Confidence Candidate
                  ↓
             A Route Input
```

## Update trace

```text
New Evidence → Reality Update Candidate → Field Update Candidate
             → Situation Reassessment Candidate → Brain Awareness Input
```

Reality Facts remain separated from hypotheses and Situation interpretation.
Same Reality plus different Self Capability may yield different Situation
Candidates without changing Reality. Unknown is retained when Evidence Support
is insufficient. This trace contains no Decision, Action, Prediction, private
chain-of-thought, or direct State mutation. private chain-of-thought is not
stored.

The Reducer remains the sole State mutation authority. No real model, No OCR,
No SLAM, No Camera, No Hardware Runtime, No Emotion, No Role, No Social
Runtime, and No B Runtime are included. No Social Runtime is included.
