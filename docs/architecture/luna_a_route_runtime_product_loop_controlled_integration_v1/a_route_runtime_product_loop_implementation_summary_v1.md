# Implementation summary

The new integration package contains immutable product-loop types, a deterministic controlled engine, synthetic L01-L40 fixtures, a cwd-independent Runner, narrow orchestration errors, and ownership guards.

L40 is assembled stage by stage. It does not return a preconstructed terminal result: the engine emits input, observation, world/context, cognition, decision, task, action, runtime admission, controlled execution, result, evaluation, feedback, output, and completion handoffs.

The integration does not modify existing A Route core files or downstream owners. It does not invoke providers or models, perform runtime execution, persist state, deliver output, execute learning, activate Emotion, activate B Route, or perform semantic compression.
