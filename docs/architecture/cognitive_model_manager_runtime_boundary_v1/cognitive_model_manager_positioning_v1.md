# Cognitive Model Manager Positioning v1

## Position

Model Manager is an asset and implementation governance manager. It is not a
Brain, reasoning center, Task scheduler, Decision maker, Capability authority,
or cognitive subject.

```text
Cognitive Requirement
        ↓
Capability
        ↓
Model Manager
        ↓
Model / Provider Candidate
        ↓
Evidence Gateway
        ↓
Reality Workspace
```

Luna requests Text Evidence, Scene Evidence, Spatial Evidence, Audio Evidence,
or another abstract Capability. It does not request “GPT” or a vendor model.

## Model Manager responsibilities

- Model Registry identity and version;
- Provider mapping and Capability binding;
- resource and performance profile;
- Hardware Compatibility;
- health and diagnostics;
- permission and Admission metadata;
- controlled availability and deprecation candidates.

Model Manager does not create a Goal, receive full Self or Field, make a
Decision, create a Field, modify Reality, or execute Action. Model replacement
may change Evidence Quality Candidate, not Identity, Field, Task, Goal, or A
Route cognition.

## Model cognitive scope

Local model reasoning is allowed only inside the declared Capability Scope. A
VLM may return “possible vehicle” as Scene Evidence Candidate; it may not say
“you should go there”. A model may generate local feature candidates, never
final cognitive authority.

## Prohibitions

No real model, GPT, VLM, OCR, SLAM, ASR, Provider Runtime, automatic model
switching, automatic learning, Action, B, Emotion, or Role is implemented.

Model Manager is not a Brain. Its resource profile is governed. It does not
receive full Self, make a Decision, create a Field, modify Reality, or execute
Action. No GPT, No VLM, No OCR, No SLAM, No ASR, No Provider Runtime, No
automatic model switching, No automatic learning, No B, No Emotion, and No Role
are implemented.

Model Manager does not receive full Self, does not make a Decision, does not
create a Field, does not modify Reality, and does not execute Action. No
automatic model switching is permitted.

Exact boundary terms: does not create a Field. No automatic model switching.
