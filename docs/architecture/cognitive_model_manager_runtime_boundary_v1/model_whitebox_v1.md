# Model Manager Runtime Boundary Whitebox v1

## Controlled model path

```text
Cognitive Requirement
        ↓
Capability Requirement
        ↓
Capability Governance
        ↓
Model Registry / Capability Binding
        ↓
Model Admission
        ↓
Hardware Compatibility / Resource Profile / Health
        ↓
Provider Candidate
        ↓
Raw Evidence Candidate
        ↓
Evidence Gateway
        ↓
Reality Workspace
```

## Assertions

- Capability is abstract; Model is an implementation option.
- Model Manager manages registry, version, Provider, binding, resource,
  compatibility, performance, health, and permission.
- Model Cognitive Scope permits local feature/candidate generation only.
- Model never receives full Goal, Self, Field, Authority, Decision, or Task.
- Evidence contains Source, Confidence, Limitation, Unknown, and Provenance.
- Evidence Gateway and Reducer remain mandatory.
- Model Replacement changes implementation candidate, not Identity, Field,
  Task, Goal, or A Route cognition.
- Health degradation produces candidate feedback; automatic model switching is
  disabled.

No real model, GPT, VLM, OCR, SLAM, ASR, Provider Runtime, Action Runtime,
Hardware Runtime, automatic learning, B, Emotion, or Role is included.

No full Self or full Field is passed. No GPT, No VLM, No OCR, No SLAM, No ASR,
No Provider Runtime, No Action Runtime, No Hardware Runtime, No automatic
learning, No B, No Emotion, and No Role are included.

No automatic learning is included.
