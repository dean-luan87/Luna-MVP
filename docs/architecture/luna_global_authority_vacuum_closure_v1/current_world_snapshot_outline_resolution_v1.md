# Current World, Cognitive Snapshot and Semantic Outline Resolution v1

## Current World

Current World is a candidate representation, not World Truth and not a second Field store. Observation/Evidence and source references may produce a Current World candidate. The Current World representation / Cognitive State Formation boundary owns candidate formation, structural validity, source-version alignment, stale marking, supersession and provenance. Field owns operational state transitions separately.

There is no independent World Admission or World Truth Manager. A owns adoption for reasoning: it may consume, reject, or treat the candidate as insufficient. A is responsible for an incorrect semantic interpretation; the candidate producer is responsible for malformed structure, source mismatch, lost provenance or invalid versioning.

## Cognitive Snapshot

Cognitive State Formation owns assembly, source alignment, snapshot version, and partial/degraded/stale status. “Adoption” is downstream use, not an additional admission state. A consumes or rejects the valid snapshot for its reasoning cycle. State Formation owns snapshot construction errors; A owns incorrect semantic use. Brain owns the Concern/Grant that scopes the work, not the snapshot payload.

## Semantic Working Outline

Semantic Module owns the local-derived lifecycle: construction, version, provenance, stale/degraded status and supersession. It does not admit a new semantic truth. A decides whether the Outline is cognitively useful, sufficient, or grounds a Next-step. Semantic Module owns malformed transformation; A owns interpretation.

## Shared conclusion

Formation creates a candidate, validation checks it, and A adopts or rejects it for reasoning. None of the three products may mutate Field, Current World source state, Need, Sufficiency, or Brain state.
