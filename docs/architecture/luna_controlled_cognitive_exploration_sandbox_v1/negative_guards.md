# Negative Guards

Sandbox 必须保持：

- synthetic-only、deterministic、no network/database dependency；
- no fake runtime、Provider、Model、OCR、Observation Demand 或 Strategy Coordination；
- no winner selection、priority、scheduling、resource merge 或 acquisition；
- no decision/task/action authority；
- no canonical cognition mutation 或 ownership transfer；
- no Field、Current World、Memory/PCN mutation；
- no Truth / World Truth declaration；
- no Branch auto-expansion 或 hidden fallback strategy；
- no Goal/Question/Need string lookup、keyword/substring semantics、scenario/case mapping；
- no synthetic evidence presented as real evidence；
- no autonomous infinite loop；
- no movement/camera command；
- no B-route result written into A-route Current World。

Verifier 将 Contract Failure 与 Cognitive Logic Observation 分开。前者使验证失败；
后者只进入报告供人工审阅，不被强制改写成预期认知答案。
