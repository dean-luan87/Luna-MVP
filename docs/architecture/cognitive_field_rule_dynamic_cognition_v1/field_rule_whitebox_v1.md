# Field Rule / Dynamic Cognition Whitebox v1

## Integrated trace

```text
Reality Evidence
      ↓
Physical / Entity / Spatial Field
      ↓
Rule Candidate + Evidence + Confidence + Unknown
      ↓
Dynamic Density / Direction / Flow Pattern
      ↓
Field Understanding Candidate
      ↓
Attention Bias Candidate
      ↓
Capability Requirement Candidate
      ↓
Situation Enhancement
```

## Assertions

- Reality “people are queued” is separate from Rule “queue norm may apply”.
- Physical, Functional, Social, Legal, and Temporary Rule types are candidates.
- Human Flow is group behavior: Density, Direction, Flow Pattern, entry, exit,
  queue, gathering, and evacuation.
- Crowd Following is risk reduction under Unknown High, not blind following.
- Information Source Candidate can seek service desk, signs, maps, user input,
  exits, or stable flow evidence.
- Field + Task + Unknown determine Capability Requirement; Model does not.
- Field Rule does not create Goal, Decision, Action, Role, Emotion, or B.
- Reducer remains the sole State mutation authority.

No Prediction, automatic planning, Action Runtime, real model, OCR, SLAM,
Camera, Hardware, Social Relationship, Role, Emotion, or B Runtime is included.

Dynamic Direction and Dynamic Flow Pattern remain candidates. No automatic
planning, No Action Runtime, No real model, No OCR, No SLAM, No Camera, No
Hardware, No Social Relationship, No Role, No Emotion, and No B Runtime are
included.
