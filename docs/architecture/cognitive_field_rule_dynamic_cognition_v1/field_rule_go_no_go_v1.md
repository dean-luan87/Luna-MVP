# Field Rule / Dynamic Cognition Go / No-Go v1

## Required readiness checks

- Cognitive Field includes Physical, Entity, Spatial, Rule, and Dynamic layers.
- Rule types include Physical Rule, Functional Rule, Social Rule, Legal Rule,
  and Temporary Rule.
- Rule Candidate is separated from Reality Fact and retains Evidence,
  Confidence, Provenance, Validity, Scope, and Unknown.
- Human Flow represents Density, Direction, Flow Pattern, entry, exit, queue,
  gathering, dispersal, and evacuation candidates.
- Crowd Following Strategy is a low-information risk-reduction candidate, not
  blind following, Prediction, Decision, or Action.
- Information Source Candidate can seek service desks, signs, maps, people,
  exits, or other governed sources.
- Field + Task + Unknown generate Capability Requirement Candidate; Model and
  Provider cannot define the requirement.
- Attention receives Rule/Dynamic bias candidates without Goal or Decision
  mutation.
- Reality remains Evidence-first and the Reducer remains the sole State
  mutation authority.

## Explicit prohibitions

No Role, No Emotion, No Social Relationship, No B Route, No Prediction, No
automatic planning, No Action Runtime, No real model, No OCR, No SLAM, No
Camera, No Hardware, No automatic execution, No direct Reality mutation, No
direct Goal mutation, and No direct Decision mutation.

The Agent performs V0 static checks only, does not run the Final Phase
Verifier, and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.

No automatic planning, No Camera, and No direct Goal mutation are permitted.
