# Crowd Following Strategy v1

## Boundary

Crowd Following is a candidate risk-reduction strategy for low-information
environments. It is not blind following, a Decision, a Goal, a prediction, or
an Action.

## Candidate flow

```text
Unknown High
      ↓
Information Source Candidate
      ↓
Observe Crowd Density / Direction / Flow Pattern
      ↓
Estimate Low Risk Path Candidate
      ↓
Acquire More Evidence
      ↓
Situation / Option Reassessment
```

The candidate preserves alternative sources, flow uncertainty, rule
confidence, Capability limits, and provenance. It may request OCR, spatial
Evidence, human confirmation, or additional observation through Capability
Governance. It cannot directly follow, move, or execute.

## Safety boundary

Crowd behavior never overrides Constitution, Survival, Brain authority,
Evidence, or explicit Unknowns. A dense flow can be a queue, evacuation,
gathering, or unrelated movement; the Field Rule remains a candidate until
supported.

No automatic planning, Prediction, Action Runtime, Role, Emotion, Social
Relationship, B, or real model is included.

Crowd Following is not a Decision, not a Goal, not a prediction, and not an
Action. Rule confidence and spatial Evidence remain explicit. It does not
directly follow and does not execute. No Prediction, No Action Runtime, No
Role, No Emotion, No Social Relationship, and No B are included.

Crowd Following is not an Action. Rule confidence and spatial Evidence are
explicit. It does not directly follow.

Rule confidence is explicit. No Role is included.

The rule confidence value remains explicit.
