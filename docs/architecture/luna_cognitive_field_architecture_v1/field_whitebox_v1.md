# Cognitive Field Whitebox

The Field is a subject-bound interpretation space, not a second Reality store. Its components are independently sourced and retain provenance, confidence, and unknowns. Memory and Knowledge contribute context; Self and Social Self contribute constraints and position; Brain receives a composed context package.

This phase freezes the A Route Field and a future B Route interface only. No Field Runtime, World Model, Emotion Runtime, Role Runtime, Memory Consolidation, Learning, Action, or simulation engine is implemented.
