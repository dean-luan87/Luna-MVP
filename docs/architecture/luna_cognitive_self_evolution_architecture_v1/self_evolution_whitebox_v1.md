# Self Evolution Whitebox v1

| Question | Answer |
|---|---|
| Who creates experience candidates? | Experience Consolidation from outcome, expectation difference, and feedback. |
| Who extracts patterns? | Pattern Extraction from repeated, traceable evidence. |
| Who proposes strategies? | Strategy Evolution; candidates only. |
| Who assesses capability growth? | Capability Growth from performance evidence and failure attribution. |
| Who writes the profile? | An admitted evolution update through the Profile owner; not a provider. |
| Who reviews adoption? | Evolution Governance and the authorized Brain/Governance review boundary. |
| Who can revoke? | Evolution Governance through an explicit review/revocation path. |
| What remains immutable here? | Constitution, Identity, Value, Goal ownership, model parameters, and current Reality. |
| What remains unknown? | Any capability or pattern lacking sufficient evidence. |

The whitebox is a control description, not an implementation authorization.
