# A-Route Bridge Contract

Implementation: `run_boundary_v1.py`, `assess_a_route_bridge_readiness_v1`.

The bridge accepts a validated evaluation case and records which refs are supplied to the existing A-Route ingress target. It does not create Attention, Information Need, Observation strategy, Current World, Hypothesis, Sufficiency, Information Gap, Re-observation, Stop Reason, or Decision.

The synthetic fixture returns:

`status=PARTIAL`

because the current repository evidence does not establish a general real A-Route cognitive ingress or runtime cognitive event stream. This is an honest readiness result, not a failed synthetic test and not a runtime claim.

The Dataset Registry's `runtime_allowed=false` means the registry is not a runtime owner. It does not prevent an explicitly governed evaluation boundary from presenting controlled sample references to an approved evaluation/A-Route ingress in a later phase.
