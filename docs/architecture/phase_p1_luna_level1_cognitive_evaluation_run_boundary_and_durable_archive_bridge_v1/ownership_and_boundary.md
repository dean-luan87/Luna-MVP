# Ownership and Boundary

| Concern | Owner | Evaluation role |
|---|---|---|
| Dataset/sample declaration | Evaluation Governance | Validate and reference. |
| Level-1 case composition | Evaluation Governance | Supply controlled inputs; do not perform cognition. |
| Goal/Concern/Role/Field | Existing Luna owners / test case authority | Reference only. |
| Attention, Observation planning, Current World, Hypothesis, Sufficiency, Information Gap, Re-observation | Existing Luna cognitive owners | Observe only; no creation or mutation by this module. |
| Capability/Model/Provider admission and binding | Existing governance owners | Reference only. |
| White-box trace/profile/gap observation | Evaluation | Attach existing V1 refs; no runtime ownership. |
| Durable evaluation history | Evaluation Governance | Append immutable records. |
| TestBoard protection | TestBoard | Protect artifacts; no cognition or archive authority. |
| Memory/Experience/Knowledge | Their canonical owners | No promotion. |

Core rule: the bridge composes references; the authority that owns a semantic state remains responsible for it.
