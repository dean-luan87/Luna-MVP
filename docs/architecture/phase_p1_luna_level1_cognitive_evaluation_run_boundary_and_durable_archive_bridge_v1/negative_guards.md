# Negative Guards

The implementation rejects or records false for:

- missing Dataset/Sample/Case linkage, registry membership, version consistency, required Goal/Concern, conditions, perturbations, capabilities, or observation budget;
- invalidation on the input Dataset/Sample;
- non-evaluation or runtime-enabled Dataset/Sample/Case;
- A-Route bridge cognition ownership;
- fabricated unavailable metrics;
- synthetic fixture claiming cognition execution;
- model/provider/Observation/Action execution;
- World Truth, Field mutation, Memory, Experience, or Knowledge promotion;
- archive writes to `_eval_out` or `_tmp_eval_out`;
- silent overwrite of an existing archive identity.

`false` execution flags are boundary assertions that no execution occurred, not substitutes for unavailable measurements.
