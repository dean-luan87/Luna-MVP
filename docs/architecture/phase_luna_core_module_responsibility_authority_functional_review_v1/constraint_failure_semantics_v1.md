# Constraint Failure Semantics v1

| Status | Owner |
|---|---|
| SAFETY_BLOCKED / SAFETY_REVOKED / SAFETY_RISK_UNRESOLVED | Safety/Brain policy/enforcement |
| PERMISSION_BLOCKED / EXPIRED / REVOKED / SCOPE_MISMATCH | Permission governance/enforcement |
| RESOURCE_BLOCKED / DEGRADED / EXHAUSTED / RESERVATION_FAILED | Resource governance plus runtime enforcement |
| POLICY_STALE / SOURCE_VERSION_MISMATCH | policy/source-version boundary |

Statuses are admission facts/candidates, not semantic conclusions.
