# A Negative Boundaries

A must not:

- govern Goal;
- admit, reject, merge, split or supersede Concern;
- issue or revoke global grants;
- own Semantic Working Outline construction;
- mutate Intent, Task, Role, Field, Context or Current World;
- schedule Attention;
- select model or Provider;
- perform Runtime Admission or Provider invocation;
- execute Observation;
- own Loop persistence;
- perform final Brain assimilation;
- execute external Action;
- mutate Memory/Experience;
- perform Learning or semantic compression;
- declare World Truth.
