# A / B-CR Boundary

## A owns

- detecting bounded uncertainty that justifies contingency reasoning;
- deciding why B is requested;
- defining question, scope, depth, branch, safety, permission and resource limits;
- issuing the request within A's grant/derived B grant boundary;
- receiving and evaluating B's result;
- adopting, partially using, retaining, superseding or discarding it;
- requesting a new B candidate when needed.

## B owns

- bounded contingency computation inside the request;
- termination compliance;
- returning a non-binding candidate result to A;
- reporting stale source, revoked grant, limits or residual uncertainty.

B cannot self-initiate, recursively invoke itself, control Loop, mutate Concern, declare Truth, select final Need/Sufficiency/Continuation, or adopt its own output. Malformed B output is B responsibility for production validity and A responsibility for rejecting/non-adopting it.
