# Decision / Action Adjudication Summary v1

| Boundary | Disposition | Timing |
|---|---|---|
| Decision Governance | NARROW independent commitment boundary | CONTRACT_ONLY / RUNTIME_CONSOLIDATION_LATER |
| Action Governance | NARROW independent side-effect admission/result boundary | CONTRACT_ONLY / RUNTIME_CONSOLIDATION_LATER |
| Task→Action | KEEP as organization-to-candidate handoff | migration later |
| Capability/Runtime/Provider | KEEP existing owners | no reassignment |
| Outcome Evaluation/Brain | KEEP candidate evaluation/final adjudication split | no reassignment |

Target flow: `A local disposition → DecisionCandidate → Decision Governance →
approved Decision → Task → Action Candidate → Action Governance →
Capability/Runtime Admission → Provider → Action Result → Field/Current
World/Task/A evaluation → Outcome Candidate → Brain adjudication`.

Narrow direct Decision→Action is allowed only under the documented bounded
simple-action conditions and never bypasses Action Governance.

Documentation only. Runtime, types, enums, owners, Provider, Action, Runner
and Verifier were not changed or executed.
