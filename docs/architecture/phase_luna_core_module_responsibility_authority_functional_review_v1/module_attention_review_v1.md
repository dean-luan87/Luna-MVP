# M11 Attention — Module Review

## Identity and purpose

Canonical name: Attention Allocation / Attention Governance. Evidence: `situation_understanding/attention_allocation/` (budget manager, policy, value assessment, scan, adapter) and attention-gated RI dryrun assets, plus cognitive-state attention types. If removed, Luna loses policy-constrained focus/observation prioritization and budget candidates.

## Functions and authority

`CORE`: allocate/prioritize candidate focus under policy and budget. `SUPPORTING`: value assessment, scan, observation attention plan. `COMPATIBILITY_ONLY`: dryrun visual attention overlays. Attention has `CANDIDATE_ONLY` prioritization authority within its policy; it does not own Goal, cognitive Need, sufficiency, observation execution, Capability resolution, or Action. Brain owns global resources; A determines what information is missing; Observation/FPO admits/acquires.

Responsibility is priority/budget candidate validity, not semantic answer correctness. A evaluates whether an attention result addresses its Requirement.

## Inputs, outputs, state, lifecycle

Inputs: Brain/resource policy, field/context/current-world refs, A requirement/observation hints, available capability refs. Outputs: focus/priority/budget candidates to Observation/FPO and A. State is candidate policy/reference state. Lifecycle: plan → prioritize → admit/acquire externally → update/supersede.

## Communication and negative boundaries

Allowed: Brain policy→Attention, A requirement→Attention, Field/Context→Attention, Attention→Observation/FPO/A refs. Forbidden: Attention→Need creation, Attention→Loop cognition, Attention→Provider direct, Attention→World Truth. Known ambiguity is the phrase “what to observe”: semantic missing-information ownership is A, prioritization is Attention, execution is Observation/FPO.

## Walkthroughs

1. Normal: A requests missing evidence; Attention ranks candidate focus; Observation admits.
2. Budget/resource block: Attention returns no/degraded priority candidate; A decides replan/wait.
3. Current World change: attention plan is versioned/superseded; A judges whether new evidence is required.

## Overlap, gaps, evolution, disposition

Overlap: `SEMANTIC_OVERLAP` risk with A Need and Observation controller; `IMPLEMENTATION_OVERLAP` with field-centric planning. Gap: explicit A→Attention→Observation bridge and ownership wording. It may evolve as prioritization governance, never a cognitive Need or Observation strategy owner. **Disposition: KEEP / CLARIFY**.

**Ledger summary:** authority = policy-constrained prioritization candidate; responsibility = priority/budget validity; state = candidate; receiver = Observation/FPO/A; confidence = medium.
