# Model Resource, Safety, and Permission Boundary v1

Model contracts may declare expected resource, device, safety, permission, and
operational restrictions. Brain/global governance owns policy; Diagnostics
observes facts; Resource/Safety/Permission Governance owns constraints;
Runtime/Provider Admission enforces them.

Model Governance does not allocate GPU/CPU/memory, grant permission, or
override Safety. Attention may provide quality/latency/budget constraints that
Runtime Admission evaluates.
