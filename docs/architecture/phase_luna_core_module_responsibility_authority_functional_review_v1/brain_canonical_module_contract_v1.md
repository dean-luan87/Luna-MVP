# Brain Canonical Module Contract v1

## Canonical one-line purpose

**Brain is Luna's global cognitive-subject governance boundary: it governs why cognition is undertaken, which global constraints and authorities apply, and how outcomes are globally adjudicated and assimilated, while not performing Concern-local reasoning or capability execution.**

## Why Brain exists

Brain is the only target owner that can connect Goal, Concern, global priority, safety/permission/resource policy, authority grants, and final global adjudication. Without it, local A reasoning could proceed without a global governance boundary and outcomes could not be assimilated into the governed cognitive subject.

## Core responsibilities

1. Self Governance — `CORE`.
2. Goal Governance — `CORE`.
3. Concern Governance — `CORE`.
4. Authority / Grant Governance — `CORE`.
5. Global Constraint Governance — `CORE` (Safety, Permission, Resource, global priority).
6. Outcome Adjudication & Assimilation — `CORE`, with Outcome Evaluation Governance retaining outcome-evaluation production.

## Authority and responsibility

Brain may authoritatively admit, suspend, supersede, merge, defer, or terminate Goals and Concerns; issue/revoke/expire grants; apply global safety, permission, resource, and priority policy; and accept/reject/defer/assimilate global outcomes. Each decision carries responsibility for the governance decision and its error path. Brain does not inherit responsibility for local A reasoning, B bounded compliance, Provider execution, or Loop mechanics.

## State

Brain may own authoritative global Goal/Concern governance state, active grants, global policy, and adjudication records. It must reference rather than duplicate Field, Context, Current World, Role, Task, Intent, Memory, Experience, model, or Provider state. Current repository implementations are metadata/candidate governance, not a unified runtime subject.

## Initiation and result return

Brain initiates admitted cognitive work by issuing a grant or governance instruction. A returns local semantic decisions and outcomes; B returns only to A; Capability/Observation return evidence through their contracts; Loop returns mechanical persistence refs. Brain owns the final global result receiver and governance error boundary.

## Disposition

`KEEP`. This is a target contract, not a runtime implementation.
