# Role / Perspective / Attention / Capability Boundary v1

Role/Perspective can affect relevance and permission applicability. They do
not schedule Attention, select Capability, select a model/provider, perform
Runtime Admission, or execute Observation.

Target path:

`Role/Perspective refs → Semantic/A relevance impact → Attention priority
candidate → Observation/Capability governed admission`.

Permission Governance and Brain policy decide actual permission; Role only
provides identity/relationship evidence.
