# Task Negative Boundaries v1

Task must not become:

- Goal, Concern, or global priority governance;
- Intent owner or Intent mutator;
- A Need/Hypothesis/Sufficiency/Reconsideration/B authority;
- Semantic Working Outline owner;
- Attention scheduler or Observation executor;
- Capability resolver, Runtime Admission owner, model/provider selector;
- Decision maker or Action executor;
- Cognitive Loop controller;
- Memory/Experience writer, learner, or World Truth authority;
- global Planner or Scheduler.

Task may only carry governed refs and constraints for these domains.
