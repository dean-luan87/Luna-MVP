# Intent Governance Adjudication Summary v1

## Decision

**KEEP** as an independent canonical module. Implementation timing:
`CONTRACT_ONLY / DEFER_RUNTIME`.

## Canonical summary

Intent is a governed directed purpose/orientation/commitment. Intent
Governance owns Intent identity, admission, version, coexistence and lifecycle
and returns refs/handoffs to the rest of Luna. Brain governs Goals, Concerns
and global constraints; A reasons locally under an Intent ref; Task organizes
execution; Semantic Module represents Intent relations; State Formation aligns
refs; Loop persists supplied refs mechanically.

## Main flow

`Goal/Brain + source candidates → PotentialIntent → IntentCandidate → Intent
Governance admission/lifecycle → Intent ref/version → Working Envelope /
Cognitive Snapshot → Semantic representation + A reasoning → governed
Concern/Task/Capability handoffs`.

The candidate implementation proves the boundary but not the complete runtime.
No runtime, canonical type, enum, owner, provider, test or runner changed in
this adjudication.
