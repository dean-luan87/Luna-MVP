# Working Envelope Context, Role, Intent, and Task Boundary v1

Context describes the situation under which reality is used; the Envelope is
the admitted cognitive-work input set. Context is a source to the Envelope.

Role remains source-governed. Perspective Projection Function and Result are
external derived boundaries; the Envelope carries refs, versions,
applicability, and provenance but performs no projection.

Intent Governance owns Intent lifecycle. Task owns execution organization.
The Envelope carries their admitted refs and constraints. Intent or Task
changes may invalidate applicability, but the Envelope never mutates either
source or decides the semantic consequence.
