# Semantic Module Canonical Contract v1

## Canonical one-line purpose

**Semantic Module constructs, expands, organizes, and folds the semantic working outline that defines the cognitive work environment for a Concern, while not deciding what is true, what is sufficient, or what action or capability should be taken.**

## Why this module exists

Without this boundary, Goal, Concern, Intent, Role/Perspective, Field, Context, Current World, Task, Behavior, Emotion, Attention, Safety, Permission, Resource, and Experience/Memory refs remain distributed and inconsistently projected into cognition. The unique responsibility is to create one bounded, traceable semantic working representation for Brain/A and a future Experience/Short-Path Filter.

The responsibility is sufficiently distinct to justify a module boundary, but the repository currently contains a contract/deferred concept rather than a unified Semantic runtime.

## Final disposition

`NARROW`.

Implementation timing: `CONTRACT_ONLY` / `DEFER_RUNTIME`. The module is retained, but its authority is explicitly limited to semantic working-environment transformation.
