# Working Envelope Brain, Concern, and Grant Boundary v1

Target admission:

```text
Brain-admitted Concern + valid cognitive-work Grant + global constraints
        → Working Envelope candidate
        → binding validation/admission
```

Brain owns Goal, Concern, Grant, global Safety, Permission, Resource, and
Priority. The Envelope records and binds those refs. It does not create
Concern, issue Grant, alter priority, or judge Goal significance.

Concern and Grant mismatch, expiry, or revocation invalidate the binding.
Brain owns the global consequence; the Envelope reports invalidity only.
