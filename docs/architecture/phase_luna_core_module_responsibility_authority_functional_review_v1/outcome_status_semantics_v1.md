# Outcome Status Semantics v1

Existing candidate vocabulary supports MATCH, PARTIAL_MATCH, MISMATCH,
UNKNOWN, CONTESTED, COMPARABLE, PARTIALLY_COMPARABLE, NOT_COMPARABLE,
INSUFFICIENT_EVIDENCE, STALE_ACTUAL, STALE_EXPECTATION and
NEEDS_CONFIRMATION.

These are Outcome Evaluation statuses, not Brain final decisions. They must
preserve mixed/uncertain results rather than collapse them to Boolean success.
