# A → Decision Boundary v1

A remains the sole Concern-local reasoning authority. It emits Need,
Hypothesis, Sufficiency, Reconsideration and local Next-step results and may
produce a `DecisionCandidate`, recommended action direction, defer/stop or
escalation candidate.

The default target is `A recommendation → Decision Governance commitment`.
A does not create an authoritative Decision merely by reaching a local
disposition and never executes Action. If additional cognition is needed, the
path returns to A/Brain rather than Decision becoming another reasoner.
