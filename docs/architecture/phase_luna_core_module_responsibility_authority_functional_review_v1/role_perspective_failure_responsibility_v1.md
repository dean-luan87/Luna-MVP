# Role / Perspective Failure Responsibility v1

Source Role governance owns identity collision, invalid lifecycle/version,
provenance loss, cross-role contamination, and unauthorized Role mutation.

The derived projection boundary owns invalid Perspective binding and version
assembly. Semantic Module owns projection/transformation error. A owns
reasoning consequence. Intent Governance owns Intent lifecycle. Task owns Task
readiness. Attention owns priority. Permission/Safety owners own policy.

Failures should return missing, unknown, stale, conflicting, degraded, or
invalid-provenance candidates. The system must not fabricate Role or
Perspective.
