# Cross-Constraint Conflict v1

Conceptual precedence:

1. Hard Safety prohibition/emergency override.
2. Hard Permission prohibition/revocation.
3. Grant scope and source-version validity.
4. Protected Resource ceiling/reserve.
5. Resource optimization/degradation.
6. Local Attention/Task/Decision priority.

The ordering governs admission precedence, not semantic outcome. Conflicts
produce explicit blocked/degraded/uncertain refs and return consequences to
A/Decision/Brain.
