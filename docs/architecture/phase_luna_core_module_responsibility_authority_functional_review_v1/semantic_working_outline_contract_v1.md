# Semantic Working Outline Contract v1

## Definition

The Semantic Working Outline is a versioned, candidate/local-derived representation of admitted source references and their bounded semantic relationships for one Brain-governed Concern. It is not authoritative source state, a final judgment, a plan, or a memory record.

## Structured contents

- Goal ref and Concern ref;
- Intent ref;
- Role/Perspective projection refs;
- Field, Context, and Current World refs;
- Task and Behavior constraints;
- Emotion modulation and Attention refs;
- Safety, Permission, and Resource constraints;
- Experience/Memory prior refs;
- temporal/spatial continuity refs;
- semantic relations and relation provenance;
- unresolved semantic elements and ambiguity candidates;
- source-state versions, outline version, trace, and provenance.

## Ownership separation

Source owners retain authoritative refs. Semantic Module owns only derived outline structure/candidates. A owns local reasoning fields: Need, Hypothesis judgment, evidence relevance, Sufficiency, Reconsideration, Next-step, Capability/Observation requests, and B decisions. Brain owns Goal/Concern/global governance.

## Invariants

- No authoritative Field/Context/Current World/Intent/Task/Memory copy.
- Every derived relation retains source refs and version lineage.
- Unknown, stale, or conflicting inputs remain represented as uncertainty/degradation.
- Outline output cannot directly command Loop, Capability, Observation, Provider, or Action.
