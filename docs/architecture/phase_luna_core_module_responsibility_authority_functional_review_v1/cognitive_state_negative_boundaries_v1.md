# Cognitive State Formation Negative Boundaries

State Formation must not:

- govern Goal or Concern;
- select Need;
- own active Hypothesis;
- judge Sufficiency, Reconsideration or Next-step;
- own Semantic expansion/folding;
- mutate Intent, Task, Role, Field, Context or Current World;
- schedule Attention;
- select Capability/Provider;
- execute Observation;
- control Loop;
- create Decision/Action;
- declare World Truth;
- mutate Memory/Experience;
- perform Learning.
