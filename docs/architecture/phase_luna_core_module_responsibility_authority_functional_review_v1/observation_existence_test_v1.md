# Observation Existence Test v1

| Architecture | Finding |
|---|---|
| Embedded in A | A gains acquisition/runtime responsibility |
| Embedded in Attention | priority becomes execution and evidence ownership |
| Embedded in Capability | logical capability boundary absorbs acquisition scope/result |
| Embedded in Provider | provider decides request semantics and evidence return |
| Independent narrow Observation | modality-independent request, freshness, correlation and result boundary |
| Request contract only | no owner for lifecycle, stale/cancelled handling or result correlation |

An independent boundary is justified, provided execution remains Provider-owned
and semantic interpretation remains A-owned.
