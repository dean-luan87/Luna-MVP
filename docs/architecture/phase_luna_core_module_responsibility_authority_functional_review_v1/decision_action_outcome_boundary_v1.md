# Decision / Action / Outcome Boundary v1

`A local disposition → DecisionCandidate → Decision commitment → Task or
narrow direct Action candidate → Action admission/execution → Action Result →
Task/A evaluation → OutcomeCandidate → Brain final adjudication`.

Decision selects/commits what should be done. Task organizes it. Action
Governance admits a concrete side effect. Provider executes. Outcome Evaluation
compares expected and actual candidates; Brain adjudicates globally.

Action Result, Task Completion, A local sufficiency and Outcome are distinct
domains.
