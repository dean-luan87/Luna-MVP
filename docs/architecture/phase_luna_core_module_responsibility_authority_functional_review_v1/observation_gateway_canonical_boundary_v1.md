# Observation Gateway — Canonical Boundary v1

Observation Gateway normalizes ingress, forms Evidence and Observation
candidates, validates/admit/rejects stale/malformed/duplicate evidence,
preserves trace/provenance and emits downstream routing refs.

Repository guards explicitly prohibit Provider/model execution, Field/Context/
Attention/Hypothesis/Intent/Decision/Task/Memory mutation, Learning,
World Truth, scheduler and device control.

Disposition: **KEEP** as a narrow Evidence/Observation admission and routing
boundary.
