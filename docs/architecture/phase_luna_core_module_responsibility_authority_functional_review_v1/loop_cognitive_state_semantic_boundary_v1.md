# Loop / Cognitive State / Working Envelope / Semantic Boundary

Loop may store refs to Working Envelope, Semantic Outline, Cognitive Snapshot and source versions. It may mechanically validate identity/ref/version shape and scope.

Loop must not:

- assemble snapshots;
- transform/expand/fold semantic outline;
- decide semantic sufficiency;
- interpret stale/partial/degraded snapshots;
- infer cognitive recovery or replan.

Cognitive State Formation assembles candidate snapshots; Semantic Module transforms semantic representation; A judges cognitive consequence.
