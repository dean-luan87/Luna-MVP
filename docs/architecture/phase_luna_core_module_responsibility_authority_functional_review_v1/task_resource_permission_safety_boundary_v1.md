# Task / Resource / Permission / Safety Boundary v1

Brain/global governance owns policy, priority, safety, permission, and
resource authority. Task carries scoped constraints and readiness refs and may
become blocked, waiting, or not-ready when supplied governance state disallows
execution.

Task cannot override, issue, revoke, or reinterpret global policy. A Task
block is an execution-organization result; it is not a global adjudication or
A semantic disposition.
