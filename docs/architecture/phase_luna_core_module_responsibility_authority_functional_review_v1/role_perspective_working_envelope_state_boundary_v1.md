# Role / Perspective / Working Envelope / State Boundary v1

Working Envelope carries read-only `role_refs`, current Perspective input and
projection refs, Context/Intent/Task/Concern refs, applicable governance
constraints, augmentation versions, source versions, applicability refs and
provenance. Emotion is not a current Perspective input; any future Emotion ref
belongs to a separately adjudicated modulation boundary. The envelope does not
duplicate Role or base world state and does not perform Perspective
computation.

Cognitive State Formation carries projection refs, augmentation version and
source-version lineage in a candidate snapshot and may detect stale or missing
versions. It does not own Projection computation. It cannot decide whether a
Role change means Need change, Reconsideration, Task block, or Intent change.
A decides cognitive consequence; Brain decides global consequence.

World ontology remains stable: a working overlay is never an authoritative
copy or rewrite of base information.

Ordering is not a new strict serial authority chain. The target is:

`Working Envelope → Semantic Working Outline` and
`Working Envelope → Cognitive Snapshot Formation` as version-linked sibling
derived products → `A`.

Perspective Projection Result enters as an admitted/derived ref in this
linked flow. Working Envelope, Cognitive State Formation, and Semantic Module
do not thereby acquire Perspective authority.
