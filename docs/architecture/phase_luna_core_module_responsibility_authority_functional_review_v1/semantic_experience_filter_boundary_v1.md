# Semantic Module — Experience / Short-Path Filter Boundary

## Target flow

Semantic Working Outline → Experience / Short-Path Filter → direct-resolution or short-capability candidate / A boundary.

Semantic Module prepares structure. A future Experience/Short-Path Filter may compare that structure with read-only prior Experience/Memory and produce match, mismatch, hit-rate, or short-path candidates.

## Ownership

Semantic Module does not decide direct resolution, short capability execution, or that an experience match is sufficient. Experience/Memory remains read-only prior/governed candidate input. A decides whether the comparison resolves the Concern, changes Need, or establishes Sufficiency.

## Current status

No unified Experience/Short-Path Filter runtime was found. This is a `RUNTIME_GAP` and `ADAPTER_GAP`, not permission for Semantic Module to absorb the Filter or A's judgment.
