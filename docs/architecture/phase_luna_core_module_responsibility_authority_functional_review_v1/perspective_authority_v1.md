# Perspective Authority v1

Perspective is a dynamically augmented working view, not a second identity
system. Its Projection Function derives additional working attributes and
relations; its Projection Result is a versioned candidate/derived view.

- Current Perspective inputs are Role, Context, Intent, Task, Concern, and
  applicable governance constraints. Emotion is deferred and is not a current
  conditioner or Projection input.
- Brain may constrain applicability for global safety, permission, resource,
  or Concern policy.
- A may request or adopt a local reasoning perspective for a cycle.
- Perspective Projection derives conditionally available attributes before
  semantic organization.
- Semantic Module organizes the admitted base and augmented information.
- Cognitive State Formation carries projection refs, augmentation version and
  source-version lineage.
- B may explore hypothetical perspectives inside its bounded request.

A local hypothetical frame, such as “from the shop employee’s perspective,”
does not mutate authoritative Role or create a persistent Perspective state.
Augmentation is evidence/relationship/source-derived and cannot fabricate
information. Any future Emotion integration requires a separately adjudicated
Modulation / Arbitration / Self-Regulation boundary.
