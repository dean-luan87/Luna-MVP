# Shared Information / Perspective Overlay Principle v1

## Canonical principle

**Shared Information Once, Perspective Augmentation Many.**

**世界本体稳定原则：** 世界本身不因观察角色或情感状态发生改变。

**角色/情感条件化属性增强原则：** 角色与情感基于既有对象属性、关系、
能力、记忆与上下文信息，对当前 working view 附加新的条件化属性；附加结果
不得反向污染世界本体。

## Retrospective projection

`Existing shared information + New Role → New Role-conditioned augmentation`

Adding a Role must not require re-perceiving historical information,
re-recognizing entities, duplicating Field/World state, or creating
Role-specific Memory objects. Only the derived working overlay changes.

An augmentation cache, if implemented later, is derived, versioned,
invalidatable, and disposable. Cache loss must not destroy base information.
