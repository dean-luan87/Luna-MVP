# Loop / B-CR / Task / Intent Boundary

## B-CR

B cannot issue Loop commands. Loop may record B request, branch, result or pending refs only from A/Brain supplied commands.

## Task

Task owns behavior constraints, dependencies, readiness and completion organization. Loop owns cognitive-work persistence. Task may pause independently; Loop may pause while Task remains active. Task completion does not automatically close cognition; Loop closure does not automatically mutate Task completion.

## Intent

Intent Governance owns Intent. Loop may reference Intent/version. Intent supersession can lead to Brain/A semantic closure, after which Loop applies the supplied mechanical consequence. No direct Intent→Loop mutation bypass is valid.
