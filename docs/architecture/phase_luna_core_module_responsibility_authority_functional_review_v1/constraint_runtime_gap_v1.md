# Constraint Runtime Gap v1

## Evidence

Brain documents define global Safety/Permission/Resource policy and Grant
authority. Safety Constitution and Survival Constitution preserve conservative,
non-harm, consent, uncertainty and minimum-viable principles. Action types
carry permission/safety rechecks and resource status. Runtime Admission carries
permission/resource/safety refs. Diagnostics and resource contracts provide
facts/candidate allocation without execution.

## Gaps

- `OWNER_GAP`: no new Manager required; all three are Brain-owned sub-boundaries with distributed enforcement.
- `CONTRACT_GAP`: unified cross-constraint policy/version precedence and revocation handoff.
- `ADAPTER_GAP`: Brain→Working Envelope/Grant→all admission points.
- `RUNTIME_GAP`: no emergency override, resource enforcement, or permission runtime is implemented here.
- `LEGACY_OVERLAP`: Attention policy flag, MONC/Constitution variants, navigation/speech guards.
- `TERMINOLOGY_GAP`: Policy, Grant, Permission, Admission, Budget, Reservation, and Availability overlap.
