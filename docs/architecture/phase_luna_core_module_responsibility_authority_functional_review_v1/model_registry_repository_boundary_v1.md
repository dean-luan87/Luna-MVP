# Model Registry and Repository Boundary v1

Model Registry is the authoritative metadata repository for registered model
identity, assets, versions, declarations, and lifecycle references. Model
Manager/Governance is the authority for registration, change, lifecycle,
provisioning, and retirement. The repository is storage/contract
implementation, not an independent architecture owner.

Filesystem is physical state. Runtime is execution state. Neither directory
layout nor a Provider registry replaces Model Governance.
