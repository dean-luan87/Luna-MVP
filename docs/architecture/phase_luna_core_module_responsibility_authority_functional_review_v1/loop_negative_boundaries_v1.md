# Loop Negative Boundaries

Loop must never receive or exercise authority to:

- select Need;
- generate/activate Hypothesis;
- judge Sufficiency or Reconsideration;
- decide Next-step;
- select Capability/Provider;
- request B or adopt B result;
- split/merge Concern;
- declare Truth;
- adjudicate final Outcome;
- mutate Goal, Intent, Task, Field, Context, Current World, Memory or Experience;
- execute Observation, Provider, Decision or Action;
- perform Learning or semantic compression.

These are capability-boundary violations, not ordinary absent permissions.
