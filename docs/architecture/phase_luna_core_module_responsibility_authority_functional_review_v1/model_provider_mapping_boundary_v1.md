# Model Provider Mapping Boundary v1

Model Governance may declare `Model Asset ↔ Provider Family/Adapter/Loader`
compatibility metadata. Provider Governance owns Provider identity, admission,
invocation, session, and runtime execution.

Model Governance does not select or invoke Provider. Provider does not own
model files, checksums, or model lifecycle. Mapping records preserve model,
adapter, loader, contract, version, and provenance refs.
