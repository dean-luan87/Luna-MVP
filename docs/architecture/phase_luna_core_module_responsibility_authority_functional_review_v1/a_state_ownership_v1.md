# A State Ownership v1

| State | A classification | Boundary |
|---|---|---|
| Active Need | AUTHORITATIVE_LOCAL | selected under A grant |
| Active/competing hypotheses | AUTHORITATIVE_LOCAL | local reasoning only; not World Truth |
| Sufficiency state | AUTHORITATIVE_LOCAL | Concern-local cognitive judgment |
| Reconsideration record | AUTHORITATIVE_LOCAL | local reasons and invalidations |
| Local reasoning history | LOCAL_DERIVED | versioned/provenanced |
| B request/result evaluation | AUTHORITATIVE_LOCAL | A evaluates; B remains non-binding |
| Evidence relevance refs | LOCAL_DERIVED | source evidence remains external |
| Working Envelope/Outline | REFERENCE_ONLY | source owners remain owners |
| Field/Context/Current World | EXTERNAL | A reads and judges consequence |
| Brain Goal/Concern/grant | EXTERNAL | Brain owns |
| Loop lifecycle | MECHANICAL | Loop owns persistence |
| Memory/Experience | EXTERNAL | read-only prior/candidate |

A must not duplicate authoritative source state or global Brain state.
