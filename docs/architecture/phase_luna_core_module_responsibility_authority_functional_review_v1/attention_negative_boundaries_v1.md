# Attention Negative Boundaries v1

Attention must not:

- own Goal or Concern;
- create Cognitive Need or judge Sufficiency;
- perform A Reconsideration or choose A Next-step;
- mutate Intent, Task, Role, Field, Context or Current World;
- perform Semantic expansion/folding;
- select model/provider or perform Runtime Admission;
- invoke Provider or execute Observation;
- execute Action or control Loop;
- mutate Memory/Experience or perform Learning;
- declare World Truth;
- create a Scheduler or autonomous sampling runtime;
- override Brain Safety, Permission, Resource or Priority policy.

An Attention candidate is not an Observation Request, Capability admission,
Decision, Action, fact or Truth declaration.
