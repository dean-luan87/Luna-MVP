# FPO Existence / Responsibility Review v1

Repository FPO assets cover observation goal/requirement building, information
gap detection, region planning, budget, capability/model handoff, invocation
history, deduplication, result linking, re-observation and visual adapters.
This is a historical composite, not a single clean authority.

FPO should remain a **NARROW** acquisition orchestration/adapter boundary for
turning admitted Observation constraints into provider-facing acquisition
requests, managing bounded invocation correlation and returning result refs.
It must not own Cognitive Need, Attention priority, Capability resolution,
Provider identity/admission, Evidence truth, Current World, Field, A or Task.

No separate new FPO Manager is created by this adjudication.
