# Provider Governance — Canonical Module Contract v1

## Purpose

Provider Governance admits and invokes an implementation runtime for an
already-resolved executable Capability or Action/Observation contract,
enforcing provider compatibility, invocation scope, health, permissions,
resources, safety, session and trace constraints, then returning a Provider
Result.

Provider is not Model, Capability, Observation, Action, Evidence, World Truth,
A reasoning or Brain governance.

## Disposition

**KEEP** as a narrow independent runtime-admission/invocation boundary.
Timing: `CONTRACT_ONLY / RUNTIME_CONSOLIDATION_LATER`.
