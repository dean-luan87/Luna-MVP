# A Reality Thinking Canonical Module Contract v1

## Canonical one-line purpose

**A Reality Thinking is Luna's Concern-local reality reasoning authority: it evaluates the current cognitive situation against admitted reality evidence, determines what is cognitively missing or sufficient, forms and revises local hypotheses, requests bounded additional cognition when necessary, and returns a local semantic disposition without assuming global Brain governance or execution authority.**

## Why A exists

If A is removed, Luna loses the irreducible authority to judge the meaning and sufficiency of current reality for one admitted Concern. Brain governs globally; Semantic Module transforms representation; B-CR explores bounded contingencies; Attention prioritizes; Capability/Observation acquire evidence; Loop persists mechanics. None of those may replace Concern-local semantic judgment.

## Final disposition

`KEEP`.

Implementation timing: `CONTRACT_ONLY` / `DEFER_RUNTIME`. The controlled A decision bridge already proves the boundary, but a unified A runtime and all-caller cutover are not complete.
