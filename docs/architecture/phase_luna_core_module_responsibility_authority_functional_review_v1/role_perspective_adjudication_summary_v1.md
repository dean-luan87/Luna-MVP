# Role / Perspective Adjudication Summary v1

## Decision

**ROLE_REASSIGN + PERSPECTIVE_FUNCTION_KEEP / RESULT_NARROW.** Role is
source-owned governed social identity state. Perspective is a canonical
Projection Function plus versioned Projection Result boundary. No Role Manager
or Perspective Manager is created.

## Canonical flow

`Shared base information + Role/Context/Intent/Task/Concern/applicable
governance constraints → Perspective Projection Function → augmented working
view → version-linked sibling products: Semantic Working Outline and Cognitive
Snapshot → A impact assessment → Intent/Task/Attention effects via governed
refs`.

Brain constrains global applicability; A judges local cognitive consequence;
Semantic transforms; Loop stores refs mechanically. No source directly mutates
Intent, Task, A, Attention, Capability, or Loop.

## Status

World information is not duplicated or rewritten because Role changes. A new
Role projects over existing shared information; it does not re-perceive or
create Role-specific world state. Attribute augmentation is
source/evidence/relationship derived, provenance-bearing and non-authoritative
until A interprets it.

Emotion is deferred, a future modulation source, not a current conditioner or
Perspective input. Its eventual effect on Perspective, Attention, Memory
retrieval, A weighting, Role augmentation, Decision, output, or combinations
requires separate Modulation / Arbitration / Self-Regulation adjudication.

This is a contract adjudication only. Runtime ownership, neural architecture,
identity recognition, Emotion runtime, caching, and propagation adapters remain
future work.
