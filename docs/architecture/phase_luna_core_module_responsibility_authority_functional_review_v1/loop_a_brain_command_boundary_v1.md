# Loop A / Brain Command Boundary

## A → Loop

A supplies semantic decision/ref. The mechanical adapter validates issuer, grant, Concern/Work scope and state versions, then Loop applies the mechanical operation.

## Brain → Loop

Brain may supply accepted global lifecycle decisions such as STOP, SUSPEND, SUPERSEDE, MERGE or revocation consequences. They should enter the same generic authorized mechanical adapter/validator rather than bypassing command validation. No unnecessary orchestration layer is required.

Loop executes mechanics; it does not own the meaning of the supplied command.
