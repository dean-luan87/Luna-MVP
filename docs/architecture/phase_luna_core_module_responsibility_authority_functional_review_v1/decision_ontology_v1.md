# Decision Ontology v1

| Concept | Canonical meaning |
|---|---|
| Goal | Brain-governed global objective/identity |
| Intent | governed directed purpose/orientation |
| Concern | Brain-governed cognitive work identity |
| A Local Disposition | A's local semantic recommendation/next-step |
| Decision Candidate | proposed commitment option, not yet admitted |
| Decision | governed commitment selecting what should be done or not done |
| Task | execution organization for an approved commitment |
| Action | concrete admitted operation with external/system effect |
| Action Result | execution/effect report, not Goal-level success |
| Outcome | evaluated candidate and finally Brain-adjudicated global result |

Decision is neither A's local disposition, Task, Action, nor Brain's final
Outcome adjudication.
