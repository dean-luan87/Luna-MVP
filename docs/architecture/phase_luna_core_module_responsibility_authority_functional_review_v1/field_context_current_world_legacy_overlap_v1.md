## Terminology conflicts

`Field`, `field scene`, `Current World`, `world state`, and `World Truth` are
not interchangeable. Existing `world_state_kind_candidate` and
`active_hypothesis_refs` fields are candidate/compatibility names and must not
be interpreted as new authority.
