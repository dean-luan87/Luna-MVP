# Cognitive State Formation Canonical Module Contract v1

## Canonical one-line purpose

**Cognitive State Formation assembles source-owned and candidate cognitive inputs into a version-aligned, provenance-preserving candidate cognitive snapshot for downstream reasoning, without deciding Need, active Hypothesis, Sufficiency, Reconsideration, or World Truth.**

## Irreducible responsibility

The module's unique responsibility is cross-source snapshot assembly and version alignment: it forms a coherent candidate view from admitted Field, Context, Current World, Observation/Evidence, Attention, hypothesis-related, Intent, Task, Role/Perspective and continuity refs, while preserving source ownership.

## Disposition

`NARROW`. The boundary survives, but “state formation” is restricted to candidate snapshot assembly and alignment. Implementation timing: `CONTRACT_ONLY` / `DEFER_RUNTIME` for further consolidation.
