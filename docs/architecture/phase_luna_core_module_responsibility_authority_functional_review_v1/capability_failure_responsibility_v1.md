# Capability Failure Responsibility v1

Capability Governance owns:

- invalid taxonomy or slot definition;
- incorrect scope assessment;
- incorrect logical resolution;
- capability-side model mapping contract errors;
- cross-capability contamination;
- invalid admission coordination;
- malformed Executable Capability Candidate;
- lost capability version/provenance lineage.

It does not own:

- A Need or Task purpose;
- model-file corruption/provisioning;
- checksum computation or integrity source evidence;
- dependency/device probe correctness;
- Provider execution failure;
- evidence quality or World Truth;
- A Sufficiency;
- Brain policy.

Each failure should retain the source owner and evidence refs instead of being
flattened into generic “capability unavailable.”
