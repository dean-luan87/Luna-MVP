# Cognitive State Observation / Evidence Return Boundary

Canonical path:

`Observation/Evidence → Field/Context/Current World source update → new State Formation snapshot candidate → A reassessment`

After new evidence or source version changes, State Formation rematerializes a candidate snapshot and preserves lineage. It does not judge evidence relevance or Sufficiency. A decides whether the updated snapshot changes Need, Hypothesis, Reconsideration, or Next-step.

Observation/FPO and Provider Governance remain acquisition/evidence owners. Loop may record snapshot/evidence refs only.
