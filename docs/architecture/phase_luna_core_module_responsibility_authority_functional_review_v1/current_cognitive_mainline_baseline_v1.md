# Current Cognitive Mainline Baseline

## Owner map

| Layer | Owner | Boundary |
|---|---|---|
| Governance | Brain | Goal, Concern identity/admission/split/merge, global priority, safety, permission, resources, grants, final adjudication |
| Local cognition | A Reality Thinking | Current Need, hypothesis/evidence relevance, sufficiency, reconsideration, local continuation, B request and B-result evaluation |
| Contingency cognition | B-CR | A-started, bounded, non-binding contingency candidates returned to A |
| Representation | Cognitive State Formation | Candidate attention/hypothesis/current-world/state assembly; no final semantic decision |
| Persistence | Loop | Mechanical identity, refs, versions, lifecycle, history, pause/wait/close/freeze |
| Capability | Capability Governance + Runtime Admission | logical scope/resolution, then evidence-gated executable candidate; no A/Brain provider selection |
| Evidence | Observation/FPO and provider governance | admitted acquisition/execution and evidence return; evidence is not World Truth |
| Constraints/inputs | Intent, Task, Role/Perspective, Field, Context, Emotion, Attention, Experience | source-owned refs and constraints supplied through a working envelope |

## Runtime information flow

Brain admits a Concern and grants bounded authority. A receives an envelope of source-owned refs, reasons locally, and requests evidence/capability categories. Capability Governance resolves logical capability; Runtime Admission assesses readiness; Observation/provider paths return evidence. A reassesses and emits semantic decisions. The A→Loop adapter converts those decisions to mechanical commands. Brain receives outcome/adjudication candidates.

## Closure assessment

The mainline is conceptually reducible to Brain governance, A reality cognition, B-CR contingency cognition, Loop mechanics, capability/observation evidence services, and peripheral context/constraint/prior providers. It is `PARTIAL` as an implementation closure because Brain runtime/API, envelope generation, propagation/invalidation, and semantic retirement remain open.
