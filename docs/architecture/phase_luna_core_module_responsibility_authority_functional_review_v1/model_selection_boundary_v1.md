# Model Selection Boundary v1

Selection layers remain separate:

- Capability Governance: logical functional capability/slot.
- Model Governance: mapped model assets and declaration candidates.
- Runtime Admission: current executable eligibility.
- Provider Governance: concrete provider compatibility/admission.
- A/Decision/Task: semantic or execution preference where applicable.

No monolithic Model Selector is created. A model name must not silently stand
for capability identity, provider identity, or execution authorization.
