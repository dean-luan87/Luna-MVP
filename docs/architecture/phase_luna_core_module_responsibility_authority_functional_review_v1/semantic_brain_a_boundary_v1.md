# Semantic Module — Brain / A Boundary

## Brain boundary

Brain governs which sources and constraints are admitted into cognition, and owns Goal, Concern, grants, global safety, permission, resource, and priority policy. Brain does not perform semantic expansion/folding itself.

Semantic Module transforms admitted refs into the working outline. It does not admit Concern, govern Goal, issue grants, adjudicate outcomes, or mutate global state.

## A boundary

A consumes the outline as semantic working context and remains the local semantic authority for Need, Hypothesis, evidence relevance, Sufficiency, Reconsideration, Next-step, Capability/Observation requests, B requests, and B-result adoption.

Semantic Module may emit:

- expanded relation candidates;
- candidate interpretations;
- ambiguity/collision candidates;
- unresolved semantic slots;
- source/version mismatch records.

A decides the cognitive consequence. The outline is never a substitute for an A decision.
