# Field / Context / Current World World-Truth Boundary v1

## Adjudication

Luna currently has **no single canonical World Truth owner**. The safest
operational interpretation is:

- governed admitted Field state = best-known operational source state;
- Current World = candidate representation for cognition;
- Context = situation frame;
- evidence/provenance = bounded support, not truth itself;
- future truth adjudication, if required, must be separately governed.

## Explicit non-equivalences

`Provider evidence != World Truth`.

`Current World != World Truth`.

`Field-admitted state != metaphysical World Truth`; it is governed operational
state with temporal/provenance limits.

`Perspective augmentation != World Truth`.

`A hypothesis != World Truth`.

## Consequence

No Field, Context, Current World, Observation, Semantic, State Formation or A
path may silently introduce a `WorldTruthManager` or equivalent authority.
Conflict and uncertainty remain explicit candidates for downstream governance
and reasoning.
