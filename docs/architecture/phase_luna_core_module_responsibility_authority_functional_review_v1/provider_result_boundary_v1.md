# Provider Result Boundary v1

Provider Result is raw or structured runtime output: detection, OCR,
transcript, embedding, depth, API/device response, generated audio, status or
error. It carries invocation/provider/model refs where applicable, target,
payload/ref, confidence/runtime metadata, status, timestamps and provenance.

Provider Result is not automatically Evidence, Fact, World Truth, Action
success, Task completion or A Sufficiency.
