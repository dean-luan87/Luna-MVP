# Current World State Ownership v1

| Item | Current World status | Owner |
|---|---|---|
| Candidate identity | authoritative within candidate lineage | Current World formation boundary |
| Candidate/source versions | derived alignment metadata | Current World/State Formation |
| Candidate entities/attributes/relations | derived candidate | evidence/Field refs + formation |
| uncertainty/conflict/temporal status | candidate status/provenance | formation |
| Field state | external authoritative source | Field Reducer/read model |
| Context envelope | external assembled source | Context Foundation |
| Observation/Evidence | external source | Observation/FPO/provider governance |
| active Need/Hypothesis/Sufficiency | external authoritative local reasoning | A |
| Role/Perspective projection | external source/derived ref | Role/Perspective boundary |
| Intent/Task | external authoritative source | respective governance |
| World Truth | no owner established | not created by Current World |

The `active_hypothesis_refs` field in the current candidate type must be read as
a carried input/reference slot. It does not transfer A's hypothesis authority
to Current World or Cognitive State Formation.
