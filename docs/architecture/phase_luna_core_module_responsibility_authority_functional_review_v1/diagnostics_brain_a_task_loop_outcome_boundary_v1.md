# Diagnostics Brain, A, Task, Loop, and Outcome Boundary v1

Brain consumes high-level summaries for degradation, protected capability
availability, survival/minimum viable mode, escalation, and global governance.
A decides Need, relevance, Reconsideration, and Next-step. Task uses diagnostic
refs as readiness/dependency blockers. Loop persists refs and timestamps only.
Outcome evaluates execution/environment consequences but does not mutate
diagnostic state.

Diagnostics does not produce A Next-step, complete Task, close Concern, decide
Goal impact, diagnose Loop, or become Brain.
