# Semantic Transformation vs Judgment

## Semantic Module transformation

Semantic Module may answer representation questions:

- how admitted refs relate in the current working context;
- which semantic dimensions are explicit, implied, unresolved, or ambiguous;
- how Role/Perspective changes a projection;
- how expanded relations can be organized or folded into a bounded outline;
- which source versions or relations collide at representation level.

## A judgment

A answers cognitive decision questions:

- What is the Current Need?
- Which Hypothesis is currently preferred?
- Is evidence relevant and sufficient?
- Is Reconsideration required?
- What is the local Next-step?
- Should Capability/Observation or B-CR be requested?
- Should a B result be adopted, retained, superseded, or discarded?

Semantic Module may expose candidate interpretations, missing semantic slots, ambiguity, collision, and comparison features. It must not convert those into A decisions.
