# Perspective Augmentation Provenance v1

Every augmented attribute should be traceable to:

- base information refs;
- relation refs;
- Role condition;
- no Emotion condition in the current contract; future Emotion provenance is
  deferred to separate adjudication;
- capability or knowledge source, when applicable;
- Context, Intent, Task, and Concern refs;
- source/projection version;
- provenance chain;
- confidence/status when derived.

Required status distinctions include base, relation, derived, conditioned,
stale, invalidated, and unknown. None is promoted to World Truth by the
projection boundary.
