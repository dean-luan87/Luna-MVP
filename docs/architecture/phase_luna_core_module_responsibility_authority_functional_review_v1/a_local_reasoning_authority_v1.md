# A Local Reasoning Authority v1

## Canonical chain

Semantic Working Outline / Cognitive Environment → Current Situation Assessment → Current Need → Hypothesis / competing hypotheses → evidence relevance → Sufficiency → Reconsideration → Next-step → optional B request → B-result evaluation → local semantic disposition.

## A-authoritative elements

- Current Need selection
- local Hypothesis creation, ranking, revision and abandonment
- evidence-to-hypothesis relevance
- local Sufficiency
- Reconsideration
- semantic Next-step disposition
- B request scope at the local reasoning boundary
- B-result adoption/rejection/retention
- Cognitive Requirement formation from Need

These are local decisions under a valid A grant. They are candidate outputs until downstream/global contracts accept them, but their semantic owner is A.

## Non-A elements

Brain owns Goal/Concern/global governance. Semantic Module owns representation transformation. Attention owns priority/budget candidates. Capability/Runtime Admission/Provider own technical execution boundaries. Observation returns evidence. Loop persists supplied mechanics. Decision/Action/Memory/Learning remain separate owners.
