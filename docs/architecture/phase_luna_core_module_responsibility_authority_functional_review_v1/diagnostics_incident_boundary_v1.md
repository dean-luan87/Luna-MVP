# Diagnostics Incident Boundary v1

Diagnostics may form a **Diagnostic Incident Candidate** by correlating
source-linked findings, timestamps, affected components, severity, and
contradicting signals. It remains diagnostic aggregation, not a semantic
incident declaration, policy decision, or remediation command.

Incident resolution, restart, repair, escalation, and user notification belong
to Maintenance/owner-specific governance and Action/Output paths. No Incident
Manager is created.
