# Brain Negative Boundaries

Brain must not:

- select Current Need;
- generate or own local Hypothesis reasoning;
- judge local Sufficiency;
- perform Reconsideration or local continuation;
- start B outside the A-mediated request boundary;
- select Logical Capability, model, or Provider;
- perform Runtime Admission or dependency/integrity/device probes;
- execute Observation or Provider;
- implement Loop persistence or lifecycle mechanics;
- schedule Task execution;
- mutate Intent directly;
- mutate Field, Context, Current World, Task, Memory, or Experience directly;
- perform Learning or semantic compression;
- execute Action;
- declare Evidence or Current World to be World Truth;
- silently turn assimilation into Memory mutation.

Brain may issue governance decisions whose mechanical effect is later applied by Loop, but the implementation boundary remains Loop-owned.
