# Cognitive State Formation / Working Envelope Boundary

## Working Envelope

Working Envelope answers: which source refs, constraints, grants, and versions are admitted into a cognitive work context.

## Cognitive State Formation

Cognitive State Formation answers: what version-aligned candidate snapshot can be assembled from those admitted refs at a particular point in the cycle.

The output may include snapshot id/version, source-ref set, source-version set, assembly status, partial/degraded/stale flags, Current World candidate ref, Attention candidates, hypothesis-related refs, continuity refs, and trace/provenance.

If the Envelope is the only representation and no snapshot/alignment step is required, the two boundaries may be consolidated later. Current source evidence supports keeping them distinct: Envelope is admission/context; Formation is aligned candidate snapshot.
