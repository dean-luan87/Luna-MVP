# Brain Authority Boundary

## Authoritative decisions

| Domain | Brain authority | Explicit non-authority |
|---|---|---|
| Goal | identity, admission, priority, conflict, suspension, termination | direct Provider execution |
| Concern | identity, admission, defer, reject, merge, split governance, lifecycle | local Need or hypothesis reasoning |
| Grants | issue, scope, revoke, expire, global responsibility binding | granting beyond capability/safety/resource policy |
| Global constraints | safety, permission, resource, global priority | low-level dependency/model/device probes |
| Outcomes | global acceptance/rejection/defer/supersede and assimilation | Memory mutation, Learning, World Truth declaration |
| Lifecycle governance | global STOP/SUSPEND/SUPERSEDE/MERGE decisions | Loop persistence implementation |

## Required separation

- Goal → Brain.
- Concern → Brain.
- Current Need → A.
- Hypothesis → A/B reasoning, represented through State Formation candidates.
- Local Sufficiency → A.
- Reconsideration → A.
- B request → A, under Brain grant constraints.
- B result evaluation → A.
- Global final adjudication → Brain.
- Assimilation → Brain governance, with source owners retaining their mutations.

Brain may constrain the envelope and grant, but consuming a source reference does not make Brain its canonical owner.
