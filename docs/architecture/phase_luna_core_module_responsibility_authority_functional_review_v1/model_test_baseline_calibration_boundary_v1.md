# Model Test, Baseline, and Calibration Boundary v1

Test Lens and Calibration may provide benchmark, quality, degradation,
compatibility, and baseline refs. Baseline/Calibration owners define expected
references; Diagnostics reports observed deviation; Model Governance may use
the refs in lifecycle/mapping review.

Evaluation evidence does not automatically mutate identity, register a model,
or admit runtime execution. No tests, benchmarks, or calibration are run here.
