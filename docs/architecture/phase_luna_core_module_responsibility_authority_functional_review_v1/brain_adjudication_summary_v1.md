# Brain Adjudication Summary

## Canonical decision

Brain is retained as Luna's global cognitive-subject governance boundary. It owns Goal and Concern governance, authority/grants, global Safety/Permission/Resource/Priority policy, and global outcome adjudication/assimilation. It does not perform local A reasoning, B contingency reasoning, capability resolution/admission, Provider execution, Observation, or Loop mechanics.

## Goal / Intent / Concern / Task / Need

- Goal: globally governed desired result; Brain owns identity/admission/priority/conflict/suspension/termination.
- Intent: governed purpose/causal handoff; Intent Governance owns it.
- Concern: Brain-governed cognitive work object; A/B work inside an admitted Concern.
- Task: behavior/completion/dependency organization; Task Manager owns it.
- Need: local missing-information/evidence requirement; A owns it.

## Assimilation

Assimilation is Brain's global acceptance and integration of an evaluated outcome into Goal/Concern/global priority/governance state and its handoffs. It is not Memory mutation, Experience mutation, Learning, semantic compression, or World Truth declaration. Outcome Evaluation Governance may construct/evaluate an Outcome candidate; Brain adjudicates globally.

## Repository conflict adjudication

The integrated closure registry names Outcome Evaluation Governance as canonical Outcome owner, while the target mainline names Brain as final adjudicator/assimilation owner. These are compatible when Outcome Evaluation Governance produces/evaluates the candidate and Brain owns final global acceptance/assimilation. Older documents mentioning Brain/Neural/Entity Governance are historical terminology and do not override the verified A/B/Loop boundary.

## Final disposition

`KEEP`.

## Implementation status

Documentation-only target contract. Current implementation gap: unified Brain subject/API, grant propagation, change invalidation, and explicit Outcome→Brain assimilation handoff.
