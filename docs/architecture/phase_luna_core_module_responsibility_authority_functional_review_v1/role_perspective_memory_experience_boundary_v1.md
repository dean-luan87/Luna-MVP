# Role / Perspective / Memory / Experience Boundary v1

Role-conditioned augmentation primarily draws from identity, responsibility,
skill, knowledge, functional duty and capability relevance. Emotion-related
modulation of Memory/Experience is deferred and is not a current Perspective
input or augmentation path.

Memory and Experience may retain Role/Perspective refs when necessary to
preserve event meaning. They do not own Role identity or Perspective
applicability. A new Role can project over existing shared information without
re-recognizing or duplicating the world or historical memory. Historical
association cannot automatically reactivate a Role.

No Memory mutation, Experience mutation, Learning, or semantic compression is
introduced by this contract.

Any future Emotion relation to Memory retrieval or autobiographical relevance
requires separate Modulation / Arbitration / Self-Regulation adjudication.
