# Cognitive Loop Existence Test

| Architecture | Result |
|---|---|
| Independent Loop mechanical engine | strongest separation, resumability, version lineage, isolation and testability |
| Mechanics embedded in A | couples semantic judgment to persistence and increases leakage risk |
| Mechanics embedded in Brain | couples global governance to process bookkeeping |
| Generic persistence store | lacks cognitive identity, authorized lifecycle commands, freeze/history and multi-Concern contract |

An independent Loop remains justified as a mechanical process-thread boundary. It must be narrow and reference-oriented, not a generic reasoning state machine.
