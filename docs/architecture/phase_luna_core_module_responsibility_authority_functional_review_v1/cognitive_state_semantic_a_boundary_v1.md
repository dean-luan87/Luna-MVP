# Cognitive State Formation / Semantic Module / A Boundary

Semantic Module constructs the Semantic Working Outline: relations, semantic projections, ambiguity/collision representations, expansion and folding.

Cognitive State Formation assembles structural/version-aligned snapshot refs and candidate state representations. It must not duplicate semantic expansion/folding.

A consumes both as inputs to local reasoning and owns:

- Current Need
- active Hypothesis
- evidence relevance
- Sufficiency
- Reconsideration
- Next-step
- B request/result adoption

Fields named hypothesis, sufficiency, need or reconsideration in State Formation are candidate/input refs only, never A-authoritative decisions.
