# Loop Closure / Freeze / Archive Boundary

Separate stages:

1. A local closure request or Brain/global closure decision;
2. governance acceptance where required;
3. Loop `CLOSE` mechanics;
4. `FREEZE_FINAL_STATE`;
5. `RECORD_OUTCOME_REF`;
6. `ARCHIVE_HISTORY_BOUNDARY`;
7. Brain adjudication/assimilation.

Closure reason belongs to A/Brain/governance. Outcome Evaluation Governance may produce an Outcome candidate. Loop mechanically packages refs/history and never interprets outcome quality, truth or closure reason.
