# Cognitive State Version Alignment

## Unique alignment responsibility

State Formation may compare and record versions for:

- Current World
- Field
- Context
- Working Envelope
- Role/Perspective
- Intent/Task
- Observation/Evidence

It may detect stale refs, mixed source versions, incomplete snapshots, and inconsistent provenance.

## Boundary

State Formation reports alignment status and returns complete, partial, degraded, or stale candidates. A decides the semantic consequence: keep, reassess, replan, request evidence, pause, or wait. Brain decides global grant/policy consequences. State Formation does not infer semantic impact.
