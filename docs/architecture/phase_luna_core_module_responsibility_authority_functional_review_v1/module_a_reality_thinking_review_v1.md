# M03 A Reality Thinking — Module Review

## Identity and purpose

Canonical name: A Reality Thinking / A reasoning role. Primary evidence: `a_owned_semantic_decision_loop_bridge_controlled/` and `a_b_contingency_reasoning_bridge_controlled/`. If removed, Luna loses local reality-grounded cognition for an admitted Concern: Need, evidence relevance, sufficiency, reconsideration, continuation, B request, and B-result evaluation.

## Functions and authority

`CORE`: Current Need selection, local sufficiency, reconsideration, next-step, Cognitive Requirement formation, environment impact assessment, B request, B result evaluation/consolidation. `SUPPORTING`: interpretation of Dynamic Flow compatibility output. `COMPATIBILITY_ONLY`: wrapping legacy Dynamic Flow computed values. A has `LOCAL_DECISION` authority under an active A grant; it does not have Brain-global Concern closure, provider/model, Scope/Resolution, or Loop mechanical authority.

The A grant pairs authority with responsibility for local decisions, stale evidence, incorrect interpretation, and returned-result handling. B may only start from A; A is B-result receiver/evaluator. Brain grants/revokes and adjudicates globally.

## Inputs, outputs, state, lifecycle

Inputs: Brain grant, working-envelope refs, Need/evidence/Current World/Task/Role/Field/Context/Emotion/Experience refs, Dynamic Flow compatibility output, B result. Source versions are required. Outputs: A-owned decision candidates, Cognitive Requirement, B request, B evaluation, mechanical command input, outcome candidate. Local reasoning state is A-owned; authoritative source state remains with source owners; Loop stores refs/mechanics.

Lifecycle: admit → reason → request evidence/B → reassess → continue/replan/close candidate → hand off to Loop/Brain. A decides semantic meaning; Loop executes persistence mechanics.

## Communication and negative boundaries

Allowed: Brain→A, source refs→A envelope, A↔B, A→Capability/Observation request, A→Loop adapter, Loop→A mechanical return, A→Brain outcome. Forbidden: A→Provider/model direct selection, A→global Concern split/merge without Brain, A→Loop semantic inference. Residual bypass risk is legacy Dynamic Flow/A Route direct consumption.

## Walkthroughs

1. Normal: evidence enters, A keeps/selects Need, judges sufficiency, emits outcome/Loop command.
2. Insufficient: A forms Cognitive Requirement, receives evidence, judges INSUFFICIENT or requests B; no Loop inference.
3. Changed role/world/task: A receives versioned changes, assesses material impact, invalidates/reissues local decisions as needed; grant governance remains Brain-owned.

## Overlap, gaps, evolution, disposition

Overlap: `SEMANTIC_OVERLAP` with Dynamic Flow and old Loop continuity; `IMPLEMENTATION_OVERLAP` with A Route/State Formation. Gaps: integrated Working Envelope generator, Observation/Capability return bridge, unified propagation/invalidation, Brain outcome assimilation. A may evolve into the single local semantic authority, never a global Brain replacement, provider selector, or mechanical Loop engine. **Disposition: KEEP**.

**Ledger summary:** authority = local semantic decisions; responsibility = local reasoning correctness; state = local reasoning state; receiver = Brain/Loop/Capability/Observation/B; confidence = high at controlled boundary.
