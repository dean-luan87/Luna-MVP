# Attention Adjudication Summary v1

## Overall adjudication

Attention does **not** decide what cognition needs. A decides the Cognitive
Need. Attention allocates bounded focus, priority, modality and resource
candidates after that Need exists and within Brain global policy.

## Owner map

```text
Brain global safety/permission/resource/priority constraints
                         ↓
A Cognitive Need / Cognitive Requirement
                         +
Role/Perspective + Semantic relevance + Task/Context urgency
                         ↓
Attention focus / priority / budget candidate
                         ↓
Observation/FPO admission and acquisition
                         ↓
Evidence → Current World / Field / Context updates
                         ↓
A reassessment
```

Capability Governance and Runtime Admission remain between functional
requirements and executable Provider/Observation capability where applicable.

## Owner decision

**Independent narrow Attention Governance/Allocation boundary: NARROW.** No
Attention Manager is created. The retained responsibility is candidate
competition, focus ranking, temporal decay and bounded resource allocation.

## Current status

Documentation-only adjudication. Runtime, types, enums, owners, runners,
verifiers, providers and devices were not modified or executed.
