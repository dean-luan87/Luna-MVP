# Semantic Module Negative Boundaries

Semantic Module must not:

- govern Goal;
- admit, reject, split, merge, or supersede Concern;
- issue or revoke grants;
- mutate Intent or Task;
- create Role identity;
- select Current Need;
- make a final Hypothesis judgment;
- judge evidence relevance or Sufficiency;
- decide Reconsideration or Next-step;
- issue a B request or adopt a B result;
- select Capability, model, or Provider;
- execute Observation or Provider;
- control Loop or issue Decision/Action;
- declare World Truth;
- mutate Field, Context, Current World, Memory, or Experience;
- perform Learning or semantic compression;
- bypass A through a direct short-path execution decision.
