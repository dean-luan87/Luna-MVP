# Model Capability Mapping Boundary v1

Capability Governance owns Capability identity, Slot, functional I/O contract,
scope, and logical resolution. Model Governance declares model-supported
capability contracts and compatibility/deployment metadata.

`Capability ↔ Model` is a shared, versioned mapping with split ownership. It
must preserve capability/slot version, model asset/version, input/output and
evidence contracts, compatibility, baseline, deployment constraints,
integrity/provisioning refs, and provenance. Model Governance is not the
Capability resolver.
