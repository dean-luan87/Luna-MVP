# Provider Ontology v1

| Concept | Meaning |
|---|---|
| Provider | implementation runtime that performs a bounded invocation |
| Provider Adapter | contract adapter to a runtime |
| Provider Family | compatible runtime class |
| Provider Instance | concrete local/cloud/device runtime |
| Provider Admission | permission/health/compatibility gate |
| Provider Invocation | actual bounded runtime call |
| Provider Session | bounded single/streaming execution context |
| Provider Result | runtime output/status/error |
| Runtime Executor | generic execution infrastructure |

Provider may be model, sensor, device, API, TTS, ASR, local software, or other
runtime. Provider != Model.
