# Intent / Attention / Capability / Observation Boundary v1

Intent can influence priority candidates, constraints and the interpretation
of why evidence matters. Brain supplies global priority/resource/safety policy.
Attention selects a bounded attention candidate. A identifies the cognitive
information need. Observation/FPO acquires evidence through its own admission
boundary.

Intent does not schedule Attention, resolve Logical Capability, select a
model/provider, perform Runtime Admission or invoke a Provider. Observation
results are evidence refs; they can cause A or Intent Governance proposals but
cannot directly mutate Intent.

The safe path is:

`Intent refs + A Need → Attention/Capability/Observation governed handoff →
Evidence → A interpretation or Intent-change candidate`.
