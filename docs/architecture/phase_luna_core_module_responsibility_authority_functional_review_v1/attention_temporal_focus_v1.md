# Attention Temporal Focus v1

Attention may represent immediate, sustained, periodic, deferred and expired
focus as candidate temporal characteristics. It may carry TTL, persistence,
decay and refresh refs.

Temporal expiry of a focus is a mechanical/candidate allocation event. It does
not mean the Cognitive Need is satisfied, the Concern is closed, or the Task is
complete.

If recurring sampling or timed execution requires a Scheduler-like mechanism,
that is a deferred contract/runtime gap. This review creates no Scheduler and
grants Attention no autonomous scheduling authority.
