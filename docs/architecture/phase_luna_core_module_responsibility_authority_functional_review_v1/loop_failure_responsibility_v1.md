# Loop Failure and Responsibility

## Loop responsibility

- incorrect persistence;
- wrong Loop state-version transition;
- cross-Concern contamination;
- invalid mechanical command acceptance;
- lost refs;
- trace/provenance break;
- incorrect freeze/archive mechanics;
- violation of revoked/expired grant.

## Non-responsibility

Loop is not responsible for incorrect Need, Sufficiency, closure reason supplied by A/Brain, Provider failure, Task failure or semantic Outcome quality.

On failure it returns mechanical rejection/status and preserves diagnostics; it does not invent semantic recovery advice.
