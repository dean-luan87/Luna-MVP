# Outcome Evaluation / Brain Assimilation Adjudication Summary v1

## Owner split

Outcome Evaluation Governance forms/evaluates the bounded candidate. Brain
owns final global adjudication and Assimilation. A owns local semantic
interpretation. Task owns completion. Decision owns commitment lifecycle.
Intent Governance owns Intent lifecycle. Experience/Memory Governance owns
later candidate admission and persistence. Loop owns mechanical closure,
freeze, package and history.

## Canonical close-loop flow

`Action Result / Task result / governed world-state update → A reassessment +
Task completion + Decision refs → Outcome Evaluation → Outcome Candidate →
Brain adjudication/assimilation → Goal/Concern consequences, Intent impact
candidate, follow-up cognition, ExperienceCandidate and MemoryCandidate
handoffs → authorized Loop CLOSE/FREEZE/ARCHIVE`.

## Disposition

Outcome Evaluation: **KEEP** narrow independent candidate-evaluation boundary.
Brain Outcome Adjudication/Assimilation: **KEEP** as part of Brain's existing
global governance boundary, with an explicit future API/adapter gap.

Documentation only. Runtime, types, enums, owners, Memory, Experience,
Learning, Provider, Action, Runner and Verifier were not changed or executed.
