# Target Module Owner Map

```text
GOVERNANCE
  Brain: Goal, Concern, global priority, safety/permission/resource, grants, final adjudication

COGNITIVE REASONING
  A: local reality reasoning and semantic decisions
  B-CR: bounded contingency reasoning, always A-started and A-evaluated
  Semantic Module: outline construction/expansion/folding only (deferred)

STATE REPRESENTATION
  Cognitive State Formation: candidate state assembly
  Field Reducer: authoritative Field transitions
  Context Foundation: context validity/assembly
  Intent Governance: Intent ownership
  Task Manager: Task lifecycle/constraints
  Role/Perspective: source refs, owner still to consolidate
  Attention: priority/focus candidates

MECHANICAL PERSISTENCE
  Loop: refs, versions, lifecycle, history, close/freeze, trace

CAPABILITY / EXECUTION
  Capability Governance: logical scope/resolution
  Runtime Admission: evidence-bound executable candidate seam
  Provider Governance: provider admission/invocation
  Observation/FPO: acquisition/admission/evidence
```

The map separates semantic authority from mechanical persistence and from infrastructure readiness. It does not create a new owner.
