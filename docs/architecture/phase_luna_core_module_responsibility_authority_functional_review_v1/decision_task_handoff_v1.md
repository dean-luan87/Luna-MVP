# Decision → Task Handoff v1

Approved Decision → Task candidate/admission. Decision owns what should be
done; Task owns identity, dependencies, readiness, completion conditions and
progress. Task must not reinterpret the commitment. Task reports impossible,
blocked, degraded, completion and failure as refs/statuses to Decision, A and
Brain as applicable.

Task capability routing remains a requirement/ref handoff; Capability
Governance resolves capability and Runtime Admission.
