# Role / Perspective Negative Boundaries v1

Role/Perspective must not become:

- Brain or global priority governance;
- A or semantic reasoning authority;
- Intent or Task owner;
- Semantic Module or World Truth authority;
- Attention scheduler;
- Capability, Runtime Admission, model/provider, or Observation owner;
- Loop controller;
- Memory/Experience writer or learner;
- personality/persona system;
- identity recognition, face/speaker recognition, camera-pose, or SLAM system.

They provide versioned source/projection refs only.
