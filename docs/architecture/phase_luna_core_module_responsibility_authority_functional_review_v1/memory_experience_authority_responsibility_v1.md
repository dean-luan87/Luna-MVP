# Memory / Experience Authority and Responsibility v1

| Boundary | Current authority | Responsibility |
|---|---|---|
| Source owner | Source state only | Correctness of Field, Context, evidence, outcome, role, task, and other source refs. |
| Candidate producer | Candidate construction | Correct source binding, versions, uncertainty, trace, and provenance. |
| Brain Assimilation | Global adjudication and handoff authorization | Correctly deciding whether candidate handoffs may be emitted; no persistence. |
| Future Memory Governance | Placeholder | Future Memory admission, lifecycle, and mutation. |
| Future Experience Governance | Placeholder | Future Experience admission, lifecycle, and mutation. |
| Loop | Mechanical reference persistence | Lineage, closure, archive, and candidate refs only. |

No current source module becomes Memory/Experience authority merely because it
provides candidate data. Authority and responsibility remain paired.
