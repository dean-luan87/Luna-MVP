# Memory / Experience Role and Perspective Compatibility v1

Role/Perspective refs may be retained when required to preserve the meaning of
a candidate. This does not create Role-specific Memory or make Memory the Role
owner.

The compatibility constraint is **Shared Information Once, Perspective
Augmentation Many**: a new Role may project over existing shared information
without re-recognizing or duplicating world, Field, or historical information.
Perspective remains derived. Emotion is **DEFERRED**, a future modulation
source, not a current conditioner or projection input, and is not introduced
into Memory/Experience design here.
