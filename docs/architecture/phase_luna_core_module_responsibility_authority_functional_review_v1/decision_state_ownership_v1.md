# Decision State Ownership v1

| State | Classification | Owner/meaning |
|---|---|---|
| decision candidate id | CANDIDATE then AUTHORITATIVE after admission | Decision Governance |
| decision id/version/lifecycle | AUTHORITATIVE | Decision Governance |
| A disposition, Goal, Intent, Concern refs | REFERENCE_ONLY | A/Brain/Intent source owners |
| option set, rejected options, rationale | LOCAL_DERIVED / recorded authority | Decision Governance, with provenance |
| safety/permission/resource constraints | REFERENCE_ONLY | Brain/policy owners |
| approval/admission and supersession | AUTHORITATIVE | Decision Governance under Brain constraints |
| Task/Action/result refs | REFERENCE_ONLY | downstream owners |

No Decision state is a Need, Hypothesis, Task lifecycle, Action execution,
Field state or Outcome truth declaration.
