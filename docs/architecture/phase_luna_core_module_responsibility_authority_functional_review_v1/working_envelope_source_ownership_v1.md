# Working Envelope Source Ownership v1

| Source | Owner | Envelope role |
|---|---|---|
| Goal / Concern / Grant | Brain | admitted scope refs |
| Intent | Intent Governance | identity/version ref |
| Role | applicable source governance | role/version/applicability refs |
| Perspective Projection Result | derived projection boundary | result/version/provenance ref |
| Field | Field boundary | state/version ref |
| Context | Context boundary | situation/version ref |
| Current World | Current World boundary | candidate/version ref |
| Task | Task | execution constraint/ref |
| Safety / Permission / Resource | global constraint governance | scoped/versioned refs |
| Attention | Attention | focus/budget candidate refs |
| Evidence | Observation/Gateway/source owner | evidence refs/version |
| Memory / Experience | future governance | admitted or explicitly governed candidate refs |
| Diagnostics | System Diagnostics | health/freshness refs |

The Envelope owns none of these authoritative payloads.
