# Cognitive State Formation Name-Semantics Review

## Finding

Repository assets imply a mixed historical meaning: the implementation is largely candidate state assembly, but names such as `CognitiveHypothesisCandidateV1`, `HypothesisCompetitionResultV1`, `CurrentWorldCandidateV1`, and “cognitive state” can overstate semantic authority.

The current guards explicitly support the narrower interpretation: `candidate_only`, no source mutation, no single-truth collapse, no causal truth, read-only Field refs, and candidate-only hypothesis/attention boundaries.

## Future naming candidates

Consider later, only through migration approval:

- Cognitive State Candidate Formation
- Cognitive Input State Assembly
- Cognitive Snapshot Formation

No rename is made now. Current name remains a compatibility label; the adjudicated contract narrows its meaning.
