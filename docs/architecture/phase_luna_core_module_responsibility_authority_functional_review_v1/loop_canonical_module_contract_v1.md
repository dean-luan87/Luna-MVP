# Cognitive Loop Canonical Module Contract v1

## Canonical one-line purpose

**Cognitive Loop is Luna's mechanical cognitive-process persistence engine: it preserves the identity, version lineage, pending references, lifecycle mechanics, trace/provenance, freeze and history boundary of an admitted cognitive work process, while never deciding its semantic meaning.**

## Irreducible responsibility

Loop is the persistent mechanical thread/materialization associated with cognitive work for a Concern. It is not the Concern, A reasoning, Task, Intent, Provider runtime, or a generic database.

## Final disposition

`NARROW`. Keep the independent boundary and remove semantic interpretation from its canonical surface over time.
