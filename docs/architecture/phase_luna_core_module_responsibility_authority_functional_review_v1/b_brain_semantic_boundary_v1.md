# B-CR / Brain Boundary

Brain owns Concern governance, grants, global priority, Safety, Permission, Resource and final outcome adjudication.

B may report a severe safety/permission/resource problem through its result and the defined A/Brain governance handoff. B does not create new global governance state or bypass A for ordinary reasoning. Direct Brain escalation is limited to an explicit governed failure path; it does not grant B Goal/Concern authority.

A remains responsible for interpreting B's result and deciding whether to escalate, while Brain owns the global policy decision.
