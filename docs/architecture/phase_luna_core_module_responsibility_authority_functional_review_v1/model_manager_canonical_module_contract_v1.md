# Model Manager / Model Governance Canonical Contract v1

## Purpose

Model Manager / Model Governance governs model identity, model assets, versions,
declared runtime requirements, integrity metadata, loader/provider compatibility,
lifecycle, provisioning metadata, and model-side mappings.

It does not decide Cognitive Need, Capability Scope, logical Capability
Resolution, Runtime Admission, Provider invocation, or semantic consequence.

## Disposition

**KEEP / NARROW** as an independent governance boundary. Existing repository,
registry, lifecycle, provisioning, and contract assets are evidence of this
boundary; no new Manager or runtime is created.
