# Outcome Ontology v1

| Concept | Meaning |
|---|---|
| Action Result | concrete executor/provider report |
| Execution Result | runtime/effect fact or candidate |
| Task Completion Result | Task contract completion status |
| A Local Evaluation | Concern-local semantic interpretation |
| Local Cognitive Outcome | A-scoped consequence candidate |
| Outcome Candidate | bounded cross-source consequence candidate |
| Outcome Evaluation | comparison, deviation, attribution and follow-up assessment |
| Final Outcome Adjudication | Brain global acceptance/rejection/defer/supersession |
| Assimilation | Brain integration into governed Goal/Concern/global state and handoffs |
| Concern Closure | Brain semantic closure decision followed by Loop mechanics |
| Experience/Memory Candidate | downstream candidate handoff, not mutation |

Action Result, Task Completion, A Sufficiency, Outcome Candidate and final
Brain Outcome are distinct.
