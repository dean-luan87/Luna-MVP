# Diagnostics Device and Runtime Health v1

Device domains include camera, microphone, GPU, CPU, storage, network, audio,
sensors, and future peripherals. Runtime domains include process/loader
availability, service connectivity, session/thread health, contract
compatibility, and version mismatch.

Diagnostics classifies bounded health facts. It does not select a device,
define capability meaning, execute observation/action, or decide fallback.
Observation/Action/Provider Admission consumes the refs and applies the
appropriate execution consequence.
