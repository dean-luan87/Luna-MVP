# Working Envelope Ontology v1

- **Working Envelope**: admitted binding set for one bounded cognitive work context.
- **Envelope Candidate**: proposed binding set awaiting validation/admission.
- **Admitted Envelope**: binding set accepted under Concern/Grant/constraint scope.
- **Envelope Version**: version of the admitted binding set, not a global source version.
- **Source Ref / Source Version**: reference and version owned by the source module.
- **Constraint Ref / Grant Ref / Concern Ref**: governed references bound to the work.
- **Applicability Ref**: evidence that a source/constraint applies to this work.
- **Projection Ref**: derived Role/Perspective projection reference.
- **Invalidation Ref**: record that a binding is no longer current/valid.
- **Supersession Ref**: lineage from an old envelope version to a replacement candidate.
- **Envelope Refresh Candidate**: proposed new binding after source change.

The ontology is reference-oriented; it does not introduce enums or duplicate
source payloads.
