# Evidence Ontology v1

| Concept | Meaning |
|---|---|
| Raw result | provider payload/output |
| Structured Provider Result | normalized runtime output with runtime metadata |
| Evidence Candidate | source-linked, uncertain, non-truth evidence representation |
| Admitted Evidence | structurally/provenance-admitted input for cognition |
| Evidence ref | reference to admitted/candidate evidence |
| Fact Candidate | possible fact representation, still not Truth |
| World-state update candidate | handoff to Current World/Field owners |

Evidence admission means structurally admitted for cognition, not semantically
true. Evidence != Fact != World Truth.
