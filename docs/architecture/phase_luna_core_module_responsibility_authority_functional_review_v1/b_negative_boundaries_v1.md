# B-CR Negative Boundaries

B must not:

- self-initiate;
- architecturally invoke B recursively;
- govern Goal or Concern;
- own Cognitive Need, active Hypothesis, Sufficiency or final Next-step;
- mutate Semantic Working Outline or source state;
- schedule Attention or Observation;
- select model/Provider or perform Runtime Admission;
- invoke Provider/Observation;
- control Loop;
- make final Decision or execute Action;
- mutate Task;
- mutate Memory/Experience;
- perform Learning or semantic compression;
- declare World Truth;
- adopt its own result.
