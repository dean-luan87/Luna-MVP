# Role, Identity, Persona and Relationship Terminology Map v1

| Term | Classification | Canonical interpretation |
|---|---|---|
| Role | CANONICAL_ROLE | governed subject/relationship position |
| Perspective | CANONICAL_PERSPECTIVE | derived interpretive viewpoint |
| Self identity | IDENTITY_ONLY | Self Governance/source identity boundary |
| observed entity identity | IDENTITY_ONLY / CANDIDATE | external identity evidence, not automatically fact |
| persona/personality | PERSONA | Personality/Self boundary; not Role |
| relationship | RELATIONSHIP | relation source; may support Role candidate |
| user role/system role | TERMINOLOGY_ONLY | source/context qualifier |
| task role | TASK_ROLE | Task requirement or candidate constraint |
| object role | LEGACY_OVERLAP / FIELD ROLE | field-centric object function candidate |
| speaker/face identity | OUT_OF_SCOPE | recognition/evidence system, not Role governance |
| first-person camera view | VISUAL_VIEWPOINT | Perception/SLAM geometry, not cognitive Perspective |

The existing object-role inference asset is candidate-only and explicitly
field-constrained; it is not Self/Other Role authority.
