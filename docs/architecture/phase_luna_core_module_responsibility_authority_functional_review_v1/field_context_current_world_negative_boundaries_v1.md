# Field / Context / Current World Negative Boundaries v1

The three boundaries must not become:

- a World Truth manager;
- a substitute for Brain governance;
- A or any Need/Hypothesis/Sufficiency/Reconsideration authority;
- Semantic Module or semantic expansion/folding engine;
- Role/Perspective identity or projection owner;
- Intent or Task lifecycle owner;
- Attention scheduler;
- Capability/Runtime Admission/Provider selector;
- Observation executor, camera/OCR/YOLO/SLAM runtime;
- Loop controller or semantic lifecycle interpreter;
- Memory/Experience writer, learner or semantic compressor;
- a generic data lake or a second mutable copy of source state.

Field may reject invalid Field transitions. Context may reject invalid source
projection assembly. Current World may reject invalid candidate formation. Those
are structural/source responsibilities, not semantic judgments.
