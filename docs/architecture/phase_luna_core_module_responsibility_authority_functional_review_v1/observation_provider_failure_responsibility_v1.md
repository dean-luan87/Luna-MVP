# Observation / Provider / Evidence Responsibility v1

Observation/FPO owns invalid request/source matching, stale request use,
lost focus constraints, invalid Provider handoff, lifecycle errors and lost
acquisition provenance.

Provider Governance owns invalid admission, wrong runtime binding, duplicate
invocation, invocation contract violation, timeout/cancel and Provider
runtime failure handling.

Evidence/Gateway owns malformed admission, source/provider/request mismatch,
stale/duplicate Evidence, provenance loss and invalid downstream handoff.
None owns A relevance, Sufficiency, Truth, Field semantics, Goal or Concern.
