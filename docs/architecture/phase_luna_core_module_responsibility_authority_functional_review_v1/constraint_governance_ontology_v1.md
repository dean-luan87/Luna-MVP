# Constraint Governance Ontology v1

| Concept | Meaning |
|---|---|
| Safety Policy | global non-harm/protected-state rule |
| Safety Constraint | scoped policy ref applied to work/execution |
| Safety Risk Evidence | observed/candidate risk input |
| Safety Admission | policy-bound allow/block assessment |
| Safety Override | Brain/governance revocation or emergency precedence |
| Emergency Stop | high-priority stop/interruption command under policy |
| Permission Policy | rule for allowed subject/operation/scope |
| Permission Evidence | identity/Role/relationship/consent/access input |
| Permission Grant | scoped allowed-operation record |
| Permission Admission | enforcement check for a request |
| Permission Revocation | invalidation of prior scope/permission |
| Resource Policy | allocation/ceiling/protected reserve rules |
| Resource Ceiling/Budget | bounded permitted consumption |
| Resource Availability | measured current capacity |
| Reservation | candidate or committed allocation claim |
| Consumption/Exhaustion | runtime fact/status |

Policy != Evidence. Evidence != Grant. Grant != Admission. Admission != runtime
execution. Resource budget != resource fact.
