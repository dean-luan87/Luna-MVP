# Current World Canonical Module Contract v1

## Adjudication

**Disposition: NARROW.** Current World survives as a derived candidate boundary,
not as a canonical world-state owner or truth authority.

## Canonical purpose

Current World is Luna's cognition-cycle candidate representation of the best
currently assembled environmental situation from admitted evidence, Field and
Context refs, temporal/uncertainty/conflict metadata and other governed source
refs. It preserves a candidate snapshot and provenance for reasoning; it never
declares World Truth or mutates source state.

## Repository evidence

`CurrentWorldCandidateV1` carries context, Field, observation, intent,
attention, hypothesis-related, uncertainty, conflict and temporal refs, source
versions, trace and provenance. It is explicitly `candidate_only=True`; Field
mutation, Field transition, reducer-as-mutation-authority and Field truth
declaration are all false.

The B1/context integration labels outputs `PARTIAL_CANDIDATE` or `CONTESTED`,
preserves temporal/conflict/provenance refs, and creates no direct Field state.
The B2 adapter requires candidate-only Current World input and passes it as a
read-only source reference into Cognitive State Formation.

## Authority and responsibility

Current World may own candidate identity, candidate version, source alignment,
conflict/uncertainty status, partial/degraded status and provenance for the
candidate. It may not own Field state, Context source state, Role/Intent/Task
state, active A hypotheses, World Truth or the semantic consequence of a
candidate.

Current World formation is responsible for invalid candidate assembly, wrong
source/version binding, lost provenance, false completeness and cross-cycle or
cross-entity contamination. A owns relevance, Need, Hypothesis, Sufficiency,
Reconsideration and Next-step.

## Output receivers

Primary receivers are A, Cognitive State Formation, Working Envelope and
controlled observation/evidence handoffs. Brain may consume a candidate ref for
global governance. Loop may persist refs only. No receiver may treat it as
World Truth without a separate future adjudication contract.

## Current implementation status

`NO_GAP` for the candidate boundary; `ADAPTER_GAP`/`RUNTIME_GAP` remain for
explicit source-version/invalidation and production formation. Existing assets
are controlled candidates, not a production world-state runtime.
