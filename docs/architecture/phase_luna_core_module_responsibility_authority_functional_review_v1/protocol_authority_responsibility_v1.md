# Protocol Authority and Responsibility v1

WHO HAS AUTHORITY OWNS RESPONSIBILITY.

Protocol Governance is responsible for invalid protocol identity, canonical
contract, version lineage, compatibility declaration, lifecycle transition,
deprecation/supersession, migration requirement, and protocol provenance.

Producer owns invalid emitted payloads; consumer owns misinterpretation of a
valid supported payload; adapter owns corrupt translation; Diagnostics owns
missed or incorrect drift detection; migration implementation owner owns source
mutation errors. Protocol Governance is not responsible for consumer defects
unless it owns the consumer implementation.
