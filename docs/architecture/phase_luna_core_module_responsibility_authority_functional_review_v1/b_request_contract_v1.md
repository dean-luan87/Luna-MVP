# B-CR Request Contract v1

## Mandatory conceptual inputs

- Concern ref
- A reasoning-cycle ref
- active Need ref
- active Hypothesis refs
- admitted semantic/working context refs
- evidence refs
- explicit contingency question
- source-state versions
- valid A request/grant scope
- return receiver = A
- trace/provenance

## Bounded controls

- allowed scenario scope
- branch limit
- depth limit
- resource/compute budget
- optional time/termination budget
- safety constraints
- permission constraints
- prohibited operations

## Optional inputs

Role/Perspective projection, Current World candidate, Experience/Memory prior refs, expectation refs, branch hints, and requested result categories.

No request may authorize B to mutate source state, invoke Provider/Observation, control Loop, recurse architecturally, or declare truth.
