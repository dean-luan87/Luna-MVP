# Task / A Reality Thinking Boundary v1

A owns Cognitive Need, active Hypothesis, evidence relevance, Sufficiency,
Reconsideration, Next-step, and B invocation/adoption. Task supplies execution
constraints, completion conditions, dependency refs, and execution-state refs.

Task must not generate Need, judge Sufficiency, request B, or decide cognitive
Reconsideration. A may assess whether Task conditions fit reality and may emit
a Task-change or execution-dependency candidate. Task Manager owns the Task
lifecycle consequence after governed input.
