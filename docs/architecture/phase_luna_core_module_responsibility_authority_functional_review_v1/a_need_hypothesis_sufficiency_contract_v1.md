# A Need / Hypothesis / Sufficiency Contract v1

## Terminology

- Goal: global desired result, Brain-owned.
- Concern: Brain-governed cognitive work object.
- Intent: Intent Governance-owned purpose/causal handoff.
- Task: Task Manager-owned constraints, dependencies and completion conditions.
- Cognitive Need: missing information/evidence for the admitted Concern, A-owned.
- Observation Need: downstream acquisition request derived from A's requirement; Observation/FPO does not create the underlying Cognitive Need.
- Capability Requirement: technical demand mapped from A's Cognitive Requirement; Capability Governance resolves it.

## Hypothesis authority

A may create, rank, revise, compare, abandon and invalidate local hypotheses. Semantic Module may provide candidate interpretations and relations; State Formation may provide hypothesis-related candidate refs; Current World/evidence never self-promotes into hypothesis truth.

## Sufficiency authority

A judges whether, for the current Concern, Working Envelope/Outline, available evidence, constraints, and hypotheses, information is sufficient for the local cognitive objective.

Sufficiency is not Brain outcome adjudication, Provider success, evidence existence, Observation completion, Task completion, Action success, or World Truth.
