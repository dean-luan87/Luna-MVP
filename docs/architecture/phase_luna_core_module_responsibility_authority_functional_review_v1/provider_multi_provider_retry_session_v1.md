# Provider Multi-Provider / Retry / Session Boundary v1

Provider Governance may retain multiple compatible Provider candidates and
admission results. It may expose retryable metadata, invocation ID,
retry-after, timeout, cancellation and duplicate status.

Semantic fallback/retry remains A/Decision/Task-governed. A bounded session or
stream differs from Observation lifecycle: Provider owns runtime session
status, Observation owns acquisition request/result lifecycle. The current
single-invocation trial is evidence, not a universal future limitation.
