# Role / Perspective Change Propagation v1

Canonical propagation:

`source Role/Perspective update → governed source version → Working Envelope
invalidation/update → Semantic projection refresh → Cognitive Snapshot refresh
→ Intent applicability candidate → A impact assessment → A reconsideration if
needed → Task readiness impact where applicable`.

There is no direct Role-to-A REPLAN, Role-to-Task mutation, or Role-to-Intent
mutation. Each owner receives a ref/candidate through its existing boundary.
