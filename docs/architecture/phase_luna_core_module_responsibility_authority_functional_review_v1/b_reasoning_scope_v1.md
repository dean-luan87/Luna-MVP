# B-CR Reasoning Scope

B may compute, within request scope:

- alternative hypotheses and scenario branches;
- counterfactual consequences;
- causal alternatives;
- exception and rare-case analysis;
- contradiction exploration;
- fallback candidates;
- bounded multi-step reasoning;
- uncertainty decomposition;
- failure scenarios;
- residual unknowns and missing-evidence candidates.

For every output, A owns whether it matters, changes the active hypothesis, changes Need, alters Sufficiency, or warrants a Next-step. B does not create a final plan, Decision, Action, or Concern.
