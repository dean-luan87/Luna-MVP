# Permission Governance — Canonical Contract v1

Permission Governance determines whether a governed subject is allowed to
perform, access, observe, mutate, disclose, or invoke something within a
defined scope.

Brain owns global Permission policy and Grant governance. Permission
Governance is the scoped policy/admission boundary; Observation, Capability,
Provider and Action enforce supplied permission refs.

Disposition: **NARROW** as a Brain-owned/global constraint boundary. No new
Permission Manager is created.
