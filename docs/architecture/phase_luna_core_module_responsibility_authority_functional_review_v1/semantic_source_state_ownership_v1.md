# Semantic Source and State Ownership

| Input/domain | Source owner | Semantic Module role | A role |
|---|---|---|---|
| Goal | Brain | reference/projection | local context input |
| Concern | Brain | reference/projection | local work boundary |
| Intent | Intent Governance | represent meaning | assess relevance |
| Role/Perspective | external role/context governance; owner not yet consolidated | role-conditioned projection | judge impact |
| Field | Field State Reducer | relation over ref | judge significance |
| Context | Context Foundation | contextual projection | judge impact |
| Current World | State Formation/source world boundary | candidate relation structure | evaluate evidence/reality |
| Task/Behavior | Task Manager | constraint representation | reason under constraint |
| Emotion | Emotion owner/governance | modulation representation | judge cognitive consequence |
| Attention | Attention Governance | relevance/focus features | decide information need |
| Safety/Permission/Resource | Brain/governance owners | constraint refs | reason within granted envelope |
| Experience/Memory | Experience/Memory Governance | read-only prior projection | evaluate usefulness/sufficiency |

Semantic state is `LOCAL_DERIVED` / `CANDIDATE`. Source refs are `REFERENCE_ONLY` inside the module. Semantic Module owns neither A reasoning state nor authoritative source state.
