# Memory / Experience Brain, Outcome, and Loop Boundary v1

Canonical conceptual path:

```text
Evidence / Field / Current World / Context / A / Decision / Task /
Action Result / Outcome
        → Brain Assimilation and/or governed candidate producer
        → MemoryCandidate / ExperienceCandidate
        → future Memory / Experience Governance
        → DEFERRED
```

Outcome Evaluation may provide evaluated consequence refs but does not write
Memory or Experience. A may identify local relevance candidates but does not
persist them. Brain may authorize or construct candidate handoffs but does not
directly create authoritative persistent Memory or Experience.

Loop may retain candidate refs, source refs, outcome refs, versions,
provenance, closure, and archive refs. Loop history is not automatically
Memory and does not decide retention, importance, forgetting, or
generalization.
