# Observation Ontology v1

| Concept | Meaning |
|---|---|
| Cognitive Need | A's missing-information judgment |
| Cognitive Requirement | A's requirement derived from Need |
| Observation Need | acquisition-oriented candidate |
| Observation Request | governed acquisition contract |
| Acquisition Request | modality/target execution request |
| Provider Admission | runtime provider eligibility |
| Provider Invocation | actual runtime call |
| Provider Result | raw/structured runtime output |
| Observation Result | correlated acquisition result |
| Evidence Candidate | normalized non-truth evidence |
| Evidence Admission | structural/provenance admission |
| Observation Gateway | ingress/evidence normalization/admission/routing |
| Current World update | candidate world representation handoff |
| Field Event candidate | candidate event for Field admission |

Observation Request is not Provider Invocation; Provider Result is not
Evidence; Evidence is not World Truth; Observation is not Current World or
Action.
