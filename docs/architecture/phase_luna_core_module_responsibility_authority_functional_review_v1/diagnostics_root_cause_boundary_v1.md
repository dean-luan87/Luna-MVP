# Diagnostics Root-Cause Boundary v1

Diagnostics may emit causal candidates, dependency chains, likely sources, and
correlated failures when evidence supports them. Each claim carries evidence,
confidence/status, and provenance. Speculative classification remains a
candidate and never becomes World Truth.

Consumers may use a root-cause candidate for admission or maintenance review,
but Diagnostics does not own final cause adjudication, policy, or repair.
