# Protocol Ontology v1

- **Protocol**: governed identity and exchange contract.
- **Contract**: semantic/operational obligations represented by a protocol.
- **Schema**: structural representation of a record or message.
- **Message/Record**: payload instance.
- **Protocol Identity/Version**: stable identity and governed revision.
- **Schema/Contract Version**: independent version domains.
- **Producer/Consumer Binding**: declared use of a protocol version.
- **Lifecycle**: governed protocol state and lineage.
- **Change/Deprecation/Supersession**: governed lifecycle events.
- **Migration Declaration**: requirement and target for affected owners.
- **Adapter**: explicit translation between supported contracts.
- **Validation**: conformance evidence.
- **Drift/Violation**: mismatch or non-conformance finding.

Protocol != payload, source state, implementation, adapter, validator, policy,
or runtime availability.
