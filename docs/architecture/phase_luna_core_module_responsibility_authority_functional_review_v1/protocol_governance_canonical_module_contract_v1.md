# Protocol Manager / System Protocol Governance Canonical Contract v1

## Purpose

Protocol Governance owns protocol identity, canonical contract/version,
lifecycle, compatibility declarations, change-control admission,
deprecation/supersession, retirement, migration requirements, and protocol
provenance.

It does not own source state, semantic module authority, runtime execution,
consumer implementation, Diagnostics, or arbitrary migration.

## Disposition

**KEEP / NARROW** as an independent L1 governance boundary. Existing Protocol
Manager assets are candidate-only and do not authorize runtime protocol loading
or direct registry mutation.
