# Semantic Expansion and Folding Boundary

## Expansion

Expansion is bounded construction of additional semantic representation from admitted refs. It may include relations, implied dimensions, Role-dependent meanings, Goal/Concern-relevant candidates, unresolved slots, and alternative interpretations.

Expansion is bounded by Working Outline scope, admitted refs, Goal/Concern, Role/Perspective, source versions, provenance, safety/permission/resource limits, and finite outline/resource policy. It is not unlimited associative reasoning and does not generate final hypotheses or plans.

## Folding

Folding is reducing an expanded representation to the minimum working representation needed for the current cognition. It is working-state reduction, representation selection, and relevance-oriented projection with traceability.

Folding is not semantic compression of Memory/Experience. It does not mutate Memory, Experience, or Learning state, and does not create a durable prior.

## Responsibility split

Semantic Module constructs and folds representation. A decides whether the resulting representation changes Need, Sufficiency, Reconsideration, or continuation. Brain governs global constraints and outcome adoption.
