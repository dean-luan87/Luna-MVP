# FPO Target Boundary v1

FPO retains acquisition orchestration, request adaptation, target/ROI binding,
bounded invocation bookkeeping, deduplication and result correlation.

Move/narrow information-gap semantics to A, priority/budget to Attention,
logical capability/model mapping to Capability/Model owners, Provider admission
and invocation to Provider Governance, and evidence normalization/admission to
Observation Gateway. FPO does not declare Evidence, Truth, Sufficiency or
Current World.
