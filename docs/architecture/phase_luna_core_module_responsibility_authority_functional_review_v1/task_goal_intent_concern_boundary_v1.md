# Task / Goal / Intent / Concern Boundary v1

| Concept | Owner | Task relationship |
|---|---|---|
| Goal | Brain | reference/global constraint |
| Intent | Intent Governance | one Intent may support multiple Tasks; Task may propose change only |
| Concern | Brain | reference; Task cannot admit/merge/split |
| Need | A | Task may expose execution dependency; cannot create Need |
| Decision | Decision Governance | normal Task materialization follows approved Decision |
| Task | Task Manager | execution organization |
| Action | Action Governance/runtime | Task may carry required Action refs |

Task completion is not Intent completion, Goal success, Concern closure, or A
Sufficiency. Intent supersession may make a Task stale or blocked through a
governed handoff, but Task cannot mutate Intent directly.
