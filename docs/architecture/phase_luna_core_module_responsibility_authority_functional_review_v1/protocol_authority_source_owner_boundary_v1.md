# Protocol Authority and Source Owner Boundary v1

Protocol Governance defines, registers, versions, approves, deprecates,
supersedes, retires, and publishes compatibility/migration metadata. It owns
responsibility for incorrect protocol identity, contract, lineage, lifecycle,
compatibility, and change decisions.

Source owners retain state authority. For example, Intent Governance owns
Intent state while Protocol Governance owns the Intent exchange contract.
The same distinction applies to Brain, Role/Perspective, Field, Context,
Current World, Task, Capability, Model, Provider, Observation, Evidence,
Decision, Action, Outcome, Diagnostics, and Memory/Experience handoffs.
