# Attention Need / Relevance / Priority Ontology v1

| Concept | Canonical meaning | Owner |
|---|---|---|
| Cognitive Need | information cognition lacks for the Concern | A |
| Cognitive Requirement | structured requirement derived from the Need | A / Capability boundary as mapped ref |
| Relevance | relation of information/target to Concern, Intent, Role, Context or Task | Semantic/A inputs; A judges cognitive consequence |
| Priority | relative ordering among eligible focus candidates | Attention candidate, within Brain policy |
| Urgency | time sensitivity or expiry pressure | source/policy input; Attention candidate representation |
| Focus | target candidate selected for bounded attention allocation | Attention candidate |
| Budget | bounded compute/sensor/latency/token/energy allowance | Brain ceiling; Attention allocation candidate |
| Observation Request | governed acquisition request | Observation/FPO |
| Capability Requirement | functional ability needed for the Need | A/Capability Governance boundary |

Attention may reformulate an A Requirement into target dimensions, such as a
region, object, modality or time window, but may not change the Requirement's
semantic meaning or create a new Need.

“What cognition lacks” belongs to A. “Which eligible target gets limited focus
first” belongs to Attention.
