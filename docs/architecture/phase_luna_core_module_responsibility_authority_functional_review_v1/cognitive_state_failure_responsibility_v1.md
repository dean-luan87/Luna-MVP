# Cognitive State Formation Failure and Responsibility

## State Formation responsibility

- correct source assembly;
- version alignment;
- snapshot consistency;
- read-only owner preservation;
- trace/provenance lineage;
- partial/degraded/stale reporting.

## Non-responsibility

State Formation does not own Need, active Hypothesis, Sufficiency, Reconsideration, semantic interpretation, Attention priority, World Truth, Provider/Observation execution, or Loop persistence.

Missing Current World/Context, stale/mixed versions, missing Role/Task, missing Outline, partial Evidence, or provenance breaks produce partial/degraded/stale candidates. A decides the cognitive consequence; Brain decides global consequences.
