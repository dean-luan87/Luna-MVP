# Migration Recommendation

## P0 — blockers to a clean baseline

1. Keep Dynamic Flow semantic outputs behind the compatibility→A adapter for every active caller.
2. Cut remaining Loop continuity semantic interpretation to supplied A/Brain refs; retain old helpers only as compatibility.
3. Define the Brain runtime subject/API before any global governance runtime is built; do not solve this by making A or Loop global.

## P1 — required integration

1. Consolidate Working Envelope generation and source-version/invalidation propagation.
2. Complete A→Cognitive Requirement→Capability/Observation→Evidence→A bridge.
3. Establish Role/Perspective source ownership and propagate role/field/context/emotion/task changes to A impact assessment and Brain grant invalidation.
4. Stabilize Semantic Working Outline and Experience short-path contracts without granting them Need/decision authority.

## P2 — consolidation and cleanup

1. Separate Task technical routing from Capability Governance.
2. Normalize Need/Requirement and B-CR/Route-B terminology.
3. Consolidate trace/provenance/id helpers only where an existing shared protocol permits it.
4. Migrate fixture/verifier dependencies before any helper deletion.

## Defer

Real concurrency/scheduling, Brain runtime implementation, Experience compression/learning, Action, new managers, and any provider/runtime redesign are outside this baseline review.
