# Working Envelope Source-Version Map v1

Potential source-version domains are distinct: Brain Goal/Concern/Grant,
Intent, Role, Perspective Projection, Field, Context, Current World, Task,
Safety/Permission/Resource, Diagnostics, Evidence, and future admitted
Memory/Experience refs.

Envelope Version identifies the admitted binding set. It does not collapse
source versions into one global version or take ownership of source state. A
valid map preserves source ref, source version, applicability, validity,
provenance, and the admission/refresh lineage.
