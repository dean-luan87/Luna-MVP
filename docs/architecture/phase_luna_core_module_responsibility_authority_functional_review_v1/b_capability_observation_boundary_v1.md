# B-CR / Capability / Observation Boundary

B may identify residual uncertainty or a missing-evidence candidate, but it must return that need to A.

Canonical path:

`B residual need candidate → A evaluation → A Cognitive Requirement → Attention/Capability/Observation`

B must not schedule Attention, issue Observation directly, select model/Provider, perform Runtime Admission, invoke external Capability, or fabricate evidence. B may use only evidence explicitly supplied/admitted in its request.
