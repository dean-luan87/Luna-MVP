# Model Ontology v1

- **Model**: governed computational artifact identity.
- **Model Identity**: stable asset/family/variant/version identity.
- **Model Asset/Artifact**: declared or physical artifact reference.
- **Weights / Weights Version**: parameter artifact and its lineage.
- **Model Family / Variant**: taxonomy dimensions, not one overloaded name.
- **Manifest**: governed declaration of asset and compatibility metadata.
- **Model Contract**: declaration of input/output, loader, dependency, mapping, and deployment requirements.
- **Loader Contract**: instantiation compatibility declaration.
- **Dependency Requirement**: declared prerequisite, not observed health.
- **Capability Mapping**: Model-to-capability compatibility declaration.
- **Provider Mapping**: Model-to-provider-family/adapter compatibility declaration.
- **Provisioning**: governed acquisition/registration preparation.
- **Admission Candidate**: candidate for downstream admission.
- **Health Evidence**: observed operational state.
- **Runtime Instance**: loaded/executing runtime object.

Model != Capability, Provider, Loader, Runtime Instance. Registered Model !=
Executable Model. Healthy Model != Admitted Model.
