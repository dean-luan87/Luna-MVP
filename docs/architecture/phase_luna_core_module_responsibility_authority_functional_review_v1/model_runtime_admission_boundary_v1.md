# Model Runtime Admission Boundary v1

Canonical chain:

```text
Capability Logical Resolution
  + Model declarations
  + Diagnostics health/integrity evidence
  + Provider compatibility
  + Safety / Permission / Resource
        → Runtime Admission
        → Executable Capability Candidate
        → Provider Admission
```

Model Governance supplies declarations and candidates; it does not create an
Executable Capability Candidate. Registered, supported, or healthy metadata
does not imply executable readiness.
