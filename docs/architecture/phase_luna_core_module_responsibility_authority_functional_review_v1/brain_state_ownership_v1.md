# Brain State Ownership

## Authoritative global state

Brain may own:

- Goal identity and governance status;
- Concern identity, admission, merge/split/supersede status;
- global priority and policy decisions;
- active/revoked/expired authority grants;
- global Safety, Permission, and Resource governance decisions;
- adjudication and assimilation records.

## Source-owned references

Brain references, but does not duplicate, Field State, Context, Current World, Role/Perspective, Task, Intent, Attention, Capability/Model, Provider, Memory, and Experience state. Their owners remain responsible for source updates and provenance.

## Candidate-only state

Current World candidates, A/B decisions, Capability resolutions, Runtime Admission assessments, Executable Capability candidates, Evidence, Outcome candidates, and Experience candidates remain candidates until their existing owners/governance boundaries accept them.

## Not Brain state

Brain does not become the owner of A local reasoning state, B local contingency state, Loop mechanical state, model weights/paths, dependency health, checksums, or provider runtime state.
