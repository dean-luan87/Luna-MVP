# Role / Perspective Canonical Contract v1

## Canonical definitions

**Role** is a governed social identity position occupied by Self or another
entity, together with the responsibilities, obligations, skills, domain
knowledge, capability relevance, permissions, relationship expectations, and
learned relevance patterns that make that position cognitively meaningful.

Role may condition capability relevance; Capability Governance retains
capability ownership.

**Perspective** is the dynamically augmented working view produced by applying
Role-conditioned processing to shared admitted information under current
Context, Intent, Task, Concern, and applicable governance constraints. Emotion
is deferred and is not a current conditioner or Projection input. It is not
camera pose, visual geometry, personality, or World Truth.

Perspective has two conceptual parts:

1. Perspective Projection Function — the transformation that derives
   conditionally available attributes and relations.
2. Perspective Projection Result — the versioned candidate/derived augmented
   working view.

Role and Perspective are related but not identical. One or more Roles may
condition Perspective candidates; a Role does not deterministically force a
Perspective.

## Target ownership

This review does not create a Role Manager or Perspective Manager.

- Role identity/lifecycle remains with the applicable existing source owner:
  Self Governance for Self roles, Relationship/External Identity/Field or
  Context governance for other-entity and situational roles.
- Perspective Projection is a canonical function/result boundary, not a
  Manager. Working Envelope and Cognitive State Formation carry refs and
  lineage but do not compute the projection.
- Brain constrains global applicability; A may adopt a local reasoning frame;
  Semantic Module projects meaning; source owners retain Role truth.

## Disposition

**ROLE_REASSIGN + PERSPECTIVE_FUNCTION_KEEP / RESULT_NARROW.** Resolve the
Role owner gap through existing source governance. Keep Perspective Projection
as a conceptual function and derived result boundary without creating a
Perspective Manager or giving it semantic judgment authority.

Core principle: **Shared Information Once, Perspective Augmentation Many.**
世界本体稳定原则：世界本身不因观察角色或情感状态发生改变。
角色条件化属性增强原则：Role 基于既有对象属性、关系、能力、知识与上下文
信息，对当前 working view 附加条件化属性；附加结果不得反向污染世界本体。

Emotion is `DEFERRED`, `FUTURE_MODULATION_SOURCE`,
`NOT_CURRENT_CONDITIONER`, and `NOT_CURRENT_PROJECTION_INPUT`. Its eventual
relationship to Perspective, Attention, Memory retrieval, A weighting, Role
augmentation, Decision, or output requires a separately adjudicated
Modulation / Arbitration / Self-Regulation boundary.
