# Decision / Action Negative Boundaries v1

Decision Governance must not own Goal/Concern, A reasoning, Need,
Sufficiency, Intent mutation, Task dependencies, Capability/Provider
selection, Action execution, Field mutation, Loop control, Memory mutation,
Learning or World Truth.

Action Governance must not own Goal/Intent, cognition, Need, Sufficiency,
Task creation, Capability taxonomy, Provider runtime, direct Field declaration,
Task/Outcome inference, Loop cognition, Memory/Learning, autonomous retry or
Planner/Scheduler authority.
