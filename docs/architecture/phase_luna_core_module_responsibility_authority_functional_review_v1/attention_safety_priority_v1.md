# Attention Safety Priority v1

Safety/risk sources may produce a high-priority Attention candidate. Brain and
Safety Governance remain the authority for safety policy, protected priorities,
permission and resource preemption.

Attention may represent safety preemption or reserved focus, but cannot define
what is safety-critical, override Brain policy, execute an emergency action or
turn general attention into a survival runtime.

Always-on safety perception, if required later, is a separately governed
capability/runtime path. It is not evidence that general Attention should own
Observation execution.
