# Decision Failure Responsibility v1

Decision Governance owns invalid option selection under supplied constraints,
inconsistent commitment, stale/revoked Decision use, provenance loss,
cross-Concern contamination and invalid Task/Action handoff.

It does not own A's reasoning error, Task dependency/readiness error, Action or
Provider execution failure, Field corruption, or Brain policy/final Outcome
error. It returns explicit rejection/defer/blocked candidates and never
invents evidence or silently converts failure into execution.
