# Attention / Task / Context Boundary v1

Task may provide urgency, deadline, dependency, readiness blocker or required
evidence condition. Context may provide time, location, social setting,
freshness and applicability refs. Field/Current World may provide risk,
availability and uncertainty refs.

Attention may use these as priority inputs. It may not mutate Task, decide Task
completion, own Context, mutate Field/Current World or create a Cognitive Need.

Task completion is not Attention completion. Focus expiry or acquisition
failure is not Task failure. These effects are returned as refs for the
respective owner to adjudicate.

Goal-driven legacy value assessment must be interpreted as an admitted
relevance/policy input, not a direct Goal→Observation shortcut.
