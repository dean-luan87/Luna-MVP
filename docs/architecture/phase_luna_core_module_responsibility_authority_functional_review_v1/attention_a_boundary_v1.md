# Attention / A Boundary v1

## Canonical flow

`A Cognitive Need → Cognitive Requirement → Attention focus/priority/budget
candidate → Observation/FPO admission`.

A owns missing-information judgment, evidence relevance, Sufficiency,
Reconsideration and Next-step. Attention does not create, revise or close the
underlying Need.

Attention may derive focus dimensions from the Requirement:

- target object/region;
- candidate modality;
- urgency/expiry;
- resource cost;
- persistence/decay;
- expected evidence type.

That derivation is a candidate allocation representation, not semantic
reformulation of the Need.

Observation returns evidence, failure, target-unavailable or stale-focus refs.
Attention may update its focus candidate; A decides whether the Need is
satisfied or whether reconsideration is required.

Attention is not responsible for an incorrect A Need, A Sufficiency judgment or
A Next-step. A is not responsible for Attention's ranking/budget/provenance
error unless it ignored an explicit contract violation.
