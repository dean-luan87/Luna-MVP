# Resource Governance — Canonical Contract v1

Resource Governance provides global policy and bounded allocation constraints
over scarce cognitive and execution resources: compute, memory, GPU/CPU,
battery/energy, network, latency, token/context, sensor time, model invocations,
storage and bandwidth.

Brain owns long-horizon policy, protected reserves and global priority.
Resource Governance is the narrow policy/allocation constraint boundary;
Diagnostics supplies facts and runtime boundaries enforce them.

Disposition: **NARROW** as a Brain-owned/global constraint boundary. No new
Resource Manager or Scheduler is created.
