# B Contingency Reasoning Canonical Module Contract v1

## Canonical one-line purpose

**B-CR is an A-invoked bounded contingency reasoning service that explores counterfactual, alternative, exceptional, or deeper reasoning branches under an explicit A-issued scope and returns non-binding reasoning candidates to A.**

## Why B exists

B keeps expensive, exceptional, branching, counterfactual, risk-sensitive, or deeper exploration outside the normal A reasoning cycle. Its value is bounded exploration with explicit limits, provenance, observability, replaceability, and non-binding return—not a second local semantic authority.

## Final disposition

`KEEP` as a narrow independent service boundary. It is not preserved merely for historical “B” names: the existence test shows a distinct need for bounded budgeted exploration and isolated failure semantics.

Implementation timing: `CONTRACT_ONLY` / `CONTROLLED_SKELETON_LATER`; no B runtime is implemented here.
