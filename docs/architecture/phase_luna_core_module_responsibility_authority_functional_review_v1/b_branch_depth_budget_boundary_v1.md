# B-CR Branch, Depth and Budget Boundary

- Brain supplies global upper bounds through Safety, Permission, Resource and priority governance.
- A requests bounded B work within those bounds and the A grant.
- B executes only within the derived B grant and request scope.

The request defines branch/depth/resource limits and termination conditions. B cannot expand its own authority or budget. Cancellation, timeout, revocation, stale source, safety restriction and permission restriction terminate or degrade B. Partial return is preferred to unbounded continuation.

No fixed thresholds are canonical in the inspected repository; existing `depth_limit` and `branch_limit` are controlled candidate fields, not universal policy values.
