# Working Envelope Canonical Module Contract v1

## Purpose

Working Envelope is a Brain-admitted, Concern-scoped, versioned working-input
boundary. It binds source-owned references, governance constraints,
authority/grant scope, source versions, applicability, and provenance for one
bounded cognitive work context.

It is not Context, Current World, Semantic Working Outline, Cognitive Snapshot,
A reasoning state, Loop persistence, Brain global state, or a generic data
container.

## Authority and disposition

Disposition: **KEEP / NARROW**. The boundary owns envelope identity, admitted
binding, version map, invalidation/supersession record, and trace. It owns none
of the authoritative source payloads. No Working Envelope Manager is created.

Existing bridge assets are controlled candidate-only evidence. Runtime
generation and unified cross-source invalidation remain deferred.
