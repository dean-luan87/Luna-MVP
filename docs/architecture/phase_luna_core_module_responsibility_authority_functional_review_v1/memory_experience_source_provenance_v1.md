# Memory / Experience Source and Provenance v1

Candidate packages should minimally preserve reverse-linkable refs to source
identity, source versions, Concern, Context, Role/Perspective, Intent,
Decision, Task, Action, Outcome, evidence, timestamps, uncertainty/status,
and trace/provenance where relevant.

Candidate construction must not mutate Field, Current World, Context, Evidence,
Role, Perspective, Intent, Decision, Task, Action Result, Outcome, or Loop
source records. A source remains responsible for its own state correctness.

`Evidence`, `Field`, `Current World`, `Context`, `Perspective augmentation`,
`Task history`, `Action Result`, `Outcome`, `Loop history`, and `Diagnostics
history` are candidate sources only; none is automatically Memory or
Experience.
