# Observation Request Contract v1

Conceptual fields: request identity/version, Cognitive Requirement ref, focus
and target/ROI/object refs, modality, freshness, temporal/spatial scope,
expected evidence type, Attention priority/budget, Brain safety/permission/
resource refs, source versions, Grant scope, trace and provenance.

The request is a candidate/admission contract, not a Provider invocation or
semantic evidence judgment.
