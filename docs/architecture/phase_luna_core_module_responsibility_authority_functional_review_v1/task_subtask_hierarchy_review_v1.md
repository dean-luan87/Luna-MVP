# Task Subtask and Hierarchy Review v1

The repository contains `task_manager_task_decomposition_v1.py`, which builds
parent/child and sequential/parallel candidate structures, including
verification and recovery candidates. This supports Task decomposition as an
execution-organization capability.

The boundary is not a general Planner or Scheduler. Decomposition may occur
only under a supplied Decision/approved execution contract and bounded Task
scope. No canonical evidence currently justifies independent global planning,
autonomous scheduling, or Task-created Concern/Intent identity. Those cases
remain deferred.
