# A Reconsideration and Next-step Contract v1

## Reconsideration

A owns local reconsideration when triggered by new/conflicting evidence, source-version changes, failed hypotheses, stale Current World, Role/Perspective changes, Intent/Task changes, grant/constraint changes, B results, or resource/safety changes.

A may reconsider Need, Hypotheses, Sufficiency, and local Next-step. A may emit a NewConcernCandidate or escalation candidate, but Brain decides Concern admission/merge/split and global Goal consequences.

## Next-step vocabulary

Use existing controlled vocabulary where available: `CONTINUE`, `REQUEST_MORE_EVIDENCE`, `REPLAN`, `STOP_SUFFICIENT`, `DEFER`, `WAIT`, `PAUSE`, and the A/B bridge's bounded B request path. `BLOCKED` and `ESCALATE_TO_BRAIN` are semantic concepts unless an existing canonical enum/contract proves a specific representation.

A selects the semantic disposition. Capability/Observation, B, Brain and Loop respectively govern or execute their own consequence; no downstream module derives the meaning.
