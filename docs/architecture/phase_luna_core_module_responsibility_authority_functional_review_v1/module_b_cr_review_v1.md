# M04 B-CR — Module Review

## Identity and purpose

Canonical name: B Contingency Reasoning (B-CR); historical Route B is ambiguous and also refers to perception dual-route semantics. Evidence: `a_b_contingency_reasoning_bridge_controlled/`. If removed, Luna loses bounded alternative/contingency exploration while A continues reality reasoning.

## Functions and authority

`CORE`: execute only A-issued bounded contingency request, generate conditional scenario candidates, return bounded uncertainty/result. `SUPPORTING`: envelope/termination bookkeeping. `COMPATIBILITY_ONLY`: historical B route labels. B has `CANDIDATE_ONLY` reasoning output, not final Need, sufficiency, continuation, Concern, World Truth, Action, or Loop authority. Derived B grant is narrower than A grant, capability boundary, request scope, safety, permission, and resources.

Responsibility: B is responsible for respecting its bounded request and returning a truthful non-binding status; A owns initiation, scope, evaluation/adoption/rejection; Brain owns global governance and grants.

## Inputs, outputs, state, lifecycle

Inputs: A trigger/request, read-only envelope refs, derived grant, source state version, depth/branch/resource/safety limits. Outputs: non-binding contingency result and handoff to A, optionally additional-contingency-need ref. Local B reasoning state is isolated candidate state. Lifecycle: request → bounded reasoning → terminate on limits/stale/revocation → return to A; no self-resume or recursive delegation.

## Communication and negative boundaries

Allowed: A→B, B→A; Brain governs grants; Loop may record refs only. Forbidden: B→Loop mechanical command, B→Concern create/split/merge, B→B recursion, B→Provider, B→A self-adoption, B→World Truth. Historical Route B directness is a terminology/compatibility risk, not an accepted authority path.

## Walkthroughs

1. Normal: A requests “if blocked, alternatives”; B returns conditional candidates; A decides.
2. Blocked: derived grant expired or depth/resource limit reached; B returns bounded status, no direct action.
3. Changed world: source A state becomes stale; B stops/marks stale; A compares current reality and decides whether to request a new B.

## Overlap, gaps, evolution, disposition

Overlap: `TERMINOLOGY_OVERLAP` with historical Route B; no intended semantic overlap with A. Gaps: unified envelope/version propagation and future scheduler integration, both deferred; no real concurrency exists. B may evolve as bounded contingency computation, never a second Brain/A, Concern owner, or scheduler. **Disposition: KEEP**.

**Ledger summary:** authority = bounded execution only; responsibility = scope/termination compliance; receiver/evaluator = A; state = isolated local candidate; confidence = high at controlled seam.
