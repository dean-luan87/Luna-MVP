# Working Envelope Field, World, Evidence, and Constraint Boundary v1

The Envelope may carry Field, Context, Current World, Evidence, Safety,
Permission, Resource, and Diagnostics refs plus source versions. It does not
reduce Field, form Current World, admit Evidence, declare reality, classify
health, or define policy.

Constraint refs preserve scope, authority, Grant compatibility,
expiry/revocation, and provenance. A partial or stale constraint is reported
as an Envelope validity issue; Safety/Permission/Resource governance owns the
constraint meaning.
