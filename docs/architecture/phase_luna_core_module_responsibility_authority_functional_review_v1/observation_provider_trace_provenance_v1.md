# Observation / Provider Trace and Provenance v1

Required reverse-linkable chain:

`Cognitive Requirement → Attention ref → Capability Requirement → Executable
Capability → Observation Request → Provider Admission → Provider Invocation →
Provider Result → Evidence Candidate → Evidence Admission → Current World /
Field handoff → A`.

Every transition preserves request, source, version, provider, invocation,
payload, uncertainty, timestamp, trace and provenance refs.
