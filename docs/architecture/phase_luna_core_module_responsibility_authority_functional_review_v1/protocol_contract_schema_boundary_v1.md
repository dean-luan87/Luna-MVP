# Protocol Contract and Schema Boundary v1

Semantic contract, wire/data schema, canonical type, runtime object, and
serialized payload are distinct layers. A JSON schema, Markdown document,
Python dataclass, or registry file is an implementation artifact unless a
governed Protocol entry designates its contract role.

Repository implementation does not gain authority merely by existing.
Protocol Governance owns contract/version semantics; producer and consumer
owners retain payload/state correctness.
