# Loop State-Version Domains

| Version domain | Owner | Meaning |
|---|---|---|
| Loop mechanical state version | Loop | persistence/lifecycle transition lineage |
| Cognitive snapshot version | Cognitive State Formation | candidate snapshot assembly/version alignment |
| Source state version | Field/Context/Current World/Intent/Task/etc. | authoritative source lineage |
| Working Envelope version | envelope/source governance | admitted refs/constraints snapshot |
| Dynamic Flow version | Dynamic Flow compatibility computation | reusable transition/computation lineage |

These are not one global state version. Loop validates references to other versions and records them; it does not own or interpret their semantic freshness.
