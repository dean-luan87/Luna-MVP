# Model Authority and Responsibility v1

Model Governance owns wrong identity registration, version lineage, declared
path/checksum, dependency and loader declaration, model-side capability/provider
compatibility metadata, lifecycle errors, retirement/supersession, and
provenance loss.

Diagnostics owns observed-health mistakes. Runtime Admission owns executable
eligibility mistakes. Provider owns runtime invocation. Capability Governance
owns capability-side logical mapping. Authority and responsibility remain
paired; Model Governance does not inherit downstream execution responsibility.
