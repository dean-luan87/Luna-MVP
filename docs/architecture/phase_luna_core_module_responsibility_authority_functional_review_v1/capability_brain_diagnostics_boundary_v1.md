# Capability / Brain / System Diagnostics Boundary v1

Brain owns global safety, permission, resource, protected availability and
policy constraints. Brain may block or limit capability use but does not resolve
technical scope, select models or perform Runtime Admission details.

System Diagnostics supplies evidence for dependency health, runtime/device
health, resource diagnostics and environment readiness. It is not admission
authority.

Runtime Admission consumes Diagnostics evidence and combines it with Model
Manager, Provider compatibility, permission, resource and safety refs. Capability
Governance must not become a diagnostic probe or a hidden health authority.
