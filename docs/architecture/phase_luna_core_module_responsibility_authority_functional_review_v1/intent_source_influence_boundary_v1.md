# Intent Source Influence Boundary v1

| Source | Allowed influence | Authority retained by |
|---|---|---|
| Goal/Brain | purpose and global constraint signal | Brain for Goal; Intent Governance for Intent |
| Context/PCN/Field | candidate evidence and applicability context | respective source owner |
| Role/Perspective | role-conditioned proposal or invalidation signal | Role/Perspective owner |
| Emotion | modulation/candidate strength signal | Emotion owner |
| Memory/Experience | prior-match or historical candidate | Memory/Experience owner |
| Task | execution feedback and change proposal | Task Manager for Task; Intent Governance for Intent |
| A | reality-fit or intent-change proposal | A for local reasoning; Intent Governance for Intent |

All influences require source refs, versions and provenance. A changed Role,
Context or Field may make an Intent inapplicable; it does not mutate Intent.
Intent Governance evaluates the candidate change and either preserves,
versions, suspends or supersedes the Intent.
