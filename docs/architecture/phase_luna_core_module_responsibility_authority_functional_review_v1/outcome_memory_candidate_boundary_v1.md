# Outcome / MemoryCandidate Boundary v1

Potential MemoryCandidate input may include event/entity/relationship refs,
Goal/Concern relevance, accepted outcome refs, provenance, salience, retention,
privacy and uncertainty candidates.

Brain and Outcome Evaluation never write Memory. Memory Governance owns
admission and persistence; current contracts keep `candidate_only=True`,
`persisted=False` and `fact_admitted=False`.
