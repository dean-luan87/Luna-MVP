# Intent / A Reality Thinking Boundary v1

## Propagation

`Intent version/change → Working Envelope / Cognitive Snapshot impact → A
applicability assessment → A reconsideration when required`.

A consumes Intent refs and versions as a purpose/constraint input. A owns
Current Need, active Hypothesis, evidence relevance, Sufficiency,
Reconsideration, local Next-step and B-result adoption. Intent Governance does
not judge any of those fields.

A may emit an `IntentChangeCandidate` or escalation reference when reality no
longer fits an Intent. That is a proposal to Intent Governance, not a direct
mutation. An Intent version change may invalidate a Working Envelope or make
an A cycle stale; A decides the cognitive consequence.

Intent is not Cognitive Need. Intent answers the governed direction being
pursued; Need answers what information or reasoning is currently missing for
the admitted Concern.
