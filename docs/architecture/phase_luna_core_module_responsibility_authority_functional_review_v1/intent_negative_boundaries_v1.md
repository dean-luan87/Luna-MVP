# Intent Governance Negative Boundaries v1

Intent Governance must not become:

- Brain, Goal/Concern/global constraint governor, or final outcome adjudicator;
- A, Need/Hypothesis/Sufficiency/Reconsideration/Next-step authority;
- Semantic Module or a general semantic transformation engine;
- Task Manager, Planner, Scheduler, Attention controller or Action executor;
- Capability router, Logical Capability resolver, Runtime Admission owner,
  model/provider selector or Provider invoker;
- Loop controller or lifecycle-mechanics interpreter;
- Memory/Experience writer, learner or semantic compressor.

An Intent relation may constrain or inform those paths only through versioned,
read-only refs and governed handoffs.
