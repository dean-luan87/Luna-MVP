# Attention / Brain Resource Boundary v1

Brain owns global priority policy, safety, permission, resource ceilings,
protected priorities, conflict resolution and global constraints.

Brain may supply policy refs for:

- maximum budget and protected minimums;
- modality restrictions;
- safety floors or preemption rules;
- urgency ceilings/floors;
- permission/resource constraints;
- latency, energy, compute or invocation ceilings.

Attention allocates candidates inside those bounds. It must not override,
expand or reinterpret global policy. A local focus candidate cannot become a
global priority decision merely because Attention ranks it highly.

Repository conflict: older attention documents describe Self as final resource
governance and Attention as deciding what information is worth processing.
Under the adjudicated Luna backbone, Brain is the global governance owner and A
owns the Need; those older descriptions are retained as historical/compatible
planning language, not canonical authority.
