# Working Envelope Existence Test v1

| Alternative | Adjudication |
|---|---|
| No envelope; A reads all sources | Rejected: weakens Concern isolation, Grant enforcement, reproducibility, and version alignment. |
| Embedded in Brain | Rejected: Brain would own local input assembly rather than global governance. |
| Embedded in A | Rejected: A would own source binding and lose semantic-boundary isolation. |
| Equal to Context | Rejected: Context frames situation; Envelope admits cognitive-work inputs. |
| Equal to Cognitive State | Rejected: State Formation assembles a candidate snapshot; Envelope admits refs. |
| Independent narrow envelope | **KEEP**: isolates binding, versions, provenance, and invalidation. |

The independent boundary is justified by Concern scoping, Grant binding,
reproducibility, source ownership, and sibling Semantic/Snapshot production.
