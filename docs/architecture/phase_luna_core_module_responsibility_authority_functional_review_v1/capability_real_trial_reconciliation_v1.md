# Capability Real Trial Reconciliation v1

The migrated Real Capability trial provides evidence for:

`Cognitive Requirement → Scope/Logical Resolution → Runtime Admission →
Executable Capability Candidate → Provider Admission → Provider Invocation →
Observation Evidence → A/Dynamic Flow compatibility`.

The compatibility adapter consumes terminal/model admission candidates and
does not probe, calculate checksum, load or invoke. The trial still contains
legacy `_prepare()` admission/model-path construction and existing Provider
admission construction. Those are compatibility artifacts, not the canonical
Capability Governance owner.

The trial's one-invocation contract does not change this ownership conclusion:
Capability resolution and Runtime Admission precede Provider admission; actual
invocation remains Provider Governance/Observation behavior.
