# Intent Ontology Boundary v1

| Concept | Canonical meaning | Owner | Must not be confused with |
|---|---|---|---|
| Goal | globally governed desired direction/result | Brain | a local Need or Task |
| Intent | governed directed purpose/orientation/commitment | Intent Governance | evidence, hypothesis, or action |
| Concern | Brain-governed cognitive work identity | Brain | Intent or a Task |
| Cognitive Need | local information gap/objective for current reasoning | A | purpose/commitment |
| Cognitive Requirement | A-issued demand for cognition/evidence/capability | A/Capability bridge | Intent |
| Task | execution organization, dependencies and completion conditions | Task Manager | Intent completion |
| Action | externally executable operation | Action Governance/runtime | Intent itself |
| Potential Intent | pre-admission indication of a possible directed orientation | candidate-producing source / Intent Governance | admitted Intent |
| Intent Candidate | structured, uncertain, provenance-bearing proposal | Intent Governance | authoritative Intent |
| admitted/active Intent | governed identity/version usable as a constraint/ref | Intent Governance | A's current Need |

Intent is neither a generic user utterance nor a hidden cognitive truth. A
user/system signal may produce a Potential Intent or Intent Candidate, but the
candidate is not an Intent until the canonical owner admits it.

An admitted Intent can constrain interpretation, priority proposals, and
handoffs. It cannot directly create a Concern, Task, Capability request, or
Action. Those are separate governed transitions.
