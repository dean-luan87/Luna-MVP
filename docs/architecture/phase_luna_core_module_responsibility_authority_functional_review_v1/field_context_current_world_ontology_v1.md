# Field / Context / Current World Ontology v1

| Boundary | Canonical meaning | State character | Does not mean |
|---|---|---|---|
| Field | governed operational environmental state and transition lineage | source-owned/admitted operational state | World Truth, map, SLAM, cognition |
| Context | situation frame assembled from source refs and validity metadata | derived reference envelope | reality itself or a second Field |
| Current World | cognition-cycle representation of currently assembled world evidence | derived candidate snapshot | World Truth or writable Field |

## Existence test

The supported architecture is **D: three separate but narrowly defined
boundaries**. Merging them would lose important distinctions:

- Field needs deterministic source-state transitions and replay lineage.
- Context needs cross-source situational framing and temporal validity.
- Current World needs partial/contested observation-derived candidate assembly
  for a cognition cycle.

Current World is a derived representation, but that does not make it redundant:
it is the explicit boundary where evidence and source refs become a bounded
cognitive-cycle candidate without becoming source truth.

## Shared information principle

Base Field/Current World information remains source-oriented. Role-conditioned
Perspective overlays are derived augmentations and must not mutate either base
state. Context can carry their refs and applicability metadata only.
