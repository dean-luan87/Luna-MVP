# Attention Failure and Responsibility v1

| Condition | Attention response | Semantic/global owner |
|---|---|---|
| no valid Need | no valid focus candidate; report missing requirement | A |
| stale Need/source | stale candidate or invalidation ref | A/source owner |
| conflicting candidates | retain alternatives/conflict and bounded ranking | Brain policy; A consequence |
| insufficient budget | degraded/blocked allocation | Brain/resource governance and A |
| modality unavailable | alternative candidate or blocked status | Capability/Observation |
| target disappeared/stale ROI | expire or supersede focus | A decides Need impact |
| safety preemption | record policy-driven protected focus | Brain/Safety |
| permission/resource block | blocked handoff candidate | Brain/Permission/Resource |
| Observation failure | acquisition-failure/focus-stale ref | Observation/FPO; A |
| source-version mismatch | stale/invalidation candidate | source owner; A |

Attention owns incorrect ranking, budget candidate, stale-focus handling,
cross-focus contamination, provenance loss and invalid handoff formation.

Attention does not own wrong Need, A Sufficiency, Brain policy, Capability
resolution, Provider failure, evidence quality or Task readiness.
