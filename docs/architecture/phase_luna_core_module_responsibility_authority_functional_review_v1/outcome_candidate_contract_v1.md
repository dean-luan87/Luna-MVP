# Outcome Candidate Contract v1

An Outcome Candidate should preserve refs to Goal, Concern, Intent, Decision,
Task, Actions/Results, A evaluation, Field/Current World changes, source
versions, completion/partiality, uncertainty, safety/resource consequences,
user-visible consequence, unresolved follow-up, trace and provenance.

It is candidate-only (`final_adjudicated = false` conceptually) and must not
duplicate or mutate source payloads.
