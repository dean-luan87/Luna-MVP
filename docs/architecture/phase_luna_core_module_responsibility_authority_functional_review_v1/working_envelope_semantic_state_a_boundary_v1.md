# Working Envelope Semantic, State Formation, and A Boundary v1

Working Envelope is the input admission boundary. Semantic Module consumes its
refs and produces the Semantic Working Outline; it does not receive semantic
authority from the Envelope. Cognitive State Formation consumes Envelope and
source updates to assemble a version-aligned candidate snapshot.

The Envelope performs no expansion, folding, relation construction,
ambiguity resolution, snapshot assembly, Need judgment, Hypothesis judgment,
Sufficiency, Reconsideration, or Next-step. A consumes valid bindings and
decides semantic consequence.
