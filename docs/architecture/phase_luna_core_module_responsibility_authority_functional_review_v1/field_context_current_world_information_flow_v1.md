# Field / Context / Current World Information Flow v1

## Target flow

```text
Brain governance
    → Working Envelope (admitted refs/constraints)
    → Semantic Working Outline  ┐
    → Cognitive Snapshot         ├─ version-linked sibling products
    → A Concern-local reasoning ┘

Observation / Evidence
    → evidence and observation refs
    ├→ Current World candidate
    └→ Field Event candidate
         → Field Event Admission
         → Field State Reducer / Field version lineage

Field refs + Context refs + Current World refs
    → refreshed Working Envelope / sibling derived products
    → A reassessment
```

This is information flow, not one serial authority chain. Working Envelope is
not a Perspective engine; Semantic Module is not a Field/World owner; Cognitive
State Formation is not a Field/Context owner.

## Direction rules

1. Observation may create evidence and candidate handoffs.
2. Only governed Field admission/reducer may create a Field transition.
3. Current World may represent evidence and Field refs but cannot write Field.
4. Context may assemble refs but cannot mutate source projections.
5. A interprets source/candidate changes; no source boundary emits an A
   semantic decision directly.
6. Loop may persist refs and versions only.

## Normal / degraded cases

Normal: admitted evidence and valid Field/Context refs produce a complete-ish
Current World candidate, a sibling cognitive snapshot and A input.

Degraded: missing or mixed versions produce partial/stale/contested candidates;
the source boundary preserves the reason and A decides whether cognition must
reconsider. No module fabricates reality.
