# Diagnostics Static Validation and Runtime Boundary v1

Static validators and TestBoard/Model Test Lens can prove or display structural
properties at development/maintenance time. Runtime Diagnostics reports
observed operational state. Neither verifier authority nor UI visibility
becomes Runtime Admission, Provider admission, or policy authority.

A static PASS is not a live health PASS; a runtime finding does not rewrite a
contract. Existing candidate-only validators remain compatibility evidence and
are not executed by this phase.
