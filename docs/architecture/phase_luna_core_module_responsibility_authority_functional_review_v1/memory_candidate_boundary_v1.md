# MemoryCandidate Boundary v1

MemoryCandidate is candidate-only information for a future Memory Governance
boundary. It may reference source evidence, Field/Current World/Context,
Concern, Role/Perspective, Intent, Decision, Task, Action, Outcome, timestamps,
uncertainty, and provenance.

It is not Memory, a fact, a retrieval result, a retention decision, a storage
write, or a learning input with execution authority. Existing
`MemoryCandidateV1` and persistence-handoff types are controlled candidate
assets; their type fields and provisional states are not finalized by this
phase.

Future path: `MemoryCandidate → future Memory Governance admission → admitted
Memory`. Admission criteria, storage, retention, retrieval, decay, and
consolidation remain unspecified.
