# Capability State Ownership v1

| State | Classification | Owner |
|---|---|---|
| capability identity/taxonomy | authoritative | Capability Registry/Governance |
| Capability Slot identity/version | authoritative | Capability Governance |
| input/output/evidence contract | authoritative contract | Capability/Provider contract owners |
| Capability Requirement | candidate/ref | A or Task source; Capability consumes |
| Scope assessment | candidate result | Capability Governance |
| Logical Resolution | candidate result | Capability Governance |
| Model mapping | split authoritative metadata | Model Manager asset side + Capability contract side |
| Runtime Admission assessment | candidate result | Capability Admission Governance |
| Executable Capability Candidate | candidate | Runtime Admission boundary |
| Provider Admission | candidate/authoritative at Provider boundary | Provider Governance |
| execution result | external result | Provider/Observation owner |
| evidence | external candidate/admitted evidence | Observation/Gateway |
| versions/provenance | lineage refs | each source owner; carried downstream |

Capability Governance must not duplicate Model Asset, diagnostics, Provider,
Evidence or A Need state.
