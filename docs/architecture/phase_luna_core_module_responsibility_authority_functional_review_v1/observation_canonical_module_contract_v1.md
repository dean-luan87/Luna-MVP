# Observation / Acquisition Governance — Canonical Contract v1

## Purpose

Observation is Luna's governed acquisition request and result boundary for
obtaining new information about external or internal source state. It owns
acquisition scope, target/focus refs, modality, freshness, temporal/spatial
constraints, expected evidence and request lifecycle; Provider owns runtime
execution.

## Authority

Observation may admit, constrain, expire, cancel and correlate an acquisition
request/result. A owns the Cognitive Need and semantic consequence. Observation
does not create Need, select Capability/Model/Provider, declare Evidence truth,
mutate Field/Current World, or judge Sufficiency.

## Disposition

**NARROW** as an independent acquisition boundary. Timing:
`CONTRACT_ONLY / RUNTIME_CONSOLIDATION_LATER`.
