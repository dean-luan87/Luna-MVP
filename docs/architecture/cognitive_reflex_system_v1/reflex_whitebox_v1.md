# Cognitive Reflex Whitebox v1

```text
Constitution → Innate Reflex Candidate
Learning Experience → Pattern → Learned Reflex Candidate
Field + Role + Risk + Safety Constraint
                 ↓
            Reflex Governance
                 ↓
       Attention Candidate / Response Candidate
                 ↓
             Brain Escalation
```

## Control questions

- Who defines Innate Reflex? Constitution; no learning and no rule mutation.
- Who proposes Learned Reflex? Learning System as a candidate.
- Who validates admission? Reflex Governance.
- Who binds a trigger? Field Context, Active Role, Condition, Risk, and Safety Constraint.
- Who receives attention changes? Attention and Workspace interfaces.
- Who owns complex judgment? Brain.
- Who owns external-world mutation? Action Boundary and Runtime, outside this phase.
- Who revokes an incorrect reflex? Governance through lifecycle review.

## Isolation invariants

Reflex → Attention Adjustment Candidate and Reflex → Brain Escalation are
allowed. Reflex → automatic Action, Reflex → Safety Rule Mutation, Reflex → Value Mutation, Reflex → Identity Mutation, Reflex → Goal Mutation, Reflex → Decision, Reflex → Model Training, and Reflex → Prediction Runtime are
forbidden.

Innate Reflex and Learned Reflex remain distinguishable. Learned Reflex is
validated, context-bound, feedback-enabled, and revocable. This is a Planning Only artifact; no Action Runtime is implemented.
