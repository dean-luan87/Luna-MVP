# Cognitive Reflex Go / No-Go v1

## Required readiness checks

- Reflex is a Fast Response Mechanism and not Decision or Shortcut Brain.
- Innate Reflex is Constitution-sourced, fixed, high priority, and learning-forbidden.
- Learned Reflex is Experience/Pattern-sourced, validated, admitted, feedback-enabled, and revocable.
- Reflex Trigger preserves Condition, Field Context, Risk, Active Role, and Safety Constraint.
- Attention interface produces Attention Adjustment Candidate and Workspace Update only.
- Complex or uncertain candidates use Reflex Escalation Interface and Brain Review.
- Lifecycle supports Candidate, Review, Active, Triggered, Feedback, Adjusted, and Deprecated.

## Explicit prohibitions

No automatic Action, No automatic safety-rule modification, No automatic Value change, No automatic Personality change, No Emotion Runtime, No B Runtime, No Prediction Runtime, and No model training. Reflex cannot modify Safety Rules,
Value, Identity, Goal, Decision, or Action.

The Agent performs V0 static checks only, does not run the Final Phase Verifier,
and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.
