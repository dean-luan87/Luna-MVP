# A Route Cognitive Constitution Whitebox v1

## Constitutional flow

```text
Reality / Evidence
        ↓
Field / Attention / Self
        ↓
Situation / Goal / Task
        ↓
Option / Decision Candidate
        ↓
Brain Review / Authorization
        ↓
Action Boundary
        ↓
External Change → Evidence
        ↓
Outcome / Cause Attribution / Experience Candidate
```

## Constitutional assertions

- Brain owns Goal, Value, final Decision, and authorization.
- Reducer is the sole State mutation authority.
- Capability provides Evidence and never becomes a cognitive subject.
- Model Manager governs assets and health, not cognition.
- Attention allocates finite resources but cannot modify Goal or Decision.
- Field and Task provide context/continuity but cannot modify Goal or Reality.
- Experience informs candidates but does not replace Reality.
- Unknown is preserved.
- Self Identity remains continuous while Capability and State change.
- Action Boundary requests but does not execute.

This is a static constitutional trace. No Runtime, Scheduler, Model call, OCR,
VLM, SLAM, ASR, Camera, Hardware, Action, Emotion, Role, Social, B, or
external operation is executed.

Attention cannot modify Decision. No Scheduler, No Model call, No OCR, No VLM,
No SLAM, No ASR, No Camera, No Hardware, No Action, No Emotion, No Role, and
No Social are executed.

No B is executed.
