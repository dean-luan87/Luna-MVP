# A Route Cognitive Constitution Go / No-Go v1

## Required readiness checks

- Brain final authority is explicit for Intent, Goal, Value, Decision, and
  authorization.
- A Route, Reality, Field, Attention, Task, Action, Experience, Capability,
  Provider, and Model Manager boundaries are explicit.
- Mandatory Evidence → Reality → Field → Attention → Situation → Option →
  Decision → Brain → Action Boundary → Outcome → Experience flow is frozen.
- Reducer remains the sole State mutation authority.
- Unknown Preservation, Reality > Experience, and Self Identity Continuity are
  frozen principles.
- Provider, Model, OCR, VLM, SLAM, ASR, Camera, and Hardware cannot create
  Decision, Goal, Value, Field, or direct Reality mutation.
- Failure is candidate-based, multi-cause, diagnosable, and non-destructive.
- Regression baseline is declared before Capability Runtime integration.

## Explicit prohibitions

No Capability Runtime, No Model Manager Runtime, No real model call, No OCR,
No VLM, No SLAM, No ASR, No Camera, No Hardware, No Provider execution, No
Action execution, No automatic planning, No automatic learning, No Emotion, No
Role, No Social Runtime, No B Route, No Simulation, No direct Reality
mutation, No direct Goal mutation, No direct Decision mutation.

The Agent performs V0 static checks only, does not run the Final Phase
Verifier, and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`.

No Action execution, No Role, and No direct Reality mutation are permitted.
