# A Route Constitution External Capability Boundary v1

## Capability is an instrument

Capability is not Understanding, Situation, Decision, Goal, Reality, Brain, or
Action. It supplies Evidence through a governed Evidence Gateway.

Examples:

- OCR → Text Evidence;
- VLM → Scene Evidence Candidate;
- SLAM → Spatial Evidence Candidate;
- ASR → Audio/Text Evidence;
- Camera → sensor Evidence;
- Hardware → body/resource state Evidence.

No Provider may create a Field, modify Reality, create a Goal, change Value,
reach Brain directly, or execute Action. Provider Replacement changes only the
Evidence Quality Candidate and diagnostics.

## Future controlled chain

```text
Observation Requirement
  ↓
Capability Admission
  ↓
Capability Selection
  ↓
Provider Execution Boundary
  ↓
Evidence Gateway
  ↓
Reality Update Candidate
  ↓
Reducer
```

Model Manager manages Model Registry, version, resource profile, capability
mapping, and health state. It does not manage cognition or make a Decision.
Attention and Capability Governance produce selection candidates; the Model
itself never triggers selection.

## Failure contract

Provider unavailable, timeout, low quality, hallucination, protocol error, or
hardware degradation becomes Diagnostics plus Capability State/Confidence
Update Candidate. It does not become a Fact, Goal, Decision, or Self Identity
rewrite.

This constitution freeze does not authorize real model calls, OCR Runtime,
VLM Runtime, SLAM Runtime, ASR Runtime, Camera, Hardware Runtime, Action, or
external service operation.

Capability Confidence remains a candidate. No real model calls, No OCR Runtime,
No VLM Runtime, No SLAM Runtime, No ASR Runtime, No Camera, and No Hardware
Runtime are authorized.

No Hardware Runtime is authorized.
