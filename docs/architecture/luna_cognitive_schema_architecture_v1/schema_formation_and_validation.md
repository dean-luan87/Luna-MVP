# Schema Formation and Validation v1

```text
Memory Cluster
  -> Pattern Candidate
  -> Schema Candidate
  -> Validation
  -> Schema Admission
  -> Active Schema
```

Validation considers Repeatability, Context Stability, Prediction Support, and Contradiction. Prediction Support means improved future understanding as an evaluation signal; it does not authorize a Prediction Engine. Contradicting evidence, Unknown, provenance, and Field scope remain visible. One experience never becomes a rule automatically.
