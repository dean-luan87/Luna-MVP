# Failure Classification Model v1

An unexpected outcome must be attributed before it becomes useful experience.
The canonical failure classes are:

- **Perception Failure** — the input or observation was wrong or incomplete.
- **Understanding Failure** — evidence was structured or interpreted wrongly.
- **Decision Failure** — the selected candidate was unsuitable despite the
  available context.
- **Execution Failure** — the admitted action was not carried out as intended.
- **Environment Change** — Reality changed after the decision or during
  execution.

Classification is a candidate and may be multi-causal or Unknown. It carries
source evidence, time, Field, Decision, Action, confidence, and unresolved
unknowns. Misclassification would contaminate Memory and Schema, so a single
outcome cannot directly update a higher-order pattern.
