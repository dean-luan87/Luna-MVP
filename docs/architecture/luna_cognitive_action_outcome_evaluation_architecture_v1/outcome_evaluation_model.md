# Outcome Evaluation Model v1

Outcome Quality is a multi-dimensional evaluation candidate:

```text
Outcome Quality =
  Goal Achievement
  + Safety Result
  + Resource Efficiency
  + Prediction Accuracy
  + User Impact
```

The expression is not an implemented score and does not imply that safety can
be compensated by convenience. A safety failure remains a distinct result and
may require governance rejection or escalation.

Evaluation states may include Success, Failure, Partial Success, Unexpected
Outcome, and Unknown. A partial result preserves what worked and what did
not. An unknown result remains unknown rather than being inferred as failure or
success.

Evaluation outputs are candidates for Experience, Memory, Schema, Belief
Update, and Self Capability Adjustment. No output directly changes a source
state.
