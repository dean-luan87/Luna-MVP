# Cognitive Attention Global Architecture Go/No-Go v1

## Required checks

- Cognitive Attention Layer is horizontal across Reality, Cognitive Field,
  Experience, Brain, Capability, Memory, and Neural.
- Attention Perception, Attention Allocation, Attention Arbitration, Attention
  Memory, Attention Adaptation, and Attention Governance are represented.
- Brain provides Intent/Goal/Value and receives Brain Awareness Candidate;
  Brain retains final Decision authority.
- Field provides context and receives candidate-only updates.
- Memory returns Attention Prior Candidate and cannot override Reality.
- Capability returns Evidence Candidate through Capability Registry, Model
  Manager, Provider, and Evidence Gateway.
- Neural returns Fast Attention Candidate and resource/interrupt constraints;
  Neural does not decide or change Goal.
- Attention does not modify Reality, Goal, Decision, Brain, or Action.

## Explicit prohibitions

This architecture-only phase has No Runtime, No real model call, No Camera, No
OCR, No SLAM, No Hardware Runtime, No model training, No online learning, No
Emotion Runtime, No Role Runtime, No Social Field, No B Runtime, No Decision,
and No Action. Attention is not a control center and cannot replace Brain.

The agent performs V0 static checks only, does not run the Final Phase Verifier,
and stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION`. The user must execute
the phase verifier and return all required sections. Attention Memory is a
required global component. Attention does not modify Goal and does not modify
Decision. No OCR and No Emotion Runtime are enabled. Attention does not modify Decision.
