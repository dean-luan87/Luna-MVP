# Cognitive Attention Global Authority Boundary v1

## Authority table

| Layer | May provide | May not do |
|---|---|---|
| Reality | Evidence/State candidates | decide meaning or action |
| Cognitive Field | Situated context | set Goal or Decision |
| Attention | relevance, allocation, arbitration candidates | modify Reality, Goal, Decision, or Brain |
| Capability | local Evidence | become cognition or Reality authority |
| Memory/Experience | historical prior candidates | override current Reality |
| Neural | fast interrupt/resource candidates | change Goal or decide |
| Brain | Intent, Goal, final evaluation | bypass governance for hardware |

Attention remains subordinate to Brain authority while mediating finite
resources across layers. It is not a control center and not a second cognitive
subject. This is not a second cognitive subject.
