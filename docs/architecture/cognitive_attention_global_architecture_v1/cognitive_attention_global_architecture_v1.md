# Cognitive Attention Global Architecture v1

## Position

Cognitive Attention Layer is a horizontal resource-governance layer across the
Luna cognitive system. It is not a Cognitive Field submodule and it is not a
control center.

```text
                         Brain
                           ↓
                    Intent / Goal / Value
                           ↓
Reality ←→ Cognitive Field ←→ Experience
       ↘          ↓          ↙
             Cognitive Attention Layer
       ↙          ↓          ↘
 Capability    Memory       Neural
```

The layer contains Attention Perception, Attention Allocation, Attention
Arbitration, Attention Memory, Attention Adaptation, and Attention Governance.
It decides which information should receive finite cognitive resources; it
does not modify Reality, Goal, Decision, or Brain authority.

## Cross-layer flow

```text
Reality Evidence
      ↓
Attention Relevance Candidate
      ↓
Context Projection / Cognitive Field
      ↓
Brain Awareness Candidate
      ↓
Decision Evaluation
```

Field provides situated context. Brain provides Intent, Goal, and Value Context.
Experience provides historical pattern candidates. Capability provides
Evidence through governance. Neural provides fast interruption and resource
constraints. Attention mediates all of these as candidates.

## Experience loop

```text
Experience Candidate
      ↓
Attention Prior Candidate
      ↓
Future Observation
      ↓
New Experience Candidate
      ↓
Updated Attention Pattern Candidate
```

Memory stores selective, value-weighted candidates rather than a complete
recording. Future Emotion and Meaning weights are placeholders and cannot
control Attention in this phase. Future Simulation Field may use an Attention
Pattern candidate; B is not implemented.

## Authority boundary

Attention is not a control center. It cannot modify Reality, modify Goal,
modify Decision, replace Brain, issue Action, or become a second cognitive
subject. The Reducer remains the sole State mutation authority. This phase is
architecture-only and has no Runtime, real model call, Camera, OCR, SLAM, or
Hardware integration. Attention Arbitration and Observation Requirement are
global terms. Attention does not modify Goal and does not modify Decision. No
Runtime, No real model call, No Camera, No OCR, No SLAM, and No Hardware are
enabled. No Runtime is enabled.
