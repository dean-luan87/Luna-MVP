# Cognitive Attention Global Whitebox v1

```text
Reality Evidence ↔ Cognitive Field ↔ Experience
        ↘              ↓              ↙
          Cognitive Attention Layer
    Attention Perception / Allocation / Arbitration
       Memory / Adaptation / Governance
        ↙              ↓              ↘
Capability         Brain Awareness       Neural
        ↓              ↓                 ↓
Evidence        Brain Evaluation   Resource / Interrupt
```

Capability path:

```text
Attention Requirement → Capability Governance → Evidence → Reality Update Candidate
```

Memory path:

```text
Experience Candidate → Attention Prior Candidate → Future Attention
```

Brain path:

```text
Attention Candidate → Brain Awareness Candidate → Brain Evaluation → Decision
```

Attention is a horizontal layer, not a control center. It does not modify
Reality, Goal, Decision, Brain, or Action. Reducer remains the sole State
mutation authority. No Runtime, model training, Emotion Runtime, Role Runtime,
Social Field, or B Runtime is included. Attention Allocation, Attention
Arbitration, Attention Memory, Attention Adaptation, and Attention Governance
remain horizontal candidates. It does not modify Reality, does not modify Goal,
and does not modify Decision. Reducer remains the sole State mutation authority.
No model training, No Emotion Runtime, No Role Runtime, No Social Field, and No
B Runtime are included. Attention Arbitration is a horizontal component. No B Runtime is included.
