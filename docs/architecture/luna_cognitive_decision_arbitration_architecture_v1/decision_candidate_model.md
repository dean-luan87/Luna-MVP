# Decision Candidate Model v1

Each candidate is a bounded proposal, not a command:

```text
Candidate ID
Goal Reference
Expected Outcome
Utility Candidate
Risk Candidate
Confidence Candidate
Required Capability
Resource Cost Candidate
Reversibility
Unknowns
Provenance
```

Candidates may be generated by Brain from the current Field understanding.
They can be alternatives such as direct navigation, a rest reminder, or a
route-change suggestion. The candidate set must preserve alternatives and
unknowns rather than forcing an early choice.

Decision Candidate is distinct from Action Request. A candidate can be
selected for review while still being rejected by Self constraints or the
Action Boundary. No candidate in this phase changes Reality or executes a
device operation.
