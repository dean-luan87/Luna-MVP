# Structured Evidence First Boundary Freeze

This lightweight freeze establishes the distinction between human-authored
language and machine-observed evidence.

S1 remains valid because external human text enters the existing
`ProductLoopInputV1` contract through the Real User Input Adapter. The adapter
does not infer meaning or declare external truth.

S2 is corrected to raw camera/input-stream ingestion only. S3, S4 and S5 are
structured Vision/YOLO, OCR and SLAM/VIO evidence replacements respectively.
None may emit authoritative natural-language world conclusions.

Semantic compression remains deferred. No S0/S1 implementation or existing
owner is modified by this freeze.
