# Cognitive Attention Resource Allocation Implementation Plan v1

This phase is Architecture Only. The read-only inventory found reusable assets:

- Cognitive Attention Global Architecture and Competition/Arbitration for existing priority, preemption, persistence, release, and Brain boundaries;
- Attention Adaptation Stability and Field Attention/Decision Integration for experience, Memory, Field, and context interfaces;
- Cognitive Field, Belief/Understanding, Uncertainty Governance, Memory, Schema, Cognitive State, Self Regulation, and Self Rhythm for input context and resource constraints;
- Vision and MobileSAM/model-attention assets, which remain L5/model capability boundaries and are not changed or promoted into Cognitive Attention.

Duplicate risks include a second Attention Controller, a model-attention replacement layer, a Scheduler, or competing resource owners. Existing Runtime attention interfaces remain unchanged. Future implementation must map to the canonical Attention Layer through adapters and explicit Self governance.
