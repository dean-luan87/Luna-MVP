# Attention Resource Allocation Model v1

The conceptual value interface is:

```text
Attention Value = Task Importance + Safety Impact + Decision Impact
                 + Uncertainty Value + Conflict Value + Memory Relevance
                 - Resource Cost
```

The model is not implemented here. Unknown is weighted by impact, not by novelty alone. Belief Conflict may boost validation attention. Schema supplies a prior, while Current Evidence remains authoritative.
