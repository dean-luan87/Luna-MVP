# Luna Cognitive Attention Resource Allocation Architecture v1

## Position

Cognitive Attention is the allocator of limited cognition. It decides which Field information deserves processing, delaying, reduction, or suspension under finite compute, time, interaction, and Self resources. It is not Perception, visual/model Attention, Search, Reasoning, or Decision.

```text
Reality -> Field -> Information -> Attention Evaluation
        -> Attention Allocation Candidate -> Self Resource Governance
        -> Active Attention -> Understanding -> Decision Candidate
```

Attention proposes resource direction. Self owns final resource governance; Brain consumes the resulting context. Attention never produces Understanding, changes Reality, executes Action, or grants unlimited resources.
