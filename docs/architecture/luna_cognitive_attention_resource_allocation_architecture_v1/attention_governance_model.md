# Attention Governance Model v1

```text
Cognitive Kernel
  -> Attention Candidate
  -> Self Attention Governance
  -> Approved Attention Budget
  -> Cognitive Processing
```

Self reviews current state, resource availability, task, risk, rhythm, and interaction cost. Low resources may reject exhaustive analysis while retaining safety-related observation. Memory may be activated by Attention; it may not force-preempt Attention. Schema may provide a prior; it may not override Reality.
