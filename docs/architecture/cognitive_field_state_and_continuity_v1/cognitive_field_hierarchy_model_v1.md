# Cognitive Field Hierarchy Model v1

## Nested field structure

Fields may be nested by Reality scope:

```text
Reality Field: City
      ↓
Environment Field: Commercial District
      ↓
Place Field: Building / Mall
      ↓
Local Field: Room / Counter
      ↓
Task Context Field: Appointment / Navigation
```

Parent fields provide spatial, temporal, validity, and authority context. Child
fields refine scope and observation windows. A child field cannot contradict
stronger Reality State without a conflict candidate and Reducer review.
These parent fields and child fields define scope only.

## Boundary

Hierarchy is a scope and context relationship, not a command hierarchy. It does
not implement Brain Coordination, Multi-A Coordination, Role System, Emotional
Relationship Calculation, or field competition.
