# Cognitive Field State and Continuity Whitebox v1

```text
Reality / Self / Goal / Rule
          ↓
      Field State
 ┌────────┼─────────┐
 ↓        ↓         ↓
Stable  Adaptive  Transient
Layer    Layer     Layer
          ↓
   Leaving / Entering / Shared / Suspended Context
          ↓
       Field Transition
          ↓
     Hierarchical Field Scope
          ↓

          ↓
      Reality Update Candidate
```

Field continuity preserves Luna's stable Identity while adapting context. Field
state does not perform Decision, Prediction, Planning, Reasoning, Action, Role
Selection, Emotional Relationship Calculation, or Brain Coordination.
