# Cognitive Field State Model v1

## State composition

Every Cognitive Field carries:

- stable context reference;
- adaptive context;
- transient context;
- current Reality projection;
- Self context projection;
- Goal and Rule references;
- lifecycle, validity, Unknown, and Provenance.

Field State is a contextual organization state, not a Self replacement, Decision,
Memory, or Personality. A field may change its adaptive and transient contents
while its stable context and Identity references remain continuous.
Stable, Adaptive, and Transient are explicit Field State layers. Field State is not a Decision.

## State update

```text
Reality / Self / Goal / Rule change
              ↓
       Field State Update Candidate
              ↓
        Field Transition Review
```

Updates do not directly mutate Reality, Self, Goal, or Decision. The Reducer and
the declared adoption contract remain authoritative.
