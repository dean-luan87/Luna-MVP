# Cognitive Field Stable Adaptive Transient Model v1

## Three state layers

### Stable Layer

Cross-field references: Survival Constitution, Identity, Core Capability,
foundational Authority, safety boundaries, and validated long-term relationship
references.

### Adaptive Layer

Field-specific context that changes with location and situation: work files and
meetings in an office; roads, vehicles, and safety observations on a street.

### Transient Layer

One-time context such as “find this exit”, a temporary Observation Requirement,
or a short-lived resource constraint. It is released when its validity ends.

## Boundary

Stable, Adaptive, and Transient are context layers, not three personalities or
three A routes. Adaptive context does not rewrite Identity; Transient context does
not become permanent Memory without Experience Governance.
