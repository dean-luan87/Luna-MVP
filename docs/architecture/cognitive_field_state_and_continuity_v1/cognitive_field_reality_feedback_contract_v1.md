# Cognitive Field Reality Feedback Contract v1

## Bidirectional observation relation

```text
Reality Field
      ↓
Cognitive Field
      ↓
Observation Requirement
      ↓
Reality Update Candidate
      ↓
Reality Neural Operating Space
```

Field determines a current observation window and requirement candidate. It does
not determine the Goal or Decision. The resulting observation updates Reality
State only through Evidence, Provenance, Conflict, Unknown, and Reducer
governance.
The feedback contract does not execute Action.

## Boundary

Field-to-Reality feedback is an observation request relationship, not a field
writing arbitrary facts. It cannot execute Action, modify Hardware, infer value,
or bypass Capability Governance.
