# Cognitive Field State and Continuity Go/No-Go v1

## Required checks

- Stable Layer, Adaptive Layer, and Transient Layer are distinct.
- Field Transition Package contains Leaving Context, Entering Context, Shared Context, and Suspended Context.
- Field Continuity preserves Identity while allowing context change.
- Field hierarchy defines parent/child scope without command authority.
- Self relation is a Self Presentation Candidate, not a Role System or Identity change.
- Reality feedback is Reality Field → Cognitive Field → Observation Requirement → Reality Update Candidate.
- Parallel fields are structural placeholders only.
- Field does not perform Decision, Prediction, Planning, Reasoning, Action, or Emotional Relationship Calculation.
- Field is not Memory and cannot accumulate Personality.

## Hard prohibitions

No Role System, No Emotional Relationship Calculation, No Multi-A Coordination,
No Brain Coordination, no B, No Prediction, No Decision, No Action Runtime, no
real model, no OCR, no SLAM, no Hardware, no online learning, and no direct
Reality, Self, or State mutation.

## Verification handoff

The agent performs planning and V0 static checks only. User Terminal runs the
phase verifier and returns all required sections. The agent stops at
`WAITING_FOR_USER_TERMINAL_VERIFICATION`.

Target output: `COGNITIVE_FIELD_STATE_AND_CONTINUITY_ARCHITECTURE_READY_WITH_NOTES`.
