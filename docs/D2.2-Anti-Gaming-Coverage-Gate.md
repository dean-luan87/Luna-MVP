# D2.2 冻结文档（Anti-Gaming + Coverage Gate）

**目标**：让 D 在离线实验室里无法靠沉默/低风险刷分/单场景侥幸通过门禁。

**边界**：不改 runtime、不动主循环；只在 `simulation/logic` + `library/analyzer`（离线）里做评估增强。

---

## 1）Coverage Gate（防采样逃避）

**定义（对每个 replay_output.jsonl）**：

- **total_frames**：对齐比较的 seq 数（baseline/candidate 交集）
- **decision_valid_frames**：该帧有 `decision.safety_level` 且 `decision.control_mode` 非空
- **lookahead_valid_frames**：该帧有 `decision.pal_lookahead_m` 且 > 0（或非 null）

**指标**：

- `decision_coverage_ratio` = decision_valid_frames / total_frames
- `lookahead_coverage_ratio` = lookahead_valid_frames / total_frames
- `decision_coverage_delta` = candidate_ratio - baseline_ratio
- `lookahead_coverage_delta` = candidate_ratio - baseline_ratio

**门禁阈值（冻结）**：

- `MAX_COVERAGE_LOSS = 0.02`
- 若 `decision_coverage_delta < -MAX_COVERAGE_LOSS` → FAIL
- 若 `lookahead_coverage_delta < -MAX_COVERAGE_LOSS` → FAIL

**解释**：允许轻微浮动，但不允许 candidate 通过“少决策/少暴露前瞻”规避 regression/volatility。

## 2）Weighted Early Gain（防低风险刷分）

现有 `early_conservative_action_gain` 只看 first_guarded_seq，易在低风险帧提前进 GUARDED 刷分。

**冻结策略**：只在“高风险帧集合”上计算 early gain（v1 写入 scorecard，不进硬门禁）。

**高风险帧集合（v1 规则，冻结）**：

- `high_risk_seq = { seq | complexity_delta > 0 }`（来自 replay 或 explain）
- 若 complexity_delta 全为空或全 0，则 `weighted_early_gain_available = false`，标记 `WEIGHTED_EARLY_GAIN_UNAVAILABLE`

**指标**：

- `early_gain_weighted` = (baseline_first_guarded_in_high_risk - candidate_first_guarded_in_high_risk) / max(len(high_risk_seqs), 1)
- 硬门禁仍保留原 `early_conservative_action_gain >= 0`

---

## 3）Entropy Tags + 分桶一票否决

Golden 数据集必须有 tags。规则：**任一 tag bucket FAIL → 全局 FAIL**。

**tags 枚举（冻结）**：

- low_light
- cross_traffic
- dynamic_object
- crowded
- reflection
- narrow_passage

**门禁规则**：

- 对每个 bucket 计算 gate 结果：该 bucket 内**所有** episode 均 PASS 才算该 bucket PASS
- 任一 bucket FAIL → overall FAIL
- 未覆盖 bucket：不算 FAIL，但必须在报告里标记 `MISSING_COVERAGE:`，进入 C 人工审核队列

---

## 4）Gate 判定顺序（审计标准）

1. **Safety**：regression_count > 0 → FAIL  
2. **Safety**：danger_delta > 0 → FAIL  
3. **Stability**：volatility_index > 0.2 → FAIL  
4. **Efficiency**：guarded_ratio_delta > 0.30 → FAIL  
5. **Efficiency**：lookahead_drop_ratio > 0.15 → FAIL  
6. **Coverage**：decision_coverage_delta < -0.02 → FAIL  
7. **Coverage**：lookahead_coverage_delta < -0.02 → FAIL  
8. **Conservative timing**：early_conservative_action_gain < 0 → FAIL  

否则 PASS。**不得合并条件、不得颠倒顺序。**

## 5）失败原因枚举（打印用）

- `REGRESSION(n)`
- `DANGER_DELTA(n)`
- `VOLATILITY(x.xxx)`
- `EFF_GUARDED_RATIO_DELTA(x.xxx)`
- `EFF_LOOKAHEAD_DROP(x.xxx)`
- `COVERAGE_FAIL: decision_coverage_delta = x.xxx (max loss 0.02)`
- `COVERAGE_FAIL: lookahead_coverage_delta = x.xxx (max loss 0.02)`
- `EARLY_GAIN_NEG(x.xxx)`
- `BUCKET_FAIL:<tag>:<episode_id>:<reason>`

---

## 6）Scorecard 结构（D2.2）

- `regression_count`, `compared_count`, `volatility_index`, `early_conservative_action_gain`, `danger_delta`
- `efficiency`: `guarded_ratio_*`, `lookahead_*`, `lookahead_drop_ratio`
- `coverage`: `total_frames`, `decision_*_ratio_*`, `lookahead_*_ratio_*`, `decision_coverage_delta`, `lookahead_coverage_delta`
- `early`: `early_gain_weighted`, `weighted_early_gain_available`, `reason`（可选）
- `decision_coverage_delta`, `lookahead_coverage_delta` 同时挂在 scorecard 顶层供 gate 读取
