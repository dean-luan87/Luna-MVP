# 判断立场 × 裁决责任（复用模型）

## 结论（冻结）
立场冲突 ≠ 系统错误。  
错误是：无裁决权者做了裁决。

## 角色映射
- Observation / Proposal → B（事实候选）
- Instinct / Safety → C（本能否决）
- Arbitration / Authority → BC（裁决执行）

## 工业语义映射
- within envelope：硬约束（Gate / C）
- admissible：可进入裁决域（BC）
- acceptable：策略可接受（BC / 上层）
- safe enough：经验判断（可演化）

## 冲突处理原则
- B vs C：允许，C 可 veto
- B vs BC：允许，BC 仲裁
- C vs BC：不允许，BC 必须服从 C 的 veto
- 多 B 之间：允许，Arbiter 处理

## 体系内一句话
We don’t resolve opinions. We resolve authority.
