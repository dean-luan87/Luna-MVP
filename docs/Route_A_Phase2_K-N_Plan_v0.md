# 路线 A 后半段规划（K–N）v0

**状态说明**

- A–O 已封版（冻结）
- 本文档仅做规划与分层定义，不涉及实现、不引入参数调优
- 目标：为后续逐步拆解提供稳定、可回滚的路线图

---

## 总体原则（必须遵守）

1. **克制优先**：任何新增层不得削弱 A–O 已验证的“宁可不说，也不乱说”。
2. **只读优先**：能先观测就不立刻干预，能先统计就不自动调整。
3. **单向依赖**：K→L→M→N 单向流动，不允许反向控制 A–O。
4. **可冻结**：每一层都必须可以单独冻结、独立回放验证。

---

## K：介入意图层（Intervention Intent Layer）

### 目标

将“是否介入”升级为“为何介入”，但不涉及“说什么”。

K 层解决的是：

- 当系统获得介入资格时，这次介入想达成什么目的。

### 不做的事

- 不生成文本
- 不涉及情感、语气
- 不涉及强度（由 M 层决定）

### 核心输出

```json
{
  "intent": "ENV_AWARENESS",
  "source": "A3/PAL/Rhythm",
  "priority": "NORMAL"
}
```

### v0 意图集合（建议冻结）

- **INTENT_ENV_AWARENESS**：环境提醒 / 周围变化
- **INTENT_TASK_ASSIST**：任务协助 / 状态推进
- **INTENT_NAV_GUIDANCE**：方向 / 路径 / 导航
- **INTENT_SAFETY_ALERT**：安全提示（最高优先级）

### 与 G（仲裁）的关系

- K 层为仲裁提供语义维度
- 仲裁不再只是“哪个任务赢”，而是“哪种意图此刻更值得赢”

---

## L：介入内容规划层（Content Skeleton Layer）

### 目标

把“要说的话”拆成结构化内容骨架，而不是自然语言。

### 不做的事

- 不生成最终话术
- 不引入 Prompt / NLG

### 核心输出形式

```json
{
  "intent": "ENV_AWARENESS",
  "slots": {
    "object": "前方人群",
    "distance": "约5米",
    "direction": "正前方"
  }
}
```

### v0 slots 原则

- slots 只来自已有感知/状态
- slots 必须可为空（允许部分信息）
- 不做推理补全

### L 层价值

- 让“说话”从即兴变成可审计结构
- 为未来多语言 / 多表达形式留接口

---

## M：介入强度 × 形式映射层（Engagement Mapping Layer）

### 目标

决定说多重、说多急、是否打断，而不是是否介入。

### 输入

- complexity_effective
- PAL
- rhythm_state
- control_mode

### 核心输出

```json
{
  "level": "L2",
  "form": "VOICE_HINT"
}
```

### v0 强度定义（建议冻结）

- **L1**：弱提示 / Shadow / 不一定说
- **L2**：正常语音提醒
- **L3**：强打断（极少，仅安全类）

### M 层约束

- 不允许单一信号直接抬到 L3
- L3 必须经过 Rhythm + Safety 双门禁

---

## N：长期平衡与偏置观测层（Long-term Balance Observer）

### 目标

观察系统长期行为结构，而不是单次决策。

### 只做观测，不做控制

N 层不修改任何实时策略，只输出报告与告警。

### 关注指标（v0）

- 意图胜率分布（Intent Win Rate）
- 长期 deferred 统计
- ENGAGED 成功率随时间变化
- 不同设备 / 场景下的介入差异

### 输出示例

```json
{
  "period": "7d",
  "intent_bias": {
    "ENV_AWARENESS": "NORMAL",
    "TASK_ASSIST": "STARVING"
  }
}
```

---

## 推荐拆解顺序（后续执行用）

1. 先设计 **K**（意图集合 + 仲裁语义）
2. 再补 **L**（slots 定义，不生成语言）
3. 深化 **M**（你已部分完成）
4. 最后定义 **N** 的观测指标（不跑、不调）
