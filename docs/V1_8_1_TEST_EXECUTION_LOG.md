## 测试执行总原则（再压一遍）

### 执行顺序原则（不可调整）

这是"工程理性顺序"，不是功能顺序。

1. **先回滚，后功能**
2. **先危险，后正常**
3. **observer_mode=false 的结果优先级 > 一切**

### 硬规则

- **TC-06 / TC-07 任一 FAIL → 测试立即终止**
- **不允许"先看看功能好不好"**

### 目的

- 尽早发现"版本不可存在"的问题
- 避免把时间浪费在无意义的功能验证上
