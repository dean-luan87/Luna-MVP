# Cognitive Memory Runtime Integration Go/No-Go

## Readiness criterion

`LUNA_COGNITIVE_MEMORY_RUNTIME_INTEGRATION_READY` is emitted by the user-owned V2 verifier only after the governed pipeline and fixture pass.

## No-go conditions

- Self and Social Memory share a writer or store;
- a candidate is stored before explicit validation;
- Memory output is treated as Reality, Decision, Identity, or Goal authority;
- Self Rhythm directly controls resources;
- retrieval is unbounded or context-free;
- automatic learning, model training, parameter update, Emotion/Social Runtime, or external persistence appears.

The agent stops at `WAITING_FOR_USER_TERMINAL_VERIFICATION` and does not declare a final GO decision.
