# Memory Runtime Integration Whitebox

Memory is a governed reference source, not a decision authority. Experience Records preserve what happened and its provenance. Memory Candidates are not facts until an explicit review marks them validated. Storage rejects all other states.

Self Memory and Social Memory use separate adapters and stores. Retrieval is scope- and query-bound; it never replaces current Reality. Self Rhythm changes an advisory retention budget only. There is no disk/database persistence, model training, automatic learning, or direct Brain write.
