## 手工测试 Checklist

### 前置条件

- [ ] 系统已启动
- [ ] 摄像头正常工作
- [ ] 音频线程正常
- [ ] 日志正常输出

### 测试执行

#### TC-08: 静态场景抑制

**操作**:
1. 将摄像头对准静态场景（人 + 标志牌）
2. 保持 10 秒不动

**期望**:
- [ ] 第 1 次播报（场景描述）
- [ ] 后续不再播报（场景稳定抑制）
- [ ] 日志显示 `[SpeechPolicy] 抑制播报`

**验证**:
- [ ] 日志仍在写（无丢失）
- [ ] 音频线程不阻塞
- [ ] CPU 无明显抖动
- [ ] 无连续 TTS 重复

---

#### TC-09: 新物体进入

**操作**:
1. 保持静态场景稳定
2. 新增物体（如：自行车、包等）

**期望**:
- [ ] 场景变化时立即播报一次
- [ ] 新场景稳定后不再重复播报

**验证**:
- [ ] 场景变化检测正确
- [ ] 播报及时响应

---

#### TC-10: 危险优先级穿透

**操作**:
1. 场景稳定
2. 连续检测到"人靠近"或"危险物体"

**期望**:
- [ ] 危险消息可重复播报（受 TTL 8 秒控制）
- [ ] 优先级 3 穿透场景稳定抑制

**验证**:
- [ ] 危险消息优先级正确
- [ ] TTL 去重正常工作

---

#### TC-11: 快速抖动

**操作**:
1. 快速移动摄像头（模拟场景抖动）
2. 观察播报行为

**期望**:
- [ ] 不刷屏（不连续播报）
- [ ] 场景稳定后才播报

**验证**:
- [ ] 场景稳定判断正确
- [ ] 播报频率合理

---

## 关键验证点

### 1. 日志仍在写（无丢失）

- [ ] 检查日志文件是否正常写入
- [ ] 检查是否有日志丢失

### 2. 音频线程不阻塞

- [ ] 检查主循环是否流畅
- [ ] 检查视频帧处理是否连续
- [ ] 检查是否有卡顿

### 3. CPU 无明显抖动

- [ ] 监控 CPU 使用率
- [ ] 检查是否有异常峰值

### 4. 无连续 TTS 重复

- [ ] 检查是否有相同文本重复播报
- [ ] 检查 TTL 去重是否生效
