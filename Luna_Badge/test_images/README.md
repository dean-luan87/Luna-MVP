# 测试图片目录

将测试图片按关键词分类存放在此目录下。

## 目录结构

```
test_images/
├── 医院挂号大厅/
│   ├── image1.jpg
│   ├── image2.jpg
│   └── ...
├── 地铁入口/
│   ├── image1.jpg
│   └── ...
└── ...
```

## 支持的图片格式

- .jpg
- .jpeg
- .png
- .webp

## 使用方法

1. 创建关键词目录（如：`test_images/医院挂号大厅/`）
2. 将相关图片放入该目录
3. 在测试页面选择关键词，系统会自动随机选择一张图片进行测试
