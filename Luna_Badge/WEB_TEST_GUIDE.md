# Luna 手机端完整功能测试使用指南

## 📱 功能说明

这个Web服务器允许你在手机上通过浏览器测试Luna的所有核心功能，包括：

### 👁️ 视觉识别功能
- 📸 拍照识别
- 📁 上传图片识别
- 🎯 物体检测（YOLO）
- 📝 文字识别（OCR）
- 🪜 台阶检测
- 🚏 标识牌检测（洗手间、电梯、出口等）
- ⚠️ 危险环境检测（水域、工地、高台等）
- 🔍 综合检测（同时运行所有视觉模块）

### 🎤 语音功能
- 🎙️ 语音识别（Whisper）
- 🔊 语音合成（TTS，支持多种风格）
  - 😊 欢快风格
  - 😌 平静风格
  - ⚡ 紧急风格
  - 等等...

## 🚀 快速开始

### 1. 安装依赖

```bash
cd Luna_Badge
pip install flask flask-cors
```

### 2. 启动服务器

**方式一：使用启动脚本（推荐）**
```bash
./start_web_test.sh
```

**方式二：直接运行**
```bash
python web_test_server.py
```

### 3. 在手机上访问

1. **确保手机和Mac在同一WiFi网络下**

2. **查看Mac的IP地址**（启动脚本会自动显示）
   - 或者手动查看：系统设置 → 网络 → 查看IP地址

3. **在手机浏览器中打开**
   ```
   http://<你的Mac IP>:5000
   ```
   例如：`http://192.168.1.100:5000`

### 4. 使用步骤

#### 视觉识别标签页
1. 打开页面后，点击 **"📷 打开摄像头"**
2. 允许浏览器访问摄像头权限
3. 对准要识别的路标、标识牌等
4. 点击 **"📸 拍照识别"** 进行基础识别
5. 或使用专门的功能按钮：
   - **🪜 台阶检测** - 检测楼梯和台阶
   - **🚏 标识牌检测** - 识别各种标识牌
   - **⚠️ 危险检测** - 检测危险环境
   - **🔍 综合检测** - 运行所有检测模块

或者：
- 点击 **"📁 选择图片"** 上传已有图片

#### 语音功能标签页
1. **语音识别**：
   - 点击 **"🎤 开始录音"**
   - 说话
   - 点击 **"⏹️ 停止录音"**
   - 自动识别并显示结果

2. **语音合成**：
   - 在输入框中输入文字
   - 选择风格（欢快/平静/紧急）
   - 点击对应按钮播放语音

#### 综合检测标签页
- 点击 **"🔍 综合检测"** 运行所有视觉检测模块
- 生成完整的分析报告

## 🔧 常见问题

### Q: 手机无法访问？
**A:** 检查以下几点：
1. Mac和手机是否在同一WiFi网络
2. Mac防火墙是否允许5000端口
3. 确认IP地址是否正确

### Q: 摄像头无法打开？
**A:** 
1. 确保浏览器有摄像头权限
2. 尝试使用HTTPS（需要配置SSL证书）
3. 某些浏览器可能需要HTTPS才能访问摄像头

### Q: 识别速度慢？
**A:**
- 首次加载模型需要时间
- 图片较大时处理时间会较长
- 可以在代码中调整YOLO输入尺寸

### Q: 识别不准确？
**A:**
- 确保光线充足
- 图片清晰度足够
- 文字/标识牌完整可见

## 🛠️ 高级配置

### 修改端口
```bash
PORT=8080 python web_test_server.py
```

### 仅本地访问
修改 `web_test_server.py` 中的：
```python
app.run(host='127.0.0.1', port=port)  # 仅本地
```

### 使用HTTPS（推荐用于生产环境）
需要配置SSL证书，修改启动代码：
```python
app.run(host='0.0.0.0', port=port, ssl_context='adhoc')
```

## 📝 技术说明

- **后端**: Flask + VisionOCREngine
- **前端**: HTML5 + JavaScript (原生，无需框架)
- **识别引擎**: YOLOv8 + PaddleOCR
- **图片格式**: 支持JPEG、PNG等常见格式

## ⚠️ 注意事项

1. 这是测试版本，仅用于功能验证
2. 首次运行需要下载AI模型，可能需要较长时间
3. 确保Mac有足够的存储空间（模型文件较大）
4. 建议在稳定的WiFi环境下使用
