# V6.1 使用指南

## 快速开始

### 1. 安装可选依赖（推荐）

```bash
# 自动搜图功能
pip install duckduckgo-search

# 高级错误聚类（可选）
pip install scikit-learn numpy
```

### 2. 使用自动搜图功能

1. 打开 `http://localhost:9001`
2. 切换到"综合检测"标签页
3. 滚动到"V6.1：自动搜图 + 错误聚类"区域
4. 输入关键词列表（每行一个），例如：
   ```
   电梯
   斑马线
   公交站牌
   危险施工区
   公园入口
   人行道
   ```
5. 设置每个关键词下载数量（如：10）
6. 点击"🔍 自动搜索并下载图片"
7. 等待下载完成

### 3. 批量测试 + 错误聚类

1. 在同一个区域，点击"🚀 批量测试 + 错误聚类"
2. 系统会自动：
   - 从 `downloads/` 目录读取图片
   - 批量调用 Luna 场景描述
   - 自动判断匹配结果
   - 对错误样本进行聚类分析
   - 自动保存错误样本到训练数据

### 4. 查看结果

- **整体指标**：总样本数、准确率、Precision、Recall、F1
- **按关键词统计**：每个关键词的详细统计
- **错误聚类摘要**：按 cluster 分组的错误样本

### 5. 导出训练数据

点击"📥 导出 CSV"按钮，下载包含所有训练样本的 CSV 文件。

## 关键词建议

以下关键词适合测试：

- **交通场景**：斑马线、红绿灯路口、人行横道、公交站、地铁入口
- **建筑场景**：电梯、自动扶梯、商场入口、公园入口、医院入口
- **公共设施**：洗手间、服务台、收银台、咨询台、取号机
- **危险场景**：危险施工区、井盖打开、道路施工、电动车乱停

## 文件结构

```
Luna_Badge/
├── downloads/              # 自动下载的图片（V6.1）
│   ├── 电梯/
│   ├── 斑马线/
│   └── ...
├── test_images/            # 本地测试图片库（V2-V6）
│   ├── 医院挂号大厅/
│   └── ...
└── auto_test/
    └── training_samples.jsonl  # 训练样本存储
```

## API 接口

- `POST /api/auto/auto_search_images` - 自动搜索并下载图片
- `POST /api/auto/run_batch_with_clustering` - 批量测试 + 错误聚类
- `GET /api/auto/training_samples/export` - 导出训练样本

## 注意事项

1. **自动搜图功能**：需要安装 `duckduckgo-search`，否则功能不可用
2. **错误聚类**：如果没有 `scikit-learn`，会使用简化版本（按关键词分组）
3. **图片存储**：自动下载的图片保存在 `downloads/<keyword>/` 目录
4. **训练数据**：所有错误样本会自动保存到 `auto_test/training_samples.jsonl`
