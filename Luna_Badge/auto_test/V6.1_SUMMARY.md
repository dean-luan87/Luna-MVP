# V6.1 完整功能总结

## ✅ 已实现的功能

### 1. 自动搜图功能（DuckDuckGo）
- **文件**: `backend/auto_image_search.py`
- **功能**: 使用 DuckDuckGo 自动搜索并下载图片（无需 API key）
- **依赖**: `duckduckgo-search`（可选）

- **文件**: `backend/auto_test_clustering.py`
- **功能**: 对错误样本进行聚类分析
- **方法**: 
  - 高级版本：使用 sklearn KMeans（需要 scikit-learn）
  - 简化版本：按关键词分组（无需依赖）
- **降级**: 自动降级到简化版本

### 3. 批量测试 + 错误聚类 + 训练数据生成
- **文件**: `routes/auto_test_routes.py`
- **API**: `/api/auto/run_batch_with_clustering`
- **功能**:
  1. 批量测试（从 `downloads/` 或 `test_images/` 读取图片）
  2. 自动判断匹配结果
  3. 错误样本聚类分析
  4. 自动保存错误样本到训练数据

### 4. 自动搜图 API
- **文件**: `routes/auto_test_routes.py`
- **API**: `/api/auto/auto_search_images`
- **功能**: 自动搜索并下载图片到 `downloads/<keyword>/` 目录

### 5. 前端 UI 集成
- **文件**: `web_test_server.py`
- **功能**: 
  - V6.1 专用面板
  - 关键词列表输入
  - 自动搜图按钮
  - 批量测试 + 错误聚类按钮
  - 结果显示和统计

### 6. 训练数据自动保存
- **文件**: `backend/auto_training_store.py`
- **功能**: 自动保存错误样本到 `auto_test/training_samples.jsonl`
- **格式**: JSONL（每行一个 JSON 对象）

## 🔄 工作流程

### 完整流程（V6.1）

1. **自动搜图**
   ```
   用户输入关键词列表 → 调用 /api/auto/auto_search_images
   → DuckDuckGo 搜索图片 → 下载到 downloads/<keyword>/
   ```

2. **批量测试 + 错误聚类**
   ```
   调用 /api/auto/run_batch_with_clustering
   → AutoTestRunner 从 downloads/ 或 test_images/ 读取图片
   → 批量调用 Luna 场景描述
   → AutoTestJudger 自动判断匹配结果
   → ErrorClustering 对错误样本进行聚类
   → TrainingSampleStore 自动保存错误样本
   ```

3. **导出训练数据**
   ```
   点击"导出 CSV" → 调用 /api/auto/training_samples/export
   → 下载 luna_training_samples.csv
   ```

## 🎯 核心特性

### ✅ 三合一功能
1. **自动搜图**：无需手动准备图片
2. **错误聚类**：自动发现模型弱点
3. **训练数据生成**：自动收集和导出训练样本

### ✅ 智能降级
- 没有 `duckduckgo-search`：自动搜图不可用，但可以使用本地图库
- 没有 `scikit-learn`：使用简化版聚类（按关键词分组）

### ✅ 多目录支持
- `downloads/`：V6.1 自动下载的图片（优先）
- `test_images/`：V2-V6 本地图库（备用）

## 🚀 使用示例

### 示例 1：自动搜图 + 批量测试

```javascript
// 1. 自动搜图
fetch('/api/auto/auto_search_images', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    keywords: ['电梯', '斑马线', '公交站牌'],
    max_per_keyword: 10
  })
})

// 2. 批量测试 + 错误聚类
fetch('/api/auto/run_batch_with_clustering', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify({
    keywords: ['电梯', '斑马线', '公交站牌'],
    max_per_keyword: 10,
    n_clusters: 3
  })
})
```

### 示例 2：Python 脚本

```python
from backend.auto_image_search import search_images
from backend.auto_test_runner import AutoTestRunner
from backend.auto_test_clustering import ErrorClustering

# 1. 自动搜图
keywords = ['电梯', '斑马线', '公交站牌']
for kw in keywords:
    paths = search_images(kw, max_results=10)
    print(f'{kw}: 下载了 {len(paths)} 张图片')

# 2. 批量测试
runner = AutoTestRunner()
result = runner.run_batch(keywords, max_per_keyword=10)

# 3. 错误聚类
error_samples = [s for s in result['samples'] if not s.get('match')]
clustering = ErrorClustering()
clustered = clustering.cluster_errors(error_samples, n_clusters=3)
summary = clustering.get_cluster_summary(clustered)
print(f'错误聚类摘要: {summary}')
```

## 📝 注意事项

1. **依赖安装**（可选）：
   ```bash
   pip install duckduckgo-search  # 自动搜图功能
   pip install scikit-learn numpy  # 高级错误聚类
   ```

2. **目录权限**：确保 `downloads/` 和 `auto_test/` 目录可写

3. **图片格式**：支持 `.jpg`, `.jpeg`, `.png`, `.webp`

4. **训练数据格式**：JSONL（每行一个 JSON 对象），包含：
   - `keyword`: 关键词
   - `description`: 场景描述
   - `match_auto`: 自动判断结果
   - `human_label`: 人工标签（correct/wrong）
   - `cluster`: 聚类 ID
   - `image_base64`: 图片 base64（CSV 导出时不包含）
