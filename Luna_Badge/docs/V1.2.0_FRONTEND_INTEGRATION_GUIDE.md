## 📋 快速开始

### 1. 自动集成（推荐）

所有模块已自动集成，只需调用VisionBridge即可：

```javascript
// 从摄像头获取图像
const imageBlob = ...; // Blob或File对象

// 发送进行分析
VisionBridge.sendFrameForNavigationGuidance(imageBlob, {
  onSuccess: (events) => {
    console.log("策略事件:", events);
  },
  onError: (error) => {
    console.error("错误:", error);
  }
});
```

系统会自动：
1. ✅ 调用后端API获取策略指引
2. ✅ 转换为前端事件格式
3. ✅ 通过EventDispatcher分发
4. ✅ NavigationHook监听并处理
5. ✅ 冷却检查 → 优先级队列 → 融合 → TTS播报

## 🔄 完整数据流

```
用户摄像头/图像
    ↓
VisionBridge.sendFrameForNavigationGuidance(imageBlob)
    ↓
后端API: POST /api/navigation/visual_guidance
    ↓
后端策略分析（A-G七个策略）
    ↓
返回guidance数组
    ↓
VisionGuidanceAdapter.mapGuidanceResponse()
    ↓
转换为NAV_GUIDANCE事件数组
    ↓
EventDispatcher.dispatch(event)
    ↓
NavigationHook监听器触发
    ↓
StrategyCooldown.canTrigger() → 冷却检查
    ↓
StrategyPriorityQueue.enqueue() → 入队
    ↓
StrategyFusion.fuse() → 融合多个策略
    ↓
TTSManager.speak() → 语音播报
    ↓
用户听到提示
```

## 🎯 核心模块说明

### StrategyPriorityQueue（优先级队列）

**用途**: 按优先级排序策略事件，确保重要提示优先播报

**优先级**: critical(4) > high(3) > medium(2) > low(1)

**使用**:
```javascript
strategyQueue.enqueue({
  severity: "critical",
  message: "前方有危险",
  code: "NAV_STRAT_HAZARD"
});

const top = strategyQueue.peek(); // 查看最高优先级
const event = strategyQueue.dequeue(); // 取出最高优先级
```

---

### StrategyCooldown（冷却机制）

**用途**: 防止同类策略重复播报

**冷却时间**:
- `NAV_STRAT_LOW_LIGHT`: 8秒
- `NAV_STRAT_REFLECTIVE_SURFACE`: 10秒
- `NAV_STRAT_SHADOW_RISK`: 12秒
- `NAV_STRAT_MULTI_LIGHT`: 6秒
- `NAV_STRAT_WATER_REFLECTION`: 15秒
- `NAV_STRAT_BACKLIGHT`: 8秒
- `NAV_STRAT_DARK_ZONE_AHEAD`: 10秒

**使用**:
```javascript
if (strategyCooldown.canTrigger("NAV_STRAT_LOW_LIGHT")) {
  // 可以触发
} else {
  // 在冷却中
}

const remaining = strategyCooldown.getRemainingCooldown("NAV_STRAT_LOW_LIGHT");
console.log(`剩余冷却时间: ${remaining}ms`);
```

---

### StrategyFusion（策略融合器）

**用途**: 多个策略同一帧触发时合并成一句话

**融合规则**:
1. 存在critical → 直接返回critical（不融合）
2. 否则合并所有message，用"，"连接
3. 确定最高严重程度作为最终severity

**使用**:
```javascript
const events = [
  { severity: "warning", message: "当前环境光线较暗", code: "NAV_STRAT_LOW_LIGHT" },
  { severity: "info", message: "前方可能有积水", code: "NAV_STRAT_WATER_REFLECTION" }
];

const fused = strategyFusion.fuse(events);
// 结果: {
//   severity: "warning",
//   message: "当前环境光线较暗，前方可能有积水",
//   code: "NAV_STRAT_FUSED",
//   meta: { fused: true, count: 2 }
// }
```

---

### EventDispatcher（事件分发器）

**用途**: 统一的事件订阅和分发机制

**使用**:
```javascript
// 订阅事件
function handler(event) {
  if (event.type === "NAV_GUIDANCE") {
    console.log("收到导航指引:", event.message);
  }
}

EventDispatcher.subscribe(handler);

// 分发事件
EventDispatcher.dispatch({
  type: "NAV_GUIDANCE",
  severity: "warning",
  message: "前方有危险",
  code: "NAV_STRAT_HAZARD"
});

// 取消订阅
EventDispatcher.unsubscribe(handler);
```

---

### TTSManager（TTS管理器）

**用途**: 统一的TTS播报接口

**使用**:
```javascript
TTSManager.speak("前方有台阶，请注意", {
  priority: "HIGH",
  style: "urgent",
  onComplete: () => {
    console.log("播报完成");
  }
});
```

---

### VisionBridge（视觉桥接器）

**用途**: 与后端视觉API通信

**使用**:
```javascript
// multipart/form-data方式
const imageBlob = ...;
VisionBridge.sendFrameForNavigationGuidance(imageBlob, {
  onSuccess: (events) => {
    console.log("策略事件:", events);
  },
  onError: (error) => {
    console.error("错误:", error);
  }
});

// base64方式
const imageBase64 = "data:image/jpeg;base64,...";
VisionBridge.sendBase64ForNavigationGuidance(imageBase64);
```

---

### NavigationHook（导航指引Hook）

**用途**: 监听导航指引事件，自动处理策略并触发TTS

**自动设置**: 页面加载后自动设置监听器

**手动设置**:
```javascript
// 非React环境
const cleanup = setupNavigationGuidance();

// React环境
import { useNavigationGuidance } from "./core/navigation/NavigationHook";

function MyComponent() {
  useNavigationGuidance();
  // ...
}
```

## 🔧 配置和调优

### 调整冷却时间

编辑 `frontend/core/strategy/StrategyCooldown.js`:

```javascript
const STRATEGY_COOLDOWN = {
  NAV_STRAT_LOW_LIGHT: 8000,  // 改为10秒
  // ...
};
```

### 调整优先级权重

编辑 `frontend/core/strategy/StrategyPriorityQueue.js`:

```javascript
const PRIORITY_WEIGHTS = {
  critical: 4,
  high: 3,
  medium: 2,
  low: 1,
};
```

### 自定义融合规则

编辑 `frontend/core/strategy/StrategyFusion.js` 的 `fuse()` 方法。

## 🐛 故障排除

### 问题1: 策略事件没有触发TTS

**检查**:
1. 打开浏览器控制台，查看是否有错误
2. 检查EventDispatcher是否有订阅者
3. 检查NavigationHook是否已设置
4. 检查冷却时间是否过长

**调试**:
```javascript
// 检查EventDispatcher订阅者数量
console.log("订阅者数量:", EventDispatcher.getSubscriberCount());

// 手动触发事件测试
EventDispatcher.dispatch({
  type: "NAV_GUIDANCE",
  severity: "warning",
  message: "测试消息",
  code: "NAV_STRAT_LOW_LIGHT"
});
```

### 问题2: 策略重复播报

**原因**: 冷却机制未生效

**解决**: 检查StrategyCooldown是否正确初始化

### 问题3: 多个策略没有融合

**原因**: 融合规则可能过滤了某些策略

**解决**: 检查StrategyFusion的fuse()方法逻辑
