## 🔄 集成步骤

### 步骤1：初始化视觉路由

在 `web_test_server.py` 中，初始化完detector后：

```python
from backend.routes.vision_routes import init_vision_routes

# 初始化视觉路由
init_vision_routes(yolo_detector, scene_engine)
```

### 步骤2：访问测试界面

1. 启动服务器
2. 访问 `/frontend/test_center/new_test_interface.html`
3. 或直接在浏览器中打开该文件

### 步骤3：测试场景描述

```javascript
// 在前端控制台
const imageBase64 = "data:image/jpeg;base64,..."; // 你的图片base64
const result = await VisionBridge.describeScene(imageBase64);
console.log(result);
```

## 🎯 API使用示例

### 示例1：场景描述（新API）

```javascript
// 前端调用
const res = await fetch('/api/vision/describe_scene', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ image: imageBase64 })
});
const json = await res.json();
// json.data.summary - 自然语言摘要
// json.data.objects - 检测到的物体列表
// json.data.scene_type - 场景类型
```

### 示例2：导航场景描述（语音问答版）

```javascript
// 前端调用
const res = await fetch('/api/navigation/describe_scene', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ image: imageBase64 })
});
const json = await res.json();
// json.data.summary - 场景摘要
// json.data.tts - TTS文本（可直接播报）
```
