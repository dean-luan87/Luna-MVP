## 🔄 完整数据流（v2.0）

```
视觉帧
    ↓
VisionBridge.sendFrameForNavigationGuidance(imageBlob)
    ↓
后端API: POST /api/navigation/visual_guidance
    ↓
后端策略分析（A-G七个策略 + 评分计算）
    ↓
返回guidance数组（含score字段）
    ↓
VisionGuidanceAdapter.mapGuidanceResponse()
    ↓
EventDispatcher.dispatch(NAV_GUIDANCE事件)
    ↓
GuidanceProcessor.process()
    ↓
┌─────────────────────────────────────┐
│  1. StrategyFusion.add()            │
│     → 去重 + 融合相关策略            │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  2. GuidanceQueue.push()            │
│     → 冷却检查 + 优先级排序          │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  3. GuidanceProcessor._processNext() │
│     → 根据score设置TTS优先级         │
└─────────────────────────────────────┘
    ↓
TTSManager.speak()（优先级：HIGH/MEDIUM/LOW）
    ↓
GuidanceBubble.show()（根据score显示颜色）
    ↓
用户听到语音播报 + 看到提示卡片
```

```
└─────────────────────────────────────┘
```

## 🎨 UI展示规则（v2.0）

### 根据评分和风险等级显示

- **score > 80** → 红色气泡（critical），HIGH优先级TTS
- **score 50-80** → 黄色气泡（warning），MEDIUM优先级TTS
- **score < 50** → 蓝色气泡（info），LOW优先级TTS

### 错误提示

- **critical** → 红色气泡，显示6秒
- **error** → 橙色气泡，显示4秒
- **warning** → 黄色气泡，显示4秒
- **info** → 蓝色气泡，显示3秒

## 🔧 使用示例

### 1. 手动触发策略提示

```javascript
// 显示策略提示卡片
GuidanceBubble.show({
  message: "前方光线较暗，请注意脚下。",
  severity: "warning",
  duration: 4000,
  position: "bottom-right"
});

// 处理策略事件（含评分）
guidanceProcessor.process({
  type: "NAV_GUIDANCE",
  severity: "warning",
  code: "NAV_STRAT_LOW_LIGHT",
  message: "前方光线较暗，请注意脚下。",
  meta: {
    score: 75,  // 策略强度评分
    confidence: 0.85
  }
});
```

### 2. 手动触发错误事件

```javascript
// 映射错误码
const errorEvent = errorCodeMapper.map("NAV_VIS_001", "YOLO推理失败");

// 分发错误事件
EventDispatcher.dispatch(errorEvent);

// 或直接创建错误事件
EventDispatcher.dispatch({
  type: "NAV_ERROR",
  code: "NAV_VIS_001",
  message: "YOLO推理失败",
  severity: "error"
});
```

### 3. 获取错误历史

```javascript
// 获取所有错误历史
const errors = errorHandler.getHistory();

// 清空错误历史
errorHandler.clearHistory();
```
