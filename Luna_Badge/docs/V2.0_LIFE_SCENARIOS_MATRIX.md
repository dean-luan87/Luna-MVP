## 🎯 策略评分规则（0-100）

### 评分维度

1. **环境风险度** (0-40分)
   - 0-15: 低风险（信息提示）
   - 16-30: 中风险（注意级别）
   - 31-40: 高风险（警告级别）

2. **视觉干扰度** (0-30分)
   - 0-10: 轻微干扰
   - 11-20: 中等干扰
   - 21-30: 严重干扰

3. **碰撞/跌倒风险** (0-30分)
   - 0-10: 低风险
   - 11-20: 中风险
   - 21-30: 高风险

### 评分示例

```javascript
// 弱光环境（傍晚）
{
  environment_risk: 25,      // 中风险
  visual_interference: 20,   // 中等干扰
  collision_risk: 15,       // 中风险
  total_score: 60           // 注意级别
}

// 玻璃门反射（商场）
{
  environment_risk: 30,      // 高风险
  visual_interference: 25,   // 严重干扰
  collision_risk: 30,       // 高风险
  total_score: 85           // 警告级别
}

// 向下楼梯暗区
{
  environment_risk: 35,      // 高风险
  visual_interference: 30,   // 严重干扰
  collision_risk: 30,       // 高风险
  total_score: 95           // 高危级别
}
```

## 🔄 策略融合规则

### 多策略同时触发时的融合逻辑

1. **弱光 + 暗区跳变** → "前方光线偏暗，注意脚下。"
2. **反射面 + 多点光源** → "前方环境光线复杂，可能有反光区域，请小心行走。"
3. **影子 + 积水** → "前方地面可能有台阶或积水，请放慢速度，注意脚下。"
4. **弱光 + 强逆光** → "前方光线变化较大，请放慢速度，注意观察。"
5. **暗区 + 动态光源** → "前方有暗区，注意观察动态光源。"

## 🎨 UI展示规则

### 根据评分和风险等级显示

- **score > 80** → 红色气泡（critical）
- **score 50-80** → 黄色气泡（warning）
- **score < 50** → 蓝色气泡（info）

### TTS播报优先级

- **score > 80** → HIGH优先级，紧急播报
- **score 50-80** → MEDIUM优先级，正常播报
- **score < 50** → LOW优先级，可选播报
