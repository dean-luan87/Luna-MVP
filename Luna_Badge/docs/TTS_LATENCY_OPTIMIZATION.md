## 🔧 优化方案

### 1. 快速TTS缓存系统

**核心思路**: 预生成和缓存常用短语，避免重复网络请求

#### 实现要点：
- ✅ **预生成常用短语** - 启动时后台预生成14条常用提示
- ✅ **智能缓存索引** - MD5哈希索引，快速查找
- ✅ **缓存命中检测** - 优先检查缓存，命中则直接返回
- ✅ **后台保存** - 新生成的音频自动保存到缓存

## 📝 技术细节

### 1. 缓存键生成
```python
def _get_cache_key(text: str, voice: str, rate: str) -> str:
    key_str = f"{text}|{voice}|{rate}"
    return hashlib.md5(key_str.encode('utf-8')).hexdigest()
```

### 2. 缓存索引结构
```json
{
  "md5_hash": {
    "text": "前方有台阶，请小心",
    "voice": "zh-CN-XiaoxiaoNeural",
    "rate": "+50%",
    "file": "abc123.mp3",
    "size": 45678,
    "created_at": 1234567890
  }
}
```

### 3. 预生成策略
- **启动时**: 后台线程预生成常用短语
- **不阻塞**: 预生成不影响服务器启动
- **多风格**: 为每个短语生成3种常用风格（紧急/欢快/平静）
