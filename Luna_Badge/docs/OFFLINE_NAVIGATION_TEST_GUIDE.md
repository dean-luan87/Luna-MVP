# Luna 离线地图导航测试指南

## 📋 测试概述

本指南说明如何在**无WiFi环境**下测试Luna的完整地图引导能力，包括：
- 离线导航
- 视觉辅助导航（标识牌、台阶识别）
- 语音播报导航指令
- GPS定位（如果可用）

## 🎯 测试目标

验证Luna在户外环境下的完整导航能力：
1. ✅ 视觉识别（标识牌、台阶、路标）
2. ✅ 路径规划和导航
3. ✅ 语音播报导航指令
4. ✅ 离线地图记忆

## 📱 准备工作

### 1. 设备准备
- ✅ Mac电脑（运行服务器）
- ✅ iPhone（测试设备）
- ✅ 确保Mac和iPhone在同一WiFi（仅用于初始连接）
- ✅ 或者使用手机热点

### 2. 功能准备
- ✅ 已安装SSL证书（用于HTTPS访问）
- ✅ 摄像头权限已授权
- ✅ 麦克风权限已授权
- ✅ GPS定位权限（如果测试GPS功能）

### 3. 测试环境
- 🏞️ 选择一个熟悉的户外环境（公园、街道等）
- 📍 了解测试区域的标识牌和路标位置
- 🗺️ 准备测试路线（起点 → 目的地）

## 🚀 测试步骤

### 步骤1：启动服务器（在Mac上）

```bash
cd Luna_Badge
PORT=5001 python3 web_test_server.py
```

### 步骤2：连接设备

**方式A：使用WiFi（推荐）**
- 确保Mac和iPhone在同一WiFi
- 在iPhone Safari中访问：`https://192.168.3.213:5001`

**方式B：使用手机热点**
- iPhone开启个人热点
- Mac连接到iPhone热点
- 获取Mac的新IP地址
- 在iPhone Safari中访问新IP

**方式C：完全离线模式（需要修改代码）**
- 使用本地存储的地图数据
- 不依赖网络连接

### 步骤3：开始导航测试

#### 3.1 语音启动导航
1. 点击"语音功能"标签页
2. 点击"开始录音"
3. 说："我要去[目的地]"（例如："我要去公园入口"）
4. 点击"停止录音"
5. 系统识别后开始导航

#### 3.2 视觉辅助导航
1. 在导航过程中，使用"视觉识别"功能
2. 拍摄路标、标识牌、台阶等
3. 系统会自动识别并更新导航路径

#### 3.3 查看导航状态
- 导航指令会通过语音播报
- 识别结果会显示在页面上
- 可以随时查看当前导航状态

- **步骤**：

  4. 验证到达目的地提示

## 💡 测试技巧

1. **选择熟悉的环境**：了解路线和标识牌位置，便于验证
2. **分段测试**：先测试短距离导航，再测试长距离
3. **多角度拍摄**：从不同角度拍摄标识牌，测试识别稳定性
4. **记录问题**：记录识别不准确的情况，便于后续优化
5. **测试不同光照**：在不同光线条件下测试

## ⚠️ 注意事项

1. **GPS精度**：户外GPS精度较高，但可能受天气影响
2. **网络切换**：从WiFi切换到移动网络时，IP地址会变化
3. **电池消耗**：GPS和摄像头会消耗较多电量
4. **数据流量**：如果使用移动网络，注意数据流量消耗
5. **安全第一**：测试时注意交通安全，不要边走边看手机
