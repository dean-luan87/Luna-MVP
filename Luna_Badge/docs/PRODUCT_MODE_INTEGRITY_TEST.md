# Luna Badge 完整产品模式 - 完整性测试指南

## 📋 测试前准备

### 1. 确认服务器运行
- 服务器地址：`http://172.16.0.218:8080` 或 `http://198.18.0.1:8080`
- 确保服务器正在运行

### 2. 浏览器要求
- ✅ **推荐**：Chrome、Edge、Firefox（支持HTTP模式下的摄像头/麦克风）
- ⚠️ **Safari/iOS**：需要HTTPS才能使用摄像头/麦克风
- ✅ 确保浏览器允许摄像头和麦克风权限

### 3. 网络要求
- Mac和手机在同一WiFi网络下
- 防火墙允许8080端口

## 🔍 调试方法

### 1. 浏览器控制台（F12）

**打开方式**：
- Chrome/Edge：按 `F12` 或 `Cmd+Option+I` (Mac)
- Safari：`Cmd+Option+C` (Mac)

**查看日志**：
- 摄像头启动：查找 `📹`、`✅ 摄像头`
- 语音监听：查找 `🎤`、`✅ 麦克风`
- 视觉导航：查找 `🎥`、`🔍 正在扫描`
- 错误信息：查找 `❌`、`⚠️`

### 2. 网络请求检查

**打开方式**：
- 浏览器控制台 → Network（网络）标签

**检查点**：
- `/api/navigation/visual_guidance` - 视觉导航API
- `/api/tts` - 语音合成API
- `/api/recognize` - 语音识别API

**预期**：
- 请求状态码：200
- 响应时间：<1秒
- 无错误请求

### 3. 权限检查

**Chrome/Edge**：
- 地址栏左侧的锁图标 → 网站设置
- 检查摄像头和麦克风权限

**Safari**：
- Safari → 设置 → 网站 → 摄像头/麦克风
- 检查权限设置

## 🐛 常见问题排查

### 问题1：摄像头没反应

**可能原因**：
1. 浏览器权限未授予
2. Safari/iOS需要HTTPS
3. 摄像头被其他程序占用
4. 浏览器不支持

**解决方法**：
1. 检查浏览器权限设置
2. 使用Chrome浏览器测试
3. 关闭其他使用摄像头的应用
4. 刷新页面重试

### 问题2：语音没有

**可能原因**：
1. 麦克风权限未授予
2. 浏览器自动播放策略限制
3. 语音监听未启动
4. TTS服务异常

**解决方法**：
1. 检查浏览器权限设置
2. 点击页面任意位置启用音频
3. 查看浏览器控制台错误信息
4. 检查TTS API是否正常

### 问题3：视觉检测不更新

**可能原因**：
1. 摄像头未就绪
2. 网络请求失败
3. 服务器处理异常
4. 检测频率设置问题

**解决方法**：
1. 检查摄像头状态
2. 查看网络请求是否成功
3. 查看服务器日志
4. 检查浏览器控制台错误
