**功能**:

- ✅ `query()` - 场景问答（主动问答）

### 2. 后端API接口 ✅

**文件**: `luna_backend/routes/navigation_routes_v4.py`

**新增接口**:

#### `/api/navigation/describe_scene` (POST)
- **功能**: 场景描述（被动问询）
- **输入**: 图像（multipart或base64）或vision_result

- **功能**: 场景问答
- **输入**: question + 图像（可选）

## 🔄 完整数据流

### 被动问询流程

```
用户问："Luna，现在看到什么？"
    ↓
SceneDescriptionBridge.describeScene(image)
    ↓
POST /api/navigation/describe_scene
    ↓
SceneDescriptionEngine.describe(frame, vision_result)
    ↓
返回场景描述JSON
    ↓
EventDispatcher.dispatch(SCENE_DESCRIPTION事件)
    ↓
SceneDescriptionHook.handle()
    ↓
┌─────────────────────────────────────┐
│  1. TTS播报场景描述                  │
│  2. UI显示提示卡片                   │
│  3. 控制台日志输出                   │
└─────────────────────────────────────┘
```

### 主动问答流程

```
用户问："有没有人？"
    ↓
SceneDescriptionBridge.queryScene(question, image)
    ↓
POST /api/navigation/scene_query
    ↓
SceneDescriptionEngine.query(question, frame, vision_result)
    ↓
返回回答JSON
    ↓
EventDispatcher.dispatch(SCENE_QUERY事件)
    ↓
SceneDescriptionHook.handleQuery()
    ↓
TTS播报答案
```

## 🎯 使用示例

### 1. 被动问询（场景描述）

```javascript
// 从摄像头获取图像
const imageBlob = ...; // Blob或File对象

// 调用场景描述
SceneDescriptionBridge.describeScene(imageBlob, {
  onSuccess: (event) => {
    console.log("场景描述:", event.summary);
    // 系统会自动：
    // 1. TTS播报场景描述
    // 2. UI显示提示卡片
  },
  onError: (error) => {
    console.error("场景描述失败:", error);
  }
});
```

### 2. 主动问答

```javascript
// 用户问题
const question = "有没有人？";

// 调用场景问答
SceneDescriptionBridge.queryScene(question, imageBlob, {
  onSuccess: (result) => {
    console.log("回答:", result.answer);
    // 系统会自动TTS播报答案
  }
});
```

### 3. 集成到CommandParser

```javascript
// 在CommandParser.js中添加场景问询命令
if (t.includes('看到什么') || t.includes('现在是什么地方')) {
  // 获取当前图像
  const currentImage = getCurrentCameraFrame();
  
  SceneDescriptionBridge.describeScene(currentImage, {
    onSuccess: (event) => {
      speak(event.summary);
    }
  });
  
  return;
}

if (t.includes('有没有人') || t.includes('有没有楼梯')) {
  const currentImage = getCurrentCameraFrame();
  
  SceneDescriptionBridge.queryScene(t, currentImage, {
    onSuccess: (result) => {
      speak(result.answer);
    }
  });
  
  return;
}
```

## 🎨 场景分类

### 支持的场景类型

- `indoor_mall` - 购物中心
- `subway` - 地铁站
- `hospital` - 医院
- `dark_indoor` - 室内暗光环境
- `bright_indoor` - 室内明亮环境
- `unknown` - 未知环境

### 问题匹配

支持的问题类型：
- "有没有人？" / "有人吗？"
- "有没有楼梯？" / "有楼梯吗？"
- "现在是什么场景？" / "这是什么地方？"
- "室内还是室外？"
- "光线怎么样？"
- "有没有障碍物？"
- "最近的门在哪里？"
