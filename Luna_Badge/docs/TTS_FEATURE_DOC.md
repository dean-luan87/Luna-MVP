# Luna TTS 语音合成功能说明文档

## 📋 功能概述

Luna 项目的语音合成（TTS）功能基于 Microsoft Edge-TTS 实现，支持中文、英文、数字混合文本的语音合成。

## 🔢 输入限制

### 单次请求限制
- **最大字符数**: 5000 字符（含标点符号）
- **字符计算**: 中英文、数字、标点符号均按1个字符计算
- **示例**: 
  - "你好Hello123！" = 10个字符
  - "这是一个测试文本，包含中文、English和123数字。" = 28个字符

### 超长文本处理
当输入文本超过 5000 字符时，系统会自动进行**智能分段处理**：

1. **分段策略**:
   - 优先在句号（。）、问号（？）、感叹号（！）处分割
   - 优先在英文句号（.）、问号（?）、感叹号（!）处分割
   - 如果单个句子超过5000字符，则按字符强制分割

2. **分段处理流程**:
   ```
   输入文本（>5000字符）
   ↓
   智能分段（按句子边界）
   ↓
   逐段合成语音
   ↓
   自动拼接音频
   ↓
   返回完整音频
   ```

3. **分段信息**:
   - API响应中包含分段信息：
     ```json
     {
       "success": true,
       "audio": "...",
       "text_length": 8000,
       "segmented": true,
       "segments_count": 2
     }
     ```

## 🎨 支持的语音风格

| 风格 | 语音角色 | 语速调整 | 适用场景 |
|------|---------|---------|---------|
| 欢快 (cheerful) | zh-CN-XiaoxiaoNeural | +20% | 日常交流、欢迎语 |
| 平静 (calm) | zh-CN-XiaoyiNeural | -5% | 信息播报、说明 |
| 紧急 (urgent) | zh-CN-XiaoxiaoNeural | +50% | 警告、提醒 |
| 共情 (empathetic) | zh-CN-YunxiNeural | -10% | 安慰、理解 |
| 愤怒 (angry) | zh-CN-YunjianNeural | +30% | 警告、批评 |
| 温和 (gentle) | zh-CN-YunxiNeural | -15% | 温柔提示 |

## 💻 使用方式

### Web界面
1. 在"语音功能"标签页
2. 在文本框中输入要合成的文字（最多5000字符）
3. 实时显示字符计数：`当前字符数 / 5000`
4. 选择语音风格（欢快/平静/紧急）
5. 点击对应按钮播放

### API接口
```http
POST /api/tts
Content-Type: application/json

{
  "text": "要合成的文字内容",
  "style": "cheerful"  // 可选: cheerful, calm, urgent, empathetic, angry, gentle
}
```

**响应示例**:
```json
{
  "success": true,
  "audio": "base64编码的音频数据",
  "text_length": 1234,
  "segmented": false,
  "segments_count": 1
}
```

## ⚙️ 技术实现

### 后端实现
- **引擎**: Microsoft Edge-TTS
- **Python库**: `edge-tts` (版本 7.2.3+)
- **分段算法**: 智能句子边界识别 + 强制字符分割
- **音频格式**: MP3
- **编码方式**: Base64

### 前端实现
- **输入控件**: `<textarea>` (支持多行输入)
- **字符限制**: `maxlength="5000"`
- **实时计数**: JavaScript监听输入事件
- **颜色提示**: 
  - 0-4500字符: 灰色
  - 4500-5000字符: 黄色警告
  - 超过5000字符: 红色（前端限制，不会提交）

## 📊 性能指标

- **单段处理时间**: 约 1-3秒（取决于文本长度）
- **分段处理**: 每段独立处理，总时间 = 段数 × 单段时间
- **音频质量**: 24kHz采样率，MP3格式
- **内存占用**: 单次请求约 5-10MB（取决于文本长度）

## ⚠️ 注意事项

1. **网络要求**: Edge-TTS需要联网访问Microsoft服务
2. **字符计算**: 所有字符（包括空格、换行）都计入字符数
3. **分段延迟**: 超长文本分段处理会增加总处理时间
4. **浏览器限制**: 某些浏览器可能限制音频播放时长
5. **API限制**: Microsoft Edge-TTS可能有频率限制，大量请求时注意控制
