# 🧭 导航功能测试指南

## 📋 测试前准备

1. **确保服务器运行**：`web_test_server.py` 已启动
2. **确保模块初始化**：导航管理器、路径规划器、场景记忆系统都已初始化
3. **打开测试页面**：在手机浏览器访问 `https://<服务器IP>:5001`

---

## 🚀 测试步骤

### 方法一：完整导航流程（推荐）

#### 步骤1：规划路径
1. 打开"🧭 离线导航"标签页
2. 填写起点：例如 `挂号处`
3. 填写目的地（多个用逗号分隔）：例如 `检查室,报告领取`
4. 点击 **"🗺️ 规划路径"** 按钮
5. 查看路径规划结果（会显示路径段信息）

#### 步骤2：开始导航
1. 在"导航控制"区域，填写目的地：例如 `检查室`
2. 点击 **"▶️ 开始导航"** 按钮
3. 系统会：
   - 启动导航
   - 自动播报："开始导航到检查室，请跟随指引"
   - 显示导航状态

#### 步骤3：更新位置（模拟移动）
有两种方式更新位置：

**方式A：手动输入坐标**
1. 填写纬度（Lat）：例如 `31.2304`
2. 填写经度（Lng）：例如 `121.4737`
3. 点击 **"📍 更新位置"** 按钮
4. 系统会：
   - 更新当前位置
   - 检测障碍（如果摄像头开启）
   - 自动播报转弯提示（如果接近转弯点）
   - 显示导航状态

**方式B：使用GPS（真实位置）**
1. 点击 **"🌍 获取当前位置（需要GPS权限）"** 按钮
2. 允许浏览器访问位置权限
3. 系统会自动填充经纬度
4. 然后点击 **"📍 更新位置"**

#### 步骤4：模拟移动过程
- **多次更新位置**：模拟从起点到目的地的移动
- **每次更新时**：
  - 系统会检测是否接近转弯点
  - 如果检测到障碍，会自动播报警告
  - 显示当前导航状态（距离、方向等）

#### 步骤5：完成导航
1. 到达目的地后，点击 **"✅ 完成导航"** 按钮
2. 系统会播报："已到达检查室，导航完成"

---

### 方法二：快速测试（不规划路径）

如果不想先规划路径，可以直接开始导航：

1. 填写目的地：例如 `检查室`
2. 点击 **"▶️ 开始导航"**
3. 更新位置模拟移动
4. 完成导航


## 💡 测试技巧

### 1. 模拟真实移动
- 每次更新位置时，稍微改变经纬度（例如：+0.0001）
- 模拟从起点到目的地的渐进移动

### 2. 测试语音播报
- 确保TTS管理器已初始化
- 导航过程中会自动播报：
  - 开始导航提示
  - 转弯提示（"前方10米左转"）
  - 障碍警告（"请注意，前方有台阶"）
  - 到达提示（"已到达目的地"）

### 3. 测试障碍检测
- 在导航过程中，如果摄像头开启
- 更新位置时会自动检测障碍
- 检测到危险会自动播报

### 4. 测试离线功能
- 开始导航后，可以断开WiFi
- 导航功能会继续工作（因为使用本地地图数据）
- 但无法更新位置（需要网络通信）

## ⚠️ 常见问题

### Q1: 点击"开始导航"提示失败？
- **检查**：导航管理器是否已初始化
- **检查**：是否已有导航在进行中（需要先取消或完成）

### Q2: 更新位置没有反应？
- **检查**：是否已开始导航
- **检查**：经纬度格式是否正确（数字格式，例如：31.2304）

### Q3: 没有语音播报？
- **检查**：TTS管理器是否已初始化
- **检查**：浏览器是否允许自动播放音频

### Q4: 路径规划失败？
- **检查**：路径规划器是否已初始化
- **检查**：场景记忆系统是否有数据
- **提示**：可以先查看可用路径，了解系统中有哪些路径
