# Safari HTTPS 配置和使用指南

## ✅ HTTPS已启用

服务器已配置HTTPS，现在可以在Safari浏览器中使用摄像头和麦克风功能了！

## 📱 在iPhone上信任证书的步骤

### 方法1：通过Safari浏览器（推荐）

1. **访问HTTPS地址**
   - 在Safari中打开：`https://192.168.3.213:5001`
   - 会看到"此连接不是私人连接"的警告

2. **显示详细信息**
   - 点击地址栏的**锁图标**或**"显示详细信息"**

3. **访问网站**
   - 点击**"访问此网站"**或**"继续访问"**
   - 页面会加载，但证书还未完全信任

4. **完全信任证书**
   - 打开iPhone **设置** > **通用** > **关于本机**
   - 滚动到底部，点击 **"证书信任设置"**
   - 找到 **"Luna"** 或 **"192.168.3.213"** 证书
   - 打开开关，信任该证书

5. **重新访问**
   - 返回Safari，刷新页面
   - 现在应该可以正常使用摄像头和麦克风了

### 方法2：通过设置安装证书

1. **访问证书下载页面**
   - 在Safari中访问：`https://192.168.3.213:5001/ssl/cert.pem`
   - 会提示下载证书

2. **安装证书**
   - 点击**"允许"**下载
   - 打开**设置** > **已下载的描述文件**
   - 点击证书，输入密码安装

3. **信任证书**
   - 按照方法1的第4步操作

## 🔒 安全提示

- 这是**自签名证书**，仅用于开发和测试
- 浏览器会显示"不安全"警告，这是正常的
- 生产环境应使用正式的SSL证书（如Let's Encrypt）

## ⚠️ 常见问题

### Q: 仍然无法访问摄像头？
**A:** 
1. 检查是否已信任证书（设置 > 通用 > 证书信任设置）
2. 确保使用HTTPS访问（不是HTTP）
3. 检查Safari权限（设置 > Safari > 网站设置 > 摄像头）

### Q: 证书信任设置找不到？
**A:** 
- 确保iOS版本 >= 10.3
- 需要先访问一次HTTPS网站才会出现证书

### Q: 如何重新生成证书？
**A:** 
```bash
cd Luna_Badge
python3 generate_ssl_cert.py
# 输入 y 重新生成
```

## 📝 技术说明

- **证书类型**: 自签名X.509证书
- **有效期**: 365天
- **加密算法**: RSA 4096位
- **证书位置**: `Luna_Badge/ssl/cert.pem` 和 `key.pem`
