## 🎯 使用方式

### 1. 打开测试中心

**方式1**: 按 `T` 键（快捷键）

**方式2**: 在浏览器控制台执行
```javascript
window.testCenterUI.init();
```

### 2. 实时视觉调试

1. 点击"▶ 开启摄像头"
2. 点击"📷 捕获当前帧"
3. 查看右侧场景描述和检测结果

### 3. 功能测试

1. 切换到"② 功能测试台"标签
2. 点击任意功能按钮（如"YOLO Object Detection"）
3. 查看右侧测试结果

### 4. 场景模拟

1. 切换到"③ 联动场景模拟"标签
2. 选择场景（如"场景A：街道路况导航"）
3. 点击"运行场景"
4. 查看场景执行结果

### 5. 性能监控

1. 切换到"④ 性能监控"标签
2. 自动显示系统性能指标
3. 点击"刷新指标"手动更新

## 🔄 测试流程示例

### 示例1：测试YOLO检测

```javascript
// 1. 打开测试中心
window.testCenterUI.init();

// 2. 切换到功能测试标签
window.testCenterUI.switchTab('feature');

// 3. 启动摄像头
window.testCenterUI.startCamera();

// 4. 捕获帧并测试
window.testCenterUI.captureFrame();
// → 自动调用TestCenter.testYOLO()
// → 显示检测结果
```

### 示例2：运行街道路况导航场景

```javascript
// 准备多帧图像数据
const frames = [frame1_b64, frame2_b64, frame3_b64];

// 运行场景
TestCenter.scenarioStreetNavigation(frames, (result) => {
  console.log("场景执行结果:", result);
  // result包含：
  // - total_frames: 总帧数
  // - frames: 每帧的处理结果
  // - summary: 场景总结
});
```
