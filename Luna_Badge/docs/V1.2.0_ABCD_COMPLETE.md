### C. NavigationFSM × 策略行为联动 ✅

**文件**: `frontend/navigation_strategy_bridge.js`

**功能**:
- ✅ 策略事件自动映射到NavigationFSM行为
- ✅ critical级别 → GUIDANCE_STOP（建议停下）
- ✅ 近距离危险 → GUIDANCE_SLOW（放慢速度）
- ✅ 环境策略（弱光/反光）→ 仅提示，不改变导航状态
- ✅ 监听Hooks.onActionSuggest和EventDispatcher事件

**映射规则**:
- `severity === "critical"` → `GUIDANCE_STOP`
- `distance < 1.0m && hazard类型` → `GUIDANCE_SLOW`
- `LOW_LIGHT/REFLECTIVE/BACKLIGHT` → 不改变导航状态

## 🔄 完整数据流（更新版）

```
后端API: /api/navigation/visual_guidance
    ↓
VisionBridge.sendFrameForNavigationGuidance()
    ↓
VisionGuidanceAdapter.mapGuidanceResponse()
    ↓
EventDispatcher.dispatch(NAV_GUIDANCE事件)
    ↓
Hooks.onActionSuggest触发
    ↓
┌─────────────────────────────────────┐
│  并行处理（4个模块同时响应）          │
├─────────────────────────────────────┤
│ A. StrategyUI.show()                │
│    → 显示右下角提示条 + 播放声音     │
├─────────────────────────────────────┤
│ B. StrategyDebugPanel.logStrategy() │
│    → 记录到调试面板 + 控制台输出     │
├─────────────────────────────────────┤
│ C. NavigationStrategyBridge         │
│    → 调用NavigationFSM.handleEvent() │
├─────────────────────────────────────┤
│ D. SoundPack.play()                 │
│    → 播放对应严重程度的beep音       │
└─────────────────────────────────────┘
    ↓
NavigationHook（如果已加载）
    ↓
冷却检查 → 优先级队列 → 融合 → TTS播报
    ↓
用户看到提示条 + 听到语音 + 听到beep音
```

## 🎯 使用方式

### 自动集成（推荐）

所有模块已自动集成，只需调用VisionBridge即可：

```javascript
// 从摄像头获取图像
const imageBlob = ...;

VisionBridge.sendFrameForNavigationGuidance(imageBlob, {
  onSuccess: (events) => {
    console.log("策略事件:", events);
    // 系统会自动：
    // 1. 显示右下角提示条（StrategyUI）
    // 2. 记录到调试面板（StrategyDebugPanel）
    // 3. 触发导航行为（NavigationStrategyBridge）
    // 4. 播放提示音（SoundPack）
  }
});
```

### 手动触发

```javascript
// 手动显示提示条
StrategyUI.show({
  severity: "warning",
  message: "前方有台阶，请注意",
  code: "NAV_STRAT_STEP",
  durationMs: 4000
});

// 手动记录调试信息
StrategyDebugPanel.logStrategy({
  severity: "info",
  code: "NAV_STRAT_TEST",
  message: "测试消息"
});

// 手动触发导航行为
NavigationStrategyBridge.handleStrategy({
  severity: "critical",
  code: "NAV_STRAT_HAZARD",
  distance: 0.5
});

// 手动播放声音
SoundPack.play("critical");
```

## 🐛 故障排除

### 问题1: 提示条不显示

**检查**:
1. 打开浏览器控制台，查看是否有错误
2. 检查Hooks.onActionSuggest是否已注册
3. 检查EventDispatcher是否正常工作
4. 检查StrategyUI是否已加载

**调试**:
```javascript
// 手动测试
StrategyUI.show({
  severity: "warning",
  message: "测试消息",
  code: "TEST"
});
```

### 问题2: 声音不播放

**原因**: Web Audio API需要用户交互后才能播放

**解决**: 确保在用户交互（如点击按钮）后调用

### 问题3: 导航行为未触发

**检查**:
1. NavigationFSM是否存在
2. NavigationFSM.handleEvent方法是否存在
3. 策略映射规则是否正确

**调试**:
```javascript
// 检查映射结果
const navEvent = NavigationStrategyBridge.mapStrategyToNavEvent({
  severity: "critical",
  code: "NAV_STRAT_HAZARD"
});
console.log("映射结果:", navEvent);
```
