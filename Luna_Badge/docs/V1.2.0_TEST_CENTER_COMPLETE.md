## 🎯 使用方式

### 方式1：使用React组件（如果项目使用React）

```jsx
import TestCenter from './frontend/test_center/TestCenter';

// 在应用中渲染
<TestCenter />
```

### 方式2：使用纯JavaScript版本（当前已集成）

1. **打开测试中心**:
   - 按 `T` 键（快捷键）
   - 或在控制台执行：`window.testCenterUI.init()`

2. **使用测试功能**:
   ```javascript
   // 视觉调试
   TestCenter.visionDebug(imageBlob, (result) => {
     console.log("视觉结果:", result);
   });

   // 导航测试
   TestCenter.testNavigation('status', {}, (result) => {
     console.log("导航状态:", result);
   });

   // TTS测试
   TestCenter.testTTS("测试文本", "zh-CN-XiaoxiaoNeural", "+0%", (result) => {
     console.log("TTS结果:", result);
   });
   ```

## 🔄 测试流程示例

### 示例1：视觉调试

```javascript
// 1. 启动摄像头
window.testCenterUI.startCamera();

// 2. 捕获帧并测试
window.testCenterUI.captureFrame();
// → 自动调用TestCenter.visionDebug()
// → 显示检测结果和场景描述
```

### 示例2：导航步骤模拟

```javascript
// 模拟左转
fetch('/api/test/navigation/simulate_step', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ step: 'turn_left' })
})
.then(res => res.json())
.then(data => console.log('模拟结果:', data));
```

### 示例3：场景描述

```javascript
// 描述当前场景
TestCenter.scenarioLifeScenarios('find_restroom', imageBase64, (result) => {
  console.log('找到洗手间:', result.found);
  console.log('匹配文本:', result.details.matched_texts);
});
```
