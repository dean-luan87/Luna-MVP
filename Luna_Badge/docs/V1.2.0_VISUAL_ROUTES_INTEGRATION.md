### 1. 统一错误码规范 ✅

**文件**: `luna_backend/config/error_codes.py`

**特性**:
- ✅ 使用 `ErrorCategory` 枚举分类错误
- ✅ 使用 `ErrorCodeSpec` 数据类定义错误规范
- ✅ 支持通过 key（如 `"VISION_ENGINE_NOT_INITIALIZED"`）或 code（如 `"VIS-1001"`）查找错误
- ✅ 向后兼容：保留 `ERR` 类和 `ERROR_MESSAGES` 字典

**错误码分类**:
- `SYS` - 系统级错误
- `VIS` - 通用视觉
- `STEP` - 台阶检测
- `SBD` - 标识牌检测
- `HAZ` - 危险检测
- `FAC` - 公共设施检测
- `TL` - 红绿灯检测
- `CRD` - 人群密度
- `QUE` - 排队检测
- `DPT` - 门牌号识别
- `MAP` - 本地地图
- `NAV` - 导航视觉引导

### 2. 统一API响应封装 ✅

**文件**: `luna_backend/core/response.py`

**函数**:
- ✅ `api_success(data, message)` - 统一成功响应
- ✅ `api_error(error, details, status_code)` - 统一错误响应
- ✅ 向后兼容：`ok()` 和 `error()` 函数

**调用方式**:

## 🔄 集成步骤

### 步骤1：在 `web_test_server.py` 中导入和注册

```python
# web_test_server.py（片段示例）

from routes.visual_routes import create_visual_blueprint
from core.response import api_success, api_error  # 替换原有定义

# ... init_all_modules() 之后，app 创建之后：

if not init_all_modules():
    logger.warning("部分模块初始化失败，但服务器仍会启动")

# 创建并注册视觉 Blueprint
visual_bp = create_visual_blueprint(
    vision_engine=vision_engine,
    step_detector=step_detector,
    signboard_detector=signboard_detector,
    hazard_detector=hazard_detector,
    facility_detector=facility_detector,
    traffic_light_detector=traffic_light_detector,
    crowd_density_detector=crowd_density_detector,
    queue_detector=queue_detector,
    doorplate_reader=doorplate_reader,
    local_map_generator=local_map_generator,
    scene_memory_system=scene_memory_system,
    saliency_roi=saliency_roi,
    temporal_fusion=temporal_fusion,
    visual_language_fusion=visual_language_fusion,
    log_manager=log_manager,
)

app.register_blueprint(visual_bp)
```

## 🎯 错误码使用示例

### 示例1：视觉引擎未初始化

```python
if vision_engine is None:
    return api_error("VISION_ENGINE_NOT_INITIALIZED")
```

**响应**:
```json
{
  "success": false,
  "error": {
    "code": "VIS-1001",
    "category": "VIS",
    "message": "Vision engine is not initialized",
    "user_message": "视觉模块暂时不可用。"
  }
}
```

### 示例2：图片解码失败

```python
image_np = image_to_numpy(file.read())
if image_np is None:
    return api_error("VISION_IMAGE_DECODE_FAILED")
```

**响应**:
```json
{
  "success": false,
  "error": {
    "code": "VIS-1003",
    "category": "VIS",
    "message": "Failed to decode image",
    "user_message": "图片格式不支持或已损坏。"
  }
}
```
