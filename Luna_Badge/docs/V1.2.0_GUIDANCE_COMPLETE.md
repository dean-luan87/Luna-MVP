## ✅ 完成的工作

### 1. Guidance优先级队列 ✅

**文件**: `frontend/core/guidance/GuidanceQueue.js`

**功能**:
- ✅ 按优先级排序（critical > warning > info）
- ✅ 同优先级按时间顺序处理
- ✅ 内置冷却机制（默认2.5秒）
- ✅ 自动去重（相同code在冷却期内不重复）

**优先级权重**:
- `critical`: 3
- `warning`: 2
- `info`: 1

**冷却机制**:
- 每个策略代码独立冷却时间
- 默认冷却：2.5秒
- 可动态调整冷却时间

---

### 2. Guidance去重融合器 ✅

**文件**: `frontend/core/guidance/StrategyFusion.js`

**功能**:
- ✅ 避免重复策略播报
- ✅ 智能融合相关策略
- ✅ 1.5秒融合窗口
- ✅ 自动重置激活状态

**融合规则**:
1. **弱光 + 暗区跳变** → "前方光线偏暗，注意脚下。"
2. **反射面 + 多点光源** → "前方环境光线复杂，可能有反光区域，请小心行走。"
3. **影子 + 积水** → "前方地面可能有台阶或积水，请放慢速度，注意脚下。"
4. **弱光 + 强逆光** → "前方光线变化较大，请放慢速度，注意观察。"
5. **存在critical** → 直接返回critical（不融合）
6. **默认** → 合并消息，取最高严重程度

---

### 3. Guidance处理器 ✅

**文件**: `frontend/core/guidance/GuidanceProcessor.js`

**功能**:
- ✅ 整合融合器 + 优先级队列 + TTS播报
- ✅ 自动监听EventDispatcher和Hooks事件
- ✅ 自动处理队列（每500ms处理一次）
- ✅ 支持多种TTS后端（TTSManager/speakText/PriorityTTSQueue）

**处理流程**:
1. 接收NAV_GUIDANCE事件
2. 送入融合器（去重+融合）
3. 进入优先级队列（冷却检查）
4. 自动处理队列（按优先级播报）
5. 触发TTS播报

## 🔄 完整数据流（最终版）

```
视觉帧
    ↓
VisionBridge.sendFrameForNavigationGuidance(imageBlob)
    ↓
后端API: POST /api/navigation/visual_guidance
    ↓
后端策略分析（A-G七个策略）
    ↓
返回guidance数组
    ↓
VisionGuidanceAdapter.mapGuidanceResponse()
    ↓
EventDispatcher.dispatch(NAV_GUIDANCE事件)
    ↓
GuidanceProcessor.process()
    ↓
┌─────────────────────────────────────┐
│  1. StrategyFusion.add()            │
│     → 去重 + 融合相关策略            │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  2. GuidanceQueue.push()            │
│     → 冷却检查 + 优先级排序          │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  3. GuidanceProcessor._processNext() │
│     → 自动处理队列（每500ms）        │
└─────────────────────────────────────┘
    ↓
TTSManager.speak()
    ↓
用户听到语音播报
```

## 🎯 使用方式

### 自动集成（推荐）

只需调用VisionBridge，系统会自动完成所有处理：

```javascript
// 从摄像头获取图像
const imageBlob = ...; // Blob或File对象

VisionBridge.sendFrameForNavigationGuidance(imageBlob, {
  onSuccess: (events) => {
    console.log("策略事件:", events);
    // 系统会自动：
    // 1. 融合去重
    // 2. 优先级排序
    // 3. 冷却过滤
    // 4. TTS播报
  }
});
```

### 手动处理

```javascript
// 手动处理策略事件
guidanceProcessor.process({
  type: "NAV_GUIDANCE",
  severity: "warning",
  code: "NAV_STRAT_LOW_LIGHT",
  message: "当前环境光线较暗，请放慢速度，注意脚下。"
});

// 手动清空
guidanceProcessor.clear();
```

## 🔧 配置和调优

### 调整冷却时间

```javascript
// 设置全局冷却时间
guidanceQueue.setCooldown(5000); // 5秒

// 重置特定策略的冷却
guidanceQueue.resetCooldown("NAV_STRAT_LOW_LIGHT");
```

### 调整融合窗口

编辑 `frontend/core/guidance/StrategyFusion.js`:

```javascript
this.fusionWindow = 2000; // 改为2秒
```

编辑 `frontend/core/guidance/StrategyFusion.js` 的 `merge()` 方法。
