✨ 新增功能
================================================================================

【v1.1】浏览器 UI 面板版自动测试
  - 单张图片上传 + 关键词测试
  - 自动场景描述 + 匹配判断
  - 人工校对界面 + CSV 导出
  - 支持 17 个关键词

【v1.2】视频自动检测
  - 视频上传 + 自动抽帧（每隔10帧）
  - 批量场景描述 + 匹配统计
  - 整体准确率计算

【v1.3】多场景 Playlist 自动测试
  - 一次性测试多个场景关键词
  - 基于单张图片循环测试
  - 汇总表格展示

【v2.0】真实设备数据上报骨架
  - 设备事件上报接口
  - 简单指标统计
  - JSONL 格式日志存储

【TestEngine v1.0】完整的自动化测试框架
  - 自动搜图（DuckDuckGo）
  - 自动检测（YOLO + OCR）
  - 自动评估、聚类、报告生成
  - 5 个预置场景配置

【V6.1】自动搜图 + 错误聚类增强
  - DuckDuckGo 图片搜索（无需 API key）
  - 批量测试 + 错误聚类分析
  - 训练数据自动生成
