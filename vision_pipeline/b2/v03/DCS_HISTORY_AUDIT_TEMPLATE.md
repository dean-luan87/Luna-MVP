# DCS 历史版本回审报告模板

## 📋 审计目标
使用 DCS（Design Consistency Score）规则，回审 B2 v0.1 / v0.2 / v0.3 的历史 decision / timeline / summary，找出所有"越权预测"的历史输出。

---

## 🎯 判定标准（DCS 判刑标准）

### ❌ 判为「越权预测」的条件（任一命中即 FAIL）

1. **输出语义等价于：**
   - "风险已经确定"
   - "世界状态已经变化"
   - "必然会发生"

2. **输出没有显式条件前提**
   - 没有"在当前行为模式不变的前提下"

3. **输出没有保留 C / 用户确认空间**
   - 剥夺了 C 的核验权

## 🔍 审计执行说明

### 输入数据要求
- 使用已有 v0.1–v0.3 的 trace / timeline
- 每个版本任选连续 30 秒片段即可

### 判定规则
- 若输出等价于"风险已确认 / 必然发生" → FAIL
- 若输出缺少条件前提 → FAIL
- 若输出剥夺了 C 的核验权 → FAIL

### 输出要求
- 必须按照上述格式输出
- 每个违规项必须包含所有字段

## 🔒 不可逆的架构红线

### 基于历史审计的硬约束

1. **禁止"世界描述"语义**
   - v0.1 的失败证明：B 不能描述世界，只能预警行为影响

2. **禁止"确认性风险"表述**
   - v0.1–v0.3 的失败证明：B 不能确认风险，只能条件预警

3. **强制条件前提**
   - v0.1–v0.3 的失败证明：所有输出必须包含"如果继续当前行为模式"的前提

4. **保留 C 的核验权**
   - v0.1–v0.3 的失败证明：B 不能剥夺 C 的确认空间
