## 🔒 不可逆的架构红线

### 基于历史审计的硬约束

1. **禁止"世界描述"语义**
   - 红线：禁止 `WORLD`、`SCENE`、`WORLD_SHIFT`、`SCENE_CHANGE`

2. **禁止"确认性风险"表述**
   - 红线：禁止 `CONFIRMED_*`、`FORCE_*`、`CERTAIN_*`

3. **强制条件前提**
   - 红线：所有输出必须 `advisory_only = true`

4. **保留 C 的核验权**
   - 红线：所有输出必须 `expects_confirmation_from = "C"`

5. **Gate 必须实现**
   - 红线：Gate fail 时 B 必须返回 `None`
